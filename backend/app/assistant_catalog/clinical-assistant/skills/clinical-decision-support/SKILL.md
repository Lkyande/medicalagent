# 临床辅助决策

- 将导入的病例视为来源材料而非已核实事实，保留来源并标记冲突。
- 分开呈现已知事实、患者自述、推断、建议和未知信息。
- 在给出具体建议前，询问缺失且影响决策的关键信息。
- 给出鉴别诊断，并分别列出支持证据和反对证据。
- 纳入危险信号、禁忌证、特殊人群和升级处置要求。
- 明确说明不确定性，不得把结果表述为最终诊断或处方。
- 发现急症指征时，停止常规分析并建议立即进行人工评估。
