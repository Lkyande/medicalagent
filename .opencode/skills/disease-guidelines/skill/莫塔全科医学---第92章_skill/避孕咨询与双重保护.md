# Skill: 避孕咨询与双重保护

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第92章 家庭计划(避孕)
- 页码: 第92章“生育控制”“双重保护”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第92章.md`

**目标 / Objective**
帮助病人根据有效性、偏好和 STI 风险选择合适的避孕方式。

**适用范围 / Scope**
- 前来咨询避孕、性健康或生育计划的育龄女性和青少年

**操作步骤 / Procedure**
1. 评估病人的避孕目标、妊娠计划、月经情况和对方法的偏好。
2. 解释不同方法的有效性差异,特别是 LARC 的优势。
3. 评估 STI 风险,对有风险者建议避孕套加高效避孕法的双重保护。
4. 同步讨论性传播感染筛查、免疫接种和宫颈筛查需要。
5. 与病人共同决定方案并安排启动与复查计划。

**注意事项 / Precautions**
- 避孕套是唯一同时预防 STI 的避孕方法。
- 对青少年,保密和知情同意处理尤其关键。
- 图表和视觉工具有助于降低方法选择困惑。

**量化指标 / Metrics**
- 避孕咨询中 STI 风险评估率
- 双重保护建议率
- 方法启动后继续使用率
