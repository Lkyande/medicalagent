# Skill: COC禁忌筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第92章 家庭计划(避孕)
- 页码: 第92章“安全处方”“复方口服避孕药”“表92.3 使用复方口服避孕药的禁忌”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第92章.md`

**目标 / Objective**
在开具复方激素避孕药前识别静脉血栓和其他重要禁忌风险。

**适用范围 / Scope**
- 准备开始 COC 或阴道环等复方激素避孕法的女性

**操作步骤 / Procedure**
1. 使用 MEC 框架评估病人是否适合复方激素避孕法。
2. 筛查年龄、吸烟、血栓史、偏头痛先兆、高血压、心脏病和恶性肿瘤病史。
3. 询问肝病、近期大手术、长期不动和抗磷脂抗体情况。
4. 对绝对或相对禁忌者改选 POP、LARC 或其他方法。
5. 记录禁忌评估结果和共同决策依据。

**注意事项 / Precautions**
- 35 岁以上吸烟和血栓高风险者尤其不适合 COC。
- 肝酶诱导药物可影响部分激素避孕效果。
- 不能默认“年轻就一定安全”。

**量化指标 / Metrics**
- COC 处方前禁忌筛查率
- 高风险人群替代方案使用率
- 相关不良事件发生率
