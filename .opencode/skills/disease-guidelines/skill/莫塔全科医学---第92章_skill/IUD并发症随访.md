# Skill: IUD并发症随访

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第92章 家庭计划(避孕)
- 页码: 第92章“IUD 的副作用和并发症”“脱落、子宫穿孔和异位”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第92章.md`

**目标 / Objective**
在 IUD 放置后早期识别感染、穿孔、脱落和异位妊娠风险。

**适用范围 / Scope**
- 放置含铜或左炔诺孕酮 IUD 的女性

**操作步骤 / Procedure**
1. 解释放置后 3 至 6 个月内可能出现的出血和疼痛模式。
2. 提醒病人在放置后 3 至 6 周复诊。
3. 复诊时评估是否有发热、盆腔痛、异常出血、线头变化或怀孕线索。
4. 若怀疑穿孔或异位,安排超声或 X 线定位并转介处理。
5. 若发生妊娠,尽早评估并考虑取出 IUD。

**注意事项 / Precautions**
- 盆腔炎风险在植入后前 20 日略升高。
- IUD 失效时异位妊娠比例相对更高。
- 母乳喂养和产后前 6 个月穿孔风险更高。

**量化指标 / Metrics**
- IUD 放置后复诊完成率
- 早期并发症识别率
- 异常妊娠及时评估率
