# Skill: LARC优先介绍

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第92章 家庭计划(避孕)
- 页码: 第92章“生育控制”“LARC”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第92章.md`

**目标 / Objective**
在避孕咨询中主动介绍长效可逆避孕方法,减少意外妊娠。

**适用范围 / Scope**
- 希望高效、低维护、可逆避孕的女性,包括年轻和未育女性

**操作步骤 / Procedure**
1. 主动询问病人对埋植剂、IUD 和避孕针的认识与顾虑。
2. 说明 LARC 的高效性、低失败率和低依赖每日记忆的优势。
3. 结合月经模式、疼痛、哺乳、药物相互作用和个人偏好选择类型。
4. 解释不同 LARC 的常见出血模式和副作用预期。
5. 若病人愿意,安排插入、植入或注射计划及后续复诊。

**注意事项 / Precautions**
- LARC 是最有效的可逆避孕方法。
- 需充分解释不规则出血,否则停用率会上升。
- 有 STI 风险时仍需加用避孕套。

**量化指标 / Metrics**
- 避孕咨询中 LARC 介绍率
- LARC 选择率
- 12 个月内持续使用率
