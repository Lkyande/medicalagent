# Skill: 避免行话并使用可视工具

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“避免使用行话”“使用可视的和实物的沟通方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
用病人能理解的语言和可视化材料解释医疗信息,提升理解、参与和后续执行。

**适用范围 / Scope**
- 病情解释、健康教育、治疗决策与操作说明场景

**操作步骤 / Procedure**
1. 将专业术语转换为日常语言后再向病人解释。
2. 识别病人的认知水平和交流能力,调整表达复杂度。
3. 在适当时使用图表、模型、病人手册或信息单辅助说明。
4. 必要时使用可靠网站或视频帮助病人理解人体功能、疾病表现或操作流程。
5. 主动推荐可信信息源,避免病人自行接触错误网络信息。

**注意事项 / Precautions**
- 可视工具应辅助理解,不能替代个体化解释。
- 避免使用未经验证的网站和夸大式宣教材料。
- 对低识字水平或视听障碍病人,应选择更适合的媒介方式。

**量化指标 / Metrics**
- 医学术语替换为通俗语言的比例
- 可视材料使用率
- 病人对核心信息理解率
