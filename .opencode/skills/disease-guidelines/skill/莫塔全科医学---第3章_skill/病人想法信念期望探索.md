# Skill: 病人想法信念期望探索

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“病人的看法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
探索病人对疾病、看诊和治疗的想法、信念与期望,实现真正的以病人为中心沟通。

**适用范围 / Scope**
- 诊断不明、治疗依从性差、情绪成分明显或需共同决策的病人

**操作步骤 / Procedure**
1. 主动询问病人如何看待自己的问题和症状原因。
2. 了解病人对本次看诊和医生角色的期待。
3. 识别其最希望优先解决的问题。
4. 结合语言和非语言提示探索恐惧、焦虑、沮丧或失望。
5. 在解释病情和制订方案时,尽量用与病人信念一致的表达方式。
6. 同时评估文化背景、年龄、性别和宗教等因素对看法的影响。

**注意事项 / Precautions**
- 不能把病人信念简单归为“错误”,应先理解其来源。
- 对心理健康问题病人,生病信念往往强烈且情绪化,需要更细致探索。
- 文化胜任力要求尊重差异,而不是迎合一切非医学观点。

**量化指标 / Metrics**
- 想法/信念/期望记录率
- 文化相关因素识别率
- 计划与病人价值观一致性评分
