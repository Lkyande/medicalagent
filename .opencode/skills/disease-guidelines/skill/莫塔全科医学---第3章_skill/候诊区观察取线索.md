# Skill: 候诊区观察取线索

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“准备”中“见病人和领病人”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
在病人进入诊室前通过自然观察获取有助于沟通和诊断的背景线索。

**适用范围 / Scope**
- 医生从候诊区接病人入诊室的看诊流程

**操作步骤 / Procedure**
1. 在接病人时观察其步态、姿势、表情和整体精神状态。
2. 注意穿着、配饰、随身物品和文件夹等可提示文化背景或当前问题的线索。
3. 识别陪同就诊者是谁,以及他们与病人的互动方式。
4. 留意可能反映健康问题的外在线索,如跛行、绷带、医院信件或影像资料。
5. 将观察所得作为沟通切入点或诊断提示,但不在未核实前直接下结论。
6. 在正式问诊中用开放式方式验证这些线索。

**注意事项 / Precautions**
- 观察是为了理解病人,不是为了贴标签或作价值判断。
- 文化、服饰和行为表达存在差异,不得凭单一线索推断敏感结论。
- 对儿童、残障者和情绪脆弱病人,应特别避免让观察变成凝视或压迫感。

**量化指标 / Metrics**
- 候诊区观察线索记录率
- 观察线索经问诊验证的有效率
- 由观察触发的重要问题识别数
