# Skill: 共同决策与同理桥

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“医患协商并制订一致的诊疗计划”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
通过共同决策和同理桥技术把对话锚定在病人经历上,再回到可执行的诊疗计划。

**适用范围 / Scope**
- 需协商诊疗计划、处理沟通中断或病人顾虑强烈的看诊场景

**操作步骤 / Procedure**
1. 明确提出医生建议,同时邀请病人表达自己的看法。
2. 识别病人价值观、感受和优先事项,作为共同决策依据。
3. 当沟通偏离或卡住时,先用反应或复述锚定病人的经历。
4. 从这个锚定点平稳引回到需要讨论的诊疗内容。
5. 共同决定今天处理的问题和可延后处理的问题。
6. 确认双方都理解并愿意承担各自计划中的责任。

**注意事项 / Precautions**
- 共同决策不等于放弃专业判断,应在医学安全边界内协商。
- 同理桥要基于真实理解,不能变成套路式重复。
- 对害怕、愤怒或高度不信任病人,应先修复关系再推进计划。

**量化指标 / Metrics**
- 共同决策事项数
- 沟通中断后成功回到主题的比例
- 病人对计划认同度
