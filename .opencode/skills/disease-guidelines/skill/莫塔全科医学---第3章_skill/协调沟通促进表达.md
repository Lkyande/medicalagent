# Skill: 协调沟通促进表达

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“倾听并收集信息”中“协调”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
通过最小干预式反馈鼓励病人继续讲话,提高担忧和背景信息暴露程度。

**适用范围 / Scope**
- 病人初始叙述和问题展开阶段

**操作步骤 / Procedure**
1. 使用点头、简短回应和接纳性姿态鼓励病人继续说。
2. 在适当时机加入“多给我讲讲这件事”等引导语。
3. 避免一次抛出多个问题,以免打断叙述流。
4. 当病人接近关键主题时,保持开放姿态而不是马上解释或建议。
5. 在病人表达受阻时,用温和澄清帮助其重新组织语言。

**注意事项 / Precautions**
- 协调沟通不应演变为机械性“嗯嗯”回应。
- 对情绪高度激动者,鼓励表达的同时要注意安全和边界。
- 如果病人明显偏离主题过远,需及时温和收束。

**量化指标 / Metrics**
- 协调性回应使用频次
- 病人继续展开叙述的比例
- 关键问题自然暴露率
