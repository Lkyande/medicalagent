# Skill: 路标法说明流程

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“路标法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
通过明确说明当前阶段和下一步安排,帮助病人理解看诊流程并集中注意关键信息。

**适用范围 / Scope**
- 看诊转换节点,如从病史转向体检、从检查转向解释或讨论计划时

**操作步骤 / Procedure**
1. 在每个重要环节转换时明确说明已经完成了什么。
2. 告知接下来将要做什么或将讨论哪些主题。
3. 使用简短、清晰且可预期的语言作为“方向提示”。
4. 在病人显得紧张、分心或信息过载时增加路标提示频率。
5. 说明后观察病人反应,必要时重复或简化表达。

**注意事项 / Precautions**
- 路标法应简洁,避免变成长篇解释。
- 对焦虑、认知负荷高或健康素养有限者尤其有帮助。
- 如果流程实际发生变化,要及时更新说明,避免病人失去掌控感。

**量化指标 / Metrics**
- 关键转换节点路标提示使用率
- 病人对流程理解率
- 因流程不清导致的重复提问率
