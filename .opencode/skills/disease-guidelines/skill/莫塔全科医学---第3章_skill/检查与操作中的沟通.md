# Skill: 检查与操作中的沟通

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“身体检查或操作过程中的沟通”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
在体检或操作全过程持续告知、解释和倾听,降低病人不安并提升配合度。

**适用范围 / Scope**
- 需要身体接触、体格检查或门诊操作的看诊场景

**操作步骤 / Procedure**
1. 在接触病人身体前说明计划做什么并获得知情同意。
2. 询问病人是否存在既往不愉快经历、文化顾虑或对触摸、针头的恐惧。
3. 检查或操作过程中同步解释正在进行的步骤和发现。
4. 留意病人的语言和非语言反应,继续倾听新增担忧。
5. 完成后总结结果和下一步安排。

**注意事项 / Precautions**
- 医生常低估病人对检查的抵触,需主动探查。
- 对创伤史、文化禁忌、性别敏感和儿童病人需特别谨慎。
- 解释不充分时,病人容易把沉默或动作误读为异常发现。

**量化指标 / Metrics**
- 检查前知情同意完成率
- 检查中持续解释记录率
- 因检查沟通不足导致的不适或中断发生率
