# Skill: 避免沟通路障

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“妨碍良好沟通的路障”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
识别并避免会破坏信任、抑制表达或中断合作的典型沟通行为。

**适用范围 / Scope**
- 所有医患沟通场景,尤其处理敏感问题和行为改变时

**操作步骤 / Procedure**
1. 避免使用批评、辱骂、贴标签式“诊断”和带评判色彩的表扬。
2. 避免用命令、威胁、道德化说教和居高临下式建议替代协商。
3. 控制过度或不恰当提问,避免让病人感到像被审问。
4. 不要通过转移话题、空泛逻辑或不恰当安慰回避病人顾虑。
5. 一旦发现自己已形成沟通路障,及时承认并重新回到病人关切。

**注意事项 / Precautions**
- 路障行为常在医生焦虑、赶时间或价值判断强烈时出现。
- 对物质依赖、暴力、性问题等敏感领域尤其要警惕评判语气。
- 真诚同理不等于纵容问题行为,但必须先维持沟通通道。

**量化指标 / Metrics**
- 路障行为自我审查次数
- 因沟通评判导致的对立事件数
- 敏感议题沟通完成率
