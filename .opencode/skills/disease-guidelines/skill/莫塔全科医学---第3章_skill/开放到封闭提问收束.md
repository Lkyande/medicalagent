# Skill: 开放到封闭提问收束

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“开放-封闭型圆锥体模式”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
先开放探索病人问题,再逐步收窄提问,兼顾信息完整性与诊断效率。

**适用范围 / Scope**
- 需要在病人自由表达和结构化诊断之间切换的看诊场景

**操作步骤 / Procedure**
1. 先用非指向性开放问题启动对话。
2. 让病人充分表达主要问题和担忧后,再逐步缩小焦点。
3. 使用更直接的问题澄清时间、部位、程度、诱因等关键细节。
4. 对每个主要问题持续探寻,直到确认没有新的补充问题出现。
5. 避免因医生急于“深入了解”而过早收窄问题范围。

**注意事项 / Precautions**
- 圆锥体缩窄过快是常见错误,会漏掉真正主诉。
- 对复杂心理社会问题,开放阶段往往需要更长时间。
- 对急危重症病人可适当加快收束,但仍要保留核心开放探询。

**量化指标 / Metrics**
- 开放问题与封闭问题比例
- 多重主诉完整识别率
- 提问收束后新增问题漏报率
