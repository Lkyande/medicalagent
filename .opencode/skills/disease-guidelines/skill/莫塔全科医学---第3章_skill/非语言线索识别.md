# Skill: 非语言线索识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“非语言交流”“对肢体语言的解读”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
识别姿势、语气、距离和动作中的非语言信息,辅助理解病人的真实感受和沟通状态。

**适用范围 / Scope**
- 所有面对面看诊场景,尤其情绪和心理社会问题明显时

**操作步骤 / Procedure**
1. 观察病人的姿势、坐姿、身体距离、手脚动作和面部表情。
2. 同时关注语气、音量和说话节奏是否与内容一致。
3. 识别抑郁样姿态、防御性姿态或准备结束谈话的姿势。
4. 结合文化背景和当前情境解释这些线索,避免孤立判断。
5. 在必要时把观察到的线索温和反馈给病人,探索相关感受。

**注意事项 / Precautions**
- 非语言线索受文化影响很大,不能机械解码。
- 病人身体不适也会影响姿势,需与临床情况结合判断。
- 反馈时需婉转,避免让病人感到被分析或被揭穿。

**量化指标 / Metrics**
- 非语言线索记录率
- 线索触发情绪探索的次数
- 由非语言信息修正沟通策略的比例
