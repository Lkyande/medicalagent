# Skill: 主动倾听与信息收集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“倾听并收集信息”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
通过主动倾听充分获取事实、感受和隐含信息,减少过早打断导致的信息丢失。

**适用范围 / Scope**
- 全科门诊病史采集和心理社会问题探索阶段

**操作步骤 / Procedure**
1. 在看诊初期让医生保持更多沉默,允许病人连续表达。
2. 同时倾听事实内容、情绪反应、语气变化和言外之意。
3. 用轻松、专注和理解的姿态倾听,不过早进入控场。
4. 采用反应式语句回应病人感受,如指出其难过、愤怒或担忧。
5. 在适当停顿中给病人继续展开的空间,尤其在心理社会问题上。
6. 在信息足够后再进入更聚焦的问题澄清。

**注意事项 / Precautions**
- 过早追问细节会压缩病人表达真正担忧的机会。
- 对创伤、丧亲、抑郁和焦虑病人,沉默和陪伴本身就是干预的一部分。
- 主动倾听不等于放任谈话失控,需要在充分表达后适度收束。

**量化指标 / Metrics**
- 病人未被打断的初始表达时长
- 情绪线索识别率
- 病人隐藏担忧引出率
