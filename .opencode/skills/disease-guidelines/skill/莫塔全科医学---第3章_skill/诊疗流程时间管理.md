# Skill: 诊疗流程时间管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“管理诊疗流程”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
在不破坏医患关系的前提下控制看诊节奏和时间,保证当前与后续病人的服务质量。

**适用范围 / Scope**
- 多问题、心理社会问题或容易超时的门诊看诊

**操作步骤 / Procedure**
1. 在看诊中保持对时间、阶段和当前核心问题的持续觉察。
2. 通过不显眼的方式掌握时间,如观察诊室时钟或屏幕计时器。
3. 必要时提前设定规则,如本次可处理的问题数量或时间边界。
4. 当病人持续偏离主题时,用语言或非语言方式温和阻断并收回流程控制。
5. 对重大危机、自杀风险或剧烈痛苦病人,适当突破时限并优先安全。
6. 无法在本次完成的问题,明确安排后续看诊处理。

**注意事项 / Precautions**
- 时间管理不能演变成冷漠打断或效率优先的压迫感。
- 避免频繁看表等明显动作,以免削弱病人被重视感。
- 设定边界时要给出理由并提供后续安排,避免病人感到被拒绝。

**量化指标 / Metrics**
- 超时看诊比例
- 多问题看诊分流安排率
- 因时间管理不当引发投诉率
