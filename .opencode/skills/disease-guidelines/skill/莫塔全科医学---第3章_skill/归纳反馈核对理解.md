# Skill: 归纳反馈核对理解

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“归纳能力”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
通过明确口头总结向病人反馈当前理解,同时校正误解并提高病人被理解感。

**适用范围 / Scope**
- 病史采集、问题整理和管理讨论中的关键节点

**操作步骤 / Procedure**
1. 在收集到一段关键信息后,用简洁语言总结当前理解。
2. 同时概括事实、情绪和病人最关注的问题。
3. 向病人确认总结是否准确,鼓励其纠正遗漏或误解。
4. 根据反馈修正问题列表和下一步计划。
5. 在咨询结束前再次进行关键点归纳。

**注意事项 / Precautions**
- 总结应使用病人能理解的语言,避免术语堆砌。
- 归纳不是抢夺叙述权,需在合适停顿点进行。
- 对情绪脆弱病人,总结感受部分时要保持敏感和不过度解释。

**量化指标 / Metrics**
- 归纳反馈使用次数
- 病人纠正信息发生率
- 关键问题理解一致率
