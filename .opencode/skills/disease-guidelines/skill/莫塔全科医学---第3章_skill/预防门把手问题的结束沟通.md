# Skill: 预防门把手问题的结束沟通

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“结束诊疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
在结束看诊前提前预告、再次清点担忧并总结计划,降低“门把手问题”发生率。

**适用范围 / Scope**
- 所有接近结束阶段的门诊看诊

**操作步骤 / Procedure**
1. 提前告知病人本次看诊即将结束及其原因。
2. 主动询问病人是否还有尚未提出的担忧或需要。
3. 对本次看诊和实施计划的关键点进行简要总结。
4. 明确可能出现的意外情况和安全网措施。
5. 使用合适方式告别,并确认随访或再次联系路径。

**注意事项 / Precautions**
- 焦虑和抑郁病人更容易在结尾才提出核心问题,需额外留出空间。
- 安全网交代应具体,如恶化时何时何地求助。
- 结束语不能过于仓促,否则会强化被“赶出诊室”的感受。

**量化指标 / Metrics**
- 结束前未解决担忧再次筛查率
- 门把手问题发生率
- 病人对后续安排理解率
