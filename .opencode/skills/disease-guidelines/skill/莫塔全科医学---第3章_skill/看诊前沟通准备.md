# Skill: 看诊前沟通准备

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“准备”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
在正式看诊前完成环境、病历和自我状态准备,为高质量沟通创造条件。

**适用范围 / Scope**
- 全科门诊所有首次或复诊看诊场景

**操作步骤 / Procedure**
1. 检查诊室环境,确保私密、舒适并尽量减少干扰。
2. 调整座位和空间布局,避免制造俯视感或隔桌阻隔感。
3. 在看诊前做简短自我反思,识别可能影响判断的个人假设和价值观。
4. 回顾病历,重点查看上次看诊经过、重要疾病问题、近期检查结果和来信。
5. 留意病历中的个体化提示,如偏好称呼、陪同者信息和特殊恐惧。
6. 必要时结合团队前置信息或病人看病表,预判本次就诊目标。

**注意事项 / Precautions**
- 预判就诊原因只能帮助准备,不能替代现场开放式探询。
- 对有创伤史、文化差异或明显焦虑者,更应重视环境安全感。
- 医生个人疲惫、偏见或情绪波动会直接损害沟通质量,需主动识别。

**量化指标 / Metrics**
- 看诊前病历回顾完成率
- 诊室隐私与舒适条件达标率
- 关键个体化信息提前识别率
