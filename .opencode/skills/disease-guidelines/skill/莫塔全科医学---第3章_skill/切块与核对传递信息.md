# Skill: 切块与核对传递信息

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“切块与核对”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
把复杂医学信息分成小块传递,每次即时核对病人理解程度,减少信息过载。

**适用范围 / Scope**
- 解释诊断、治疗方案、检查结果或慢病教育时

**操作步骤 / Procedure**
1. 将需要传递的信息拆分为几个小块。
2. 每次只讲一小块最重要内容。
3. 每讲完一块后立即询问病人是否理解,或请其复述要点。
4. 如病人理解不足,换用更简单说法再次解释。
5. 在确认前一块理解无误后,再进入下一块信息。

**注意事项 / Precautions**
- 不要在情绪高压时一次性灌输大量信息。
- 对老年人、低健康素养者和刚接收坏消息者,更要减小信息颗粒度。
- 核对理解不能流于“你明白了吗”式形式问题,应尽量让病人复述。

**量化指标 / Metrics**
- 解释后病人复述正确率
- 单次解释信息块数量
- 需重复解释的次数
