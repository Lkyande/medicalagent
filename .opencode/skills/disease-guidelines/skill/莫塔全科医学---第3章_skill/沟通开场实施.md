# Skill: 沟通开场实施

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第3章 沟通技能
- 页码: 第3章“开场”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第3章.md`

**目标 / Objective**
在咨询开场阶段快速建立舒适感、集中注意力并促使病人自然表达就诊目的。

**适用范围 / Scope**
- 全科看诊开场阶段

**操作步骤 / Procedure**
1. 用病人偏好的名字问候病人及陪同者。
2. 通过座位、语气和姿态帮助病人尽快感到舒适。
3. 保持从容、轻松和专注的状态,让注意力集中在病人身上。
4. 使用开放性开场提问,如“今天我可以为您做些什么?”。
5. 配合适当的令人安心的非语言姿势,鼓励病人继续表达。
6. 在病人开始叙述后避免立即切换到高度控制式问答。

**注意事项 / Precautions**
- 陪同者在场时要明确病人是否接受其参与沟通。
- 对紧张、羞怯或文化背景差异明显者,开场节奏应更慢。
- 过度熟络、轻佻或假性放松会削弱信任感。

**量化指标 / Metrics**
- 开场后病人自发叙述时长
- 病人主诉在前2分钟内明确率
- 病人开场舒适度主观评分
