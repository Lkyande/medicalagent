# Skill: 步态与姿势基础检查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第58章 行走困难和腿部肿胀
- 页码: 第58章“步态和姿势检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第58章.md`

**目标 / Objective**
用标准化床旁流程快速筛查异常步态的主要神经肌肉与本体感觉问题。

**适用范围 / Scope**
- 行走困难、反复跌倒或主诉步态改变的病人

**操作步骤 / Procedure**
1. 先观察病人从坐位站起是否困难,以筛查近端肌无力。
2. 令病人双脚并拢站立并完成 Romberg 试验,比较睁眼和闭眼稳定性。
3. 让病人走足够距离,观察起步、步幅、步宽、摆臂和骨盆控制。
4. 加做直线行走、足尖与足跟行走,筛查本体感觉和远端肌无力。
5. 根据步态轮廓判断是疼痛步态、帕金森型、小脑型、痉挛型、垂足型或肌病型。

**注意事项 / Precautions**
- 步态异常可混合存在,老年人尤其不宜生硬归入单一类别。
- 奇怪夸张步态也不能直接等同心因性,仍需先排除神经系统病变。
- 观察距离过短会漏掉起步犹豫和冻结等关键表现。

**量化指标 / Metrics**
- 标准步态检查完成率
- Romberg 试验记录率
- 步态分型一致率
