# Skill: 儿童跛行分层评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第58章 行走困难和腿部肿胀
- 页码: 第58章“儿童跛行”“病史”“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第58章.md`

**目标 / Objective**
按年龄和病程对儿童跛行进行快速分层,优先锁定髋部和感染性病因。

**适用范围 / Scope**
- 所有婴幼儿、儿童和青少年跛行或拒绝行走的病人

**操作步骤 / Procedure**
1. 先按年龄分层:初学走路期、4 至 8 岁和青春期分别对应不同高危病因。
2. 明确跛行是急性、亚急性还是慢性,并补问创伤、运动与鞋具因素。
3. 若病因不明,优先检查髋关节和膝关节,不要只盯住疼痛部位。
4. 观察止痛步态、偏瘫步态和特伦德伦堡步态,并检查足底及趾间异物。
5. 结合年龄将 DDH、短暂滑膜炎、Perthes 病、SCFE、感染和虐待纳入分流。

**注意事项 / Precautions**
- 儿童跛行先默认器质性病因,不要过早贴心因性标签。
- 膝痛在儿童常是髋部病变的表现,需要联查。
- 无痛蹒跚步态更要警惕 DDH 或 Perthes 病。

**量化指标 / Metrics**
- 儿童跛行年龄分层记录率
- 髋关节检查完成率
- 重大病因早期识别率
