# Skill: 儿童骨髓炎初始识别与住院分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第58章 行走困难和腿部肿胀
- 页码: 第58章“骨髓炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第58章.md`

**目标 / Objective**
尽早识别儿童急性血源性骨髓炎并启动住院、培养和静脉抗感染路径。

**适用范围 / Scope**
- 发热、拒动肢体、干骺端压痛或急性跛行的儿童

**操作步骤 / Procedure**
1. 对急性发热合并四肢不愿动和干骺端压痛的儿童立即考虑骨髓炎。
2. 同时追问疖肿、脓肿、足趾化脓和免疫低下等感染来源。
3. 立即抽取全血细胞计数、红细胞沉降率和血培养。
4. 安排 X 线和 MRI,并知晓早期 X 线可在前 10 天内正常。
5. 直接住院并启动经验性静脉抗生素,后续根据培养和敏感性调整方案。

**注意事项 / Precautions**
- 早期影像阴性不能排除骨髓炎,临床怀疑仍应按重症管理。
- 与化脓性关节炎常需并行鉴别和处理。
- 儿童骨髓炎是需要住院的外科感染问题,不适合门诊观察等待。

**量化指标 / Metrics**
- 骨髓炎首诊识别率
- 血培养采集率
- 首诊到住院抗感染时间
