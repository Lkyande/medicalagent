# Skill: 儿童化脓性关节炎紧急处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第58章 行走困难和腿部肿胀
- 页码: 第58章“化脓性关节炎”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第58章.md`

**目标 / Objective**
把儿童发热性急性关节炎作为关节内化脓性感染进行紧急住院和引流分流。

**适用范围 / Scope**
- 发热伴急性关节炎、拒动或跛行的儿童

**操作步骤 / Procedure**
1. 对发热合并急性关节红肿痛或拒动的儿童立即怀疑化脓性关节炎。
2. 将其与骨髓炎同步评估,不要等待典型全身病态出现。
3. 立即安排血液检查、血培养和必要影像,并评估关节穿刺或外科引流需求。
4. 住院并与外科团队协作,按化脓性关节炎路径启动抗生素。
5. 明确需要手术引流加抗生素作为标准治疗,避免门诊延误。

**注意事项 / Precautions**
- 婴幼儿可能外观并不“很病”,但关节感染进展可很快。
- 仅靠止痛观察会显著增加关节破坏风险。
- 髋关节感染更应提高紧迫度。

**量化指标 / Metrics**
- 儿童化脓性关节炎识别率
- 首诊到住院时间
- 关节引流及时率
