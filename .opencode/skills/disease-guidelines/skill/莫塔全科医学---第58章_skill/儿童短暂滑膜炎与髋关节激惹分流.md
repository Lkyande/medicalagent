# Skill: 儿童短暂滑膜炎与髋关节激惹分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第58章 行走困难和腿部肿胀
- 页码: 第58章“急性髋关节综合征(短暂滑膜炎)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第58章.md`

**目标 / Objective**
在常见儿童急性跛行中识别短暂滑膜炎,同时不漏掉需要紧急处理的感染性髋关节病变。

**适用范围 / Scope**
- 3 至 8 岁急性跛行和髋关节活动受限的儿童

**操作步骤 / Procedure**
1. 识别急性跛行、髋活动受限且 X 线正常的典型短暂滑膜炎模式。
2. 询问近期上呼吸道感染或轻微外伤背景,作为支持线索。
3. 同时评估发热、明显病态和实验室炎症反应,主动排除化脓性关节炎。
4. 建议整形外科评估,并根据症状给予卧床休息或拐杖减重及止痛。
5. 安排 4 至 6 个月后复查影像,以排除 Perthes 病等后续显现病变。

**注意事项 / Precautions**
- 短暂滑膜炎是排除性诊断,不能在感染未排除前草率定论。
- 不能行走或病情恶化应立即升级处理。
- 即便短期恢复良好,仍需随访排除 Perthes 病。

**量化指标 / Metrics**
- 短暂滑膜炎识别率
- 感染性髋病排除完整率
- 影像随访完成率
