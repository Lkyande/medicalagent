# Skill: 撞脱恒牙现场回纳

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第41章 面部疼痛
- 页码: 第41章“撞掉的牙齿”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第41章.md`

**目标 / Objective**
在恒牙完全脱出后尽快保护牙周组织并提高再植成功率。

**适用范围 / Scope**
- 第二恒牙被撞脱且具备立即处理条件的病人

**操作步骤 / Procedure**
1. 戴手套仅拿住牙冠,避免接触和擦拭牙根表面。
2. 如牙齿污染,先放入牛奶中或用唾液轻柔冲洗,不要用水。
3. 条件允许时立即将牙齿回纳原牙槽窝。
4. 用结实银箔或类似材料临时将牙齿与邻牙固定。
5. 尽快转诊牙科做进一步固定和评估,强调最好在 30 分钟内完成回纳。

**注意事项 / Precautions**
- 本技能适用于恒牙,乳牙不应按同样方式回纳。
- 任何粗暴清洗或触碰牙根都会降低再植成功率。
- 无法立即回纳时应优先保存在合适介质中并快速转诊。

**量化指标 / Metrics**
- 撞脱恒牙 30 分钟内处理率
- 临时回纳成功率
- 后续牙科再植保留率
