# Skill: 脓性颌下炎紧急处置

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第41章 面部疼痛
- 页码: 第41章“脓性颌下炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第41章.md`

**目标 / Objective**
及时识别脓性颌下炎的气道威胁并启动经验性抗感染和专科协作。

**适用范围 / Scope**
- 牙源性感染后出现舌下或颌下迅速肿胀的病人

**操作步骤 / Procedure**
1. 识别舌下和颌下间隙快速肿胀且无明显脓肿形成的蜂窝织炎表现。
2. 立即评估气道、吞咽和说话情况,将其视为潜在危及生命状态。
3. 送培养和药敏检查,并同步联系口腔颌面或耳鼻喉等专科。
4. 按书中方案尽快启动静脉阿莫西林联合甲硝唑经验治疗。
5. 持续监测病情扩展和气道变化,必要时转入更高等级救治。

**注意事项 / Precautions**
- 脓性颌下炎可迅速累及气道,优先级高于局部疼痛处理。
- 该病通常源自根管感染,不可仅作普通牙痛处理。
- 仅口服药物和门诊观察往往不足以覆盖病情风险。

**量化指标 / Metrics**
- 脓性颌下炎当日识别率
- 静脉抗生素启动时间
- 气道并发症发生率
