# Skill: 面部疼痛定位式查体

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第41章 面部疼痛
- 页码: 第41章“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第41章.md`

**目标 / Objective**
通过系统体检确认面部疼痛的解剖来源,缩小牙源、鼻窦、关节和神经病因范围。

**适用范围 / Scope**
- 需要进一步明确病变来源的面部疼痛病人

**操作步骤 / Procedure**
1. 观察一般状态和疼痛行为,注意突然刺痛伴抽动是否提示神经痛。
2. 触诊面部和颈部,包括腮腺、眼周、淋巴结、皮肤及颈椎。
3. 详细检查颞下颌关节,在开口和咀嚼动作中寻找压痛或弹响。
4. 检查鼻、口、咽和鼻后间隙,对每颗牙进行叩诊并评估口底硬结。
5. 完成脑神经检查,重点评估三叉神经、动眼神经和舌咽神经功能。

**注意事项 / Precautions**
- 面部疼痛很多时候主要依赖临床检查定位,不能只依赖影像学。
- 牙科和 TMJ 病因常被忽略,查体时要主动覆盖。
- 应比较症状侧与无症状侧,提高定位准确性。

**量化指标 / Metrics**
- 面部疼痛系统查体完成率
- 病因定位与最终诊断一致率
- TMJ 与牙源性疼痛识别率
