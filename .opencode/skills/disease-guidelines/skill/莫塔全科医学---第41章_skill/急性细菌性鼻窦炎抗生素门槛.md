# Skill: 急性细菌性鼻窦炎抗生素门槛

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第41章 面部疼痛
- 页码: 第41章“管理(急性细菌性鼻窦炎)”“抗生素治疗指南”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第41章.md`

**目标 / Objective**
减少急性鼻窦炎中过早使用抗生素,同时识别更可能属于细菌性感染的病例。

**适用范围 / Scope**
- 急性面部痛、鼻塞或脓性鼻涕提示鼻窦炎的病人

**操作步骤 / Procedure**
1. 先排除牙根感染并识别鼻炎、阻塞等易感因素。
2. 了解大多数病例为自限性,前 5~7 日通常以支持治疗和引流为主。
3. 仅在超过 5~7 日仍无明显改善且满足至少 3 项严重特征时考虑抗生素。
4. 严重特征包括持续黏液脓性鼻涕、面痛、减充血剂反应差和上颌窦压痛等。
5. 启动抗生素后安排复评,并继续促进鼻窦引流和控制诱因。

**注意事项 / Precautions**
- 抗生素对 10 日结局改善有限,应避免把病毒性感染常规细菌化处理。
- 单侧鼻窦症状或上磨牙叩痛时要重视牙源性病因。
- 影像学不能替代病史和查体对初始决策的作用。

**量化指标 / Metrics**
- 急性鼻窦炎抗生素适应证符合率
- 初始支持治疗使用率
- 7~10 日内症状改善率
