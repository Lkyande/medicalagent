# Skill: 面部疼痛红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第41章 面部疼痛
- 页码: 第41章“面部疼痛的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第41章.md`

**目标 / Objective**
识别面部疼痛中提示恶性病变、血管炎或严重神经病因的警示信号。

**适用范围 / Scope**
- 急性、慢性或反复发作的面部疼痛病人

**操作步骤 / Procedure**
1. 询问疼痛是否持续存在且无明显诱因。
2. 询问有无不明原因体重减轻及其他全身恶病质表现。
3. 对三叉神经痛样表现者评估是否存在非典型特征或继发性病因线索。
4. 发现鼻部带状疱疹、老年新发疼痛或颞区症状时提高警惕。
5. 红旗征阳性时扩大检查至口鼻咽、眼眶、颞动脉并尽快转专科。

**注意事项 / Precautions**
- 60 岁以上新发面部疼痛要优先排除颞动脉炎和恶性肿瘤。
- 带状疱疹累及鼻部提示眼部并发症风险,不应仅作对症处理。
- 面部疼痛长期无法解释时不可简单归为心理因素。

**量化指标 / Metrics**
- 面部疼痛红旗征记录率
- 高危病例专科转诊率
- 恶性病因漏诊率
