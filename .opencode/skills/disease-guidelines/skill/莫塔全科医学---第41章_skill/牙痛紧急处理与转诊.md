# Skill: 牙痛紧急处理与转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第41章 面部疼痛
- 页码: 第41章“牙痛的治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第41章.md`

**目标 / Objective**
在基层为牙痛病人提供镇痛和感染分层,并尽快衔接牙科治疗。

**适用范围 / Scope**
- 疑似龋齿、根尖周感染、智齿炎或牙脓肿引起的牙痛病人

**操作步骤 / Procedure**
1. 判断疼痛是否局限于患牙、是否受冷热刺激影响且不越过中线。
2. 优先安排紧急牙科会诊,明确根本处理依赖牙科干预。
3. 给予阿司匹林、布洛芬或对乙酰氨基酚等镇痛治疗。
4. 仅在牙脓肿、智齿发炎、播散性感染或根管感染重症时考虑抗生素。
5. 对青霉素过敏者使用替代方案,并复核吞咽困难、蜂窝织炎等扩散征象。

**注意事项 / Precautions**
- 单纯龋齿性牙痛通常不需要抗生素。
- 反复仅开抗生素而不转牙科会延误根本治疗。
- 颌面部肿胀、张口受限或全身毒性表现提示感染扩散。

**量化指标 / Metrics**
- 牙痛病人牙科转诊率
- 非适应证抗生素处方率
- 首次就诊镇痛覆盖率
