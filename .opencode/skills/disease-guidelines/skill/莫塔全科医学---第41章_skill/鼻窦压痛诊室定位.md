# Skill: 鼻窦压痛诊室定位

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第41章 面部疼痛
- 页码: 第41章“一些简单的诊室里的测试”“诊断窦性压痛”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第41章.md`

**目标 / Objective**
通过系统触诊区分窦性与非窦性压痛,定位可能受累的鼻窦。

**适用范围 / Scope**
- 怀疑鼻窦炎导致面部疼痛、压痛或牙痛的病人

**操作步骤 / Procedure**
1. 先触诊非鼻窦区域如颞骨和颧骨,建立对照基线。
2. 按顺序系统触诊额窦、筛窦和上颌窦区域。
3. 比较症状侧与无症状侧的压痛差异和定位一致性。
4. 若考虑单侧上颌窦或额窦积液,可进一步采用透照法比较透光度。
5. 将触诊结果与鼻塞、脓性鼻涕、牙痛和鼻后滴漏等症状整合判断。

**注意事项 / Precautions**
- 触诊前先建立非窦性对照点有助于减少误判。
- 病毒性与细菌性鼻窦炎在早期难以单靠压痛区分。
- 单侧症状明显时要警惕牙根感染或扩张性病变。

**量化指标 / Metrics**
- 鼻窦压痛系统触诊完成率
- 症状侧定位一致率
- 鼻窦炎与牙源性疼痛鉴别准确率
