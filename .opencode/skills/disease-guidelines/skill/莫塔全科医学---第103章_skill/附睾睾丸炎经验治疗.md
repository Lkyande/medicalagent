# Skill: 附睾睾丸炎经验治疗

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第103章 阴囊痛
- 页码: 第103章“急性附睾睾丸炎”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第103章.md`

**目标 / Objective**
在排除扭转后为附睾睾丸炎病人提供适当的经验性抗感染和支持治疗。

**适用范围 / Scope**
- 性活跃年轻男性或老年男性急性附睾睾丸炎

**操作步骤 / Procedure**
1. 根据年龄和暴露背景判断 STI 相关还是尿路感染相关病原体更可能。
2. 提供卧床休息、阴囊抬高支撑和镇痛治疗。
3. 对 STI 相关病人按衣原体/淋病路径启动经验性抗生素。
4. 对尿路感染相关病人按培养和药敏选择合适口服方案。
5. 若重症、脓肿或治疗失败,升级住院和外科评估。

**注意事项 / Precautions**
- 治疗失败时需考虑脓肿引流。
- 严重感染可进展为败血症。
- 培养和 NAAT 有助于后续精准调整方案。

**量化指标 / Metrics**
- 附睾睾丸炎经验治疗规范率
- STI 样本采集率
- 复诊症状缓解率
