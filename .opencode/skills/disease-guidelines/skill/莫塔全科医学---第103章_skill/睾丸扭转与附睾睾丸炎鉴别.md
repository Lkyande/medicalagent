# Skill: 睾丸扭转与附睾睾丸炎鉴别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第103章 阴囊痛
- 页码: 第103章“睾丸扭转和附睾睾丸炎”“表103.2”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第103章.md`

**目标 / Objective**
根据病史和查体快速区分睾丸扭转与附睾睾丸炎,指导紧急程度。

**适用范围 / Scope**
- 阴囊红肿疼痛的男童、青少年和成年男性

**操作步骤 / Procedure**
1. 比较起病速度,扭转多为突发剧烈痛,附睾睾丸炎多渐进起病。
2. 询问发热、排尿困难和尿道分泌物等感染线索。
3. 检查睾丸位置、阴囊红肿、提睾反射及阴囊抬高是否缓解疼痛。
4. 结合尿检、培养和 STI 检测支持感染诊断,但不延误扭转处理。
5. 如仍不能明确,按扭转路径紧急处理。

**注意事项 / Precautions**
- 临床上很多病例只能在手术探查时完全区分。
- Prehn 征不能单独替代整体判断。
- 青春期以前一般不轻易把急性阴囊痛归为附睾睾丸炎。

**量化指标 / Metrics**
- 扭转与感染鉴别记录率
- 不能明确病例的紧急处理率
- 误分流率
