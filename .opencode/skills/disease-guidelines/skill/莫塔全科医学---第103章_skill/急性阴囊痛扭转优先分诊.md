# Skill: 急性阴囊痛扭转优先分诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第103章 阴囊痛
- 页码: 第103章“儿童和青少年急性阴囊痛”“睾丸扭转”“转诊时机”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第103章.md`

**目标 / Objective**
在急性阴囊痛场景中优先识别睾丸扭转并避免可挽救睾丸的延误。

**适用范围 / Scope**
- 儿童、青少年及年轻男性突发阴囊痛、腹股沟痛或相关呕吐时

**操作步骤 / Procedure**
1. 先把任何突发急性阴囊痛视为睾丸扭转,直到证实另有原因。
2. 询问突发剧痛、腹股沟放射痛、恶心呕吐和既往短暂自发缓解发作史。
3. 检查睾丸高位、横向占位和提睾反射是否消失。
4. 避免因影像等待而延误,对高度怀疑者立即泌尿外科急转诊。
5. 向团队明确“时间窗”概念,6 小时内挽救率最高。

**注意事项 / Precautions**
- 睾丸扭转是年轻男性急性阴囊痛中最重要的诊断。
- 超声和核素检查可能带来危险性延误。
- 反复短暂疼痛可能提示间歇性扭转。

**量化指标 / Metrics**
- 急性阴囊痛病例的扭转优先分诊率
- 急诊转诊时效
- 睾丸挽救率
