# Skill: 异位妊娠红旗识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第95章 女性的下腹和盆腔痛
- 页码: 第95章“异位妊娠”“异位妊娠破裂的临床特点”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第95章.md`

**目标 / Objective**
在育龄女性腹痛中尽早识别异位妊娠,防止破裂性失血致命事件。

**适用范围 / Scope**
- 育龄女性出现下腹痛、闭经或异常阴道出血时

**操作步骤 / Procedure**
1. 牢记诊断三联征:闭经、下腹痛和阴道异常出血。
2. 询问既往异位妊娠、盆腔炎、输卵管手术、IUD 和 IVF 等风险因素。
3. 检查髂窝压痛、宫颈抬举痛、附件包块和循环衰竭线索。
4. 安排尿或血 β-hCG 及经阴道超声,必要时动态复测 hCG。
5. 对破裂或高度怀疑病例立即转入急诊手术路径。

**注意事项 / Precautions**
- 异位妊娠可在非常早期被识别,也可迅速破裂致命。
- 尿妊娠试验可为阴性,不能完全排除异位妊娠。
- 疼痛放射至直肠、阴道或腿部时要提高警惕。

**量化指标 / Metrics**
- 育龄腹痛女性 β-hCG 检测率
- 异位妊娠红旗识别率
- 高危病例急诊转诊时效
