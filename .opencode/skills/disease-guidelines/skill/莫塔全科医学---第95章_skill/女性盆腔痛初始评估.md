# Skill: 女性盆腔痛初始评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第95章 女性的下腹和盆腔痛
- 页码: 第95章“临床方法”“病史”“身体检查”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第95章.md`

**目标 / Objective**
对女性下腹和盆腔痛进行系统分层,尽快区分妇科、泌尿和腹部病因。

**适用范围 / Scope**
- 育龄期或绝经前后女性出现急性、慢性或反复发作的下腹和盆腔痛

**操作步骤 / Procedure**
1. 先区分疼痛是急性、慢性还是反复发作,并记录严重度和功能影响。
2. 询问月经史、性交困难、避孕方式、妊娠可能性和既往盆腹手术史。
3. 分析与月经周期相关的疼痛模式,识别痛经、排卵痛和内异症线索。
4. 进行腹部检查,按需要补充窥器和双合诊检查。
5. 选择 CBC、CRP、尿检、β-hCG、宫颈拭子和经阴道超声等基础检查。

**注意事项 / Precautions**
- 育龄女性腹痛要始终保持“异位意识”。
- 年轻无性活动女性不一定需要阴道侵入性器械检查。
- 慢性盆腔痛常伴显著心理社会创伤背景。

**量化指标 / Metrics**
- 盆腔痛病人的妊娠排查率
- 月经和性交相关史记录率
- 急慢性分层记录率
