# Skill: 月经周期相关盆腔痛分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第95章 女性的下腹和盆腔痛
- 页码: 第95章“概率诊断”“与月经有关的典型疼痛模式”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第95章.md`

**目标 / Objective**
根据疼痛与月经周期关系快速区分痛经、排卵痛和内异症等常见病因。

**适用范围 / Scope**
- 周期性或反复发作的盆腔痛女性

**操作步骤 / Procedure**
1. 记录疼痛发生在经前、经期、排卵期还是整个月经周期。
2. 对反复自限性中期剧痛优先考虑排卵痛。
3. 对经期相关显著疼痛考虑原发性痛经或子宫内膜异位症。
4. 对慢性、反复且伴性交痛或不孕线索者提高对子宫内膜异位症的怀疑。
5. 根据分层结果安排对症治疗、超声或专科评估。

**注意事项 / Precautions**
- 子宫内膜异位症常被漏诊。
- 周期性疼痛并不代表一定“功能性”,仍需排除器质性病因。
- 慢性便秘和腰骶源性牵涉痛是常见陷阱。

**量化指标 / Metrics**
- 周期相关疼痛模式记录率
- 内异症可疑病例识别率
- 对症治疗后症状改善率
