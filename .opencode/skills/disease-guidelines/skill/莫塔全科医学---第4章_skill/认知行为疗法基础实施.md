# Skill: 认知行为疗法基础实施

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“认知行为疗法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
用基础 CBT 流程帮助病人识别并改变维持症状的认知和行为模式。

**适用范围 / Scope**
- 抑郁、焦虑、失眠、部分慢性症状和行为问题的基层非药物干预

**操作步骤 / Procedure**
1. 与病人共同设定具体、现实的功能和情绪目标。
2. 对病人进行疾病与认知行为模式教育。
3. 教授基本症状控制技能,如放松和呼吸控制。
4. 识别不适合的想法、感受、感知和行为。
5. 帮助病人挑战并尝试改变这些维持问题的模式。
6. 强化积极行为,不鼓励消极行为。
7. 鼓励病人作为积极参与者持续练习并记录进展。

**注意事项 / Precautions**
- CBT 并不适合所有病人或所有治疗师,需先评估适配性。
- 目标设置过大或过空泛会削弱执行效果。
- 对严重精神障碍、自杀风险或妄想明显者,应避免单靠基础 CBT 管理。

**量化指标 / Metrics**
- 目标设定完成率
- 家庭练习执行率
- 自动负性思维识别与修正次数
