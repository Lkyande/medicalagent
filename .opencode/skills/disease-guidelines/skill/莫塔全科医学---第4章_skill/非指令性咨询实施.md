# Skill: 非指令性咨询实施

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“以病人为中心的咨询价值”“咨询和心理治疗的基础”“咨询策略”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
以协调员角色帮助病人理解自身处境并形成解决路径,而不是由医生直接替病人作决定。

**适用范围 / Scope**
- 适合全科短程心理咨询、情感和社会问题支持性干预的病人

**操作步骤 / Procedure**
1. 以倾听和同理心启动咨询,保持真诚、平静和保密。
2. 使用反应式陈述、静默、转述和归纳帮助病人继续思考。
3. 用温和、机智和试探式问题促进病人表达核心情绪和矛盾。
4. 允许病人纠正医生对其感受的理解,共同澄清问题。
5. 提供指导和帮助以促进领悟,但避免直接命令病人该怎么做。
6. 在病人暂时缺乏应对能力时,再适度增加医生主导度。

**注意事项 / Precautions**
- 非指令性不等于被动,医生仍需维护结构和安全。
- 对困惑、心烦意乱或反应能力差的病人,可暂时更多指导。
- 不要把个人价值观、行为方式或人生经验强加给病人。

**量化指标 / Metrics**
- 反应式技巧使用率
- 病人自主提出解决方案的次数
- 咨询后病人主观掌控感变化
