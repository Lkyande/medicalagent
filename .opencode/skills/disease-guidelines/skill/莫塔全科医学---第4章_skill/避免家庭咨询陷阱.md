# Skill: 避免家庭咨询陷阱

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“全科医生可能落入的陷阱”“避免陷入困境的可能解决方案”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
在家庭咨询中避免医生陷入救援者角色、偏袒或隐私失守,保持家庭自主和合作治疗。

**适用范围 / Scope**
- 家庭咨询、婚姻咨询和涉及多个家庭成员的全科干预

**操作步骤 / Procedure**
1. 明确医生不承担“改变整个家庭”的单方面责任。
2. 设定现实目标,并让家庭成员共同承担改变任务。
3. 尽量在关键家庭成员到场的情况下开始或推进治疗。
4. 及时识别家庭中的替罪羊倾向、联手效应和隐藏病人。
5. 在涉及隐私共享前获得家庭明确同意并记录在病历中。
6. 避免快速解决方案和偏袒某一方,必要时寻求同事支持。

**注意事项 / Precautions**
- 与某一成员关系过密时,最容易滑向救世主或偏袒角色。
- 泄露家庭成员隐私会严重破坏治疗联盟。
- 医生个人经历不应过度带入家庭咨询过程。

**量化指标 / Metrics**
- 家庭目标共同确认率
- 隐私同意记录率
- 家庭咨询中偏袒/联手风险识别率
