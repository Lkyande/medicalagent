# Skill: 咨询适应证与转诊筛选

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“注意事项”“不太可能从咨询中获益的病人”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
筛选适合基层咨询的病人,识别相对禁忌证并及时转向更合适的专业支持。

**适用范围 / Scope**
- 计划开展全科咨询前的病人评估阶段

**操作步骤 / Procedure**
1. 判断病人当前问题是否适合通过基层咨询获益。
2. 评估其表达能力、改变能力、对心理诊断的接受度和治疗动机。
3. 识别精神病、既往多次治疗无效、强烈抵制改变或明显器质性病因等情况。
4. 对语言情感表达困难或维持症状有既得利益者,谨慎评估咨询价值。
5. 若咨询关系已无效或问题超出能力范围,及时结束并转诊。

**注意事项 / Precautions**
- 医生不能替病人解决其生活问题,只能提供支持和框架。
- 大多数初始病人更需要信息、支持和增强信心,而非长期心理治疗。
- 转诊不代表失败,而是匹配病人需要的重要决策。

**量化指标 / Metrics**
- 咨询前适应证筛查完成率
- 不适合病例及时转诊率
- 无效咨询关系终止与改道率
