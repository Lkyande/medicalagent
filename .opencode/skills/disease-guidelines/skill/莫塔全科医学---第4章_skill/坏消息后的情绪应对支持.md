# Skill: 坏消息后的情绪应对支持

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“应对病人的反应”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
在坏消息告知后即时容纳和支持病人及家属的情绪反应,降低失控和孤立感。

**适用范围 / Scope**
- 已完成坏消息告知后的即时支持阶段

**操作步骤 / Procedure**
1. 预先准备病人可能出现的沉默、难以置信、悲痛、愤怒和内疚等反应。
2. 允许并鼓励病人表达情绪,如哭泣或尖叫。
3. 使用纸巾、安静陪伴和适度抚触等支持性举措。
4. 询问病人和亲属此刻的感受、最需要什么及是否希望联系其他人。
5. 提供教育材料和支持服务信息。
6. 明确安排后续随访和可再次联系的方式。

**注意事项 / Precautions**
- 抚触必须基于情境合适和病人接受,避免越界。
- 情绪支持不能替代事实说明和后续计划。
- 若出现激越、自伤风险或失控行为,需立即进入安全处置流程。

**量化指标 / Metrics**
- 坏消息后即时支持措施完成率
- 情绪反应得到表达的比例
- 告知后48小时内随访触达率
