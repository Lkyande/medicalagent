# Skill: PLISSIT咨询应用

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“PLISSIT模式”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
在全科咨询中分层给予容许、信息、具体建议和强化治疗,适度匹配病人需求与医生能力。

**适用范围 / Scope**
- 以心理感受、敏感问题或有限干预为主的咨询场景

**操作步骤 / Procedure**
1. 先给予病人“可以谈”的容许,以不带偏见的方式接纳其问题。
2. 只提供病人当前真正需要的有限信息,避免一次灌输过多内容。
3. 在需要时提供与其处境匹配、简单可行的具体建议。
4. 若问题超出基层处理深度,及时转入强化治疗或转诊相关专家。
5. 至少确保全科医生能够完成“容许”和“有限信息”两个层级。

**注意事项 / Precautions**
- 许多病人只需要被允许表达担忧,不一定需要立即进入建议阶段。
- 具体建议必须针对病人处境,不能空泛说教。
- 当问题涉及深层创伤、复杂精神障碍或专业边界时,应避免勉强继续。

**量化指标 / Metrics**
- 咨询层级匹配率
- 有限信息后病人理解率
- 需升级至强化治疗或转诊的比例
