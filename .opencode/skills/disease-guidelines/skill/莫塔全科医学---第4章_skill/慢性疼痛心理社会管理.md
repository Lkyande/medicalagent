# Skill: 慢性疼痛心理社会管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“慢性疼痛”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
在慢性疼痛管理中纳入心理社会评估和行为重建,避免仅围绕疼痛本身反复处置。

**适用范围 / Scope**
- 长期疼痛、反复治疗失败或伴复杂社会心理问题的病人

**操作步骤 / Procedure**
1. 先进行全面细致的医学评估,排查和界定疼痛相关器质性问题。
2. 同步安排心理学评估,识别抑郁、丧亲反应或其他心理因素。
3. 向病人及家属详细解释治疗方法和对疼痛原因的合理理解。
4. 同时管理相关问题,如抑郁和性功能障碍。
5. 通过行为改变逐步增加活动,帮助病人回归较正常的功能状态。
6. 必要时联动多学科团队持续管理。

**注意事项 / Precautions**
- 慢性疼痛常让医生产生无力感,需避免因挫败而过度检查或放弃管理。
- 对明显躯体化表现病人,解释方式要谨慎,避免让其感到被否定。
- 复杂疼痛常需长期多学科合作,不宜单一依赖药物。

**量化指标 / Metrics**
- 多维评估完成率
- 活动水平逐步恢复情况
- 疼痛相关功能受限评分变化
