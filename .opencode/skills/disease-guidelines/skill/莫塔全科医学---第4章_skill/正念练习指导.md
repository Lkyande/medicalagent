# Skill: 正念练习指导

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“正念”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
通过基础正念训练提升病人对当下的觉察和对压力的应对能力。

**适用范围 / Scope**
- 压力、焦虑、情绪波动或注意力容易被负面内容占据的病人

**操作步骤 / Procedure**
1. 向病人说明正念是基于冥想的注意力训练。
2. 引导病人把注意力转向当前积极或中性的当下体验。
3. 在放松状态下练习集中注意力,用于应对压力情境。
4. 强调把注意力拉回“当下”,而不是反复沉浸在烦心事中。
5. 当注意力分散时,训练病人反复、主动地将其带回。

**注意事项 / Precautions**
- 正念不是压抑情绪,而是提升觉察与调节。
- 对急性创伤反应或严重精神症状者,应谨慎选择练习方式。
- 需要通过重复训练形成效果,不能期待一次指导即明显改善。

**量化指标 / Metrics**
- 正念练习频率
- 注意力回拉成功次数
- 病人自评压力水平变化
