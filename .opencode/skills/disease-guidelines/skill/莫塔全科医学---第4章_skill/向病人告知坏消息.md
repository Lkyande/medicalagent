# Skill: 向病人告知坏消息

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“告诉坏消息”“向病人告知坏消息”“告知坏消息的7个步骤”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
以诚实、清晰和支持性的方式向病人告知坏消息,减少额外心理创伤并建立持续支持计划。

**适用范围 / Scope**
- 诊断重大疾病、病情恶化、死亡相关信息或其他重大坏消息告知场景

**操作步骤 / Procedure**
1. 提前制订会谈计划,回顾临床资料并预留充足时间。
2. 选择私密、安静且不被打扰的空间,询问病人是否需要家属或朋友陪伴。
3. 评估病人想知道多少、能理解多少,并了解其原有疾病信念。
4. 使用简单易懂语言,少量多次地提供准确事实,不断核对理解。
5. 留意并允许病人沉默、流泪、愤怒或其他反应。
6. 随病情变化重复解释关键信息,并尽可能让家人参与。
7. 制订持续支持和沟通计划,安排随访及相关资源衔接。

**注意事项 / Precautions**
- 不要通过电话或互联网草率告知重大坏消息,除非别无选择。
- 不要给出精确预后时间预测或使用掩饰性语言回避核心事实。
- 对儿童要使用符合年龄的语言,同时兼顾家庭沟通。

**量化指标 / Metrics**
- 告知后病人关键信息理解率
- 坏消息告知后随访安排完成率
- 家属参与率
