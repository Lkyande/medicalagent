# Skill: 咨询约定与问题解决流程

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“解决问题的方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
以结构化咨询流程帮助病人界定问题、设定目标、完成行动计划并评估进展。

**适用范围 / Scope**
- 全科门诊中需要开展短程心理社会咨询的病人

**操作步骤 / Procedure**
1. 先倾听病人首次陈述的问题,同时关注事件、经历、感受和痛苦。
2. 尽可能用行为术语定义问题,把事件、经历和感受联系起来。
3. 与病人明确咨询约定,包括频率、每次时长和初步疗程。
4. 分别设定短期与长期目标。
5. 共同选择一个可尝试的行动方案。
6. 制订病人在两次咨询之间完成的“功课”或家庭任务。
7. 在下次咨询时评估进展,决定继续、调整方案或转诊。

**注意事项 / Precautions**
- 咨询约定应现实可行,避免一开始目标过大。
- 问题定义不清会导致后续行动计划失焦。
- 对重度精神障碍、自杀风险或高度复杂问题,应尽早升级处理或转诊。

**量化指标 / Metrics**
- 咨询约定完成率
- 家庭作业执行率
- 目标达成率与症状改善趋势
