# Skill: 夫妻基本咨询与家庭作业

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“对夫妻的基本咨询”“列出清单”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
通过基础婚姻咨询要点和结构化家庭作业,促进伴侣之间的理解、责任感和沟通改进。

**适用范围 / Scope**
- 婚姻不和谐、沟通困难或关系紧张的伴侣咨询

**操作步骤 / Procedure**
1. 先向双方强调关心和责任是婚姻成功的两个关键因素。
2. 讨论常见冲突来源,如不切实际期望、经济问题、沟通不善和物质使用。
3. 引导双方梳理成功婚姻中的积极态度和共同目标。
4. 布置双方各自完成清单任务:列出父母的品格、伴侣的品格、希望对方改变的行为和希望对方为自己做的事情。
5. 约定每周安排固定时间共同分享和讨论这些清单。
6. 必要时建议双方寻求进一步专业帮助。

**注意事项 / Precautions**
- 医生不应急于裁判对错,而应维护双方表达空间。
- 若存在家庭暴力、强控制或明显安全风险,不宜按普通夫妻咨询推进。
- 伴侣作业需要双方自愿参与,否则易变成相互指责工具。

**量化指标 / Metrics**
- 双方家庭作业完成率
- 每周讨论执行率
- 伴侣对沟通改善的主观评分
