# Skill: 问题赌博识别与初步干预

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“问题赌博”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
在基层识别问题赌博相关风险,开展简短干预并在严重时及时转介专业支持。

**适用范围 / Scope**
- 社会史采集、情绪问题、家庭冲突、债务或冲动行为相关病人

**操作步骤 / Procedure**
1. 在社会史中主动询问赌博情况。
2. 识别关键警示,如每周赌博支出过高和反复追回损失。
3. 留意大量时间赌博、撒谎、秘密行为、债务、酗酒和心境波动等迹象。
4. 必要时使用 SOGS 等筛查工具支持初步诊断。
5. 一旦怀疑问题赌博,直接但尊重地质对该问题。
6. 提供教育材料,评估改变阶段并鼓励行为改变。
7. 同时关注家庭暴力和家庭支持,建议家人不要持续提供“救助金”。
8. 严重或简单干预无效时转诊赌博问题顾问,并考虑 CBT。

**注意事项 / Precautions**
- 问题赌博自杀风险高,需同步评估抑郁和安全风险。
- 没有推荐药物治疗,重点在行为和心理干预。
- 讨论财务和家庭问题时要保护隐私并避免羞辱化表达。

**量化指标 / Metrics**
- 赌博风险筛查率
- 高风险个案识别率
- 简短干预后转介接受率
