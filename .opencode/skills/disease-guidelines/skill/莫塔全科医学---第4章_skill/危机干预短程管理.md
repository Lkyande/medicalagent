# Skill: 危机干预短程管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“危机管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
在危机早期快速、建设性地干预,帮助病人恢复心理平衡和基本控制感。

**适用范围 / Scope**
- 意外死亡、婚姻破裂、突发坏消息等急性危机中的个体或家庭

**操作步骤 / Procedure**
1. 主动、直接并尽早介入危机情境。
2. 与病人建立同理心联盟,让其感到被理解和支持。
3. 评估家庭和社会支持系统,尽量把支持资源拉入干预。
4. 提前准备应对前24到48小时最困难阶段的计划。
5. 将干预设计为简短且有时限,通常6周内不超过6次交谈。
6. 必要时考虑短期精神类药物,帮助病人先恢复基本睡眠。
7. 维持可及性,但避免把危机全部背负在医生一人身上。

**注意事项 / Precautions**
- 危机干预目标是稳定和支持,不是一次解决所有深层问题。
- 药物仅作短期辅助,需严格控制适应证和时限。
- 对自杀风险、暴力风险或严重精神症状应立即升级处置。

**量化指标 / Metrics**
- 危机后24-48小时内随访率
- 短期睡眠恢复情况
- 6周内危机稳定率
