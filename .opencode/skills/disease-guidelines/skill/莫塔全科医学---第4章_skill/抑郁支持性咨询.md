# Skill: 抑郁支持性咨询

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“抑郁的病人”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
通过同理心、支持和合理解释帮助抑郁病人理解自身状态并提高治疗依从性。

**适用范围 / Scope**
- 全科门诊抑郁或低落情绪病人的初步管理与持续支持

**操作步骤 / Procedure**
1. 以同理心解释抑郁是真实疾病,而不是意志薄弱。
2. 向病人说明其会影响活动、性欲、睡眠、食欲和应对生活能力。
3. 解释“振作起来”式建议通常无效,以减少病人和家属误解。
4. 用病人易理解的方式说明可能的生物学基础,帮助其接受治疗。
5. 保持持续联系和支持,确保病人在需要时能够找到医生。
6. 在需要时转诊更专业人员,并考虑 CBT 作为重要治疗方法。

**注意事项 / Precautions**
- 仅靠解释不足以替代风险评估,需警惕自杀风险和功能明显下降。
- 对家属的教育同样重要,可提高支持质量和治疗依从性。
- 出现精神病性症状或严重抑郁时应立即升级处理。

**量化指标 / Metrics**
- 抑郁解释与教育完成率
- 复诊接触连续性
- 治疗依从性和症状量表变化
