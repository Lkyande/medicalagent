# Skill: 危机个体十条指导

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“帮助处于困扰中的人的十条规则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
为危机中的个体提供可带走的日常行为指导,帮助其在短期内恢复秩序感和行动能力。

**适用范围 / Scope**
- 处于急性压力、危机或重大生活事件后的病人

**操作步骤 / Procedure**
1. 鼓励病人允许自己表达情绪,不要压抑哭泣或喊叫等正常反应。
2. 鼓励与朋友交谈,不要回避讨论已发生的事件。
3. 引导病人专注当下和近期可处理的事情。
4. 教病人一次只解决一个问题,避免同时处理多个难题。
5. 鼓励一旦想到可行方案就积极行动。
6. 建议病人尽量参加社会活动,减少长期独处。
7. 提醒避免记仇或责怪自己和家人。
8. 每天安排放松和适量体力活动。
9. 尽量维持原有规律作息,必要时处理失眠问题。
10. 说明需要帮助时应尽早联系全科医生和社区资源,并提醒注意交通安全。

**注意事项 / Precautions**
- 指导应先口头解释,再提供书面资料带走。
- 若病人已出现严重失眠、自杀意念或明显功能崩溃,单靠指导不足。
- 不同文化和宗教背景可影响病人的支持来源,需个体化调整。

**量化指标 / Metrics**
- 书面指导发放率
- 危机后日常作息恢复率
- 社会支持资源实际使用率
