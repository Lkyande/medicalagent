# Skill: 丧亲之痛支持与筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“丧亲之痛”“全科医生作为咨询者”“长期咨询”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
识别正常与病态丧亲反应,提供早期支持并在需要时安排持续咨询或转诊。

**适用范围 / Scope**
- 亲人去世或重大丧失后的病人及其家属

**操作步骤 / Procedure**
1. 评估病人处于震惊、悲痛绝望还是适应接受阶段。
2. 识别强烈愤怒、持续不减的痛苦、多次躯体化就诊和病态悲痛线索。
3. 给予明确解释和支持,特别是关于死亡原因、方式和后续讨论需求。
4. 早期主动干预,以减少病态性悲痛发生。
5. 关注高风险家庭成员和家庭内部关系变化。
6. 提供宗教、支持团体、临终关怀或其他社区资源信息。
7. 对持续多年不减或极度悲痛者安排长期咨询或精神科转诊。

**注意事项 / Precautions**
- 丧亲者常有内疚和迁怒,医生需避免因尴尬而疏远。
- 强烈悲痛可以是正常过程,不要过早病理化。
- 出现自杀行为、重性抑郁或明显精神障碍时需立即升级处理。

**量化指标 / Metrics**
- 丧亲后早期随访率
- 高风险个体识别率
- 病态悲痛转诊率
