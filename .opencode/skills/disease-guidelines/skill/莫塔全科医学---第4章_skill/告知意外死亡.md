# Skill: 告知意外死亡

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第4章 咨询技能
- 页码: 第4章“意外死亡”“给医生的指南”“告知意外死亡坏消息的建议方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第4章.md`

**目标 / Objective**
在意外死亡场景中以最小额外伤害的方式向亲属传递事实,并提供初步支持与后续联系。

**适用范围 / Scope**
- 意外死亡、重大创伤死亡或突发死亡后的亲属沟通

**操作步骤 / Procedure**
1. 尽量由医生或有经验且有同理心的人亲自联系亲属。
2. 安排安静、私密、不受干扰的会面环境,并避免亲属独自驾车赴约。
3. 会谈前核实全部事实并制订清晰计划。
4. 先询问亲属是否已听说任何消息,并评估其理解能力。
5. 以不慌不忙、诚实、简单易懂的方式直接说明死亡事实和死因。
6. 留出时间、沉默和提问空间,必要时允许查看尸体或受伤部位。
7. 在同一场会谈中提供支持、鼓励和后续联系安排,避免告知后失联。

**注意事项 / Precautions**
- 避免忙乱、迟钝、隐瞒真相、陈词滥调和技术术语。
- 不要用委婉模糊话术掩盖死亡事实。
- 对极度激动亲属要同时关注其即时安全和陪伴支持。

**量化指标 / Metrics**
- 面对面告知完成率
- 死因解释清晰度反馈
- 告知后后续联系落实率
