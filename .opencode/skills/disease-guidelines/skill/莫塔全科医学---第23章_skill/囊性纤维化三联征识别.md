# Skill: 囊性纤维化三联征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第23章 遗传性疾病
- 页码: 第23章“囊性纤维化”“临床特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第23章.md`

**目标 / Objective**
在初诊场景识别囊性纤维化典型临床组合,尽早启动确诊流程和专科照护。

**适用范围 / Scope**
- 生长发育迟缓、慢性咳嗽、反复肺部感染或脂肪泻儿童

**操作步骤 / Procedure**
1. 关注生长发育迟缓、慢性咳嗽和稀便或灰白大便这一典型组合。
2. 追问是否存在反复肺炎、鼻息肉、鼻窦症状、吸收不良和新生儿胎粪性肠梗阻病史。
3. 评估是否合并男性不育、胰腺功能不全和运动耐量下降等支持性线索。
4. 一旦高度怀疑,安排汗氯试验并结合新生儿免疫反应性胰蛋白酶筛查结果。
5. 及时转入多学科团队,启动呼吸道引流、营养和感染管理。

**注意事项 / Precautions**
- DNA检测只能识别最常见突变,阴性不能完全排除囊性纤维化。
- 早期表现可被反复“支气管炎”或“营养不良”掩盖,需主动整合多系统线索。
- 确诊后需进行家庭遗传咨询和生育风险说明。

**量化指标 / Metrics**
- 可疑病例至确诊时间
- 汗氯试验完成率
- 多学科管理转入率
