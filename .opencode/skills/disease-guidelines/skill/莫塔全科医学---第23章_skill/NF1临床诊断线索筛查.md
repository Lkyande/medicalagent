# Skill: NF1临床诊断线索筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第23章 遗传性疾病
- 页码: 第23章“神经纤维瘤病”“NF1 的临床特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第23章.md`

**目标 / Objective**
利用体表和系统特征筛查 NF1,尽早发现需要长期监测的儿童和成人病人。

**适用范围 / Scope**
- 皮肤咖啡牛奶斑、皮肤肿物、学习困难或家族史提示 NF1 者

**操作步骤 / Procedure**
1. 检查皮肤是否存在 6 个及以上浅褐色斑点及腋窝或腹股沟雀斑。
2. 观察是否存在肉色皮肤肿瘤,并记录出现年龄和数量变化。
3. 评估伴随表现,包括高血压、学习困难、脊柱侧弯和视神经相关症状。
4. 做眼科和神经系统初筛,寻找虹膜错构瘤或视神经胶质瘤线索。
5. 对高度怀疑者转专科门诊,建立每年一次的血压、神经、骨骼和眼科随访。

**注意事项 / Precautions**
- 目前常规遗传检测并非首选,临床检查仍是主要诊断依据。
- 病情轻重差异很大,即使仅有皮肤表现也需要长期观察。
- 出现新发神经系统症状、肿瘤快速增大或视力变化时应提前复诊。

**量化指标 / Metrics**
- 可疑 NF1 病人年度随访率
- 眼科和血压筛查完成率
- 严重并发症早期识别率
