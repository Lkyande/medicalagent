# Skill: 血色素沉着病放血维持方案

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第23章 遗传性疾病
- 页码: 第23章“血色素沉着病”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第23章.md`

**目标 / Objective**
通过规范静脉放血和随访指标管理铁负荷过重,减少肝脏、心脏和内分泌并发症。

**适用范围 / Scope**
- 已确诊遗传性血色素沉着病并需要降铁治疗者

**操作步骤 / Procedure**
1. 与专科协作启动治疗,确认基线铁蛋白、转铁蛋白饱和度及器官受累情况。
2. 进入去铁阶段时每周静脉放血 500ml,持续至铁储量恢复正常。
3. 达标后转入维持阶段,每 3~4 个月放血 1 次。
4. 随访目标控制为血清铁蛋白 <100ug/L,通常维持在 40~80ug/L,转铁蛋白饱和度 <50%。
5. 同步指导低铁健康饮食、限制饮酒并避免铁剂和维生素C补充。

**注意事项 / Precautions**
- 治疗周期可能持续数年,需提前解释长期依从性的重要性。
- 已出现肝硬化、糖尿病或心肌病者应由专科同步管理并发症。
- 去铁胺可作为替代方案,但效果通常不如规律放血。

**量化指标 / Metrics**
- 铁蛋白达标率
- 维持期复诊依从率
- 治疗后器官并发症进展率
