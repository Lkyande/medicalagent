# Skill: 三代家系图绘制

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第23章 遗传性疾病
- 页码: 第23章“家系图”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第23章.md`

**目标 / Objective**
系统收集至少三代家族信息,初步识别遗传模式并为转诊咨询提供基础资料。

**适用范围 / Scope**
- 疑似遗传性疾病、先天异常、反复流产或家族聚集性疾病家庭

**操作步骤 / Procedure**
1. 以先证者为中心,收集至少三代亲属的健康、患病和死亡信息。
2. 记录每位成员的性别、亲缘关系、发病年龄、死亡年龄及主要诊断。
3. 标注家族内重复出现的疾病、早发病例、近亲婚配及不孕不育情况。
4. 结合谱系分布初步判断常染色体显性、隐性、X连锁或线粒体遗传倾向。
5. 鼓励病人按模板补充家族资料,在后续复诊时更新家系图。

**注意事项 / Precautions**
- 资料收集要细致,避免遗漏死胎、流产、夭折及不明原因猝死信息。
- 需尊重家庭隐私和伦理边界,敏感信息应在解释用途后再记录。
- 家系图只能提示遗传模式,不能替代正式遗传咨询和基因检测。

**量化指标 / Metrics**
- 至少三代家系图完成率
- 可疑遗传模式识别率
- 因家系图触发遗传转诊率
