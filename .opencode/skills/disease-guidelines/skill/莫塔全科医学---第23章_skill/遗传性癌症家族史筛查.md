# Skill: 遗传性癌症家族史筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第23章 遗传性疾病
- 页码: 第23章“关键事实和要点”“家族性癌症”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第23章.md`

**目标 / Objective**
在基层识别具有遗传性癌症倾向的家庭,及时转入专业遗传咨询和进一步检测路径。

**适用范围 / Scope**
- 本人或一级亲属有乳腺癌、卵巢癌、结直肠癌或其他早发癌症者

**操作步骤 / Procedure**
1. 询问夫妇双方家族中患癌人数、癌症类型及是否存在多原发癌。
2. 重点记录原发癌的发病年龄,识别早发癌症或同类癌症聚集现象。
3. 追问一级和二级亲属中是否存在乳腺癌、卵巢癌、结直肠癌、黑色素瘤或前列腺癌。
4. 将家族史整理入家系图,标注疑似遗传性癌症分支。
5. 建议病人接受专业遗传咨询,必要时转家庭癌症门诊评估基因检测适应证。

**注意事项 / Precautions**
- 大多数癌症并非遗传性,解释时避免造成不必要恐慌。
- 不能只记录“家里有人得癌症”,必须具体到癌种和发病年龄。
- 基因预测检测可能带来明显心理负担,需提前告知并建议专业咨询。

**量化指标 / Metrics**
- 癌症病人家族史完整记录率
- 可疑遗传性癌症识别率
- 遗传咨询转诊完成率
