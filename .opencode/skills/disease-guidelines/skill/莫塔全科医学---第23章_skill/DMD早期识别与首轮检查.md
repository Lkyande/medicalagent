# Skill: DMD早期识别与首轮检查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第23章 遗传性疾病
- 页码: 第23章“进行性假肥大性肌营养不良”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第23章.md`

**目标 / Objective**
早期识别 Duchenne 型肌营养不良并启动实验室和遗传学确诊流程。

**适用范围 / Scope**
- 2~7 岁男性儿童出现运动发育迟缓、步态异常或小腿假性肥大者

**操作步骤 / Procedure**
1. 询问运动发育、言语发育、跌倒频率和上下楼困难等早期功能问题。
2. 观察蹒跚步态、小腿假性肥大及从地面起立时的高尔征。
3. 首轮化验检测血清肌酸激酶,作为高度敏感的初筛指标。
4. 如结果支持,转入肌电图、肌营养不良蛋白基因检测及必要时肌活检。
5. 同步为母亲和家属安排遗传咨询与携带者筛检讨论。

**注意事项 / Precautions**
- 早期可仅表现为“走路晚”或“语言慢”,不要等到明显失能才评估。
- 女性携带者家属咨询不可忽略,关系到后续生育决策。
- 目前无根治治疗,但及早诊断有助于支持治疗和家庭规划。

**量化指标 / Metrics**
- 首发症状至确诊时间
- 可疑患儿 CK 检测完成率
- 遗传咨询覆盖率
