# Skill: SMA症状前筛查转介

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第23章 遗传性疾病
- 页码: 第23章“脊髓性肌萎缩”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第23章.md`

**目标 / Objective**
识别脊髓性肌萎缩高风险婴儿并尽早转入症状前治疗路径。

**适用范围 / Scope**
- 新生儿筛查异常、家族史阳性或婴儿出现肌张力低下与喂养困难者

**操作步骤 / Procedure**
1. 识别肌无力、肌张力低下、哭声微弱、吞咽或咳嗽无力等典型表现。
2. 询问家族中是否有早发肌萎缩、婴儿死亡或已知 SMN1 突变史。
3. 查看出生后 DNA 筛查结果,异常时立即联系神经肌肉专科。
4. 在等待专科期间评估喂养、呼吸和误吸风险,必要时安排支持治疗。
5. 与家属讨论症状前干预价值,包括基因治疗和鞘内诺西那生钠路径。

**注意事项 / Precautions**
- 智力和感觉通常正常,不要因意识清楚而低估病情严重性。
- 呼吸衰竭和喂养障碍进展可很快,转诊不应延迟。
- 遗传咨询对后续妊娠风险管理非常重要。

**量化指标 / Metrics**
- 筛查异常至专科转诊时间
- 呼吸和喂养支持启动率
- 症状前治疗进入率
