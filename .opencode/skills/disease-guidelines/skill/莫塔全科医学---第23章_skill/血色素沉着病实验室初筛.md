# Skill: 血色素沉着病实验室初筛

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第23章 遗传性疾病
- 页码: 第23章“血色素沉着病”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第23章.md`

**目标 / Objective**
通过关键铁代谢指标识别遗传性血色素沉着病高风险病人,启动确诊和家族筛查。

**适用范围 / Scope**
- 不明原因肝病、皮肤色素加深、糖尿病、关节痛、性腺功能减退或家族史阳性者

**操作步骤 / Procedure**
1. 识别提示铁过载的病史和体征,包括慢性肝病、青铜色皮肤、关节痛和勃起功能障碍。
2. 安排血清转铁蛋白饱和度和血清铁蛋白检测作为首选筛查。
3. 将结果与阈值比对:女性转铁蛋白饱和度 >50%,男性 >60%;女性铁蛋白 >200ug/L,男性 >300ug/L。
4. 指标异常时进一步申请 HFE 基因检测,重点关注 C282Y 和 H63D 突变。
5. 对确诊或高度可疑病人的一级亲属安排相应生化筛查或遗传检测并转专科管理。

**注意事项 / Precautions**
- 血清铁不是理想筛查指标,不要单独依赖血清铁判断。
- 未成年人通常无须常规筛查,亲属检测应结合年龄与风险分层。
- 铁蛋白明显升高伴肝功能异常或肝大时,需警惕肝损伤并加快专科评估。

**量化指标 / Metrics**
- 高风险病人铁代谢筛查率
- 指标异常后基因检测完成率
- 一级亲属筛查覆盖率
