# Skill: 糖尿病并发症监测

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第11章 糖尿病
- 页码: 第11章“糖尿病的并发症”“监测技术”“管理原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第11章.md`

**目标 / Objective**
通过结构化随访监测糖尿病的大血管和微血管并发症,实现早发现和早干预。

**适用范围 / Scope**
- 所有 1 型和 2 型糖尿病病人,尤其病程长或控制不佳者

**操作步骤 / Procedure**
1. 每次随访记录血压、空腹或餐后血糖、低血糖事件和体重变化。
2. 每 3 个月复查 HbA1c,根据控制情况调整频率。
3. 定期检测 ACR、血清肌酐、eGFR 和血脂,评估肾病与心血管风险。
4. 主动询问视力变化、足部麻木刺痛、勃起功能障碍、感染和心脑血管症状。
5. 组织眼底检查、足部检查和免疫接种更新,必要时转专科处理。

**注意事项 / Precautions**
- 2 型糖尿病在确诊时即可能已有并发症,不要等待病程很长才启动监测。
- 试纸尿蛋白不如 ACR 敏感,早期肾病监测应优先选择晨尿 ACR。
- 老年病人要特别注意直立性低血压、足部护理和多重用药风险。

**量化指标 / Metrics**
- HbA1c 达标率
- 年度 ACR 检测率
- 眼底与足部检查完成率
