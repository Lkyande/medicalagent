# Skill: 糖尿病前期生活方式干预

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第11章 糖尿病
- 页码: 第11章“糖尿病前期”“糖尿病的预防”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第11章.md`

**目标 / Objective**
对糖尿病前期或极高危人群实施生活方式干预,延缓或预防 2 型糖尿病发生。

**适用范围 / Scope**
- 空腹血糖受损、糖耐量受损、超重或肥胖的高危成人

**操作步骤 / Procedure**
1. 向病人解释其当前处于糖尿病前期而非确诊糖尿病,但进展风险显著升高。
2. 以减重为核心,制订 SNAP 生活方式计划,覆盖吸烟、营养、酒精和体力活动。
3. 设定每周至少 150 分钟运动或每周 5 天每次至少步行 30 分钟的目标。
4. 指导减少高糖、高脂和过量酒精摄入,增加健康饮食与规律作息。
5. 安排定期复查血糖或 HbA1c,根据体重和活动达标情况强化随访。

**注意事项 / Precautions**
- 糖尿病前期通常无需立即药物治疗,重点在持续行为改变。
- 生活方式干预的健康收益可超过后期单纯药物干预。
- 干预目标应具体、可追踪,避免只给出笼统的“注意饮食运动”。

**量化指标 / Metrics**
- 体重下降幅度
- 每周运动达标率
- 糖尿病前期进展为糖尿病的比例
