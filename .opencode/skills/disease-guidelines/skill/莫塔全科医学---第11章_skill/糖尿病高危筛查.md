# Skill: 糖尿病高危筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第11章 糖尿病
- 页码: 第11章“危险因素”“筛查(2型糖尿病)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第11章.md`

**目标 / Objective**
在基层识别无症状但处于糖尿病高风险的人群,决定是否进入实验室筛查流程。

**适用范围 / Scope**
- 年龄增长、肥胖、家族史、妊娠糖尿病史、PCOS、心血管疾病或高风险族群成人

**操作步骤 / Procedure**
1. 询问年龄、一级亲属糖尿病史、既往妊娠糖尿病史和体力活动水平。
2. 记录 BMI、腰围、血压及是否长期使用类固醇或抗精神病药。
3. 识别高风险族群,包括原住民、太平洋岛民、印度次大陆居民和非洲裔加勒比人。
4. 对年龄大于 40 岁或年龄大于 30 岁且伴肥胖、家族史等风险因素者安排血糖或 HbA1c 检测。
5. 对糖尿病前期或原住民等高危人群至少每年复筛,一般高危成人每 3 年复筛一次。

**注意事项 / Precautions**
- 许多 2 型糖尿病病人无症状,不能仅凭症状决定是否筛查。
- 急性疾病、外伤或手术后可出现暂时性高血糖,解释结果时要结合情境。
- 高风险年轻人同样需要筛查,不要仅因年龄较小而漏诊。

**量化指标 / Metrics**
- 高危人群筛查覆盖率
- 首次筛查阳性检出率
- 高危人群按建议周期复筛率
