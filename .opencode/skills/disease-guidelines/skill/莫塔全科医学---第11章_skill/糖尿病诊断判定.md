# Skill: 糖尿病诊断判定

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第11章 糖尿病
- 页码: 第11章“诊断”“表11.3 糖尿病的诊断试验结果解释”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第11章.md`

**目标 / Objective**
依据症状与实验室阈值,标准化判定糖尿病、糖尿病前期或需进一步 OGTT 的情况。

**适用范围 / Scope**
- 疑似糖尿病或筛查异常的成人、儿童及妊娠期需进一步评估者

**操作步骤 / Procedure**
1. 先确认病人是否存在多饮、多尿、反复皮肤或生殖器感染等高血糖症状。
2. 有症状时,按空腹静脉血糖大于等于 7.0 mmol/L、随机血糖大于等于 11.1 mmol/L 或 HbA1c 大于 6.5% 判定糖尿病。
3. 无症状时,要求至少 2 次独立异常血糖结果,或采用 OGTT 两个时间点结果进行确认。
4. 当随机或空腹静脉血糖处于 5.5 到 11.0 mmol/L 的不确定范围,且伴症状或危险因素时安排 OGTT。
5. 将空腹血糖 6.1 到 6.9 mmol/L 或糖耐量受损者归入糖尿病前期,进入生活方式干预和复查路径。

**注意事项 / Precautions**
- 尿糖受肾阈值影响大,不能作为确诊依据。
- 妊娠糖尿病和临界病例优先使用 OGTT。
- 儿童高血糖常提示 1 型糖尿病急症,不要延迟转诊。

**量化指标 / Metrics**
- 异常血糖结果复核完成率
- OGTT 安排完成率
- 糖尿病前期识别率
