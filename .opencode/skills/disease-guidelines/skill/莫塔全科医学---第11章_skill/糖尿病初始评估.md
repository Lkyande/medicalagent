# Skill: 糖尿病初始评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第11章 糖尿病
- 页码: 第11章“病史”“身体检查”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第11章.md`

**目标 / Objective**
在疑似或已知糖尿病病人首次评估时系统收集症状、并发症与心血管风险信息。

**适用范围 / Scope**
- 新发现高血糖、疑似糖尿病或新确诊糖尿病病人

**操作步骤 / Procedure**
1. 询问多尿、多饮、多食、体重减轻、夜尿、乏力和感染倾向等典型症状。
2. 同步询问胸痛、呼吸困难、视物模糊、足手刺痛、性功能变化和泌尿症状,筛查并发症。
3. 记录家族史、用药史、吸烟饮酒、体力活动、饮食习惯及孕产史。
4. 完成 BMI、腰围、血压、视力、皮肤检查及周围神经病变筛查。
5. 安排尿常规、血糖、HbA1c,并按临床需要追加血脂、肾功能、ACR 和心电图。

**注意事项 / Precautions**
- 初评不仅是确诊,还要同步寻找终末器官损害和心血管风险。
- 皮肤和生殖器真菌感染可作为未控糖尿病的重要线索。
- 站立位和卧位血压都有价值,尤其老年病人和疑似自主神经病变者。

**量化指标 / Metrics**
- 新诊糖尿病完整初评率
- ACR 与肾功能基线检测率
- 周围神经病变筛查完成率
