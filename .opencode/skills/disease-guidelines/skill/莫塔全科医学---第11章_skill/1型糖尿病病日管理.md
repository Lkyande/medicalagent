# Skill: 1型糖尿病病日管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第11章 糖尿病
- 页码: 第11章“有症状的时候”“运动”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第11章.md`

**目标 / Objective**
在感染、恶心、呕吐或食欲差等病日情境中,降低 1 型糖尿病酮症和失控风险。

**适用范围 / Scope**
- 出现急性疾病、呕吐、进食减少或运动安排变化的 1 型糖尿病病人

**操作步骤 / Procedure**
1. 预先为病人制订病日行动计划,明确何时加测血糖和何时求助。
2. 即使生病或食欲差,也提醒病人不要自行减少胰岛素剂量。
3. 在血糖升高时增加监测频率,若血糖大于 15 mmol/L 提高警觉并寻求专业支持。
4. 根据活动量和进食情况调整胰岛素并补充额外碳水化合物,尤其运动前后。
5. 一旦出现持续呕吐、进行性高血糖或明显脱水,立即转急诊评估酮症酸中毒。

**注意事项 / Precautions**
- 病日往往需要更多而不是更少的快速起效胰岛素。
- 呕吐或恶心不代表可以停胰岛素。
- 运动前应个体化调整剂量,避免低血糖。

**量化指标 / Metrics**
- 病日教育覆盖率
- 病日紧急就诊前电话求助率
- 1 型糖尿病酮症酸中毒发生率
