# Skill: 急性痛风首发处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第25章 关节炎
- 页码: 第25章“痛风”“急性发作”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第25章.md`

**目标 / Objective**
在急性痛风发作时快速缓解疼痛并避免常见用药错误。

**适用范围 / Scope**
- 典型急性单关节炎,疑似或确诊急性痛风病人

**操作步骤 / Procedure**
1. 识别典型表现,包括第一跖趾关节晨起急性红肿热痛及触痛剧烈。
2. 在条件允许时抽取滑膜液,用偏振显微镜寻找尿酸盐晶体作为确诊依据。
3. 及时启动一线抗炎治疗,首选足量 NSAIDs,无法使用时选择口服泼尼松龙。
4. 需要时使用低剂量秋水仙碱方案:先 1mg,1 小时后 0.5mg,总量 1.5mg。
5. 治疗期间监测肾功能和电解质,同时处理脱水、酒精和利尿剂等诱因。

**注意事项 / Precautions**
- 急性发作期不要新启或调整别嘌醇等降尿酸治疗。
- 避免阿司匹林,并警惕秋水仙碱与大环内酯类药物相互作用,尤其在慢性肾病病人中。
- 血尿酸在急性发作时可正常,不能因化验正常而否定痛风。

**量化指标 / Metrics**
- 发作后 24 小时内抗炎治疗启动率
- 关节液晶体确诊率
- 急性期用药错误率
