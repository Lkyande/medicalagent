# Skill: 假性痛风穿刺与局部注射

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第25章 关节炎
- 页码: 第25章“焦磷酸钙晶体性疾病(假性痛风)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第25章.md`

**目标 / Objective**
在排除感染后通过关节穿刺和局部激素治疗缓解假性痛风急性发作。

**适用范围 / Scope**
- 老年人急性膝关节、腕关节或掌指关节炎,怀疑假性痛风者

**操作步骤 / Procedure**
1. 根据受累关节分布和老年发病特点怀疑假性痛风。
2. 抽取滑膜液做显微镜检查确认焦磷酸钙晶体,并同时排除化脓性关节炎。
3. 结合 X 线查找关节软骨钙化,支持临床诊断。
4. 在排除感染后行关节穿刺减压并关节腔内注射长效糖皮质激素镇痛。
5. 如仍有症状,根据耐受性加用对乙酰氨基酚、秋水仙碱或慎用 NSAIDs。

**注意事项 / Precautions**
- 发热并不一定是感染,假性痛风也可表现为明显炎症反应。
- 老年病人使用 NSAIDs 风险高,通常优先考虑对乙酰氨基酚。
- 未排除感染前不要盲目注射激素。

**量化指标 / Metrics**
- 关节液显微镜检查完成率
- 穿刺后疼痛缓解率
- 误治化脓性关节炎事件数
