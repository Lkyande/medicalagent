# Skill: 痛风长期降尿酸管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第25章 关节炎
- 页码: 第25章“痛风”“长期治疗”“预防”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第25章.md`

**目标 / Objective**
通过生活方式干预和降尿酸药物减少痛风复发及痛风石形成。

**适用范围 / Scope**
- 频繁急性发作、痛风石、慢性痛风性关节炎或尿酸结石病人

**操作步骤 / Procedure**
1. 在急性发作完全缓解后评估是否具备长期降尿酸治疗适应证。
2. 指导减重、减少酒精和果糖饮料、限制高嘌呤食物并保证每日约 2L 饮水。
3. 首选别嘌醇,一般从 50~100mg/d 起始,逐步加量至最大 300mg/d 或按反应调整。
4. 4 周后复查尿酸,目标控制在 <0.38mmol/L,并根据结果继续滴定剂量。
5. 起始数月加用秋水仙碱 0.5mg 每日 1~2 次或其他预防方案,减少诱发再发。

**注意事项 / Precautions**
- 肾功能不全和老年病人需降低别嘌醇剂量并密切监测。
- 别嘌醇与硫唑嘌呤、巯嘌呤存在潜在致命相互作用。
- 长期管理必须同时处理肥胖、高血压、糖尿病和慢性肾病等共病。

**量化指标 / Metrics**
- 血尿酸达标率
- 12 个月内复发次数
- 生活方式干预依从率
