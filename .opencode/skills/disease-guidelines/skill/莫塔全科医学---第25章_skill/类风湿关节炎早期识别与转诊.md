# Skill: 类风湿关节炎早期识别与转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第25章 关节炎
- 页码: 第25章“类风湿关节炎”“治疗原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第25章.md`

**目标 / Objective**
在早期阶段识别类风湿关节炎并尽快进入 DMARD 治疗窗口。

**适用范围 / Scope**
- 手足小关节对称性疼痛、晨僵或持续炎性关节炎病人

**操作步骤 / Procedure**
1. 识别典型分布:掌指关节、近端指间关节、腕关节和跖趾关节对称受累。
2. 询问晨僵是否超过 1 小时、夜间痛是否影响睡眠及症状是否持续超过 6 周。
3. 查体寻找软组织肿胀、滑膜增厚、握力下降和早期功能受限。
4. 安排 ESR、CRP、类风湿因子和抗环瓜氨酸抗体,必要时做 X 线或 MRI。
5. 对高度怀疑或抗 CCP 阳性病人尽快转风湿专科,争取前两年内启动 DMARD 治疗。

**注意事项 / Precautions**
- 类风湿因子阴性不能排除 RA,早期病例尤其如此。
- 单关节起病也可能是 RA,不要只在多关节受累时考虑。
- RA 伴显著心血管风险,长期管理不能只关注关节症状。

**量化指标 / Metrics**
- 症状至专科转诊时间
- 抗 CCP 检测完成率
- 早期 DMARD 启动率
