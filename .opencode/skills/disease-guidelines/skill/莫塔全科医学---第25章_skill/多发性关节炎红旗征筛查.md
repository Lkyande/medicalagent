# Skill: 多发性关节炎红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第25章 关节炎
- 页码: 第25章“多发性关节炎的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第25章.md`

**目标 / Objective**
尽早识别提示感染、系统性炎症或肿瘤的关节炎病人,避免以“普通风湿痛”误处理。

**适用范围 / Scope**
- 新发多关节痛或多关节炎病人

**操作步骤 / Procedure**
1. 记录是否存在发热、体重减轻、大量皮疹、淋巴结肿大和明显乏力。
2. 查体评估是否有心脏杂音、血管炎征象和两个及以上系统受累表现。
3. 关注剧烈疼痛、残疾程度与关节数目是否匹配,警惕感染性关节炎或恶性病变。
4. 将病人分层为炎性、感染性、结缔组织病性或肿瘤相关可能,决定检查优先级。
5. 红旗征阳性者尽快安排血液检查、培养或专科转诊,不以单纯止痛结束评估。

**注意事项 / Precautions**
- 发热合并心脏杂音时要警惕感染性心内膜炎相关关节炎。
- 多系统受累往往提示全身性疾病,不要只盯住单个关节。
- 老年人被误归为骨关节炎的风险高,尤其要注意风湿性多肌痛和恶性肿瘤。

**量化指标 / Metrics**
- 红旗征记录率
- 红旗阳性病人专科转诊率
- 系统性疾病漏诊率
