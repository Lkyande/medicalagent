# Skill: 关节炎关键病史采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第25章 关节炎
- 页码: 第25章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第25章.md`

**目标 / Objective**
通过结构化提问区分炎性、退行性、感染性和反应性关节病线索。

**适用范围 / Scope**
- 所有关节痛或关节炎病人

**操作步骤 / Procedure**
1. 明确疼痛是单关节还是多关节,是否对称,以及疼痛是否影响睡眠和晨起活动。
2. 询问活动后是否缓解或加重,用以区分炎性疼痛与骨关节炎样疼痛。
3. 追问皮疹、发热、乏力、咽痛、腹泻、眼部症状、尿道或阴道分泌物等关节外表现。
4. 记录家族史、外伤史、银屑病史、风湿热史、旅行史、未经处理牛奶暴露及药物使用,特别是利尿剂。
5. 询问酒精摄入和性病风险,为痛风、反应性关节炎和淋球菌感染分层。

**注意事项 / Precautions**
- 不是所有关节痛都是关节炎,需区分关节周围疼痛与关节内炎症。
- 利尿剂、抗生素和可诱导自身抗体的药物都可能是病因线索。
- 腹泻、红眼、口腔溃疡和皮疹常比局部关节体征更能提示系统性病因。

**量化指标 / Metrics**
- 关节炎病史要素完整率
- 药物和旅行史记录率
- 初诊病因分层准确率
