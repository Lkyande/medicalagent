# Skill: 骨关节炎与炎性关节病鉴别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第25章 关节炎
- 页码: 第25章“骨关节炎”“与炎性关节病的鉴别”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第25章.md`

**目标 / Objective**
在门诊快速区分骨关节炎和炎性关节病,指导后续检查与治疗方向。

**适用范围 / Scope**
- 中老年关节痛、僵硬或活动受限病人

**操作步骤 / Procedure**
1. 询问疼痛是否在下午、晚上、负重或活动后加重,休息后缓解。
2. 判断晨僵持续时间是否少于 30 分钟,并与炎性关节炎的长晨僵相比较。
3. 观察受累关节分布,重点看第一腕掌关节、远端指间关节、膝髋关节及脊柱小关节。
4. 查体寻找粗糙捻发音、骨性增生、无明显软组织肿胀以及无全身表现。
5. 必要时结合 X 线查看关节间隙变窄、骨赘和软骨下硬化,完成临床影像整合判断。

**注意事项 / Precautions**
- X 线严重程度与症状并不总成正比,不要只按片子做决定。
- 利尿剂使用者的手部骨关节炎可合并结节性痛风,需留意混合病因。
- 老年人不能把所有关节痛都归因于骨关节炎。

**量化指标 / Metrics**
- OA 与炎性关节炎初诊鉴别准确率
- 不必要自身抗体检测减少率
- 骨关节炎功能评估完成率
