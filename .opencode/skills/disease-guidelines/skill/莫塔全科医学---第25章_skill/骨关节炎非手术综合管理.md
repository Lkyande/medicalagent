# Skill: 骨关节炎非手术综合管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第25章 关节炎
- 页码: 第25章“骨关节炎”“治疗原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第25章.md`

**目标 / Objective**
通过教育、运动、减重和阶梯镇痛减少骨关节炎疼痛并维持功能。

**适用范围 / Scope**
- 已确诊骨关节炎且暂无手术急症指征者

**操作步骤 / Procedure**
1. 向病人解释骨关节炎的退行性本质和长期管理目标,减轻对“关节坏死”的焦虑。
2. 纠正可变危险因素,尤其是肥胖、重复劳损和不合理活动模式。
3. 制定循序渐进的锻炼计划,鼓励髋膝关节规律运动而非长期休息。
4. 以规律对乙酰氨基酚为基础镇痛,必要时短期加用 NSAIDs 或 COX-2 抑制剂并评估胃肾风险。
5. 对功能受限者联合物理治疗、作业治疗、辅助器具或在特定情况下考虑关节内激素注射。

**注意事项 / Precautions**
- 长期卧床休息是禁忌,会加重功能下降。
- 不建议常规推荐氨基葡萄糖、软骨素、干细胞或口服激素等缺乏证据的治疗。
- 使用 NSAIDs 前要权衡胃出血、肾功能和肝毒性风险。

**量化指标 / Metrics**
- 运动处方执行率
- BMI 下降比例
- 镇痛后功能改善评分
