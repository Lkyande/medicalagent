# Skill: 脊柱关节病识别与初始管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第25章 关节炎
- 页码: 第25章“脊柱关节病”“管理原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第25章.md`

**目标 / Objective**
识别血清阴性脊柱关节病并启动基础理疗、止痛和专科评估路径。

**适用范围 / Scope**
- 年轻人炎性腰背痛、骶髂痛、附着点炎或不对称下肢关节炎

**操作步骤 / Procedure**
1. 识别炎性腰背痛特征:持续超过 3 个月、晨僵 >30 分钟、下半夜痛醒、活动缓解休息不缓解。
2. 查找附着点炎、指趾炎、虹膜炎、银屑病、炎症性肠病和家族聚集等支持线索。
3. 安排骶髂关节 X 线、ESR、CRP,必要时补充 HLA-B27 和感染相关培养。
4. 启动非甾体抗炎药治疗并指导伸展训练、姿势练习和水疗。
5. 对诊断不清、常规治疗无效或合并眼部并发症者转风湿专科。

**注意事项 / Precautions**
- HLA-B27 特异度有限,阳性更多用于风险和预后判断。
- 不推荐常规全身糖皮质激素治疗。
- 急性前葡萄膜炎是重要并发症,出现眼红痛畏光需立即眼科会诊。

**量化指标 / Metrics**
- 炎性腰背痛识别率
- 骶髂关节影像完成率
- 早期理疗启动率
