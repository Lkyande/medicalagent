# Skill: 髌股关节疼痛综合征初始管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第56章 膝痛
- 页码: 第56章“髌股关节疼痛综合征”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第56章.md`

**目标 / Objective**
对最常见的膝前痛实施保守治疗并纠正加重因素。

**适用范围 / Scope**
- 以髌骨后方或膝前部过度使用性疼痛为主的病人

**操作步骤 / Procedure**
1. 识别爬楼、下蹲、下坡、久坐和“电影院征”诱发的髌股关节痛模式。
2. 通过髌骨挤压与股四头肌收缩试验再现症状,支持髌股来源。
3. 告知病人该病通常良性,先减少会加重疼痛的活动。
4. 转诊理疗并实施股四头肌和相关下肢力线康复训练。
5. 评估扁平足或鞋袜问题,必要时使用矫形器并配合对乙酰氨基酚或短程 NSAID。

**注意事项 / Precautions**
- 该病常无明确外伤史,不要因影像正常而忽视症状真实性。
- 髋部与足部生物力学异常会持续加重膝前痛。
- 持续积液或机械交锁不符合单纯髌股疼痛综合征。

**量化指标 / Metrics**
- 髌股疼痛综合征识别率
- 康复训练启动率
- 6 至 12 周症状改善率
