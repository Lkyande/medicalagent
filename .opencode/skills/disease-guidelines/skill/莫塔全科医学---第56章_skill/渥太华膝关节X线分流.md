# Skill: 渥太华膝关节X线分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第56章 膝痛
- 页码: 第56章“渥太华膝部定律”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第56章.md`

**目标 / Objective**
用渥太华膝关节规则识别需要急诊 X 线检查的损伤膝。

**适用范围 / Scope**
- 急性膝关节损伤后评估是否需要拍片的病人

**操作步骤 / Procedure**
1. 记录病人年龄是否 55 岁或以上。
2. 检查是否存在独立的髌骨压痛。
3. 触诊腓骨头是否有压痛。
4. 判断膝关节能否屈曲到 90 度。
5. 评估受伤当时和就诊时是否都无法完成 4 步负重,任一阳性即安排 X 线。

**注意事项 / Precautions**
- 跛行本身不算不能负重,必须确认无法完成 4 步承重。
- 规则用于分流拍片,不能替代对韧带和半月板损伤的判断。
- 老年人跌落后注意力可能转移至头部,膝部损伤容易被漏问。

**量化指标 / Metrics**
- 渥太华规则应用率
- 不必要膝部 X 线减少率
- 骨折漏检率
