# Skill: 膝痛红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第56章 膝痛
- 页码: 第56章“膝部疼痛的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第56章.md`

**目标 / Objective**
及时识别提示感染、关节积血、肿瘤或严重内部损伤的高危膝痛表现。

**适用范围 / Scope**
- 所有急性或持续性膝痛病人

**操作步骤 / Procedure**
1. 判断是否存在创伤或非创伤所致的急性膝关节肿胀。
2. 查找急性红斑或慢性红斑急性加重表现。
3. 询问发热或其他非创伤性全身反应。
4. 识别无法解释的慢性持续性疼痛,尤其夜间痛或骨痛。
5. 红旗征阳性时优先安排影像、炎症检查和必要的关节穿刺。

**注意事项 / Precautions**
- 自发性积液可能是风湿病、晶体病或骨坏死的重要线索。
- 腘窝囊肿破裂可模拟 DVT,不能轻率处理。
- 儿童和青少年膝痛更需回看髋部和全身炎症病因。

**量化指标 / Metrics**
- 膝痛红旗征记录率
- 红旗征阳性病例进一步检查完成率
- 严重病因漏诊率
