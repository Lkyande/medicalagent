# Skill: 膝损伤病史与肿胀时序判断

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第56章 膝痛
- 页码: 第56章“病史”“受伤后肿胀”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第56章.md`

**目标 / Objective**
通过损伤机制和肿胀发生时序快速判断关节积血、渗出或滑囊炎来源。

**适用范围 / Scope**
- 急性膝部损伤或损伤后肿胀的病人

**操作步骤 / Procedure**
1. 详细询问是否跳起落地、直接打击、扭转、外翻或内翻受伤。
2. 追问是否听到爆裂声、感觉打软腿、震颤感或骨头分离感。
3. 明确受伤后多久出现疼痛以及多久开始肿胀。
4. 将 60 分钟内肿胀解释为关节积血,6 至 24 小时肿胀解释为滑液渗出。
5. 若肿胀数天后局限于膝前,优先考虑滑囊炎而非关节内大损伤。

**注意事项 / Precautions**
- 急性关节积血最常见原因是前交叉韧带撕裂。
- 轻微损伤却快速积血时要考虑出血倾向或抗凝药物影响。
- 半月板本身无血供,通常不会单独导致典型急性积血。

**量化指标 / Metrics**
- 损伤机制记录率
- 肿胀时序记录率
- 初步病变层次判断准确率
