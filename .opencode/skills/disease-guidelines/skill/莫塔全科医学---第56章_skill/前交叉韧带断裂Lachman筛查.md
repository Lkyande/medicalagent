# Skill: 前交叉韧带断裂Lachman筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第56章 膝痛
- 页码: 第56章“前交叉韧带断裂”“Lachman试验”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第56章.md`

**目标 / Objective**
尽早识别前交叉韧带断裂并区分其与其他急性膝损伤。

**适用范围 / Scope**
- 运动损伤后急性膝痛、快速积血或打软腿病人

**操作步骤 / Procedure**
1. 先根据突然变向、屈膝旋转、外翻外力和爆裂感提高 ACL 怀疑度。
2. 记录是否在 30 分钟内形成明显血性渗出并出现不能负重或膝不稳。
3. 将膝关节置于 15 至 20 度屈曲位,一手固定股骨远端,一手前拉胫骨近端。
4. 比较双侧前移距离及终点感,前移增大且无明确终点视为阳性。
5. 若合并内侧副韧带或半月板损伤线索,尽快转骨科做进一步评估与重建决策。

**注意事项 / Precautions**
- 屈膝 90 度的前抽屉试验可能阴性,不能取代 Lachman 试验。
- 髌骨脱位可模拟 ACL 损伤,需做鉴别。
- 轴移试验更复杂,通常在明确不稳定时由熟练者进行。

**量化指标 / Metrics**
- ACL 早期识别率
- Lachman 试验完成率
- 首诊到骨科评估时间
