# Skill: 儿童肺炎住院分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第32章 咳嗽
- 页码: 第32章“儿童的肺炎”“儿童肺炎的住院指南”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第32章.md`

**目标 / Objective**
识别需要住院治疗的儿童肺炎,尽早处理低氧和喂养失败风险。

**适用范围 / Scope**
- 怀疑儿童肺炎的婴幼儿和年长儿童

**操作步骤 / Procedure**
1. 识别呼吸急促、呼吸沉重及局部胸部体征,必要时用胸片确认肺炎。
2. 婴儿重点筛查呼吸频率 >70 次/min、间歇性呼吸暂停和不能喂食。
3. 较大儿童重点筛查呼吸频率 >50 次/min、呼噜声和脱水征象。
4. 所有年龄段评估 SaO2<=92%、发绀、呼吸困难和家庭照护能力。
5. 符合任一住院标准时安排住院,并同步开始补液、监测和经验性抗菌治疗。

**注意事项 / Precautions**
- 48 个月以下儿童住院阈值更低,需更积极处理。
- 病毒病因常见,但重症分层首先看呼吸和氧合,而不是先区分病原。
- 血氧和喂养能力是儿童病情恶化的重要早期指标。

**量化指标 / Metrics**
- 儿童肺炎血氧评估率
- 符合标准病人住院率
- 低氧延迟识别率
