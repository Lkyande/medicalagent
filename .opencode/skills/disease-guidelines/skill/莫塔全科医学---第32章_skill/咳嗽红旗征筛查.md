# Skill: 咳嗽红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第32章 咳嗽
- 页码: 第32章“咳嗽的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第32章.md`

**目标 / Objective**
在咳嗽初诊时识别需要紧急进一步检查的严重呼吸系统疾病。

**适用范围 / Scope**
- 急性或慢性咳嗽病人

**操作步骤 / Procedure**
1. 主动询问咯血、体重减轻、发热盗汗、胸痛、呼吸困难和持续时间。
2. 筛查吸烟史、石棉或鸟类暴露、结核接触史和近期卧床手术史。
3. 对老年人、持续咳嗽和高危职业人群提高对肺癌、肺栓塞和结核的警惕。
4. 若存在红旗征,优先安排胸片及进一步影像或专科评估。
5. 对任何咯血病人执行单独的咯血排查路径,不按普通支气管炎处理。

**注意事项 / Precautions**
- 慢性咳嗽并不等于哮喘,缺少气流受限时不要轻率诊断。
- 肺癌在老年慢性咳嗽中必须主动筛查。
- 支气管扩张、异物和假性咯血是常见漏诊点。

**量化指标 / Metrics**
- 红旗征记录率
- 高危咳嗽胸片完成率
- 严重病因漏诊率
