# Skill: 流感临床识别与抗病毒启动

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第32章 咳嗽
- 页码: 第32章“流行性感冒”“临床诊断标准”“抗病毒药物”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第32章.md`

**目标 / Objective**
在流感流行期识别真正流感并在高风险病人中及时启动抗病毒药物。

**适用范围 / Scope**
- 流感季节出现急性发热、肌痛和呼吸道症状的病人

**操作步骤 / Procedure**
1. 在流行期根据体温 >38℃、至少一种呼吸道症状和一种全身症状判断流感可能性。
2. 区分流感与普通感冒:流感常突然起病,伴高热、寒战、头痛和肌痛。
3. 必要时做鼻咽拭子 PCR 或快速特异性检测确认。
4. 对高风险或易感病人尽量在发病 36 小时内启动奥司他韦或扎那米韦,疗程 5 日。
5. 同时给予卧床休息、充分补液和退热镇痛,并监测细菌继发感染等并发症。

**注意事项 / Precautions**
- 低风险普通病人从抗病毒中获益有限,不要机械性全员开药。
- 流感后 2~4 周出现肺炎链球菌肺炎是重要并发症,复诊时需提醒。
- 持续高热、呼吸困难或虚脱需升级评估重症流感或继发肺炎。

**量化指标 / Metrics**
- 高风险病人 36 小时内抗病毒启动率
- PCR 检测完成率
- 流感并发症复诊率
