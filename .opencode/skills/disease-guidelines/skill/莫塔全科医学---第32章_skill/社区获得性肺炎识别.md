# Skill: 社区获得性肺炎识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第32章 咳嗽
- 页码: 第32章“社区获得性肺炎”“典型肺炎”“临床特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第32章.md`

**目标 / Objective**
识别社区获得性肺炎的典型和非典型表现,避免将其误判为单纯上呼吸道感染。

**适用范围 / Scope**
- 发热、咳嗽、脓痰、胸膜痛或全身症状明显的呼吸道病人

**操作步骤 / Procedure**
1. 对急性起病高热、寒战、胸膜痛、浅快呼吸和肺实变体征病人考虑典型肺炎。
2. 对发热、头痛、全身不适而呼吸道体征轻微者考虑非典型肺炎。
3. 安排胸部 X 线、血氧饱和度、痰检和必要的特异性检测或 PCR。
4. 结合年龄、基础病和病原体可能性做经验性抗感染分层。
5. 动态监测是否出现胸腔积液、脓胸、肺脓肿或呼吸衰竭等并发症。

**注意事项 / Precautions**
- 肺炎初期可先以全身症状为主,尤其在非典型病原体感染中更易漏诊。
- 胸部 X 线浸润与胸部体征不一致时尤其要想到非典型肺炎。
- 老年人和慢性病病人常表现不典型,需更积极影像学确认。

**量化指标 / Metrics**
- 可疑肺炎胸片完成率
- 首诊至抗生素启动时间
- 肺炎并发症检出率
