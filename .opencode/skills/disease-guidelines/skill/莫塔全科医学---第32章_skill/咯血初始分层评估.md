# Skill: 咯血初始分层评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第32章 咳嗽
- 页码: 第32章“咯血”“咯血诊断策略模型”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第32章.md`

**目标 / Objective**
在发现咯血时快速区分感染、肿瘤、肺栓塞和假性咯血等主要路径。

**适用范围 / Scope**
- 痰中带血或大量咯血的成人病人

**操作步骤 / Procedure**
1. 先确认血液来源,将咯血与鼻咽出血、鼻窦炎血液混入唾液及呕血区分开。
2. 评估咯血量、伴随胸痛、呼吸困难、发热和体重减轻等危险症状。
3. 结合急性肺部感染、慢性支气管炎、支扩、结核和肺癌等常见病因分层。
4. 首轮安排胸部 X 线,必要时做痰细胞学、培养和 CT。
5. 对可疑肺栓塞、肺癌或大量咯血病人立即升级急诊或专科处理。

**注意事项 / Precautions**
- 即使少量痰中带血也不能掉以轻心,尤其是吸烟者和老年人。
- 支气管镜最好在活动性咯血时更有定位价值。
- 急性支气管炎也可有血丝痰,但需在排除严重病因后才能下此结论。

**量化指标 / Metrics**
- 咯血病人胸片完成率
- 假性咯血识别率
- 严重咯血紧急转诊率
