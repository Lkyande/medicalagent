# Skill: 普通感冒支持治疗

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第32章 咳嗽
- 页码: 第32章“普通感冒”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第32章.md`

**目标 / Objective**
对普通感冒提供以休息、补液和对症用药为核心的管理,减少不必要抗生素使用。

**适用范围 / Scope**
- 轻度上呼吸道感染、明显鼻部症状且无严重并发症病人

**操作步骤 / Procedure**
1. 根据流涕、打喷嚏、咽痛、低热和轻度全身不适识别普通感冒。
2. 建议充足休息、多饮水并戒烟。
3. 以对乙酰氨基酚等镇痛退热药缓解不适,鼻塞明显时可考虑雾化吸入或局部对症措施。
4. 干咳明显时可短期使用止咳药,咽痛可用局部含漱或缓解措施。
5. 向病人说明维生素 C、锌和紫锥菊疗效不确定,通常无需抗生素。

**注意事项 / Precautions**
- 儿童 16 岁以下避免使用阿司匹林。
- 脓涕在感冒后 24 小时内出现并不一定代表细菌感染。
- 普通感冒与流感要区分,流感的全身症状更重且起病更急。

**量化指标 / Metrics**
- 抗生素不恰当使用率
- 对症治疗宣教覆盖率
- 复诊因并发症升级比例
