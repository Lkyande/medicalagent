# Skill: 急性支气管炎抗生素决策

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第32章 咳嗽
- 页码: 第32章“急性支气管炎”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第32章.md`

**目标 / Objective**
在急性支气管炎中合理区分仅需对症处理和需要抗生素的少数病人。

**适用范围 / Scope**
- 咳嗽咳痰、散在哮鸣音且疑似急性支气管炎病人

**操作步骤 / Procedure**
1. 根据咳嗽、咳痰、喘息和听诊散在哮鸣音识别急性支气管炎。
2. 评估是否存在气流受限,有则加用吸入支气管扩张剂。
3. 对健康成人和儿童以对症治疗为主,常规不使用抗生素。
4. 仅当出现发热、痰量增加和脓痰等急性细菌感染证据时才开抗生素。
5. 疑似支原体感染时改用多西环素等针对性方案,并安排复评。

**注意事项 / Precautions**
- 大多数急性支气管炎是病毒性,不要因为咳嗽时间长就自动给抗生素。
- 咯血和明显高热不是典型表现,出现时要警惕肺炎等其他病因。
- 老年体弱病人病情可更重,需更密切随访。

**量化指标 / Metrics**
- 急性支气管炎抗生素处方率
- 符合细菌证据后抗生素使用准确率
- 7 日内症状自限改善率
