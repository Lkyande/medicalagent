# Skill: 咳嗽病史结构化采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第32章 咳嗽
- 页码: 第32章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第32章.md`

**目标 / Objective**
通过结构化病史明确咳嗽病因线索并初步分层为感染性、气道性、肿瘤性或暴露相关疾病。

**适用范围 / Scope**
- 所有主诉咳嗽的病人

**操作步骤 / Procedure**
1. 记录咳嗽持续时间、是否咳痰及痰液颜色和量。
2. 追问胸痛、发热、寒战、喘息、体重减轻、咯血和其他全身症状。
3. 详细询问吸烟史、职业暴露史、石棉接触、养鸟和宠物情况。
4. 询问童年反复肺部感染、哮喘/花粉热、家族史和异物吸入可能。
5. 对近期手术、卧床和下肢肿胀病人,同步评估肺栓塞风险。

**注意事项 / Precautions**
- 伴随症状往往比咳嗽本身性质更有诊断价值。
- 养鸟、农作和采矿等暴露史容易漏问,但提示性很强。
- 家庭中有人持续咳嗽或结核病史时需主动追问接触情况。

**量化指标 / Metrics**
- 咳嗽病史要素完整率
- 职业和环境暴露记录率
- 首诊病因分层准确率
