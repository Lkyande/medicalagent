# Skill: 痰液特征判读

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第32章 咳嗽
- 页码: 第32章“痰液特点”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第32章.md`

**目标 / Objective**
根据痰液颜色、气味和黏稠度缩小咳嗽病因范围。

**适用范围 / Scope**
- 咳痰性咳嗽病人

**操作步骤 / Procedure**
1. 观察痰液是透明白色、黄色绿色、铁锈色、粉红泡沫样还是大量恶臭脓痰。
2. 记录痰液黏稠度和 24 小时痰量,区分少量黏液与大量脓性分泌物。
3. 将透明白痰倾向于非感染性支气管炎或吸烟相关,黄绿痰提示炎症细胞增多。
4. 将铁锈色痰联想到大叶性肺炎,粉红色泡沫痰联想到肺水肿,恶臭大量痰联想到支扩或肺脓肿。
5. 如痰量多或特征异常,安排痰培养、胸片或进一步影像检查。

**注意事项 / Precautions**
- 黄绿痰不一定等于细菌感染,哮喘也可因嗜酸性粒细胞增多而呈脓色。
- 大量水样痰需警惕肺泡细胞癌等少见病因。
- 痰液观察是辅助判断,不能替代影像和体征。

**量化指标 / Metrics**
- 痰液特征记录率
- 痰检送检率
- 痰液特征与最终病因一致率
