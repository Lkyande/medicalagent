# Skill: 细针穿刺与活检分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第50章 颈部肿块
- 页码: 第50章“关键事实和要点”“辅助检查”“转诊时机”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第50章.md`

**目标 / Objective**
合理选择 FNAB 与整块淋巴结活检,提高颈部肿块病因诊断效率。

**适用范围 / Scope**
- 原因未明、可疑恶性或对抗生素不敏感的颈部肿块病人

**操作步骤 / Procedure**
1. 先完成病史、查体、全血细胞计数和胸片等基础评估。
2. 对甲状腺结节或其他可疑肿块优先考虑细针穿刺细胞学检查。
3. 当肿块持续存在、逐渐增大或对抗生素不敏感时提高活检优先级。
4. 对未知或高度可疑原因的淋巴结病,在合适时机安排完整淋巴结活检。
5. 结合影像结果和穿刺细胞学发现决定进一步专科转诊与原发灶搜索。

**注意事项 / Precautions**
- 活检重要,但不应在基础评估前就盲目作为第一步。
- FNAB 是诊断效率很高的单项辅助检查,尤其适合甲状腺和实体肿块。
- 抗生素无反应的异常增大淋巴结不能长期反复经验治疗。

**量化指标 / Metrics**
- 可疑肿块 FNAB 完成率
- 持续肿块活检率
- 从首诊到病理诊断时间
