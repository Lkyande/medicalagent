# Skill: 颈部肿块红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第50章 颈部肿块
- 页码: 第50章“颈部肿块的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第50章.md`

**目标 / Objective**
及时识别提示恶性、结核或复杂感染的高危颈部肿块表现。

**适用范围 / Scope**
- 所有新发、持续或逐渐增大的颈部肿块病人

**操作步骤 / Procedure**
1. 记录年龄,对大于 40 岁尤其大于 70 岁病人提高恶性警惕。
2. 测量淋巴结直径,重点标记大于 2.5 厘米或 3 至 4 厘米的病变。
3. 评估肿块是否孤立、逐渐增大、固定于皮肤、质硬或伴吞咽困难。
4. 注意紫色病变提示领扣状脓肿,并追问 HIV 和结核暴露风险。
5. 红旗征阳性时尽快安排影像、细针穿刺或专科评估。

**注意事项 / Precautions**
- 成人持续颈部肿块在排除前应先按恶性病变看待。
- 中央质硬的甲状腺肿块尤其需要警惕癌变。
- 单纯触痛不能排除严重病因。

**量化指标 / Metrics**
- 颈部肿块红旗征记录率
- 红旗征阳性病人专科转诊率
- 恶性病变漏诊率
