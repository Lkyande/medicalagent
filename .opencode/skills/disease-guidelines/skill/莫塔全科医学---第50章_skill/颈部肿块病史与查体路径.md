# Skill: 颈部肿块病史与查体路径

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第50章 颈部肿块
- 页码: 第50章“病史”“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第50章.md`

**目标 / Objective**
通过标准化病史和区域性查体缩小颈部肿块的来源范围。

**适用范围 / Scope**
- 门急诊所有颈部肿块病人

**操作步骤 / Procedure**
1. 询问上呼吸道、下呼吸道、EB 病毒、HIV、巨细胞病毒和结核感染史。
2. 追问体重减轻、吞咽困难、肿块增大、癌症史及抗生素治疗反应。
3. 触诊时轻转头部,用指腹系统检查颈前三角、颈后三角、颏下和颌下区。
4. 记录肿块位置、大小、活动度、质地、压痛及是否随吞咽移动。
5. 将淋巴结部位与相应引流区域匹配,并检查远处淋巴结和肝脾大。

**注意事项 / Precautions**
- 颈部淋巴结查体必须超出颈部本身,否则容易漏掉系统病。
- 位置判断对原发灶搜索很关键,不能只写“颈部包块”。
- 吞咽时移动的中线肿块提示甲状腺来源可能较高。

**量化指标 / Metrics**
- 标准化病史完成率
- 肿块位置和质地记录率
- 首诊定位判断准确率
