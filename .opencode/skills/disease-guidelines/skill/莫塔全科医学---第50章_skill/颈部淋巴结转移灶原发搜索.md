# Skill: 颈部淋巴结转移灶原发搜索

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第50章 颈部肿块
- 页码: 第50章“转移癌”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第50章.md`

**目标 / Objective**
依据淋巴结部位系统搜索颈部转移灶的潜在原发肿瘤来源。

**适用范围 / Scope**
- 怀疑转移性颈部淋巴结病的成人病人

**操作步骤 / Procedure**
1. 先判断病变位于上颈部还是下颈部,以决定原发灶搜索方向。
2. 上颈部肿大时重点检查头皮、口腔、鼻窦、咽喉和上呼吸道。
3. 下颈部或锁骨上淋巴结肿大时从肺、胃、乳房、结肠等锁骨下器官开始搜索。
4. 根据具体站位细化检查,如颏下查口腔舌牙,左锁骨上考虑胃部病变。
5. 结合 FNAB、胸片及进一步影像或内镜结果尽快完成原发灶定位。

**注意事项 / Precautions**
- 锁骨上恶性淋巴结的原发灶多数位于锁骨下方。
- 上下颈部分区有助于减少无序检查和延误。
- 发现恶性鳞状细胞后更要优先搜索皮肤、肺、喉、咽、耳和食管。

**量化指标 / Metrics**
- 原发灶搜索完整率
- 锁骨上淋巴结快速分流率
- 原发灶定位成功率
