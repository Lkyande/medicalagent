# Skill: 颈部肿块年龄分层判断

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第50章 颈部肿块
- 页码: 第50章“20∶40 和 80∶20 法则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第50章.md`

**目标 / Objective**
利用年龄法则快速提高颈部肿块病因判断和恶性警觉度。

**适用范围 / Scope**
- 初诊尚未明确病因的颈部肿块病人

**操作步骤 / Procedure**
1. 先按年龄分为 0 至 20 岁、20 至 40 岁和大于 40 岁三组。
2. 0 至 20 岁时优先考虑先天性、炎性、淋巴瘤和结核病。
3. 20 至 40 岁时重点考虑炎性、唾液腺、甲状腺、乳头状甲状腺癌和淋巴瘤。
4. 大于 40 岁时默认先排除淋巴瘤和转移癌,而非先按良性处理。
5. 同时结合儿童多良性、成人持续肿块恶性概率更高的 80∶20 原则决定检查紧迫度。

**注意事项 / Precautions**
- 年龄法则用于提高先验概率,不能替代实际查体和影像。
- 成人尤其颈后三角持续肿块不能长期经验性抗感染观察。
- 儿童良性比例高,但仍要警惕冷脓肿和淋巴瘤。

**量化指标 / Metrics**
- 年龄分层记录率
- 高危年龄组及时转诊率
- 恶性病因识别时效
