# Skill: 药物性食管损伤预防与处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第37章 吞咽困难
- 页码: 第37章“药物性食管损伤”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第37章.md`

**目标 / Objective**
识别药片相关食管损伤并通过用药方式调整减少再发。

**适用范围 / Scope**
- 吞咽痛、吞咽困难或胸骨后疼痛且近期口服刺激性药物的病人

**操作步骤 / Procedure**
1. 核对是否服用多西环素、铁剂、缓释钾、NSAIDs、双膦酸盐等高风险药物。
2. 询问是否在睡前服药、是否饮水不足或存在食管基础疾病导致药片滞留。
3. 对可疑病例立即停用或替换可疑药物。
4. 指导病人服药时保持直立并用一整杯水送服。
5. 必要时加用抗酸药并观察疼痛和吞咽改善情况。

**注意事项 / Precautions**
- 老年人和已有食管通过延迟者更易出现穿孔等严重并发症。
- 症状持续或加重需进一步做内镜排除深溃疡或其他结构病变。
- 预防比治疗更关键,应把正确服药方式讲清楚。

**量化指标 / Metrics**
- 高风险药物服药宣教率
- 停药后症状改善率
- 复发性药片食管炎发生率
