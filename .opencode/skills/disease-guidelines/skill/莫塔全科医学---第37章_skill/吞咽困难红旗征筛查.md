# Skill: 吞咽困难红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第37章 吞咽困难
- 页码: 第37章“吞咽困难的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第37章.md`

**目标 / Objective**
在吞咽困难病人中及时识别恶性梗阻和神经系统高危病因。

**适用范围 / Scope**
- 新发或进行性吞咽困难病人

**操作步骤 / Procedure**
1. 主动筛查年龄 >50 岁、近期或突然起病、体重下降和进行性加重。
2. 询问是否有吞咽痛、呃逆、声嘶和神经系统症状。
3. 对仅固体吞咽困难者优先警惕结构性狭窄或癌症。
4. 对伴脑神经异常、误吸或肌无力者同步进行神经系统分流评估。
5. 红旗征阳性时加快内镜、影像和专科转诊,避免经验性长期用药拖延。

**注意事项 / Precautions**
- 老年人进行性吞咽困难加消瘦是食管癌直到证明不是为止。
- 声嘶和肩胛区不适可提示更高位肿瘤侵犯。
- 吞咽困难是常见心因症状,但必须先完成必要器质性排查。

**量化指标 / Metrics**
- 红旗征记录率
- 高危病人内镜完成率
- 恶性病变早期识别率
