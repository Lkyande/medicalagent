# Skill: 嗜酸性食管炎识别与饮食排除

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第37章 吞咽困难
- 页码: 第37章“嗜酸性食管炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第37章.md`

**目标 / Objective**
识别与过敏相关的嗜酸性食管炎并启动内镜活检和六食物排除饮食路径。

**适用范围 / Scope**
- 反复食物卡喉、吞咽困难、反流或急性食物梗阻的儿童和成人

**操作步骤 / Procedure**
1. 对规律性感到食物卡喉且伴花粉热、哮喘或食物过敏者考虑嗜酸性食管炎。
2. 安排胃镜并做食管黏膜活检确认嗜酸性粒细胞浸润。
3. 解释本病与过敏相关,不是单纯“反流严重”。
4. 启动六食物排除饮食,去除牛奶蛋白、小麦、大豆、鸡蛋、海鲜和花生。
5. 急性发作时在专科指导下使用丁溴东莨菪碱或吞服局部类固醇气雾剂如氟替卡松 8 周。

**注意事项 / Precautions**
- 72 小时内去除致敏食物后症状可明显改善,病史追问很重要。
- 急性食物团梗阻可能需要急诊内镜处理。
- 需与 GERD 和功能性喉球感区分,不能只按反流长期加药。

**量化指标 / Metrics**
- 可疑病例胃镜活检完成率
- 六食物排除执行率
- 食物梗阻复发率
