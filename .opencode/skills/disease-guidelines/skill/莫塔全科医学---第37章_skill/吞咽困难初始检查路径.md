# Skill: 吞咽困难初始检查路径

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第37章 吞咽困难
- 页码: 第37章“身体检查”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第37章.md`

**目标 / Objective**
根据病变部位和机制选择吞咽困难的首选检查,提高诊断效率。

**适用范围 / Scope**
- 需要进一步评估病因的吞咽困难病人

**操作步骤 / Procedure**
1. 身体检查时评估营养状态、口咽喉、颈部淋巴结、甲状腺和脑神经功能。
2. 对疑似口咽性吞咽困难者首选钡剂造影。
3. 对疑似食管性吞咽困难者通常首选上消化道内镜。
4. 对疑似食管环、结构性狭窄或动力障碍者考虑钡剂造影先于内镜。
5. 若内镜和放射学阴性,进一步做食管测压寻找贲门失弛症或其他动力障碍。

**注意事项 / Precautions**
- 检查选择必须围绕口咽性还是食管性分型展开。
- 误吸风险高者做水吞试验时要特别谨慎。
- 机械性外压病变可能需要 CT、胸片或 PET 补充定位。

**量化指标 / Metrics**
- 首选检查路径正确率
- 钡造影/内镜完成率
- 阴性后测压追加率
