# Skill: 吞咽困难部位分型

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第37章 吞咽困难
- 页码: 第37章“诊断指南”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第37章.md`

**目标 / Objective**
根据症状位置和食物类型区分口咽性与食管性吞咽困难。

**适用范围 / Scope**
- 主诉吞咽时阻塞感、食物卡住或吞咽疼痛的病人

**操作步骤 / Procedure**
1. 询问困难发生在开始吞咽时还是食物下行过程中。
2. 判断阻塞感位于颈部/胸骨上切迹还是胸骨中下段。
3. 追问固体食物、液体或两者是否都困难,以及是否有反流、误吸或未消化食物返流。
4. 将仅固体困难更偏向结构性病变,液体和固体都困难更偏向运动障碍。
5. 依据分型决定首选钡剂造影、内镜还是测压路径。

**注意事项 / Precautions**
- 进行性固体吞咽困难直到证实前应优先考虑癌症或狭窄。
- 喉球感不是真正吞咽困难,需与器质性梗阻区别。
- 神经系统疾病常以液体误吸和咳嗽表现,不应只盯住食管病因。

**量化指标 / Metrics**
- 口咽/食管分型记录率
- 初始检查路径选择准确率
- 结构性病变早期识别率
