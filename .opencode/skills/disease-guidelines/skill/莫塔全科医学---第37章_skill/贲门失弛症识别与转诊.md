# Skill: 贲门失弛症识别与转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第37章 吞咽困难
- 页码: 第37章“贲门失弛症”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第37章.md`

**目标 / Objective**
识别贲门失弛症的动力障碍模式并及时进入测压和扩张/肌切开路径。

**适用范围 / Scope**
- 进行性固体和液体吞咽困难、波动性反流或胸部不适病人

**操作步骤 / Procedure**
1. 识别固体和液体均受影响且症状波动的吞咽困难模式。
2. 结合反流和胸部不适等线索怀疑食管动力障碍而非单纯狭窄。
3. 安排钡剂造影观察食管扩张及光滑锥形下端表现。
4. 用食管测压作为确诊检查。
5. 对确诊者转专科选择保守治疗、球囊扩张或外科肌切开术。

**注意事项 / Precautions**
- 促动力药对贲门失弛症通常无效。
- 胃食管交界部肿瘤可造成“假性贲门失弛症”,老年病人尤需警惕。
- 液体和固体都困难是与单纯结构性狭窄鉴别的重要线索。

**量化指标 / Metrics**
- 可疑病例测压完成率
- 钡造影提示与测压一致率
- 专科介入转诊率
