# Skill: 皮赘简易去除

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第116章 常见肿块
- 页码: 第116章“纤维上皮息肉”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第116章.md`

**目标 / Objective**
对有症状或影响美观的皮赘实施安全的门诊简易去除。

**适用范围 / Scope**
- 颈部、腋下、躯干或腹股沟良性皮赘病人

**操作步骤 / Procedure**
1. 确认病变为有蒂、柔软、良性的纤维上皮息肉。
2. 与病人讨论可观察或去除的选择。
3. 选择剪除、结扎、电灼或液氮冷冻等适当方法。
4. 处理后给予局部护理建议。
5. 对不典型病变改行更正式切除或病理送检。

**注意事项 / Precautions**
- 典型皮赘通常不需局麻。
- 糖尿病和肥胖病人更常见。
- 不典型、有色素或快速变化病变不应按普通皮赘处理。

**量化指标 / Metrics**
- 典型皮赘门诊处理率
- 不典型病变病理送检率
- 复发或并发症发生率
