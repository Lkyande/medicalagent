# Skill: 表皮样囊肿切除路径

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第116章 常见肿块
- 页码: 第116章“表皮样(皮脂腺)囊肿和毛发囊肿”“手术切除方法”“感染性囊肿的治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第116章.md`

**目标 / Objective**
根据囊肿状态选择合适的表皮样囊肿门诊切除策略,减少复发。

**适用范围 / Scope**
- 头皮、面颈、躯干或阴囊部位典型表皮样或毛发囊肿病人

**操作步骤 / Procedure**
1. 识别与皮肤粘连、可波动、有中央点或含角蛋白的典型囊肿。
2. 对未感染囊肿选择切开排内容物、钝性剥离或标准剥离术。
3. 确保完整去除囊壁,降低复发风险。
4. 对感染性囊肿先切开引流,待炎症消退后再行正式切除。
5. 对切除的囊肿送病理检查。

**注意事项 / Precautions**
- 囊壁残留是复发主要原因。
- 炎性期强行完整切除常增加困难和并发症。
- 青春期前多发囊肿需考虑相关综合征线索。

**量化指标 / Metrics**
- 囊肿完整切除率
- 送病理比例
- 术后复发率
