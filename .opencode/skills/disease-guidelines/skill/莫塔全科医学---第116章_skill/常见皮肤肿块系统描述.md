# Skill: 常见皮肤肿块系统描述

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第116章 常见肿块
- 页码: 第116章“肿块的诊断方法”“肿块与解剖结构的关系”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第116章.md`

**目标 / Objective**
用标准化术语描述皮肤和皮下肿块,提高诊断和转诊质量。

**适用范围 / Scope**
- 门诊发现的皮肤、皮下、肌肉或与腱关节相关肿块

**操作步骤 / Procedure**
1. 记录肿块数量、部位、大小、形状、颜色和表面特征。
2. 评估质地、囊实性、压痛、温度和移动度。
3. 判断肿块与皮肤、皮下、肌肉、腱、骨或关节的关系。
4. 检查是否搏动、透光、波动、可复性或有区域淋巴结肿大。
5. 根据结果决定观察、门诊处理、活检还是转诊。

**注意事项 / Precautions**
- 准确描述是决定治疗或转诊的基础。
- 无痛并不等于良性。
- 需要同时思考原发与继发恶性可能。

**量化指标 / Metrics**
- 肿块标准化描述率
- 解剖层次判断记录率
- 可疑恶性转诊率
