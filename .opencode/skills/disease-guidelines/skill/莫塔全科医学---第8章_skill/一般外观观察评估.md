# Skill: 一般外观观察评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第8章 临床的察看技能
- 页码: 第8章“第一印象”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第8章.md`

**目标 / Objective**
在接触病人早期通过一般外观和行为观察快速建立初步临床判断框架。

**适用范围 / Scope**
- 所有面对面全科咨询和体格检查前的临床评估

**操作步骤 / Procedure**
1. 先回答“这位病人看上去是生病了吗?”。
2. 观察一般外表、举止、心境和情绪状态。
3. 按面部、头颈、口腔、毛发、皮肤、体型、姿势步态和肢端逐项扫描。
4. 记录引人注意的异常征象,形成初步假设。
5. 用全面体检和病史进一步验证,避免仅凭点状诊断下结论。

**注意事项 / Precautions**
- 第一印象有价值,但不能替代系统检查。
- 观察应服务于诊断,不是外貌评价或刻板印象判断。
- 对情绪、文化和残障表现需保持敏感,避免误读。

**量化指标 / Metrics**
- 一般外观关键项目记录率
- 初步观察与后续诊断一致率
- 观察触发进一步检查的比例
