# Skill: 面容特征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第8章 临床的察看技能
- 页码: 第8章“脸是疾病的镜子”“具有诊断意义的面容”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第8章.md`

**目标 / Objective**
通过识别具有诊断价值的面容特征,为内分泌、神经、遗传和系统性疾病提供早期线索。

**适用范围 / Scope**
- 门诊首诊、慢病复诊和疑难病初步评估

**操作步骤 / Procedure**
1. 观察面部轮廓、皮下组织、表情、眼睑和口唇特征。
2. 留意典型面容,如满月脸、面具脸、黏液性水肿面容或甲亢凝视。
3. 结合伴随体征,如舌体肥大、毛发稀疏、声音改变或手足异常。
4. 将异常面容作为诊断线索,触发针对性问诊和查体。
5. 通过进一步检查确认,避免仅凭面容直接诊断。

**注意事项 / Precautions**
- 面容观察属于提示性信息,不能脱离全身情况独立解释。
- 年龄、遗传和体型差异可影响外观,需谨慎区分正常变异。
- 对罕见综合征表现应在必要时及时转专科评估。

**量化指标 / Metrics**
- 典型面容识别率
- 面容线索触发针对性检查率
- 面容提示与最终诊断一致率
