# Skill: 杵状指识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第8章 临床的察看技能
- 页码: 第8章“杵状指”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第8章.md`

**目标 / Objective**
识别杵状指并据此启动对肺部、心脏、肝脏和胃肠疾病的针对性评估。

**适用范围 / Scope**
- 慢性咳嗽、呼吸困难、发绀、消瘦或系统性慢病病人

**操作步骤 / Procedure**
1. 观察甲根与甲皱角度是否消失。
2. 观察甲板是否凸起、指端软组织是否海绵样增厚。
3. 一旦确认杵状指,优先考虑肺部疾病如肺癌、支扩、肺脓肿和肺纤维化。
4. 同时考虑发绀型先天性心脏病、感染性心内膜炎、肝硬化和炎症性肠病。
5. 根据伴随症状安排胸部、心脏或消化系统进一步检查。

**注意事项 / Precautions**
- 杵状指是提示性体征,需与长期手部外观差异和职业因素区分。
- 一旦伴消瘦、咯血或发绀,应优先排查严重胸肺疾病。
- 不能因为发现杵状指就忽略原发病的系统评估。

**量化指标 / Metrics**
- 杵状指识别率
- 杵状指后胸部/心脏进一步评估启动率
- 严重基础病早期发现率
