# Skill: 发绀分型观察

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第8章 临床的察看技能
- 页码: 第8章“发绀”“中心性发绀”“周围性发绀”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第8章.md`

**目标 / Objective**
根据分布和皮肤温度区分中心性与周围性发绀,缩小严重病因范围。

**适用范围 / Scope**
- 呼吸困难、循环异常、紫绀或低氧相关病人评估

**操作步骤 / Procedure**
1. 观察口唇、舌、指尖、鼻尖和耳廓是否发绀。
2. 判断发绀主要位于血供良好部位还是肢端末梢。
3. 触摸相关部位皮肤温度,区分温暖还是冰凉。
4. 若为中心性发绀,优先考虑肺病、肺水肿、右向左分流和呼吸抑制。
5. 若为周围性发绀,优先考虑休克、周围血管病、心衰和寒冷暴露。
6. 结合血氧饱和度和急危重评估尽快处置。

**注意事项 / Precautions**
- 发绀通常提示显著低氧或循环障碍,不能仅停留在观察层面。
- 贫血可能掩盖发绀表现,红细胞增多可使其更明显。
- 对急性中心性发绀应优先处理气道、呼吸和循环。

**量化指标 / Metrics**
- 发绀分型记录率
- 紧急病因识别时效
- 发绀病人血氧评估完成率
