# Skill: 面部皮肤异常鉴别观察

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第8章 临床的察看技能
- 页码: 第8章“特殊的面部特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第8章.md`

**目标 / Objective**
通过面部皮肤分布和形态观察区分常见系统性或局部性皮肤异常线索。

**适用范围 / Scope**
- 面部红斑、色素沉着、毛细血管扩张和黄褐斑相关就诊场景

**操作步骤 / Procedure**
1. 观察皮疹或色素改变的分布、边界、是否对称和是否伴鳞屑或脓疱。
2. 对蝶形红斑,区分 SLE、玫瑰痤疮、丹毒、脂溢性皮炎和光敏性皮疹的特征。
3. 对黄褐斑或黑斑病,评估妊娠史和药物使用史。
4. 对毛细血管扩张、蜘蛛痣和广泛色素沉着,联想到肝病、结缔组织病或内分泌问题。
5. 结合病史和其他系统表现决定是否进一步检查。

**注意事项 / Precautions**
- 面部皮肤改变既可能是局部病变,也可能提示系统性疾病。
- 药物、日晒和妊娠是常见混杂因素,应主动询问。
- 明显全身征象或快速进展者需尽快完善系统评估。

**量化指标 / Metrics**
- 面部皮肤分布描述完整率
- 系统性疾病线索识别率
- 异常皮肤征象后续检查启动率
