# Skill: 儿童纪律行为结果指导

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第87章 儿童行为发育问题和障碍
- 页码: 第87章“儿童的行为和纪律”“行为结果”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第87章.md`

**目标 / Objective**
指导家长用建设性纪律策略减少不想要行为并强化期望行为。

**适用范围 / Scope**
- 幼儿和学龄儿童常见行为问题的家庭咨询场景

**操作步骤 / Procedure**
1. 向家长解释纪律的目标是指导和教导,而不是惩罚发泄。
2. 优先强化和表扬孩子想要的行为。
3. 对 3 岁以上儿童,优先使用自然结果和相关结果策略。
4. 仅谨慎使用撤回特权,避免过度惩罚性做法。
5. 帮助家长减少尖叫、威胁、反复争论和贿赂等无效方式。

**注意事项 / Precautions**
- 过度使用结果策略可能损害家庭关系。
- 纪律方法要与儿童发育年龄相匹配。
- 对情绪化家长讨论纪律问题时需保持敏感和非评判。

**量化指标 / Metrics**
- 家长纪律策略教育率
- 非体罚替代方法使用率
- 行为问题随访改善率
