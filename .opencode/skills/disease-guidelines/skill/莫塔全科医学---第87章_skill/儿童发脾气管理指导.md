# Skill: 儿童发脾气管理指导

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第87章 儿童行为发育问题和障碍
- 页码: 第87章“发脾气”“给父母的适当建议”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第87章.md`

**目标 / Objective**
帮助家长理解幼儿发脾气的发育意义并采用有效的应对策略。

**适用范围 / Scope**
- 18 个月至 3 岁左右反复发脾气的幼儿及其照顾者

**操作步骤 / Procedure**
1. 先确认发脾气是否符合年龄发育规律并排除明显异常背景。
2. 提前识别可预测触发因素,应用 5 分钟警示和分散注意策略。
3. 在孩子发作时保持平静和非情绪化反应,避免谈判或争吵。
4. 在发作前后而不是发作当下,教孩子用其他方式表达情绪。
5. 向家长强调忽略可忽略的行为、适度表扬和不使用药物。

**注意事项 / Precautions**
- 发脾气期间说教通常无效且会加重冲突。
- 孤独症也可能表现为异常发脾气模式。
- 父母平静反应本身是重要示范。

**量化指标 / Metrics**
- 发脾气触发因素识别率
- 家长行为管理建议落实率
- 发作频率或强度改善率
