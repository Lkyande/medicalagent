# Skill: 口吃早期转介

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第87章 儿童行为发育问题和障碍
- 页码: 第87章“口吃”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第87章.md`

**目标 / Objective**
尽早识别儿童口吃并转介语言治疗,提高干预成功率。

**适用范围 / Scope**
- 2 至 5 岁出现重复、延长音或发音阻滞的儿童

**操作步骤 / Procedure**
1. 明确口吃起病时间、表现形式和家庭史。
2. 向家长解释口吃不是由焦虑或压力直接引起,但兴奋时可加重。
3. 评估其对儿童情绪和社交的影响。
4. 尽早转介语言治疗师,优先在问题早期干预。
5. 随访语言治疗进展和家庭支持情况。

**注意事项 / Precautions**
- 早期转介成功率更高。
- 不应责备孩子“说慢点”或施压纠正。
- 口吃可有家族聚集性。

**量化指标 / Metrics**
- 口吃儿童语言治疗转介率
- 起病至转介时间
- 家庭教育完成率
