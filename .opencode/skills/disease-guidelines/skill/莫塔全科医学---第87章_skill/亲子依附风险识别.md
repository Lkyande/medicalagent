# Skill: 亲子依附风险识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第87章 儿童行为发育问题和障碍
- 页码: 第87章“亲子依附关系”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第87章.md`

**目标 / Objective**
识别亲子依附关系问题及其对儿童行为和心理发展的潜在影响。

**适用范围 / Scope**
- 婴幼儿和儿童门诊,尤其高压力家庭、年轻父母或产后期家庭

**操作步骤 / Procedure**
1. 观察照顾者是否能迅速、一致且恰当地回应孩子需求。
2. 关注不回应、反应不一致或带攻击性的反应模式。
3. 结合产后抑郁、社交孤立、吸毒酗酒和家庭暴力等背景因素评估风险。
4. 向家长解释稳定回应和依附关系对儿童发展的重要性。
5. 对高风险家庭安排支持服务、心理或保护机构协助。

**注意事项 / Precautions**
- 依附问题常持续影响后续发展,不只是婴儿期现象。
- 家长需要支持而非指责。
- 情绪虐待和威胁性照料方式对儿童极具伤害性。

**量化指标 / Metrics**
- 亲子互动观察记录率
- 高风险家庭支持转介率
- 随访中依附问题改善记录率
