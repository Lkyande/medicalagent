# Skill: 儿童屏气发作识别与释疑

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第87章 儿童行为发育问题和障碍
- 页码: 第87章“屏气发作”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第87章.md`

**目标 / Objective**
识别儿童良性屏气发作并向父母提供安全的释疑与行为指导。

**适用范围 / Scope**
- 6 个月至 6 岁儿童出现情绪或疼痛诱发的短暂屏气、发绀或苍白发作时

**操作步骤 / Procedure**
1. 确认发作多发生在失望、生气、疼痛或恐惧之后。
2. 区分青紫型和苍白型屏气发作。
3. 说明发作通常持续 10 至 60 秒且一般无害。
4. 释除家长担忧,强调不需吹气、泼水或因发作改变纪律规则。
5. 指导家长平静对待发作并关注整体行为管理。

**注意事项 / Precautions**
- 屏气发作看起来可怕,但多数不造成伤害。
- 仍需在不典型、持续过长或伴其他神经症状时排除其他病因。
- 不要因屏气发作给予孩子特殊纵容。

**量化指标 / Metrics**
- 屏气发作正确识别率
- 家长释疑完成率
- 不必要急诊就诊减少率
