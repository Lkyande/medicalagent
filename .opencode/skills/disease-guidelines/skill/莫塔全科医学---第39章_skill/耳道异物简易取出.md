# Skill: 耳道异物简易取出

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第39章 耳痛
- 页码: 第39章“异物”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第39章.md`

**目标 / Objective**
在可视条件下安全采取简单方法移除耳道异物,减少进一步损伤。

**适用范围 / Scope**
- 可配合且无鼓膜穿孔高风险征象的耳道异物病人

**操作步骤 / Procedure**
1. 先确认异物种类、位置和鼓膜受累风险,建立良好照明和视野。
2. 对规则异物可尝试探针法,将探针越过异物后轻柔滚出。
3. 对表面光滑异物可用涂凡士林的橡胶导管轻柔抽吸取出。
4. 对活昆虫先滴耳液或橄榄油使其固定,再考虑温水灌洗。
5. 简单方法失败或怀疑鼓膜损伤时停止操作,转显微镜下取出。

**注意事项 / Precautions**
- 若异物可能造成鼓膜穿孔,严禁灌洗。
- 儿童不配合、异物深嵌或多次失败时不要反复尝试。
- 死亡昆虫易引起化脓,通常更适合抽吸移除。

**量化指标 / Metrics**
- 耳道异物一次取出成功率
- 异物移除并发鼓膜损伤率
- 失败后及时转诊率
