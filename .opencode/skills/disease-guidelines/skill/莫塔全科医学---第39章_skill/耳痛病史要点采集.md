# Skill: 耳痛病史要点采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第39章 耳痛
- 页码: 第39章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第39章.md`

**目标 / Objective**
通过结构化病史快速区分中耳炎、外耳炎、气压伤及牵涉性耳痛。

**适用范围 / Scope**
- 急性或反复发作耳痛的成人与儿童

**操作步骤 / Procedure**
1. 明确疼痛部位、单侧或双侧、是否放射至耳前或耳下。
2. 询问疼痛起病方式、性质及加重缓解因素,尤其是游泳和下颌活动。
3. 主动询问耳聋、耳分泌物、眩晕、耳鸣、咽喉痛、发热和呕吐。
4. 询问近期游泳、乘飞机、潜水、外伤或被打耳部等暴露史。
5. 询问药物过敏史,并在儿童中记录哭闹、揪耳等非典型表现。

**注意事项 / Precautions**
- 游泳后加重更支持外耳炎,飞行或潜水后疼痛要考虑气压伤。
- 儿童常无法准确定位疼痛,要依赖照护者对伴随症状的观察。
- 单靠耳痛不能定位病灶,必须同时评估口咽、牙齿和颈部来源。

**量化指标 / Metrics**
- 耳痛结构化病史完成率
- 外耳炎与中耳炎初步分型准确率
- 暴露史记录完整率
