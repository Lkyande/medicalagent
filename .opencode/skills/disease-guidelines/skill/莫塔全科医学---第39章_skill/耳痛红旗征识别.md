# Skill: 耳痛红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第39章 耳痛
- 页码: 第39章“耳痛的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第39章.md`

**目标 / Objective**
快速识别需要紧急处理或转诊的耳痛病人,避免遗漏严重感染和破坏性疾病。

**适用范围 / Scope**
- 所有以耳痛、耳后痛或耳周放射痛就诊的病人

**操作步骤 / Procedure**
1. 询问是否存在刺激性耳分泌物持续超过 9 日。
2. 检查耳廓是否下移,并观察耳后是否有肿胀或压痛。
3. 评估是否合并头痛、嗜睡等神经系统症状。
4. 对老年人重点识别不明原因、顽固性耳痛和持续发热。
5. 任何红旗征阳性时立即升级评估并考虑耳鼻喉专科转诊。

**注意事项 / Precautions**
- 耳后肿胀和耳廓下移提示乳突炎等严重并发症,不可延误。
- 老年人顽固性单侧耳痛要警惕带状疱疹或恶性肿瘤牵涉痛。
- 红旗征阴性也不能排除中耳炎、外耳炎或牵涉痛,仍需完整检查。

**量化指标 / Metrics**
- 耳痛病人红旗征记录率
- 高危耳痛当日转诊率
- 乳突炎或严重并发症漏诊率
