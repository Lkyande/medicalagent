# Skill: 儿童急性中耳炎抗生素分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第39章 耳痛
- 页码: 第39章“儿童中耳炎”“疼痛性中耳炎患儿使用抗生素的可能临床指征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第39章.md`

**目标 / Objective**
根据年龄、病情和并发症风险决定儿童急性中耳炎是否立即使用抗生素。

**适用范围 / Scope**
- 诊断或高度怀疑急性中耳炎的儿童

**操作步骤 / Procedure**
1. 先给予充分镇痛,并确认鼓膜表现与全身症状是否支持急性中耳炎。
2. 对 6 个月以下婴儿、2 岁以下双侧中耳炎或唯一听力耳受累者考虑立即抗生素。
3. 对人工耳蜗植入者、原住民儿童等高并发症风险人群倾向立即治疗。
4. 若存在面瘫、眩晕、持续发热或 48~72 小时观察后仍疼痛发热,启动抗生素。
5. 其余轻症病例与家长共同决策,以镇痛和严密观察为主并安排复评。

**注意事项 / Precautions**
- 轻度鼓膜发红且无全身症状的病毒性上呼吸道感染不应常规用抗生素。
- 抗生素获益有限,决策重点在并发症风险和病情持续性。
- 对青霉素过敏儿童应预先规划替代方案。

**量化指标 / Metrics**
- 急性中耳炎分层决策记录率
- 不必要抗生素处方率
- 48~72 小时复评完成率
