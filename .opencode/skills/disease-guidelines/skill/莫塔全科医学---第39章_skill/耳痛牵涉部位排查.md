# Skill: 耳痛牵涉部位排查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第39章 耳痛
- 页码: 第39章“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第39章.md`

**目标 / Objective**
在耳部原发病因不明确时系统排查口咽、牙齿、颈椎和颞下颌关节来源。

**适用范围 / Scope**
- 耳镜检查不能完全解释疼痛的耳痛病人

**操作步骤 / Procedure**
1. 先检查外耳、耳道和鼓膜,判断局部发现是否足以解释症状。
2. 触诊颞下颌关节,在张口和下颌运动时评估是否诱发疼痛。
3. 检查口腔、牙齿、咽喉和鼻后间隙,寻找牙源性或咽源性病变。
4. 触诊颈部、腮腺、淋巴结和乳突,并评估上颈段压痛。
5. 对持续不明原因耳痛者进一步考虑舌癌、扁桃体癌或鼻咽肿瘤可能。

**注意事项 / Precautions**
- 牵涉痛在老年人中要优先排除恶性肿瘤,尤其是单侧慢性耳痛。
- 颞下颌关节痛和上颈椎功能障碍是常见漏诊原因。
- 不应因发现耳垢或轻度外耳炎就停止寻找真正病因。

**量化指标 / Metrics**
- 不明耳痛牵涉部位检查率
- 牵涉痛病因识别率
- 慢性单侧耳痛恶性病变转诊率
