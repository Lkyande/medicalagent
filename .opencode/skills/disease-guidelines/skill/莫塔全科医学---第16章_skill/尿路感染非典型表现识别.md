# Skill: 尿路感染非典型表现识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第16章 尿路感染
- 页码: 第16章“尿路感染是戴面具的问题”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第16章.md`

**目标 / Objective**
在婴幼儿、老年人和妊娠女性中识别非典型尿路感染表现,减少漏诊。

**适用范围 / Scope**
- 发热、意识错乱、喂养困难、腹痛或全身状态改变而原因未明者

**操作步骤 / Procedure**
1. 对婴幼儿出现发热、嗜睡、易怒、喂养困难、呕吐、腹泻或生长停滞时考虑 UTI。
2. 对老年人出现意识错乱、行为混乱或不明原因发热时纳入 UTI 鉴别。
3. 对妊娠女性或成年女性的急性腹痛,在无明确其他病因时补问尿路症状。
4. 结合风险因素如女性、性交、糖尿病、妊娠、尿路梗阻和器械使用进行分层。
5. 一旦怀疑,尽快进入规范尿液采集和实验室诊断流程。

**注意事项 / Precautions**
- 非典型 UTI 在婴幼儿和老年人中很常见。
- 尿液浑浊或异味本身通常不是治疗指征。
- 6 月龄以下婴儿存在严重菌血症风险,应降低处理门槛。

**量化指标 / Metrics**
- 非典型发热病例 UTI 纳入鉴别率
- 婴幼儿疑似 UTI 取样完成率
- 老年病人 UTI 漏诊后再就诊率
