# Skill: 尿液中段尿采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第16章 尿路感染
- 页码: 第16章“尿液采集”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第16章.md`

**目标 / Objective**
规范采集中段尿标本,提高尿液镜检与培养结果的可靠性。

**适用范围 / Scope**
- 需要进行尿路感染实验室诊断的成人和可配合儿童

**操作步骤 / Procedure**
1. 优先采集晨起首次尿液,并尽量立即送检,不能立即送检时 4℃ 冷藏不超过 24 小时。
2. 使用充盈膀胱的尿液,先排出至少 100 ml 初段尿后再采集中段尿。
3. 采集过程中不要中断排尿,将容器多次移进移出尿流以获得至少 20 ml 样本。
4. 女性采样前分开阴唇并避免接触尿流,男性如包皮过长需翻开并清洁龟头。
5. 若样本显微镜下见大量鳞状上皮和碎屑,考虑污染并必要时重采。

**注意事项 / Precautions**
- 尿液采集不规范是无菌性脓尿和假性污染的重要原因。
- 有症状病人也应尽量争取规范采样,尤其在复杂感染或治疗失败时。
- 送检延误会导致细菌增殖并影响结果判断。

**量化指标 / Metrics**
- MSU 合格率
- 污染样本重采率
- 采样后及时送检率
