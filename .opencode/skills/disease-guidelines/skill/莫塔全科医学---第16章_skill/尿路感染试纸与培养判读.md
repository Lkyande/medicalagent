# Skill: 尿路感染试纸与培养判读

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第16章 尿路感染
- 页码: 第16章“试纸检测法”“显微镜检查法”“尿培养”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第16章.md`

**目标 / Objective**
结合试纸、显微镜和培养结果判断尿路感染可能性及严重程度。

**适用范围 / Scope**
- 已留取尿标本并需要实验室结果解释的疑似尿路感染病人

**操作步骤 / Procedure**
1. 先看试纸白细胞酯酶和亚硝酸盐结果,将阳性结果与临床症状结合判断。
2. 显微镜下识别脓尿,以每高倍视野大于 10 个白细胞或每毫升白细胞计数升高作为支持证据。
3. 若样本含大量阴道鳞状上皮和碎屑,优先考虑污染。
4. 解读培养结果时,将 MSU 菌落计数大于 10^5 cfu/ml 视为高度提示感染。
5. 对有明显尿痛和尿频的女性,即便菌落计数低于 10^5 cfu/ml,仍可结合临床合理治疗。

**注意事项 / Precautions**
- 试纸灵敏度高但不能脱离临床解释。
- 大肠埃希菌以外病原体,尤其假单胞菌,提示潜在肾脏异常可能。
- 标准阈值不能机械套用到所有症状性女性。

**量化指标 / Metrics**
- 试纸与培养结果一致率
- 污染样本识别率
- 症状性低菌落计数病例合理处理率
