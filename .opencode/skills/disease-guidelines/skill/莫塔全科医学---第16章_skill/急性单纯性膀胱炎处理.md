# Skill: 急性单纯性膀胱炎处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第16章 尿路感染
- 页码: 第16章“急性单纯性膀胱炎”“对非孕期女性的治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第16章.md`

**目标 / Objective**
对非妊娠、解剖结构正常女性的急性单纯性膀胱炎进行规范经验性治疗和生活指导。

**适用范围 / Scope**
- 非妊娠成年女性急性尿痛-尿频综合征且无复杂因素者

**操作步骤 / Procedure**
1. 识别典型尿痛、尿频、尿急,并确认全身症状轻微或缺如。
2. 指导休息、大量饮水和尽量完全排空膀胱。
3. 必要时给予对乙酰氨基酚止痛,严重排尿困难者可用柠檬酸钠碱化尿液,但使用呋喃妥因时避免同时碱化。
4. 一线经验用药首选甲氧苄啶 300 mg 每日一次 3 日,或按情况选择头孢氨苄、阿莫西林/克拉维酸或呋喃妥因。
5. 若治疗后无症状,通常无需随访;若失败,复核药敏或潜在畸形。

**注意事项 / Precautions**
- 喹诺酮类不应作为一线药物常规使用。
- 复方新诺明相比甲氧苄啶无优势且副作用更大。
- 治疗失败常提示耐药或潜在尿路异常。

**量化指标 / Metrics**
- 单纯性膀胱炎一线方案使用率
- 3 到 5 日症状缓解率
- 首次治疗失败率
