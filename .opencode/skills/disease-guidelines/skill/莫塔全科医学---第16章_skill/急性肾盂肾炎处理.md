# Skill: 急性肾盂肾炎处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第16章 尿路感染
- 页码: 第16章“急性肾盂肾炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第16章.md`

**目标 / Objective**
识别急性肾盂肾炎并根据轻重程度决定口服治疗、住院和静脉抗感染路径。

**适用范围 / Scope**
- 腰痛、发热、寒战、恶心呕吐并伴下尿路症状的病人

**操作步骤 / Procedure**
1. 识别腰痛、发热、寒战、恶心呕吐和膀胱炎症状组合。
2. 立即留取 MCU,必要时加做血培养、血常规和炎症指标。
3. 轻症可口服阿莫西林/克拉维酸 14 日或环丙沙星 7 日,并根据培养结果调整。
4. 对怀疑败血症、妊娠或严重全身感染者安排住院,采样后立即静脉用阿莫西林/氨苄西林联合庆大霉素或替代方案。
5. 若男性或治疗 72 小时后仍不适,进一步排查尿路畸形或梗阻。

**注意事项 / Precautions**
- 急性肾盂肾炎鉴别时要排除阑尾炎、胆囊炎和妇科急腹症。
- 严重感染要尽快静脉治疗,不能等待全部结果回报。
- 妊娠期肾盂肾炎是特别高风险情境。

**量化指标 / Metrics**
- 肾盂肾炎病例 MCU 完成率
- 严重感染住院转运时效
- 72 小时未改善病例复评率
