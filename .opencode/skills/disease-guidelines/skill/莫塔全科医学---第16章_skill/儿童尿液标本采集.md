# Skill: 儿童尿液标本采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第16章 尿路感染
- 页码: 第16章“尿液采集”“儿童尿液标本的采集”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第16章.md`

**目标 / Objective**
为疑似儿童尿路感染选择合适的尿液采集方式,降低污染和漏诊风险。

**适用范围 / Scope**
- 新生儿、婴儿和儿童疑似尿路感染者

**操作步骤 / Procedure**
1. 所有疑似 UTI 的儿童都应在用抗生素前留取尿液标本。
2. 可配合的 3 到 4 岁以上儿童优先尝试 MSU,并由有经验人员指导采样。
3. 对婴儿或中段尿困难者,评估使用 CSU、MCC 或 SPA。
4. 需要最高可靠性时选择 SPA,因为穿刺样本中检出任何病原体都提示 UTI。
5. 明确告知尿袋样本不能用于确诊 UTI。

**注意事项 / Precautions**
- 尿袋样本污染率高,不能用于诊断。
- 6 月龄以下儿童检查和处理门槛应更低。
- 采样方式选择要兼顾年龄、可配合程度和诊断紧迫性。

**量化指标 / Metrics**
- 儿童疑似 UTI 规范取样率
- 尿袋误用率
- SPA 或 CSU 成功采样率
