# Skill: 复发性尿路感染预防

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第16章 尿路感染
- 页码: 第16章“复发性或慢性尿路感染”“预防性使用抗生素”“非抗生素策略”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第16章.md`

**目标 / Objective**
为复发性尿路感染病人建立药物和非药物复发预防策略。

**适用范围 / Scope**
- 每年反复发作膀胱炎或慢性持续性尿路感染的成人病人

**操作步骤 / Procedure**
1. 确认复发是真正再感染还是持续感染,并排查耐药、结石、前列腺炎或结构异常。
2. 指导多饮水、性行为后排尿及女性从前向后清洁等基础措施。
3. 对与性行为相关的复发性 UTI,考虑在性行为后 2 小时内单剂量使用敏感抗生素。
4. 对重症或高频复发者,考虑甲氧苄啶 150 mg 夜服或头孢氨苄 250 mg 夜服,持续 3 到 6 个月或更久。
5. 对绝经后合并萎缩性阴道炎女性,考虑局部雌激素治疗。

**注意事项 / Precautions**
- 慢性持续性感染常提示存在潜在病灶,不能只反复开短疗程抗生素。
- 蔓越莓产品已不再推荐。
- 预防方案应结合培养敏感性和复发模式选择。

**量化指标 / Metrics**
- 复发性 UTI 年发作次数变化
- 预防方案依从率
- 预防后抗生素使用总量变化
