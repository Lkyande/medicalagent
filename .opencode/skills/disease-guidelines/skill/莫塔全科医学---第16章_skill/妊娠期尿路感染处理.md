# Skill: 妊娠期尿路感染处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第16章 尿路感染
- 页码: 第16章“孕妇”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第16章.md`

**目标 / Objective**
对妊娠期无症状菌尿和急性膀胱炎进行及时治疗与复查,降低肾盂肾炎和妊娠并发症风险。

**适用范围 / Scope**
- 妊娠女性无症状菌尿、急性膀胱炎或疑似尿路感染者

**操作步骤 / Procedure**
1. 在妊娠早期筛查并排除无症状菌尿。
2. 对无症状菌尿按急性膀胱炎同样治疗,不要仅观察。
3. 经验性选用头孢氨苄、呋喃妥因或阿莫西林/克拉维酸,按推荐疗程治疗 5 日。
4. 治疗结束后 1 到 2 周复查 MCU。
5. 如伴发热、腰痛或病情加重,按急性肾盂肾炎路径升级评估。

**注意事项 / Precautions**
- 妊娠期 UTI 需要比普通膀胱炎更严密监测。
- 无症状菌尿也会进展为完全感染,不能忽视。
- 合并梗阻风险时应安排超声排查。

**量化指标 / Metrics**
- 妊娠早期无症状菌尿筛查率
- 治疗后 1 到 2 周复查率
- 妊娠期 UTI 进展为肾盂肾炎比例
