# Skill: 尿路感染进一步检查分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第16章 尿路感染
- 页码: 第16章“表16.1 对有症状尿路感染的辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第16章.md`

**目标 / Objective**
识别需要进一步泌尿系统检查的尿路感染病人,避免漏掉结构异常和肾损害。

**适用范围 / Scope**
- 有症状尿路感染病人,尤其儿童、男性、孕妇、复发者和治疗失败者

**操作步骤 / Procedure**
1. 将所有儿童、所有男性和所有妊娠女性列为需进一步评估的人群。
2. 对女性如存在急性肾盂肾炎、每年超过 2 次复发、证实无菌性脓尿、血尿或治疗失败,安排进一步检查。
3. 基本检查包括治疗后 MCU、肾功能、eGFR,并按需要安排超声或静脉尿路造影。
4. 儿童进一步评估时考虑膀胱尿道造影和 DMSA/MAG3 核素扫描。
5. 对严重肾盂肾炎或梗阻风险者加急影像,并及时专科转诊。

**注意事项 / Precautions**
- 对结构异常可能性小的病人应避免过度检查。
- 超声不能发现所有结石、小肿块和乳头坏死。
- 复发性或持续性血尿需要更深入评估。

**量化指标 / Metrics**
- 符合指征者进一步检查完成率
- 儿童 UTI 影像评估率
- 结构异常检出率
