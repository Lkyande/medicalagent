# Skill: 男性尿路感染处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第16章 尿路感染
- 页码: 第16章“成年男性病人的治疗”“前列腺炎”“转诊时机”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第16章.md`

**目标 / Objective**
对男性尿路感染进行经验治疗并同步排查前列腺炎、梗阻和潜在异常。

**适用范围 / Scope**
- 所有男性有症状尿路感染或疑似前列腺相关感染者

**操作步骤 / Procedure**
1. 将所有男性 UTI 视为需要进一步评估的病例。
2. 在治疗前或同时安排 MCU、尿素氮电解质和超声检查。
3. 经验性给予甲氧苄啶、头孢氨苄、阿莫西林/克拉维酸、呋喃妥因或诺氟沙星治疗 7 日。
4. 若伴流感样症状、发热、会阴痛和直肠指检前列腺压痛,考虑细菌性前列腺炎并延长治疗或升级静脉方案。
5. 对不能明确是否累及前列腺、复发或伴肾功能受损者及时转诊。

**注意事项 / Precautions**
- 前列腺炎是男性尿路感染再发最常见原因。
- 所有男性 UTI 都应排除潜在异常和梗阻。
- 上尿路受累或全身症状明显时不能按单纯膀胱炎处理。

**量化指标 / Metrics**
- 男性 UTI 完成进一步评估率
- 前列腺炎识别率
- 转诊及时率
