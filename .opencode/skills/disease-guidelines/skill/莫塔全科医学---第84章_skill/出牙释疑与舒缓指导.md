# Skill: 出牙释疑与舒缓指导

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第84章 儿童的特定问题
- 页码: 第84章“出牙”“症状”“舒缓方法”“药物治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第84章.md`

**目标 / Objective**
帮助家长正确理解出牙表现,避免把严重症状误归因于出牙。

**适用范围 / Scope**
- 6 个月至 3 岁婴幼儿出现牙龈不适、流口水或烦躁时

**操作步骤 / Procedure**
1. 询问牙龈轻微红肿、咀嚼增加和轻度烦躁等典型出牙表现。
2. 明确告知出牙通常只造成轻微不适。
3. 排除发热、腹泻、皮疹等并非典型出牙表现的其他病因。
4. 建议使用干净冷湿布、冷藏磨牙圈或轻柔牙龈按摩舒缓。
5. 仅在明显不适时短期使用对乙酰氨基酚,避免含水杨酸的出牙胶。

**注意事项 / Precautions**
- 出牙不应被用来解释明显全身症状。
- 家长容易高估出牙疼痛程度,需要积极释除担忧。
- 磨牙物品应安全、清洁并避免窒息风险。

**量化指标 / Metrics**
- 出牙相关释疑记录率
- 不当用药避免率
- 伴发其他病因识别率
