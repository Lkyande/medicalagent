# Skill: 生长迟缓评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第84章 儿童的特定问题
- 页码: 第84章“生长迟缓”“表84.1 生长迟缓需要考虑的原因”“病史”“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第84章.md`

**目标 / Objective**
识别真正的生长迟缓并从摄入、吸收、消耗和社会心理因素系统排查原因。

**适用范围 / Scope**
- 体重低于第 3 百分位、跨越多个百分位线或临床怀疑生长不良的婴幼儿

**操作步骤 / Procedure**
1. 在生长图上连续绘制体重、身长和头围,判断变化速度和背景。
2. 详细询问喂养方式、进食量、呕吐、固体添加、家庭喂养互动和社会支持。
3. 从热量摄入不足、吸收不良、消耗过多和社会心理因素四方面构建鉴别诊断。
4. 查体时观察总体状态、皮下脂肪、发育、变形特征、脱水和虐待线索。
5. 若存在异常,进行有针对性检查并考虑儿科、营养、哺乳和心理团队联合评估。

**注意事项 / Precautions**
- FTT 是描述性概念,不是最终诊断。
- 多数病例原因多因素交织,不能只找单一器质性病因。
- 频繁称重可能增加家长焦虑。

**量化指标 / Metrics**
- 生长图完整记录率
- 喂养史评估完整率
- 复杂病例多学科转介率
