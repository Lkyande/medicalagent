# Skill: 婴儿哭闹排查与安抚

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第84章 儿童的特定问题
- 页码: 第84章“婴儿哭闹”“管理”“抚慰的方法”“应对策略”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第84章.md`

**目标 / Objective**
排除婴儿哭闹的危险病因,并向照护者提供安全有效的安抚策略。

**适用范围 / Scope**
- 出生后前数月出现持续哭闹、烦躁或疑似“肠绞痛”的婴儿

**操作步骤 / Procedure**
1. 询问哭闹模式、持续时间、喂养、生长和家长应对能力。
2. 完整体检并评估喂养、安睡模式、发育和感染或疼痛线索。
3. 排除牛奶不耐受、GERD、尿路感染、疝和肠梗阻等可治疗原因。
4. 向父母解释正常哭闹曲线和“紫哭期”特征,减少灾难化担忧。
5. 教授温柔拥抱、轻摇、说话、减少过度刺激和照护者自我冷静策略。

**注意事项 / Precautions**
- 过度刺激有时会加重哭闹。
- 绝不可用力摇晃婴儿。
- 家长极度疲惫或情绪失控时需要额外支持和安全计划。

**量化指标 / Metrics**
- 哭闹婴儿危险病因排查率
- 家长安抚教育完成率
- 重复就诊中的担忧缓解率
