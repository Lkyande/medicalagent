# Skill: 急性躁狂识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第69章 紊乱的病人
- 页码: 第69章“双相障碍”“DSM-5 中躁狂发作的标准”“急性躁狂的处理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第69章.md`

**目标 / Objective**
在行为紊乱或情绪高涨病人中识别急性躁狂发作并及早启动精神科管理。

**适用范围 / Scope**
- 出现高涨心境、激越、睡眠需求减少、言语增多或冲动行为的病人

**操作步骤 / Procedure**
1. 询问近期是否有持续高涨或易激惹心境及睡眠显著减少。
2. 查找夸大、自我评价过高、语量增多、思维奔逸和高风险行为。
3. 评估是否伴精神病性症状、攻击性、自杀风险或财务/性冲动。
4. 排除兴奋剂、甲亢、谵妄和其他器质性原因。
5. 对明显躁狂者启动安全管理并安排紧急精神科评估。

**注意事项 / Precautions**
- 躁狂可表现为易激惹而不只是“开心”。
- 药物和物质诱发状态必须纳入鉴别。
- 功能受损明显或伴精神病性表现者风险高。

**量化指标 / Metrics**
- 疑似躁狂病人的器质性排查率
- 精神病性症状评估率
- 紧急精神科转介率
