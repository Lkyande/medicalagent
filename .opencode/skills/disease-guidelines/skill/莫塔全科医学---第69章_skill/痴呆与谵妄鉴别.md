# Skill: 痴呆与谵妄鉴别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第69章 紊乱的病人
- 页码: 第69章“关键事实和要点”“痴呆(慢性器质性大脑综合征)”“痴呆的鉴别诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第69章.md`

**目标 / Objective**
区分慢性进行性认知下降与急性可逆性意识障碍,避免误诊误治。

**适用范围 / Scope**
- 记忆力下降、定向障碍、行为改变或混乱表现的中老年病人

**操作步骤 / Procedure**
1. 判断病程是慢性渐进还是急性波动,这是鉴别第一步。
2. 重点比较记忆受损是否为主,还是注意力和意识水平改变更突出。
3. 询问近来感染、药物变化、脱水和疼痛等诱发因素。
4. 在家中或熟悉环境中观察功能状态和支持系统,必要时向照护者补充病史。
5. 对疑似痴呆病人安排认知评估,对疑似谵妄病人立即搜查可逆诱因。

**注意事项 / Precautions**
- 痴呆病人可叠加谵妄,两者并不互斥。
- 抑郁可模仿痴呆表现,需同时考虑。
- 全科中痴呆常被漏诊,不能仅凭年龄解释记忆下降。

**量化指标 / Metrics**
- 认知异常病人的病程分类记录率
- 照护者补充病史获取率
- 痴呆与谵妄初步区分准确率
