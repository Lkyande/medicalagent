# Skill: 急性紊乱病人安全处置

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第69章 紊乱的病人
- 页码: 第69章“行为急诊:对急性紊乱病人的管理”“管理方法”“镇静药应用原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第69章.md`

**目标 / Objective**
在急性行为紊乱场景中优先保障病人和周围人员安全,并为后续病因评估创造条件。

**适用范围 / Scope**
- 激越、攻击、严重混乱或存在自伤伤人风险的急性紊乱病人

**操作步骤 / Procedure**
1. 先评估现场安全,减少刺激,确保有足够人员支持并清理危险物品。
2. 采用平静、简短和一致的沟通方式尝试口头降阶。
3. 同步快速评估意识、生命体征、低血糖、缺氧和药物中毒等可逆病因。
4. 若口头干预无效且风险升级,按最小必要原则实施镇静或转运。
5. 病情稳定后补做完整精神状态、病史和躯体检查。

**注意事项 / Precautions**
- 急性激越不等于原发精神病,必须排除躯体和药物原因。
- 镇静前后都应监测呼吸和循环。
- 老年人和痴呆病人对药物更敏感,剂量需谨慎。

**量化指标 / Metrics**
- 急性紊乱场景安全评估完成率
- 低血糖和生命体征快速筛查率
- 镇静后监测记录率
