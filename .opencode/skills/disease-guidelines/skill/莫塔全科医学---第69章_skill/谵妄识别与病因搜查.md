# Skill: 谵妄识别与病因搜查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第69章 紊乱的病人
- 页码: 第69章“谵妄的重要原因”“急性器质性脑综合征(谵妄)”“谵妄的标准”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第69章.md`

**目标 / Objective**
尽早识别谵妄,并系统搜查感染、药物、代谢和缺氧等常见诱因。

**适用范围 / Scope**
- 急性或亚急性出现意识混乱、注意力下降、定向障碍的病人,尤其老年人

**操作步骤 / Procedure**
1. 判断起病是否急性且波动,并确认注意力和思维混乱是否突出。
2. 复核是否有既往痴呆基础,以及近期感染、脱水、疼痛、便秘、尿潴留或环境改变。
3. 核查处方药、抗胆碱能药、镇静药、酒精和违禁物使用或戒断情况。
4. 完成生命体征、氧饱和度、血糖和基础实验室检查,按需要补做感染和影像评估。
5. 发现诱因后优先纠正病因,并提供低刺激、再定向和安全支持。

**注意事项 / Precautions**
- 总是要积极寻找谵妄原因,不能只做症状镇静。
- 视觉幻觉较常提示器质性病因。
- 老年痴呆病人发生感染或新药暴露时特别容易出现谵妄。

**量化指标 / Metrics**
- 急性混乱病人的谵妄筛查率
- 药物清单复核率
- 诱因明确率
