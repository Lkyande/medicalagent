# Skill: 精神病性幻觉病因分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第69章 紊乱的病人
- 页码: 第69章“关键事实和要点”“表69.7 幻觉诊断策略模型”“精神分裂症及相关疾病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第69章.md`

**目标 / Objective**
根据幻觉类型和伴随表现区分功能性精神病与器质性病因。

**适用范围 / Scope**
- 出现听觉、视觉、嗅觉或触觉幻觉的青少年和成人病人

**操作步骤 / Procedure**
1. 明确幻觉模态,区分听觉、视觉、嗅觉和触觉幻觉。
2. 结合指南线索判断病因方向,如听幻觉偏向精神病,视觉幻觉常提示器质性问题。
3. 评估妄想、定向力、意识水平、物质使用及戒断背景。
4. 筛查感染、代谢紊乱、癫痫、药物毒性和脑部病变等躯体原因。
5. 根据风险决定是否需急诊医学评估或精神专科介入。

**注意事项 / Precautions**
- 视觉幻觉几乎总是要先考虑器质性疾病。
- 嗅幻觉应想到颞叶癫痫。
- 触幻觉常见于可卡因滥用和酒精戒断。

**量化指标 / Metrics**
- 幻觉模态记录率
- 器质性病因筛查完成率
- 高危精神病或躯体病转诊率
