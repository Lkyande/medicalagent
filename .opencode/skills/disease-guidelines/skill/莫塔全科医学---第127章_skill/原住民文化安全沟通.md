# Skill: 原住民文化安全沟通

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第127章 原住民和托雷斯海峡岛民的健康
- 页码: 第127章“文化和医患关系”“有用的沟通技巧”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第127章.md`

**目标 / Objective**
在诊疗中建立文化安全、尊重和长期可信赖的治疗关系。

**适用范围 / Scope**
- 原住民和托雷斯海峡岛民个人、家庭及社区相关基层医疗场景

**操作步骤 / Procedure**
1. 在每次看诊中主动考虑文化背景对沟通、健康信念和依从性的影响。
2. 必要时邀请原住民健康工作者参与沟通和管理。
3. 留出额外时间,允许停顿,避免专业术语并核对理解程度。
4. 使用图片和通俗语言解释复杂问题,注意肢体语言和眼神接触。
5. 以“让病人愿意再回来”为核心目标建立长期关系。

**注意事项 / Precautions**
- 文化安全不是“了解一点风俗”,而是持续尊重与反思偏见。
- 慢病管理更像马拉松,不适合一次性说教。
- 女事、男事和丧事等文化议题需要特别尊重。

**量化指标 / Metrics**
- 文化相关沟通记录率
- 原住民健康工作者参与率
- 后续复诊连续性
