# Skill: 原住民慢病机会性筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第127章 原住民和托雷斯海峡岛民的健康
- 页码: 第127章“关键事实和要点”“常见疾病机会性筛查的重要性”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第127章.md`

**目标 / Objective**
在日常就诊中主动开展高负担慢病和感染性疾病筛查。

**适用范围 / Scope**
- 原住民和托雷斯海峡岛民成人及高风险儿童常规门诊场景

**操作步骤 / Procedure**
1. 将 2 型糖尿病、高血压、肾功能和其他心血管危险因素纳入机会性筛查。
2. 按需要加做乙肝、STI 尿筛查、宫颈筛查、儿童贫血和听力检查。
3. 同步记录 BMI、尿白蛋白/肌酐比值、血脂和血糖等指标。
4. 对异常结果尽快解释并安排随访与治疗。
5. 将筛查与长期关系建立和家庭支持结合推进。

**注意事项 / Precautions**
- 多病共存很常见,不能只处理单一主诉。
- 终末期肾衰竭、宫颈癌和糖尿病负担明显更高。
- 偏远地区需结合当地可及资源与 CARPA 指南。

**量化指标 / Metrics**
- 机会性慢病筛查覆盖率
- 肾功能和 ACR 检测率
- 异常筛查后随访完成率
