# Skill: 原住民皮肤感染早治

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第127章 原住民和托雷斯海峡岛民的健康
- 页码: 第127章“关键事实和要点”“皮肤和软组织感染”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第127章.md`

**目标 / Objective**
通过早期发现和治疗疥疮、脓疱疮和蜂窝织炎降低侵袭性感染负担。

**适用范围 / Scope**
- 原住民和托雷斯海峡岛民儿童及成人皮肤病常规就诊和筛查场景

**操作步骤 / Procedure**
1. 主动检查疥疮、脓疱疮、蜂窝织炎、疖和体癣等高频皮肤问题。
2. 识别指蹼瘙痒丘疹、脓疱和破溃结痂等关键表现。
3. 及早启动标准治疗,并处理家庭或社区接触者问题。
4. 解释皮肤感染与后续肾小球肾炎、侵袭性感染的关系。
5. 安排复诊确认临床改善和并发症筛查。

**注意事项 / Precautions**
- 皮肤保健是该人群健康的关键切入点。
- 疥疮和脓疱病在儿童中可达到流行水平。
- 继发链球菌并发症风险不能低估。

**量化指标 / Metrics**
- 皮肤感染早期识别率
- 复诊改善率
- 接触者处理覆盖率
