# Skill: 原住民儿童耳病筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第127章 原住民和托雷斯海峡岛民的健康
- 页码: 第127章“儿童常见问题”“耳感染”“治疗建议”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第127章.md`

**目标 / Objective**
尽早识别中耳炎和慢性化脓性中耳炎,减少听力受损与学习障碍。

**适用范围 / Scope**
- 原住民和托雷斯海峡岛民婴幼儿、学龄前儿童及学龄儿童

**操作步骤 / Procedure**
1. 在常规儿童就诊中主动询问耳流脓、听力差、语言发育和学校表现。
2. 仔细耳镜检查并寻找鼓膜穿孔和慢性分泌物证据。
3. 对急性中耳炎尽早、积极使用抗生素路径治疗。
4. 对慢性化脓性中耳炎实施冲洗、拭干和局部滴耳方案,并教家庭成员操作。
5. 对持续病例安排听力评估和专科随访。

**注意事项 / Precautions**
- 听力损伤会明显影响语言和学习。
- 学龄前儿童慢性化脓性中耳炎很常见且难治。
- 鼓膜穿孔会影响药物和处理选择。

**量化指标 / Metrics**
- 儿童耳病筛查率
- 鼓膜穿孔记录率
- 听力评估转介率
