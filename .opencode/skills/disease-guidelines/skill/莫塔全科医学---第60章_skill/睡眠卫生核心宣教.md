# Skill: 睡眠卫生核心宣教

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第60章 睡眠障碍
- 页码: 第60章“管理”“睡眠卫生建议”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第60章.md`

**目标 / Objective**
通过标准化宣教改善可调整的日常行为,降低轻中度失眠维持因素。

**适用范围 / Scope**
- 以失眠、睡眠浅、睡眠不规律或夜间觉醒为主诉的病人

**操作步骤 / Procedure**
1. 指导建立固定起床时间和睡前常规,避免白天补觉。
2. 建议白天规律运动,但避免临睡前剧烈运动。
3. 提醒下午后减少咖啡因,晚上避免酒精、吸烟和过饱晚餐。
4. 优化卧室环境,保持安静、黑暗、舒适,并移除宠物和高亮时钟。
5. 与病人一起确定最能帮助放松的睡前方式,如热水澡或舒缓音乐。

**注意事项 / Precautions**
- 宣教应结合病人生活作息定制,避免只给笼统建议。
- 睡眠卫生改善通常需要连续执行数周才能评估效果。
- 若存在显著焦虑、疼痛或 OSA,单靠睡眠卫生往往不足。

**量化指标 / Metrics**
- 睡眠卫生宣教覆盖率
- 病人可执行建议落实率
- 2 至 4 周后主观睡眠改善率
