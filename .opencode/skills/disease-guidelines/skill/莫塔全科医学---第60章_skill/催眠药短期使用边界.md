# Skill: 催眠药短期使用边界

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第60章 睡眠障碍
- 页码: 第60章“治疗失眠的基本原则”“药物治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第60章.md`

**目标 / Objective**
在必要用药时明确催眠药仅作短期辅助,降低依赖和不良反应风险。

**适用范围 / Scope**
- 经评估后考虑短期药物辅助的失眠病人

**操作步骤 / Procedure**
1. 先确认已进行非药物治疗,且存在短期症状缓解的明确目标。
2. 与病人约定用药边界,必要时将计划书面化为短期使用协议。
3. 说明连续药物治疗最好限制在 2 周内,并预先设定停药时间。
4. 选药时同时评估苯二氮类依赖风险、老年跌倒风险及日间镇静。
5. 复诊时复核疗效和不良反应,无明确获益时停药并回到行为治疗主线。

**注意事项 / Precautions**
- 催眠药不应作为失眠的一线长期方案。
- 佐匹克隆、唑吡坦等非苯二氮类也有神经精神不良反应风险。
- 无抑郁障碍的老年病人应避免把镇静性三环类抗抑郁药当作常规催眠药。

**量化指标 / Metrics**
- 催眠药疗程 ≤2 周达标率
- 用药协议记录率
- 复诊停药或减药完成率
