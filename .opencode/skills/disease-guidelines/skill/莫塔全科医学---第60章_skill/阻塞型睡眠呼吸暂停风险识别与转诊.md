# Skill: 阻塞型睡眠呼吸暂停风险识别与转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第60章 睡眠障碍
- 页码: 第60章“睡眠呼吸暂停”“睡眠呼吸暂停的管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第60章.md`

**目标 / Objective**
在基层识别 OSA 高风险病人并及时转入规范睡眠评估与治疗路径。

**适用范围 / Scope**
- 打鼾、被目击呼吸暂停、白天困倦或总是感到疲倦的病人

**操作步骤 / Procedure**
1. 询问打鼾、呼吸暂停目击史、晨起头痛、日间嗜睡和驾驶风险。
2. 识别 TATT 表现,并关注肥胖、饮酒、催眠药、鼻阻塞和侧卧受益情况。
3. 对疑似 OSA 病人建议完成经验证量表,并转诊睡眠障碍中心做多导睡眠图。
4. 初步管理中给予减重、规律运动、戒烟、避免睡前饮酒和停减镇静药建议。
5. 对商业驾驶者明确说明未控制 OSA 期间继续驾驶存在法律与安全风险。

**注意事项 / Precautions**
- OSA 病人常意识不到夜间反复觉醒,不能因自述睡得久而排除。
- 儿童打鼾也应重视,常需进一步检查或 ENT 评估。
- 心肺或神经系统病变线索明显时,还需考虑中枢性睡眠呼吸暂停。

**量化指标 / Metrics**
- OSA 高风险识别率
- 睡眠中心转诊完成率
- 生活方式干预建议落实率
