# Skill: 睡眠日记记录与解读

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第60章 睡眠障碍
- 页码: 第60章“关键事实和要点”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第60章.md`

**目标 / Objective**
用连续睡眠记录补足主诉信息,帮助判断失眠与睡眠-觉醒节律问题。

**适用范围 / Scope**
- 睡眠规律不清、主诉与实际作息不一致或怀疑昼夜节律问题的病人

**操作步骤 / Procedure**
1. 说明睡眠日记用于记录上床、入睡、夜间觉醒、最终起床和日间小睡。
2. 建议连续记录至少 1 至 2 周,同时标记咖啡因、酒精、运动和药物使用。
3. 复诊时比对入睡潜伏期、总睡眠时间和觉醒占比与主诉是否一致。
4. 从记录中识别倒班、睡眠相位后移、补觉和不规则作息等模式。
5. 根据日记结果调整行为治疗计划,必要时再决定是否转睡眠专科。

**注意事项 / Precautions**
- 睡眠日记是评估工具,不能替代多导睡眠图。
- 记录时应尽量每日当日完成,避免回忆性填表。
- 主观感知睡眠不足者常存在睡眠误感知,解释时要温和校正。

**量化指标 / Metrics**
- 睡眠日记完成率
- 作息模式识别率
- 基于日记调整方案的实施率
