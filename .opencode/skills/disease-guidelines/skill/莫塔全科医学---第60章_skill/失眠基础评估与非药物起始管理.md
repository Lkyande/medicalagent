# Skill: 失眠基础评估与非药物起始管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第60章 睡眠障碍
- 页码: 第60章“失眠”“治疗失眠的基本原则”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第60章.md`

**目标 / Objective**
在失眠首诊中完成系统评估,并优先启动非药物管理路径。

**适用范围 / Scope**
- 主诉入睡困难、易醒、早醒或睡后不恢复的成人和青少年

**操作步骤 / Procedure**
1. 明确失眠类型、持续时间、日间功能受损程度和病人治疗目标。
2. 追问心理压力、疼痛、药物使用、物质滥用、倒班和生物节律紊乱。
3. 识别焦虑、抑郁、OSA、不宁腿、反流、夜尿和甲状腺疾病等共病。
4. 先以教育、 reassurance、睡眠卫生和行为治疗作为起始方案。
5. 若处理诱因后症状仍持续或病情复杂,转诊睡眠专科进一步评估。

**注意事项 / Precautions**
- 很多病人对所需睡眠时长的期待并不现实,需先校正认知。
- 用药请求明显且反复时,要警惕苯二氮依赖。
- 非药物治疗应作为默认第一线,而不是催眠药失败后的补救措施。

**量化指标 / Metrics**
- 失眠病史完整采集率
- 首诊非药物方案启动率
- 共病识别与处理率
