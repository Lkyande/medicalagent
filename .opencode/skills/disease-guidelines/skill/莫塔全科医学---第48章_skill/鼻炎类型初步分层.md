# Skill: 鼻炎类型初步分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第48章 鼻疾病
- 页码: 第48章“鼻炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第48章.md`

**目标 / Objective**
根据症状模式和诱因对鼻炎进行过敏性、感染性和血管运动性初步分层。

**适用范围 / Scope**
- 主诉打喷嚏、流涕、鼻塞或鼻痒超过 1 小时的病人

**操作步骤 / Procedure**
1. 判断症状是季节性还是常年性,并记录发作时间模式。
2. 询问打喷嚏、鼻痒、眼部刺激和水样鼻涕,判断过敏性线索。
3. 询问脓性分泌物、鼻后滴漏和上呼吸道感染背景,判断感染性线索。
4. 评估酒精、温湿度变化、空调、情绪和刺激性气味等血管运动性诱因。
5. 核查是否长期使用减充血喷雾或相关药物,排除药物性鼻炎。

**注意事项 / Precautions**
- 过敏性鼻炎与哮喘密切相关,问诊时应补充下气道症状。
- 长期使用羟甲唑啉等减充血剂可反过来加重鼻塞。
- 单侧持续鼻塞不应简单归入普通鼻炎。

**量化指标 / Metrics**
- 鼻炎分型记录率
- 药物性鼻炎识别率
- 诱因记录完整率
