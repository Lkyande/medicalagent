# Skill: 鼻出血一线止血处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第48章 鼻疾病
- 页码: 第48章“鼻出血”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第48章.md`

**目标 / Objective**
对常见前鼻部出血实施标准化一线止血处理。

**适用范围 / Scope**
- 血流动力学稳定的前鼻部鼻出血病人

**操作步骤 / Procedure**
1. 先清除鼻腔血块,指导病人擤鼻后喷 5 至 6 次减充血鼻喷剂。
2. 用拇指和示指持续捏压鼻中隔下方软部位 5 至 20 分钟。
3. 同时给予鼻梁冰敷,减少局部血流。
4. 必要时放入浸有减充血剂和利多卡因的棉球辅助局部压迫。
5. 若能明确利氏区出血点,在局麻下选择硝酸银、电灼或三氯乙酸烧灼止血。

**注意事项 / Precautions**
- 老年人新近持续鼻出血要警惕肿瘤或后鼻部出血。
- 处理前应有良好照明、吸引和合适器械。
- 烧灼后注意保护局部黏膜,避免双侧同时大面积烧灼。

**量化指标 / Metrics**
- 一线压迫止血成功率
- 前鼻部烧灼成功率
- 复发性鼻出血发生率
