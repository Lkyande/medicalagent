# Skill: 慢性鼻窦炎阶梯处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第48章 鼻疾病
- 页码: 第48章“慢性鼻窦炎”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第48章.md`

**目标 / Objective**
以冲洗和鼻内药物为基础对慢性鼻窦炎进行门诊阶梯管理并识别手术转诊时机。

**适用范围 / Scope**
- 症状和体征持续 8 至 12 周以上的慢性鼻窦炎病人

**操作步骤 / Procedure**
1. 确认症状持续时间已符合慢性鼻窦炎范围,并评估是否合并鼻息肉。
2. 先行鼻内盐水冲洗以帮助清除分泌物和改善引流。
3. 试用抗组胺鼻喷雾剂,并加用或切换至鼻内类固醇喷雾剂。
4. 在等待手术处理时,必要时短程口服泼尼松龙缓解疼痛和炎症。
5. 经上述治疗仍无效或出现眼眶或面部蜂窝织炎时立即转耳鼻喉专科处理。

**注意事项 / Precautions**
- 急性上呼吸道感染后鼻窦症状并不等于需要抗生素。
- 眼眶或面部蜂窝织炎属于紧急转诊指征。
- 机械盐水冲洗可作为药物失败后的进一步手段。

**量化指标 / Metrics**
- 鼻腔冲洗使用率
- 鼻内类固醇规范使用率
- 慢性鼻窦炎专科转诊率
