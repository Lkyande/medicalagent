# Skill: 嗅觉障碍基础评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第48章 鼻疾病
- 页码: 第48章“嗅觉障碍”“临床方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第48章.md`

**目标 / Objective**
通过病史、鼻镜和简易嗅觉测试完成嗅觉障碍的初步定位评估。

**适用范围 / Scope**
- 主诉嗅觉丧失、减退、倒错或恶臭感的病人

**操作步骤 / Procedure**
1. 询问头部外伤、鼻部手术、近期上呼吸道感染、药物和职业化学暴露史。
2. 用鼻镜检查鼻腔是否存在鼻息肉、鼻中隔偏曲、鼻炎或鼻窦炎等传导性病变。
3. 使用咖啡、丁香、柠檬、薄荷等熟悉气味做定性测试,必要时加入安慰剂对照。
4. 结合氨水刺激测试区分刺激感觉保留与纯嗅觉异常。
5. 怀疑鼻窦病变、肿瘤或复杂病因时安排 CT 等进一步检查。

**注意事项 / Precautions**
- 嗅觉丧失常合并味觉下降,会增加烟雾、煤气和食物变质风险。
- 头部外伤后嗅觉障碍可能长期不能恢复,需提前告知。
- 不要把所有嗅觉异常都归因于感冒后遗症。

**量化指标 / Metrics**
- 嗅觉障碍病史完整率
- 鼻镜检查完成率
- 危险病因识别率
