# Skill: 鼻疾病红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第48章 鼻疾病
- 页码: 第48章“鼻疾病的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第48章.md`

**目标 / Objective**
及时识别提示肿瘤、异物、并发症或系统性疾病的危险鼻部表现。

**适用范围 / Scope**
- 以鼻塞、分泌物、鼻出血或嗅觉异常就诊的病人

**操作步骤 / Procedure**
1. 识别单侧鼻腔息肉样病变,优先排除肿瘤而非按普通息肉处理。
2. 关注单侧血性分泌物和持续单侧鼻塞。
3. 对幼儿严重且单侧的鼻分泌物,主动寻找鼻异物。
4. 创伤后检查鼻中隔周围是否肿胀,警惕鼻中隔血肿。
5. 若伴慢性鼻窦炎和下呼吸道感染,考虑肉芽肿性血管炎等系统病。

**注意事项 / Precautions**
- 单侧病变比双侧症状更需要警惕肿瘤或异物。
- 药物性鼻炎虽常见,但不能掩盖其他危险病因。
- 创伤后鼻中隔血肿需要及时处理,延误可导致软骨坏死。

**量化指标 / Metrics**
- 鼻部红旗征记录率
- 单侧病变专科转诊率
- 异物漏诊率
