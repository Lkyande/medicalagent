# Skill: 嗅觉丧失安全宣教

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第48章 鼻疾病
- 页码: 第48章“嗅觉丧失的治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第48章.md`

**目标 / Objective**
降低嗅觉丧失病人在家庭环境中的烟雾、煤气和食物安全风险。

**适用范围 / Scope**
- 已确认或高度怀疑嗅觉丧失的病人及家庭照护者

**操作步骤 / Procedure**
1. 向病人解释嗅觉丧失可能影响危险气味、烟雾和变质食物识别。
2. 建议家庭安装并定期测试烟雾报警器和燃气报警装置。
3. 叮嘱处理煤气、挥发性化学品和高浓度香水时格外谨慎。
4. 强调牛奶、肉类等易腐食物需依赖保质期和冷藏管理而非气味判断。
5. 对感染后慢性嗅觉丧失可短期试用减充血喷雾,同时安排随访观察恢复。

**注意事项 / Precautions**
- 这类宣教是安全干预,不能被单纯安慰替代。
- 嗅觉恢复时间可能从数日至数月,部分病人无法完全恢复。
- 补充锌和维生素的证据有限,不应过度承诺疗效。

**量化指标 / Metrics**
- 安全宣教完成率
- 家庭报警装置配置率
- 嗅觉障碍相关家庭意外发生率
