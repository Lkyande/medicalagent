# Skill: 鼻息肉药物初始处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第48章 鼻疾病
- 页码: 第48章“鼻息肉”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第48章.md`

**目标 / Objective**
对典型鼻息肉进行以类固醇为核心的初始药物处理并识别恶性警示。

**适用范围 / Scope**
- 符合典型光滑苍白外观的鼻息肉病人

**操作步骤 / Procedure**
1. 确认病变符合圆形、柔软、苍白、带蒂的典型鼻息肉外观。
2. 询问是否伴哮喘、阿司匹林敏感或儿童囊性纤维化风险线索。
3. 给予短程口服泼尼松龙作为药物性“息肉切除术”尝试。
4. 同步启动鼻内类固醇喷雾并至少持续 3 个月维持治疗。
5. 若有脓性分泌物加用抗生素,若单侧或外观不典型则尽快专科评估。

**注意事项 / Precautions**
- 单侧“息肉”或不光滑不苍白病变必须警惕肿瘤。
- 儿童鼻息肉要考虑囊性纤维化,不能仅按成人思路处理。
- 复杂手术切除能降低复发率,但应由专科决定。

**量化指标 / Metrics**
- 典型鼻息肉药物治疗启动率
- 非典型病变转诊率
- 3 个月症状改善率
