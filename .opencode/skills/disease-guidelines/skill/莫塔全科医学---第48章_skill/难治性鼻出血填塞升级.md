# Skill: 难治性鼻出血填塞升级

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第48章 鼻疾病
- 页码: 第48章“持续的鼻前部出血”“严重的鼻后部出血”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第48章.md`

**目标 / Objective**
在简单压迫止血失败后及时升级为规范填塞与专科处理。

**适用范围 / Scope**
- 持续鼻前部出血或怀疑严重鼻后部出血的病人

**操作步骤 / Procedure**
1. 当前鼻部简单压迫和局部药物无效时,采用膨胀海绵或藻酸钙钠盐敷料进行前鼻填塞。
2. 结合口服、静脉或局部氨甲环酸提高止血效果。
3. 对间歇性前鼻区小出血,可辅以局部抗生素鼻膏或凡士林减少复发。
4. 若怀疑后鼻部出血,使用 Foley 导管、Epistat 或 Rapid Rhino 等装置升级填塞。
5. 对后鼻部或难控制出血病人尽快转入耳鼻喉专科进一步处理。

**注意事项 / Precautions**
- 高血压老年人的后鼻部出血通常更难控制。
- 肝病或凝血障碍可使鼻出血更重,需同步评估基础病。
- 升级填塞前后都要持续观察循环状态和失血情况。

**量化指标 / Metrics**
- 填塞止血成功率
- 难治性鼻出血专科转诊率
- 24 小时内再出血率
