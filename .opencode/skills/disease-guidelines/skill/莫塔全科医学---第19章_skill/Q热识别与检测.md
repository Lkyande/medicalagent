# Skill: Q热识别与检测

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“Q热”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
在屠宰场或农业暴露背景下识别 Q 热,并启动合适的实验室检测。

**适用范围 / Scope**
- 突然发热、寒战、肌痛、头痛或干咳的职业暴露人群

**操作步骤 / Procedure**
1. 询问屠宰场、农场、猎人或家畜接触等暴露史。
2. 识别发热、寒战、肌痛、头痛、干咳和可能的腹痛。
3. 对持续感染者警惕肺炎、肝炎或血培养阴性的心内膜炎。
4. 安排急性期及 2~3 周后血清学,观察抗体 4 倍升高。
5. 同步考虑伯氏立克次体 PCR 检测并按重症程度转诊。

**注意事项 / Precautions**
- 皮疹不是 Q 热主要特征。
- 未治疗慢性感染可致命。
- 瓣膜病病人持续感染时心内膜炎风险更高。

**量化指标 / Metrics**
- 屠宰场或农牧暴露病例 Q 热筛查率
- 双份血清学随访完成率
- 持续感染转诊率
