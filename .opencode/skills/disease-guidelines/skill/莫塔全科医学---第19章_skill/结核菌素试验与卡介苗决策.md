# Skill: 结核菌素试验与卡介苗决策

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“结核菌素(芒图)试验和卡介苗接种”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
根据结核菌素试验结果辅助结核感染判断并指导卡介苗接种决策。

**适用范围 / Scope**
- 计划卡介苗接种者或需结核感染筛查者

**操作步骤 / Procedure**
1. 在 6 月龄以上拟接种卡介苗者接种前安排结核菌素皮试。
2. 于 48~72 小时读取硬结直径并记录具体毫米数。
3. 结合免疫状态、密切接触史和 HIV 风险解释 >5mm 或 >10mm 的意义。
4. 对硬结 <5mm 者可考虑接种卡介苗,>5mm 者不予接种。
5. 对阳性结果者区分感染提示与活动性疾病,必要时进一步评估而非直接下活动性诊断。

**注意事项 / Precautions**
- 该试验不是活动性结核确诊试验。
- 活跃肺部感染时可出现假阴性。
- 免疫低下者和密切接触者对较小硬结也需提高警惕。

**量化指标 / Metrics**
- 卡介苗接种前皮试完成率
- 皮试结果毫米数记录完整率
- 阳性皮试进一步评估率
