# Skill: 破伤风识别与急转

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“破伤风”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
在创伤后或无明确伤口病人中识别破伤风的典型神经肌肉表现并立即转诊。

**适用范围 / Scope**
- 牙关紧闭、肌痉挛、角弓反张或最小刺激诱发痉挛者

**操作步骤 / Procedure**
1. 追问近期伤口、污染创面、分娩或脐带残端感染史,即使病人记忆不清也不排除。
2. 识别发热、不适、头痛等前驱表现。
3. 检查牙关紧闭、苦笑面容、角弓反张和刺激诱发痉挛。
4. 立即给予破伤风抗毒素和人破伤风免疫球蛋白路径评估。
5. 紧急送往专科中心,必要时准备气管插管和机械通气。

**注意事项 / Precautions**
- 10%~20% 病人无可识别伤口。
- 鉴别包括吩噻嗪中毒、马钱子碱中毒、狂犬病和牙脓肿。
- 新生儿和产妇相关病例尤其严重。

**量化指标 / Metrics**
- 可疑破伤风急诊转诊时效
- 破伤风免疫球蛋白及时启动率
- 痉挛综合征病例破伤风纳入鉴别率
