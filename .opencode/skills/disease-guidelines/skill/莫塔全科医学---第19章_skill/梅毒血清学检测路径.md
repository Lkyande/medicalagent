# Skill: 梅毒血清学检测路径

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“诊断”“血清学”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
针对疑似梅毒病人合理选择非特异性和特异性实验室检测。

**适用范围 / Scope**
- 有梅毒可疑病损、皮疹或无症状血清筛查阳性者

**操作步骤 / Procedure**
1. 对有可疑早期病损者优先考虑暗视野检查或直接涂片检测条件。
2. 首先安排 VDRL 或 RPR 作为筛查性非特异检查。
3. 同步或随后安排梅毒螺旋体特异性试验进行确认。
4. 对复杂病例或神经系统受累者考虑 PCR,必要时检测脑脊液。
5. 结合病史和体检解释结果,避免仅凭单一化验下诊断。

**注意事项 / Precautions**
- 无症状梅毒主要依赖血清学诊断。
- HIV 合并梅毒时可出现血清学假阴性。
- 需同步考虑共存其他性传播疾病。

**量化指标 / Metrics**
- 梅毒可疑病例双路径检测完成率
- 筛查阳性确认试验完成率
- 复杂病例 PCR 或 CSF 评估率
