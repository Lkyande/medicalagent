# Skill: 布鲁氏菌病识别与检测

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“布鲁氏菌病”“临床特征”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
在长期发热和职业或乳制品暴露背景下识别布鲁氏菌病并完成关键检测。

**适用范围 / Scope**
- 波状热、不适、头痛或长期发热性疾病病人

**操作步骤 / Procedure**
1. 询问生奶摄入、牲畜接触及皮肤伤口污染史。
2. 识别起病隐匿、不适、头痛、虚弱和波状热等表现。
3. 检查是否有关节痛、淋巴结肿大、肝脾大和脊柱压痛。
4. 急性发热期安排血培养、布鲁氏菌凝集试验双份血清及 PCR。
5. 对并发睾丸附睾炎、骨髓炎或心内膜炎者尽早转专科处理。

**注意事项 / Precautions**
- 血培养急性期阳性率约 50%。
- 慢性布鲁氏菌病可酷似慢性疲劳综合征。
- 复发约 10%,需警惕疗程不足。

**量化指标 / Metrics**
- 波状热病例布鲁氏菌病筛查率
- 双份血清学采集完整率
- 可疑病例 PCR 完成率
