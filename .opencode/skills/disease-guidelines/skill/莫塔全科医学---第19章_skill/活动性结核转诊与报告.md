# Skill: 活动性结核转诊与报告

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“管理和治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
在疑似或确诊活动性结核时尽快完成专科转诊、公共卫生报告和基础支持。

**适用范围 / Scope**
- 疑似或确诊活动性肺结核及肺外结核病人

**操作步骤 / Procedure**
1. 一旦病史、影像或病原学提示结核,立即联系有经验的专科团队。
2. 明确 HIV 评估、耐药风险和治疗依从性风险。
3. 将病人转入标准短程抗结核治疗路径,避免自行长期零散给药。
4. 向当地相关机构或公共卫生系统报告病例。
5. 向病人提供促进健康生活方式和依从性支持的指导。

**注意事项 / Precautions**
- MDR-TB 对免疫低下者更具侵袭性。
- DOT 或 DOTS+ 对依从性差和耐药风险高者很重要。
- 药物不良反应需专科监测,异烟肼成人常需补充维生素 B6。

**量化指标 / Metrics**
- 活动性结核专科转诊时效
- 结核病例公共卫生报告完成率
- 抗结核治疗依从性随访率
