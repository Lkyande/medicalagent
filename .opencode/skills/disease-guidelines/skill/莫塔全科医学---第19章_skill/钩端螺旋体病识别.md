# Skill: 钩端螺旋体病识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“钩端螺旋体病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
在受污染尿液暴露和急性发热背景下识别钩端螺旋体病。

**适用范围 / Scope**
- 农民、奶农、肉厂工人或洪水污水暴露后急性发热者

**操作步骤 / Procedure**
1. 询问猪、牛、马、大鼠、狗等动物尿液污染伤口或黏膜接触史。
2. 识别发热、寒战、不适、剧烈头痛和胸痛等急性表现。
3. 检查斑疹和明显充血的光敏性结膜炎。
4. 对急性期后短暂缓解又再恶化者警惕进入免疫期。
5. 安排抗体滴度检测和 PCR,并根据黄疸、肾炎或脑膜炎表现紧急转诊。

**注意事项 / Precautions**
- 早期诊断有助于阻止进入高病死率的免疫期。
- 黄疸、出血和肾损害提示严重型。
- 职业暴露线索非常关键。

**量化指标 / Metrics**
- 高危职业发热病例钩体病评估率
- 可疑病例 PCR 完成率
- 严重病例住院转诊时效
