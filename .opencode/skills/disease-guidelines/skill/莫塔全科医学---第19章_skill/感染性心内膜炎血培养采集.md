# Skill: 感染性心内膜炎血培养采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“黄金法则”“辅助检查”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
在怀疑感染性心内膜炎时及时完成规范血培养采集,为后续定向治疗提供依据。

**适用范围 / Scope**
- 疑似急性或亚急性感染性心内膜炎病人

**操作步骤 / Procedure**
1. 遵循发热合并心脏杂音先做血培养的原则。
2. 在开始经验性抗菌治疗前采集至少 3 组血培养,包括需氧和厌氧瓶。
3. 住院后尽可能在 1 小时内送 4 次血培养给实验室。
4. 同步安排全血细胞计数、ESR、尿检、超声心动图和炎症指标。
5. 完成培养后尽快启动经验性静脉抗菌治疗并联系专科团队。

**注意事项 / Precautions**
- 血培养阳性率约 75%,但前提是采样规范。
- 经食管超声较经胸超声更敏感。
- 不能因等待全部结果而延迟暴发性感染治疗。

**量化指标 / Metrics**
- 疑似心内膜炎血培养先于抗生素完成率
- 3 组以上血培养采集率
- 血培养送检到抗菌治疗间隔时间
