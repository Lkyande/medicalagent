# Skill: 气性坏疽紧急处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“坏疽/气性坏疽”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
迅速识别气性坏疽并启动外科和抗菌联合急救流程。

**适用范围 / Scope**
- 严重创伤或污染创面后突发疼痛、肿胀和全身中毒表现者

**操作步骤 / Procedure**
1. 识别污染创面后突然加重的疼痛和肿胀。
2. 检查褐色浆液性渗出以及触诊或 X 线可见组织内气体。
3. 评估虚脱、全身中毒反应和循环衰竭迹象。
4. 立即转运手术中心行清创,不等待病情完全明确。
5. 同步启动静脉青霉素加克林霉素,条件允许时考虑高压氧。

**注意事项 / Precautions**
- 气性坏疽进展极快,误时可致命。
- 单纯皮肤感染与深部肌坏死需及时区分。
- 以外科清创为核心,抗菌药不能替代手术。

**量化指标 / Metrics**
- 可疑气性坏疽到手术转运时间
- 抗菌治疗启动时效
- 组织内气体影像记录率
