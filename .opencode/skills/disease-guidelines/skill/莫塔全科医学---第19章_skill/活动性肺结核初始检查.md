# Skill: 活动性肺结核初始检查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“结核病”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
对疑似活动性肺结核病人完成规范的初始影像和病原学检查。

**适用范围 / Scope**
- 持续咳嗽、咯血、胸痛、消瘦或胸片可疑结核者

**操作步骤 / Procedure**
1. 先基于症状和流行病学背景建立对活动性结核的临床怀疑。
2. 安排胸部 X 线检查,若可疑或复杂则进一步行 CT。
3. 连续 3 日留取 3 份痰标本,其中至少 1 份为清晨样本。
4. 申请抗酸杆菌染色、培养及必要时 NAAT/PCR 检测。
5. 痰难以获得时考虑支气管镜或胃液抽吸,并尽早转结核专科。

**注意事项 / Precautions**
- 培养需时 6~8 周,但仍是关键检查。
- PCR 速度快但敏感性不如培养,不能完全替代培养。
- 肺外病灶可能需要病变组织或淋巴结活检。

**量化指标 / Metrics**
- 疑似肺结核 3 份痰标本完成率
- 可疑胸片进一步 CT 完成率
- 疑似病例病原学送检率
