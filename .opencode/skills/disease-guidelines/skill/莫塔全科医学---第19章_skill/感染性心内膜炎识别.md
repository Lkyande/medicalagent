# Skill: 感染性心内膜炎识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“感染性心内膜炎”“发展成心内膜炎的警示征象”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
在发热病人中及时识别感染性心内膜炎的高危背景和典型警示征象。

**适用范围 / Scope**
- 不明原因发热、心脏杂音或栓塞表现病人

**操作步骤 / Procedure**
1. 询问既往瓣膜病、人工瓣膜、先天性心脏病、静脉药物使用和导管史。
2. 检查是否存在新的杂音或原有杂音性质改变。
3. 识别不明原因发热合并心脏杂音这一高警示组合。
4. 追问近期侵入性操作、牙科处理或术后发热病史。
5. 对合并栓塞征象、贫血、持续疼痛或亚急性病程者提高怀疑并转入检查流程。

**注意事项 / Precautions**
- 仅约半数病人既往已知有心脏病。
- 静脉药物使用者可无杂音而以三尖瓣感染出现。
- 诊断延迟与高病死率密切相关。

**量化指标 / Metrics**
- 发热伴杂音病例心内膜炎评估率
- 高危病史记录完整率
- 疑似病例专科转诊时效
