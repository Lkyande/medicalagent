# Skill: 人畜共患病暴露史采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“人畜共患病”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
通过系统暴露史采集提高人畜共患病的识别率。

**适用范围 / Scope**
- 未明原因发热、出汗、非典型肺炎、皮疹或关节炎病人

**操作步骤 / Procedure**
1. 对未确诊发热病人常规追问动物接触史和相关职业。
2. 询问境内外旅行、蜱或蚊虫叮咬、猫抓或动物咬伤史。
3. 评估是否饮用生牛奶或接触未经消毒乳制品。
4. 结合肉厂工人、农民、鸟类爱好者等职业暴露缩小范围。
5. 根据暴露类型将 Q 热、钩端螺旋体病、鹦鹉热、布鲁氏菌病等纳入鉴别。

**注意事项 / Precautions**
- 忽视暴露史是漏诊人畜共患病的重要原因。
- 流感样症状合并非典型肺炎时尤其应考虑此类疾病。
- 许多病例病程迁延、症状不重,但后遗症可能明显。

**量化指标 / Metrics**
- 未明发热病例动物暴露史记录率
- 非典型肺炎病例职业暴露史记录率
- 人畜共患病纳入鉴别比例
