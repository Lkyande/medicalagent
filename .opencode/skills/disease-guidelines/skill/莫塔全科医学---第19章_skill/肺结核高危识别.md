# Skill: 肺结核高危识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“结核病”“高危人群/情况”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
在隐匿性呼吸道或全身症状病人中识别结核病高危背景,提高早期怀疑度。

**适用范围 / Scope**
- 咳嗽、消瘦、低热、夜汗或来源不明慢性不适者

**操作步骤 / Procedure**
1. 询问是否来自结核高流行地区或与流行地区人员密切接触。
2. 识别新生儿、婴幼儿、老年人、HIV 感染者和糖尿病病人等高危人群。
3. 评估拥挤居住环境、卫生条件差、酒精或药物滥用等社会危险因素。
4. 若存在慢性咳嗽、体重减轻、低热或夜间盗汗,将结核纳入优先鉴别诊断。
5. 对高危且症状匹配者尽早安排影像和病原学检查并考虑专科转诊。

**注意事项 / Precautions**
- 肺外结核和再活化结核可缺乏典型肺部体征。
- 即使疾病晚期也可能症状轻微或缺乏体征。
- 看到结核时应同步考虑 HIV 风险评估。

**量化指标 / Metrics**
- 慢性咳嗽病人结核风险因素记录率
- 结核高危病人进一步检查完成率
- 高危病例首诊纳入结核鉴别比例
