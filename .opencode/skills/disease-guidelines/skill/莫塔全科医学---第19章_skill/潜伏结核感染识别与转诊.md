# Skill: 潜伏结核感染识别与转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“潜伏结核感染”“儿童结核病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
识别无活动性疾病证据但存在结核感染风险的人群,并转专科评估预防性治疗。

**适用范围 / Scope**
- 结核密切接触者、来自高流行地区儿童或免疫受损高风险人群

**操作步骤 / Procedure**
1. 识别有明确结核暴露但当前无活动性结核表现的人群。
2. 结合年龄、居住地、免疫状态和 HIV 风险评估再活化可能性。
3. 安排结核菌素皮试或 IGRA 作为感染识别工具。
4. 排除活动性结核证据后,转结核专科评估预防性治疗。
5. 对儿童密切接触者尤其重视随访和异烟肼方案依从性。

**注意事项 / Precautions**
- LTBI 无传播能力,但宿主免疫下降后可再活化。
- 发展中国家居住或来源儿童中 LTBI 常见。
- 预防治疗方案应由结核专科医生制订。

**量化指标 / Metrics**
- 结核密切接触者 LTBI 筛查率
- LTBI 专科转诊完成率
- 预防治疗启动率
