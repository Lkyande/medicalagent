# Skill: 一期梅毒识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“梅毒”“一期梅毒”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
识别一期梅毒的典型硬下疳和区域淋巴结体征,避免将其误判为良性溃疡。

**适用范围 / Scope**
- 生殖器、口腔或肛门直肠无痛性溃疡病人

**操作步骤 / Procedure**
1. 询问近 3 个月性接触史及性传播感染风险。
2. 检查病灶是否为坚硬、无痛、清洁且突出的硬下疳。
3. 触诊邻近淋巴结是否为离散性肿大、质硬且不破溃。
4. 对任何肛门直肠溃疡或疮先纳入梅毒鉴别,除非有明确其他证据。
5. 立即进入梅毒实验室检测和性伴侣评估流程。

**注意事项 / Precautions**
- 早期病灶可在 4 周内自行消退,并不代表痊愈。
- 口腔和肛门直肠病损尤其容易漏诊。
- HIV 与梅毒常相关联,应同步评估。

**量化指标 / Metrics**
- 无痛性溃疡病人梅毒纳入鉴别率
- 一期可疑病灶血清学送检率
- 合并 HIV 筛查率
