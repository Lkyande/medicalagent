# Skill: 鹦鹉热识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“鹦鹉热”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
在鸟类接触史和非典型肺炎表现中识别鹦鹉热。

**适用范围 / Scope**
- 鸟类爱好者或禽类接触者出现发热、头痛和干咳者

**操作步骤 / Procedure**
1. 询问鹦鹉、鸽子、鸭子等鸟类接触和清理鸟粪史。
2. 识别发热、不适、肌痛、头痛和干咳为主的表现。
3. 注意胸部体征可能很少,但病程可迁延。
4. 安排胸部 X 线以及血清学和 PCR 检查。
5. 对病情重或住院肺炎者尽早覆盖相应非典型病原体治疗并转诊。

**注意事项 / Precautions**
- 除鸟类接触史外,与其他非典型肺炎较难区分。
- 不治疗病死率可达 20%。
- 病程既可急性,也可缓慢迁延数月。

**量化指标 / Metrics**
- 非典型肺炎病例鸟类暴露史记录率
- 鹦鹉热血清学或 PCR 送检率
- 重症病例及时治疗率
