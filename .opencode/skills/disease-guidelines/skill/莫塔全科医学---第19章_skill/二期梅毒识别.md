# Skill: 二期梅毒识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“二期梅毒”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
在多样化皮疹和全身症状病人中识别二期梅毒的典型组合。

**适用范围 / Scope**
- 发热、不适伴广泛皮疹,尤其累及掌跖者

**操作步骤 / Procedure**
1. 追问近期是否曾有自行消退的无痛性生殖器或口腔溃疡。
2. 识别发热、头痛、不适、全身酸痛等全身症状。
3. 检查是否存在对称、广泛、铜红色斑丘疹,特别是掌跖受累。
4. 牢记除水疱外二期梅毒几乎可模拟多种皮肤病。
5. 对可疑病例立即安排梅毒血清学并同步评估其他性传播感染。

**注意事项 / Precautions**
- 二期梅毒常因皮疹多样而被误诊。
- 皮疹可无瘙痒、无压痛。
- HIV 合并感染时表现和血清学可能不典型。

**量化指标 / Metrics**
- 掌跖皮疹病例梅毒筛查率
- 二期梅毒识别后 STI 联合评估率
- 可疑病例实验室确证率
