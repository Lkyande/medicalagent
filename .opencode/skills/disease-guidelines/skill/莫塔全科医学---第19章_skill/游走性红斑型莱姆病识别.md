# Skill: 游走性红斑型莱姆病识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“莱姆病和莱姆样病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
识别蜱暴露后具有特征性的游走性红斑,及时考虑莱姆病专科评估。

**适用范围 / Scope**
- 蜱叮咬后出现环形红斑、流感样症状或后续神经心脏关节表现者

**操作步骤 / Procedure**
1. 追问近期林地或灌木丛暴露及蜱叮咬史。
2. 检查是否存在以咬伤部位为中心、边界清楚的环形红斑。
3. 结合流感样症状判断是否处于早期阶段。
4. 对出现肢体无力、心脏问题或关节炎者评估疾病分期。
5. 安排血清学和 PCR,并寻求感染科专家意见。

**注意事项 / Precautions**
- 澳大利亚本地并非常见流行区,但旅行者可散发出现。
- 游走性红斑是最有特征性的临床标志。
- 首要处理之一是规范移除蜱虫。

**量化指标 / Metrics**
- 蜱叮咬后皮疹病例莱姆病考虑率
- 游走性红斑图片或描述记录率
- 感染科转诊完成率
