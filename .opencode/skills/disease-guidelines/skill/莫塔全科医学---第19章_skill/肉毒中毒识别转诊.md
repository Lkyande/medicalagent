# Skill: 肉毒中毒识别转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“肉毒中毒”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
识别食源性或伤口性肉毒中毒的早期脑神经麻痹表现并立即转入强化治疗路径。

**适用范围 / Scope**
- 可疑罐装或真空包装食物摄入后出现复视或进行性无力者

**操作步骤 / Procedure**
1. 询问 12~36 小时内家庭罐装、烟熏或真空包装食品摄入史。
2. 识别突然复视等视觉问题及其他脑神经麻痹表现。
3. 对感觉正常但脑神经受累者高度怀疑肉毒中毒。
4. 评估全身肌无力和呼吸衰竭风险。
5. 立即转诊并启动抗毒素治疗和 ICU 支持准备。

**注意事项 / Precautions**
- 婴儿肉毒中毒和伤口来源病例也需考虑。
- 全身麻痹和衰竭可迅速进展。
- 感觉系统相对正常是重要线索。

**量化指标 / Metrics**
- 可疑肉毒中毒识别到转诊时间
- 食物暴露史记录率
- 呼吸支持评估完成率
