# Skill: 李斯特菌高危感染识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“李斯特菌病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
识别高危宿主中的李斯特菌感染风险和典型暴露来源。

**适用范围 / Scope**
- 孕妇、新生儿、老年人、免疫低下者出现轻热、败血症或脑膜炎表现时

**操作步骤 / Procedure**
1. 识别高危人群,尤其是孕妇、胎儿、新生儿、老年人和免疫低下者。
2. 询问软奶酪、未消毒牛奶、加工肉类和熏制海产品摄入史。
3. 对轻度流感样表现、非典型胃肠炎、脑膜炎或败血症提高警惕。
4. 安排血液或感染部位标本的镜检、培养或 PCR。
5. 对妊娠相关病例或中枢神经系统受累者紧急转诊治疗。

**注意事项 / Precautions**
- 李斯特菌可导致死产或流产。
- 许多病例症状轻微,但高危宿主病死率高。
- 食源性暴露询问非常关键。

**量化指标 / Metrics**
- 高危宿主食物暴露史记录率
- 可疑李斯特菌病例培养或 PCR 送检率
- 妊娠相关疑似病例转诊时效
