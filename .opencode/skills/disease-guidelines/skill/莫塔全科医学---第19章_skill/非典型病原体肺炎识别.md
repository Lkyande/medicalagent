# Skill: 非典型病原体肺炎识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第19章 令人困惑的细菌感染
- 页码: 第19章“非典型病原体肺炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第19章.md`

**目标 / Objective**
在全身症状主导而呼吸道体征较轻的病人中识别非典型病原体肺炎。

**适用范围 / Scope**
- 发热、头痛、不适伴干咳但胸部体征轻微者

**操作步骤 / Procedure**
1. 识别“流感样表现 + 头痛 + 干咳”的典型组合。
2. 注意呼吸系统症状可轻,且缺乏肺实变体征。
3. 安排胸部 X 线,关注弥漫性浸润与查体不一致。
4. 结合年龄和暴露背景考虑支原体、军团菌、鹦鹉热或 Q 热等病原。
5. 视病情安排 PCR、尿抗原或血清学检查并启动相应经验治疗。

**注意事项 / Precautions**
- 全身症状可掩盖呼吸系统病因。
- 思维混乱、腹泻和低钠血症提示军团菌可能。
- 人畜共患病暴露史可显著改变鉴别方向。

**量化指标 / Metrics**
- 干咳伴流感样表现病例胸片完成率
- 非典型肺炎病例病原学送检率
- 军团菌高危线索记录率
