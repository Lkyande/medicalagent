# Skill: HEEADSSS心理社会筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第90章 青少年健康
- 页码: 第90章“HEEADSSS”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第90章.md`

**目标 / Objective**
系统识别青少年的家庭、教育、行为和心理健康风险因素。

**适用范围 / Scope**
- 青少年常规健康访视、心理健康咨询和复杂就诊场景

**操作步骤 / Procedure**
1. 以较不敏感到较敏感的顺序展开 HEEADSSS 访谈。
2. 依次询问家庭、教育就业、饮食运动、活动同伴、物质使用、性、自杀抑郁和安全。
3. 根据主诉和病人状态灵活选择重点,不必一次覆盖全部内容。
4. 记录风险行为、支持资源和保护因素。
5. 对高风险内容制定随访、转介或安全干预计划。

**注意事项 / Precautions**
- HEEADSSS 是指南框架,不是机械问卷。
- 青少年常希望医生主动询问性健康和心理健康问题。
- 非评判、尊重和清晰语言比“全问到”更重要。

**量化指标 / Metrics**
- HEEADSSS 关键域覆盖率
- 风险行为识别率
- 高风险问题后续干预率
