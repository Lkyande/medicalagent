# Skill: 青少年保密边界解释

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第90章 青少年健康
- 页码: 第90章“保密”“表90.1 保密原则的三个例外”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第90章.md`

**目标 / Objective**
在青少年就诊初期建立对保密原则和例外情况的清晰共同理解。

**适用范围 / Scope**
- 12 至 24 岁青少年或年轻人全科就诊场景

**操作步骤 / Procedure**
1. 在首次或敏感议题就诊前主动说明医疗保密原则。
2. 用清晰易懂语言解释记录、费用和父母不会自动获知内容的边界。
3. 明确说明三类主要例外:自杀/严重自伤风险、正在遭受伤害、可能严重伤害他人。
4. 邀请青少年提问,确认其理解和顾虑。
5. 在涉及性健康、心理健康和物质使用时再次强调保密框架。

**注意事项 / Precautions**
- 保密感是与青少年建立信任的核心前提。
- 不能承诺绝对保密,必须提前说清例外情况。
- 诊所层面的保密政策应对所有病人可见。

**量化指标 / Metrics**
- 青少年就诊保密说明记录率
- 对保密原则理解确认率
- 因保密顾虑导致中断就诊的比例
