# Skill: 青少年单独问诊安排

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第90章 青少年健康
- 页码: 第90章“谁在诊室里?谁说话?”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第90章.md`

**目标 / Objective**
在不破坏家庭关系的前提下,为青少年创造安全的单独表达空间。

**适用范围 / Scope**
- 由父母陪同就诊的青少年病人

**操作步骤 / Procedure**
1. 早期将单独谈话正常化,向家长解释这是青少年看诊的常规环节。
2. 征得青少年和家长同意后,请家长暂时离开诊室。
3. 在单独谈话前后明确哪些内容可或不可与家长分享。
4. 用尊重、开放和非控制式态度与青少年建立信任。
5. 谈话结束后请家长回到诊室,只分享经青少年允许或法律要求的信息。

**注意事项 / Precautions**
- 过度代言的家长会削弱青少年的表达空间。
- 必须预先说明保密和例外情况。
- 对高度焦虑或专横家长需更谨慎协商。

**量化指标 / Metrics**
- 陪同就诊青少年的单独谈话实施率
- 谈话后青少年表达满意度
- 家长接受度
