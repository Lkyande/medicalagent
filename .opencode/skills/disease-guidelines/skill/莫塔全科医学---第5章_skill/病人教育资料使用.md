# Skill: 病人教育资料使用

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第5章 健康促进与病人教育
- 页码: 第5章“病人教育资源”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第5章.md`

**目标 / Objective**
把书面教育资料作为口头解释的补充,增强病人对健康行为改变和疾病管理的理解与执行。

**适用范围 / Scope**
- 需要强化口头宣教的门诊咨询、慢病管理和行为改变干预

**操作步骤 / Procedure**
1. 先进行针对性的口头解释,明确本次最重要的教育目标。
2. 根据病人问题选择匹配的书面资料、图表或打印材料。
3. 向病人说明资料中最关键的部分,而不是简单发放后结束。
4. 结合病人的检查结果或具体疾病情境强化说明。
5. 在后续随访时询问病人是否阅读、理解并按资料执行。

**注意事项 / Precautions**
- 书面资料不能替代面对面解释。
- 资料必须简洁、可信且适合病人的识字水平和语言背景。
- 对焦虑、认知受限或文化差异明显者需额外确认理解程度。

**量化指标 / Metrics**
- 教育资料发放率
- 病人理解与使用率
- 相关健康行为改善率
