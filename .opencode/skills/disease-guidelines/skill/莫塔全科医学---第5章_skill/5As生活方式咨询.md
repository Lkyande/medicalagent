# Skill: 5As生活方式咨询

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第5章 健康促进与病人教育
- 页码: 第5章“5As式咨询”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第5章.md`

**目标 / Objective**
用 5As 模型系统推进生活方式改变咨询,从识别风险到安排后续支持形成闭环。

**适用范围 / Scope**
- 吸烟、营养、饮酒和身体活动等行为改变咨询

**操作步骤 / Procedure**
1. `询问`：识别存在危险因素的病人。
2. `评估`：判断危险因素水平、健康相关性以及病人的改变动机和就绪度。
3. `建议`：提供明确、个体化的书面信息和生活方式干预建议。
4. `帮助`：根据需要提供药物治疗、自我监测工具或实际支持策略。
5. `安排`：转诊相关服务、社会支持团体、电话咨询服务,并安排全科随访。

**注意事项 / Precautions**
- 评估改变就绪度是关键,不可对尚未准备改变者强行推进。
- 建议应具体可执行,避免空泛说教。
- 安排阶段若没有随访或转介落地,咨询效果往往难以维持。

**量化指标 / Metrics**
- 5As 五步完成率
- 行为改变目标设定率
- 随访到诊或转介完成率
