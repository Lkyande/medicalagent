# Skill: 社会心理健康促进咨询

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第5章 健康促进与病人教育
- 页码: 第5章“促进社会心理健康”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第5章.md`

**目标 / Objective**
在全科接诊中主动识别和干预心理社会风险,把健康促进延伸到情绪与关系领域。

**适用范围 / Scope**
- 压力、焦虑、丧亲、人际关系紧张、自杀风险或复杂社会心理问题病人

**操作步骤 / Procedure**
1. 在常规问诊中主动筛查压力、焦虑、抑郁和人际关系恶化等问题。
2. 对自杀倾向、家庭虐待、儿童行为问题和欺凌等高风险问题进一步评估。
3. 花时间提供初步咨询和问题处理建议。
4. 强调识别潜在问题和早期求助的重要性。
5. 对复杂个案安排随访、转诊或多学科支持。

**注意事项 / Precautions**
- 社会心理问题常较复杂,不能以简单建议替代系统评估。
- 对自杀风险、家庭暴力和儿童安全问题应优先保障安全。
- 医生需注意自身时间和能力边界,必要时及时转介。

**量化指标 / Metrics**
- 社会心理风险筛查率
- 高风险个案随访/转介率
- 病人主动求助行为改善率
