# Skill: 机会性健康促进实施

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第5章 健康促进与病人教育
- 页码: 第5章“机会性的健康促进”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第5章.md`

**目标 / Objective**
在常规看诊中主动识别并利用预防和健康教育机会,而不仅限于处理当前主诉。

**适用范围 / Scope**
- 全科门诊所有就诊场景,尤其慢病复诊、家庭随访和多次接触病人时

**操作步骤 / Procedure**
1. 在处理主诉后,快速判断本次是否存在可利用的预防或健康教育机会。
2. 区分仅对主诉作反应式处理,还是需要补充主动式健康促进服务。
3. 主动检查持续存在的健康问题,如血压、糖尿病控制或丧亲支持随访。
4. 必要时补充筛查、预防建议或早期探查措施。
5. 纠正异常寻医行为,包括长期不就诊或过度频繁就诊。
6. 将需持续跟进的项目纳入病历、召回或转诊协调系统。

**注意事项 / Precautions**
- 机会性健康促进不应粗暴插入,需结合病人当次问题和接受程度。
- 在急性病情、情绪危机或严重不适时,应优先处理当前安全问题。
- 对健康不公平人群要更积极识别机会,避免因接触不足而漏掉预防服务。

**量化指标 / Metrics**
- 每次看诊触发健康促进干预的比例
- 慢病随访项目补充完成率
- 召回/后续安排落实率
