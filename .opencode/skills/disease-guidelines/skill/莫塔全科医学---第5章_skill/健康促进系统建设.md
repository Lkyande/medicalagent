# Skill: 健康促进系统建设

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第5章 健康促进与病人教育
- 页码: 第5章“方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第5章.md`

**目标 / Objective**
建立支持全科持续开展健康促进的诊所级工作系统,提高预防服务覆盖率和连续性。

**适用范围 / Scope**
- 全科诊所、基层医疗团队和长期病人管理场景

**操作步骤 / Procedure**
1. 持续参加继续医学教育,定期更新预防和健康促进知识。
2. 在诊所内配置健康教育资料页、墙报或候诊区多媒体内容。
3. 建立高效病历记录系统,方便记录危险因素和随访需求。
4. 实施病人登记和召回系统,特别用于异常结果和高危病人管理。
5. 主动鼓励高危人群定期进行健康检查。
6. 将营养、运动、压力管理和体重控制作为常规宣教主题。

**注意事项 / Precautions**
- 召回系统需明确责任人,避免异常结果无人跟进。
- 健康教育内容应基于可靠证据并适配本地人群。
- 系统建设不能替代个体化咨询,两者应结合。

**量化指标 / Metrics**
- 召回系统覆盖率
- 高危人群定期检查完成率
- 健康教育资料实际发放/使用率
