# Skill: NEAT生活方式指导

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第5章 健康促进与病人教育
- 页码: 第5章“NEAT 指南”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第5章.md`

**目标 / Objective**
用 NEAT 框架开展简明生活方式指导,把营养、运动、有害物质回避和减压整合到一次咨询中。

**适用范围 / Scope**
- 需要简洁生活方式教育的门诊病人,尤其压力负荷高或多重行为风险者

**操作步骤 / Procedure**
1. 评估当前饮食结构,提出健康饮食建议。
2. 评估锻炼和身体活动水平,给出可执行的活动目标。
3. 识别咖啡因、酒精、烟草、糖、盐和毒品等潜在有害物质暴露。
4. 指导病人减少或避免相关有害暴露。
5. 评估压力与情绪状态,介绍放松、冥想或减压方法。
6. 与病人约定最优先改变的 1 到 2 项生活方式目标。

**注意事项 / Precautions**
- 不要同时要求病人大幅度改变所有行为,应设定优先级。
- 对存在物质依赖或严重焦虑抑郁者,需超出一般生活方式建议进行进一步管理。
- 减压建议需结合病人的实际生活资源,避免脱离现实。

**量化指标 / Metrics**
- NEAT 四项评估完成率
- 生活方式目标达成率
- 自评压力改善情况
