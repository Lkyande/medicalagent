# Skill: 低GI饮食教育

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第5章 健康促进与病人教育
- 页码: 第5章“升糖指数”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第5章.md`

**目标 / Objective**
帮助病人理解升糖指数概念并优先选择低 GI 食物以改善血糖控制。

**适用范围 / Scope**
- 糖尿病、糖耐量异常、代谢综合征和需要血糖管理的病人

**操作步骤 / Procedure**
1. 向病人解释 GI 反映食物升高餐后血糖的能力,葡萄糖为 100 的参考值。
2. 说明高 GI 食物会带来更高血糖和胰岛素反应。
3. 推荐优先选择低 GI 食物,如高密度全麦面包、麦片粥、大多数新鲜水果、酸奶和低脂牛奶。
4. 提醒减少高 GI 食物摄入,如白面包、白米饭、甜谷物、土豆和饼干。
5. 将 GI 教育与整体营养方案结合,而非单独依赖 GI 一个指标。

**注意事项 / Precautions**
- GI 只是饮食评估的一部分,不能忽略总热量和整体食物质量。
- 个体反应可能不同,应结合血糖监测调整。
- 对儿童和营养不良者不宜片面强调限制性饮食。

**量化指标 / Metrics**
- 低GI食物替换率
- 餐后血糖改善情况
- 病人对GI概念理解率
