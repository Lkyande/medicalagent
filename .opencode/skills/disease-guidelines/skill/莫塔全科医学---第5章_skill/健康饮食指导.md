# Skill: 健康饮食指导

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第5章 健康促进与病人教育
- 页码: 第5章“最佳营养的通用原则”“健康饮食的归纳”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第5章.md`

**目标 / Objective**
基于通用营养原则为病人提供简明、可执行的健康饮食建议,降低慢病风险。

**适用范围 / Scope**
- 一般成人健康管理、心血管代谢风险人群和长期生活方式管理

**操作步骤 / Procedure**
1. 鼓励每日摄入多样食物,尤其蔬菜、水果、全谷物和豆类。
2. 建议适量摄入瘦肉、鱼、蛋、低脂奶制品和替代品。
3. 建议多饮水,减少含糖饮料摄入。
4. 限制饱和脂肪、反式脂肪、盐、添加糖和加工肉类。
5. 鼓励每周至少吃鱼,优先不饱和脂肪来源。
6. 根据 BMI、胆固醇和慢病风险,个体化设定饮食调整重点。

**注意事项 / Precautions**
- 儿童、孕妇和特殊疾病人群的饮食要求可能不同,不能简单套用通用建议。
- 饮食建议应考虑文化习惯、经济条件和烹饪可行性。
- 过于严格复杂的饮食方案通常依从性较差。

**量化指标 / Metrics**
- 蔬菜水果达标率
- 含糖饮料和加工肉摄入减少率
- BMI、血脂或血糖改善情况
