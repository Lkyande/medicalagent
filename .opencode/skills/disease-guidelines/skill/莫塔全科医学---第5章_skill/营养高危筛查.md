# Skill: 营养高危筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第5章 健康促进与病人教育
- 页码: 第5章“营养评估”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第5章.md`

**目标 / Objective**
尽早识别营养不足或营养相关问题的高危病人,触发进一步营养评估和干预。

**适用范围 / Scope**
- 肥胖、慢性病、老年人、创伤、长期住院、饮食失调和术后病人

**操作步骤 / Procedure**
1. 先识别是否属于营养高危人群,包括肥胖、慢病、心理障碍、老年和长期住院者。
2. 采集 24 小时饮食回顾,必要时辅以症状问卷。
3. 评估日光照射情况和生活环境因素。
4. 进行营养查体,重点看体重、腰围、肌肉萎缩、脂肪储备和微量营养素缺乏体征。
5. 根据临床表现选择性安排实验室检查。
6. 将高危病人纳入营养随访或转介营养支持。

**注意事项 / Precautions**
- 单一体重数据不足以判断营养状态,需结合饮食和体征综合评估。
- 对婴幼儿和儿童应结合生长发育速度看待营养问题。
- 酒精使用障碍者常合并多种营养缺乏,需提高警惕。

**量化指标 / Metrics**
- 高危营养病人识别率
- 24小时饮食回顾完成率
- 营养随访/转介落实率
