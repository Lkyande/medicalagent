# Skill: 营养缺乏体征检查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第5章 健康促进与病人教育
- 页码: 第5章“营养评估”“维生素缺乏”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第5章.md`

**目标 / Objective**
通过查体和线索识别常见营养素缺乏表现,提高营养相关疾病的临床发现率。

**适用范围 / Scope**
- 营养不良、酒精使用障碍、慢病、老年人和生长发育异常病人

**操作步骤 / Procedure**
1. 评估体重变化、肌肉量、脂肪储备和全身状况。
2. 检查口腔、牙龈、牙齿和颊黏膜,识别 B 族维生素或维生素 C 缺乏线索。
3. 关注味觉、嗅觉、皮肤和神经系统表现,筛查锌、B6 和 B12 缺乏。
4. 评估骨骼、关节、骨痛和畸形,识别维生素 D、C 缺乏相关问题。
5. 对可疑缺乏情况结合实验室检查进一步确认。

**注意事项 / Precautions**
- 多种营养缺乏可同时存在,不能只寻找单一缺乏。
- 老年人和慢性酒精中毒病人的症状常不典型。
- 营养补充前应尽量明确缺乏类型,避免盲目高剂量补充。

**量化指标 / Metrics**
- 可疑营养缺乏识别率
- 查体与实验室结果一致率
- 明确缺乏后的干预启动率
