# Skill: SNAP危险因素评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第5章 健康促进与病人教育
- 页码: 第5章“SNAP 指南”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第5章.md`

**目标 / Objective**
通过 SNAP 框架系统识别病人的生活方式危险因素,为后续行为干预提供结构化入口。

**适用范围 / Scope**
- 成人和青少年门诊、慢病管理、体检和机会性健康促进场景

**操作步骤 / Procedure**
1. 依次询问吸烟、营养、饮酒和身体活动四类危险因素。
2. 记录每项危险因素当前水平和持续时间。
3. 识别危险因素与病人现有疾病或未来风险之间的关联。
4. 特别关注社会经济弱势和健康不公平人群中的高危行为聚集。
5. 将识别出的 SNAP 因素纳入病历问题清单和后续干预计划。

**注意事项 / Precautions**
- 评估应具体量化,避免只写“饮食差”或“缺乏运动”这类模糊结论。
- 谈及吸烟和饮酒时要避免指责语气,以免削弱后续改变意愿。
- 对孕妇、青少年和原住民等特定人群需使用更适配的风险解释方式。

**量化指标 / Metrics**
- SNAP 四项完整评估率
- 高危行为识别率
- 危险因素与疾病关联记录率
