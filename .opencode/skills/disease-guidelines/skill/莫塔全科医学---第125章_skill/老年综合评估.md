# Skill: 老年综合评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第125章 老年病人
- 页码: 第125章“老年病人健康评估”“病史”“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第125章.md`

**目标 / Objective**
从功能、认知、情绪和多病共存角度完成老年病人的综合健康评估。

**适用范围 / Scope**
- 65 岁及以上初诊或健康状况恶化的老年病人

**操作步骤 / Procedure**
1. 系统采集既往病史、用药、家庭支持、步行能力、饮食、排泄、睡眠和情感状态。
2. 检查外观、认知、视听、口腔、心肺、腹部、下肢循环、足部和步态平衡。
3. 关注跌倒、失禁、抑郁、孤单感和多重用药问题。
4. 在需要时结合家庭成员和问卷获取补充信息。
5. 根据评估结果制定连续随访和支持计划。

**注意事项 / Precautions**
- 老年人常以非特异症状表现严重疾病。
- 失用是功能退化的重要可干预因素。
- 多病共存和多重用药是管理重点。

**量化指标 / Metrics**
- 老年综合评估完成率
- 功能与认知记录率
- 多重用药识别率
