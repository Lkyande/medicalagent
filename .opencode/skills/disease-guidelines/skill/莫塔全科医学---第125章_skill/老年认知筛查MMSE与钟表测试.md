# Skill: 老年认知筛查MMSE与钟表测试

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第125章 老年病人
- 页码: 第125章“简易精神状态检查”“认知障碍10步快速测验”“钟面绘图测试”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第125章.md`

**目标 / Objective**
在全科环境中快速筛查老年人的认知障碍和痴呆风险。

**适用范围 / Scope**
- 记忆下降、行为改变、跌倒或功能退化的老年病人

**操作步骤 / Procedure**
1. 先以病史和总体交流观察判断认知异常可能。
2. 使用 MMSE 或认知障碍 10 步快速测验进行标准化筛查。
3. 辅以钟面绘图测试评估执行功能和空间能力。
4. 结合家属观察到的问题进行综合解释。
5. 对筛查异常者安排进一步痴呆与谵妄鉴别和长期管理评估。

**注意事项 / Precautions**
- 记忆困难是痴呆最有价值的单项线索之一。
- 抑郁、谵妄和听力视力问题可影响测试结果。
- 单次量表不能替代完整诊断。

**量化指标 / Metrics**
- 认知筛查实施率
- 家属补充信息获取率
- 筛查异常后进一步评估率
