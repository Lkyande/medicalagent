# Skill: 老年七条规则评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第125章 老年病人
- 页码: 第125章“评估不能自理老年病人的 7 条规则”“表125.1”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第125章.md`

**目标 / Objective**
对不能自理或状态恶化的老年病人进行快速问题清单式排查。

**适用范围 / Scope**
- 意识混乱、不能完成日常活动或不明原因健康恶化的老年病人

**操作步骤 / Procedure**
1. 按“7 条规则”评估心理状态、用药、膀胱肠道等关键领域。
2. 同步关注感染、抑郁、虐待、丧亲和照护压力。
3. 排查嗜睡、厌食、体重下降、跌倒和平衡障碍等非特异性表现。
4. 结合家属信息和基础化验寻找可逆病因。
5. 对危险问题启动住院、家庭支持或进一步专科评估。

**注意事项 / Precautions**
- 老年病人的“戴面具问题”很常见。
- 尿路感染、药物和抑郁是高频可逆原因。
- 行为异常往往是躯体病的表现而非单纯“老糊涂”。

**量化指标 / Metrics**
- 7 条规则使用率
- 可逆病因识别率
- 高危病例升级处理率
