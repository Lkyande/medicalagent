# Skill: 血尿分型与红旗转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第65章 泌尿系统疾病
- 页码: 第65章“血尿”“表65.2 血尿:诊断策略模型”“需要紧急外科干预的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第65章.md`

**目标 / Objective**
对血尿病人进行部位判断、危险分层和紧急转诊决策。

**适用范围 / Scope**
- 出现肉眼血尿、镜下血尿或反复血尿的病人

**操作步骤 / Procedure**
1. 先确认真性血尿,排除月经、甜菜根、食用色素和假性血尿。
2. 询问血尿发生于初段、终末还是全程,结合尿痛、腰痛和排尿症状定位来源。
3. 评估肿瘤、结石、感染、肾小球肾炎、创伤和抗凝药相关风险。
4. 检测血压、尿试纸、尿沉渣及尿白蛋白/肌酐比值,必要时安排影像和膀胱镜路径。
5. 对肉眼血尿、反复镜下血尿、血块潴留或伴贫血/梗阻者及时泌尿专科转诊。

**注意事项 / Precautions**
- 除月经期外,肉眼血尿都应视为异常。
- 无痛性血尿需高度警惕泌尿系肿瘤。
- 血尿虽常见,但伴血块、尿潴留或肾功能恶化时属于高危情况。

**量化指标 / Metrics**
- 血尿病人尿沉渣检查率
- 肉眼血尿影像或膀胱镜评估率
- 高危血尿专科转诊完成率
