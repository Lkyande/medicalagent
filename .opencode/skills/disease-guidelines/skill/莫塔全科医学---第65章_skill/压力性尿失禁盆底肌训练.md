# Skill: 压力性尿失禁盆底肌训练

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第65章 泌尿系统疾病
- 页码: 第65章“尿失禁”“压力性尿失禁”“盆底肌肉训练”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第65章.md`

**目标 / Objective**
对压力性尿失禁病人实施基层可执行的首选保守治疗。

**适用范围 / Scope**
- 以咳嗽、打喷嚏、运动或提重物时漏尿为主的女性病人

**操作步骤 / Procedure**
1. 确认漏尿与腹压增加相关,并排除尿路感染、明显脱垂和神经源性问题。
2. 评估症状频率、严重程度和对日常生活的影响。
3. 指导病人识别正确的盆底肌收缩动作,避免仅靠腹肌或臀肌代偿。
4. 制定规律训练计划并安排随访,强化坚持训练和减重、减少刺激饮料等辅助措施。
5. 若症状持续明显或影响生活质量,转诊进一步考虑器械或手术治疗。

**注意事项 / Precautions**
- 盆底肌训练需要持续执行才能见效。
- 合并明显盆腔器官脱垂或神经系统病变者需专科评估。
- 药物可加重尿失禁,应复核相关用药。

**量化指标 / Metrics**
- 压力性尿失禁盆底训练启动率
- 6 至 12 周症状改善率
- 随访出勤率
