# Skill: 蛋白尿ACR评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第65章 泌尿系统疾病
- 页码: 第65章“蛋白尿”“尿白蛋白/肌酐比值(ACR)”“表65.4 蛋白尿的重要病因”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第65章.md`

**目标 / Objective**
用 ACR 和临床分层识别持续性蛋白尿及潜在肾脏疾病。

**适用范围 / Scope**
- 尿试纸提示蛋白尿或慢性肾脏病高风险病人

**操作步骤 / Procedure**
1. 先确认蛋白尿是否一过性,结合发热、运动、脱水和体位因素判断。
2. 重复检测并补做尿白蛋白/肌酐比值作为基线定量评估。
3. 同步测量血压并询问糖尿病、肾病、系统性疾病和药物暴露史。
4. 若伴血尿、肾功能异常、水肿或高血压,提高对肾小球疾病和肾病综合征的警惕。
5. 对持续异常者安排肾功能检查、复测 ACR 并按风险决定肾内科转诊。

**注意事项 / Precautions**
- 运动后和发热期的蛋白尿可能是短暂性的。
- 糖尿病病人需特别关注微量白蛋白尿筛查。
- 蛋白尿合并血尿或肾功能恶化时不应延迟进一步评估。

**量化指标 / Metrics**
- 试纸蛋白尿后 ACR 复核率
- 持续性蛋白尿确认率
- 蛋白尿合并高血压或血尿的转诊率
