# Skill: 排尿困难初始评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第65章 泌尿系统疾病
- 页码: 第65章“排尿困难与尿频”“临床方法”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第65章.md`

**目标 / Objective**
对排尿困难和尿频病人进行首诊分层,快速定位感染、炎症或梗阻来源。

**适用范围 / Scope**
- 以尿痛、尿频、尿急、排尿不适或启动困难为主诉的病人

**操作步骤 / Procedure**
1. 明确疼痛时相,区分排尿初期疼痛、终末疼痛和耻骨上不适。
2. 询问尿色、尿味、分泌物、发热、寒战、性交相关史和性交痛。
3. 根据年龄和性别考虑主要病因,如女性膀胱炎、男性性传播感染或前列腺问题。
4. 检查生命体征、腹部、腰部、耻骨上区及必要的生殖器和直肠情况。
5. 完成尿试纸、尿培养,并按需加做初段尿或拭子 NAAT 检测衣原体和淋病。

**注意事项 / Precautions**
- 年轻男性出现排尿困难应高度怀疑性传播感染。
- 梗阻、发热或腰痛提示复杂性病因,不应按单纯膀胱炎处理。
- 绝经后女性需主动查找萎缩性尿道炎或尿道肉阜。

**量化指标 / Metrics**
- 排尿困难病人尿检完成率
- 性传播感染风险评估记录率
- 复杂性泌尿感染识别率
