# Skill: 女性排尿困难病因鉴别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第65章 泌尿系统疾病
- 页码: 第65章“真的是尿路感染吗”“阴道炎病人的排尿困难”“尿道综合征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第65章.md`

**目标 / Objective**
在女性排尿困难中区分膀胱炎、阴道炎、萎缩性尿道炎和尿道综合征。

**适用范围 / Scope**
- 青春期后至绝经后出现排尿困难或尿频的女性病人

**操作步骤 / Procedure**
1. 判断是否伴典型膀胱炎特征,如终末疼痛、尿频、尿急和耻骨上不适。
2. 若病人描述为“尿道口外”烧灼感或伴阴道刺激、分泌物,优先考虑阴道炎。
3. 对绝经后反复排尿不适者,检查是否存在萎缩性尿道炎、尿道肉阜或脱垂。
4. 若培养阴性但有长期下尿路症状和膀胱充盈痛,考虑尿道综合征或间质性膀胱问题。
5. 针对不同病因留取尿标本、阴道拭子或 STI 检测,并决定经验治疗或转诊。

**注意事项 / Precautions**
- 不能将所有女性排尿困难都等同于尿路感染。
- 儿童和青少年女性排尿困难更常见于阴道炎。
- 反复症状且培养阴性者需要重新考虑诊断而非重复开抗菌药。

**量化指标 / Metrics**
- 女性排尿困难盆腔或外阴评估率
- 阴道炎/STI 检测完成率
- 培养阴性重复抗菌药使用率
