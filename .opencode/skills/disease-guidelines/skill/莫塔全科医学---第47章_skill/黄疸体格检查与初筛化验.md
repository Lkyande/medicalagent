# Skill: 黄疸体格检查与初筛化验

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第47章 黄疸
- 页码: 第47章“身体检查”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第47章.md`

**目标 / Objective**
通过聚焦体格检查和首轮检查快速完成黄疸病因初步分层。

**适用范围 / Scope**
- 已确认或高度怀疑黄疸的病人

**操作步骤 / Procedure**
1. 触诊肝脏、胆囊和脾脏,判断有无肝大、压痛、可触及胆囊或脾大。
2. 查找腹水、抓痕、肝掌、蜘蛛痣、瘀斑、男性乳房发育和肌肉萎缩等慢性肝病征象。
3. 评估扑翼样震颤、肝病性口臭和意识状态,筛查肝衰竭。
4. 完成尿试纸检查,关注尿胆红素和尿胆素原变化。
5. 开具全血细胞计数、肝功能、胆红素分型、病毒血清学及肝胆超声作为首轮检查。

**注意事项 / Precautions**
- 可触及胆囊提示肝外胆道梗阻,需尽快影像评估。
- 脾大要联想到溶血、门脉高压或病毒性肝炎。
- 只看转氨酶升高不足以区分梗阻型与非梗阻型黄疸。

**量化指标 / Metrics**
- 黄疸首诊体检完整率
- 首轮实验室检查开具率
- 首次超声完成率
