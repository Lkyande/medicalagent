# Skill: Gilbert综合征识别与释疑

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第47章 黄疸
- 页码: 第47章“陷阱”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第47章.md`

**目标 / Objective**
识别 Gilbert 综合征这一常见良性非结合性高胆红素血症并避免过度治疗。

**适用范围 / Scope**
- 反复轻度黄疸或孤立性胆红素升高且整体状态稳定的病人

**操作步骤 / Procedure**
1. 识别反复轻度黄疸而无明显系统毒性或进行性病程的病人。
2. 结合胆红素分型确认以非结合胆红素升高为主。
3. 复核肝功能其他指标是否基本正常,并排除溶血证据。
4. 排除其他肝胆疾病、药物性损伤和梗阻性黄疸线索。
5. 向病人解释该病常见且通常无需治疗,重点做好随访和释疑。

**注意事项 / Precautions**
- 在确认良性前必须先排除溶血和器质性肝胆病。
- Gilbert 综合征可因感染、饥饿或应激而更明显。
- 不应因轻度反复黄染反复使用保肝或抗感染药物。

**量化指标 / Metrics**
- Gilbert 综合征正确识别率
- 不必要检查减少率
- 病人释疑满意度
