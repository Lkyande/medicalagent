# Skill: 黄疸病史要点采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第47章 黄疸
- 页码: 第47章“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第47章.md`

**目标 / Objective**
通过系统病史采集快速区分感染性、梗阻性、药物性和溶血性黄疸线索。

**适用范围 / Scope**
- 门急诊所有黄疸或疑似高胆红素血症病人

**操作步骤 / Procedure**
1. 追问黄疸起病经过、反复发作史以及每次发作时的伴随症状。
2. 询问粪便和尿液颜色变化,判断是否存在胆汁淤积线索。
3. 核查腹痛、厌食、发热、皮肤瘙痒、咽痛和体重下降等伴随症状。
4. 询问旅行史、肝炎接触史、饮食饮水暴露、性接触和针刺或静脉用药史。
5. 详细核对酒精、对乙酰氨基酚和其他药物或保健品使用,并补充家族史与职业暴露史。

**注意事项 / Precautions**
- 药物史和违禁药物暴露史是黄疸评估中最常漏掉的信息。
- 家族史有助于发现 Gilbert 综合征和遗传性溶血病。
- 敏感暴露史需用非评判方式询问,提高信息真实性。

**量化指标 / Metrics**
- 黄疸标准病史完整率
- 药物相关病因识别率
- 暴露史记录率
