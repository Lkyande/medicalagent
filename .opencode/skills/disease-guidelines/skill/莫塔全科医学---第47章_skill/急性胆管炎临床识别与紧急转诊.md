# Skill: 急性胆管炎临床识别与紧急转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第47章 黄疸
- 页码: 第47章“急性胆管炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第47章.md`

**目标 / Objective**
尽早识别急性胆管炎并启动紧急转诊,降低败血症和循环衰竭风险。

**适用范围 / Scope**
- 黄疸伴感染或上腹痛的病人

**操作步骤 / Procedure**
1. 识别 Charcot 三联征:发热或寒战、上腹部疼痛、黄疸。
2. 评估有无低血压、意识改变或其他循环衰竭表现,尤其在老年病人中。
3. 结合既往胆总管结石、胆管狭窄或肿瘤病史提高怀疑度。
4. 立即安排急诊血液检查和肝胆影像,并准备静脉通道与复苏支持。
5. 以胆道减压和专科处理为目标紧急转入有 ERCP 或外科能力的机构。

**注意事项 / Precautions**
- 老年病人可先表现为败血症或循环衰竭,不一定三联征完整。
- 急性胆管炎是时间敏感性疾病,不能按普通胆绞痛观察。
- 经验性抗感染不能替代胆道引流。

**量化指标 / Metrics**
- Charcot 三联征识别率
- 可疑胆管炎急诊转诊率
- 入院前延误时间
