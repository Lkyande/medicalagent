# Skill: 黄疸红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第47章 黄疸
- 页码: 第47章“黄疸的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第47章.md`

**目标 / Objective**
快速识别提示恶性梗阻、肝衰竭或严重系统病的黄疸表现。

**适用范围 / Scope**
- 所有新发或进行性黄疸病人

**操作步骤 / Procedure**
1. 询问是否存在无法解释的体重下降和整体消耗表现。
2. 判断黄疸是否持续进展,尤其注意无痛性黄疸。
3. 查找水肿、腹水或其他晚期肝病征象。
4. 评估是否合并意识模糊、嗜睡等脑功能障碍表现。
5. 一旦存在红旗征,立即安排紧急化验和肝胆影像,必要时专科转诊。

**注意事项 / Precautions**
- 无痛性进行性黄疸在老年人中必须优先排除恶性梗阻。
- 意识改变提示肝衰竭或败血症,不能仅作门诊随访。
- 仅凭肤色或巩膜观察不能代替严重程度判断。

**量化指标 / Metrics**
- 黄疸红旗征记录率
- 红旗征阳性病例紧急转诊率
- 严重病因漏诊率
