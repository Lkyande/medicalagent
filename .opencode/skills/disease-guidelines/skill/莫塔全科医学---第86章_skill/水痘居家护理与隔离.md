# Skill: 水痘居家护理与隔离

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第86章 常见的儿童期感染性疾病
- 页码: 第86章“水痘”“治疗”“给父母的建议”“休学隔离”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第86章.md`

**目标 / Objective**
为轻症水痘患儿提供规范的居家对症处理和隔离建议。

**适用范围 / Scope**
- 免疫功能正常、无并发症的儿童水痘病人

**操作步骤 / Procedure**
1. 确认向心分布、“收割庄稼”样皮疹和瘙痒等典型表现。
2. 指导卧床休息、补液、简单饮食和对乙酰氨基酚退热。
3. 建议保持指甲短清洁,避免搔抓和继发感染。
4. 可使用炉甘石或温和洗浴措施缓解瘙痒。
5. 指导至少隔离至水疱变干或按学校规定完成休学时限。

**注意事项 / Precautions**
- 儿童水痘一般轻,但成人和免疫低下者更重。
- 除非继发细菌感染,大多不会留瘢痕。
- 儿童发热性疾病应避免阿司匹林,以防瑞氏综合征。

**量化指标 / Metrics**
- 水痘家庭护理教育完成率
- 合理隔离建议覆盖率
- 继发皮肤感染发生率
