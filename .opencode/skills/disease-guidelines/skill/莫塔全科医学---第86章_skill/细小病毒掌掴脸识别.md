# Skill: 细小病毒掌掴脸识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第86章 常见的儿童期感染性疾病
- 页码: 第86章“细小病毒 B19(感染性红斑,第五种疾病)”“临床特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第86章.md`

**目标 / Objective**
识别细小病毒 B19 的典型出疹模式并避免不必要隔离和抗菌药使用。

**适用范围 / Scope**
- 学龄儿童出现面颊潮红和轻症发热性皮疹时

**操作步骤 / Procedure**
1. 询问发热、流鼻涕、头痛和恶心等轻度前驱症状。
2. 识别典型“掌掴脸颊”外观和随后四肢/躯干疹子。
3. 记录皮疹出现时病人通常已不再具传染性的时序特点。
4. 给予对症处理并向家长解释病程可能反复数周。
5. 若涉及妊娠接触史或特殊高危情况,额外评估并咨询专科建议。

**注意事项 / Precautions**
- 皮疹出现后通常已无传染性。
- 容易与其他病毒性皮疹混淆,需结合脸部典型表现。
- 孕期暴露情境需更谨慎处理。

**量化指标 / Metrics**
- 掌掴脸特征记录率
- 不必要抗生素避免率
- 高危接触情境识别率
