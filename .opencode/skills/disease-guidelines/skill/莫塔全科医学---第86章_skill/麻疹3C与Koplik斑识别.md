# Skill: 麻疹3C与Koplik斑识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第86章 常见的儿童期感染性疾病
- 页码: 第86章“麻疹”“临床特征”“并发症”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第86章.md`

**目标 / Objective**
通过经典前驱症状和黏膜体征尽早识别麻疹并启动公共卫生措施。

**适用范围 / Scope**
- 发热出疹并伴咳嗽、流涕或结膜炎的儿童和成人病人

**操作步骤 / Procedure**
1. 识别前驱期 3C 表现:咳嗽、鼻炎和结膜炎。
2. 检查口腔黏膜是否有对磨牙部位的 Koplik 斑。
3. 观察皮疹是否从耳后和面部开始向下扩散至躯干和四肢。
4. 评估是否存在肺炎、中耳炎、腹泻或神经系统并发症线索。
5. 启动隔离、报告及实验室确认路径,同时评估接触者管理。

**注意事项 / Precautions**
- 未伴干咳和红眼的出疹病不太像麻疹。
- 麻疹并发症并不少见,尤其在幼儿、成人和慢性病人中。
- 皮疹出现前后均具传染性,公共卫生处置要及时。

**量化指标 / Metrics**
- 可疑麻疹病例的 3C 记录率
- Koplik 斑检查率
- 隔离与上报时效
