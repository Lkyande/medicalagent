# Skill: 风疹孕前免疫核查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第86章 常见的儿童期感染性疾病
- 页码: 第86章“风疹”“育龄女性免疫状况”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第86章.md`

**目标 / Objective**
在育龄女性中预防先天性风疹综合征。

**适用范围 / Scope**
- 育龄女性、备孕女性、产后未完成免疫者

**操作步骤 / Procedure**
1. 核查是否有 2 剂风疹/MMR 免疫记录。
2. 若记录不清或高风险,通过血清学评估免疫状态。
3. 对无免疫者安排接种风疹/MMR 疫苗。
4. 告知接种后 28 日内避免妊娠。
5. 对孕期未完全免疫者在产后尽快补种。

**注意事项 / Precautions**
- 孕妇禁忌接种风疹疫苗。
- 母乳喂养不是产后补种禁忌证。
- 海外出生女性风疹免疫不足风险可能更高。

**量化指标 / Metrics**
- 育龄女性风疹免疫核查率
- 无免疫者补种完成率
- 产后补种覆盖率
