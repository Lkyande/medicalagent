# Skill: 高钙血症初步评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“高钙血症”“原发性甲状旁腺功能亢进”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
对乏力、便秘、多尿等提示高钙的病人进行初步检验分层并识别需专科处理的情况。

**适用范围 / Scope**
- 出现虚弱、恶心、腹痛、便秘、多尿、口渴或性格改变病人

**操作步骤 / Procedure**
1. 识别虚弱、乏力、烦躁、厌食、恶心、腹痛、便秘、多尿和嗜睡等症状。
2. 首先检测尿常规、电解质、肌酐和白蛋白,确认高钙背景。
3. 继续检测血清甲状旁腺激素,并结合 ESR、ACE、ALP、胸片或骨扫描寻找病因。
4. 将原发性甲状旁腺功能亢进和恶性肿瘤作为最常见病因优先考虑。
5. 一经确认或病情明显,转诊专科进一步处理。

**注意事项 / Precautions**
- 超过 90% 病例与甲状旁腺功能亢进、家族性高钙尿症或肿瘤有关。
- 高钙可呈现人格和意识变化,容易被误判为单纯精神问题。
- 高钙危象可能致命,严重病例不要门诊拖延。

**量化指标 / Metrics**
- 高钙疑似病例电解质首检率
- PTH 检测完成率
- 高钙病人专科转诊率
