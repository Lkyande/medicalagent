# Skill: 甲状腺结节评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“细针抽吸”“甲状腺超声”“甲状腺结节”“甲状腺癌”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
对甲状腺结节进行结构和功能评估,筛出需要细针穿刺和专科处理的病变。

**适用范围 / Scope**
- 触及或超声发现的甲状腺单发或多发结节病人

**操作步骤 / Procedure**
1. 先检测甲状腺功能,判断是否伴功能异常。
2. 安排甲状腺超声,区分单发与多结节性病变以及实性和囊性结节。
3. 对可疑结节进行细针抽吸细胞学检查,这是判断恶性最有成本效益的方法。
4. 必要时用核扫描辅助区分功能性与非功能性结节。
5. 对无痛性硬结节、腺体增大或淋巴结硬结节高度警惕甲状腺癌并转专科。

**注意事项 / Precautions**
- 多结节性甲状腺肿恶性风险通常低于单发结节,但并非无风险。
- 非功能性结节更需要警惕恶性。
- 细针抽吸结果需要有经验的细胞学或病理团队解释。

**量化指标 / Metrics**
- 甲状腺结节超声完成率
- 可疑结节 FNA 完成率
- 甲状腺癌转诊及时率
