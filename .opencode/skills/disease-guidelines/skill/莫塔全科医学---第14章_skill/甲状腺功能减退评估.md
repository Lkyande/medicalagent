# Skill: 甲状腺功能减退评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“甲状腺功能减退”“身体检查”“甲状腺功能减退的实验室诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
识别甲状腺功能减退的临床表现、危险因素和实验室模式,避免漏诊或误诊。

**适用范围 / Scope**
- 疲乏、畏寒、便秘、嗜睡、体重增加或高危女性病人

**操作步骤 / Procedure**
1. 询问便秘、畏寒、疲乏、行动迟缓、抑郁、声音沙哑和体重增加。
2. 核查高危背景,包括自身免疫病、既往甲状腺手术、放射性碘治疗、锂剂或胺碘酮使用。
3. 体检观察窦性心动过缓、皮肤干冷、眉毛外侧稀疏、反射迟缓和甲状腺肿。
4. 检测 TSH 与游离 T4,识别原发性、继发性和亚临床甲减模式。
5. 必要时补充 TPO-Ab、胆固醇、血常规和心电图评估相关影响。

**注意事项 / Precautions**
- 甲减常缓慢起病,经常就诊的老病人最容易被忽视变化。
- 若 T4 低而 TSH 不高,必须想到垂体功能障碍。
- 产后甲减可能是桥本甲状腺炎的一部分,可暂时也可永久。

**量化指标 / Metrics**
- 高危病人甲减检测率
- 继发性甲减识别率
- 甲减确诊前平均就诊次数
