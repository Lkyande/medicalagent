# Skill: 甲状腺功能异常初筛

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“甲状腺功能检测”“表14.1 甲状腺功能检测指标总结”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
在怀疑甲状腺功能异常时使用 TSH 为首选筛查指标,决定后续检查方向。

**适用范围 / Scope**
- 怀疑甲减、甲亢、甲状腺肿或原因不明全身症状病人

**操作步骤 / Procedure**
1. 根据临床线索决定筛查,如体重变化、疲乏、便秘、焦虑、心悸或心律失常。
2. 首选检测血清 TSH 作为最敏感指标。
3. 若 TSH 异常或临床怀疑强烈,加测游离 T4,必要时加测游离 T3。
4. 当结果轻度异常或临床与化验不一致时,在 3 到 6 个月内重复 TSH。
5. 结合病情决定是否加做 TR-Ab、TPO-Ab 或 Tg-Ab 以明确病因。

**注意事项 / Precautions**
- 新检测技术敏感但并非万无一失,必须结合临床解释。
- 甲状腺功能正常性病变可造成结果混淆。
- 老年人可能只有心血管表现,不要因缺乏典型症状而漏检。

**量化指标 / Metrics**
- 疑似甲状腺病人 TSH 首检率
- 轻度异常结果复查完成率
- 初筛后病因明确率
