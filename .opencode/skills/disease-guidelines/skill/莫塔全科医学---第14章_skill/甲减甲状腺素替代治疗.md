# Skill: 甲减甲状腺素替代治疗

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“管理”“甲状腺药物治疗”“特殊情况下的考虑”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
为甲状腺功能减退病人安全启动并监测甲状腺素替代治疗。

**适用范围 / Scope**
- 已明确原发性或需治疗的亚临床甲状腺功能减退病人

**操作步骤 / Procedure**
1. 启动治疗前先排除肾上腺功能减退和缺血性心脏病。
2. 一般从甲状腺素 50 到 100 μg/d 开始,老年人或缺血性心脏病者从 25 到 50 μg/d 低剂量起始。
3. 依据症状和 TSH 每次增加 25 到 50 μg/d,常见维持剂量为 100 到 200 μg/d。
4. 治疗初期每月监测一次 TSH,达稳定后可延长至每 2 到 3 月,长期稳定后每 2 到 3 年复查。
5. 将 TSH 调整到约 0.5 到 2.0 mU/L,同时进行病人教育和长期依从性管理。

**注意事项 / Precautions**
- 将垂体性甲减误按原发性甲减单纯补 T4 可能诱发肾上腺危机。
- 老年病人快速补充甲状腺素可诱发心肌梗死。
- 妊娠期通常需要继续甚至增加 T4 剂量。

**量化指标 / Metrics**
- 起始后 3 个月 TSH 复查率
- TSH 达目标范围比例
- 过量替代不良反应发生率
