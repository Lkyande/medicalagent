# Skill: 高钾血症紧急识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“高钾血症”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
在门急诊快速识别可能致死的高钾血症,及时启动心电监测和紧急转运。

**适用范围 / Scope**
- 肾衰竭、酸中毒、艾迪生病或使用保钾药、ACEI、NSAIDs 后出现无力或心电异常者

**操作步骤 / Procedure**
1. 对少尿、肾衰竭、代谢性酸中毒和相关药物使用者提高警觉。
2. 检测血钾并核对是否可能为溶血假性升高。
3. 识别乏力、肌无力、松弛性瘫痪及可能无症状的高风险状态。
4. 立即做心电图,查找高尖 T 波、QT 缩短、PR 延长等表现。
5. 当血钾大于 6.5 mmol/L 或伴心电图毒性表现时,按医疗紧急情况处理并转急救系统。

**注意事项 / Precautions**
- 高钾的首发表现可能是心搏骤停。
- 没有症状不代表安全,心脏毒性可先于主诉出现。
- 所有可疑结果都应先排除样本溶血假象。

**量化指标 / Metrics**
- 高钾危急值心电图完成率
- 血钾大于 6.5 mmol/L 紧急处置时效
- 假性高钾复核率
