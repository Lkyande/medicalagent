# Skill: 艾迪生危象紧急处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“艾迪生病危象”“紧急管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
在感染、手术或创伤诱发的肾上腺危象中快速复苏并启动住院治疗。

**适用范围 / Scope**
- 已知或疑似肾上腺功能不全并出现休克、严重低血压或急腹症表现者

**操作步骤 / Procedure**
1. 识别恶心、呕吐、急性腹痛、严重低血压、乏力、嗜睡或昏迷。
2. 立即建立静脉通路并开始补液复苏。
3. 静脉给予氢化可的松琥珀酸钠 100 mg 负荷,随后每 4 到 6 小时 50 到 100 mg 至稳定。
4. 同步寻找并处理感染、手术后应激或创伤等诱因。
5. 立即安排紧急住院和持续监测。

**注意事项 / Precautions**
- 艾迪生危象是医疗急症,等待化验结果会延误救治。
- 皮质醇在应激时不能增加是发病核心。
- 急性腹痛和休克时要把肾上腺危象纳入鉴别。

**量化指标 / Metrics**
- 疑似危象到激素给药时间
- 紧急住院转运时效
- 诱因识别与处理率
