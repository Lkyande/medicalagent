# Skill: 艾迪生病诊断

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“艾迪生病”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
识别慢性肾上腺皮质功能不全的典型临床和化验线索,避免长期漏诊。

**适用范围 / Scope**
- 乏力、体重下降、低血压、色素沉着和胃肠症状病人

**操作步骤 / Procedure**
1. 询问嗜睡、虚弱、厌食、恶心、腹泻、腹痛、体重下降和晕厥。
2. 体检时重点查看口腔黏膜、硬腭和手部皱褶色素沉着以及直立性低血压和脱水。
3. 检测电解质,寻找高钾低钠模式。
4. 测定血浆皮质醇并进行短促 ACTH 刺激试验确认反应不足。
5. 必要时结合自身抗体和影像学寻找自身免疫、结核或真菌感染病因。

**注意事项 / Precautions**
- 本病常因表现隐匿而长期漏诊,需主动联想到肾上腺功能不全。
- 低血压和严重脱水是重要警示信号。
- 未诊断病人可因慢性消耗而死亡。

**量化指标 / Metrics**
- 疑似艾迪生病完成 ACTH 刺激试验率
- 高钾低钠病人肾上腺评估率
- 确诊前就诊延迟时间
