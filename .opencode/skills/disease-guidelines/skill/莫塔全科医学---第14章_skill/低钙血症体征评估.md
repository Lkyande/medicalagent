# Skill: 低钙血症体征评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“低钙血症”“甲状旁腺功能减退”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
在神经肌肉兴奋症状出现时识别低钙血症,完成床旁体征和基础检验评估。

**适用范围 / Scope**
- 手足搐搦、抽搐、口周麻木或甲状腺/甲状旁腺术后病人

**操作步骤 / Procedure**
1. 询问手、足和口周感觉异常、手足搐搦、癫痫发作和精神症状。
2. 检测血清总钙并结合白蛋白校正,以小于 2.1 mmol/L 支持低钙诊断。
3. 床旁诱发 Trousseau 征,即充气袖带后观察腕关节痉挛。
4. 轻叩面神经检查 Chvostek 征,观察面肌抽搐。
5. 追查甲状旁腺损伤、自身免疫性甲旁减和维生素 D 缺乏等原因,并进入补钙和骨化三醇治疗路径。

**注意事项 / Precautions**
- 甲状旁腺功能减退是最常见病因。
- 要与呼吸性碱中毒引起的手足搐搦鉴别。
- 治疗时既要纠正低钙,也要避免高钙血症和高钙尿症。

**量化指标 / Metrics**
- 低钙疑似病例血钙检测率
- Trousseau 或 Chvostek 体征记录率
- 病因追查完成率
