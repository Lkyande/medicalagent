# Skill: 甲状腺危象紧急转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“甲状腺危象(甲状腺风暴)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
识别甲状腺风暴并立即启动住院急救路径,降低心律失常和循环衰竭风险。

**适用范围 / Scope**
- 甲亢病人出现高热、极度心动过速、心衰或意识改变时

**操作步骤 / Procedure**
1. 识别明显焦虑、体重减轻、近端肌无力、高热和心动过速大于 150 次/分。
2. 同步寻找诱因,尤其手术和隐匿性感染。
3. 一旦怀疑甲状腺危象,立即安排紧急住院而非门诊观察。
4. 在转运前启动静脉补液和生命体征监测,并将病情重点告知接诊团队。
5. 提醒住院团队需要抗甲状腺药、糖皮质激素及抗心衰和抗心律失常治疗,尤其 β 受体阻滞剂。

**注意事项 / Precautions**
- 甲状腺危象是医疗急症,延误转运可致命。
- 不能仅按“焦虑发作”或“感染发热”处理。
- 老年人可先表现为心衰和心律失常。

**量化指标 / Metrics**
- 疑似甲状腺危象紧急转诊时效
- 到院前监测和补液启动率
- 诱因识别率
