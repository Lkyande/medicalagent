# Skill: 高催乳素血症评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“高催乳素血症”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
识别高催乳素血症的临床表现和常见病因,决定是否需要影像和专科治疗。

**适用范围 / Scope**
- 闭经、月经过少、不育、溢乳、性欲减退或男性勃起功能障碍病人

**操作步骤 / Procedure**
1. 询问共同症状,包括性欲减退、不育和溢乳,并按性别补问月经异常或勃起功能障碍。
2. 核查可能诱因,包括抗精神病药、抗抑郁药、甲氧氯普胺、西咪替丁、雌激素、阿片类和大麻类药物。
3. 检测血清催乳素和巨催乳素。
4. 若伴头痛、视野症状或明显升高,安排垂体 MRI。
5. 将病人转入多巴胺受体激动剂、手术或放疗评估路径。

**注意事项 / Precautions**
- 妊娠和哺乳是重要生理性原因,不能漏问。
- 药物性高催乳素血症很常见,先做药史核对。
- 有局灶压迫症状时应优先排除垂体大腺瘤。

**量化指标 / Metrics**
- 高催乳素血症药史核对率
- 催乳素异常者 MRI 完成率
- 可逆药物因素识别率
