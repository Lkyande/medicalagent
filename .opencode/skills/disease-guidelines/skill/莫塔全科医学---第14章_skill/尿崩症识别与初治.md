# Skill: 尿崩症识别与初治

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“尿崩症和抗利尿激素分泌失调综合征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
对多尿多饮病人识别尿崩症可能,并实施初步鉴别和对症治疗转介。

**适用范围 / Scope**
- 每日大量稀释尿、多饮、夜尿或术后下丘脑-垂体损伤病人

**操作步骤 / Procedure**
1. 识别多尿、夜尿和代偿性多饮,关注每日尿量可达 3 到 20 L 的病史。
2. 回顾术后创伤、肿瘤、感染和浸润病史,区分中枢性与肾性病因线索。
3. 将强迫性饮水纳入鉴别诊断。
4. 在明确诊断路径前做好液体平衡监测并避免脱水。
5. 明确中枢性尿崩症时,按专科建议使用去氨加压素,通常每日 2 次滴鼻。

**注意事项 / Precautions**
- 多尿多饮不等于糖尿病,要考虑尿崩症。
- 术后尿崩症常为短暂性,但仍需监测。
- SIADH 的处理方向相反,本质是限制液体而非补充自由水。

**量化指标 / Metrics**
- 多尿多饮病人完成鉴别评估率
- 脱水并发症发生率
- 中枢性尿崩症对症治疗启动率
