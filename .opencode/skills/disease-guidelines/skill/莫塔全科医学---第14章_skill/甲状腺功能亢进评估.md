# Skill: 甲状腺功能亢进评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第14章 内分泌和代谢障碍
- 页码: 第14章“甲状腺功能亢进”“临床特征”“身体检查”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第14章.md`

**目标 / Objective**
识别甲状腺毒症临床模式并区分格雷夫斯病、毒性结节和甲状腺炎等病因方向。

**适用范围 / Scope**
- 焦虑、体重减轻、热不耐受、心悸、震颤或不明原因房颤病人

**操作步骤 / Procedure**
1. 询问热不耐受、多汗、肌无力、食欲增加伴体重减轻、焦虑和排便增多。
2. 体检寻找手温暖多汗、细微震颤、甲状腺肿、近端肌病、反射亢进和房颤。
3. 评估眼部征象,包括眼睑退缩、眼睑后退、突眼和眼肌麻痹。
4. 检测 TSH、游离 T4 和必要时游离 T3,并结合 TPO-Ab 或其他抗体。
5. 需要明确病因时安排放射性同位素扫描,区分弥漫性摄取增强、结节性增强或摄取低下模式。

**注意事项 / Precautions**
- 老年人可能仅表现为心衰、心律失常或体重下降。
- 严重焦虑可由甲状腺毒症引起,不能简单按精神症状处理。
- 诊断前先明确病因,治疗选择差异很大。

**量化指标 / Metrics**
- 疑似甲亢病人甲功完整检测率
- 眼部征象记录率
- 甲亢病因明确率
