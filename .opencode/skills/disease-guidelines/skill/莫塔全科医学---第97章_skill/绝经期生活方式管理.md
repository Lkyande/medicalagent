# Skill: 绝经期生活方式管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第97章 绝经
- 页码: 第97章“管理”“教育和生活方式”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第97章.md`

**目标 / Objective**
通过生活方式和健康教育减轻绝经期症状并降低长期疾病风险。

**适用范围 / Scope**
- 围绝经期和绝经后女性

**操作步骤 / Procedure**
1. 向病人解释绝经是自然生命过渡阶段。
2. 强调心血管、骨质疏松和癌症等长期风险管理。
3. 指导健康饮食、体重控制、放松和规律负重运动。
4. 确保充足钙摄入、戒烟和安全饮酒。
5. 根据症状和风险决定是否进一步讨论药物或 MHT。

**注意事项 / Precautions**
- 绝经管理不只针对潮热,也应覆盖长期健康。
- 生活方式干预适用于所有女性,即使不使用激素治疗。
- 需要结合个人价值和症状负担做决策。

**量化指标 / Metrics**
- 绝经女性生活方式教育率
- 负重运动建议率
- 骨心血管风险管理覆盖率
