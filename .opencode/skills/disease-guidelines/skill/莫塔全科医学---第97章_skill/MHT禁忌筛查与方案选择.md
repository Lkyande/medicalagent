# Skill: MHT禁忌筛查与方案选择

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第97章 绝经
- 页码: 第97章“绝经期激素治疗”“MHT 禁忌证”“黄金定则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第97章.md`

**目标 / Objective**
在考虑 MHT 时筛查禁忌证并根据子宫状态和风险特征选择方案。

**适用范围 / Scope**
- 有明显绝经症状并考虑使用激素治疗的围绝经期或绝经后女性

**操作步骤 / Procedure**
1. 确认主要适应证是血管舒缩症状或显著泌尿生殖症状。
2. 排查乳腺癌、子宫内膜癌、未确诊阴道出血等绝对禁忌证。
3. 对心血管病、VTE、活动性肝病和先兆偏头痛等相对禁忌慎选途径。
4. 若女性有子宫,必须联合孕激素与雌激素。
5. 尽量使用最低有效剂量,并根据年龄、绝经年限和给药途径选择方案。

**注意事项 / Precautions**
- 有症状的 60 岁以下或绝经后 10 年内女性总体风险较低。
- 经皮方案对静脉血栓风险更友好。
- 高血压本身不是 MHT 禁忌证。

**量化指标 / Metrics**
- MHT 前禁忌筛查率
- 子宫完整女性孕激素联合率
- 激素方案个体化记录率
