# Skill: 围绝经期症状评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第97章 绝经
- 页码: 第97章“临床表现”“病史”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第97章.md`

**目标 / Objective**
评估围绝经期女性的月经变化、潮热和生活质量受损情况。

**适用范围 / Scope**
- 45 至 55 岁出现月经紊乱、潮热、睡眠或泌尿生殖症状的女性

**操作步骤 / Procedure**
1. 询问月经周期变化、闭经时间和血管运动性症状。
2. 评估情绪、睡眠、性欲、阴道干燥和膀胱症状对生活质量的影响。
3. 记录心血管、骨质疏松和癌症家族史。
4. 按需做血压、体重、腰围、乳房、阴道和宫颈筛查评估。
5. 对年轻女性、子宫切除术后或使用 LNG-IUD 者再考虑辅助激素检测。

**注意事项 / Precautions**
- 围绝经期常是回顾性和临床性诊断,并非一定需要激素检测。
- 潮热需与感染性发热鉴别。
- 症状轻重差异大,约 20% 女性受影响明显。

**量化指标 / Metrics**
- 围绝经期症状谱记录率
- 生活质量影响记录率
- 共病风险筛查率
