# Skill: 自杀风险主动询问

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第71章 难应对的、苛刻的和气愤的病人
- 页码: 第71章“自杀和准自杀”“确凿的事实”“自杀风险”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第71章.md`

**目标 / Objective**
及时识别存在自杀意念或高风险特征的病人并启动保护性处置。

**适用范围 / Scope**
- 抑郁、行为紊乱、重大丧失、物质滥用或公开自伤威胁的病人

**操作步骤 / Procedure**
1. 主动直接询问是否有死亡想法、自伤意念、计划或既往自杀企图。
2. 评估精神疾病、冲动人格、社会支持差、重大损失和家族史等风险群。
3. 注意病人是否曾向家人、朋友或医生发出明确或隐晦警告。
4. 对高危者立即加强陪护、限制独处并安排精神专科或急诊评估。
5. 对准自杀病人出院后提供密集随访,尤其关注爽约和支持系统薄弱者。

**注意事项 / Precautions**
- 询问自杀意念不会诱发自杀行为。
- 谈论自杀的人未来可能实施自杀。
- 边缘型人格障碍和年轻人自伤行为需要高度重视。

**量化指标 / Metrics**
- 高危心理病人的自杀询问率
- 高危病例当日转介率
- 准自杀病人出院后 1 周内随访率
