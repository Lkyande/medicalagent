# Skill: 投诉ABCDE处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第71章 难应对的、苛刻的和气愤的病人
- 页码: 第71章“投诉”“表71.1 应对投诉的 ABCDE 方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第71章.md`

**目标 / Objective**
用标准化步骤快速、稳妥地处理病人投诉,减少沟通升级和法律风险。

**适用范围 / Scope**
- 诊所、门诊或随访过程中出现的口头或书面投诉

**操作步骤 / Procedure**
1. 尽快承认投诉存在,不要拖延或忽视。
2. 优先直接与投诉病人沟通,尽量面对面澄清事实和期望。
3. 按 ABCDE 执行:承认投诉、设定界限、表达同情关心、查明行为原因、陷入僵局时退出升级场景。
4. 核查与事件相关的病历、电话记录、检查结果和团队信息。
5. 对疑似医疗疏忽或法律诉求,及时转交监管或保险支持渠道处理。

**注意事项 / Precautions**
- 沟通失败和期望未被满足是最常见触发点。
- 法律风险事件不要仅靠口头安抚解决。
- 处理投诉时要保留完整书面记录。

**量化指标 / Metrics**
- 投诉首次响应时效
- 完整事实核查完成率
- 投诉升级为正式争议的比例
