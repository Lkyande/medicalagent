# Skill: 难应对病人结构化管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第71章 难应对的、苛刻的和气愤的病人
- 页码: 第71章“难应对的、苛刻的和气愤的病人”“管理策略”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第71章.md`

**目标 / Objective**
在面对难应对病人时维持有效医患关系、边界和连续照护。

**适用范围 / Scope**
- 黏附型、指使型、拒助型、自毁型及其他让医生感到“心沉”的病人

**操作步骤 / Procedure**
1. 先把问题理解为“难应对的问题”而非简单给病人贴标签。
2. 同步筛查焦虑、抑郁、惊恐、多种躯体形式障碍和药物依赖等常见伪装心理问题。
3. 设定清晰的看诊结构,包括固定随访频率、每次时长和讨论范围。
4. 对病人的生活背景保持真诚兴趣,但对反复无效抱怨不过度强化。
5. 在保持礼貌和信任的前提下坚持边界,必要时转介心理咨询但不轻易中断照护。

**注意事项 / Precautions**
- 不要因挫败感而放弃病人或与病人对抗。
- 避免过度检查、安慰剂式处理或与其他医生“合谋”。
- 反复新症状仍需按常规评估,不能被既往印象掩盖。

**量化指标 / Metrics**
- 难应对病人的结构化随访建立率
- 合并心理问题筛查记录率
- 团队边界与管理计划记录率
