# Skill: 药物依赖逛医生者拒方沟通

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第71章 难应对的、苛刻的和气愤的病人
- 页码: 第71章“逛医生者的药物依赖”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第71章.md`

**目标 / Objective**
在面对成瘾药物索取时保持一致拒方立场,同时提供替代帮助。

**适用范围 / Scope**
- 多点求诊、要求开具成瘾性药物或有明显药物寻求行为的病人

**操作步骤 / Procedure**
1. 尽早引出病人对特定药物的请求,明确其来诊核心诉求。
2. 用简短、礼貌且明确的语言告知不能开具所要求的成瘾药物。
3. 避免陷入讨价还价或被病人的操控意图牵引。
4. 强调这不是针对个人,而是基于一致的临床工作方式与安全原则。
5. 提供替代帮助路径,如成瘾评估、非成瘾治疗方案或心理支持。

**注意事项 / Precautions**
- 沟通要坚定而不羞辱病人。
- 对威胁、操控或伪造信息要保持警觉并记录。
- 必要时与团队建立统一处方和接诊规则。

**量化指标 / Metrics**
- 可疑 doctor shopping 病人的一致拒方执行率
- 替代治疗或转介提供率
- 重复索药事件发生率
