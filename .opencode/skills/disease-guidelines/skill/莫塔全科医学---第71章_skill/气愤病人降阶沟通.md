# Skill: 气愤病人降阶沟通

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第71章 难应对的、苛刻的和气愤的病人
- 页码: 第71章“气愤的病人”“看诊策略”“表71.2 应对气愤病人的指南”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第71章.md`

**目标 / Objective**
在病人愤怒或激惹时降低对抗、识别真实诉求并恢复合作沟通。

**适用范围 / Scope**
- 门诊、前台或电话场景中出现愤怒、指责、激动的病人或家属

**操作步骤 / Procedure**
1. 先保持冷静、静止和目光接触,避免用愤怒回应愤怒。
2. 邀请病人坐下,采用非挑衅姿势和清晰、平稳的语言交流。
3. 让病人充分表达情绪,专注倾听,不要急于辩解或主观判断。
4. 用澄清和探究式提问识别其恐惧、不安全感、失望或隐藏议程。
5. 在安全前提下安排后续计划,若当前时间不足则预约继续讨论。

**注意事项 / Precautions**
- 愤怒常是恐惧和不安全感的外在表达。
- 对具威胁性的病人,医生应位于更易撤离的位置并准备求助。
- 不要抚触病人、居高临下说教或卷入争执。

**量化指标 / Metrics**
- 情绪升级场景中的降阶成功率
- 后续随访安排率
- 安全事件或投诉升级率
