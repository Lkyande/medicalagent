# Skill: 血脂筛查与复核

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第78章 血脂异常
- 页码: 第78章“辅助检查”“需要治疗的病人”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第78章.md`

**目标 / Objective**
规范开展血脂筛查并对异常结果进行确认和风险分层。

**适用范围 / Scope**
- 45 岁及以上成人,或存在心血管高风险、糖尿病或家族史的病人

**操作步骤 / Procedure**
1. 按年龄和风险分层安排空腹或可接受的非空腹血脂检测。
2. 一次检测至少包括总胆固醇、HDL-C、LDL-C 和甘油三酯。
3. 对初次升高结果在 6 至 8 周内复核确认。
4. 同步结合绝对心血管风险判断后续管理强度。
5. 对中度及以上风险者缩短复查间隔并补充生活方式干预。

**注意事项 / Precautions**
- 不应单独只测 LDL-C 而忽视完整血脂谱。
- 异常结果需至少两次独立实验室依据再决定长期用药。
- 原住民和托雷斯海峡岛民筛查年龄应更早。

**量化指标 / Metrics**
- 目标人群血脂筛查覆盖率
- 异常结果 6 至 8 周复核率
- 风险分层记录率
