# Skill: 他汀治疗起始与监测

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第78章 血脂异常
- 页码: 第78章“药物治疗”“一线药物”“表78.4 调脂药物”“随访要做的辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第78章.md`

**目标 / Objective**
为适合的血脂异常病人启动他汀治疗并进行安全监测。

**适用范围 / Scope**
- 需药物治疗的高胆固醇血症或高心血管风险病人

**操作步骤 / Procedure**
1. 基于至少两次实验室结果和整体心血管风险决定启动他汀。
2. 明确 LDL-C 为主要治疗目标,并向病人解释长期治疗预期。
3. 治疗前获取肝酶和 CK 基线,必要时记录肌肉症状基线。
4. 启动后 4 至 8 周复查肝功能和血脂,评估疗效与耐受性。
5. 若未达目标或最大耐受剂量不足,考虑加用依折麦布等联合方案。

**注意事项 / Precautions**
- 他汀是一线药物,但肌肉或肝胆病人需谨慎。
- 无症状时不必无限制高频复查肝功能。
- 吉非贝齐与他汀联用会增加肌病风险,应避免。
**量化指标 / Metrics**
- 符合适应证病人的他汀启动率
- 启动后 4 至 8 周复查率
- 达到 LDL-C 目标比例
