# Skill: 血脂异常生活方式干预

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第78章 血脂异常
- 页码: 第78章“非药物措施”“核查点”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第78章.md`

**目标 / Objective**
通过饮食、运动和体重管理降低血脂并改善整体心血管风险。

**适用范围 / Scope**
- 高胆固醇血症、高甘油三酯血症或混合型高脂血症病人

**操作步骤 / Procedure**
1. 指导减少饱和脂肪和反式脂肪,避免快餐和油炸食品。
2. 增加高纤维饮食、水果蔬菜和健康脂肪来源,可考虑植物甾醇食品。
3. 对超重者制定减重计划,并鼓励规律身体活动。
4. 强调戒烟和限制每日酒精摄入,尤其甘油三酯升高者。
5. 持续至少 6 个月非药物治疗,并在 6 至 8 周复查初步效果。

**注意事项 / Precautions**
- 除最高风险人群外,生活方式干预通常应先于药物治疗充分实施。
- 家庭合作可明显提高执行率。
- 甘油三酯升高时减少酒精摄入尤为关键。

**量化指标 / Metrics**
- 饮食与运动计划建立率
- 6 至 8 周 LDL-C 或 TG 改善率
- 6 个月坚持非药物治疗率
