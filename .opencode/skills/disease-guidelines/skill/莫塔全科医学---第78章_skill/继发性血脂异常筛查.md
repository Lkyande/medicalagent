# Skill: 继发性血脂异常筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第78章 血脂异常
- 页码: 第78章“表78.2 继发性血脂异常的常见原因”“非药物措施”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第78章.md`

**目标 / Objective**
在血脂异常病人中主动排查可逆的继发性原因。

**适用范围 / Scope**
- 新发现血脂异常、混合型高脂血症或治疗效果不理想的病人

**操作步骤 / Procedure**
1. 询问甲减、糖尿病、肾病综合征、肥胖、酒精过量和药物暴露史。
2. 结合肝胆疾病、肾损害和神经性厌食等临床线索进行分类。
3. 对甘油三酯显著升高者重点复核酒精摄入和糖代谢异常。
4. 根据情况安排甲状腺功能、肾功能、血糖和尿蛋白等检查。
5. 先纠正继发因素,再决定是否及如何启动长期调脂药物治疗。

**注意事项 / Precautions**
- 继发性病因若未处理,药物效果常受限。
- 利尿剂、雌激素和酒精是常见但易忽略因素。
- 继发病因与原发性血脂异常可并存。

**量化指标 / Metrics**
- 血脂异常病人的继发病因筛查率
- 甘油三酯显著升高者酒精评估率
- 可逆病因纠正率
