# Skill: 重度高甘油三酯血症处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第78章 血脂异常
- 页码: 第78章“中重度(单独)甘油三酯升高”“重度高甘油三酯血症”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第78章.md`

**目标 / Objective**
降低重度高甘油三酯血症病人的胰腺炎风险并处理相关诱因。

**适用范围 / Scope**
- 甘油三酯显著升高,尤其 TG ≥10 mmol/L 的病人

**操作步骤 / Procedure**
1. 确认 TG 水平并复核近期饮酒、糖尿病失控和药物诱因。
2. 立即强化低脂饮食和严格减少酒精摄入。
3. 以贝特类为主,并可联合鱼油,必要时加用烟酸。
4. 同步筛查胰腺炎症状,如腹痛、恶心和呕吐。
5. 在短期内复查血脂和生化指标,根据反应调整治疗方案。

**注意事项 / Precautions**
- TG >10 mmol/L 时胰腺炎风险明显增加。
- 他汀对降甘油三酯作用有限,重点是诱因控制和针对性用药。
- 合并糖尿病时血糖控制对降 TG 很关键。

**量化指标 / Metrics**
- 重度高 TG 病人的诱因评估率
- 目标药物启动率
- 短期 TG 降幅达标率
