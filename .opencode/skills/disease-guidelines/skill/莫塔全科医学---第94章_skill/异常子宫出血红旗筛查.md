# Skill: 异常子宫出血红旗筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第94章 异常子宫出血
- 页码: 第94章“不能遗漏的严重疾病”“表94.4 不规则出血的重要原因”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第94章.md`

**目标 / Objective**
识别异常子宫出血中提示恶性、妊娠异常或严重感染的红旗原因。

**适用范围 / Scope**
- 月经间期出血、性交后出血、绝经后出血或月经过多的女性

**操作步骤 / Procedure**
1. 按年龄分层考虑高危病因,如青少年妊娠并发症和围绝经期癌症风险。
2. 对性交后出血、持续经间期出血和绝经后出血高度警惕宫颈癌或子宫内膜癌。
3. 排查异位妊娠、流产、妊娠滋养细胞疾病和盆腔炎性疾病。
4. 结合宫颈检查、超声和实验室结果决定是否急转诊。
5. 对绝经后或高度疑似恶性病人尽快妇科专科评估。

**注意事项 / Precautions**
- 异常妊娠是任何育龄期 AUB 的优先排除项。
- 45 岁后新发癌症相关出血原因明显增加。
- 单次症状也可能是恶性肿瘤首发,不能轻描淡写。

**量化指标 / Metrics**
- AUB 红旗征记录率
- 高危病例妇科转诊时效
- 妊娠相关异常识别率
