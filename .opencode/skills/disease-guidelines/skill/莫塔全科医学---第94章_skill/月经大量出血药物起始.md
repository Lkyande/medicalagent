# Skill: 月经大量出血药物起始

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第94章 异常子宫出血
- 页码: 第94章“内科管理”“表94.5 管理月经大量出血的各种药物”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第94章.md`

**目标 / Objective**
为月经大量出血病人选择合适的一线药物治疗并缓解失血。

**适用范围 / Scope**
- 无需立即手术且适合门诊内科管理的月经大量出血女性

**操作步骤 / Procedure**
1. 在首次就诊时就启动口服药物,避免仅观察等待。
2. 首选氨甲环酸或 NSAIDs,并指导在月经早期尽快开始服用。
3. 对需要更高效长期控制者,主动介绍 52 mg 左炔诺孕酮 IUD。
4. 备选使用口服孕激素、COC 或阴道环,结合病人需求选择。
5. 复查失血量、贫血改善和副作用后决定维持或升级治疗。

**注意事项 / Precautions**
- 52 mg 左炔诺孕酮 IUD 是最有效药物性治疗之一。
- 低剂量 LNG-IUD 不适用于月经过多治疗。
- 口服孕激素副作用较多,更适合短期使用。

**量化指标 / Metrics**
- 首次就诊药物启动率
- 失血量改善率
- 52 mg LNG-IUD 介绍率
