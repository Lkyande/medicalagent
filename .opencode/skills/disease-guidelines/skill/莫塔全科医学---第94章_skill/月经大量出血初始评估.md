# Skill: 月经大量出血初始评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第94章 异常子宫出血
- 页码: 第94章“月经大量出血”“病史”“身体检查”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第94章.md`

**目标 / Objective**
系统评估月经大量出血并识别妊娠、恶性和贫血等重要问题。

**适用范围 / Scope**
- 育龄女性主诉月经过多、周期异常或相关贫血症状时

**操作步骤 / Procedure**
1. 询问经量、更换卫生用品频率、血块、疼痛和对生活质量的影响。
2. 先排除妊娠及其并发症,包括异位妊娠和流产。
3. 评估激素使用、性生活史、吸烟和心理社会因素。
4. 查体时关注贫血体征、宫颈病变、子宫大小形态和附件压痛。
5. 安排 CBC、铁蛋白、β-hCG,并按指征补充甲状腺、凝血和经阴道超声检查。

**注意事项 / Precautions**
- 很多女性会把长期重度出血误认为“自己的正常月经”。
- 月经大量出血是常见缺铁性贫血原因。
- 年轻女性如不适合阴道检查,应避免不必要创伤。

**量化指标 / Metrics**
- HMB 病人经量量化记录率
- 妊娠检测完成率
- 贫血筛查完成率
