# Skill: 重性抑郁诊断评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第10章 抑郁
- 页码: 第10章“重性抑郁障碍的诊断标准”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第10章.md`

**目标 / Objective**
依据症状数量、持续时间和核心特征评估是否符合重性抑郁障碍标准。

**适用范围 / Scope**
- 抑郁筛查阳性或疑似情绪障碍病人

**操作步骤 / Procedure**
1. 确认情绪低落和/或快感缺失是否持续至少 2 周。
2. 系统评估九项症状中符合的数量,包括睡眠、精力、注意力、食欲体重、内疚和自杀想法等。
3. 判断是否满足至少五项症状且包含核心症状之一。
4. 评估对功能、工作和关系的影响程度。
5. 记录严重程度并规划后续治疗层级。

**注意事项 / Precautions**
- 诊断不能只凭量表分数,仍需结合病史与精神状态检查。
- 儿童和青少年可表现为易激惹多于悲伤。
- 老年人可能表现为混乱、激越或类似痴呆的表现。

**量化指标 / Metrics**
- DSM核心标准评估完成率
- 严重程度分层记录率
- 功能损害记录率
