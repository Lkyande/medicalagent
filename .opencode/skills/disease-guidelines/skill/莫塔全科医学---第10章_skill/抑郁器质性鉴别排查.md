# Skill: 抑郁器质性鉴别排查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第10章 抑郁
- 页码: 第10章“重要的鉴别诊断(器质性疾病)”“可考虑完善的检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第10章.md`

**目标 / Objective**
在诊断抑郁时同步排查可能模拟或加重抑郁表现的器质性疾病和药物因素。

**适用范围 / Scope**
- 新发抑郁、老年抑郁、症状非典型或伴明显躯体症状病人

**操作步骤 / Procedure**
1. 回顾恶性肿瘤、内分泌疾病、感染、神经系统疾病和器官衰竭相关线索。
2. 询问当前和近期药物使用及物质滥用情况。
3. 根据情况安排全血细胞计数、甲状腺功能、尿素电解质、叶酸、维生素 B/D、血糖和尿毒理等检查。
4. 对存在神经系统表现或诊断疑难者考虑影像检查。
5. 将器质性结果与精神症状整合后再确定最终诊断。

**注意事项 / Precautions**
- 老年人和躯体化病人最容易被漏掉器质性病因。
- 一旦存在体重下降、局灶神经症状或快速认知变化,应优先排除严重身体疾病。
- 器质性排查不应延误高自杀风险的安全处置。

**量化指标 / Metrics**
- 器质性鉴别记录率
- 必要检查完成率
- 器质性病因识别率
