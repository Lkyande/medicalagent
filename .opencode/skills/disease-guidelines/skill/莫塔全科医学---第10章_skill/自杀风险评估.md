# Skill: 自杀风险评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第10章 抑郁
- 页码: 第10章“自杀评估”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第10章.md`

**目标 / Objective**
通过结构化提问识别自杀风险级别,及时决定支持、随访或紧急转诊。

**适用范围 / Scope**
- 所有抑郁病人,尤其中重度症状、绝望感或既往自伤病史者

**操作步骤 / Procedure**
1. 直接询问是否存在自杀想法。
2. 继续询问是否已有计划、手段、致命性考虑和既往自杀史。
3. 询问家族或同伴自杀史等额外风险因素。
4. 根据结果将病人分为低、中或高风险。
5. 低风险者安排支持和后续复诊;中风险者制订应急与安全计划并在 1 周内复评;高风险者立即确保安全并在 24 小时内重新评估或转急诊精神科。

**注意事项 / Precautions**
- 自杀风险评估必须直接、清楚,不能靠暗示代替。
- 风险等级会变化,每次就诊都需重复评估。
- 若存在具体计划和可得手段,应优先保护环境安全而非继续长谈。

**量化指标 / Metrics**
- 抑郁病人自杀评估完成率
- 安全计划完成率
- 高风险个案紧急转介时效
