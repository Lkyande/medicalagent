# Skill: 抑郁治疗分层选择

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第10章 抑郁
- 页码: 第10章“治疗”“实用管理指南”“转诊时机”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第10章.md`

**目标 / Objective**
根据抑郁严重程度和风险状态选择心理治疗、药物治疗、联合治疗或转诊路径。

**适用范围 / Scope**
- 已完成严重度评估的轻、中、重度抑郁病人

**操作步骤 / Procedure**
1. 对轻度抑郁优先安排心理学疗法和支持性干预。
2. 对中度抑郁选择心理治疗和/或抗抑郁药。
3. 对严重抑郁优先考虑抗抑郁药,并评估精神科会诊、ECT 或住院需求。
4. 对药物治疗前评估是否可能存在双相障碍,避免误用抗抑郁药。
5. 对严重、自杀高风险、精神病性抑郁或居家无法应对者及时转诊。
6. 与病人共同决策治疗方案,兼顾既往经验和偏好。

**注意事项 / Precautions**
- 治疗强度应与风险和功能损害匹配,不能仅凭主观印象。
- 持续治疗依从性往往比初始方案选择更关键。
- 精神病性抑郁、自杀高风险和儿童严重抑郁须更谨慎处理。

**量化指标 / Metrics**
- 严重度与治疗匹配率
- 高风险病人及时转诊率
- 缓解率与持续治疗依从性
