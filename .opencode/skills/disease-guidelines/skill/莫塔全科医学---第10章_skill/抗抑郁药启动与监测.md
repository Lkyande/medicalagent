# Skill: 抗抑郁药启动与监测

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第10章 抑郁
- 页码: 第10章“抗抑郁药”“持续治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第10章.md`

**目标 / Objective**
安全启动抗抑郁药并在早期和维持期持续监测疗效、不良反应和依从性。

**适用范围 / Scope**
- 中重度抑郁或抑郁合并焦虑障碍需药物治疗病人

**操作步骤 / Procedure**
1. 选择合适的一线抗抑郁药,通常优先考虑 SSRIs。
2. 解释预期起效时间、常见不良反应和坚持治疗的重要性。
3. 在治疗早期进行密切监测,必要时每周评估一次。
4. 若前 2 周无早期反应或 6 周内反应不足,重新评估是否需要调整方案。
5. 症状缓解后首次发作至少维持 12 个月,高复发风险者维持 2 到 3 年。
6. 停药时逐步减量,通常每周减少一半剂量以减轻撤药反应。

**注意事项 / Precautions**
- 老年人应小剂量起始并缓慢加量。
- 自杀风险病人应避免一次开具过量高毒性药物。
- 若怀疑双相障碍,应避免单独使用抗抑郁药。

**量化指标 / Metrics**
- 用药后早期随访率
- 6周疗效评估完成率
- 维持治疗依从性和复发率
