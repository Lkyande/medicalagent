# Skill: 抑郁核心筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第10章 抑郁
- 页码: 第10章“诊断方法”“两个特别好的问题”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第10章.md`

**目标 / Objective**
在基层快速识别可能存在抑郁的病人,触发进一步系统评估。

**适用范围 / Scope**
- 情绪低落、疲劳、失眠、慢性疼痛、躯体化或反复就诊病人

**操作步骤 / Procedure**
1. 先询问过去一个月是否长期被沮丧、低落或绝望困扰。
2. 询问过去一个月是否因做事缺少兴趣或乐趣而困扰。
3. 若任一问题阳性,继续评估睡眠、精力、食欲、内疚和生活价值感。
4. 主动询问是否存在自杀想法。
5. 必要时使用量表如 K10 或 DASS 进行进一步筛查。

**注意事项 / Precautions**
- 躯体症状可能是抑郁的主要表现,不要只在病人主动诉苦时才筛查。
- 对男性、老年人和青少年要警惕非典型表达。
- 一旦涉及自杀念头,筛查应立即升级为风险评估。

**量化指标 / Metrics**
- 高风险人群抑郁筛查率
- 两问筛查阳性后完整评估率
- 躯体化病人识别抑郁率
