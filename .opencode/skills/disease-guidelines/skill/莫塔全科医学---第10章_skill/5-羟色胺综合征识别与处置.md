# Skill: 5-羟色胺综合征识别与处置

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第10章 抑郁
- 页码: 第10章“5-羟色胺综合征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第10章.md`

**目标 / Objective**
尽早识别与 5-羟色胺药物相关的严重不良反应并立即采取停药和急诊处理。

**适用范围 / Scope**
- 正在使用 SSRIs、SNRIs、曲马多、锂剂、圣约翰草等 5-羟色胺相关药物的病人

**操作步骤 / Procedure**
1. 确认症状是否发生在开始用药或加量之后。
2. 回顾所有可能增加 5-羟色胺活性的药物或补充剂。
3. 识别三大表现群:精神状态改变、肌张力改变和自主神经紊乱。
4. 排除感染、戒断和物质滥用等其他原因。
5. 一旦怀疑综合征,立即停用相关药物。
6. 启动支持治疗并尽快转急诊处理。

**注意事项 / Precautions**
- 圣约翰草也可能参与诱发,不能忽略补充治疗史。
- 该综合征虽少见但可能危及生命,识别后不可观望过久。
- 药物联用和剂量调整期风险更高。

**量化指标 / Metrics**
- 药物相关病史完整率
- 可疑病例停药时效
- 紧急转诊完成率
