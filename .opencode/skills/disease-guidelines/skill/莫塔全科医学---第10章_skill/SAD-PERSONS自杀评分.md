# Skill: SAD-PERSONS自杀评分

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第10章 抑郁
- 页码: 第10章“悲伤者(SAD PERSONS)指数”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第10章.md`

**目标 / Objective**
使用 SAD PERSONS 指数快速量化自杀风险,辅助决定监测和转诊强度。

**适用范围 / Scope**
- 已进行基础自杀风险评估的抑郁病人

**操作步骤 / Procedure**
1. 逐项评估性别、年龄、抑郁严重度、既往自杀史、药物/酒精、理智丧失、独居、是否有组织计划、支持缺乏和慢性病。
2. 按量表规则为每项打分。
3. 汇总总分并记录在病历中。
4. 对评分大于 7 分者按高风险处理,密切监测并考虑紧急精神科转诊。
5. 结合临床判断,不要单独依赖量表分数作决定。

**注意事项 / Precautions**
- 量表是辅助工具,不能替代面对面的风险判断。
- 即使总分不高,若有明确计划和手段仍应按高风险处理。
- 评分应随病情变化重复更新。

**量化指标 / Metrics**
- 高风险病人量表应用率
- 高分病人紧急干预率
- 量表结果与临床分层一致率
