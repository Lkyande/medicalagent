# Skill: 围产期抑郁筛查与转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第10章 抑郁
- 页码: 第10章“围产期抑郁”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第10章.md`

**目标 / Objective**
在孕期和产后早期识别围产期抑郁及相关风险,提供家庭为中心的支持和必要转诊。

**适用范围 / Scope**
- 孕期女性和产后 12 个月内女性

**操作步骤 / Procedure**
1. 在筛查前征求同意并解释筛查目的与过程。
2. 使用爱丁堡产后抑郁量表在孕期和产后至少各筛查一次,高风险者更频繁。
3. 评估既往心理问题、支持不足、家庭问题、虐待、丧失和文化孤立等风险因素。
4. 一旦筛查阳性,结合个人、家庭和文化背景进行进一步评估。
5. 提供心理教育、随访和持续照护,必要时采用团队合作方式。
6. 若母亲或婴儿存在风险,立即紧急转诊;若怀疑精神病,尽快精神科评估。

**注意事项 / Precautions**
- 围产期抑郁常伴焦虑,不能只盯住抑郁症状。
- 评估和治疗要兼顾母婴安全。
- 药物使用需平衡母亲获益与胎儿/婴儿风险。

**量化指标 / Metrics**
- 围产期筛查覆盖率
- 高风险孕产妇识别率
- 阳性筛查后随访/转诊完成率
