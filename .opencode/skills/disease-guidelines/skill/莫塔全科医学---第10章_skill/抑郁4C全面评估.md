# Skill: 抑郁4C全面评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第10章 抑郁
- 页码: 第10章“4C评估法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第10章.md`

**目标 / Objective**
从症状、严重度、共病背景和应对影响四个维度全面评估抑郁病人。

**适用范围 / Scope**
- 已识别抑郁或疑似重性抑郁病人

**操作步骤 / Procedure**
1. `描述`：具体刻画症状特征、持续时间和日内变化。
2. `校准`：评估严重程度和慢性程度,必要时使用评分量表。
3. `确认`：核实是否存在精神、身体和社会并发症及相关背景。
4. `考虑`：评估病人的应对方式以及对社会、财务和职业功能的影响。
5. 在多次咨询中持续更新上述四个维度。

**注意事项 / Precautions**
- 单次就诊常难完成完整评估,需允许逐步完善。
- 许多病人合并焦虑、创伤、慢病或伴侣暴力,不能只看情绪症状。
- 严重度评估应与安全评估同步进行。

**量化指标 / Metrics**
- 4C四项评估完整率
- 共病识别率
- 功能影响量化记录率
