# Skill: 高血压起始药物选择

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第77章 高血压
- 页码: 第77章“何时进行用药治疗”“用药指南”“表77.9 高血压一线治疗药物”“初始用药方案”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第77章.md`

**目标 / Objective**
在需要药物治疗时依据风险、合并症和禁忌证选择合适的一线降压方案。

**适用范围 / Scope**
- 已确诊原发性高血压且达到药物治疗阈值的成人病人

**操作步骤 / Procedure**
1. 先确认是否达到起始药物阈值,结合 5 年心血管风险和血压水平判断。
2. 通常从单药小剂量起始,并预期 4 至 6 周观察最高疗效。
3. 在无特殊禁忌时优先考虑 ACEI/ARB、钙通道阻滞剂或噻嗪类。
4. 根据合并糖尿病、心衰、哮喘、CKD、痛风或雷诺现象调整药物类别选择。
5. 若低剂量效果不足,按耐受情况增量、换药或联合治疗,避免 ACEI 与 ARB 联用。

**注意事项 / Precautions**
- β受体阻滞剂不再常规作为一线,除非有明确合并症获益。
- 降压应平稳缓慢,避免过快过度下降。
- 需要主动解释长期治疗和不良反应监测,提高依从性。

**量化指标 / Metrics**
- 达到药物阈值病人的起始治疗率
- 用药与合并症匹配率
- ACEI+ARB 不当联用发生率
