# Skill: 高血压确诊与随访

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第77章 高血压
- 页码: 第77章“确认和随访”“表77.7”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第77章.md`

**目标 / Objective**
在初次发现血压升高后合理确认诊断并设定随访节奏。

**适用范围 / Scope**
- 首次或近期发现血压升高的成人病人

**操作步骤 / Procedure**
1. 对初测升高者先休息 10 分钟后复测,并记录基线水平。
2. 除极高或紧急情况外,不要基于一次测量直接诊断高血压。
3. 在 3 个月内至少于不同时间再测两次血压确认持续升高。
4. 根据初诊血压分层决定 1 周、1 个月、2 个月、1 年或 2 年内复诊。
5. 对年轻病人和边界升高者确保规律追踪,避免失访。

**注意事项 / Precautions**
- 轻度升高可观察 3 至 6 个月再决定长期治疗。
- 舒张压 ≥115 mmHg 或明显靶器官损害者需更快启动药物治疗。
- 白大褂效应常见,复测和院外监测很关键。

**量化指标 / Metrics**
- 初次高血压读数的复测率
- 确诊前重复测量完成率
- 分层随访依从率
