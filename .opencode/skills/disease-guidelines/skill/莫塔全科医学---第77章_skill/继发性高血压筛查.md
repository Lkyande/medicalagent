# Skill: 继发性高血压筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第77章 高血压
- 页码: 第77章“继发性高血压”“表77.5 提示继发性高血压的临床特征”“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第77章.md`

**目标 / Objective**
筛查提示肾性、内分泌性或药物性高血压的特征,及时转入病因诊断路径。

**适用范围 / Scope**
- 40 岁以下高血压、急进性/恶性高血压或治疗效果差的病人

**操作步骤 / Procedure**
1. 识别起病年龄轻、严重度高、药物反应差或突然恶化等警讯。
2. 询问蛋白尿/血尿、夜尿、打鼾、阵发性头痛出汗心悸和药物暴露。
3. 查找腹部血管杂音、躯干肥胖紫纹、股动脉搏动减弱和腹部肿块等体征。
4. 完成尿检、肾功能、电解质和必要时肾血管或内分泌检查。
5. 对高度怀疑者及时转诊肾内或内分泌专科。

**注意事项 / Precautions**
- 肾脏疾病是最常见继发性高血压原因。
- 药物、替代疗法和睡眠呼吸暂停常被忽略。
- 继发性高血压不能只凭单一异常体征下结论。

**量化指标 / Metrics**
- 可疑病例继发性筛查记录率
- 尿检和电解质完成率
- 专科确诊转介率
