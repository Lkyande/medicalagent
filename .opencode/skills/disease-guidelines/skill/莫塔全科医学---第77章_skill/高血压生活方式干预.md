# Skill: 高血压生活方式干预

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第77章 高血压
- 页码: 第77章“非药物(生活方式)管理措施”“行为干预措施”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第77章.md`

**目标 / Objective**
通过有目标的生活方式调整降低血压并减少后续用药负担。

**适用范围 / Scope**
- 轻中度高血压或高正常血压,尤其尚无靶器官损害的病人

**操作步骤 / Procedure**
1. 评估体重、腰围、饮酒、钠摄入、运动、压力和吸烟情况。
2. 制定减重目标,说明每减重 1 kg 对血压下降的预期益处。
3. 将每日酒精限制在 1 至 2 个标准杯以内,并减少高盐加工食品。
4. 鼓励每周 150 至 300 分钟规律有氧活动,以散步等可执行方式起步。
5. 补充压力管理、健康饮食和睡眠呼吸暂停管理,3 个月后复评效果。

**注意事项 / Precautions**
- 非药物治疗适用于部分轻中度病人药前观察期。
- 戒烟虽未必持续降压,但能显著降低总体心血管风险。
- 需同时停用或替代升压药物,如 NSAIDs 和激素类药物。

**量化指标 / Metrics**
- 生活方式评估完整率
- 3 个月体重/血压改善率
- 升压药物暴露纠正率
