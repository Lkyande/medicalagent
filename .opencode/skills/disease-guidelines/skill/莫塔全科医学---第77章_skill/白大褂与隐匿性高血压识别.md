# Skill: 白大褂与隐匿性高血压识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第77章 高血压
- 页码: 第77章“24 小时动态监测”“白大褂高血压”“隐匿性高血压”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第77章.md`

**目标 / Objective**
识别诊室外血压与诊室血压不一致的病人,减少误诊和漏诊。

**适用范围 / Scope**
- 诊室血压波动明显、边界升高、疑似难治或伴靶器官损害的病人

**操作步骤 / Procedure**
1. 识别诊室读数与家庭表现不一致的线索,如在家测量正常或相反。
2. 对异常波动、临界高血压或疑似耐药者安排 24 小时动态监测或居家监测。
3. 若诊室高而院外正常,考虑白大褂高血压并继续定期随访。
4. 若诊室正常但院外升高或已有靶器官损害,考虑隐匿性高血压。
5. 根据院外监测结果决定是否启动或调整治疗。

**注意事项 / Precautions**
- 白大褂高血压心血管风险较低但仍可进展为真性高血压。
- 隐匿性高血压更容易被漏诊。
- 家庭血压监测是动态监测的实用补充。

**量化指标 / Metrics**
- 诊室-家庭血压不一致病人的院外监测率
- 白大褂高血压识别率
- 隐匿性高血压检出率
