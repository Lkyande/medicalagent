# Skill: 诊室血压标准测量

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第77章 高血压
- 页码: 第77章“高血压的测量”“诊室内测量血压指南”“记录”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第77章.md`

**目标 / Objective**
通过标准化诊室测量减少血压误差和高血压误诊。

**适用范围 / Scope**
- 18 岁及以上需筛查或随访高血压的病人

**操作步骤 / Procedure**
1. 让病人安静坐位休息至少 5 分钟,避免近期咖啡因、吸烟和进食影响。
2. 使用校准准确的血压计和合适袖带,将袖带置于与心脏同高位置。
3. 两次测量间隔至少 60 秒,缓慢放气约 2 mmHg/s。
4. 记录至少两次读数平均值,若差异较大则追加测量。
5. 同时记录心率和心律,对老年人和糖尿病病人补测站立位血压。

**注意事项 / Precautions**
- 不合适的袖带是常见测量误差来源。
- 心律不齐会影响血压读数准确性。
- 一次诊室升高不能直接下高血压诊断。

**量化指标 / Metrics**
- 诊室标准测压流程完成率
- 合适袖带使用率
- 平均双次读数记录率
