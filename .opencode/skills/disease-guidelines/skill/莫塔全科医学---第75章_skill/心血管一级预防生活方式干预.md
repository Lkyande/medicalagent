# Skill: 心血管一级预防生活方式干预

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第75章 心血管疾病
- 页码: 第75章“针对冠心病已知风险的二级预防”中生活方式/行为风险因素管理相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第75章.md`

**目标 / Objective**
围绕可改变危险因素制定可执行的心血管生活方式干预方案。

**适用范围 / Scope**
- 存在高血压、血脂异常、吸烟、肥胖、久坐或高绝对风险的成人病人

**操作步骤 / Procedure**
1. 使用 5A 框架逐项处理吸烟、饮酒、营养、运动、体重和压力管理。
2. 指导减少饱和脂肪和盐,倾向地中海式或整体健康饮食模式。
3. 设定每周至少 150 分钟中等强度活动目标。
4. 记录腰围和 BMI,并为超重病人组织减重支持。
5. 对焦虑、抑郁或慢性压力明显者,补充心理支持与压力管理措施。

**注意事项 / Precautions**
- 戒烟通常是获益最大的单项干预。
- 生活方式干预应具体而非泛泛建议“多运动少吃”。
- 家庭和社区支持可明显影响长期执行率。

**量化指标 / Metrics**
- 生活方式五要素记录率
- 吸烟者戒烟干预率
- 3 至 6 个月体重、腰围或活动改善率
