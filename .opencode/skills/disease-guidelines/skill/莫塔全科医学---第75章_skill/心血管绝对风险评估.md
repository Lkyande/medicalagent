# Skill: 心血管绝对风险评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第75章 心血管疾病
- 页码: 第75章“心血管绝对风险的评估”“具体的筛查建议”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第75章.md`

**目标 / Objective**
在一级预防中用绝对风险框架整合多项危险因素并指导干预强度。

**适用范围 / Scope**
- 无已知 CVD 的 45 岁及以上成人,或 35 岁及以上原住民/托雷斯海峡岛民

**操作步骤 / Procedure**
1. 确认病人是否属于需定期做绝对风险评估的人群。
2. 收集年龄、性别、吸烟、血压、血脂、糖尿病和肾病相关参数。
3. 对已自动归为高危的人群,如确诊 CVD 或高危糖尿病,不再重复低估性工具计算。
4. 根据绝对风险结果决定生活方式强化、筛查频率和是否启动预防用药。
5. 每 2 年或按风险变化重新评估并与病人共同讨论结果。

**注意事项 / Precautions**
- 绝对风险优于单看某一项指标。
- 已有明确高危状态者无需依赖普通风险图重复分类。
- 评估前应尽量补齐血压、血脂、糖尿病和肾病筛查信息。

**量化指标 / Metrics**
- 目标人群绝对风险评估覆盖率
- 高危病人干预启动率
- 风险复评完成率
