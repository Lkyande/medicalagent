# Skill: 呼吸困难体格检查重点执行

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第38章 呼吸困难
- 页码: 第38章“身体检查”“肺部湿啰音的原因”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第38章.md`

**目标 / Objective**
通过系统胸部和全身查体快速判断呼吸困难是局灶肺病、弥漫肺病还是心源性病变。

**适用范围 / Scope**
- 需要体格评估的呼吸困难病人

**操作步骤 / Procedure**
1. 先观察发绀、杵状指、辅助呼吸肌使用、肋间回缩和精神状态。
2. 让病人充分暴露胸部,完成视诊、叩诊和听诊,区分局灶性与弥漫性异常。
3. 听诊时要求张口深呼吸,注意细湿啰音、中湿啰音、粗湿啰音和哮鸣音的差异。
4. 结合啰音特点判断是否更支持肺炎、间质纤维化、心衰或气道黏液潴留。
5. 必要时结合气管位置、语颤和胸廓运动度综合判断塌陷、积液或气胸。

**注意事项 / Precautions**
- 扑翼样震颤提示可能存在二氧化碳潴留。
- 粗湿啰音常可咳嗽后改变,细湿啰音通常不能被咳嗽清除。
- 单靠“有喘鸣”不足以诊断哮喘,仍需结合病史和肺功能。

**量化指标 / Metrics**
- 规范胸部查体完成率
- 啰音类型记录率
- 查体与影像/肺功能一致率
