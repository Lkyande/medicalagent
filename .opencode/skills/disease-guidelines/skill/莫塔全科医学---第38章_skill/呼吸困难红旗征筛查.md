# Skill: 呼吸困难红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第38章 呼吸困难
- 页码: 第38章“呼吸困难红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第38章.md`

**目标 / Objective**
在呼吸困难首诊时快速识别需紧急处理的心肺和血栓性病因。

**适用范围 / Scope**
- 所有急性或进行性呼吸困难病人

**操作步骤 / Procedure**
1. 主动筛查突然发作、高龄、缺血性心脏病、近期旅行、HIV、药物滥用和体重减轻背景。
2. 询问咯血、胸壁创伤、小腿症状和哮喘过敏史。
3. 立即评估苍白/发绀、休息时呼吸困难、低血压、心动过速、呼吸急促和意识状态变化。
4. 查找小腿压痛、颈静脉充盈和喘鸣等关键体征。
5. 红旗征阳性时迅速进入胸片、血氧、心电图和急诊转运路径。

**注意事项 / Precautions**
- 呼吸困难伴真正器质性疾病时,不要误贴“焦虑”“缺锻炼”标签。
- 肺栓塞、急性心衰和气胸都可能突然发病,需按时间敏感病处理。
- 老年病人症状表达可能不典型,但危险度更高。

**量化指标 / Metrics**
- 红旗征记录率
- 高危呼吸困难急诊转诊率
- 心肺危重病因漏诊率
