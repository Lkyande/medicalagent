# Skill: 呼吸困难起病速度分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第38章 呼吸困难
- 页码: 第38章“病史”“发病时间相关性呼吸困难的典型原因”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第38章.md`

**目标 / Objective**
依据起病速度快速缩小呼吸困难病因范围并指导急缓分诊。

**适用范围 / Scope**
- 新发呼吸困难的门诊、急诊或电话分诊场景

**操作步骤 / Procedure**
1. 先确定呼吸困难是突然起病、数小时内、数日数周还是数月数年逐渐出现。
2. 对突然起病优先考虑气胸、肺栓塞、异物吸入、心律失常、过敏性休克和心肌梗死。
3. 对数小时内进展者重点考虑哮喘、COPD 急性加重、肺炎、左心衰和换气过度。
4. 对数日数周者考虑心衰、胸腔积液和气道肿瘤,对数月数年者考虑 COPD、结核和肺纤维化。
5. 同步将贫血、甲亢和肥胖等非呼吸性原因纳入鉴别。

**注意事项 / Precautions**
- 起病速度是最强线索之一,应在病史最早阶段明确。
- 突发静息性呼吸困难直到排除前应视为危急事件。
- 哮喘更常夜间和静息发作,COPD 更偏劳力性,有助于区分。

**量化指标 / Metrics**
- 起病时间分类记录率
- 病因分层与最终诊断一致率
- 危急病人分诊及时率
