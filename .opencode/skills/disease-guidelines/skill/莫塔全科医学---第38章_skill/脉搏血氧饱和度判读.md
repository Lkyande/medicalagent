# Skill: 脉搏血氧饱和度判读

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第38章 呼吸困难
- 页码: 第38章“脉搏血氧测定”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第38章.md`

**目标 / Objective**
利用经皮血氧快速判断低氧严重度并辅助分流呼吸困难病人。

**适用范围 / Scope**
- 所有急性或亚急性呼吸困难病人

**操作步骤 / Procedure**
1. 在安静状态下连接脉搏血氧仪并获取稳定读数。
2. 记录 SpO2 并结合年龄判断是否低于正常中位水平。
3. 将 <92% 视为非常严重的低氧提示,立即升级处理和监测。
4. 结合呼吸频率、意识状态和查体决定是否需要动脉血气分析。
5. 在治疗过程中重复测量,观察氧合趋势变化。

**注意事项 / Precautions**
- 脉搏血氧通常与动脉血氧饱和度误差不超过约 5%,但低灌注时要谨慎解释。
- 正常 SpO2 不能排除所有呼吸困难病因,仍需结合病史和查体。
- 低氧病人不应仅靠单次读数做决定,应看趋势和整体状态。

**量化指标 / Metrics**
- 呼吸困难病人血氧记录率
- 低氧识别及时率
- 治疗前后 SpO2 改善幅度
