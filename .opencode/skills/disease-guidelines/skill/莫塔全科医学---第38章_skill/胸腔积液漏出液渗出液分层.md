# Skill: 胸腔积液漏出液渗出液分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第38章 呼吸困难
- 页码: 第38章“胸腔积液”“漏出液”“渗出液”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第38章.md`

**目标 / Objective**
依据胸腔积液特征快速区分漏出液与渗出液,缩小病因范围并指导后续处理。

**适用范围 / Scope**
- 胸片或查体提示胸腔积液并伴呼吸困难的病人

**操作步骤 / Procedure**
1. 结合胸部体征和影像确认是否存在足量胸腔积液。
2. 对有症状病人行诊断性胸腔穿刺,检测蛋白和 LDH。
3. 将蛋白 <25g/L、LDH <200U/L 判为漏出液,优先考虑心衰、低蛋白血症或肝衰竭。
4. 将蛋白 >35g/L、LDH >200U/L 判为渗出液,优先考虑感染、恶性肿瘤、肺梗死和结缔组织病。
5. 对血性积液提高对恶性肿瘤、肺梗死和结核的警惕,并治疗根本病因。

**注意事项 / Precautions**
- 大量积液伴呼吸困难时可能需要反复抽液或胸膜固定术。
- 抽液分层只是病因线索,仍需结合临床背景和细胞学/微生物学检测。
- 单纯按影像不能区分漏出液与渗出液。

**量化指标 / Metrics**
- 胸腔穿刺完成率
- 分层与最终病因一致率
- 症状性积液缓解率
