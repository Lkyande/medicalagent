# Skill: PEFR床旁评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第38章 呼吸困难
- 页码: 第38章“呼气峰流速”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第38章.md`

**目标 / Objective**
用峰流速快速量化气道阻塞程度,辅助识别哮喘或慢性支气管炎相关呼吸困难。

**适用范围 / Scope**
- 怀疑哮喘或慢性气流受限的呼吸困难病人

**操作步骤 / Procedure**
1. 向病人示范迷你峰流速计的使用方法。
2. 让病人完成至少 3 次尽最大努力的呼气吹气。
3. 记录 3 次中的最佳值作为本次结果。
4. 将结果与按性别、年龄和身高推算的正常预计值比较。
5. 结合病史和症状变化决定是否进一步做肺活量测定或急性支气管舒张处理。

**注意事项 / Precautions**
- PEFR 是实用筛查工具,但不是肺活量测定的替代品。
- 测量前需确保病人理解动作,否则易低估真实能力。
- 严重呼吸窘迫病人可能无法安全完成,应优先稳定病情。

**量化指标 / Metrics**
- PEFR 测试完成率
- 最佳值记录率
- 与后续肺活量测定一致率
