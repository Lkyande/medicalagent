# Skill: 会厌炎与扁桃体周脓肿警示分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第62章 咽喉痛
- 页码: 第62章“扁桃体周脓肿”“急性会厌炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第62章.md`

**目标 / Objective**
及时识别会厌炎和扁桃体周脓肿这两类需急诊处理的深部咽喉感染。

**适用范围 / Scope**
- 单侧重度咽痛、进行性吞咽困难、流涎、张口困难或严重咽痛与体征不符的病人

**操作步骤 / Procedure**
1. 对单侧高热咽痛伴扁桃体周围明显隆起、悬雍垂偏移和张口困难者优先考虑扁桃体周脓肿。
2. 对严重咽痛、吞咽困难、流涎和颈痛但咽部外观近乎正常者警惕会厌炎。
3. 怀疑会厌炎时避免刺激性咽检,优先保障气道并立即住院。
4. 怀疑扁桃体周脓肿时安排医院抗生素治疗及抽吸或引流评估。
5. 记录发热、呼吸状态和吞咽能力,并向接诊专科明确报告高危判断依据。

**注意事项 / Precautions**
- 会厌炎在成人可被漏诊,不能因无明显扁桃体体征而放松警惕。
- 口服青霉素对扁桃体周脓肿往往不足,需要医院层面的处理。
- 深部感染进展快,门诊观察等待风险高。

**量化指标 / Metrics**
- 会厌炎和扁桃体周脓肿识别率
- 高危病人当日住院或 ENT 转诊率
- 气道危险病例延误率
