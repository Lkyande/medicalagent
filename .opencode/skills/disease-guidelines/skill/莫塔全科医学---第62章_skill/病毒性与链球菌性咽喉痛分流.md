# Skill: 病毒性与链球菌性咽喉痛分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第62章 咽喉痛
- 页码: 第62章“概率诊断”“链球菌性咽喉炎指南”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第62章.md`

**目标 / Objective**
根据症状和查体特征区分更可能的病毒性与 GABHS 性咽喉痛。

**适用范围 / Scope**
- 无立即气道危险的急性咽喉痛病人

**操作步骤 / Procedure**
1. 先寻找鼻漏、咳嗽、声音嘶哑、结膜炎和病毒性皮疹等病毒线索。
2. 再核查发热 ≥38.0℃、颈前淋巴结肿大、扁桃体渗出和无咳嗽 4 项 GABHS 特征。
3. 若以上四项聚集且病情较重,提高链球菌性扁桃体炎概率判断。
4. 若以咳嗽、鼻塞、声嘶和轻度咽充血为主,优先按病毒性咽炎处理。
5. 对判断不清或特殊流行场景,再决定是否加做咽拭子等辅助检查。

**注意事项 / Precautions**
- 临床特征只能分层概率,不能完全替代病原学证实。
- 儿童和青少年链球菌感染更常见,3 岁以下则相对少见。
- 腺病毒和 EBM 都可表现为渗出性扁桃体炎,不要见渗出就默认细菌感染。

**量化指标 / Metrics**
- 病毒性与细菌性初步分流记录率
- 不必要抗生素避免率
- 分流后复诊诊断修正率
