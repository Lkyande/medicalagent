# Skill: 链球菌性咽喉炎抗生素适应证把握

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第62章 咽喉痛
- 页码: 第62章“抗生素治疗适应证”“链球菌性咽喉炎的治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第62章.md`

**目标 / Objective**
仅在明确或高度怀疑 GABHS 获益场景下使用抗生素,避免过度处方。

**适用范围 / Scope**
- 考虑链球菌性扁桃体咽炎或需决定是否开具抗生素的病人

**操作步骤 / Procedure**
1. 确认是否存在重度扁桃体炎并伴典型 GABHS 特征。
2. 识别任何年龄的风湿性心脏病、猩红热或扁桃体周围蜂窝织炎/脓肿。
3. 对来自急性风湿热高发易感社区的 2 至 25 岁可疑病人降低用药门槛。
4. 符合适应证时选择青霉素 V 或相应替代药,并强调足疗程 10 日的重要性。
5. 不符合适应证时以支持治疗和安全网随访为主,避免经验性常规抗生素。

**注意事项 / Precautions**
- 抗生素通常只能缩短症状约 1 日,不能作为多数咽喉痛的默认方案。
- 扁桃体炎应避免随意使用阿莫西林,以免与 EBM 混淆后诱发皮疹。
- 治疗目标之一是降低风湿热风险,而不是单纯追求更快止痛。

**量化指标 / Metrics**
- 抗生素处方适应证符合率
- 足疗程完成率
- 不必要抗生素处方下降率
