# Skill: 咽喉痛对症支持治疗

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第62章 咽喉痛
- 页码: 第62章“咽喉痛和普通感冒的对症支持治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第62章.md`

**目标 / Objective**
为多数非重症咽喉痛提供标准化对症支持治疗,减少对抗生素的依赖。

**适用范围 / Scope**
- 无红旗征、以病毒性或未明确细菌性咽炎为主的病人

**操作步骤 / Procedure**
1. 建议充足饮水和舒缓性液体,包括冰棒等易耐受补液方式。
2. 按年龄给予对乙酰氨基酚、布洛芬或成人可溶性阿司匹林镇痛。
3. 可辅以舒缓性漱口液和休息,作为主要支持措施。
4. 鼻塞明显时可短期限量使用 3 日解充血剂。
5. 疼痛极重、吞咽困难或流涎时,在排除气道风险后考虑短程口服类固醇。

**注意事项 / Precautions**
- OTC 含片和局部喷雾的证据有限,不应替代基础支持治疗。
- 类固醇只适用于症状非常严重的短期减轻,不是常规用药。
- 对症治疗同时要向病人解释多数咽喉痛为自限性病毒感染。

**量化指标 / Metrics**
- 对症治疗宣教率
- 非抗生素管理接受率
- 48 至 72 小时症状缓解率
