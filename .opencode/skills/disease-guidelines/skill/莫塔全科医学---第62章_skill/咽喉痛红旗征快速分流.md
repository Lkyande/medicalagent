# Skill: 咽喉痛红旗征快速分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第62章 咽喉痛
- 页码: 第62章“咽喉痛的红旗征”“不能遗漏的严重疾病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第62章.md`

**目标 / Objective**
在首诊时快速识别需要紧急住院或上级评估的高危咽喉痛。

**适用范围 / Scope**
- 主诉咽痛、吞咽痛、扁桃体炎样症状或咽部深部疼痛的病人

**操作步骤 / Procedure**
1. 立即识别持续高热、喘鸣、呼吸窘迫、流涎和吞咽剧痛。
2. 检查是否存在扁桃体周围明显肿胀、抗生素治疗失败或疑似粒细胞缺乏。
3. 对伴念珠菌病者同步评估糖尿病或免疫抑制背景。
4. 若出现流涎并怀疑会厌炎,避免常规刺激性咽部检查并优先保障气道。
5. 将高危病人立即转急诊或 ENT,按会厌炎、扁桃体周脓肿或血液病路径处理。

**注意事项 / Precautions**
- 会厌炎在成人也可能表现为严重咽痛而咽部外观近乎正常。
- 咽喉痛并不总是感染,还需警惕异物、肿瘤和血液异常。
- 抗生素无效不应简单重复原方案,要重新评估诊断和并发症。

**量化指标 / Metrics**
- 高危咽喉痛识别率
- 紧急转诊及时率
- 会厌炎疑似病例不当咽检避免率
