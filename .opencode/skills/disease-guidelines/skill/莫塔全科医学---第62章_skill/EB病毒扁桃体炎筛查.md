# Skill: EB病毒扁桃体炎筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第62章 咽喉痛
- 页码: 第62章“陷阱”“爱泼斯坦-巴尔病毒所致单核细胞增多症筛查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第62章.md`

**目标 / Objective**
识别可能的 EBM 扁桃体炎,避免误用青霉素类药物并补充针对性检查。

**适用范围 / Scope**
- 渗出性扁桃体炎、软腭瘀点或乳黄色膜样覆盖的咽喉痛病人

**操作步骤 / Procedure**
1. 见到双侧扁桃体大块乳黄色膜样渗出时优先考虑 EBM。
2. 注意软腭瘀点、悬雍垂肿胀和鼻塞等支持线索。
3. 怀疑 EBM 时安排 EB 病毒 IgM 抗体检测。
4. 在结果未明前避免把此类扁桃体炎直接按链球菌感染给予阿莫西林或青霉素类。
5. 以支持治疗为主,并根据全身情况决定进一步随访或转诊。

**注意事项 / Precautions**
- EBM 是渗出性扁桃体炎最经典的误诊陷阱之一。
- 误用青霉素类可诱发严重皮疹,需在病历中明确提示。
- 单核细胞增多旧式筛查试验不是优先选择,本章推荐 IgM 检测。

**量化指标 / Metrics**
- 可疑 EBM 识别率
- IgM 检测完成率
- 可疑 EBM 中不当青霉素使用避免率
