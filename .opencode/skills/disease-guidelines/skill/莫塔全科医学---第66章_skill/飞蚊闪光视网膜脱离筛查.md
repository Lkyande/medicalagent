# Skill: 飞蚊闪光视网膜脱离筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第66章 视力受损
- 页码: 第66章“飞蚊症和闪光”“视网膜脱离”“玻璃体后脱离”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第66章.md`

**目标 / Objective**
在新发飞蚊或闪光病人中尽早识别视网膜脱离高风险信号。

**适用范围 / Scope**
- 主诉新出现闪光、飞蚊、蜘蛛网样影像或视野幕帘感的病人

**操作步骤 / Procedure**
1. 询问症状是否新发、突然出现及是否进行性加重。
2. 明确是否伴幕帘样遮挡、周边视野缺损或视力明显下降。
3. 核查近视史、既往眼科手术史和外伤史等高危背景。
4. 区分可能的玻璃体后脱离与疑似视网膜牵拉或脱离。
5. 对任何疑似视网膜脱离者安排紧急眼科散瞳检查。

**注意事项 / Precautions**
- 新发而非长期稳定的飞蚊更值得警惕。
- 近视人群视网膜脱离风险更高。
- 视力下降或幕帘感提示病情升级,不应观察等待。

**量化指标 / Metrics**
- 新发飞蚊闪光病人的急诊转诊率
- 高危背景记录率
- 视网膜脱离确诊前眼科评估时效
