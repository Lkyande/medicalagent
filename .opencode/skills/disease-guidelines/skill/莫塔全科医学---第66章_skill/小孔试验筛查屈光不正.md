# Skill: 小孔试验筛查屈光不正

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第66章 视力受损
- 页码: 第66章“小孔试验”“屈光不正”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第66章.md`

**目标 / Objective**
用简便的小孔试验快速判断视物模糊是否主要由屈光不正造成。

**适用范围 / Scope**
- 视物模糊、远近视力下降但无明显红眼或急性剧痛的病人

**操作步骤 / Procedure**
1. 先进行裸眼或现有矫正视力测量作为基线。
2. 让病人通过约 1 mm 针孔观察视标或固定目标。
3. 比较针孔前后视力是否明显改善。
4. 若明显改善,优先考虑屈光不正并安排验光或眼科随诊。
5. 若无改善或仅部分改善,继续寻找白内障、黄斑、视神经或其他病因。

**注意事项 / Precautions**
- 小孔试验只是筛查工具,不能替代完整眼科检查。
- 部分白内障病人也可能短暂改善,仍需进一步评估。
- 急性视力下降、闪光飞蚊或视野缺损者不应因小孔改善而延误转诊。

**量化指标 / Metrics**
- 视物模糊病人小孔试验完成率
- 小孔改善病例的验光转介率
- 小孔无改善病例进一步检查率
