# Skill: 视力受损初始评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第66章 视力受损
- 页码: 第66章“临床方法”“身体检查”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第66章.md`

**目标 / Objective**
对视力受损病人完成标准化首诊评估,初步区分屈光问题、眼底病变和神经通路病变。

**适用范围 / Scope**
- 主诉视力下降、视野缺损、失明或视觉扭曲的病人

**操作步骤 / Procedure**
1. 明确受累是单眼还是双眼,以及起病是急性、渐进性还是进行性。
2. 区分中央视力下降与周边视野缺损,并询问漂浮物、闪光、色晕、头痛和变形视。
3. 记录药物史、糖尿病、偏头痛、血管病和家族性眼病线索。
4. 完成视敏度、瞳孔反应、对诊视野、眼底检查和必要时眼压测量。
5. 根据初评决定是否进入急诊眼科转诊、常规眼科评估或进一步影像检查。

**注意事项 / Precautions**
- 除偏头痛外,几乎所有突发性失明都应视为急症。
- 单眼慢性视力下降可能只有病人本人能察觉,问诊需主动。
- 眼毒性药物史是关键线索,不能遗漏。

**量化指标 / Metrics**
- 视力受损病人的视敏度记录率
- 急性视力丧失当日转诊率
- 药物史记录完整率
