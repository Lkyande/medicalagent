# Skill: 突发无痛性视力丧失急转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第66章 视力受损
- 页码: 第66章“突然失明”“中央动脉阻塞”“颞动脉炎”“转诊时机”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第66章.md`

**目标 / Objective**
对突发无痛性视力丧失进行紧急分诊,减少可逆性失明窗口延误。

**适用范围 / Scope**
- 数分钟至数小时内发生单眼或双眼视力骤降的病人

**操作步骤 / Procedure**
1. 迅速确认起病时间、受累侧别和视力下降程度。
2. 询问一过性黑矇、血管危险因素、头痛、颞部压痛和栓塞病史。
3. 初步区分视网膜中央动脉阻塞、颞动脉炎、玻璃体积血和偏头痛相关视觉现象。
4. 完成基本视敏度、瞳孔和眼底快速检查,但不因检查延误转诊。
5. 对除偏头痛外的可疑急症立即眼科或急诊转运,并同步启动相关全身评估。

**注意事项 / Precautions**
- 老年人突然视力丧失尤其要警惕颞动脉炎或血管栓塞。
- 无痛不代表轻症,视网膜血管阻塞和颞动脉炎都可无明显眼痛。
- 短暂恢复也不能排除短暂性眼缺血。

**量化指标 / Metrics**
- 突发视力丧失当日急转诊率
- 眼血管事件疑似病例转运时效
- 颞动脉炎相关症状记录率
