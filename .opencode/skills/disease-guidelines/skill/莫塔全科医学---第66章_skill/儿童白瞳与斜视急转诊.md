# Skill: 儿童白瞳与斜视急转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第66章 视力受损
- 页码: 第66章“儿童视力受损”“转诊”“斜视”“白内障”“视网膜母细胞瘤”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第66章.md`

**目标 / Objective**
识别需要紧急眼科评估的儿童白瞳、持续斜视和视觉发育异常。

**适用范围 / Scope**
- 婴幼儿和儿童出现白瞳、斜视、缺乏注视追随或视觉发育异常时

**操作步骤 / Procedure**
1. 询问家长是否发现白瞳征、眼震、游荡眼神、怕光或不能注视跟随。
2. 检查红光反射,寻找混浊或猫眼反射样异常。
3. 判断斜视是持续性、交替性还是仅疲劳时短暂出现。
4. 对持续斜视或白瞳征立即考虑先天性白内障、视网膜母细胞瘤和青光眼。
5. 安排紧急眼科转诊,避免因弱视和潜在肿瘤延误造成永久损害。

**注意事项 / Precautions**
- 白瞳征的任何儿童都必须排除视网膜母细胞瘤。
- 持续斜视即使常规检查看似正常,也需要专科管理。
- 儿童白内障处理延误可导致不可逆弱视。

**量化指标 / Metrics**
- 儿童红光反射检查记录率
- 白瞳或持续斜视紧急转诊率
- 初诊至眼科评估时间
