# Skill: 红眼基础诊室检查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第40章 红眼和眼痛
- 页码: 第40章“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第40章.md`

**目标 / Objective**
用基层可得设备完成红眼的核心检查,提高严重病变识别率。

**适用范围 / Scope**
- 初诊红眼、眼痛或眼表刺激症状病人

**操作步骤 / Procedure**
1. 常规测量并记录双眼视力,必要时使用多孔镜辅助判断。
2. 检查瞳孔形态和反应,观察充血是否呈弥漫性或睫状充血。
3. 滴局部麻醉后做荧光素染色,寻找角膜擦伤、树枝状溃疡或溃疡面。
4. 外翻上眼睑检查睑板下异物,并同时检查双眼。
5. 有条件时测量眼压,并结合裂隙灯或放大镜完成角膜评估。

**注意事项 / Precautions**
- 视力测试是红眼检查的必做项目,不能省略。
- 局部麻醉后疼痛不缓解提示更深层病变,需升级评估。
- 未外翻上眼睑容易漏诊隐匿异物。

**量化指标 / Metrics**
- 红眼病人完整体检完成率
- 荧光素染色使用率
- 睑下异物漏诊率
