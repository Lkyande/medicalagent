# Skill: 红眼紧急转诊红旗征

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第40章 红眼和眼痛
- 页码: 第40章“红眼的红旗征(紧急眼科转诊)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第40章.md`

**目标 / Objective**
快速识别需要紧急眼科处理的红眼,避免视觉威胁性疾病延误。

**适用范围 / Scope**
- 所有红眼、眼痛或眼眶不适病人

**操作步骤 / Procedure**
1. 先评估是否存在重度眼痛、眼眶痛或明显畏光。
2. 立即检查有无视力下降、复视、瞳孔散大或角膜异常征象。
3. 识别眼球移位、眼内炎征象及眼眶蜂窝织炎提示。
4. 对隐形眼镜佩戴者出现疼痛性红眼时优先考虑微生物性角膜炎。
5. 任何红旗征阳性时停止常规处理流程并紧急眼科转诊。

**注意事项 / Precautions**
- 红眼合并视力下降往往不是单纯结膜炎,必须升级评估。
- 隐形眼镜相关角膜炎进展快,需要特别重视。
- 单侧红眼比双侧红眼更应警惕严重器质性病变。

**量化指标 / Metrics**
- 红眼病人视力记录率
- 红旗征识别及时率
- 视觉威胁性疾病延误转诊率
