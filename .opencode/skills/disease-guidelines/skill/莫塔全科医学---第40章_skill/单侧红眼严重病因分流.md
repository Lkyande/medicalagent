# Skill: 单侧红眼严重病因分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第40章 红眼和眼痛
- 页码: 第40章“临床方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第40章.md`

**目标 / Objective**
避免将单侧红眼误判为普通结膜炎,优先筛出需要急诊处理的病因。

**适用范围 / Scope**
- 以单侧红眼为主诉的病人

**操作步骤 / Procedure**
1. 先记录视力、疼痛程度、分泌物性质和畏光情况。
2. 主动询问外伤、异物、焊接光暴露和隐形眼镜佩戴史。
3. 将角膜溃疡、角膜炎、异物、虹膜炎和急性青光眼列为优先鉴别。
4. 发现视力下降、剧痛或明显畏光时立即转入紧急评估路径。
5. 仅在排除严重病因后才考虑病毒性结膜炎等较常见诊断。

**注意事项 / Precautions**
- 单侧红眼是单纯细菌性或过敏性结膜炎的情况并不常见。
- 隐形眼镜佩戴史会显著提高感染性角膜炎概率。
- 即使伴分泌物,也不能据此排除角膜或前房病变。

**量化指标 / Metrics**
- 单侧红眼视力检查率
- 严重病因首诊识别率
- 单侧红眼误诊为普通结膜炎率
