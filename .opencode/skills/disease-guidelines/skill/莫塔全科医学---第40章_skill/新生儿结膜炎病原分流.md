# Skill: 新生儿结膜炎病原分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第40章 红眼和眼痛
- 页码: 第40章“新生儿结膜炎(新生儿眼炎)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第40章.md`

**目标 / Objective**
依据起病时间和分泌物特征快速识别新生儿结膜炎的高危病原体并启动处理。

**适用范围 / Scope**
- 1 月龄内出现眼部分泌物或结膜炎表现的新生儿

**操作步骤 / Procedure**
1. 记录出生后起病天数,重点区分 1~2 日和 1~2 周内起病。
2. 对最初几天出现脓性分泌物者优先考虑淋球菌或其他严重细菌感染。
3. 对 1~2 周内出现中度黏液脓性分泌物者考虑沙眼衣原体并安排 PCR。
4. 明确需要对父母进行性传播感染评估、接触者追踪和同步治疗。
5. 依据病原风险立即启动相应全身或局部治疗并安排专科随访。

**注意事项 / Precautions**
- 新生儿结膜炎可快速造成严重角膜损伤和失明,处理不能延误。
- 淋球菌结膜炎具有高度传染性并可并发败血症。
- 单纯疱疹感染可伴眼睑小泡或角膜炎,必须单独识别。

**量化指标 / Metrics**
- 新生儿结膜炎病原学送检率
- 高危病例当日治疗启动率
- 家庭接触者评估完成率
