# Skill: 细菌性结膜炎分层处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第40章 红眼和眼痛
- 页码: 第40章“细菌性结膜炎”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第40章.md`

**目标 / Objective**
在排除严重病因后,对细菌性结膜炎进行卫生管理和局部抗感染治疗。

**适用范围 / Scope**
- 无视力下降和角膜受累征象的细菌性结膜炎病人

**操作步骤 / Procedure**
1. 根据晨起睫毛粘连、脓性分泌物和角膜透明等特征建立临床诊断。
2. 先用生理盐水清除分泌物和碎屑,并强调手卫生及单独毛巾使用。
3. 轻症病例可先行生理盐水冲洗并酌情加用局部抗菌滴眼液。
4. 重症病例按书中方案使用氯霉素等局部抗菌治疗并缩短复评间隔。
5. 对超急性、长期慢性或新生儿病例送分泌物培养并考虑特异病原体。

**注意事项 / Precautions**
- 结膜炎伴疼痛、畏光或视力下降时应重新考虑角膜炎或葡萄膜炎。
- 绝不要覆盖有分泌物的眼。
- 假单胞菌、淋球菌和衣原体需采用针对性方案,不能套用普通治疗。

**量化指标 / Metrics**
- 细菌性结膜炎卫生宣教率
- 适应证内培养送检率
- 5~7 日症状缓解率
