# Skill: 病毒性结膜炎交叉感染控制

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第40章 红眼和眼痛
- 页码: 第40章“病毒性结膜炎”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第40章.md`

**目标 / Objective**
在提供对症治疗的同时降低病毒性结膜炎的交叉传播风险。

**适用范围 / Scope**
- 临床诊断为病毒性结膜炎或流行性红眼的病人

**操作步骤 / Procedure**
1. 根据水样分泌物、滤泡反应、耳前淋巴结肿大和接触史支持诊断。
2. 明确告知病人此病传染性强,需严格执行手卫生和物品分开使用。
3. 采用冷敷、盐水浴或人工泪液等对症措施缓解不适。
4. 叮嘱避免覆盖患眼并尽量避强光,观察是否继发细菌感染。
5. 避免使用糖皮质激素滴眼液,除非已由眼科明确指示。

**注意事项 / Precautions**
- 类固醇可延缓病毒清除,基层不应常规使用。
- 病程可持续 2~3 周甚至更久,需提前设定病程预期。
- 出现角膜受累、视力变化或剧痛时需重新评估并转诊。

**量化指标 / Metrics**
- 病毒性结膜炎宣教覆盖率
- 家庭或工作场所继发传播率
- 不恰当类固醇使用率
