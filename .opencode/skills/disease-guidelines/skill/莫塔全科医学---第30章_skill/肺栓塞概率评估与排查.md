# Skill: 肺栓塞概率评估与排查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第30章 胸痛
- 页码: 第30章“肺栓塞”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第30章.md`

**目标 / Objective**
识别肺栓塞的临床高危特征并合理使用 Wells 评分、D-二聚体和 CTPA。

**适用范围 / Scope**
- 胸痛伴呼吸困难、晕厥、咯血或 DVT 风险因素病人

**操作步骤 / Procedure**
1. 询问是否存在静脉炎、小腿疼痛、长期制动、近期手术或恶性肿瘤背景。
2. 识别胸骨后痛、呼吸困难、晕厥、低血压或咯血等表现,并判断是否可能为无痛型 PE。
3. 结合临床表现使用 Wells 评分做概率分层。
4. 低至中概率病人用 D-二聚体辅助排除,高概率病人直接安排 CT 肺血管造影。
5. 对疑似重度 PE 病人同时监测右心衰竭和休克表现并紧急转院。

**注意事项 / Precautions**
- 仅有呼吸困难而无胸痛时也不能排除 PE。
- 大面积 PE 可出现右心负荷心电图改变,但 ECG 也可能正常。
- D-二聚体适用于排除低概率病人,不能替代高危病人的影像确诊。

**量化指标 / Metrics**
- Wells 评分记录率
- 高危病人 CTPA 完成率
- PE 漏诊率
