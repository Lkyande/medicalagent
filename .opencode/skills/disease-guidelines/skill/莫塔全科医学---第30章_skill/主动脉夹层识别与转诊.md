# Skill: 主动脉夹层识别与转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第30章 胸痛
- 页码: 第30章“主动脉夹层”“引起胸痛的其他疾病的治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第30章.md`

**目标 / Objective**
在胸痛首诊时识别主动脉夹层并迅速转入影像和外科路径。

**适用范围 / Scope**
- 突发撕裂样胸骨后或肩胛间痛,伴脉搏不对称或神经缺损病人

**操作步骤 / Procedure**
1. 识别突发严重近中线胸骨后或肩胛间撕裂样疼痛,并追问向腹部、腰部或腿部放射。
2. 检查双侧颈、桡和股动脉脉搏是否对称,并测量血压。
3. 评估是否伴晕厥、轻偏瘫、主动脉瓣反流杂音或休克。
4. 立即联系具备经食管超声、CTA 或 MRI 能力的医院进行诊断。
5. 在等待转运时控制高血压并尽快转胸外科/血管外科,尤其是 A 型夹层。

**注意事项 / Precautions**
- 妊娠期间发病率增加,孕产妇突发胸背痛也要考虑夹层。
- 夹层可合并冠脉受累而表现像 ACS,需特别警惕脉搏差异。
- 这是外科急症,不要在基层长时间观察。

**量化指标 / Metrics**
- 识别至转运时间
- 脉搏不对称检查率
- 早期影像确认率
