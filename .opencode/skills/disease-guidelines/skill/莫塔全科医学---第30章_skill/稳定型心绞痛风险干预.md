# Skill: 稳定型心绞痛风险干预

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第30章 胸痛
- 页码: 第30章“稳定型心绞痛的管理”“预防”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第30章.md`

**目标 / Objective**
通过系统危险因素管理和合理活动建议减少稳定型心绞痛复发。

**适用范围 / Scope**
- 已诊断稳定型心绞痛的门诊病人

**操作步骤 / Procedure**
1. 逐项干预危险因素:戒烟、减重、低脂健康饮食、控制高血压、糖尿病和血脂。
2. 向病人说明稳定型心绞痛总体预后通常较好,减少过度恐惧。
3. 鼓励在不诱发疼痛的强度下规律活动,如每日步行约 20 分钟。
4. 指导识别并避免个人诱发因素,包括寒冷、饱餐和情绪应激。
5. 结合药物方案定期复查症状变化,必要时升级为进一步检查或介入评估。

**注意事项 / Precautions**
- 不应因心绞痛而过度限制生活方式,关键是控制活动强度。
- 压力管理和放松训练对部分病人同样重要。
- 若症状在一个月内变得更频繁或更重,需重新评估是否已转为不稳定型心绞痛。

**量化指标 / Metrics**
- 危险因素控制达标率
- 每周规律运动达标率
- 心绞痛发作频率下降幅度
