# Skill: 急性胸痛红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第30章 胸痛
- 页码: 第30章“急性胸痛的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第30章.md`

**目标 / Objective**
在胸痛初诊时快速识别需要紧急送医的心血管和肺部灾难性病因。

**适用范围 / Scope**
- 所有急性胸痛或胸背痛病人

**操作步骤 / Procedure**
1. 主动筛查疼痛持续时间、晕厥、呼吸困难、出汗、恶心呕吐和背痛放射。
2. 关注胸痛是否在休息时发生、是否持续超过 15 分钟或伴进行性恶化。
3. 结合高危背景评估冠心病危险因素、DVT/术后卧床史、马方综合征和高血压。
4. 立即测量生命体征并检查脉搏不对称、氧饱和度和双下肢血栓线索。
5. 红旗征阳性时按 ACS、PE、夹层或气胸路径启动急诊评估和转运。

**注意事项 / Precautions**
- 老年、女性、糖尿病和高血压病人心肌梗死可表现不典型或无痛。
- 无法明确前,应优先按心源性胸痛处理而非先归因于胸壁痛。
- 胸膜性锐痛和按压痛可降低 MI 概率,但不能单独排除严重病因。

**量化指标 / Metrics**
- 红旗征记录率
- 急性高危胸痛转运时间
- 危重胸痛漏诊率
