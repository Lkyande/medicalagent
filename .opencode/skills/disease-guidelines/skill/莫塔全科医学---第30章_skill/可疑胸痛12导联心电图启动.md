# Skill: 可疑胸痛12导联心电图启动

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第30章 胸痛
- 页码: 第30章“辅助检查”“心电图”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第30章.md`

**目标 / Objective**
确保所有可疑缺血性胸痛病人尽早完成 12 导联心电图并据此分流。

**适用范围 / Scope**
- 怀疑 ACS、PE、心包炎或夹层相关胸痛病人

**操作步骤 / Procedure**
1. 将任何可疑胸痛定义为心电图适应证,尽快完成 12 导联记录。
2. 观察是否存在 ST 段抬高、ST 压低、T 波倒置、右心负荷或心包炎弓背样抬高。
3. 结合病史和体征区分 STEMI、NST-ACS、PE 或心包炎可能。
4. 若初始心电图正常但症状仍高度可疑,安排重复心电图和进一步酶学检查。
5. 将结果用于决定是否立即启动再灌注、住院监护或其他影像检查。

**注意事项 / Precautions**
- 早期心肌梗死心电图可以正常,正常心电图不能排除 ACS。
- 新发左束支传导阻滞可提示心肌梗死。
- 心电图是院外急性冠脉分类和再灌注决策的核心依据。

**量化指标 / Metrics**
- 首次胸痛到心电图时间
- 重复心电图执行率
- 心电图驱动正确分流率
