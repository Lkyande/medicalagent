# Skill: 胸痛SOCRATES病史采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第30章 胸痛
- 页码: 第30章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第30章.md`

**目标 / Objective**
用结构化疼痛病史快速缩小胸痛病因范围并识别高危模式。

**适用范围 / Scope**
- 所有主诉胸痛的病人

**操作步骤 / Procedure**
1. 按 SOCRATES 框架记录疼痛部位、起病、性质、放射、伴随症状、持续时间、诱发缓解因素和严重度。
2. 追问是否劳力诱发、休息发生、寒冷诱发、与进食或平卧相关以及是否可被抗酸药缓解。
3. 询问伴随的呼吸困难、晕厥、咯血、发热、恶心、出汗和体重减轻。
4. 了解是否有外伤、皮疹、糖尿病、马方综合征、贫血或结缔组织病背景。
5. 将病史归类为缺血性、胸膜性、食管性、胸壁性或心因性模式,决定后续检查优先级。

**注意事项 / Precautions**
- 急性严重胸痛时详细病史可能受限,需边稳定病人边补充信息。
- 硝酸甘油可缓解食管痉挛,不能把“对硝酸甘油有效”直接等同于心绞痛。
- 双臂放射痛是急性心肌梗死的重要提示。

**量化指标 / Metrics**
- SOCRATES 要素记录率
- 高危伴随症状记录率
- 初始病因分层准确率
