# Skill: 舌下硝酸甘油用法宣教

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第30章 胸痛
- 页码: 第30章“急性发作和时有发作心绞痛”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第30章.md`

**目标 / Objective**
让病人正确使用舌下硝酸甘油并识别何时必须呼叫急救。

**适用范围 / Scope**
- 已确诊或疑似心绞痛并需备用短效硝酸酯病人

**操作步骤 / Procedure**
1. 教病人胸痛发作时先坐下,舌下含服硝酸甘油 300~600ug 或喷雾 400ug。
2. 若 5 分钟后仍痛,重复一次,最多 15 分钟内使用 3 次。
3. 若第 2 次后疼痛仍持续超过 10 分钟,第 3 次同时立即呼叫救护车。
4. 说明常见不良反应如头痛,并提示药物需避光避热保存。
5. 明确告知若近期使用西地那非、伐地那非或他达拉非,应避免使用硝酸酯。

**注意事项 / Precautions**
- 打开药瓶超过 3 个月或随身携带过久的药片效力可能下降。
- 硝酸甘油对食管痉挛也可能有效,症状缓解不等于病因已确认。
- 使用前坐下可减少低血压和晕厥风险。

**量化指标 / Metrics**
- 用药步骤复述正确率
- 因误用导致的低血压事件数
- 未及时呼救比例
