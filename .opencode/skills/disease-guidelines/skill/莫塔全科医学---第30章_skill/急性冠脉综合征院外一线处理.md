# Skill: 急性冠脉综合征院外一线处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第30章 胸痛
- 页码: 第30章“急性冠脉综合征的治疗”“可能是心脏原因的急性胸痛的一线管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第30章.md`

**目标 / Objective**
在院外或首诊场景尽早稳定可疑 ACS 病人并缩短再灌注前延迟。

**适用范围 / Scope**
- 怀疑 STEMI 或 NSTE-ACS 的急性缺血性胸痛病人

**操作步骤 / Procedure**
1. 立即完成 12 导联心电图并通过电话通知接收医院或监护转运团队。
2. 建立静脉通道并抽血,同时仅在血氧低时给予 4~6L/min 吸氧。
3. 尽早给予阿司匹林 300mg 嚼服,如无禁忌可使用硝酸甘油缓解疼痛。
4. 疼痛明显时静脉缓慢给予吗啡并监测反应。
5. 尽快启动冠心病监护转运,目标是进入再灌注通道而不是延长门诊停留。

**注意事项 / Precautions**
- 硝酸酯使用前必须确认近 1~5 日内未使用 PDE5 抑制剂。
- 不是所有 ACS 都需要常规吸氧,仅低氧血症时给予。
- 心电图是决定 STEMI 再灌注策略的核心依据。

**量化指标 / Metrics**
- 首次医疗接触到心电图时间
- 阿司匹林给药率
- 院外停留时间
