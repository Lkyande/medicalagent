# Skill: 胸痛体格检查重点执行

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第30章 胸痛
- 页码: 第30章“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第30章.md`

**目标 / Objective**
用针对性查体快速识别心肌梗死、主动脉夹层、肺栓塞和气胸的关键体征。

**适用范围 / Scope**
- 急性或亚急性胸痛病人

**操作步骤 / Procedure**
1. 先观察一般情况,识别苍白出汗、休克、发绀和偏瘫等危险表现。
2. 同时检查桡动脉和股动脉搏动,判断是否存在脉搏不对称或股动脉搏动消失。
3. 测量血压、体温、呼吸频率和氧饱和度。
4. 触诊胸壁、颈胸椎和双下肢,寻找局部压痛、带状疱疹或 DVT 证据。
5. 听诊胸部和心脏,识别气胸呼吸音减弱、摩擦音、奔马律、主动脉瓣反流杂音或肺底湿啰音。

**注意事项 / Precautions**
- 心肌梗死早期查体可能近乎正常,不能因听诊阴性而放松警惕。
- 主动脉夹层需特别留意脉搏差异和新发神经系统缺损。
- 上腹压痛并不排除胸痛的心源性病因,但可提示胆囊或消化性溃疡。

**量化指标 / Metrics**
- 生命体征完整记录率
- 双侧脉搏检查率
- 高危体征识别率
