# Skill: 稳定型心绞痛识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第30章 胸痛
- 页码: 第30章“心绞痛”“主要特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第30章.md`

**目标 / Objective**
在门诊识别典型稳定型心绞痛并与食管痛、夹层等鉴别。

**适用范围 / Scope**
- 劳力相关、短暂反复发作性胸骨后不适病人

**操作步骤 / Procedure**
1. 确认疼痛为胸骨后压榨样不适,常放射至手臂、下颌、咽喉或背部。
2. 询问是否由运动、情绪激动、饱餐或寒冷诱发。
3. 判断持续时间是否通常小于 10 分钟且休息几分钟可缓解。
4. 记录是否伴气短、恶心、无力和出汗,并评估冠心病危险因素。
5. 若病史符合,安排心电图与进一步缺血评估,同时开始危险因素干预和药物计划。

**注意事项 / Precautions**
- 心绞痛发作间歇体检可完全正常,病史仍是诊断基础。
- 食管痛、二尖瓣脱垂和夹层与其鉴别很重要。
- 持续时间延长或在休息时发作时,要升级为不稳定型心绞痛/ACS 评估。

**量化指标 / Metrics**
- 典型特征记录率
- 危险因素评估率
- 后续缺血评估完成率
