# Skill: 骨质疏松风险筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第81章 骨质疏松
- 页码: 第81章“表81.1 骨质疏松危险因素和/或病因”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第81章.md`

**目标 / Objective**
识别高骨折风险和骨质疏松高危病人并决定进一步评估。

**适用范围 / Scope**
- 绝经后女性、老年男性、长期激素使用者及低创伤骨折病人

**操作步骤 / Procedure**
1. 询问年龄、性别、早绝经、家族髋部骨折史和低 BMI 等不可改变因素。
2. 核查吸烟、饮酒、低钙摄入、维生素 D 缺乏和体力活动不足。
3. 主动排查内分泌病、吸收不良、RA、慢性器官衰竭和类固醇等继发因素。
4. 对已有脆性骨折、身高缩减或背痛者提高警觉。
5. 根据综合风险决定是否安排 DEXA、实验室检查或专科转诊。

**注意事项 / Precautions**
- 骨质疏松通常是静默性疾病,首发表现可能就是骨折。
- 男性也会发生骨质疏松,不要漏筛。
- 椎体骨折或病理骨折需要排除多发性骨髓瘤。

**量化指标 / Metrics**
- 高危人群骨折风险评估率
- 继发性病因筛查记录率
- 低创伤骨折后骨质疏松评估率
