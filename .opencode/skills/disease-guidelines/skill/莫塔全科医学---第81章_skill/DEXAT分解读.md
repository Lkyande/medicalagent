# Skill: DEXAT分解读

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第81章 骨质疏松
- 页码: 第81章“DEXA,T分和Z分”“表81.2 T分的解释说明”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第81章.md`

**目标 / Objective**
正确解读 DEXA 的 T 分和 Z 分并据此决定后续处理。

**适用范围 / Scope**
- 已接受骨密度检测的绝经后女性、老年男性和年轻高危病人

**操作步骤 / Procedure**
1. 优先查看脊柱和股骨颈 DEXA 结果,尤其关注股骨颈。
2. 用 T 分将结果分为正常、骨量减少或骨质疏松。
3. 若 T 分 ≤ -2.5,进入治疗或进一步骨折风险评估路径。
4. 对 50 岁以下、绝经前女性和儿童使用 Z 分而非 T 分解释。
5. 若 Z 分 < -2,积极寻找继发性骨丢失原因。

**注意事项 / Precautions**
- DEXA 是诊断骨质疏松的金标准。
- 不同部位和设备的 BMD 正常范围可能不同,应以标准化评分解释。
- 不能把一次 DEXA 结果脱离临床和骨折史单独解读。

**量化指标 / Metrics**
- DEXA 结果标准化分级记录率
- T 分 ≤ -2.5 病人的干预率
- 低 Z 分病人的继发病因追查率
