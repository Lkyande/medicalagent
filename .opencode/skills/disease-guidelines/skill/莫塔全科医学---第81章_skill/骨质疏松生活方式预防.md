# Skill: 骨质疏松生活方式预防

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第81章 骨质疏松
- 页码: 第81章“预防建议”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第81章.md`

**目标 / Objective**
通过钙、维生素 D、运动和跌倒预防减少骨量流失和脆性骨折。

**适用范围 / Scope**
- 骨量减少、骨质疏松高风险或已治疗中的病人

**操作步骤 / Procedure**
1. 评估并优化每日膳食钙摄入,必要时补充钙剂。
2. 检测并维持 25-羟维生素 D 充足水平,按缺乏程度补充。
3. 推荐对抗重力运动和规律步行,并根据能力调整强度。
4. 干预吸烟、过量酒精和过多咖啡因等可改变风险因素。
5. 同步实施跌倒预防和家庭安全评估。

**注意事项 / Precautions**
- 生活方式干预是所有药物治疗的基础。
- 维生素 D 建议需结合地区日照条件解释。
- 单纯补充剂不能替代运动和跌倒预防。

**量化指标 / Metrics**
- 钙和维生素 D 评估率
- 运动建议覆盖率
- 跌倒预防措施落实率
