# Skill: 吉兰巴雷呼吸监测与住院

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“急性炎症性多发性神经根神经病(吉兰-巴雷综合征)”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
对疑似或确诊 GBS 病人尽快建立呼吸监测和住院支持路径。

**适用范围 / Scope**
- 已怀疑或确诊 GBS 的病人

**操作步骤 / Procedure**
1. 立即安排住院治疗。
2. 起病早期每 2~4 小时监测肺活量和呼吸功能。
3. 评估是否需要气管切开或机械通气支持。
4. 启动物理治疗,预防腕足下垂和并发症。
5. 配合专科实施血浆置换或静脉注射免疫球蛋白治疗。

**注意事项 / Precautions**
- 类固醇通常不推荐作为常规治疗。
- 早期呼吸监测比等待主诉呼吸困难更可靠。
- 大多数病人可恢复,但早期监护决定结局。

**量化指标 / Metrics**
- GBS 住院转入率
- 肺活量监测及时率
- IVIG 或血浆置换启动率
