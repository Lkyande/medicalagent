# Skill: 多发性硬化MRI与腰穿转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“多发性硬化”“诊断”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
对疑似多发性硬化病人完成关键影像和辅助检查转诊路径。

**适用范围 / Scope**
- 临床高度怀疑 MS 但需客观证据支持者

**操作步骤 / Procedure**
1. 明确是否已有时间和空间多发的临床证据。
2. 优先安排 MRI,寻找增强病灶或新发病灶。
3. 必要时转诊行脑脊液寡克隆 IgG 检测。
4. 根据症状考虑视觉诱发电位评估视通路受累。
5. 与神经专科共同排除感染、肿瘤和压迫性病变后确诊。

**注意事项 / Precautions**
- MS 常在第二次复发或 MRI 出现新病灶后才能确诊。
- 腰穿并非每例都必需。
- 诊断依赖国际标准,不能仅凭单次症状发作。

**量化指标 / Metrics**
- 可疑 MS MRI 完成率
- 腰穿转诊完成率
- 诱发电位检查应用率
