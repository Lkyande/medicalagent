# Skill: 上睑下垂四因鉴别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“上睑下垂”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
对上睑下垂病人快速在动眼神经麻痹、霍纳综合征、线粒体肌病和重症肌无力间做初步鉴别。

**适用范围 / Scope**
- 单侧或双侧上睑下垂病人

**操作步骤 / Procedure**
1. 观察眼位是否“向下向外”并检查瞳孔大小和光反射。
2. 检查是否存在瞳孔缩小和同侧少汗,提示霍纳综合征。
3. 评估是否合并复视和疲劳性波动而无瞳孔受累,提示重症肌无力。
4. 询问进行性眼外肌麻痹或肢体活动诱发无力,考虑线粒体肌病。
5. 对疑似危重神经病因者紧急转诊进一步影像和专科评估。

**注意事项 / Precautions**
- 第 III 脑神经麻痹可能提示危及生命的颅内病变。
- 瞳孔是否受累是重要分层点。
- 单看“眼皮下垂”容易漏掉全身性神经肌肉疾病。

**量化指标 / Metrics**
- 上睑下垂病例瞳孔检查率
- 四因鉴别记录率
- 危重病例紧急转诊率
