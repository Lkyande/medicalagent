# Skill: 吉兰巴雷综合征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“急性炎症性多发性神经根神经病(吉兰-巴雷综合征)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
尽早识别对称性上行性无力和反射消失所提示的吉兰-巴雷综合征。

**适用范围 / Scope**
- 急性或亚急性四肢无力、感觉异常或面瘫病人

**操作步骤 / Procedure**
1. 识别通常对称的肢体无力,注意从远端向近端进展。
2. 询问肢体感觉异常或疼痛以及病程是否在数周内快速加重。
3. 检查反射是否减弱或消失。
4. 留意面部、延髓或眼外肌受累线索。
5. 一旦怀疑立即住院评估,不要等待完全瘫痪后再转诊。

**注意事项 / Precautions**
- 呼吸肌麻痹可致命。
- GBS 以运动受累为主,感觉体征可较轻。
- 需与脊髓病变和重症肌无力等鉴别。

**量化指标 / Metrics**
- 急性上行性无力病例 GBS 考虑率
- 反射检查完成率
- 住院转诊时效
