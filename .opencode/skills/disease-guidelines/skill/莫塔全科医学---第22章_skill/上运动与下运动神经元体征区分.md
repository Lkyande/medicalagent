# Skill: 上运动与下运动神经元体征区分

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“肌无力”“上运动神经元病变”“下运动神经元病变”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
通过床旁神经系统检查快速区分上运动神经元和下运动神经元病变。

**适用范围 / Scope**
- 出现肢体无力、步态异常或肌张力改变的病人

**操作步骤 / Procedure**
1. 评估肌无力是否伴明显肌萎缩。
2. 检查肌张力是增高呈痉挛性还是减低呈弛缓性。
3. 观察有无肌束颤动。
4. 检查腱反射、腹壁反射和跖反射方向。
5. 结合感觉系统和病变分布判断病灶位于中枢还是前角细胞以下。

**注意事项 / Precautions**
- 脊髓病变可在病灶平面出现 LMN 体征,平面以下出现 UMN 体征。
- 明确 UMN/LMN 模式有助于缩小卒中、MS、周围神经病和 GBS 等鉴别范围。
- 反射检查对分层判断价值很高。

**量化指标 / Metrics**
- 无力病例 UMN/LMN 体征记录率
- 跖反射检查完成率
- 神经定位准确率
