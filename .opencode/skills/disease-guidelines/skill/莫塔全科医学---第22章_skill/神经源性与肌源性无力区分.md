# Skill: 神经源性与肌源性无力区分

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“神经源性和肌源性肌无力”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
依据反射、感觉和萎缩模式区分神经源性与肌源性无力。

**适用范围 / Scope**
- 需进一步分层判断病因的肌无力病人

**操作步骤 / Procedure**
1. 判断严重无力时反射是否仍保留。
2. 评估肌无力与肌萎缩是否成比例。
3. 检查感觉是否正常或合并异常。
4. 观察是否存在肌束颤动。
5. 结合近端或远端分布模式初步归为肌源性或神经源性并安排后续检查。

**注意事项 / Precautions**
- 肌源性无力常感觉正常且反射相对保留。
- 神经源性病变即便轻度无力也可早期反射消失。
- 多发性肌炎偶可出现肌束颤动,需结合全貌判断。

**量化指标 / Metrics**
- 无力病例感觉检查记录率
- 反射与萎缩模式记录率
- 后续电生理转诊率
