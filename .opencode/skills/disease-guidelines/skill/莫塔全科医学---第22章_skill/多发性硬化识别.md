# Skill: 多发性硬化识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“多发性硬化”“临床特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
在时间和空间多发的神经系统症状中识别多发性硬化的可疑模式。

**适用范围 / Scope**
- 20~50 岁反复出现视觉、感觉、无力或脑干症状者

**操作步骤 / Procedure**
1. 识别女性高发、反复缓解复发的病程特点。
2. 询问视神经炎、复视、单侧或双侧下肢无力、束带感、麻木和眩晕。
3. 检查是否存在上运动神经元体征、眼震、共济失调和区域性感觉障碍。
4. 判断症状是否无法由单一解剖病灶解释,提示时间与空间多发。
5. 尽早安排 MRI 并转神经专科进一步确诊。

**注意事项 / Precautions**
- 早期诊断困难,高度警惕性最关键。
- 膀胱症状、三叉神经痛和精神症状也可为混淆线索。
- 必须排除感染、肿瘤和脊髓压迫等其他病因。

**量化指标 / Metrics**
- 可疑 MS 多发病灶特征记录率
- MRI 完成率
- 神经专科转诊率
