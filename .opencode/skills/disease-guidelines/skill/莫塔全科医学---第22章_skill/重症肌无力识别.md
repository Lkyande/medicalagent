# Skill: 重症肌无力识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“重症肌无力”“临床特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
识别波动性、易疲劳的眼肌、延髓或肢体无力模式,提示重症肌无力。

**适用范围 / Scope**
- 上睑下垂、复视、吞咽困难或活动后加重无力病人

**操作步骤 / Procedure**
1. 询问无痛性疲劳和一天中波动加重的无力。
2. 重点检查上睑下垂、复视及向上注视后是否加重。
3. 评估咀嚼、吞咽、言语、吹口哨和摇头能力。
4. 检查近端和远端肢体以及呼吸肌是否受累。
5. 识别诱发因素如感染、妊娠、手术和情绪应激。

**注意事项 / Precautions**
- 经典线索是眼部和面部同时无力。
- 眼肌型可进展为全身型。
- 可能与胸腺瘤和其他自身免疫病相关。

**量化指标 / Metrics**
- 疲劳性无力试验完成率
- 眼部和延髓体征记录率
- 胸腺评估转诊率
