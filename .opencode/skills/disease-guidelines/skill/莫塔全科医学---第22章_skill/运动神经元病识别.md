# Skill: 运动神经元病识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“运动神经元病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
识别上、下运动神经元混合受累且感觉相对保留的运动神经元病。

**适用范围 / Scope**
- 进行性肢体无力、肌萎缩、肌束颤动或延髓症状病人

**操作步骤 / Procedure**
1. 询问抓握无力、足下垂、吞咽困难和构音障碍等渐进性症状。
2. 检查肌萎缩、肌束颤动、痉挛步态和反射亢进是否并存。
3. 观察是否有舌肌颤动和延髓麻痹表现。
4. 确认感觉系统和眼肌支配脑神经通常不受累。
5. 尽快转神经专科行电生理和 MRI 排除其他可治疗疾病。

**注意事项 / Precautions**
- MND 目前无法治愈,早期识别重在预后和支持治疗规划。
- 情绪不稳和抑郁可伴随出现。
- 需与脊髓压迫、脱髓鞘病和周围神经病鉴别。

**量化指标 / Metrics**
- 进行性无力病例 MND 红旗识别率
- 延髓症状记录率
- 神经专科转诊完成率
