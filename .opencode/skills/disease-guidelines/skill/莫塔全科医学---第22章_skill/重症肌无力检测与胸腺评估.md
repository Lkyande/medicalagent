# Skill: 重症肌无力检测与胸腺评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“重症肌无力”“诊断”“管理原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
对疑似重症肌无力病人完成抗体、电生理和胸腺肿瘤评估转诊路径。

**适用范围 / Scope**
- 临床怀疑重症肌无力的病人

**操作步骤 / Procedure**
1. 首选安排抗乙酰胆碱受体抗体检测。
2. 若抗体阴性但临床高度可疑,转诊做电生理检查。
3. 评估依酚氯铵试验是否需要在专科环境下实施。
4. 安排胸部 CT 或 MRI 以筛查胸腺瘤。
5. 结合全身受累程度转神经专科制定抗胆碱酯酶和免疫治疗方案。

**注意事项 / Precautions**
- 腾喜龙试验有风险,应在适当条件下进行。
- 全身型病人常需要尽早考虑胸腺切除术。
- 不应忽视呼吸衰竭风险评估。

**量化指标 / Metrics**
- MG 抗体检测率
- 胸部影像完成率
- 神经专科管理衔接率
