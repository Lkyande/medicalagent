# Skill: 帕金森病识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“帕金森病”“帕金森病经典五联征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
依据病史和体格检查尽早识别帕金森病的核心运动与非运动特征。

**适用范围 / Scope**
- 老年人跌倒、动作变慢、震颤、步态异常或自主神经症状者

**操作步骤 / Procedure**
1. 识别静止性震颤、肌强直、运动迟缓、姿势不稳和冻结步态等核心体征。
2. 询问嗅觉减退、便秘、快动眼睡眠障碍和直立性低血压等前驱症状。
3. 检查快速轮替动作减慢、摆臂减少、齿轮样强直和小写征。
4. 观察步态是否小碎步、拖曳、转身缓慢或易冻结。
5. 对高度怀疑病例尽早转神经专科共享管理。

**注意事项 / Precautions**
- 起病常单侧,且早期未必有明显震颤。
- 甲减和抑郁可造成运动缓慢而混淆诊断。
- 老年跌倒病人必须想到帕金森病。

**量化指标 / Metrics**
- 可疑帕金森病五联征记录率
- 非运动症状询问率
- 专科转诊完成率
