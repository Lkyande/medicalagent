# Skill: 原发性震颤识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“原发性震颤”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
识别原发性震颤的典型家族性姿势性震颤模式,避免误诊为帕金森病。

**适用范围 / Scope**
- 双手姿势性震颤、头部震颤或书写受影响病人

**操作步骤 / Procedure**
1. 询问家族史和发病年龄,尤其成年早期或青春期起病者。
2. 确认震颤在手臂伸展和动作中最明显,休息时不明显。
3. 检查是否累及头部、下颌或舌头,并影响书写或持物。
4. 询问焦虑是否加重、少量饮酒是否缓解。
5. 同时确认步态和摆臂是否正常,以支持与帕金森病鉴别。

**注意事项 / Precautions**
- 20% 病人可同时患有帕金森病和原发性震颤。
- 原发性震颤通常步态正常。
- 影像学对与帕金森病鉴别帮助有限。

**量化指标 / Metrics**
- 原发性震颤三联征记录率
- 步态观察完成率
- 酒精反应或家族史记录率
