# Skill: 震颤分型床旁评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“震颤”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
通过床旁观察将震颤分为静止性、姿势性、意向性或扑翼样,指导后续鉴别。

**适用范围 / Scope**
- 主诉手抖、头抖或动作不稳的病人

**操作步骤 / Procedure**
1. 在静息位观察是否存在静止性“搓丸样”震颤。
2. 让病人伸臂张指,观察姿势性或动作性震颤,必要时在手背放纸增强可见性。
3. 进行指鼻或跟膝胫试验,判断接近目标时是否加重为意向性震颤。
4. 让病人伸臂并过伸手腕,观察是否有扑翼样拍打。
5. 结合分型再追问家族史、酒精效应、药物和系统性疾病线索。

**注意事项 / Precautions**
- 扑翼样震颤并非严格意义上的震颤,多提示代谢性脑病。
- 单看“手抖”容易把帕金森病和原发性震颤混淆。
- 分散注意力有助于诱发帕金森静止性震颤。

**量化指标 / Metrics**
- 震颤类型记录率
- 指鼻试验完成率
- 药物与家族史记录率
