# Skill: Bell麻痹识别与激素启动

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“Bell麻痹”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
识别特发性面神经麻痹并在时窗内启动糖皮质激素治疗。

**适用范围 / Scope**
- 急性单侧下运动神经元性面瘫病人

**操作步骤 / Procedure**
1. 识别突然发生的单侧面肌无力,并判断是否在 2~5 日内进展。
2. 询问耳内或耳后前驱疼痛以及味觉丧失、听觉过敏等伴随症状。
3. 检查闭眼困难、Bell 现象和额纹受累情况。
4. 在发病 48 小时内按推荐方案启动泼尼松治疗。
5. 同时评估是否存在耳部疱疹提示 Ramsay-Hunt 综合征。

**注意事项 / Precautions**
- Bell 麻痹是下运动神经元性面瘫,需与中枢性面瘫区分。
- 抗病毒药获益证据较弱,不应替代激素时机。
- 大多数病人可完全恢复,但早期治疗更有利。

**量化指标 / Metrics**
- 面瘫病例 48 小时内激素启动率
- Bell 现象检查记录率
- Ramsay-Hunt 线索筛查率
