# Skill: 帕金森病药物诱发筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“帕金森病”“关键事实和要点”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
在帕金森综合征表现病人中排查常见药物诱发原因。

**适用范围 / Scope**
- 新发僵硬、运动迟缓或帕金森样步态病人

**操作步骤 / Procedure**
1. 详细询问近期和长期使用的精神科、止吐和其他相关药物。
2. 重点核查吩噻嗪类、丁酰苯类和利血平使用史。
3. 判断症状是否以僵硬和运动迟缓为主而震颤不明显。
4. 结合时间关系评估是否为药物诱发帕金森综合征。
5. 与相关专科协作调整致病药物并继续观察症状演变。

**注意事项 / Precautions**
- 药物性帕金森综合征非常常见且容易漏问。
- 不能在未评估风险的情况下擅自停用精神科药物。
- 双侧起病和对左旋多巴反应差需考虑非典型帕金森综合征。

**量化指标 / Metrics**
- 帕金森综合征病例用药史记录率
- 可疑药物识别率
- 药物调整后复评率
