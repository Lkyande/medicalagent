# Skill: 复视危险病因筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“复视”“关键的辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
在复视病人中快速筛查脑血管、感染、肿瘤和代谢性危险病因。

**适用范围 / Scope**
- 新发复视,尤其伴其他神经系统或全身症状者

**操作步骤 / Procedure**
1. 询问头部外伤、卒中样发作、鼻窦炎、免疫缺陷和毒物药物暴露史。
2. 识别是否伴肢体无力、共济失调、意识改变或脑神经多发受累。
3. 初始安排尿检、血糖、全血细胞计数和 ESR/CRP。
4. 按指征追加甲状腺功能和影像学检查。
5. 对近期起病且持续的双眼复视或怀疑脑神经麻痹者紧急转诊。

**注意事项 / Precautions**
- 海绵窦血栓、GBS、MG 和 MS 都可能表现为复视。
- 眼眶浸润性病变是常被遗漏的陷阱。
- 单纯“没有其他阳性发现”不能排除严重病因。

**量化指标 / Metrics**
- 新发复视病例危险病因筛查率
- ESR/CRP 完成率
- 紧急影像或专科转诊率
