# Skill: 双眼复视定位评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“复视”“诊室内测试”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
通过基础床旁检查区分单眼与双眼复视,并初步定位受累眼外肌或脑神经。

**适用范围 / Scope**
- 急性或亚急性出现复视的成人病人

**操作步骤 / Procedure**
1. 先区分复视与单纯视物模糊。
2. 分别遮盖单眼,判断复视在遮盖任一眼时是否消失。
3. 询问复视是水平、垂直还是倾斜,并明确最明显的注视方向。
4. 让病人双眼跟随手指做“H”字运动,观察哪一方向加重。
5. 根据受限方向推测第 III、IV、VI 脑神经或对应眼外肌受累。

**注意事项 / Precautions**
- 单眼复视提示眼部本身病变更多见。
- 持续性新发双眼复视需紧急转诊。
- 第 III 和 VI 脑神经麻痹需优先排除致命病因。

**量化指标 / Metrics**
- 复视病例单眼遮盖测试完成率
- 注视方向记录率
- 双眼复视紧急转诊率
