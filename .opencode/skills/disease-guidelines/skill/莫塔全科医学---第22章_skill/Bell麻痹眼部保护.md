# Skill: Bell麻痹眼部保护

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第22章 神经系统的难题
- 页码: 第22章“Bell麻痹”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第22章.md`

**目标 / Objective**
在 Bell 麻痹病人中预防暴露性角膜损伤并指导康复护理。

**适用范围 / Scope**
- 闭眼不全或眼干的面神经麻痹病人

**操作步骤 / Procedure**
1. 评估眼睑闭合是否不全及角膜暴露程度。
2. 在风大、多尘环境和睡眠期间指导使用胶布固定保护眼睑。
3. 对眼干者指导使用人工泪液,尤其睡前。
4. 恢复期开始面肌按摩和功能锻炼。
5. 解释自然病程并安排复诊监测恢复情况。

**注意事项 / Precautions**
- 角膜暴露是需要优先防范的并发症。
- 轻症完全恢复概率更高。
- 若恢复异常缓慢或出现非典型体征需重新评估诊断。

**量化指标 / Metrics**
- 面瘫病例眼部保护指导率
- 人工泪液使用指导率
- 复诊随访安排率
