# Skill: 玫瑰糠疹识别与释疑

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第114章 急性皮疹暴发
- 页码: 第114章“玫瑰糠疹”“临床特点”“预后”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第114章.md`

**目标 / Objective**
识别典型玫瑰糠疹并给予自限性疾病的解释与瘙痒处理。

**适用范围 / Scope**
- 年龄较大的儿童、青少年和年轻成人出现躯干急性鳞屑性皮疹时

**操作步骤 / Procedure**
1. 询问是否有前驱斑及 1 至 2 周后新皮疹扩散的病程。
2. 识别背部沿皮纹“圣诞树”样分布的椭圆红褐色鳞屑斑。
3. 与体癣、滴状银屑病、药疹和二期梅毒进行鉴别。
4. 向病人解释疾病通常 2 至 10 周内自限且不具传染性。
5. 对瘙痒明显者给予中性清洁、润肤和局部激素或紫外线辅助方案。

**注意事项 / Precautions**
- 前驱斑容易误认成癣。
- 玫瑰糠疹通常不伴显著全身不适。
- 自限性解释对降低焦虑很重要。

**量化指标 / Metrics**
- 玫瑰糠疹典型分布记录率
- 不必要抗感染治疗避免率
- 释疑教育完成率
