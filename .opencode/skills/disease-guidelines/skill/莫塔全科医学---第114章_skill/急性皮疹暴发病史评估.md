# Skill: 急性皮疹暴发病史评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第114章 急性皮疹暴发
- 页码: 第114章“诊断方法”“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第114章.md`

**目标 / Objective**
在急性出疹病中快速抓住决定性病史线索以缩小病因范围。

**适用范围 / Scope**
- 儿童或成人出现新发全身性皮疹、出疹伴发热或疑似药疹时

**操作步骤 / Procedure**
1. 记录皮疹起始部位、扩散方式和发展过程。
2. 询问近期用药、感染接触史、前驱斑、食物不耐受和刺激物暴露。
3. 询问是否伴发热、瘙痒、呼吸道症状或出血倾向。
4. 查体覆盖全身皮肤、掌跖、头皮、指甲、口咽和结膜。
5. 根据病史与分布判断更像病毒疹、药疹、荨麻疹或严重感染。

**注意事项 / Precautions**
- 药物反应是急性暴发皮疹的重要原因之一。
- 不能只看躯干皮疹,掌跖和黏膜信息很关键。
- 出血性皮疹和全身中毒表现需优先处理。

**量化指标 / Metrics**
- 急性皮疹病史完整率
- 用药史记录率
- 严重皮疹红旗识别率
