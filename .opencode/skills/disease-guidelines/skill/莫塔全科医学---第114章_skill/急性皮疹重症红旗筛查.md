# Skill: 急性皮疹重症红旗筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第114章 急性皮疹暴发
- 页码: 第114章“不能遗漏的严重疾病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第114章.md`

**目标 / Objective**
在暴发性皮疹中快速识别需要紧急处理的败血症、血管炎和重症药疹。

**适用范围 / Scope**
- 合并发热、黏膜受累、瘀点紫癜或全身症状的急性皮疹病人

**操作步骤 / Procedure**
1. 先排查瘀点/紫癜、黏膜病变、广泛疼痛性皮损和系统中毒表现。
2. 对脑膜炎球菌败血症、SJS/TEN、川崎病和严重血管炎保持高度怀疑。
3. 询问近期新药暴露和感染接触史。
4. 必要时安排 CBC、CRP、电解质及针对性病原或血清学检测。
5. 对高危病例立即转入急诊或住院路径。

**注意事项 / Precautions**
- 重症药疹和败血症性皮疹都可能致命。
- 掌跖和黏膜受累线索极其重要。
- 不要因“看起来像普通病毒疹”而忽视全身状态恶化。

**量化指标 / Metrics**
- 急性皮疹红旗筛查率
- 高危病例急诊转诊时效
- 重症皮疹漏诊率
