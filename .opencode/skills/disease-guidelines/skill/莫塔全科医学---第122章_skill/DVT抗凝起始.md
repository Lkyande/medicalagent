# Skill: DVT抗凝起始

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第122章 血栓形成和血栓栓塞
- 页码: 第122章“治疗”“方法一”“方法二”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第122章.md`

**目标 / Objective**
为已确诊或高度疑似 DVT 病人快速启动规范抗凝治疗。

**适用范围 / Scope**
- 深静脉血栓形成或肺栓塞确诊/高度怀疑的成人病人

**操作步骤 / Procedure**
1. 在起始抗凝前抽血检查 APTT、INR、血小板和肝肾功能。
2. 根据禁忌和可及性选择低分子肝素桥接华法林或直接口服抗凝药路径。
3. 解释疗程时长与病因、部位和复发风险相关。
4. 指导活动、弹力袜和出血警示症状。
5. 安排 INR 或肾功能等相应监测和随访。

**注意事项 / Precautions**
- 不要同时随意合用阿司匹林。
- 肾功能损害时 DOAC 需谨慎或禁用。
- 疗程需个体化,从 6 周到长期不等。

**量化指标 / Metrics**
- DVT 抗凝启动时效
- 基线化验完成率
- 规范疗程记录率
