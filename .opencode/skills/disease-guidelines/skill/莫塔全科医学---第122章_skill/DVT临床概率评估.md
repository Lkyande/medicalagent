# Skill: DVT临床概率评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第122章 血栓形成和血栓栓塞
- 页码: 第122章“深静脉血栓形成”“危险因素”“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第122章.md`

**目标 / Objective**
根据危险因素和体征快速判断 DVT 的临床可能性并安排客观检查。

**适用范围 / Scope**
- 单侧小腿或大腿肿胀、压痛或无痛性肿胀的病人

**操作步骤 / Procedure**
1. 评估既往血栓史、家族史、肿瘤、手术、制动、妊娠、长途飞行和激素药物暴露。
2. 比较双下肢有无肿胀、不对称、红斑、温暖和凹陷性水肿。
3. 避免做 Homan 征。
4. 结合 Wells 概念和临床概率决定 D-二聚体或多普勒超声路径。
5. 高概率病人直接安排影像学,而不是依赖正常 D-二聚体单独排除。

**注意事项 / Precautions**
- DVT 可无症状或仅表现为单侧肿胀。
- 未治疗血栓栓塞后果严重,客观确认很重要。
- 临床概率高时升高的 D-二聚体缺乏特异性,正常值也不能替代影像。

**量化指标 / Metrics**
- DVT 风险因素记录率
- 临床概率分层率
- 超声完成时效
