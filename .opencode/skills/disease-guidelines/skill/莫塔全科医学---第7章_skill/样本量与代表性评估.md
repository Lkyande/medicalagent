# Skill: 样本量与代表性评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第7章 研究与循证医学
- 页码: 第7章“选择规模适度并有代表性的样本”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第7章.md`

**目标 / Objective**
确定既有统计意义又切实可行的样本量,并尽量保证研究样本的代表性。

**适用范围 / Scope**
- 临床研究和服务审计设计阶段

**操作步骤 / Procedure**
1. 明确目标总体和纳入标准。
2. 评估研究对象之间差异大小、对比组数量和预期要发现的差异幅度。
3. 结合统计要求和现实资源确定样本量范围。
4. 采用尽量严格的抽样或招募方式提高样本代表性。
5. 预估招募损耗,按预期样本量的约 3 倍准备潜在对象池。

**注意事项 / Precautions**
- 样本过小可能得不到有意义结论,过大则会造成资源浪费。
- 招募困难是常见瓶颈,应提前准备替代方案。
- 样本量足够不代表样本有代表性,二者都需考虑。

**量化指标 / Metrics**
- 目标样本达成率
- 招募成功率
- 样本特征与目标总体相似度
