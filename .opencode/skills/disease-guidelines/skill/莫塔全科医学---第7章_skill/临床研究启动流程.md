# Skill: 临床研究启动流程

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第7章 研究与循证医学
- 页码: 第7章“如何开展研究”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第7章.md`

**目标 / Objective**
以规范步骤启动临床研究,提高研究可行性、方法质量和最终发表可能性。

**适用范围 / Scope**
- 全科个人研究、诊所团队研究和学术合作项目

**操作步骤 / Procedure**
1. 明确研究想法和研究假设。
2. 与同事、导师或相关专家讨论并酝酿研究思路。
3. 完成文献检索和评判性回顾,确认问题尚未被充分回答。
4. 写出简要书面研究计划,包括目标、对象、方法和时间框架。
5. 请研究指导者或权威专家评估方案。
6. 细化方法学、样本选择、统计分析和伦理可行性。
7. 先做预试验,必要时申请研究资金。
8. 正式实施研究、分析数据、解释结果并准备发表。

**注意事项 / Precautions**
- 不要在方案不清晰前仓促开始收集数据。
- 伦理审批应在招募对象前完成。
- 初次研究最好在有经验研究者指导下进行。

**量化指标 / Metrics**
- 研究方案完成率
- 伦理审批通过率
- 项目按时间表推进率
