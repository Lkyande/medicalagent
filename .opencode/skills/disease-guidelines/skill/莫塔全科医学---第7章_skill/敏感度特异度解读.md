# Skill: 敏感度特异度解读

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第7章 研究与循证医学
- 页码: 第7章“灵敏度、特异度及预测值”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第7章.md`

**目标 / Objective**
正确解读诊断检查的敏感度、特异度和预测值,提升辅助检查选择和结果判断能力。

**适用范围 / Scope**
- 全科诊断决策、筛查解读和临床教学

**操作步骤 / Procedure**
1. 先明确检测目标是尽量发现真阳性还是尽量确认真阴性。
2. 用敏感度判断检测阴性时排除疾病的能力,记住 `SNOUT`。
3. 用特异度判断检测阳性时确认疾病的能力,记住 `SPIN`。
4. 结合目标人群患病率评估阳性和阴性预测值。
5. 在社区低患病率场景下,警惕阳性预测值下降带来的误判。

**注意事项 / Precautions**
- 敏感度和特异度高并不意味着在所有场景下都好用。
- 预测值受人群基线风险影响很大,医院与社区结果不能机械类推。
- 不能脱离临床前概率单独解读检测结果。

**量化指标 / Metrics**
- 检查前概率记录率
- 辅助检查解读正确率
- 不必要追加检查减少率
