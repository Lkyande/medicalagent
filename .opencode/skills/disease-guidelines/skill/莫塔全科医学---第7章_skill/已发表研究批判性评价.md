# Skill: 已发表研究批判性评价

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第7章 研究与循证医学
- 页码: 第7章“对已发表研究的评判式评价”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第7章.md`

**目标 / Objective**
快速判断一篇研究论文的方法质量、结果可靠性和临床适用性。

**适用范围 / Scope**
- 阅读新研究、制定诊疗策略和团队学术讨论

**操作步骤 / Procedure**
1. 先评估摘要是否清楚说明研究目的、设计和主要结果。
2. 判断研究设计是否适合所回答的问题。
3. 识别潜在设计缺陷、偏倚和样本选择问题。
4. 评估纳入对象是否足以支持结论外推。
5. 核对重要结果、统计解释和临床意义。
6. 关注研究是否存在行业赞助和可能的利益冲突。

**注意事项 / Precautions**
- 统计学显著不等于临床意义大。
- 阳性研究更容易发表和引用,需警惕发表偏倚。
- 不能只凭结论段决定是否应用该研究。

**量化指标 / Metrics**
- 关键评价问题覆盖率
- 阅读后临床可采纳结论形成率
- 因质量不足被排除文献比例
