# Skill: 研究文献检索与回顾

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第7章 研究与循证医学
- 页码: 第7章“如何开展研究”中“文献检索”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第7章.md`

**目标 / Objective**
系统检索并评判现有文献,避免重复研究并为研究设计和临床决策提供依据。

**适用范围 / Scope**
- 研究立项前、临床疑问求证和循证决策场景

**操作步骤 / Procedure**
1. 明确检索问题和核心关键词。
2. 使用 Medline、系统综述数据库或相关核心资料库检索文献。
3. 优先寻找系统综述、随机对照试验和高质量原始研究。
4. 对检索到的文献做评判性回顾,关注设计质量和结论适用性。
5. 总结已知证据、空白点和对本研究或临床问题的启示。

**注意事项 / Precautions**
- 不应只检索支持自己假设的文献。
- 文献数量多不等于证据质量高。
- 要警惕发表偏倚和行业赞助带来的偏差。

**量化指标 / Metrics**
- 文献检索完整率
- 高等级证据覆盖率
- 回顾后研究问题修正率
