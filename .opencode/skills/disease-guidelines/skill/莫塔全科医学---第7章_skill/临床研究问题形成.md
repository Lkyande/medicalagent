# Skill: 临床研究问题形成

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第7章 研究与循证医学
- 页码: 第7章“提出研究问题”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第7章.md`

**目标 / Objective**
把临床工作中的疑问转化为可回答、对病人有用的研究问题。

**适用范围 / Scope**
- 全科门诊质量改进、小型研究、团队研究和临床观察项目

**操作步骤 / Procedure**
1. 从临床实践中的真实疑问或反复出现的问题出发。
2. 将问题改写为一个能够回答的具体研究问题。
3. 判断研究结果无论阳性或阴性是否都对病人管理有价值。
4. 尽量形成一个清晰的初步研究假设。
5. 与同事或导师讨论问题是否有意义、相关且可行。

**注意事项 / Precautions**
- 过于宽泛或纯理论的问题往往难以落地。
- 研究问题应服务于病人利益,而不是仅满足好奇心。
- 初学者应优先选择范围小、可在现有场景完成的问题。

**量化指标 / Metrics**
- 可操作研究问题形成率
- 研究问题经导师评估通过率
- 问题转化为正式方案的比例
