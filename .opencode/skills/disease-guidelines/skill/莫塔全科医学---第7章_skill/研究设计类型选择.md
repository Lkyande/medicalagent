# Skill: 研究设计类型选择

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第7章 研究与循证医学
- 页码: 第7章“研究类型”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第7章.md`

**目标 / Objective**
根据研究问题性质选择合适的质性或定量研究设计,提高研究结果解释力。

**适用范围 / Scope**
- 全科研究方案设计阶段

**操作步骤 / Procedure**
1. 先明确问题是想回答“为什么/怎么样”还是“多少/是否有效”。
2. 对经验、观点和过程问题优先考虑质性研究。
3. 对频率、风险、关联和因果问题优先考虑定量研究。
4. 根据目标在病例对照、横断面、队列、随机对照试验或质性方法中选择。
5. 记录所选设计与研究目标的匹配理由。

**注意事项 / Precautions**
- 设计应由问题驱动,而非由研究者熟悉的方法倒推。
- 质性研究不等于不严谨,定量研究也不自动等于高质量。
- 初学者需避免选择超出资源和时间承受范围的设计。

**量化指标 / Metrics**
- 研究问题与设计匹配率
- 方案评审通过率
- 因设计不当导致方案返工率
