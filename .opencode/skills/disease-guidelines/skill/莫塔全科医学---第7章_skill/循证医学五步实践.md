# Skill: 循证医学五步实践

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第7章 研究与循证医学
- 页码: 第7章“循证医学”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第7章.md`

**目标 / Objective**
把最佳证据与临床判断和病人处境结合,用于个体化诊疗决策。

**适用范围 / Scope**
- 日常全科诊疗、预防决策和慢病管理

**操作步骤 / Procedure**
1. 构建一个清晰的临床问题或明确病人当前诊疗困惑。
2. 查找当前可获得的最佳证据。
3. 评估证据质量、相关性和对当前特殊情况的适用性。
4. 将证据与临床经验、病人偏好和具体情境结合后应用。
5. 评估应用后的实际效果并必要时调整。

**注意事项 / Precautions**
- 循证不等于机械照搬指南,仍需个体化判断。
- 若目前没有更优证据,不应仅因“新”而强行改变做法。
- 对不太可能有效的非凡主张,需要更高强度证据支持。

**量化指标 / Metrics**
- 临床问题被证据检索覆盖的比例
- 证据应用后疗效评估完成率
- 指南与病人实际情境一致率
