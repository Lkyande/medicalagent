# Skill: 良性色素病变释疑

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第117章 色素沉着的皮肤病变
- 页码: 第117章“黑脚跟”“黑癣”“雀斑”“雀斑样痣”“普通获得性痣”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第117章.md`

**目标 / Objective**
识别常见良性色素病变并给予恰当释疑,减少过度治疗。

**适用范围 / Scope**
- 雀斑、雀斑样痣、普通痣、黑脚跟或黑癣等常见色素病变病人

**操作步骤 / Procedure**
1. 根据部位、颜色、大小、对称性和病史判断是否为典型良性病变。
2. 对运动员足跟黑斑考虑黑脚跟,必要时轻削表皮验证表浅出血点。
3. 对掌跖黑斑考虑黑癣并做刮片真菌检查。
4. 对普通获得性痣说明自然演变和何种变化需要复诊。
5. 仅在美观困扰或诊断不确定时考虑干预或切除。

**注意事项 / Precautions**
- 掌跖或足跟黑斑需与黑色素瘤鉴别。
- 释除担忧是很多良性色素病变管理的主要任务。
- 对发生变化的痣不能因“看起来像老痣”而忽视。

**量化指标 / Metrics**
- 良性病变释疑记录率
- 不必要切除避免率
- 可疑变化病变复诊率
