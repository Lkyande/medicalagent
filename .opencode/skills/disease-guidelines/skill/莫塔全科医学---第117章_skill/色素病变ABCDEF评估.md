# Skill: 色素病变ABCDEF评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第117章 色素沉着的皮肤病变
- 页码: 第117章“关键事实和要点”“黑色素瘤”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第117章.md`

**目标 / Objective**
在门诊中快速评估色素病变恶性风险并决定观察或切除转诊。

**适用范围 / Scope**
- 新发、变化或令病人担忧的色素沉着皮肤病变

**操作步骤 / Procedure**
1. 观察病变是否不对称、边界不规则、颜色不均、直径增大或持续演变。
2. 核查病人是否有黑色素瘤家族史、晒伤史、发育不良痣或多痣背景。
3. 对可疑病变进行测量、摄影和必要的皮肤镜评估。
4. 对高危或变化病变安排切除或专科转诊。
5. 对典型良性病变进行释疑并给出自我监测建议。

**注意事项 / Precautions**
- 早期发现是黑色素瘤预后的关键。
- 并非所有黑色素瘤都来自已有痣。
- 青春期前黑色素瘤罕见,但成人尤其老年男性风险高。

**量化指标 / Metrics**
- 色素病变风险分层记录率
- 可疑病变切除/转诊率
- 影像随访建立率
