# Skill: 发育不良痣随访

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第117章 色素沉着的皮肤病变
- 页码: 第117章“发育不良黑色素细胞痣”“发育不良痣综合征”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第117章.md`

**目标 / Objective**
对发育不良痣及综合征病人建立规律监测和早期切除路径。

**适用范围 / Scope**
- 多发不规则痣、发育不良痣综合征或有黑色素瘤家族史的病人

**操作步骤 / Procedure**
1. 识别大于 5mm、边界不清、颜色不均且位于躯干的不规则痣。
2. 记录病灶尺寸并拍摄全身及局部照片。
3. 对有家族史或综合征者设立更密集的 3 至 6 个月随访。
4. 教病人和家属掌握自我监测重点。
5. 对任何变化或可疑病变立即切除并送组织学检查。

**注意事项 / Precautions**
- 发育不良痣是黑色素瘤风险标志,不一定每个都是癌前病变。
- 家族性综合征终生风险极高,不能靠一次看诊结束管理。
- 专业摄影对随访极有价值。

**量化指标 / Metrics**
- 发育不良痣摄影建档率
- 规律随访完成率
- 变化病灶切除率
