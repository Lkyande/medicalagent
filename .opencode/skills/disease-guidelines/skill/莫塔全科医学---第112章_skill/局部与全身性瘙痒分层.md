# Skill: 局部与全身性瘙痒分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第112章 瘙痒
- 页码: 第112章“局部瘙痒”“广泛性瘙痒”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第112章.md`

**目标 / Objective**
区分局部性与全身性瘙痒,快速判断是原发皮肤病还是系统性疾病线索。

**适用范围 / Scope**
- 主诉瘙痒,伴或不伴皮疹的儿童和成人

**操作步骤 / Procedure**
1. 先判断瘙痒是局限某一部位还是广泛全身分布。
2. 对局部瘙痒重点查找特应性皮炎、疥疮、虱病、接触性皮炎和干燥病。
3. 对无皮疹或广泛性瘙痒考虑肝胆、肾脏、血液、内分泌和心理因素。
4. 记录是否夜间加重、热水诱发、是否伴睡眠受损或抓痕。
5. 根据分层结果决定局部处理还是系统性筛查。

**注意事项 / Precautions**
- 持续慢性瘙痒可与慢性疼痛一样难以忍受。
- 严重夜间瘙痒提示疥疮的可能性高。
- 无皮疹不代表没有严重病因。

**量化指标 / Metrics**
- 瘙痒分层记录率
- 局部皮肤病识别率
- 全身性病因筛查率
