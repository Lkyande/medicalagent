# Skill: 皮肤划痕症床旁测试

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第112章 瘙痒
- 页码: 第112章“指南”“关键的身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第112章.md`

**目标 / Objective**
通过床旁划痕试验识别皮肤划痕症,帮助解释慢性瘙痒与荨麻疹反应。

**适用范围 / Scope**
- 轻触即痒或疑似物理性荨麻疹的病人

**操作步骤 / Procedure**
1. 选择未抓破的皮肤区域进行检查。
2. 用压舌板或类似器具在皮肤上划一条有力但不过度损伤的线。
3. 观察是否出现夸张的风团样划痕反应。
4. 将阳性结果与病人的瘙痒模式和诱发因素相结合解释。
5. 根据结果进入抗组胺和触发因素管理路径。

**注意事项 / Precautions**
- 皮肤划痕症是躯体荨麻疹的常见形式。
- 试验要避免在明显炎症或破损皮肤上进行。
- 阳性不排除其他瘙痒病因并存。

**量化指标 / Metrics**
- 可疑病例划痕试验实施率
- 阳性检出率
- 结果解释记录率
