# Skill: 全身性瘙痒系统病筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第112章 瘙痒
- 页码: 第112章“可能导致瘙痒的全身性因素”“关键病史”“关键辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第112章.md`

**目标 / Objective**
在全身性瘙痒中及时筛查潜在的肝胆、肾脏、血液和恶性疾病。

**适用范围 / Scope**
- 广泛性瘙痒、润肤剂无效且影响睡眠,或无明显原发皮疹的病人

**操作步骤 / Procedure**
1. 询问妊娠、肝病、肾病、体重下降、发热、药物和淋巴结肿大线索。
2. 注意热水诱发瘙痒、掌跖明显瘙痒和胆汁淤积样提示。
3. 完成皮肤、腹部和淋巴系统全面检查。
4. 安排 CBC、铁、肝肾功能、甲状腺功能、血糖、尿检和必要的胸片等检查。
5. 对霍奇金淋巴瘤、慢性肾衰、原发性胆汁性肝硬化等高危病因进一步转诊。

**注意事项 / Precautions**
- 霍奇金淋巴瘤相关瘙痒可非常剧烈。
- 原发性胆汁性肝硬化可先于其他症状多年出现瘙痒。
- 老年人的干燥症常见,但不能因此漏掉系统病。

**量化指标 / Metrics**
- 全身性瘙痒实验室筛查率
- 重大系统病因检出率
- 高危病人专科转诊率
