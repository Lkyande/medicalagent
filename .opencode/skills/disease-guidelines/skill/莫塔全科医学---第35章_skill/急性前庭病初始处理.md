# Skill: 急性前庭病初始处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第35章 头晕/眩晕
- 页码: 第35章“急性前庭病”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第35章.md`

**目标 / Objective**
对急性前庭神经炎或迷路炎实施早期症状控制和安全分流。

**适用范围 / Scope**
- 突发眩晕伴恶心呕吐,怀疑前庭神经炎或迷路炎病人

**操作步骤 / Procedure**
1. 根据急性眩晕、恶心呕吐及近期流感样前驱症状识别急性前庭病。
2. 区分是否伴耳鸣或听力丧失,以判断更偏向前庭神经炎还是迷路炎。
3. 初始建议卧床休息和平卧,并让病人凝视可减轻症状的方向。
4. 根据症状严重程度短期使用止吐药、抗组胺药或苯二氮卓类药物缓解眩晕。
5. 在排除中枢病因后,必要时短期加用糖皮质激素并安排复诊观察恢复。

**注意事项 / Precautions**
- 卒中可模拟急性前庭病,任何中枢体征或 HINTS 异常都要升级评估。
- 症状虽多为自限性,但严重呕吐和脱水可能需要住院。
- 苯二氮卓类和止吐药应短期使用,避免延迟前庭代偿。

**量化指标 / Metrics**
- 症状缓解用药启动时间
- 中枢病因排除记录率
- 7 日内功能恢复率
