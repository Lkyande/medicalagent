# Skill: 头晕眩晕病史分型

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第35章 头晕/眩晕
- 页码: 第35章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第35章.md`

**目标 / Objective**
通过结构化病史区分真性眩晕、假性眩晕和系统性头晕,指导后续床旁检查与分诊。

**适用范围 / Scope**
- 主诉头晕、旋转感、失衡感或突发站立不稳的病人

**操作步骤 / Procedure**
1. 先让病人描述“头晕”具体感受,区分旋转感、眼前发黑、漂浮感或失衡。
2. 询问症状是阵发性还是持续性,是否与姿势和体位改变相关。
3. 追问是否伴耳鸣、耳聋、视觉异常、神经系统症状、恶心呕吐或近期感冒。
4. 核对近期颅脑外伤、药物、酒精、大麻、降压药和精神类药物使用情况。
5. 依据耳症状、神经症状和诱发方式初步分层为外周前庭性、中枢性、循环性或药物性头晕。

**注意事项 / Precautions**
- “头晕”是笼统主诉,必须追问感受性质,不能直接套用某一诊断。
- 近期上呼吸道感染后急性真性眩晕提示前庭神经炎可能。
- 药物和酒精诱发很常见,问药史时不要遗漏大麻和非处方药物。

**量化指标 / Metrics**
- 症状性质记录率
- 诱发因素记录率
- 首诊病因分层准确率
