# Skill: 头晕红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第35章 头晕/眩晕
- 页码: 第35章“头晕/眩晕的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第35章.md`

**目标 / Objective**
在头晕就诊时识别听神经瘤、脑血管病、心律失常和其他需紧急转诊的严重病因。

**适用范围 / Scope**
- 急性或慢性头晕、眩晕病人

**操作步骤 / Procedure**
1. 主动筛查单侧听力下降、持续神经症状、步态异常和明显头痛等中枢线索。
2. 询问是否伴晕厥、胸痛、心悸、卒中危险因素或近期头部外伤。
3. 关注进行性恶化、持续性呕吐、脑神经异常和高龄等高危背景。
4. 对耳鸣或单侧耳聋合并头晕者优先排查听神经瘤。
5. 红旗征阳性时立即升级影像、心电图或神经/耳科转诊。

**注意事项 / Precautions**
- 老年人头晕很常见,但恶性肿瘤和心律失常也更常见,不能轻率归因。
- 中枢性眩晕可能表现不戏剧化,需主动查脑神经和小脑体征。
- 单侧耳聋合并眩晕不是“普通内耳炎”直到证明为止。

**量化指标 / Metrics**
- 红旗征记录率
- 高危头晕紧急转诊率
- 严重病因漏诊率
