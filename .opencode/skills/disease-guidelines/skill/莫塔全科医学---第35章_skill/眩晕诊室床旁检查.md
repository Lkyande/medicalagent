# Skill: 眩晕诊室床旁检查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第35章 头晕/眩晕
- 页码: 第35章“诊室里的头晕检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第35章.md`

**目标 / Objective**
在门诊用床旁动作试验复现症状并区分外周性与中枢性眩晕。

**适用范围 / Scope**
- 可在诊室安全完成动作诱发的头晕或眩晕病人

**操作步骤 / Procedure**
1. 让病人做任何可重复诱发症状的头位或体位动作。
2. 进行 Hallpike 动作,观察是否诱发眩晕及位置性眼震。
3. 对急性持续性眩晕病人实施三部分 HINTS 检查,包括头冲击、眼震和偏斜试验。
4. 同时在仰卧、坐位和站位测量血压,筛查体位性低血压。
5. 结合耳镜、听力、小脑体征和脑神经检查综合判断病变部位。

**注意事项 / Precautions**
- 明显自发性眩晕或危险中枢体征病人不要反复激惹,应尽快转急诊评估。
- HINTS 主要用于急性持续性前庭综合征,不适合所有轻微头晕病人。
- 颈动脉和颈窦触诊应谨慎,避免不必要风险。

**量化指标 / Metrics**
- Hallpike/HINTS 执行率
- 外周/中枢分层准确率
- 体位血压测量完成率
