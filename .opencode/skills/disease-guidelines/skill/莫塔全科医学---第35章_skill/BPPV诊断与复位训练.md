# Skill: BPPV诊断与复位训练

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第35章 头晕/眩晕
- 页码: 第35章“良性阵发性体位性眩晕”“管理”“位置性前庭训练”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第35章.md`

**目标 / Objective**
确诊 BPPV 并通过复位或训练动作缩短症状持续时间。

**适用范围 / Scope**
- 头位改变诱发的短暂眩晕病人,尤其老年人

**操作步骤 / Procedure**
1. 识别发作持续 10~60 秒、起床或床上转头时诱发且不伴耳鸣耳聋的典型病史。
2. 通过 Hallpike 动作确认位置性眩晕和潜伏后出现的眼震。
3. 向病人解释 BPPV 常为耳石性、自限性但易复发。
4. 指导 Brandt-Daroff 或 Cawthorne-Cooksey 位置训练,反复诱发至症状消退。
5. 在合适条件下实施 Epley 或 Semont 复位操作,并安排复发时复诊。

**注意事项 / Precautions**
- BPPV 一般不推荐常规药物治疗。
- 若伴持续性神经症状、明显呕吐或听力改变,要重新评估非 BPPV 病因。
- 约有一定比例与创伤或病毒性迷路炎相关,病史应补问。

**量化指标 / Metrics**
- Hallpike 阳性确认率
- 初次复位成功率
- 复发再处理率
