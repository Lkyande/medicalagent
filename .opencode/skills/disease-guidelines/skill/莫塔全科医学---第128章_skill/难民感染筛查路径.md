# Skill: 难民感染筛查路径

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第128章 难民的健康
- 页码: 第128章“乙型肝炎”“疟疾”“血吸虫”“类圆线虫”“结核病”“血液传播性病毒”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第128章.md`

**目标 / Objective**
针对难民背景人群的高患病感染性疾病建立有重点的筛查路径。

**适用范围 / Scope**
- 来自中东、亚洲、非洲等高风险地区的难民和寻求庇护者

**操作步骤 / Procedure**
1. 根据出生地区、过境国和旅行/暴露史确定高风险感染谱。
2. 常规考虑乙肝、结核、寄生虫及血液传播性病毒筛查。
3. 对发热或疟疾流行区旅行史者优先排除疟疾。
4. 对来自高风险地区者安排血吸虫、类圆线虫或粪检等相应检查。
5. 根据阳性结果安排治疗、复查及家庭接触者筛查。

**注意事项 / Precautions**
- 许多感染可长期无症状,但最终造成器官损害。
- 寄生虫筛查要结合药物禁忌和妊娠状态。
- 需同时更新疫苗和慢病筛查,不能只做感染评估。

**量化指标 / Metrics**
- 重点感染筛查覆盖率
- 阳性结果后治疗启动率
- 家庭接触者筛查率
