# Skill: 难民创伤知情沟通

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第128章 难民的健康
- 页码: 第128章“沟通”“创伤-知情照护的原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第128章.md`

**目标 / Objective**
在照护有难民背景的人时建立安全、尊重、创伤知情的沟通基础。

**适用范围 / Scope**
- 难民、寻求庇护者及有强制迁徙背景的个人和家庭就诊场景

**操作步骤 / Procedure**
1. 以病人为中心,先了解当前最关心的问题和就诊目标。
2. 必要时安排专业口译员,并说明其同样遵守保密原则。
3. 尊重文化差异,用开放问题询问健康信念和治疗偏好,避免假设。
4. 采用创伤知情方式沟通,不在首次就诊中追问创伤细节。
5. 用回授技巧确认病人是否理解管理计划。

**注意事项 / Precautions**
- 详细追问创伤经历可能再次造成创伤。
- 语言通了不等于真正理解了就医系统和计划。
- 医生自身的文化偏见也需要被持续反思。

**量化指标 / Metrics**
- 口译员使用适配率
- 回授技巧使用率
- 创伤知情沟通记录率
