# Skill: 难民铁与维生素缺乏筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第128章 难民的健康
- 页码: 第128章“铁缺乏”“维生素D”“维生素B12”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第128章.md`

**目标 / Objective**
在有难民背景人群中尽早发现和治疗常见营养缺乏问题。

**适用范围 / Scope**
- 儿童、育龄女性、营养不良者和有疲劳/发育不良症状的难民背景病人

**操作步骤 / Procedure**
1. 对儿童、育龄女性及有疲劳、营养不良或胃肠道问题者筛查缺铁。
2. 对深肤色、缺乏日晒及儿童青少年主动筛查维生素 D。
3. 对来自特定地区、素食或粮食不安全者筛查维生素 B12。
4. 结合饮食教育、口服补充或静脉补铁进行个体化治疗。
5. 安排复查并评估症状、发育和实验室改善。

**注意事项 / Precautions**
- 难民背景儿童和育龄女性营养缺乏负担明显更高。
- 维生素 D 缺乏常无症状,但儿童可出现骨骼问题。
- 纠正铁缺乏后若仍有小细胞低色素贫血需考虑血红蛋白病。

**量化指标 / Metrics**
- 铁、维生素 D、B12 筛查率
- 缺乏后治疗启动率
- 复查改善率
