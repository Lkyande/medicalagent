# Skill: 难民初始健康评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第128章 难民的健康
- 页码: 第128章“移民后的健康评估”“表128.3 难民的健康评估”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第128章.md`

**目标 / Objective**
在难民抵达后早期完成系统性健康评估并建立后续照护路径。

**适用范围 / Scope**
- 新近抵达澳大利亚或长期未完成综合筛查的有难民背景人群

**操作步骤 / Procedure**
1. 在抵达后 1 个月内安排较长时间的初始评估。
2. 采集当前问题、移民史、疫苗记录、慢病、感染暴露和社会心理压力源。
3. 完成一般体检、营养评估、血压、视听、口腔及发育/残疾筛查。
4. 按指南安排贫血、维生素 D、乙肝、结核、寄生虫和慢病等筛查。
5. 建立随访、补种疫苗和专科转介计划。

**注意事项 / Precautions**
- 病史应额外关注移民前后创伤和定居压力。
- 初始筛查并非“一次做完所有检查”,需病人主导、循序推进。
- 难民与寻求庇护者获取服务的现实障碍要同步处理。

**量化指标 / Metrics**
- 难民初始健康评估完成率
- 补种疫苗安排率
- 高危筛查项目覆盖率
