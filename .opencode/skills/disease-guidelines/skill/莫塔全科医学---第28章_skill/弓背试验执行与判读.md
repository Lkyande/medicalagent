# Skill: 弓背试验执行与判读

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第28章 腰背痛
- 页码: 第28章“弓背试验”“弓背试验的意义”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第28章.md`

**目标 / Objective**
用高敏感度激发试验筛查椎间盘病变和硬脊膜牵拉所致的腰腿痛。

**适用范围 / Scope**
- 腰背痛向臀部或大腿后部放射的病人

**操作步骤 / Procedure**
1. 让病人坐于检查床边缘,放松并自然下垂双腿。
2. 令病人身体前倾且下颌靠近胸部,形成脊柱屈曲位。
3. 先伸直健侧腿,再伸直患侧腿,必要时进一步双腿伸直。
4. 在患侧腿伸直基础上加做足背屈,观察是否诱发熟悉的腰腿痛。
5. 若放松颈部后疼痛减轻,支持硬脊膜牵拉而非单纯腘绳肌紧张。

**注意事项 / Precautions**
- 需区分神经牵拉痛和腘绳肌拉伸不适。
- 阳性提示椎间盘病变可能,进行手法治疗需更谨慎。
- 试验阴性不能完全排除所有腰腿痛病因,仍需结合神经学检查。

**量化指标 / Metrics**
- 弓背试验执行率
- 阳性结果与影像或神经学一致率
- 手法治疗前神经牵拉筛查率
