# Skill: 腰背痛红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第28章 腰背痛
- 页码: 第28章“腰背痛的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第28章.md`

**目标 / Objective**
在腰背痛初诊时识别肿瘤、感染、骨折和神经压迫等严重病因。

**适用范围 / Scope**
- 所有急性、慢性或复发性腰背痛病人

**操作步骤 / Procedure**
1. 主动筛查持续昼夜痛、夜间痛醒、发热、体重减轻、外伤史和恶性肿瘤史。
2. 询问膀胱或肠道功能改变、鞍区麻木、进行性无力和双下肢症状。
3. 结合年龄、抗凝治疗、感染风险和免疫抑制背景进行风险分层。
4. 红旗征存在时优先安排针对性影像和实验室筛查,而不是常规保守观察。
5. 对疑似马尾综合征、感染或恶性病变立即紧急转诊。

**注意事项 / Precautions**
- 没有红旗征的急性非特异性腰背痛通常不需常规 X 线。
- 抗凝治疗可导致腹膜后出血并模拟严重神经根症状。
- 夜间痛并不常见于单纯机械性背痛,不能忽视。

**量化指标 / Metrics**
- 红旗征记录率
- 紧急转诊及时率
- 严重病变漏诊率
