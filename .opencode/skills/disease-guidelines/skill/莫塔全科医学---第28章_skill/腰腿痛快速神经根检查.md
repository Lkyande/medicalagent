# Skill: 腰腿痛快速神经根检查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第28章 腰背痛
- 页码: 第28章“神经学检查”“主要神经根”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第28章.md`

**目标 / Objective**
在 2~3 分钟内完成腰腿痛病人的快速神经根筛查,识别 L4/L5/S1 受压。

**适用范围 / Scope**
- 症状延伸至臀部、小腿或足部的腰背痛病人

**操作步骤 / Procedure**
1. 先做快速功能筛查:足跟行走评估 L5,足尖行走评估 S1。
2. 结合弓背试验和直腿抬高试验判断是否存在硬脊膜牵拉。
3. 检查 L4 的足内翻力量、膝反射及内侧足感觉。
4. 检查 L5 的抗 趾背伸力量、中三趾感觉及足跟行走能力。
5. 检查 S1 的小趾和足底感觉以及踝反射,并综合判断是否需紧急影像或转诊。

**注意事项 / Precautions**
- 只有当症状延伸至腿部时才做完整神经学检查,避免无效重复。
- 两个及以上神经根同时受累时要警惕肿瘤或较大椎间盘突出。
- 进行性无力、反射消失或膀胱症状提示更高危的神经压迫。

**量化指标 / Metrics**
- 神经根检查完整率
- 神经定位与后续影像一致率
- 高危神经压迫转诊及时率
