# Skill: 腰背痛关键病史采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第28章 腰背痛
- 页码: 第28章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第28章.md`

**目标 / Objective**
通过结构化提问确定腰背痛的病理线索、诱因和社会心理风险。

**适用范围 / Scope**
- 所有腰背痛病人

**操作步骤 / Procedure**
1. 询问疼痛性质、外伤史、昼夜变化以及起床和夜间睡眠受影响情况。
2. 明确休息、活动、坐位、站位、咳嗽和打喷嚏对疼痛的影响。
3. 追问长距离步行后是小腿上行痛还是臀部下沉痛,鉴别血管性与神经源性跛行。
4. 询问银屑病、腹泻、眼病、阳痿、泌尿症状及药物使用,特别是抗凝剂。
5. 同时评估工作压力、抑郁、焦虑和家庭因素等黄旗征。

**注意事项 / Precautions**
- 上腰痛的年轻女性,尤其妊娠期,即使无尿频尿痛也要想到尿路感染。
- 黄旗征并不否定真实疼痛,而是提示慢性化风险更高。
- 病史常比单次影像学更能指导病因分层。

**量化指标 / Metrics**
- 病史完整率
- 黄旗征评估率
- 跛行类型初诊分层率
