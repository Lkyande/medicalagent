# Skill: 机械性与炎性腰背痛鉴别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第28章 腰背痛
- 页码: 第28章“疼痛的性质”“炎症性和机械性腰背痛的疼痛模式比较”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第28章.md`

**目标 / Objective**
依据疼痛昼夜模式和活动关系区分机械性与炎性腰背痛,指导后续检查和治疗。

**适用范围 / Scope**
- 需要进行病因分层的腰背痛病人

**操作步骤 / Procedure**
1. 询问疼痛是隐匿起病还是与外伤、既往发作相关。
2. 判断休息是否加重、轻微活动是否缓解,以及晨僵是否明显且持续。
3. 评估夜间或凌晨疼痛与活动后加重之间的时间模式。
4. 记录放射特点,炎症性更局限或交替双侧,机械性更常单侧弥漫放射。
5. 若表现符合炎症性模式,进一步筛查脊柱关节病线索并调整检查策略。

**注意事项 / Precautions**
- 部分病人可同时存在机械性和炎性成分,不能强行二分。
- 清晨在床上即疼痛还需考虑抑郁或恶性肿瘤/感染。
- 仅凭影像退变不能判断疼痛机制。

**量化指标 / Metrics**
- 疼痛模式记录率
- 炎症性腰背痛识别率
- 不必要影像检查减少率
