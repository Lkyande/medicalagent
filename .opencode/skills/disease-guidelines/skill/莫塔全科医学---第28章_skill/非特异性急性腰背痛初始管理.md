# Skill: 非特异性急性腰背痛初始管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第28章 腰背痛
- 页码: 第28章“椎体功能障碍伴非神经根痛”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第28章.md`

**目标 / Objective**
对非特异性急性腰背痛实施基于证据的初始管理,缩短病程并降低慢性化风险。

**适用范围 / Scope**
- 无红旗征的急性非神经根性腰背痛病人

**操作步骤 / Procedure**
1. 向病人说明严重病变罕见且多数能较快恢复,进行释除担忧。
2. 从就诊一开始就鼓励维持正常活动,避免长期卧床休息。
3. 提供背部健康教育资料和日常活动指导。
4. 依据疼痛模式使用对乙酰氨基酚,必要时短期加用 NSAIDs。
5. 对持续性疼痛者考虑锻炼计划、游泳或物理治疗,并动态复查是否出现红旗征。

**注意事项 / Precautions**
- 在没有红旗征时不推荐常规 X 线检查。
- 保持活动是核心措施,完全休息反而增加失能风险。
- 若出现向腿部加重的神经症状,需升级为神经根病评估。

**量化指标 / Metrics**
- 保持活动建议覆盖率
- 非必要影像减少率
- 6 周内疼痛和功能改善率
