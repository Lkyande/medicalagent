# Skill: 急救DRSABCD初始处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第120章 急诊服务
- 页码: 第120章“管理原则”“重要的基本技能”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第120章.md`

**目标 / Objective**
在院前或基层急症场景中按统一框架迅速完成初始生命支持。

**适用范围 / Scope**
- 胸痛、意识丧失、大出血、呼吸窘迫或其他时间危急性急症

**操作步骤 / Procedure**
1. 先评估现场危险并确认病人反应。
2. 立即寻求帮助并启动团队支援。
3. 开放气道并评估呼吸,必要时辅助通气。
4. 评估循环并进行止血、静脉通路或胸外按压。
5. 尽快连接除颤设备并根据具体急症进入下一步路径。

**注意事项 / Precautions**
- 时间危急性是急症管理核心概念。
- 常规完整病史会让位于快速评估和即刻处理。
- 院前急救的设备准备和团队演练同样重要。

**量化指标 / Metrics**
- DRSABCD 流程完成率
- 从接触到首项干预时效
- 团队响应到位率
