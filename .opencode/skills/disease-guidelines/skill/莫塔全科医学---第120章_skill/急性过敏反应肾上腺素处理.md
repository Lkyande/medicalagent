# Skill: 急性过敏反应肾上腺素处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第120章 急诊服务
- 页码: 第120章“急性过敏和过敏反应”“一线治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第120章.md`

**目标 / Objective**
在急性过敏反应中尽早使用肾上腺素和液体复苏挽救生命。

**适用范围 / Scope**
- 蜇伤、药物、食物或其他暴露后出现荨麻疹、喘息、低血压或血管性水肿的病人

**操作步骤 / Procedure**
1. 识别手掌足底瘙痒、荨麻疹、喘息、腹痛、晕厥和低血压等过敏表现。
2. 让病人平卧并去除可移除的病因。
3. 立即给予大腿前外侧肌注肾上腺素并高流量吸氧。
4. 建立静脉通路并快速补充晶体液,必要时重复肾上腺素。
5. 对呼吸道症状加用吸入支气管扩张药,并安排住院观察及出院后自动注射器教育。

**注意事项 / Precautions**
- 肾上腺素是第一线治疗,越早越关键。
- 皮肤症状可能不是最危险表现,低血压和喘息优先级更高。
- 需至少观察数小时防止双相反应。

**量化指标 / Metrics**
- 急性过敏反应肌注肾上腺素时效
- 晶体液复苏完成率
- 出院自动注射器教育率
