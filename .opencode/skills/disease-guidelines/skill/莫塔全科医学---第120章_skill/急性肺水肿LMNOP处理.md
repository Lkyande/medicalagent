# Skill: 急性肺水肿LMNOP处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第120章 急诊服务
- 页码: 第120章“急性心源性肺水肿”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第120章.md`

**目标 / Objective**
对急性心源性肺水肿实施 LMNOP 核心处理并尽快稳定通气和循环。

**适用范围 / Scope**
- 急性呼吸困难、端坐呼吸、湿啰音或已知心衰恶化病人

**操作步骤 / Procedure**
1. 让病人端坐,双腿垂下以减轻静脉回流。
2. 给予高流量氧气并建立大口径静脉通路。
3. 使用舌下或静脉硝酸酯,前提是血压允许。
4. 静脉给予呋塞米,按病情酌情追加。
5. 对严重低氧或无反应者尽快使用 CPAP/BiPAP 并安排急诊住院。

**注意事项 / Precautions**
- 牢记 LMNOP: 呋塞米、吗啡、硝酸酯、氧气、正压通气。
- 高流量氧疗并非无条件适用于所有呼吸困难,但此场景通常需要。
- 需同时思考心肌梗死、心律失常和贫血等病因。

**量化指标 / Metrics**
- 急性肺水肿 LMNOP 执行率
- 氧疗与静脉通路建立时效
- 正压通气使用率
