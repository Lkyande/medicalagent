# Skill: 提肛痉挛发作处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第26章 肛肠疾病
- 页码: 第26章“痉挛性肛门疼痛(提肛痉挛)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第26章.md`

**目标 / Objective**
帮助病人识别提肛痉挛的良性短暂发作并采取即时缓解措施。

**适用范围 / Scope**
- 短暂发作性直肠疼痛、夜间痛醒而无明显局部器质性病变者

**操作步骤 / Procedure**
1. 确认疼痛持续 3~30 分钟、可夜间发作且发作间期无持续异常。
2. 向病人解释该病通常自限,以减轻对癌症或严重疾病的担忧。
3. 发作时建议立即饮水,最好热水,并对会阴部局部保暖。
4. 可尝试吸入沙丁胺醇 2 吸,或在专科建议下使用硝酸甘油喷雾等替代方法。
5. 若疼痛模式改变、持续时间延长或伴出血发热,重新评估其他肛肠病变。

**注意事项 / Precautions**
- 诊断前应先排除脓肿、肛裂和肿瘤等器质性病因。
- 沙丁胺醇用于此病循证依据有限,需向病人说明。
- 持续性直肠疼痛不应简单按提肛痉挛处理。

**量化指标 / Metrics**
- 发作后自行缓解率
- 不必要急诊就诊减少率
- 症状模式再评估率
