# Skill: 内痔分期与初始处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第26章 肛肠疾病
- 页码: 第26章“内痔”“临床分期和病理”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第26章.md`

**目标 / Objective**
按内痔分期判断病情严重度并选择保守或介入治疗方向。

**适用范围 / Scope**
- 便后出血、脱垂或肛门黏液分泌病人

**操作步骤 / Procedure**
1. 询问主要症状是出血、脱垂、瘙痒还是排便不尽感。
2. 根据脱垂程度分期:Ⅰ度仅出血,Ⅱ度排便时脱出后自行回纳,Ⅲ度需手法复位,Ⅳ度无法回纳。
3. 首先实施保守治疗,包括高纤维饮食、软化粪便和避免久坐用力排便。
4. 对需要非手术介入者优先考虑橡皮圈套扎。
5. 大的绞窄性痔或严重脱垂者尽早转外科评估手术治疗。

**注意事项 / Precautions**
- 即使见到痔,也不能自动解释全部出血症状,仍要排除近端病变。
- 注射治疗已非优选方案,不应机械沿用旧习惯。
- 应劝导病人在几分钟内完成排便,避免长期蹲厕和滥用泻药。

**量化指标 / Metrics**
- 内痔分期记录率
- 保守治疗依从率
- 橡皮圈套扎后症状改善率
