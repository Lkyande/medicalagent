# Skill: 肛裂保守治疗路径

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第26章 肛肠疾病
- 页码: 第26章“肛裂”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第26章.md`

**目标 / Objective**
通过减轻括约肌痉挛和软化大便促进肛裂愈合,减少复发和不必要手术。

**适用范围 / Scope**
- 急性或慢性单发肛裂病人

**操作步骤 / Procedure**
1. 通过视诊确认典型后正中线裂口,并评估是否存在便秘、产后或阿片使用背景。
2. 指导高纤维饮食、保持粪便柔软和排便后温盐水坐浴。
3. 需要时在排便前使用局部麻醉缓解疼痛。
4. 局部涂抹 2% 硝酸甘油软膏,每日 3 次,持续约 6 周,或改用地尔硫卓乳膏每日 2 次 6~8 周。
5. 若反复发作或伴纤维化、肛门狭窄,转外科评估侧内括约肌切开或肉毒毒素注射。

**注意事项 / Precautions**
- 多发裂口、硬结、水肿或发绀时应考虑克罗恩病而非单纯肛裂。
- 硝酸甘油常见不良反应是头痛,开立前需说明。
- 肛门指检和镜检可能因疼痛困难,应避免粗暴检查。

**量化指标 / Metrics**
- 保守治疗 6 周症状缓解率
- 便秘纠正率
- 复发后外科转诊率
