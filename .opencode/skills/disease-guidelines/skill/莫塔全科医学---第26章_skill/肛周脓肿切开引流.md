# Skill: 肛周脓肿切开引流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第26章 肛肠疾病
- 页码: 第26章“肛周脓肿”“治疗”“抗生素”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第26章.md`

**目标 / Objective**
及时引流肛周脓肿并识别需要加用抗生素或进一步寻找基础病因的病人。

**适用范围 / Scope**
- 肛门周围严重持续跳痛、红肿热和发热病人

**操作步骤 / Procedure**
1. 根据严重跳痛、发热中毒症状和局部红肿热判断肛周脓肿。
2. 仔细检查是否存在瘘管、克罗恩病或肛肠癌证据。
3. 在硬结最明显处做较深的十字切口,修剪边角后充分引流。
4. 根据需要放置引流管 7~10 日,通常无需包扎。
5. 如难以控制或伴蜂窝织炎,加用甲硝唑和头孢氨苄口服 5~7 日。

**注意事项 / Precautions**
- 抗生素不能替代引流,延迟切开会加重感染。
- 坐骨直肠脓肿位置更深,通常需要全麻手术处理。
- 复发性脓肿应高度怀疑肛瘘或克罗恩病。

**量化指标 / Metrics**
- 脓肿诊断至引流时间
- 复发率
- 伴蜂窝织炎病人抗生素覆盖率
