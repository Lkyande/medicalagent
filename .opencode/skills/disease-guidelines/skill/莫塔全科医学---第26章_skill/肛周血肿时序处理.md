# Skill: 肛周血肿时序处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第26章 肛肠疾病
- 页码: 第26章“肛周血肿”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第26章.md`

**目标 / Objective**
根据发病时间选择肛周血肿最合适的处理方式,减轻疼痛并减少皮赘形成。

**适用范围 / Scope**
- 疑似血栓性外痔或肛周血肿病人

**操作步骤 / Procedure**
1. 通过病史和视诊确认紫色压痛性肿胀,并记录发病时间。
2. 若发病 <=24 小时,在血肿未凝结时用 19 号针头简单抽吸。
3. 若发病在 24 小时至 3 日之间,局麻后在顶端做小切口并挤出凝血块。
4. 若发病 >=4 日且疼痛不重,以保守观察为主,等待自然消退。
5. 4 周内复查直肠指检和直肠镜,同时指导高纤维饮食和避免用力排便。

**注意事项 / Precautions**
- 单个绞窄性痔与肛周血肿可能混淆,必要时借助直肠镜鉴别。
- 过晚切开收益有限,反而增加不适。
- 明显感染或异常出血时应重新评估其他病因。

**量化指标 / Metrics**
- 发病时间记录率
- 处理后疼痛缓解率
- 后续皮赘形成率
