# Skill: 直肠出血红旗征排查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第26章 肛肠疾病
- 页码: 第26章“直肠出血”“直肠出血的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第26章.md`

**目标 / Objective**
在肛门出血就诊时识别提示结直肠癌或重大肠道病变的警报信号。

**适用范围 / Scope**
- 所有主诉直肠出血或便血病人

**操作步骤 / Procedure**
1. 明确血液颜色及表现形式,区分便后鲜血、血黏液便、混合便血或黑便。
2. 主动筛查年龄 >50 岁、排便习惯改变、体重减轻、虚弱乏力和癌症家族史。
3. 追问腹泻、便秘、肿块感、里急后重和不尽感等伴随症状。
4. 完成一般评估、肛门检查、直肠指检及乙状结肠镜或结肠镜路径评估。
5. 即使发现痔或肛裂,若存在肠道症状或无法解释的出血,仍继续排除近端病变。

**注意事项 / Precautions**
- 看到痔并不等于找到出血原因,这是最常见误区之一。
- 黑便提示上消化道出血,应住院评估。
- 右半结肠癌可仅表现为隐匿失血性贫血,没有明显鲜血便。

**量化指标 / Metrics**
- 便血红旗征记录率
- 需要镜检病人的完成率
- 近端重大病变检出率
