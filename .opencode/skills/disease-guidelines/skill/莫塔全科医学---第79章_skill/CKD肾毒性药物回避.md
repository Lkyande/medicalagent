# Skill: CKD肾毒性药物回避

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第79章 慢性肾脏病
- 页码: 第79章“慢性肾脏病的药物处方”“谨防三重打击”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第79章.md`

**目标 / Objective**
在 CKD 病人中识别并避免加重肾损伤的药物暴露。

**适用范围 / Scope**
- 已知 CKD、老年人或近期肾功能恶化的病人

**操作步骤 / Procedure**
1. 系统核对处方药、非处方药和补充医学用药。
2. 重点识别 NSAIDs、COX-2 抑制剂、氨基糖苷类、万古霉素、锂和秋水仙碱等肾毒性药物。
3. 警惕 ACEI/ARB、利尿剂和 NSAIDs 组合形成“三重打击”。
4. 按 eGFR 调整药物剂量,必要时停药或替换方案。
5. 用药调整后复查肾功能和电解质。

**注意事项 / Precautions**
- CKD 病人药物不良反应和高钾血症风险显著增加。
- 老年人和脱水状态下更容易出现药物相关 AKI。
- 肾毒性药物常来自非处方用药史,不能只查处方单。

**量化指标 / Metrics**
- CKD 病人的完整用药核对率
- 三重打击组合识别率
- 剂量按肾功能调整率
