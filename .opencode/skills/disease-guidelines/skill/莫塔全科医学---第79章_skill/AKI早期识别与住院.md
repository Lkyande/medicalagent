# Skill: AKI早期识别与住院

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第79章 慢性肾脏病
- 页码: 第79章“急性肾损伤”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第79章.md`

**目标 / Objective**
尽早识别急性肾损伤并及时安排住院治疗,减少不可逆肾损害。

**适用范围 / Scope**
- 出现少尿、无尿、肌酐快速上升或水电解质紊乱的病人

**操作步骤 / Procedure**
1. 将 AKI 分为肾前性、肾后性和肾性三类进行初步思考。
2. 主动寻找低血容量、感染、梗阻、肾炎和药物毒性等诱因。
3. 关注少尿/无尿、高血压或低血压、尿异常和意识改变等表现。
4. 尽快检测肌酐、电解质和尿液情况,并排查梗阻证据。
5. 及早住院并开始液体、电解质和病因处理。

**注意事项 / Precautions**
- AKI 可进展为慢性肾脏病。
- 进行性肾炎、SLE 和血管炎相关 AKI 需紧急处理。
- 高危病人出现少尿时不要等待“再观察几天”。

**量化指标 / Metrics**
- 可疑 AKI 病人的当日肌酐检测率
- 住院转诊时效
- AKI 病因明确率
