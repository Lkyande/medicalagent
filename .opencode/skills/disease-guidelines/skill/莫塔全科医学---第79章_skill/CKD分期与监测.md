# Skill: CKD分期与监测

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第79章 慢性肾脏病
- 页码: 第79章“表79.2 慢性肾脏疾病分期”“监测慢性肾脏病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第79章.md`

**目标 / Objective**
根据 eGFR 和肾损伤证据完成 CKD 分期并建立监测频率。

**适用范围 / Scope**
- 已发现 eGFR 下降、蛋白尿、血尿或结构性肾损伤的病人

**操作步骤 / Procedure**
1. 依据 eGFR 数值初步分为 1 至 5 期,并记录是否存在蛋白尿或结构异常。
2. 确认异常持续至少 3 个月后再定义为慢性肾脏病。
3. 对 3a 至 5 期病人提高监测密度,同步评估贫血、酸中毒和矿物质代谢问题。
4. 定期复查 ACR、肌酐、电解质和血压,跟踪进展速度。
5. 对 4 至 5 期或进展明显者尽早准备肾专科转诊和肾替代治疗讨论。

**注意事项 / Precautions**
- 血清肌酐单独并不敏感,应结合 eGFR 解读。
- CKD 3b 以后需更严格关注用药剂量和并发症。
- 阶段判断要结合临床而非只记一个数字。

**量化指标 / Metrics**
- CKD 病人的分期记录率
- 3 个月复核确认率
- 分期匹配监测完成率
