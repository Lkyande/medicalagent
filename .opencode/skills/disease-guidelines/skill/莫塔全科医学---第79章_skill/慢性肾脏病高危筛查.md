# Skill: 慢性肾脏病高危筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第79章 慢性肾脏病
- 页码: 第79章“重要的临床相关问题”“慢性肾脏病的危险因素”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第79章.md`

**目标 / Objective**
在无明显症状阶段识别慢性肾脏病高风险人群并启动检测。

**适用范围 / Scope**
- 糖尿病、高血压、心血管病、严重痛风、既往尿路异常或肾损伤史病人

**操作步骤 / Procedure**
1. 识别年龄大于 60 岁、糖尿病、高血压、肥胖和吸烟等高危因素。
2. 主动询问既往尿路反流、膀胱出口梗阻、AKI 和家族肾病史。
3. 对无解释的健康不佳、贫血、夜尿、水肿或血尿者提高警觉。
4. 安排尿白蛋白/肌酐比值、尿常规、血肌酐和 eGFR 评估。
5. 对持续异常者进入 CKD 分期、监测和干预路径。

**注意事项 / Precautions**
- 多数 CKD 病人并不知道自己患病。
- CKD 是重要心血管危险因素,不能仅视作“肾脏问题”。
- 老年 eGFR 下降常见,但仍需结合结局风险和蛋白尿综合判断。

**量化指标 / Metrics**
- CKD 高危人群筛查覆盖率
- ACR 与 eGFR 同步检测率
- 早期 CKD 识别率
