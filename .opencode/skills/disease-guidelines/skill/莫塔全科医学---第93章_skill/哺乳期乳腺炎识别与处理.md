# Skill: 哺乳期乳腺炎识别与处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第93章 乳房疾病
- 页码: 第93章“乳腺炎”“临床特点”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第93章.md`

**目标 / Objective**
尽早识别哺乳期乳腺炎并防止快速进展为乳房脓肿。

**适用范围 / Scope**
- 哺乳期乳房红、热、痛、发热或乳头疼痛的女性

**操作步骤 / Procedure**
1. 识别局部疼痛、红热肿、全身不适和哺乳相关疼痛模式。
2. 评估是否存在乳头破损、乳汁淤积或念珠菌线索。
3. 及时启动抗感染和支持治疗,并鼓励继续有效排空乳房。
4. 对病情进展快、波动感或局灶肿块者警惕脓肿形成。
5. 症状未改善或怀疑脓肿时安排影像和专科处理。

**注意事项 / Precautions**
- 乳腺炎应视为严重而紧急的问题。
- 念珠菌可导致哺乳期严重乳头/乳房疼痛,需与细菌感染区分。
- 非哺乳期乳房红热需排除炎性乳癌。

**量化指标 / Metrics**
- 哺乳期乳腺炎当日处理率
- 继续排乳教育覆盖率
- 进展为脓肿的比例
