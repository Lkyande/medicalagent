# Skill: 周期性乳腺痛处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第93章 乳房疾病
- 页码: 第93章“周期性乳腺痛”“治疗方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第93章.md`

**目标 / Objective**
为周期性乳腺痛提供以释疑和保守措施为主的一线管理。

**适用范围 / Scope**
- 30 至 40 岁常见的经前加重、经后缓解型乳房疼痛病人

**操作步骤 / Procedure**
1. 在排除癌症和可触及囊肿后确认其为周期性乳腺痛。
2. 向病人解释该病缓解率较高并认可其疼痛体验。
3. 建议合适胸罩支撑、体重管理、减压和定期乳房自我关注。
4. 视需要调整口服避孕药或激素替代治疗方案。
5. 需要时使用对乙酰氨基酚或局部 NSAIDs 等对症处理,严重者转乳腺专科。

**注意事项 / Precautions**
- 周期性乳腺痛是最常见类型。
- 许多宣传疗法证据有限,不应过度承诺疗效。
- 停用或更换激素相关药物前需综合避孕或更年期管理需求。

**量化指标 / Metrics**
- 周期性乳腺痛释疑完成率
- 支撑胸罩和生活方式建议覆盖率
- 症状改善率
