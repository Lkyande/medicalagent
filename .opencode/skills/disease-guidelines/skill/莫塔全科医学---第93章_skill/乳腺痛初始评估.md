# Skill: 乳腺痛初始评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第93章 乳房疾病
- 页码: 第93章“乳房疼痛”“临床方法”“病史”“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第93章.md`

**目标 / Objective**
区分周期性与非周期性乳腺痛,并排查癌症、感染和胸壁来源疼痛。

**适用范围 / Scope**
- 主诉乳房疼痛、不适或乳头周围痛的女性病人

**操作步骤 / Procedure**
1. 询问疼痛与月经周期关系、单侧或双侧、是否妊娠及末次月经。
2. 评估疼痛是弥漫性还是局灶性,并追问背部、胸壁和胸椎症状。
3. 检查乳房皮肤、乳头、肿块、压痛点和腋窝淋巴结。
4. 同步检查胸壁和胸椎,识别肋软骨炎或牵涉痛。
5. 根据年龄和病灶性质决定是否需要超声、乳腺摄影或穿刺评估。

**注意事项 / Precautions**
- 乳房痛虽多为良性,仍需排除恶性肿瘤。
- 左乳房下收缩性疼痛应先考虑心肌缺血。
- 乳房疼痛是许多女性强烈癌症焦虑的来源,释疑很重要。

**量化指标 / Metrics**
- 乳腺痛月经相关史记录率
- 胸壁来源疼痛识别率
- 高危病人影像或专科转诊率
