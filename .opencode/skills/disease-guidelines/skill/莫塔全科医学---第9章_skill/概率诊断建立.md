# Skill: 概率诊断建立

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第9章 安全的诊断策略
- 页码: 第9章“概率诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第9章.md`

**目标 / Objective**
结合患病率、自然病史和社区经验快速建立最可能的初步诊断方向。

**适用范围 / Scope**
- 全科首诊、常见病评估和门诊初步决策

**操作步骤 / Procedure**
1. 结合主诉、年龄、性别和社区流行病学背景形成初步假设。
2. 回想该症状在全科场景中最常见的病因模式。
3. 根据病史和查体不断更新诊断概率排序。
4. 将最可能诊断与不能遗漏的严重疾病并行考虑。
5. 根据概率排序决定问诊、查体和检查优先级。

**注意事项 / Precautions**
- 概率高不等于可以忽略罕见但危险的诊断。
- 专科环境的疾病谱不能直接套用到基层概率判断。
- 概率诊断必须随着新信息不断修正。

**量化指标 / Metrics**
- 初步诊断与最终诊断一致率
- 概率排序后检查精简率
- 诊断修正记录率
