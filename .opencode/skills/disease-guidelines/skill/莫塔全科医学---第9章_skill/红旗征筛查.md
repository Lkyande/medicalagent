# Skill: 红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第9章 安全的诊断策略
- 页码: 第9章“红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第9章.md`

**目标 / Objective**
通过快速识别红旗征发现潜在严重损害,决定是否需要紧急检查或升级处置。

**适用范围 / Scope**
- 所有未分化症状和全科初诊场景

**操作步骤 / Procedure**
1. 在问诊和查体中主动筛查体重减轻、呕吐、认知改变、发热、头晕和晕厥等红旗征。
2. 将红旗征与当前主诉联系起来评估严重病可能性。
3. 一旦存在红旗征,提高检查和随访优先级。
4. 必要时立即安排急诊、影像或实验室检查。
5. 在病历中清楚记录是否存在红旗征及相应处理。

**注意事项 / Precautions**
- 红旗征是警钟,并不直接等于诊断,但绝不能忽视。
- 老年人、儿童和免疫抑制者红旗征可能不典型。
- 未记录红旗征评估常导致后续安全隐患。

**量化指标 / Metrics**
- 红旗征筛查完成率
- 红旗征后升级评估率
- 红旗征相关延误诊断率
