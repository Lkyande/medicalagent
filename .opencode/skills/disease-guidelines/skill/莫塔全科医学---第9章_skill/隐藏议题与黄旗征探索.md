# Skill: 隐藏议题与黄旗征探索

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第9章 安全的诊断策略
- 页码: 第9章“病人是否试图告诉我什么”“黄旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第9章.md`

**目标 / Objective**
识别症状背后的隐藏诉求、心理压力和阻碍康复的黄旗征,完善整体诊断与管理。

**适用范围 / Scope**
- 未分化症状、慢性疼痛、反复就诊和明显压力相关病人

**操作步骤 / Procedure**
1. 在症状解释不足时,主动询问病人是否有额外担忧或未说出口的问题。
2. 探索家庭冲突、疾病恐惧、性问题、经济压力和工作场所欺凌等可能来源。
3. 观察是否存在异常生病行为、取消预约、不依从或关系破裂等黄旗征。
4. 将情感需求与器质性评估并行纳入管理计划。
5. 对需要进一步支持者安排咨询、心理干预或持续随访。

**注意事项 / Precautions**
- 隐藏议题探索应建立在信任和保密前提下。
- 黄旗征提示康复障碍,不应被误解为“装病”。
- 对家暴、自伤和严重心理危机需优先安全干预。

**量化指标 / Metrics**
- 隐藏议题发现率
- 黄旗征记录率
- 心理社会因素纳入计划比例
