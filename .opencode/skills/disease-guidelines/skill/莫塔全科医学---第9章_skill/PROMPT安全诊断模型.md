# Skill: PROMPT安全诊断模型

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第9章 安全的诊断策略
- 页码: 第9章“基本模型”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第9章.md`

**目标 / Objective**
用结构化五问模型处理未分化症状,降低漏诊严重疾病和常见陷阱的风险。

**适用范围 / Scope**
- 全科门诊未分化主诉、复杂症状和诊断不确定场景

**操作步骤 / Procedure**
1. 先问最可能的概率诊断是什么。
2. 再问有哪些严重疾病绝对不能遗漏。
3. 列出常会遗漏的常见陷阱问题。
4. 考虑病人是否戴着“面具”来看病,即存在伪装性疾病。
5. 最后探索病人是否试图告诉医生某个隐藏诉求或情绪问题。
6. 用上述五步形成问题清单和检查优先级。

**注意事项 / Precautions**
- 模型是为了结构化思考,不能替代病史、查体和随访。
- 在急危重症前,应优先处理 ABC 和明显红旗征。
- 对复杂症状不要只停留在概率最高的解释上。

**量化指标 / Metrics**
- 五问模型使用率
- 未分化症状后续诊断明确率
- 严重漏诊事件减少率
