# Skill: 严重疾病排除清单

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第9章 安全的诊断策略
- 页码: 第9章“不能遗漏哪些严重疾病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第9章.md`

**目标 / Objective**
在全科首诊中系统排查潜在危及生命或高诉讼风险的严重疾病。

**适用范围 / Scope**
- 胸痛、头痛、发热、呼吸困难、晕厥、腹痛和其他未分化急性症状

**操作步骤 / Procedure**
1. 每次先问当前症状背后是否可能隐藏严重或致命疾病。
2. 重点排除恶性肿瘤、严重感染、梗死和血管性疾病。
3. 对胸部和上腹部不适,警惕非典型心肌缺血或心律失常。
4. 对发热伴低血压、头痛伴呕吐或意识改变等情况立即进入急症路径。
5. 必要时使用 M2I 或 VIC 助记快速回顾重症类别。

**注意事项 / Precautions**
- 经验丰富也会因过熟悉常见病而低估罕见严重病。
- 严重疾病排除优先于陷阱和隐藏议题探索。
- 梗死性疾病具有时间窗,延误会造成不可逆后果。

**量化指标 / Metrics**
- 高危主诉严重病排除记录率
- 急危重症转诊时效
- 重大漏诊事件发生率
