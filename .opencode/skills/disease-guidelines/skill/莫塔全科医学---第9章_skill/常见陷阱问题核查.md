# Skill: 常见陷阱问题核查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第9章 安全的诊断策略
- 页码: 第9章“常会遗漏哪些问题”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第9章.md`

**目标 / Objective**
在常见主诉中主动回顾易被忽略的常见问题,减少“简单病被漏掉”的情况。

**适用范围 / Scope**
- 腹痛、发热、头痛、皮区疼痛、疲劳和其他日常门诊主诉

**操作步骤 / Procedure**
1. 在形成初步诊断后,额外回顾一次本症状常见的陷阱病因。
2. 对儿童、孕妇和老年人特别考虑尿路感染的非典型表现。
3. 对皮区疼痛而无皮疹者考虑带状疱疹前驱期。
4. 对腹泻合并腹胀和渗漏者考虑粪便嵌塞。
5. 对长期乏力、腹泻或体重下降者考虑乳糜泻、血色病等隐匿问题。

**注意事项 / Precautions**
- 陷阱问题通常不危及生命,但忽略后会造成长期误诊和无效治疗。
- 经验不足时更容易被表面症状带偏。
- 陷阱核查应在严重疾病排除之后进行。

**量化指标 / Metrics**
- 陷阱问题核查记录率
- 非典型表现的常见病识别率
- 反复就诊后才确诊比例
