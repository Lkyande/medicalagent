# Skill: 常见戴面具问题核查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第9章 安全的诊断策略
- 页码: 第9章“面具”及表9.4相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第9章.md`

**目标 / Objective**
在症状清单复杂或诊断不明时系统排查常见伪装性疾病,避免长期误诊。

**适用范围 / Scope**
- 疲劳、躯体化、症状多样或反复就诊而查体不典型的病人

**操作步骤 / Procedure**
1. 对症状复杂病人主动回顾七个常见戴面具问题清单。
2. 重点排查抑郁、糖尿病、药物/酒精、贫血、甲状腺和其他内分泌疾病。
3. 同时考虑脊柱功能障碍和尿路感染等易被忽视病因。
4. 将这些可能性与病人的全部症状尝试建立统一解释。
5. 根据最可能的伪装性疾病安排有针对性的检查和随访。

**注意事项 / Precautions**
- 面具问题常表现为购物清单式症状,易让医生失去方向。
- 不应因病人看起来焦虑就停止排查器质性或代谢性原因。
- 药物和医源性因素在多病共存病人中尤需重视。

**量化指标 / Metrics**
- 面具问题清单使用率
- 复杂症状统一诊断建立率
- 反复误诊后纠正诊断率
