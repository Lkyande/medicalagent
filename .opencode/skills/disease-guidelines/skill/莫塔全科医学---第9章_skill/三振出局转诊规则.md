# Skill: 三振出局转诊规则

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第9章 安全的诊断策略
- 页码: 第9章“临床要领”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第9章.md`

**目标 / Objective**
在延迟或蹊跷诊断场景中通过设定诊断止损点,减少反复试探带来的漏诊风险。

**适用范围 / Scope**
- 反复就诊仍未明确诊断的全科病人

**操作步骤 / Procedure**
1. 对诊断迟迟不清或症状与常见解释不符的病人提高警惕。
2. 记录每次就诊后的主要假设和已完成评估。
3. 若多次就诊后仍无法合理解释病情,启动“三振出局”原则。
4. 停止单独重复原有思路,及时会诊、转诊或升级检查。
5. 向病人解释转诊原因和安全考虑。

**注意事项 / Precautions**
- 三振出局不是机械数字,而是提醒要避免陷入思维僵局。
- 病情恶化或出现红旗征时无需等到多次就诊才转诊。
- 必须保留连续性责任,不能“转出去就结束”。

**量化指标 / Metrics**
- 诊断不明病例升级处理率
- 延迟诊断时间
- 转诊后明确诊断率
