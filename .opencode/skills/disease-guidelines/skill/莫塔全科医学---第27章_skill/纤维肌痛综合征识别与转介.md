# Skill: 纤维肌痛综合征识别与转介

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第27章 胸背痛
- 页码: 第27章“纤维肌痛综合征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第27章.md`

**目标 / Objective**
识别纤维肌痛综合征的典型临床组合,减少不必要抗炎治疗并转入多学科支持。

**适用范围 / Scope**
- 广泛性慢性疼痛、疲劳和睡眠障碍病人

**操作步骤 / Procedure**
1. 确认疼痛是否累及全身四个象限并持续至少 3 个月。
2. 评估是否同时存在疲劳、睡眠问题、认知障碍和情绪问题。
3. 检查典型痛点,记录是否有多个点按压即引发疼痛而非单纯触痛。
4. 安排 ESR 或 CRP 以排查炎性替代诊断。
5. 向病人解释病情特点,转入教育、有氧锻炼、心理支持和必要时抗抑郁药路径。

**注意事项 / Precautions**
- NSAIDs 和阿片类对纤维肌痛缺乏明确获益,不应作为核心治疗。
- 病人常被误解为“没病”,解释和持续支持本身就是治疗的一部分。
- 若炎症指标升高,要主动寻找其他诊断而非机械贴上纤维肌痛标签。

**量化指标 / Metrics**
- 可疑病例替代诊断排查率
- 运动与教育方案启动率
- 不必要阿片使用率
