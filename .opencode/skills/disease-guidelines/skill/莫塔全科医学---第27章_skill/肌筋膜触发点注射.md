# Skill: 肌筋膜触发点注射

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第27章 胸背痛
- 页码: 第27章“肌筋膜触发点”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第27章.md`

**目标 / Objective**
在明确局部肌筋膜触发点后进行安全注射,获得短期疼痛缓解。

**适用范围 / Scope**
- 局灶性胸背部肌筋膜触痛点明显且保守措施效果有限者

**操作步骤 / Procedure**
1. 通过局部压痛和受刺激时抽搐反应确定最明显的触发点。
2. 与病人确认按压该点可再现熟悉的疼痛模式。
3. 在无禁忌情况下向痛点注射 5~8ml 局部麻醉药,如 1% 利多卡因。
4. 注射后立即进行局部按摩或配合温和锻炼。
5. 复评短期镇痛效果,并继续姿势和活动纠正方案。

**注意事项 / Precautions**
- 触发点识别一致性有限,应避免把弥漫性疼痛病人都纳入注射。
- 注射前需排除深部器质性病因和局部感染风险。
- 注射通常只提供暂时缓解,不能替代整体康复管理。

**量化指标 / Metrics**
- 注射后即刻疼痛缓解率
- 1 周内复发率
- 触发点复现准确率
