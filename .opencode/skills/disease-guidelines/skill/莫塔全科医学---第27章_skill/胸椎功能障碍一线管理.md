# Skill: 胸椎功能障碍一线管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第27章 胸背痛
- 页码: 第27章“胸椎功能障碍”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第27章.md`

**目标 / Objective**
用教育、活动和基础镇痛作为胸椎功能障碍的一线治疗,减少慢性化。

**适用范围 / Scope**
- 已排除严重器质性疾病的非特异性胸椎功能障碍病人

**操作步骤 / Procedure**
1. 向病人解释该病常见且多可自行恢复,进行释除担忧。
2. 根据疼痛程度鼓励持续活动,避免长期卧床和完全制动。
3. 提供姿势教育及以伸展、旋转为核心的具体动员运动计划。
4. 必要时使用基础镇痛药,如对乙酰氨基酚作为一线口服止痛。
5. 对持续疼痛者可短期转物理治疗,考虑关节松动或谨慎手法操作。

**注意事项 / Precautions**
- 手法治疗证据有限,骨质疏松病人尤其要谨慎。
- 机械性诊断成立前必须先排除心脏和胃肠道牵涉痛。
- 活动锻炼应以疼痛可耐受为限,避免粗暴扭转。

**量化指标 / Metrics**
- 一线教育覆盖率
- 2 周内功能改善率
- 非必要影像减少率
