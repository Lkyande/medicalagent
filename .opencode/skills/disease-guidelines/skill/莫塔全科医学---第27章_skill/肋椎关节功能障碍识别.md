# Skill: 肋椎关节功能障碍识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第27章 胸背痛
- 页码: 第27章“肋椎关节功能障碍”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第27章.md`

**目标 / Objective**
识别由肋椎关节引起的局部或前胸放射性疼痛,减少误判为单纯心肺病或不明胸痛。

**适用范围 / Scope**
- 距胸部中线 3~4cm 局部痛或放射至侧胸壁、前胸壁的病人

**操作步骤 / Procedure**
1. 关注疼痛是否起于胸背近中线区并向侧胸或前胸放射。
2. 询问深呼吸、咳嗽、打喷嚏或肋骨活动时疼痛是否明显加重。
3. 触诊肋横突连接处,并通过诱发肋骨活动观察是否再现局部痛和牵涉痛。
4. 结合胸椎旋转受限和局部压痛,支持肋椎关节功能障碍判断。
5. 排除胸膜炎、肺炎和心肌缺血等严重病因后,再进入机械性治疗路径。

**注意事项 / Precautions**
- 当前胸痛为主而病人不主动提背痛时,最容易漏诊此问题。
- 只有肋骨活动能诱发同样疼痛时,诊断才更有把握。
- 深呼吸痛并非机械性疾病特异表现,必须排除胸膜炎和肺炎。

**量化指标 / Metrics**
- 牵涉痛复现率
- 误诊为非特异胸痛的纠正率
- 严重心肺病排除记录率
