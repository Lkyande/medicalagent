# Skill: 胸背痛病史结构化采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第27章 胸背痛
- 页码: 第27章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第27章.md`

**目标 / Objective**
通过标准化提问区分胸椎功能障碍、牵涉痛和严重内脏病因。

**适用范围 / Scope**
- 胸椎、肩胛间或侧胸壁疼痛病人

**操作步骤 / Procedure**
1. 明确疼痛是否与躯干旋转、深呼吸、咳嗽、打喷嚏或久坐姿势相关。
2. 追问是否有举重、摔伤、机动车事故或长期伏案、哺乳等诱因。
3. 询问疼痛是否夜间出现,是否伴发热、夜汗、皮疹、胸痛或胃肠症状。
4. 判断疼痛是否在运动后、进食后、平卧后或胸壁受压时加重或缓解。
5. 综合职业、年龄和伴随症状,初步分层为机械性、感染性、肿瘤性或牵涉痛。

**注意事项 / Precautions**
- 肩胛间痛可来自心肌缺血、食管疾病或穿透性消化性溃疡,不能只按脊柱病处理。
- “靠墙角挤压可缓解”提示机械性胸椎痛,但不能单独作为排除严重病因的依据。
- 夜间持续痛要高度警惕恶性肿瘤或感染。

**量化指标 / Metrics**
- 病史要素完整率
- 牵涉痛线索记录率
- 初诊病因分层准确率
