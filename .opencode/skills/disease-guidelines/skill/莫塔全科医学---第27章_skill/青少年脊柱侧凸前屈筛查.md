# Skill: 青少年脊柱侧凸前屈筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第27章 胸背痛
- 页码: 第27章“青少年特发性脊柱侧凸”“测试”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第27章.md`

**目标 / Objective**
在青少年体检或就诊时早期识别脊柱侧凸,及时进入观察、支具或手术评估路径。

**适用范围 / Scope**
- 9~14 岁儿童和青少年,尤其是快速生长期人群

**操作步骤 / Procedure**
1. 站立位先观察双肩是否等高、肩胛骨是否对称以及胸壁轮廓是否不对称。
2. 让受试者双脚并拢站立,双臂伸展,尽可能向前弯腰做前屈试验。
3. 观察前屈时背部或胸廓两侧是否出现隆起不对称。
4. 对筛查阳性者安排一次直立位脊柱 X 线测量 Cobb 角。
5. 依据 Cobb 角和骨骼成熟度决定观察、支具或手术转诊。

**注意事项 / Precautions**
- 严重青少年侧凸多见于女孩,但男女都应筛查。
- 轻度侧凸常无症状,不能只在病人诉痛时才检查。
- X 线应控制为必要次数,避免重复无意义拍片。

**量化指标 / Metrics**
- 适龄儿童筛查率
- 筛查阳性后 X 线完成率
- 需支具者及时干预率
