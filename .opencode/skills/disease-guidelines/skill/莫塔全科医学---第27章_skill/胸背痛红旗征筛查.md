# Skill: 胸背痛红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第27章 胸背痛
- 页码: 第27章“胸背痛的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第27章.md`

**目标 / Objective**
在胸背痛就诊时快速识别创伤、恶性肿瘤和化脓性感染等严重器质性病变。

**适用范围 / Scope**
- 所有急性或持续性胸背痛病人

**操作步骤 / Procedure**
1. 询问近期创伤、恶性肿瘤史、发热波动、夜汗及进行性夜间疼痛。
2. 关注老年、骨质疏松、免疫抑制或长期使用糖皮质激素的高危背景。
3. 判断是否存在持续昼夜痛、体重减轻、局灶神经症状或进行性功能下降。
4. 对胸痛与胸背痛并存者,优先排除心脏、肺部和胃肠道牵涉痛。
5. 一旦存在红旗征,优先安排 MRI 或相应实验室检查并转专科评估。

**注意事项 / Precautions**
- 老年胸背痛不能简单归因于“劳损”,器质性疾病比例更高。
- 带状疱疹出疹前可仅有肩胛区或单侧胸背痛,容易误诊。
- 在明确病因前,胸背痛伴胸部症状应先按心脏病处理原则评估。

**量化指标 / Metrics**
- 红旗征记录率
- 红旗阳性病人影像检查完成率
- 严重胸背痛漏诊率
