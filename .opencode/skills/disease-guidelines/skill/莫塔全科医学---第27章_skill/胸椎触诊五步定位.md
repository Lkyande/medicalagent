# Skill: 胸椎触诊五步定位

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第27章 胸背痛
- 页码: 第27章“触诊”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第27章.md`

**目标 / Objective**
通过标准化胸椎和肋椎关节触诊复现症状并定位功能障碍层面。

**适用范围 / Scope**
- 怀疑胸椎或肋椎关节功能障碍的胸背痛病人

**操作步骤 / Procedure**
1. 让病人俯卧并轻度前屈胸椎,以利于关节触诊。
2. 用拇指或掌骨突起对胸椎各节段做适度弹性按压,询问是否诱发熟悉疼痛。
3. 按顺序检查中线棘突上方、距中线 2~3cm 的骨突关节区、棘突旁横位区。
4. 继续触诊距中线 4~5cm 的肋横突连接处及沿肋骨轴向的肋骨区。
5. 同时记录疼痛分布、活动范围变化、关节阻力类型和肌肉痉挛情况。

**注意事项 / Precautions**
- 触诊要能再现病人熟悉的症状,而不是仅记录“压痛”。
- 骨质疏松或创伤后病人需避免粗暴手法,先排除骨折。
- 胸椎定位本身存在解剖重叠,应结合活动诱发和整体病史判断。

**量化指标 / Metrics**
- 触诊后症状复现率
- 功能障碍层面记录率
- 不适当重手法事件数
