# Skill: 医患关系建立开场

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第2章 看病技能
- 页码: 第2章“看病的阶段”“临床要领”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第2章.md`

**目标 / Objective**
在诊疗开始阶段快速建立信任、明确角色并为后续病史采集创造开放氛围。

**适用范围 / Scope**
- 全科门诊、初诊和复诊看病场景

**操作步骤 / Procedure**
1. 使用病人偏好的称呼并主动问候,确认基本身份信息。
2. 以简洁语句说明自己需要了解其身体、健康和生活情况。
3. 邀请病人按自己的方式先讲述最想表达的问题。
4. 在病人表达期间保持关注和目光接触,减少不必要打断。
5. 适时回应和总结,让病人感到被理解和被认真对待。
6. 在进入更具体问诊前,确认本次就诊的核心目标。

**注意事项 / Precautions**
- 初始几分钟避免过早控场,否则易漏掉真正诉求。
- 对语言、听力或文化沟通障碍者需调整表达方式。
- 对焦虑、疼痛明显或情绪激动病人,应先稳定情绪再推进问诊。

**量化指标 / Metrics**
- 病人首次连续表达时长
- 首诊核心诉求明确率
- 病人对沟通满意度
