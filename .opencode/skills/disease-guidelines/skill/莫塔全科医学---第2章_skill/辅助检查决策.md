# Skill: 辅助检查决策

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第2章 看病技能
- 页码: 第2章“辅助检查”“三振出局原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第2章.md`

**目标 / Objective**
以临床价值、风险和病人获益为标准,选择性安排辅助检查并避免无效检查。

**适用范围 / Scope**
- 全科门诊所有需要考虑实验室、影像或其他诊断检查的情形

**操作步骤 / Procedure**
1. 与病人讨论检查目的,取得知情同意。
2. 在开单前依次自问:是否必需、是否改变处理方案、希望看到什么结果。
3. 判断同类信息能否通过更便宜、更小创伤的方法获得,如补充病史或观察。
4. 评估检查风险是否与潜在临床价值匹配。
5. 仅在结果可直接辅助诊断或影响管理时安排检查。
6. 连续三次咨询仍不能明确诊断时,停止单独反复试探,及时咨询同事或转介。

**注意事项 / Precautions**
- 不能把辅助检查当作替代病史和体检的捷径。
- 对高风险检查、经济负担重检查和偶然发现率高的检查,需特别说明利弊。
- 对孕妇、儿童、肾功能不全或对比剂过敏病人,需先评估特殊风险。

**量化指标 / Metrics**
- 检查后影响诊疗决策的比例
- 非必要检查减少率
- 三次未确诊后及时会诊/转介率
