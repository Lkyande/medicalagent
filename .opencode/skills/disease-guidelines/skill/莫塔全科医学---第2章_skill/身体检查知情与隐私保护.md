# Skill: 身体检查知情与隐私保护

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第2章 看病技能
- 页码: 第2章“身体检查的医学准则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第2章.md`

**目标 / Objective**
在体格检查中兼顾医学需要、知情同意、隐私保护和病人舒适度。

**适用范围 / Scope**
- 所有需要身体检查的门诊咨询,尤其涉及敏感部位检查时

**操作步骤 / Procedure**
1. 检查前解释检查性质、目的和重点步骤。
2. 对可能不适或疼痛的操作提前说明,并请病人不适时立即告知。
3. 若需脱衣,明确告知脱衣范围及原因。
4. 提供屏风、床单或外袍,尽量减少暴露时间并避免他人干扰。
5. 尊重病人要求陪同者在场的意愿。
6. 检查过程中持续说明发现,尤其正常结果应及时反馈。
7. 保持门未上锁和可中止原则,让病人明确其随时可暂停检查。

**注意事项 / Precautions**
- 直肠、阴道、乳腺和生殖器检查前必须特别充分解释。
- 医生的沉默和非语言行为可能被误读为异常发现,需主动沟通。
- 对儿童、青少年、创伤史病人和羞怯明显者,应增加保护措施和沟通确认。

**量化指标 / Metrics**
- 检查前解释完成率
- 敏感检查知情同意记录率
- 病人对隐私保护满意度
