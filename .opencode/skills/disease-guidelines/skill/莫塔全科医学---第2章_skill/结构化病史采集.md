# Skill: 结构化病史采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第2章 看病技能
- 页码: 第2章“病史采集”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第2章.md`

**目标 / Objective**
通过系统化病史采集明确就诊原因、补充问题及隐藏诉求,为诊断和管理奠定基础。

**适用范围 / Scope**
- 所有全科门诊看病场景,尤其是症状不明确或问题复杂的病人

**操作步骤 / Procedure**
1. 先明确病人陈述的主要就诊原因。
2. 追问病人为什么选择今天或当前阶段来就诊。
3. 系统梳理补充症状和问题列表,避免只围绕单一主诉。
4. 主动探索未说出口的担忧,如对严重疾病的恐惧。
5. 询问一般症状和红旗征,包括乏力、体重变化、发热、头痛、睡眠和应对能力。
6. 完成既往史、药物史、过敏史、家族史、心理社会史和预防保健史记录。
7. 用反馈总结核对你对病人问题和就诊目的的理解,及时纠正误解。

**注意事项 / Precautions**
- 不要频繁打断病人自发叙述。
- 记录信息时仍应维持交流感,避免全程只看屏幕。
- 对高危红旗症状、儿童、老年人和沟通受限者,要降低漏诊阈值。

**量化指标 / Metrics**
- 完整病史要素记录率
- 隐藏诉求识别率
- 红旗征筛查完成率
