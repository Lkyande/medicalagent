# Skill: 转诊决策

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第2章 看病技能
- 页码: 第2章“转诊”“全科医生的守门人角色”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第2章.md`

**目标 / Objective**
在病人最佳利益基础上把握转诊时机与对象,避免过度转诊或不当滞留。

**适用范围 / Scope**
- 需要在基层继续管理与上级或其他专业支持之间做决策的病人

**操作步骤 / Procedure**
1. 判断病情严重程度、复杂性及是否存在危及生命或重度慢病情形。
2. 评估当前问题是否超出基层处置能力或需要特定专长支持。
3. 在专科、医院、特定兴趣全科医生及支持团队成员之间选择最合适去向。
4. 向病人解释转诊目的、预期收益和后续衔接方式。
5. 提供足够的病情摘要和问题清单,确保信息连续。
6. 转诊后继续承担核心协调角色,跟进结果并整合后续管理。

**注意事项 / Precautions**
- 严重慢性病或危及生命疾病不予转诊属于高风险错误。
- 过度转诊会增加碎片化照护和资源浪费,需保持平衡。
- 对多病共存、老年和健康素养有限病人,更需要明确转诊后的协调责任。

**量化指标 / Metrics**
- 合理转诊率
- 转诊信息完整率
- 转诊后结果回流与后续跟进率
