# Skill: 抗菌药物处方管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第2章 看病技能
- 页码: 第2章“抗菌药物管理”“处方抗生素的一般原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第2章.md`

**目标 / Objective**
优化抗菌药物使用,改善临床结局并减少耐药和不良后果。

**适用范围 / Scope**
- 全科门诊需考虑是否使用抗生素的感染性疾病,尤其呼吸道感染

**操作步骤 / Procedure**
1. 先判断是否存在明确细菌感染证据或证据支持的适应证。
2. 能依据培养/药敏时,优先选择可覆盖病原体的最窄谱抗生素。
3. 在有效性和安全性相近时,选择成本更低方案。
4. 优先使用适当的口服方案,并按个体情况调整剂量。
5. 选择严重副作用更少、疗程尽可能短的方案。
6. 避免对病毒性呼吸道感染开抗菌药物,必要时采取等待观察和对症治疗。
7. 避免无必要的联合用药、局部抗生素和预防性用药。

**注意事项 / Precautions**
- 急性中耳炎、咽炎、扁桃体炎、急性支气管炎、细支气管炎和流感常为病毒病因,不可机械处方抗生素。
- 眼部感染和阴道炎是局部抗生素少数例外情形,仍需符合适应证。
- 对儿童、孕妇、肾功能不全和药物过敏史病人,需做额外安全评估。

**量化指标 / Metrics**
- 窄谱抗生素使用率
- 病毒性感染不恰当抗生素处方率
- 抗菌药物疗程符合率
