# Skill: 合理处方决策

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第2章 看病技能
- 页码: 第2章“处方”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第2章.md`

**目标 / Objective**
基于疾病判断、病人期望和药物风险收益做出审慎处方,必要时合理选择不处方。

**适用范围 / Scope**
- 需要开具或评估是否需要药物治疗的全科门诊场景

**操作步骤 / Procedure**
1. 明确药物治疗是否真正必要,先核对疾病性质和治疗目标。
2. 评估病人期望、既往用药、药物相互作用和不良反应风险。
3. 若药物并非绝对需要,优先考虑非药物治疗或观察随访。
4. 决定不给药时,向病人解释原因和替代方案。
5. 决定给药时,选择与病情匹配且风险可控的方案。
6. 对阿片类药物、抗生素和镇静剂保持更高处方阈值。

**注意事项 / Precautions**
- 对“不确定是否该开”的药物,应避免仓促处方。
- 要特别关注多病共存、老年人、肝肾功能异常者的相互作用与不良反应。
- 不处方也属于积极管理,必须提供清楚解释和复诊指引。

**量化指标 / Metrics**
- 处方合理性审核通过率
- 非必要药物处方减少率
- 用药相关不良事件发生率
