# Skill: 管理阶段交谈

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第2章 看病技能
- 页码: 第2章“管理阶段的交谈程序”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第2章.md`

**目标 / Objective**
在诊断后以结构化方式解释病情、协商方案并安排随访,提升理解和依从性。

**适用范围 / Scope**
- 已形成初步诊断或管理方向的全科咨询

**操作步骤 / Procedure**
1. 告知病人目前诊断或最可能诊断。
2. 确认病人是否真正理解该诊断及其意义。
3. 探索病人对诊断和管理的态度与顾虑。
4. 补充疾病教育并纠正错误健康观念。
5. 围绕即时、长期和预防三个维度共同制订管理计划。
6. 发现并利用其他预防时机,把健康促进纳入本次就诊。
7. 强化关键信息,必要时结合检查结果解释。
8. 提供可带走的信息或资源。
9. 评估本次看病是否解决了病人问题。
10. 明确随访时间、警示症状和后续安排。

**注意事项 / Precautions**
- 若病人依从性差,应优先反思管理阶段是否沟通不足。
- 使用病人能理解的语言,避免术语堆积。
- 对慢病、多病共存或健康素养较低者,需分步重复重点信息。

**量化指标 / Metrics**
- 管理计划共同决策完成率
- 病人对诊断/方案复述正确率
- 随访执行率与依从性
