# Skill: 开放式提问应用

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第2章 看病技能
- 页码: 第2章“好的提问”“开放式问题”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第2章.md`

**目标 / Objective**
用开放式和邀请式提问充分暴露病人的真实诉求、担忧和社会心理背景。

**适用范围 / Scope**
- 初诊、复杂主诉、疑似社会心理问题或医患目标尚不清楚的咨询

**操作步骤 / Procedure**
1. 以开放式问题启动对话,如请病人讲述“今天为什么来”。
2. 在病人初步表达后,继续用邀请式语句鼓励展开,如“再多说说”。
3. 询问病人最担心的事情、对病因的看法和对本次看病的期待。
4. 视情况追问家庭、工作、压力、欺凌或关系问题。
5. 在合适时机再转入直接式提问,收窄诊断范围。
6. 避免过早使用诱导式、封闭式或反问式问题主导谈话。

**注意事项 / Precautions**
- 开放式提问不是无限发散,需要在充分表达后及时归纳。
- 涉及创伤、暴力或性相关问题时应先建立安全感。
- 对认知受损或急危重症病人,提问方式需更直接简洁。

**量化指标 / Metrics**
- 开放式问题使用次数
- 病人主动提供的新信息条数
- 社会心理因素识别率
