# Skill: 结束诊疗评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第2章 看病技能
- 页码: 第2章“结束诊疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第2章.md`

**目标 / Objective**
在咨询结束前确认病人问题是否被回应、是否仍有未满足需求,并减少信息遗漏。

**适用范围 / Scope**
- 所有完成诊断或管理讨论后的门诊咨询

**操作步骤 / Procedure**
1. 在结束前主动询问本次看病是否对病人和其问题有所帮助。
2. 进一步询问是否还有其他需要医生处理或解释的问题。
3. 确认病人已理解诊断、治疗、警示症状和随访安排。
4. 识别仍未解决的担忧,必要时当场补充说明或调整计划。
5. 用简短总结结束本次咨询,明确下一步。

**注意事项 / Precautions**
- 不应把结束语变成形式化客套,应真正留出补充问题的空间。
- 对多问题病人,需避免在结束时才暴露关键新主诉而未妥善处理。
- 对焦虑明显或理解能力有限者,应再次核对其对后续安排的掌握程度。

**量化指标 / Metrics**
- 结束阶段新增问题发现率
- 病人对随访安排理解率
- 诊后回访中的信息遗漏率
