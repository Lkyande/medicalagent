# Skill: HIV暴露后预防启动

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“暴露后预防”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
对显著高风险 HIV 暴露者及时评估并启动 PEP,减少感染发生。

**适用范围 / Scope**
- 无保护高风险性暴露、针刺伤或其他高危体液暴露后 72 小时内病人

**操作步骤 / Procedure**
1. 立即评估暴露类型、来源者风险和暴露发生时间。
2. 对低风险暴露不常规推荐 PEP,但对显著高风险暴露进入快速启动流程。
3. 确保在暴露后 72 小时内开始治疗。
4. 启动通常每日 2 到 3 种抗逆转录病毒药物联合方案,持续 28 日。
5. 同步安排基线和后续 HIV 检测、咨询及专科支持。

**注意事项 / Precautions**
- 超过 72 小时将显著降低 PEP 的预期获益。
- 风险评估是关键,不能对所有低风险暴露一概给药。
- 需参照针刺和锐器伤流程并咨询当地相关机构。

**量化指标 / Metrics**
- 高风险暴露后 72 小时内 PEP 启动率
- 28 日 PEP 完成率
- PEP 随访检测完成率
