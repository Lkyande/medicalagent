# Skill: EB样综合征病原鉴别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“四种相似的临床表现”“巨细胞病毒感染”“弓形虫病”“原发性HIV感染鉴别诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
对 EBM 样发热性疾病进行病原学分层,避免遗漏原发 HIV、CMV 和弓形虫感染。

**适用范围 / Scope**
- 发热、乏力、淋巴结肿大、肝功能异常或异型淋巴细胞增多的病人

**操作步骤 / Procedure**
1. 将 EBV、原发 HIV、CMV 和弓形虫列为四个核心鉴别病原体。
2. 依据有无渗出性咽炎、颈后淋巴结肿大、异嗜性抗体结果和风险暴露史进行初步排序。
3. 对异嗜性抗体阴性且类似 EBM 的病人加做 HIV、CMV 或弓形虫相关检测。
4. 对大量输血、器官移植或免疫抑制病人优先考虑 CMV。
5. 对猫接触、免疫功能低下或神经系统症状病人增加弓形虫评估。

**注意事项 / Precautions**
- 原发 HIV 是最重要不能漏掉的 EB 样综合征病原体之一。
- 单看发热和淋巴结病无法区分这四种感染。
- 结果阴性时要结合窗口期和复测策略。

**量化指标 / Metrics**
- EBM 检测阴性病例扩展鉴别率
- 原发 HIV 早期识别率
- EB 样综合征病原明确率
