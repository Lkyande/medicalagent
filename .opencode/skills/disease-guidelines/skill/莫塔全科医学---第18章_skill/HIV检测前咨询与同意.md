# Skill: HIV检测前咨询与同意

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“HIV检测:全科医生的作用”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
在 HIV 检测前完成风险沟通、保密说明和知情同意,降低检测障碍和结果冲击。

**适用范围 / Scope**
- 所有计划接受 HIV 检测或有高危暴露评估需求的病人

**操作步骤 / Procedure**
1. 采集完整性生活史、吸毒史和其他相关暴露史。
2. 在检测前落实“三个 C”:咨询、保密和知情同意。
3. 解释筛查与核验流程、窗口期和可能需要复测的原因。
4. 预先讨论阳性、阴性和不确定结果各自的含义及下一步安排。
5. 若结果阳性,立即提供支持并安排专业团队参与照护。

**注意事项 / Precautions**
- 缺乏检测前咨询会显著加重病人的困惑和崩溃感。
- 必须以无偏见和接纳性的方式开展检测沟通。
- 保密是建立信任和提高检测接受度的核心。

**量化指标 / Metrics**
- HIV 检测前咨询完成率
- 知情同意记录率
- 检测后失访率
