# Skill: EB病毒单核细胞增多症抗生素皮疹规避

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“皮疹”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
在疑似或确诊 EBM 病人中避免因不当使用青霉素类药物而诱发广泛皮疹。

**适用范围 / Scope**
- 扁桃体炎、咽炎或发热性淋巴结病且怀疑 EBM 的病人

**操作步骤 / Procedure**
1. 在开具抗生素前评估病人是否存在 EBM 线索,如咽痛、发热、颈后淋巴结肿大和脾大。
2. 若怀疑 EBM,不要经验性使用氨苄西林或阿莫西林治疗“扁桃体炎”。
3. 如需排除细菌性咽炎,优先安排相关检查而不是盲目用药。
4. 若病人在用药后出现广泛斑丘疹或紫色皮疹,回顾是否存在 EBM 背景。
5. 在病历中记录该药疹背景,并向病人解释其与 EBM 的关系。

**注意事项 / Precautions**
- 使用氨苄西林或阿莫西林的 EBM 病人 90% 到 100% 会出现皮疹。
- 该反应不等同于典型青霉素过敏,需结合临床解释。
- 误将 EBM 当作细菌性扁桃体炎是常见错误。

**量化指标 / Metrics**
- 疑似 EBM 病例避免阿莫西林使用率
- EBM 相关药疹发生率
- 咽炎病例抗生素合理使用率
