# Skill: 巨细胞病毒EB样感染诊断

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“巨细胞病毒感染”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
识别健康成人中类似 EBM 的获得性 CMV 感染,并通过血清学或 PCR 确认。

**适用范围 / Scope**
- 发热、乏力、关节肌痛、肝功能异常且异嗜性抗体阴性的成人

**操作步骤 / Procedure**
1. 询问发热模式、乏力、关节痛、肌痛和输血或大型手术史。
2. 识别相对淋巴细胞增多、非典型淋巴细胞和肝功能异常。
3. 注意其常缺乏明显颈部淋巴结肿大和渗出性咽炎。
4. 通过急性期与恢复期 2 周血清抗体滴度 4 倍升高确认新近感染,或使用 PCR 检测。
5. 对免疫功能正常者以支持治疗为主,免疫抑制者转专科抗病毒治疗。

**注意事项 / Precautions**
- 大量输血后出现 EB 样综合征要高度怀疑 CMV。
- 免疫低下者 CMV 可能播散并累及肺、视网膜和脑。
- 阴性异嗜性抗体是重要鉴别线索。

**量化指标 / Metrics**
- 异嗜性抗体阴性 EB 样病例 CMV 检测率
- 免疫低下 CMV 及时转诊率
- 病原确诊率
