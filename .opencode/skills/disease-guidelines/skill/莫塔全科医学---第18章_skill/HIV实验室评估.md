# Skill: HIV实验室评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“检查和诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
用标准化实验室路径确认 HIV 感染并评估免疫状态、病毒活性和并发感染。

**适用范围 / Scope**
- HIV 初筛阳性、疑似感染或已知感染需基线评估的病人

**操作步骤 / Procedure**
1. 先进行 HIV 抗原-抗体筛查或快速检测。
2. 筛查阳性后用另一方法如免疫印迹法进行核验。
3. 检测 CD4 细胞计数以评估免疫缺陷程度,并标记小于 500 和小于 200 个/μl 的关键阈值。
4. 检测血清 HIV RNA 病毒载量以评估活性和治疗相关风险。
5. 完成机会性感染、其他性传播感染、肝炎、结核和常规健康检查作为基线。

**注意事项 / Precautions**
- 诊断不仅是“是否感染”,还要同步了解免疫和病毒状态。
- CD4 小于 200 个/μl 提示严重免疫缺陷。
- 基因型和药物耐药评估需由专科治疗方案统筹。

**量化指标 / Metrics**
- HIV 初筛阳性核验完成率
- 基线 CD4 与病毒载量检测率
- 基线机会性感染筛查完成率
