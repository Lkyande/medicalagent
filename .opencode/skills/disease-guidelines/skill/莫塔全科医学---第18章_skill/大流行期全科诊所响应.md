# Skill: 大流行期全科诊所响应

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“全科医生在疾病大流行时的作用”“表18.6 澳大利亚全科医学针对大流行不同阶段的响应计划”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
在传染病大流行不同阶段保持全科诊所业务连续性并减少社区传播。

**适用范围 / Scope**
- 流感、冠状病毒或其他全国性大流行期间的全科诊所与基层团队

**操作步骤 / Procedure**
1. 根据大流行阶段定期审查应对计划、资源储备和人员分工。
2. 持续获取最新官方建议,并按病毒传播方式更新接触、飞沫和空气预防措施。
3. 重新组织诊所流程,通过分流、社交距离、远程医疗和专门呼吸道门诊降低交叉感染。
4. 维持常规病人护理和合并症管理,同时开展大规模疫苗接种与病例监测。
5. 为工作人员和病人提供心理支持,并定期复盘以修订后续计划。

**注意事项 / Precautions**
- 每一次大流行都不同,不能机械照搬既往方案。
- 全科医生自我护理和团队可持续性非常关键。
- 业务连续性与感染控制要同步考虑,不能偏废其一。

**量化指标 / Metrics**
- 大流行预案更新频率
- 远程医疗使用率
- 诊所内交叉感染事件数
