# Skill: EB病毒单核细胞增多症识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“EBV所致单核细胞增多症”“临床特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
识别 EBM 的典型咽痛-发热-淋巴结病模式,并与其他相似感染区分。

**适用范围 / Scope**
- 10 到 35 岁发热、咽喉痛、淋巴结肿大、不适或脾大病人

**操作步骤 / Procedure**
1. 询问持续 1 到 6 周的缓慢起病不适、发热、肌痛、头痛和咽喉痛。
2. 体检重点查看渗出性咽炎、颈后淋巴结肿大、脾大和肝脏受累迹象。
3. 识别发热型、心绞痛型和腺体型三种常见表现。
4. 将原发 HIV、CMV、弓形虫和链球菌咽炎纳入鉴别。
5. 对疑似病例安排血液学和异嗜性抗体检测。

**注意事项 / Precautions**
- EBM 是重要“伪装者”,可像 HIV、肝炎或急性白血病。
- 儿童原发 EBV 感染常无症状,成人更典型。
- 脾大病人要特别提醒避免接触性运动。

**量化指标 / Metrics**
- 咽痛伴淋巴结肿大病例 EBM 考虑率
- 相关鉴别诊断覆盖率
- EBM 初诊识别率
