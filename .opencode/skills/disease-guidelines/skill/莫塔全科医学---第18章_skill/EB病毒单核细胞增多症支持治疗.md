# Skill: EB病毒单核细胞增多症支持治疗

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“EBV所致单核细胞增多症”“治疗”“预后”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
为 EBM 病人提供以休息和并发症预防为核心的支持治疗。

**适用范围 / Scope**
- 已诊断或高度怀疑 EBM 的门诊病人

**操作步骤 / Procedure**
1. 解释病程多为自限性,主要症状通常 2 到 3 周缓解,总体病程 6 到 8 周。
2. 建议急性期在家休息,保证充足饮水。
3. 使用 NSAIDs 或对乙酰氨基酚缓解不适,并用阿司匹林溶液、30% 葡萄糖溶液或生理盐水漱口减轻咽痛。
4. 叮嘱 8 周内避免饮酒、高脂饮食和持续尤其接触性运动。
5. 出现神经系统受累、血小板减少或高危气道阻塞时考虑糖皮质激素并升级处理。

**注意事项 / Precautions**
- 无并发症病例不推荐常规使用类固醇。
- 脾破裂风险决定了运动限制很重要。
- 病后虚弱和抑郁可持续数月,需提前解释和随访。

**量化指标 / Metrics**
- EBM 生活方式限制宣教率
- 并发症升级识别率
- 病后持续乏力随访率
