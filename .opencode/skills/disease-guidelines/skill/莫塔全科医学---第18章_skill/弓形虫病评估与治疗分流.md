# Skill: 弓形虫病评估与治疗分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“弓形虫病”“诊断”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
识别弓形虫病的临床表现并根据症状严重度和宿主状态决定是否治疗。

**适用范围 / Scope**
- 无痛性淋巴结肿大、EBM样发热、免疫低下神经系统症状或妊娠病人

**操作步骤 / Procedure**
1. 询问猫粪污染食物暴露、免疫缺陷和妊娠状态。
2. 识别无症状淋巴结肿大、EBM 样发热、皮疹、心肌炎、肺炎或脉络膜视网膜炎表现。
3. 对头痛、颈强直和脑膜脑炎表现者警惕严重神经系统受累。
4. 通过血清学检测抗体滴度 4 倍升高进行诊断。
5. 轻症或无症状者可不治疗,有症状者用乙胺嘧啶联合磺胺嘧啶,妊娠病人通常用克林霉素并转专科。

**注意事项 / Precautions**
- 免疫功能低下病人更易出现严重脑膜脑炎。
- 先天性弓形虫病虽少见但预后差,妊娠期必须慎重处理。
- 5 岁以下儿童治疗是为了预防脉络膜视网膜炎。

**量化指标 / Metrics**
- 弓形虫病高危暴露询问率
- 可疑病例血清学完成率
- 重症或妊娠病例专科转诊率
