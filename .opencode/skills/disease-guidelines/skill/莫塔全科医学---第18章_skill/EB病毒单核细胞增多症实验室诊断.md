# Skill: EB病毒单核细胞增多症实验室诊断

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“EBV所致单核细胞增多症”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
使用血液学和血清学检查确认 EBM,并识别假阴性或替代诊断。

**适用范围 / Scope**
- 临床怀疑 EBM 或假性 EBM 的病人

**操作步骤 / Procedure**
1. 先查全血细胞计数,寻找淋巴细胞绝对值增多。
2. 查外周血涂片,识别不典型淋巴细胞。
3. 进行 Paul-Bunnell 或 Monospot 异嗜性抗体检测。
4. 若异嗜性抗体阴性但临床高度怀疑,改做 EBV 特异性抗体如 VCA IgM、IgG 和 EBNA。
5. 必要时加做咽拭子培养,排除链球菌性咽炎。

**注意事项 / Precautions**
- 约 10% 病例异嗜性抗体可延迟阳性或始终阴性。
- 肝炎、霍奇金淋巴瘤和急性白血病可造成假阳性。
- 无须常规做病毒培养。

**量化指标 / Metrics**
- 疑似 EBM 异嗜性抗体检测率
- 异嗜性抗体阴性后补充 EBV 特异性检测率
- EBM 与链球菌咽炎鉴别完成率
