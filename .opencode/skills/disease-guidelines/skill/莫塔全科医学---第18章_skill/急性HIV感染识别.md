# Skill: 急性HIV感染识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“人类免疫缺陷病毒/艾滋病”“急性症状期(血清转化期)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
在血清转化期尽早识别急性 HIV 感染,避免被误诊为单纯 EBM 或普通病毒感染。

**适用范围 / Scope**
- 发热、严重不适、淋巴结肿大、皮疹或高危暴露后出现 EB 样综合征者

**操作步骤 / Procedure**
1. 采集性行为、既往性传播感染、注射吸毒、输血和伴侣风险等暴露史。
2. 识别发热、盗汗、严重嗜睡、咽痛、腹泻、全身皮疹和血小板减少等急性期表现。
3. 对 EBV 检测阴性或临床不典型的 EBM 样病人主动考虑原发 HIV。
4. 解释窗口期概念,在合适时点进行 HIV 抗原-抗体检测并视情况 4 周后复测。
5. 对疑似或确诊病例尽早转 HIV 专科联合管理。

**注意事项 / Precautions**
- 约半数病人在感染后数周出现类似 EBM 的急性疾病。
- 病毒复制在早期非常活跃,早诊断价值极高。
- 一次阴性结果不能排除窗口期感染。

**量化指标 / Metrics**
- EB 样综合征完成 HIV 风险评估率
- 高危暴露后及时检测率
- 急性 HIV 早期识别率
