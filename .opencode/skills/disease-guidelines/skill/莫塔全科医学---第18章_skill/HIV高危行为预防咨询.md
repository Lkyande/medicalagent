# Skill: HIV高危行为预防咨询

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“HIV感染的预防”“向高危人群提供有关更安全做法的咨询”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
向高危个体提供可执行的安全性行为和减少血液暴露的预防建议。

**适用范围 / Scope**
- HIV 高危人群、性传播疾病病人、注射药物使用者及其伴侣

**操作步骤 / Procedure**
1. 评估当前性行为模式、避孕套使用情况、针具共用和其他高危行为。
2. 强调正确且持续使用避孕套,并说明肛交中破损风险更高。
3. 建议使用水基润滑剂,避免凡士林等油基润滑剂削弱避孕套。
4. 讨论替代式性行为和减少体液交换的可行选择。
5. 同步筛查和治疗其他性传播疾病,并评估是否适合 PrEP。

**注意事项 / Precautions**
- 其他性传播疾病显著增加 HIV 传播风险。
- 预防咨询应具体到行为,不能只泛泛说“注意安全”。
- 需要避免污名化表达,提高病人接受度。

**量化指标 / Metrics**
- 高危病人预防咨询完成率
- 避孕套正确使用教育率
- 同步 STI 筛查完成率
