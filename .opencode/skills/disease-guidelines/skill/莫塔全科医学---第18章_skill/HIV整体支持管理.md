# Skill: HIV整体支持管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第18章 令人困惑的病毒和原虫感染
- 页码: 第18章“管理”“整体化的管理方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第18章.md`

**目标 / Objective**
为 HIV 感染者提供持续的心理社会支持、生活方式指导和与专科协作的慢病管理框架。

**适用范围 / Scope**
- 所有已知 HIV 感染者及其长期随访阶段

**操作步骤 / Procedure**
1. 评估心理压力、污名感、支持系统和是否存在严重心理问题。
2. 与专科医生共同管理,明确全科在预防、咨询、监测和慢病支持中的角色。
3. 指导均衡饮食、戒烟限酒、避免非法药物、适当睡眠与锻炼。
4. 讨论病人使用的自然疗法或补充剂,将其作为补充而非替代正规治疗。
5. 持续提供支持小组、咨询和复诊跟踪,营造无偏见、可持续的照护关系。

**注意事项 / Precautions**
- HIV 现已更接近慢病管理模式,但心理冲击仍然很大。
- 必须主动询问补充疗法使用情况,避免药物相互作用。
- 接纳性和连续照护对长期依从性至关重要。

**量化指标 / Metrics**
- HIV 病人心理社会评估率
- 生活方式指导覆盖率
- 专科联合随访完成率
