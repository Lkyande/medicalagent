# Skill: 宁养疗护六问沟通

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第126章 临终关怀与宁养疗护
- 页码: 第126章“全科医生的特殊作用”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第126章.md`

**目标 / Objective**
用关键六问框架与病人及家属开展诚实、支持性的宁养疗护沟通。

**适用范围 / Scope**
- 癌症、终末器官衰竭或退行性疾病进入宁养疗护阶段的病人及家属

**操作步骤 / Procedure**
1. 主动围绕“出了什么问题、能做什么、会有多痛苦”等六个核心问题展开对话。
2. 诚实回答,避免轻率直言或虚假希望。
3. 明确病人知道了什么、想知道什么。
4. 允许病人和家属提问与澄清。
5. 以居家照护和尊严维护为中心安排后续计划。

**注意事项 / Precautions**
- 永远不要对病人撒谎。
- 家属与医生的“沉默合谋”会伤害病人感受。
- 沟通本身是宁养疗护质量的核心组成部分。

**量化指标 / Metrics**
- 宁养疗护沟通记录率
- 病人问题回应率
- 家属满意度
