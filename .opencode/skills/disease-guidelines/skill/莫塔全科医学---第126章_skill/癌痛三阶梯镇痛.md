# Skill: 癌痛三阶梯镇痛

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第126章 临终关怀与宁养疗护
- 页码: 第126章“癌症的疼痛控制”“使用镇痛药”“第1步至第3步”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第126章.md`

**目标 / Objective**
根据 WHO 三阶梯原则为癌痛病人建立规律、可升级的镇痛方案。

**适用范围 / Scope**
- 需要宁养疗护的癌痛病人

**操作步骤 / Procedure**
1. 先评估疼痛强度、病因和是否对阿片敏感。
2. 轻度疼痛先用非阿片类镇痛药并定时给药。
3. 中度疼痛升级为弱或小剂量阿片类,并逐步滴定。
4. 剧烈疼痛使用吗啡等强阿片类,按规律给药并设置突破痛救援剂量。
5. 预防便秘和恶心,1~2 日内重新评估剂量和反应。

**注意事项 / Precautions**
- 给药应规律定时,不是等痛了再给。
- 口服是首选途径,但晚期病人皮下途径常更实用。
- 需主动释除病人和家属对吗啡的误解。

**量化指标 / Metrics**
- 癌痛病人的阶梯镇痛匹配率
- 突破痛救援剂量设置率
- 镇痛后疼痛缓解率
