# Skill: 突破痛阿片滴定

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第126章 临终关怀与宁养疗护
- 页码: 第126章“使用镇痛药”“指菌”“表126.3 常见的关于吗啡的误解”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第126章.md`

**目标 / Objective**
在基础镇痛方案上为突破痛设定安全、有效的阿片滴定策略。

**适用范围 / Scope**
- 已使用阿片类药物但仍有突破痛的宁养疗护病人

**操作步骤 / Procedure**
1. 先确认基础疼痛是否对阿片敏感并已获得相对稳定控制。
2. 设定 5~10 mg 或按方案比例换算的突破痛救援剂量。
3. 当某次剂量无效时,下次按 30%~50% 原则上调。
4. 记录基础剂量与额外用量,再换算回缓释或长效方案调整。
5. 同步预防便秘、恶心并持续释疑吗啡相关误解。

**注意事项 / Precautions**
- 吗啡没有“最后手段”这一说法。
- 阿片剂量调整以止痛为目标,而非固定上限。
- 频繁突破痛提示基础方案需要重估。

**量化指标 / Metrics**
- 突破痛救援方案设置率
- 1~2 日内复评率
- 突破痛控制成功率
