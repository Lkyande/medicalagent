# Skill: 呕血与黑便病史核查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第44章 呕血和黑便
- 页码: 第44章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第44章.md`

**目标 / Objective**
通过关键病史区分真实上消化道出血、食管来源出血和伪黑便。

**适用范围 / Scope**
- 所有诉呕血、咖啡样呕吐物或黑便的病人

**操作步骤 / Procedure**
1. 明确呕吐物是鲜血还是咖啡样,并询问是否先有剧烈呕吐或干呕。
2. 询问黑便、血块、近期排便情况及消化不良、胃灼热或腹痛。
3. 系统核查药物史,重点关注阿司匹林、NSAIDs、抗血小板药和抗凝药。
4. 询问饮酒量、既往消化性溃疡或胃部手术史。
5. 排除鼻出血吞血、铁剂、含铋制剂和红色食物等混淆因素。

**注意事项 / Precautions**
- 食管出血更常见鲜血,咖啡样呕吐提示血液已接触胃酸。
- 服药史常直接决定出血风险和后续处理策略。
- 呕血和咯血容易混淆,必要时追问伴咳嗽与胸部症状。

**量化指标 / Metrics**
- UGIB 关键病史完成率
- 药物相关出血识别率
- 伪黑便误判率
