# Skill: Mallory-Weiss综合征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第44章 呕血和黑便
- 页码: 第44章“食管贲门黏膜撕裂综合征(Mallory-Weiss综合征)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第44章.md`

**目标 / Objective**
在上消化道出血中识别由剧烈呕吐或干呕后造成的食管胃结合部撕裂。

**适用范围 / Scope**
- 剧烈呕吐、干呕或咳嗽后出现呕血的病人

**操作步骤 / Procedure**
1. 追问呕血前是否有连续剧吐、干呕或剧烈咳嗽。
2. 识别饮酒背景下突发呕血的典型场景。
3. 在没有其他明显原因时将 Mallory-Weiss 综合征列入高优先级鉴别。
4. 同时进行循环稳定性评估,不要因其常自限而低估急性失血风险。
5. 安排上消化道内镜以明确诊断并排除其他活动性出血来源。

**注意事项 / Precautions**
- 该综合征虽常自限,但首诊仍按 UGIB 流程处理。
- 仅凭病史不能完全排除食管静脉曲张或溃疡出血。
- 咖啡样呕吐和鲜血呕吐都可能出现,需结合前驱事件判断。

**量化指标 / Metrics**
- 典型剧吐前驱识别率
- 内镜确认率
- 误归因于普通胃炎率
