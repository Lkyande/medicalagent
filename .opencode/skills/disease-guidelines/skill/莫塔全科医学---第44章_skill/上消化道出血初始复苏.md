# Skill: 上消化道出血初始复苏

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第44章 呕血和黑便
- 页码: 第44章“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第44章.md`

**目标 / Objective**
在严重上消化道出血中优先恢复有效循环血容量并衔接专科救治。

**适用范围 / Scope**
- 伴大出血、休克或循环不稳定的上消化道出血病人

**操作步骤 / Procedure**
1. 立即将复苏作为首要任务,同时安排住院和专科转诊。
2. 建立静脉通路并快速输入等渗盐水。
3. 必要时加用血浆扩容剂,随后尽快输血。
4. 在复苏同时继续监测心率、血压和意识状态变化。
5. 稳定后尽快安排上消化道内镜明确并处理出血点。

**注意事项 / Precautions**
- 复苏优先级高于病因定性,不能等检查结果后再补液。
- 所有严重出血病人都应住院,不适合门诊观察。
- 出血后早期血红蛋白可能尚未明显下降,不能据此低估严重度。

**量化指标 / Metrics**
- UGIB 到补液启动时间
- 循环不稳病人住院转运率
- 初始复苏后生命体征稳定率
