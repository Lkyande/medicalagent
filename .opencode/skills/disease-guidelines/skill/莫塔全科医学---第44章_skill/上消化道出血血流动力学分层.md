# Skill: 上消化道出血血流动力学分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第44章 呕血和黑便
- 页码: 第44章“关键事实和要点”“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第44章.md`

**目标 / Objective**
以血流动力学而非主观估计判断上消化道出血严重度并决定紧急程度。

**适用范围 / Scope**
- 呕血、咖啡样呕吐物、黑便或疑似上消化道出血病人

**操作步骤 / Procedure**
1. 立即测量心率、血压并评估体位改变对循环的影响。
2. 识别心动过速、低血压、头晕、出汗和昏厥等失血性休克表现。
3. 结合年龄和代偿能力判断风险,注意年轻病人可在较大失血后才表现失代偿。
4. 将循环不稳定者直接归入大出血高危路径并准备复苏。
5. 对相对稳定者继续完善病史、直肠指检和后续专科评估。

**注意事项 / Precautions**
- 病人对呕血量的估计常常偏高,不能作为严重度核心依据。
- 黑便通常提示风险低于剧烈呕血,但仍需评估循环状态。
- 既往健康成人出现休克往往意味着失血已达约 1000~1500ml。

**量化指标 / Metrics**
- UGIB 病人体征记录率
- 循环不稳定识别及时率
- 休克延误识别率
