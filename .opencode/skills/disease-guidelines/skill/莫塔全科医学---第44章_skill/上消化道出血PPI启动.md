# Skill: 上消化道出血PPI启动

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第44章 呕血和黑便
- 页码: 第44章“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第44章.md`

**目标 / Objective**
在怀疑消化性溃疡相关出血时尽早启动质子泵抑制剂治疗。

**适用范围 / Scope**
- 初步评估为上消化道出血且考虑消化性溃疡来源的病人

**操作步骤 / Procedure**
1. 在完成初始复苏后评估是否存在消化性溃疡出血可能。
2. 对大多数病人尽早开始 PPI 治疗。
3. 病情较轻且可口服者使用口服 PPI。
4. 对严重病人按书中方案改用静脉 PPI,随后持续治疗数日。
5. 待病情稳定后再过渡为口服 PPI 并结合内镜结果调整方案。

**注意事项 / Precautions**
- PPI 不能替代内镜评估和止血,只是初始管理的一部分。
- 静脉制剂更适用于重症或不能口服病人。
- 同时要继续处理诱因,尤其是 NSAIDs 和阿司匹林相关出血。

**量化指标 / Metrics**
- 可疑溃疡出血 PPI 启动率
- 重症 UGIB 静脉 PPI 使用率
- 稳定后口服转换完成率
