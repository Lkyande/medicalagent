# Skill: TIAABCD2风险分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第121章 卒中和短暂性脑缺血发作
- 页码: 第121章“TIA 的意义”“ABCD2 卒中风险工具”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第121章.md`

**目标 / Objective**
对 TIA 病人进行短期卒中风险分层并决定处理紧迫度。

**适用范围 / Scope**
- 神经症状已完全恢复或短暂发作的 TIA 可疑病人

**操作步骤 / Procedure**
1. 记录年龄、血压、临床特征、持续时间和糖尿病情况。
2. 使用 ABCD2 工具估计 7 日内卒中风险。
3. 对高分或高危临床特征病人安排更紧急的影像和血管评估。
4. 同步启动二级预防方向讨论,包括抗血小板和危险因素控制。
5. 教育病人一旦再发症状需立即就医。

**注意事项 / Precautions**
- TIA 后多数卒中发生在最初 48 小时到 2 周内。
- 年龄 >60 岁、症状 >10 分钟、无力或语言障碍风险最高。
- TIA 不应被当作“已经好了的小问题”。

**量化指标 / Metrics**
- TIA 病人的 ABCD2 评分率
- 高危 TIA 紧急转介率
- 48 小时内评估完成率
