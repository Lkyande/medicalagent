# Skill: 疑似卒中急诊分诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第121章 卒中和短暂性脑缺血发作
- 页码: 第121章“关键事实和要点”“管理”“紧急处理方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第121章.md`

**目标 / Objective**
将卒中或 TIA 视为医疗急症并尽快转入影像和卒中单元路径。

**适用范围 / Scope**
- 突发局灶神经功能缺损、语言障碍、单侧无力或短暂神经症状病人

**操作步骤 / Procedure**
1. 识别突发神经功能缺损并记录起病时间。
2. 立即稳定气道、呼吸和循环,同时排除低血糖和明显头外伤。
3. 尽快安排 CT 或 MRI 鉴别缺血性与出血性卒中。
4. 对病人启动卒中单元转运或急诊住院路径。
5. 在影像基础上再进入阿司匹林、溶栓或出血性卒中管理分流。

**注意事项 / Precautions**
- 卒中和 TIA 都是急症,不能因症状暂时缓解而放松。
- 影像越早越关键,尤其溶栓时窗内。
- 不可先验性将年轻病人的神经症状归为偏头痛或心理问题。

**量化指标 / Metrics**
- 疑似卒中影像完成时效
- 卒中单元转运率
- 起病时间记录率
