# Skill: 一过性黑矇识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第121章 卒中和短暂性脑缺血发作
- 页码: 第121章“一过性黑矇”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第121章.md`

**目标 / Objective**
识别颈动脉来源 TIA 的眼部表现并及时启动卒中预防路径。

**适用范围 / Scope**
- 突发短暂单眼视力丧失或“窗帘样”视野遮挡的病人

**操作步骤 / Procedure**
1. 询问是否为单眼、突然、短暂的视觉丧失,像窗帘自上或下落下。
2. 将其视作颈动脉循环 TIA 的重要信号。
3. 同步排查颈动脉狭窄和其他血栓来源。
4. 尽快安排影像和颈动脉评估,并按路径启动抗血小板或血管外科转诊。
5. 告知病人该症状可能是偏瘫或失明的前兆。

**注意事项 / Precautions**
- 一过性黑矇是紧急事件,不应仅按眼科小病观察。
- 需与颞动脉炎、视网膜病变和偏头痛鉴别。
- 高度狭窄可能需要颈动脉内膜切除术。

**量化指标 / Metrics**
- 一过性黑矇颈动脉评估率
- 卒中预防治疗启动率
- 高危狭窄转诊率
