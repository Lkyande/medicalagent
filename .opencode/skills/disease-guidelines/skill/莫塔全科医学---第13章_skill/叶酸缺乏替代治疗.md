# Skill: 叶酸缺乏替代治疗

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第13章 贫血
- 页码: 第13章“叶酸缺乏病”“治疗(替代疗法)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第13章.md`

**目标 / Objective**
确认叶酸缺乏并给予规范替代治疗,纠正相关大细胞性贫血风险。

**适用范围 / Scope**
- 营养不良、酗酒、吸收不良、抗癫痫药使用或妊娠相关大细胞性贫血者

**操作步骤 / Procedure**
1. 检测血清叶酸和红细胞叶酸,优先以红细胞叶酸反映储备状态。
2. 寻找高龄、贫困、营养不良、酗酒、吸收不良和妊娠需求增加等病因。
3. 口服叶酸 5 mg/d 连续 4 周补充储备量。
4. 持续治疗约 4 个月,并确认维生素 B12 水平正常或已同步纠正。
5. 强化饮食教育,增加水果和绿色蔬菜摄入。

**注意事项 / Precautions**
- 叶酸不会像 B12 那样在体内大量储存,需要持续摄入。
- 妊娠相关叶酸缺乏若漏诊可致命,应高度警惕。
- 未排除 B12 缺乏前单独补叶酸可能掩盖问题。

**量化指标 / Metrics**
- 大细胞贫血叶酸检测率
- 叶酸缺乏治疗完成率
- 妊娠相关病例及时识别率
