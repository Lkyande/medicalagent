# Skill: 贫血按MCV分型

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第13章 贫血
- 页码: 第13章“贫血的分类”“表13.2 根据平均红细胞体积对贫血进行分类”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第13章.md`

**目标 / Objective**
利用 MCV 将贫血快速分为小细胞性、大细胞性和正常细胞性,缩小病因范围。

**适用范围 / Scope**
- 已确认贫血、需进一步病因鉴别的病人

**操作步骤 / Procedure**
1. 获取全血细胞计数中的 Hb、MCV 及其他红细胞指数。
2. 将 MCV 小于等于 80 fl 归为小细胞性贫血,优先考虑缺铁、地中海贫血和慢性病贫血。
3. 将 MCV 大于 100 fl 归为大细胞性贫血,考虑维生素 B12 缺乏、叶酸缺乏、骨髓增生异常和酒精相关病因。
4. 将 MCV 80 到 100 fl 归为正常细胞性贫血,重点考虑急性失血、慢性炎症、肾衰竭和溶血。
5. 结合病史和进一步检查决定后续铁代谢、维生素水平、肾功能或血红蛋白电泳等检测。

**注意事项 / Precautions**
- 各类贫血之间存在交叉,MCV 分型不是最终诊断。
- 实验室 MCV 上限可略有差异,解释时以本地参考范围为准。
- 先分型再扩展检查,可减少无效化验。

**量化指标 / Metrics**
- 新诊贫血完成 MCV 分型率
- 分型后针对性检查匹配率
- 非目标性检查减少率
