# Skill: 口服铁治疗

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第13章 贫血
- 页码: 第13章“治疗”“疗效”“表13.4 针对成人铁缺乏的饮食建议”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第13章.md`

**目标 / Objective**
通过规范口服补铁和饮食指导纠正缺铁性贫血并补足体内储铁。

**适用范围 / Scope**
- 已明确缺铁性贫血且适合口服治疗的成人和儿童

**操作步骤 / Procedure**
1. 在处理病因的同时启动口服铁剂,成人常用硫酸亚铁每日 1 到 2 片。
2. 指导与橙汁或抗坏血酸同服,避免与牛奶同服以提高吸收。
3. 同时指导增加富含铁和维生素 C 的食物摄入,并限制过量牛奶和加工食品。
4. 连续治疗至少 3 到 6 个月,即使 Hb 恢复也继续补足储铁。
5. 定期复查 Hb 和铁蛋白,以铁蛋白大于 50 μg/L 作为储铁充足的参考。

**注意事项 / Precautions**
- 2 周后症状可开始改善,但完全纠正通常需更久。
- 肌内注射铁剂无明显优势且可致色素沉着,一般不优先选择。
- 输血应尽量避免,除非存在特殊紧急指征。

**量化指标 / Metrics**
- 2 个月 Hb 纠正率
- 3 到 6 个月补铁疗程完成率
- 铁蛋白恢复至目标比例
