# Skill: 缺铁性贫血诊断

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第13章 贫血
- 页码: 第13章“缺铁性贫血”“临床和实验室特征”“血液学检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第13章.md`

**目标 / Objective**
结合血象和铁代谢指标确认缺铁性贫血,并与其他小细胞性贫血鉴别。

**适用范围 / Scope**
- 小细胞低色素性贫血或临床怀疑缺铁者

**操作步骤 / Procedure**
1. 确认血常规提示小细胞低色素性贫血及 MCV、MCH、MCHC 降低。
2. 检测血清铁、血清铁蛋白、转铁蛋白和转铁蛋白饱和度。
3. 以血清铁蛋白降低作为最有用的储铁不足证据,并结合低血清铁和转铁蛋白升高支持诊断。
4. 如需与慢性病贫血鉴别,可增加可溶性转铁蛋白受体检测。
5. 若指标不典型或补铁无效,继续评估地中海贫血、慢性病或骨髓病变。

**注意事项 / Precautions**
- 感染、肝病和恶性肿瘤可使铁蛋白假性升高,不能单看一项结果。
- 缺铁可先于贫血出现,早期同样值得干预。
- 诊断缺铁后仍需继续寻找失铁病因。

**量化指标 / Metrics**
- 小细胞贫血铁蛋白检测率
- 缺铁诊断后病因追查率
- 缺铁与地中海贫血鉴别完成率
