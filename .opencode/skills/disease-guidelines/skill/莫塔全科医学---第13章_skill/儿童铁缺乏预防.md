# Skill: 儿童铁缺乏预防

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第13章 贫血
- 页码: 第13章“儿童的铁缺乏”“预防”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第13章.md`

**目标 / Objective**
针对高危婴幼儿和儿童实施喂养与补充策略,降低缺铁和相关发育影响。

**适用范围 / Scope**
- 早产儿、低出生体重儿、6 到 36 月龄高乳制品低铁饮食儿童及青春期高危女孩

**操作步骤 / Procedure**
1. 识别早产、低出生体重、长期纯母乳且辅食添加迟缓或高牛奶摄入等高危因素。
2. 对早产儿和低出生体重儿补充铁剂和多种维生素。
3. 从 4 到 5 月龄尽早添加含铁辅食,如谷类、蔬菜、鸡蛋和肉类。
4. 鼓励母乳喂养,避免 12 月龄内用牛奶喂养,且 24 月龄前避免过量饮奶。
5. 促进使用强化铁配方和谷物,并随访生长、行为和面色变化。

**注意事项 / Precautions**
- 儿童缺铁常为亚临床,但可先出现认知和精神运动问题。
- 高牛奶低铁饮食是常见可干预危险因素。
- 补铁无效且铁蛋白正常时要考虑血红蛋白病。

**量化指标 / Metrics**
- 高危儿童铁补充覆盖率
- 含铁辅食按月龄添加率
- 儿童缺铁检出率
