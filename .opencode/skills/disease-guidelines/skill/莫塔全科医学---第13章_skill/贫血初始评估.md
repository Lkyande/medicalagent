# Skill: 贫血初始评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第13章 贫血
- 页码: 第13章“临床特征”“征象”“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第13章.md`

**目标 / Objective**
在发现低 Hb 或怀疑贫血时,系统评估症状严重度并收集病因线索。

**适用范围 / Scope**
- 疲劳、心悸、劳力性呼吸困难或血常规提示贫血的成人与儿童

**操作步骤 / Procedure**
1. 询问乏力、头晕、头痛、耳鸣、劳力性呼吸困难、心悸和胸痛。
2. 查找失血、妊娠、饮食不足、胃肠手术、酗酒、素食和药物使用等病因线索。
3. 体检时观察苍白、心动过速、收缩期杂音、口角干裂、黄疸和匙状甲。
4. 对病情较重者评估心力衰竭、间歇性跛行或心肌缺血加重等并发表现。
5. 结合年龄、性别和妊娠状态判断 Hb 是否低于相应阈值。

**注意事项 / Precautions**
- 贫血只是一个标签,必须继续寻找原因。
- 贫血可以无症状,尤其慢性进展时更容易被忽视。
- 心血管基础病病人出现症状突然加重时要想到贫血。

**量化指标 / Metrics**
- 新诊贫血完整病因病史采集率
- 贫血伴心血管症状进一步评估率
- 体征记录完整率
