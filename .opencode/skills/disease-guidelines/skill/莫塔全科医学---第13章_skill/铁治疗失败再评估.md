# Skill: 铁治疗失败再评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第13章 贫血
- 页码: 第13章“铁剂治疗失败”“临床要领”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第13章.md`

**目标 / Objective**
在补铁效果不佳时快速识别依从性、持续失血、吸收不良或误诊等原因。

**适用范围 / Scope**
- 接受补铁后 Hb 或铁蛋白改善不符合预期的病人

**操作步骤 / Procedure**
1. 核对病人是否按推荐剂量、疗程和服药方法规律使用铁剂。
2. 重新评估是否存在持续失血,尤其月经过多或胃肠道出血。
3. 考虑吸收不良,如严重乳糜泻、胃切除术后或并存炎症性肠病。
4. 复核原始诊断,排除地中海贫血、慢性病贫血、铁粒幼细胞性贫血或骨髓浸润病变。
5. 对确有口服失败且存在适应证者,考虑在专科支持下改为静脉补铁。

**注意事项 / Precautions**
- 不要在原因未明时反复盲目增加铁剂剂量。
- 小细胞贫血治疗无效时要想到铁粒幼细胞性贫血。
- 静脉铁可能引起过敏反应和注射部位皮肤变色。

**量化指标 / Metrics**
- 铁治疗失败病因复核率
- 误诊纠正率
- 口服失败后专科转诊率
