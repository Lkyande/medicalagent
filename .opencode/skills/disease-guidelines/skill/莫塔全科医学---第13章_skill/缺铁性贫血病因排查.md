# Skill: 缺铁性贫血病因排查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第13章 贫血
- 页码: 第13章“缺铁性贫血”“病因”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第13章.md`

**目标 / Objective**
在确认缺铁后系统寻找失血、需求增加、吸收不良或摄入不足等根本原因。

**适用范围 / Scope**
- 已诊断缺铁或缺铁性贫血的病人

**操作步骤 / Procedure**
1. 询问月经过多、频繁献血、妊娠、青少年生长期和特殊饮食史。
2. 评估胃肠道失血风险,包括消化性溃疡、肿瘤、痔疮、NSAIDs 使用和反流病史。
3. 询问吸收不良相关线索,如乳糜泻、胃切除术后和慢性肠病。
4. 根据病史和体检决定是否进行直肠指检、胃镜、结肠镜或小肠活检等检查。
5. 对病因不明者持续追踪,直至发现可解释缺铁的来源。

**注意事项 / Precautions**
- 成人缺铁性贫血在没有其他证据前应视为失血性贫血处理。
- 大便潜血试验在怀疑胃肠道失血时价值有限,不能替代内镜评估。
- 地中海贫血与缺铁并存时会干扰判断,必要时进一步做血红蛋白电泳。

**量化指标 / Metrics**
- 缺铁病因查明率
- 胃肠道高风险者内镜完成率
- 月经过多相关妇科评估率
