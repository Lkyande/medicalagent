# Skill: 足踝病史与基础查体

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第57章 足踝痛
- 页码: 第57章“病史采集”“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第57章.md`

**目标 / Objective**
通过疼痛特征、鞋具因素和系统化查体快速缩小足踝疼痛病因范围。

**适用范围 / Scope**
- 门急诊所有足部或踝关节疼痛病人

**操作步骤 / Procedure**
1. 询问疼痛性质、分布、发病方式、与负重关系及肿胀或皮色变化。
2. 追问是否存在银屑病、慢性腹泻、虹膜炎、多关节痛和不合适鞋具史。
3. 对踝扭伤补问是内翻还是外翻、跖屈还是背屈以及是否能立即行走。
4. 检查病人站立、行走、光脚与穿鞋状态,并直接查看鞋底磨损和鞋型。
5. 系统触诊全足和踝部,测试踝关节、距下关节和跗骨间关节活动范围。

**注意事项 / Precautions**
- 大多数足部问题可以通过精细触诊和定位获得重要线索。
- 足痛可能是脊柱关节病或类风湿的局部表现,不能只看足部本身。
- 鞋具是可干预因素,必须在病史里明确记录。

**量化指标 / Metrics**
- 足踝病史完整率
- 鞋具检查记录率
- 疼痛定位准确率
