# Skill: 跟腱断裂汤普森试验识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第57章 足踝痛
- 页码: 第57章“跟腱完全性断裂”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第57章.md`

**目标 / Objective**
及时识别跟腱完全断裂并避免因仍能跖屈而漏诊。

**适用范围 / Scope**
- 足跟后方突发剧痛、跌倒或踮脚困难的病人

**操作步骤 / Procedure**
1. 识别突然剧烈疼痛、摔倒、随后短暂“好转”以及后续肿胀淤血病史。
2. 早期触诊跟腱连续性,寻找 2 至 3 小时内最易发现的缺口。
3. 进行汤普森试验,挤压小腿肌腹观察患侧是否缺乏正常跖屈。
4. 将诊断结果与部分断裂、跟腱周围炎和单纯扭伤进行区分。
5. 一旦怀疑完全断裂,尽快转外科评估 3 周内修复时机。

**注意事项 / Precautions**
- 病人仍可做一定程度跖屈并不能排除完全断裂。
- 血肿可迅速填平间隙,越早检查越容易发现缺口。
- 部分断裂处理路径不同,需谨慎分流。

**量化指标 / Metrics**
- 跟腱断裂早期识别率
- 汤普森试验完成率
- 首诊到外科评估时间
