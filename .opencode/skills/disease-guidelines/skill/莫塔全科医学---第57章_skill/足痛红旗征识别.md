# Skill: 足痛红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第57章 足踝痛
- 页码: 第57章“足痛的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第57章.md`

**目标 / Objective**
及时识别提示感染、缺血、神经病变或骨性病变的高危足踝疼痛表现。

**适用范围 / Scope**
- 所有足部或踝部疼痛病人

**操作步骤 / Procedure**
1. 识别影响睡眠的前足痛,提高对骨样骨瘤、缺血和痛风等病因的警惕。
2. 查找伴骨痛的发热和全身不适,优先排除严重感染。
3. 对儿童远离足跟的局灶压痛主动考虑骨折、异物或骨软骨病变。
4. 询问和检查足部灼热感、感觉异常及糖尿病或神经病背景。
5. 红旗征阳性时尽快安排影像、血管或感染性评估并转专科。

**注意事项 / Precautions**
- 糖尿病相关灼痛可能同时来自神经病变和小血管病变。
- 夜间痛被阿司匹林缓解时要想到骨样骨瘤。
- 不要把所有足痛都归为鞋子不合适或“劳损”。

**量化指标 / Metrics**
- 足痛红旗征记录率
- 高危病例影像检查完成率
- 严重病因漏诊率
