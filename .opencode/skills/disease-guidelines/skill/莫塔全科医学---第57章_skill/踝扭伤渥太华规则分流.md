# Skill: 踝扭伤渥太华规则分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第57章 足踝痛
- 页码: 第57章“足踝损伤进行X线检查的渥太华规则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第57章.md`

**目标 / Objective**
用渥太华规则快速识别踝扭伤后需要拍片排除骨折的病人。

**适用范围 / Scope**
- 踝关节或中足急性扭伤病人

**操作步骤 / Procedure**
1. 对踝痛病人触诊外踝后缘 6 厘米和内踝后缘 6 厘米有无骨压痛。
2. 判断受伤后及就诊时是否都无法完成 4 步负重。
3. 对中足痛病人触诊第五跖骨底和舟骨有无压痛。
4. 满足踝部或足部任一渥太华标准时安排相应 X 线检查。
5. 若规则阴性且临床稳定,按软组织损伤路径处理并安排复评。

**注意事项 / Precautions**
- 儿童韧带真正扭伤较少,更要警惕撕脱骨折。
- 严重前足 Lisfranc 韧带断裂是关键红旗,不能只按普通扭伤处理。
- 渥太华规则是排骨折工具,不排除严重韧带断裂。

**量化指标 / Metrics**
- 渥太华规则应用率
- 不必要足踝 X 线减少率
- 骨折漏诊率
