# Skill: 产后抑郁筛查与分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第101章 产后服务
- 页码: 第101章“产后抑郁障碍”“产后忧郁”“产后适应障碍”“产后抑郁”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第101章.md`

**目标 / Objective**
在产后服务中区分常见短暂情绪波动与需要干预的抑郁障碍。

**适用范围 / Scope**
- 产后数周至数月出现情绪低落、焦虑、哭泣或适应困难的女性

**操作步骤 / Procedure**
1. 询问症状起始时间、持续时间和与分娩的关系。
2. 区分产后忧郁、产后适应障碍和产后抑郁的严重程度与持续时间。
3. 评估睡眠、照护能力、支持系统和自伤风险。
4. 需要时使用爱丁堡产后抑郁量表进行筛查。
5. 根据分层安排支持、心理治疗、精神科评估或紧急处置。

**注意事项 / Precautions**
- 产后情绪问题常被误认为“正常辛苦”,需主动筛查。
- 母婴关系和哺乳问题会相互影响。
- 自伤或精神病性症状需要紧急升级处理。

**量化指标 / Metrics**
- 产后抑郁筛查率
- 中高危病例转介率
- 随访完成率
