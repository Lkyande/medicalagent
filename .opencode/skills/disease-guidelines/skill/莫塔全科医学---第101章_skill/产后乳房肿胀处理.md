# Skill: 产后乳房肿胀处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第101章 产后服务
- 页码: 第101章“乳房肿胀”“给母亲的建议”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第101章.md`

**目标 / Objective**
缓解产后乳房肿胀并防止衔乳失败和继发乳腺炎。

**适用范围 / Scope**
- 产后乳房充盈、坚硬、压痛或婴儿难以衔乳的哺乳母亲

**操作步骤 / Procedure**
1. 解释肿胀与乳汁、血供和组织液同时增加有关。
2. 指导从第 1 日开始按需喂养,尽量先喂空一侧乳房。
3. 喂前挤出少量乳汁软化乳晕帮助婴儿衔乳。
4. 哺乳后按摩肿块并间歇冷敷缓解肿胀。
5. 需要时使用合适胸罩及对乙酰氨基酚或布洛芬镇痛。

**注意事项 / Precautions**
- 正确衔乳和频繁排空是最有效治疗。
- 若乳房长期不排空,需警惕乳腺炎。
- 婴儿睡眠过久时可能需要唤醒哺乳。\n+
**量化指标 / Metrics**
- 乳房肿胀处理教育率
- 衔乳改善率
- 继发乳腺炎发生率
