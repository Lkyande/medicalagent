# Skill: 乳汁分泌不足评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第101章 产后服务
- 页码: 第101章“乳汁分泌不足”“管理”“泌乳刺激”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第101章.md`

**目标 / Objective**
识别真正的乳汁供应不足并优先纠正哺乳技术和供需问题。

**适用范围 / Scope**
- 产后哺乳期担心奶量不足或婴儿体重增长不佳的母婴对

**操作步骤 / Procedure**
1. 评估衔乳姿势、乳汁喷射反射、哺乳频率和乳房排空情况。
2. 识别婴儿体重增加不良、湿尿布少和大便异常等低摄入线索。
3. 排查母体贫血、甲状腺病、多囊卵巢综合征和压力等影响因素。
4. 指导按需、频繁、不受限制哺乳,并在可行时哺乳后排空乳房。
5. 必要时转哺乳专家,并谨慎评估多潘立酮使用风险。

**注意事项 / Precautions**
- 大多数“奶不够”并非真正乳腺不能产奶。
- 困倦的婴儿可能在安静地挨饿,是红旗征。
- 多潘立酮有延长 QT 间期风险。

**量化指标 / Metrics**
- 哺乳技术评估率
- 婴儿体重增长监测率
- 哺乳支持转介率
