# Skill: 产后六周检查清单执行

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第101章 产后服务
- 页码: 第101章“产后六周的看诊”“表101.1”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第101章.md`

**目标 / Objective**
在产后 4 至 6 周系统完成母婴恢复、哺乳、避孕和心理健康评估。

**适用范围 / Scope**
- 产后 4 至 6 周复诊的女性及婴儿

**操作步骤 / Procedure**
1. 询问恶露、会阴或剖宫产伤口愈合以及排便排尿问题。
2. 评估母乳喂养、性交恢复、避孕需求和产后锻炼计划。
3. 必要时进行盆腔检查、宫颈筛查和盆底肌力评估。
4. 使用量表或临床访谈筛查产后抑郁。
5. 对婴儿完成生长、体检、喂养和免疫计划讨论。

**注意事项 / Precautions**
- 这是妇女健康长期管理的重要节点,不应只看伤口恢复。
- 母乳喂养、性功能和心理健康都应主动问而非等待病人提起。
- 产前筛查结果若需后续处理,此时应回顾落实。

**量化指标 / Metrics**
- 产后六周检查清单完成率
- 避孕讨论覆盖率
- 产后抑郁筛查率
