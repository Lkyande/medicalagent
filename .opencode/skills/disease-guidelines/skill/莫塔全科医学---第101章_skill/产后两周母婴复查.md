# Skill: 产后两周母婴复查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第101章 产后服务
- 页码: 第101章“产后两周的看诊”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第101章.md`

**目标 / Objective**
在产后早期同时评估母亲恢复情况和新生儿基本健康状态。

**适用范围 / Scope**
- 分娩后约 2 周的产妇和新生儿

**操作步骤 / Procedure**
1. 记录生产过程和围产期并发症史。
2. 为母亲检查血压、体重、哺乳情况和适应母亲角色状态。
3. 主动筛查产后抑郁早期迹象。
4. 对婴儿测量体重、身长和头围,完成基础体检项目。
5. 给予鼓励、喂养指导和需要时的进一步随访安排。

**注意事项 / Precautions**
- 产后早期教育应在孕期就开始铺垫。
- 母婴问题常相互影响,应联动评估。
- 对看似“安静”的婴儿也要警惕摄入不足。
**量化指标 / Metrics**
- 产后 2 周母婴复查完成率
- 产后抑郁筛查率
- 婴儿生长参数记录率
