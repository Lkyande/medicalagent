# Skill: 骨折怀疑轴向加压检查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第124章 常见的骨折和脱位
- 页码: 第124章“骨折检查方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第124章.md`

**目标 / Objective**
在门诊快速判断软组织损伤与骨折可能性,辅助决定影像学检查。

**适用范围 / Scope**
- 前臂、手部及其他肢体受伤后怀疑骨折但体征不典型的病人

**操作步骤 / Procedure**
1. 询问疼痛、压痛、功能丧失和受伤机制。
2. 用轴向加压法从损伤部位近远端沿骨长轴施压。
3. 观察病人是否能准确定位骨折样疼痛点。
4. 对承重骨骼观察步态和负重情况作为功能性轴向压力判断。
5. 若高度怀疑骨折即使初片阴性,也按骨折夹板固定并复查影像。

**注意事项 / Precautions**
- 骨折可仅表现为局部压痛,无明显畸形。
- 本法是辅助判断,不能替代影像学。
- 疑似骨折的常规原则仍是拍摄合适 X 线。

**量化指标 / Metrics**
- 轴向加压检查记录率
- 可疑骨折影像完成率
- 初片阴性后复查率
