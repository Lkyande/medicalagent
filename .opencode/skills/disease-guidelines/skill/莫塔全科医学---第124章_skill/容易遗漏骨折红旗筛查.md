# Skill: 容易遗漏骨折红旗筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第124章 常见的骨折和脱位
- 页码: 第124章“容易遗漏的骨折:红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第124章.md`

**目标 / Objective**
在轻微外伤或初片阴性情况下警惕容易漏诊的骨折和坏死风险。

**适用范围 / Scope**
- 受伤后症状与影像不完全匹配,或高风险骨折部位损伤病人

**操作步骤 / Procedure**
1. 主动检查手舟骨、儿童肘部、股骨颈、距骨穹窿等高漏诊部位。
2. 对所有关节内骨折和头骨特定部位损伤保持高警惕。
3. 若 X 线正常但临床高度怀疑,先夹板固定 7 至 10 日后复查。
4. 监测神经、血管和缺血坏死并发症风险。
5. 需要时尽早骨科转诊。

**注意事项 / Precautions**
- 某些看似轻微的骨折可导致终生残疾。
- 儿童和老年人影像解读陷阱更多。
- 肱骨头和股骨头缺血坏死属于重要远期并发症。

**量化指标 / Metrics**
- 红旗骨折部位复查率
- 初片阴性但临床固定率
- 漏诊并发症发生率
