# Skill: 下颌脱位手法复位

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第124章 常见的骨折和脱位
- 页码: 第124章“颞下颌关节脱位”“复位方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第124章.md`

**目标 / Objective**
对颞下颌关节脱位实施标准化手法复位,缓解锁颌和疼痛。

**适用范围 / Scope**
- 单侧或双侧下颌脱位,无法闭口或说话的病人

**操作步骤 / Procedure**
1. 让病人坐直并头靠墙,医者戴好防护。
2. 用布或手帕包住拇指放在下磨牙上,其余手指抓住下颌外侧。
3. 拇指向下牵引,同时手指向上旋转下颌骨。
4. 复位成功后重新评估咬合和疼痛。
5. 安排后续避免再次大张口和必要转诊。

**注意事项 / Precautions**
- 操作时注意保护拇指避免复位后被咬伤。
- 明显骨折或无法复位者应停止反复尝试并转诊。
- 病人疼痛和紧张会影响复位成功率。

**量化指标 / Metrics**
- 下颌脱位复位成功率
- 复位后咬合恢复率
- 需专科转诊比例
