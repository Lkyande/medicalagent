# Skill: 创伤性口腔溃疡管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第61章 口舌痛
- 页码: 第61章“创伤性溃疡”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第61章.md`

**目标 / Objective**
识别并去除创伤性因素,促进口腔创伤性溃疡在预期时间内愈合。

**适用范围 / Scope**
- 与咬伤、锋利牙面、义齿、烫伤或刷牙损伤相关的局灶性口腔溃疡

**操作步骤 / Procedure**
1. 明确诱因是否为咬伤、义齿摩擦、锐利牙面、热食灼伤或阿司匹林药疮。
2. 向病人解释病变性质,并优先移除或纠正持续创伤来源。
3. 指导温盐水含漱,必要时给予局部麻醉性漱口液短期缓解疼痛。
4. 说明大多数创伤性溃疡应在约 10 日内愈合。
5. 若去除原因后仍不愈合或持续超过 3 周,改按恶性病变路径评估。

**注意事项 / Precautions**
- 创伤史并不能完全排除恶性病变,持续不愈必须升级处理。
- 医源性创伤如插管、内镜和牙科操作后同样可致溃疡。
- 使用局麻漱口液后需提醒病人避免误咬伤黏膜。

**量化指标 / Metrics**
- 创伤源识别与去除率
- 10 日内愈合率
- 持续病变升级评估率
