# Skill: 复发性阿弗他溃疡处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第61章 口舌痛
- 页码: 第61章“复发性阿弗他溃疡”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第61章.md`

**目标 / Objective**
对典型复发性阿弗他溃疡进行症状控制、诱因排查和升级分流。

**适用范围 / Scope**
- 位于非角化黏膜、直径多为 3 至 5 mm 的典型阿弗他溃疡病人

**操作步骤 / Procedure**
1. 确认溃疡位于颊、唇或口底等非角化黏膜,并具有红晕带和凹陷底部。
2. 追问创伤、压力、新药、过敏及铁、叶酸、维生素 B12 缺乏等诱因。
3. 局部止痛可选利多卡因凝胶或 EMLA 乳膏短时涂抹。
4. 首选 0.1% 曲安奈德口腔糊剂餐后及夜间使用,并评估疗效。
5. 巨大溃疡、频繁复发或 3 周未愈合时,考虑系统病筛查并转诊。

**注意事项 / Precautions**
- 阿弗他溃疡典型发生在非角化黏膜,位于角化区应重新考虑诊断。
- 反复口腔溃疡要记得排查白塞综合征、克罗恩病和乳糜泻。
- 局部类固醇用于疑似疱疹病变前需特别谨慎。

**量化指标 / Metrics**
- 典型阿弗他溃疡识别率
- 诱因筛查完成率
- 3 周未愈合转诊率
