# Skill: 口腔病变红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第61章 口舌痛
- 页码: 第61章“口腔疾病的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第61章.md`

**目标 / Objective**
在基层口腔检查中快速识别需要加速评估或转诊的高危口腔病变。

**适用范围 / Scope**
- 主诉口痛、舌痛、口腔溃疡、口腔斑块或软组织病变的病人

**操作步骤 / Procedure**
1. 先确认是否存在脱水、持续发热或进食饮水受限等全身危险信号。
2. 识别持续 3 周以上的孤立溃疡或软组织病变。
3. 注意口腔溃疡是否合并皮肤病、肠道症状或软腭瘀点。
4. 发现口腔念珠菌病时同步评估糖尿病、HIV 或其他免疫抑制状态。
5. 出现任何红旗征时,安排进一步检查并转口腔科、ENT 或相关专科。

**注意事项 / Precautions**
- 口腔痛常被当作局部小问题,但持续病变需警惕系统病和肿瘤。
- 儿童疱疹性龈口炎最需要警惕的是脱水而非单纯疼痛。
- 舌痛可与心理障碍相关,但必须先排除器质性病变。

**量化指标 / Metrics**
- 口腔红旗征记录率
- 高危病变及时转诊率
- 免疫抑制相关线索识别率
