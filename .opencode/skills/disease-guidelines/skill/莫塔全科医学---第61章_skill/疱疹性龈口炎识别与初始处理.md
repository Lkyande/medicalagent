# Skill: 疱疹性龈口炎识别与初始处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第61章 口舌痛
- 页码: 第61章“疱疹感染”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第61章.md`

**目标 / Objective**
早期识别疱疹性龈口炎,避免错误用药并处理疼痛与脱水风险。

**适用范围 / Scope**
- 伴明显口腔疼痛、龈口炎、疱疹样病变或儿童拒食拒饮的病人

**操作步骤 / Procedure**
1. 根据多形性口腔病变和急性疼痛,考虑原发性单纯疱疹感染。
2. 评估是否已出现饮水减少、尿少和精神差等脱水表现。
3. 起病 48 小时内发现者考虑阿昔洛韦或同类抗病毒药。
4. 同步给予液体支持和止痛性漱口液,帮助维持进食饮水。
5. 病情重、无法口服补液或需静脉补水者,及时转上级治疗。

**注意事项 / Precautions**
- 疑似疱疹病变禁用局部类固醇,否则可能加重并扩散病灶。
- 儿童最常见并发问题是脱水,评估优先级高于局部外观。
- 单侧分布或三叉神经支配区病变还需考虑带状疱疹。

**量化指标 / Metrics**
- 疱疹性龈口炎首诊识别率
- 不当局部类固醇避免率
- 脱水住院分流及时率
