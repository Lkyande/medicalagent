# Skill: 持续口腔病变活检转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第61章 口舌痛
- 页码: 第61章“关键事实和要点”“白斑”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第61章.md`

**目标 / Objective**
对持续不愈的口腔溃疡、白斑或红斑及时启动活检转诊,排除 SCC 等恶性病变。

**适用范围 / Scope**
- 去除明显诱因后仍持续 3 周的口腔溃疡或软组织异常病变

**操作步骤 / Procedure**
1. 复核病变持续时间,确认已超过 3 周或去除明确原因后仍未好转。
2. 视诊并触诊病灶的硬度、边缘硬化、界限和局部淋巴结情况。
3. 对顽固白斑、红斑或孤立性不愈合溃疡提高恶性病变警惕。
4. 向病人说明需行活体组织检查以排除 SCC 或其他肿瘤。
5. 及时转口腔科、口腔颌面外科或 ENT 完成活检和后续管理。

**注意事项 / Precautions**
- 所谓咬伤或轻微创伤可能只是病变被注意到的诱因,不能当作解释终点。
- 红斑的恶性潜能高,不能因面积小而延后处理。
- 伴局部淋巴结肿大或硬结时,更应快速升级。

**量化指标 / Metrics**
- 持续 >3 周病变活检转诊率
- 高危体征记录完整率
- 口腔恶性病变早期发现率
