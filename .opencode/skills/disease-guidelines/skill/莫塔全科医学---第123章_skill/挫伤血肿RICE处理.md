# Skill: 挫伤血肿RICE处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第123章 常见皮肤损伤及异物
- 页码: 第123章“挫伤和血肿”“管理原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第123章.md`

**目标 / Objective**
对挫伤和血肿进行早期保守处理,减轻疼痛和组织损伤范围。

**适用范围 / Scope**
- 四肢、躯干或局部软组织挫伤、青紫和血肿病人

**操作步骤 / Procedure**
1. 向病人解释挫伤和血肿恢复通常需要数日至数周。
2. 在最初 48 小时内实施 RICE:休息、冰敷、压迫和抬高。
3. 使用对乙酰氨基酚镇痛。
4. 避免针吸和按摩,除非特殊部位或明确指征。
5. 72 小时后可考虑局部热敷,并监测是否存在异常出血倾向。

**注意事项 / Precautions**
- 出血量与损伤程度不相称时应考虑出血性疾病。
- 大血肿液化前常表现为发热、发红和硬结,不等于感染。
- 特定部位血肿如耳廓、鼻中隔需额外处理。

**量化指标 / Metrics**
- RICE 指导覆盖率
- 不必要针吸避免率
- 复诊疼痛和肿胀改善率
