# Skill: 撕裂伤修复前评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第123章 常见皮肤损伤及异物
- 页码: 第123章“撕裂伤”“修复原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第123章.md`

**目标 / Objective**
在缝合前识别污染、异物及重要结构损伤,避免漏诊和修复失败。

**适用范围 / Scope**
- 需考虑缝合或进一步外科处理的皮肤撕裂伤病人

**操作步骤 / Procedure**
1. 评估伤口年龄、污染程度和是否存在压碎边缘。
2. 仔细检查神经、肌腱、动脉及周围关节功能损伤。
3. 对玻璃、高能量机械或深部伤口考虑 X 线或超声寻找异物和骨折。
4. 决定是否需要清创、延期缝合、引流或专科转诊。
5. 同步评估破伤风免疫和抗生素适应证。

**注意事项 / Precautions**
- 超过 8 小时的污染陈旧伤口一般不宜直接缝合。
- 伤口外表轻微不代表深层损伤轻微。
- 面部、手和小腿伤口对美容和功能要求更高。

**量化指标 / Metrics**
- 撕裂伤结构损伤排查率
- 异物影像评估率
- 破伤风预防落实率
