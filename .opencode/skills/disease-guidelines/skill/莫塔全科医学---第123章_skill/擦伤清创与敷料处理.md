# Skill: 擦伤清创与敷料处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第123章 常见皮肤损伤及异物
- 页码: 第123章“擦伤”“管理原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第123章.md`

**目标 / Objective**
对污染性擦伤进行充分清创和保护性敷料处理,减少感染和纹身样残留。

**适用范围 / Scope**
- 自行车、摩托车、滑板等事故导致的擦伤病人

**操作步骤 / Procedure**
1. 评估擦伤深度、关节跨越情况和污染程度。
2. 在合适麻醉条件下用无菌生理盐水彻底去除污垢、金属和衣物碎屑。
3. 对深度或关节相关擦伤按烧伤思路进行局部护理。
4. 使用石蜡纱布和无黏性吸水垫等保护性敷料覆盖。
5. 安排随访并固定可能影响深部结构愈合的关节。

**注意事项 / Precautions**
- 沙砾和金属残留可形成永久性“文身”样改变。
- 横跨关节的擦伤需特别关注活动和深层损伤。
- 不充分清创是后续感染和美容差结果的重要原因。

**量化指标 / Metrics**
- 擦伤彻底清创完成率
- 适当敷料使用率
- 污染残留并发症发生率
