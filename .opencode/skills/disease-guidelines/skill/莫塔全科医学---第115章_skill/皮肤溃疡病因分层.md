# Skill: 皮肤溃疡病因分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第115章 皮肤溃疡
- 页码: 第115章“临床方法”“表115.1 皮肤溃疡的类型和原因”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第115章.md`

**目标 / Objective**
根据病史和溃疡特征快速区分静脉性、动脉性、压力性、神经营养性和恶性溃疡。

**适用范围 / Scope**
- 腿、足、骶尾部或其他部位慢性皮肤溃疡病人

**操作步骤 / Procedure**
1. 询问 DVT、动脉缺血、糖尿病、RA、慢性溃疡和相关药物史。
2. 系统记录溃疡部位、形状、大小、深度、边缘、底部和分泌物。
3. 结合周围皮肤颜色、水肿、温度和感觉判断血管性或神经营养性特征。
4. 警惕长期不愈、边缘隆起或瘢痕基础上的恶性溃疡。
5. 根据初步分层决定 ABI、多普勒、活检或专科转诊路径。

**注意事项 / Precautions**
- 多数溃疡是多因素造成,不要只找单一病因。
- 诊断正确性直接决定后续敷料和加压方案是否安全。
- 慢性瘢痕上发展的 Marjolin 溃疡是重要陷阱。

**量化指标 / Metrics**
- 溃疡病因分层记录率
- 关键溃疡特征完整记录率
- 恶性溃疡活检率
