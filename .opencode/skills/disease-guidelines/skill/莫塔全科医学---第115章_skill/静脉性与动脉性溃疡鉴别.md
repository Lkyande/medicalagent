# Skill: 静脉性与动脉性溃疡鉴别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第115章 皮肤溃疡
- 页码: 第115章“表115.3 腿部静脉性和动脉性溃疡典型特征比较”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第115章.md`

**目标 / Objective**
利用临床特征区分静脉性和动脉性溃疡,指导不同治疗方向。

**适用范围 / Scope**
- 下肢慢性溃疡病人

**操作步骤 / Procedure**
1. 观察溃疡位置,内外踝附近更偏静脉性,足趾及足侧受压点更偏动脉性。
2. 比较疼痛程度,动脉性通常更痛且有缺血静息痛或跛行史。
3. 检查水肿、静脉曲张、色素沉着和静脉曲张性皮炎等静脉特征。
4. 检查脉搏、皮温、灌注、皮肤光泽和干燥等动脉缺血特征。
5. 对混合性特征者补充 ABI 和多普勒进一步分类。

**注意事项 / Precautions**
- 足部溃疡更常与动脉病变有关。
- 混合性溃疡不能简单按静脉性加压处理。
- 糖尿病病人常合并神经和缺血双重问题。

**量化指标 / Metrics**
- 动静脉溃疡鉴别记录率
- 混合性溃疡识别率
- 针对性治疗启动率
