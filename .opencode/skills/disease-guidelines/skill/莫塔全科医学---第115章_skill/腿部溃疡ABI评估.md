# Skill: 腿部溃疡ABI评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第115章 皮肤溃疡
- 页码: 第115章“踝臂指数的测量”“表115.4 ABI 的典型水平”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第115章.md`

**目标 / Objective**
在腿部溃疡中评估动脉供血状况并判断加压治疗安全性。

**适用范围 / Scope**
- 需要制定下肢溃疡处理方案的静脉性、动脉性或混合性溃疡病人

**操作步骤 / Procedure**
1. 用手提式多普勒测量踝部和上臂收缩压。
2. 计算 ABI 并按正常、临界、中度 PAD 或重度 PAD 解释。
3. 对 ABI 大于 0.9 者更支持静脉性背景。
4. 对 ABI 0.7~0.8 者只考虑低压加压,低于 0.7 者避免常规加压。
5. 对 ABI 低于 0.4 或高度缺血者立即血管专科转诊。

**注意事项 / Precautions**
- 未排除动脉病前盲目加压可能有害。
- ABI 只是管理决策的一部分,仍需结合临床和多普勒结果。
- 混合性溃疡很常见,需谨慎解释。

**量化指标 / Metrics**
- 腿部溃疡 ABI 测量率
- 加压前供血评估率
- 低 ABI 紧急转诊率
