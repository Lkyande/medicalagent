# Skill: 慢性疼痛生物心理社会教育

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第82章 慢性疼痛
- 页码: 第82章“病人教育”“全面的慢性疼痛管理方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第82章.md`

**目标 / Objective**
帮助病人理解慢性疼痛机制,重建现实治疗预期并提高参与度。

**适用范围 / Scope**
- 慢性非癌痛、反复就诊或对疼痛高度焦虑的病人

**操作步骤 / Procedure**
1. 解释疼痛体验受到生物、心理和社会因素共同影响。
2. 若怀疑中枢敏感化,说明疼痛真实存在但不等于持续组织损伤。
3. 明确告知慢性疼痛通常难以完全治愈,但可以通过管理改善功能。
4. 将治疗目标从单纯“止痛”转向睡眠、活动、情绪和工作功能改善。
5. 与病人共同制定多维治疗计划和随访目标。

**注意事项 / Precautions**
- 教育本身就是治疗的重要组成部分。
- 过度聚焦药物会削弱病人对自我管理的投入。
- 需要避免让病人觉得“疼痛只是心理作用”。

**量化指标 / Metrics**
- 慢性疼痛病人的教育记录率
- 功能性目标设定率
- 病人对疼痛机制理解提升率
