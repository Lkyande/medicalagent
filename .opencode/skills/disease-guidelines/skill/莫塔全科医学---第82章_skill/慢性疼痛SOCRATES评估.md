# Skill: 慢性疼痛SOCRATES评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第82章 慢性疼痛
- 页码: 第82章“对疼痛的评估和测量”“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第82章.md`

**目标 / Objective**
用结构化病史全面描述慢性疼痛并支持病因判断。

**适用范围 / Scope**
- 持续超过 3 个月或超过预期恢复期的疼痛病人

**操作步骤 / Procedure**
1. 使用 SOCRATES 依次询问部位、起止、性质、放射、伴随症状、时间、缓解/加重因素和严重程度。
2. 记录疼痛是否与动作、姿势、夜间或情绪有关。
3. 结合人体图标注疼痛范围和放射分布。
4. 判断疼痛是否更像伤害性、神经性或中枢敏感性疼痛。
5. 在每次复诊中重复可比性记录,用于观察变化趋势。

**注意事项 / Precautions**
- 疼痛是主观体验,需要接受和尊重病人描述。
- 多种疼痛机制可以并存。
- 新的病理变化要持续重新评估,不能长期按旧诊断套用。

**量化指标 / Metrics**
- 慢性疼痛 SOCRATES 记录完整率
- 疼痛机制初步分类率
- 随访可比性记录率
