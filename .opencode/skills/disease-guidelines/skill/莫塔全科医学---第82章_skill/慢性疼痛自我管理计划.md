# Skill: 慢性疼痛自我管理计划

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第82章 慢性疼痛
- 页码: 第82章“积极的自我管理”“多维度的方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第82章.md`

**目标 / Objective**
以功能改善为核心为慢性疼痛病人建立多维度自我管理计划。

**适用范围 / Scope**
- 慢性非癌痛病人,尤其存在活动受限、睡眠差或情绪问题者

**操作步骤 / Procedure**
1. 与病人共同确认最受疼痛影响的生活领域,如睡眠、活动、工作和社交。
2. 将目标分解为身体活动、情绪调节、睡眠改善和营养优化等维度。
3. 使用动机访谈帮助病人确定可执行的小目标。
4. 将多学科支持纳入计划,如物理治疗、心理治疗和作业治疗。
5. 定期复盘功能改善而不仅是疼痛分数变化。

**注意事项 / Precautions**
- 最佳实践支持在团队支持下的自我管理。
- 功能提升本身可反向降低疼痛强度。
- 自我管理计划需要随着病情和生活情境持续调整。

**量化指标 / Metrics**
- 慢性疼痛病人的书面计划建立率
- 功能目标达成率
- 多学科协作介入率
