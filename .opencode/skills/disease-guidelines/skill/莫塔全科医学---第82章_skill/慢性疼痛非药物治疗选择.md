# Skill: 慢性疼痛非药物治疗选择

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第82章 慢性疼痛
- 页码: 第82章“非药物疗法”“表82.3 慢性非癌性疼痛的非药物疗法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第82章.md`

**目标 / Objective**
优先选择证据支持的非药物疗法来管理慢性非癌痛。

**适用范围 / Scope**
- 慢性非癌性疼痛病人,尤其不适合长期药物治疗者

**操作步骤 / Procedure**
1. 依据病人疼痛类型和功能障碍选择物理、心理或综合干预。
2. 优先考虑渐进有氧运动、物理治疗、水疗、瑜伽或太极等方案。
3. 对情绪和灾难化思维明显者加入 ACT、注意力转移或生物反馈等心理干预。
4. 评估可及性、费用和病人偏好后制定组合方案。
5. 随访观察活动能力、睡眠和伤残变化而非单一疼痛强度。

**注意事项 / Precautions**
- 长期药物治疗在慢性疼痛中的角色已减弱。
- 非药物方案需要循序渐进,避免一次性要求过高。
- 早期解释为什么重点放在功能而非完全止痛,有助于提高接受度。

**量化指标 / Metrics**
- 非药物治疗推荐率
- 实际参与率
- 功能障碍改善率
