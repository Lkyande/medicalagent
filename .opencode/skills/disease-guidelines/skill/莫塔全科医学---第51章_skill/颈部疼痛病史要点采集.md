# Skill: 颈部疼痛病史要点采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第51章 颈部疼痛
- 页码: 第51章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第51章.md`

**目标 / Objective**
通过结构化问诊区分机械性颈痛、神经根痛和严重继发性病因。

**适用范围 / Scope**
- 门急诊所有颈痛、颈僵或斜颈病人

**操作步骤 / Procedure**
1. 询问疼痛的具体部位、起病方式、放射方向和昼夜节律。
2. 追问仰头、倒车、活动及睡眠是否诱发或加重症状。
3. 核查头颈部外伤史,包括头顶撞击和车辆相关损伤。
4. 询问头痛、头晕、手臂疼痛、麻木、无力或笨拙等神经症状。
5. 询问双侧肩颈痛、痛醒和活动相关性,为功能障碍、炎症或脊髓病分层。

**注意事项 / Precautions**
- 倒车困难和仰头痛有助于发现活动受限型颈椎病。
- 手臂麻木无力提示必须补做神经系统查体,不能只按肌肉劳损处理。
- 白天夜间持续痛比单纯晨起僵硬更提示严重病变。

**量化指标 / Metrics**
- 颈痛标准病史完整率
- 神经症状记录率
- 首诊病因分层准确率
