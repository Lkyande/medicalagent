# Skill: 颈椎定位触诊与活动度检查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第51章 颈部疼痛
- 页码: 第51章“身体检查”“触诊”“活动度检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第51章.md`

**目标 / Objective**
通过标准化定位触诊和活动评估重现症状并初步定位受累节段。

**适用范围 / Scope**
- 无明显急性不稳定征象的颈部疼痛病人

**操作步骤 / Procedure**
1. 先坐位观察肩高、颈部轮廓、侧屈姿势和头部活动意愿。
2. 俯卧位前额置于手上,从 C2 到 C7 依次定位棘突,区分 C6 与 C7。
3. 用拇指沿后正中线和两侧关节柱系统按压,寻找疼痛、僵硬和肌痉挛区。
4. 将触诊范围扩展到前颈部,排查淋巴结炎、甲状腺病变和其他非脊柱病因。
5. 测试前屈、背伸、侧屈和旋转,必要时在末端轻加压力并记录疼痛方向图。

**注意事项 / Precautions**
- 触诊应轻柔系统,越重压反而越不利于辨别真实压痛。
- Lhermitte 征阳性提示颈髓受累,不能继续按普通机械痛处理。
- 有明显创伤或不稳定风险时不做诱发性末端加压。

**量化指标 / Metrics**
- 颈椎定位触诊完成率
- 运动方向图记录率
- 触诊与最终节段判断一致率
