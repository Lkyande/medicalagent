# Skill: 颈神经根病基础神经查体

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第51章 颈部疼痛
- 页码: 第51章“神经系统检查”“颈神经根综合征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第51章.md`

**目标 / Objective**
识别 C5 至 T1 神经根受压的典型感觉、肌力和反射异常。

**适用范围 / Scope**
- 颈痛伴手臂放射痛、麻木、无力或感觉异常的病人

**操作步骤 / Procedure**
1. 明确疼痛和感觉异常是否沿单一神经根皮节分布。
2. 检查局部感觉减退区域,并与 C5 至 T1 皮节图对应。
3. 分别测试三角肌、肱二头肌、肱三头肌、拇长伸肌和骨间肌肌力。
4. 检查肱二头肌、肱桡肌和肱三头肌反射是否减弱。
5. 若出现多个神经根异常或伴步态、双下肢体征改变,立即升级评估脊髓病。

**注意事项 / Precautions**
- 一个椎间盘通常对应一根神经根,多根受累要警惕更严重病因。
- C5 损伤的外旋无力可能与肩部疾病混淆,需结合肩部查体。
- 脊髓病表现优先级高于单纯根性痛。

**量化指标 / Metrics**
- 神经根查体完成率
- 节段定位准确率
- 脊髓病早期识别率
