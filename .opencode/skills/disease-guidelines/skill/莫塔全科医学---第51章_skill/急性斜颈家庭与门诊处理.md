# Skill: 急性斜颈家庭与门诊处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第51章 颈部疼痛
- 页码: 第51章“急性斜颈”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第51章.md`

**目标 / Objective**
对典型急性斜颈进行以早期活动和舒缓治疗为核心的门诊处理。

**适用范围 / Scope**
- 无红旗征的急性疼痛性斜颈病人

**操作步骤 / Procedure**
1. 确认病程短、侧向倾斜伴肌痉挛且无明显神经缺陷或感染征象。
2. 向病人解释本病通常自限,多数在 48 小时至 1 周内缓解。
3. 鼓励热敷、热按摩和尽早恢复轻柔活动,避免长时间固定不动。
4. 明确告知不要常规使用颈托,以免延缓恢复。
5. 必要时转诊有经验治疗师进行颈部运动治疗或肌肉能量疗法,并安排复诊评估。

**注意事项 / Precautions**
- 儿童或青少年伴发热时要优先排除脑膜炎和咽部感染。
- 手法治疗应由有经验者实施,避免不当操作带来血管或神经风险。
- 持续不缓解或反复发作需重新评估椎间盘病变和其他病因。

**量化指标 / Metrics**
- 急性斜颈自限性恢复率
- 不必要颈托使用率
- 1 周内复诊改善率
