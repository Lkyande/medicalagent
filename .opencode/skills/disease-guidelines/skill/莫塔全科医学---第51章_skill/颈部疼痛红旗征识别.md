# Skill: 颈部疼痛红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第51章 颈部疼痛
- 页码: 第51章“颈部疼痛的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第51章.md`

**目标 / Objective**
快速识别提示骨折、感染、肿瘤、神经根病或脊髓病的高危颈痛表现。

**适用范围 / Scope**
- 所有急性或持续性颈部疼痛病人

**操作步骤 / Procedure**
1. 追问是否存在重大创伤史或近期挥鞭样损伤背景。
2. 识别年龄大于 50 岁、昼夜持续痛、癌症史和无法解释的体重减轻。
3. 询问是否发热超过 38 摄氏度或伴明显全身不适。
4. 查找颈前疼痛、神经缺陷、手臂神经根痛和脊髓病征象。
5. 红旗征阳性时立即安排影像和神经系统评估,必要时紧急转诊。

**注意事项 / Precautions**
- 颈前痛要联想到内脏牵涉痛、甲状腺炎或咽后感染。
- 多神经根受累不符合单纯单节段椎间盘病变,要警惕肿瘤或广泛压迫。
- 唐氏综合征和类风湿关节炎病人要额外警惕颈椎不稳。

**量化指标 / Metrics**
- 颈痛红旗征记录率
- 红旗征阳性病例影像完成率
- 严重病因漏诊率
