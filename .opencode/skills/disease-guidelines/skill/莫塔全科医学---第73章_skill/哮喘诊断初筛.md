# Skill: 哮喘诊断初筛

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第73章 哮喘
- 页码: 第73章“临床特征”“身体检查”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第73章.md`

**目标 / Objective**
识别具有可变性气流受限特征的哮喘并启动客观检测。

**适用范围 / Scope**
- 出现喘息、咳嗽、胸闷或呼吸困难的儿童和成人病人

**操作步骤 / Procedure**
1. 询问症状是否反复发作、夜间或清晨加重,以及运动后是否诱发。
2. 记录过敏史、家族哮喘史和 SABA 吸入后症状是否快速缓解。
3. 检查是否有弥漫性哮鸣音,但若查体正常不能排除哮喘。
4. 安排肺功能或 PEFR 前后支气管舒张试验,确认可逆性气流受限。
5. 若幼儿无法完成肺功能,结合可变呼吸道症状作临床判断并随访验证。

**注意事项 / Precautions**
- 功能测定优于单纯主观感觉判断。
- 呼吸困难但听不到哮鸣音是严重信号。
- 有哮鸣音并不一定等于哮喘,需结合可逆性和病程。

**量化指标 / Metrics**
- 可疑哮喘病人的肺功能或 PEFR 检测率
- 夜间症状与运动诱发记录率
- 初诊后诊断确认率
