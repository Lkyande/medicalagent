# Skill: 定量吸入器闭口式指导

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第73章 哮喘
- 页码: 第73章“正确使用哮喘定量吸入器”“闭口式技术”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第73章.md`

**目标 / Objective**
提高病人对 MDI 的正确使用率,增加药物肺部沉积。

**适用范围 / Scope**
- 使用定量吸入器的哮喘或其他吸入治疗病人

**操作步骤 / Procedure**
1. 取下盖子并摇匀吸入器,保持直立。
2. 将吸嘴置于牙齿间并闭口包住,先缓慢呼气到舒适水平。
3. 轻度后仰头部,开始缓慢吸气的同时按压 1 次。
4. 持续吸入 3 至 5 秒,随后屏气约 10 秒再慢慢呼出。
5. 需要重复时恢复正常呼吸后再进行下一喷,并在复诊时复核技术。

**注意事项 / Precautions**
- 至少三分之一使用者技术不正确。
- 高达 90% 的药物可因错误使用而滞留口腔。
- 若技术始终差,可考虑自动吸入器或储雾器。

**量化指标 / Metrics**
- 吸入器技术示教完成率
- 复诊技术复核率
- 因技术错误导致控制不良的识别率
