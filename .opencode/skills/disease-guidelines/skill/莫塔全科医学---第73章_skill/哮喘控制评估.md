# Skill: 哮喘控制评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第73章 哮喘
- 页码: 第73章“评估哮喘控制时的提问”“哮喘控制的三步计划”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第73章.md`

**目标 / Objective**
标准化评估近期哮喘控制情况和未来严重发作风险。

**适用范围 / Scope**
- 已确诊或疑似哮喘、需要复诊调整治疗的病人

**操作步骤 / Procedure**
1. 回顾前 4 周是否有日间症状、夜间醒来、活动受限和缓解药物使用增加。
2. 询问病人自觉控制水平,并记录是否发生恶化或急诊就诊。
3. 识别危险因素,如既往重症发作、住院史、频繁使用 SABA 和依从性差。
4. 在升级治疗前检查吸入技术、依从性和装置是否适合。
5. 根据控制水平决定维持、升级或降级治疗,并安排下一次随访。

**注意事项 / Precautions**
- 频繁使用 SABA 提示控制不良,而非“药物够用”。
- 调整药物前必须排除吸入器使用错误。
- 夜间症状和近期情绪问题可提示严重发作风险。

**量化指标 / Metrics**
- 哮喘复诊控制评估完成率
- 吸入技术复核率
- 高风险病人个体化随访率
