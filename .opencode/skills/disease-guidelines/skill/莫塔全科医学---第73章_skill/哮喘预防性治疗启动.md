# Skill: 哮喘预防性治疗启动

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第73章 哮喘
- 页码: 第73章“预防性治疗的适应证”“启动治疗”“吸入性类固醇皮质激素”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第73章.md`

**目标 / Objective**
为需要长期控制的哮喘病人及时启动 ICS 为核心的预防治疗。

**适用范围 / Scope**
- 使用 SABA 频繁、夜间症状存在或反复发作的哮喘病人

**操作步骤 / Procedure**
1. 根据适应证判断是否需要预防治疗,如每周症状超过 2 次、夜间症状或发作频繁。
2. 以低至中等剂量 ICS 起始,而不是直接高剂量或单用 LABA。
3. 向病人解释“预防药”和“缓解药”的不同角色。
4. 教会病人每日规律使用及吸入后漱口等减少副作用方法。
5. 4 至 6 周后复评控制情况,必要时逐步上调或后续联合治疗。

**注意事项 / Precautions**
- LABA 不能作为哮喘单药治疗。
- 大多数成人和大龄青少年应长期使用 ICS。
- 目标是达到控制后降至最低有效剂量。

**量化指标 / Metrics**
- 符合适应证病人的 ICS 启动率
- 用药教育完成率
- 启动后 6 周复诊率
