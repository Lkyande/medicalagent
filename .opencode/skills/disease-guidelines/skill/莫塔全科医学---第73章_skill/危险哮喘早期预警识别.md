# Skill: 危险哮喘早期预警识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第73章 哮喘
- 页码: 第73章“危险的哮喘”“高危病人”“早期预警信号”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第73章.md`

**目标 / Objective**
在严重发作前识别高风险病人和恶化信号,提前升级处理。

**适用范围 / Scope**
- 既往严重发作史或近期控制不良的哮喘病人

**操作步骤 / Procedure**
1. 识别既往 ICU 住院、过去 12 个月急诊就诊、长期口服激素等高危背景。
2. 询问近期是否尽管用足量药物仍持续恶化。
3. 关注咳嗽胸闷加重、夜间睡眠被打断、缓解药维持不足 2 小时和 PEFR 降低。
4. 一旦出现早期危险信号,立即复核用药并安排紧急评估。
5. 为高危病人制定书面行动计划并强化求助阈值。

**注意事项 / Precautions**
- 严重发作可突然发生,轻度哮喘病人也可能出现。
- 对两种吸入药反应差是危险信号。
- 情绪问题和随意用药会增加重症风险。

**量化指标 / Metrics**
- 高危哮喘病人的行动计划覆盖率
- 危险信号识别后的当日评估率
- 严重发作前预警命中率
