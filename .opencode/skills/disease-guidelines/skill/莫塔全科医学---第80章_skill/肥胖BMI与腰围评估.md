# Skill: 肥胖BMI与腰围评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第80章 肥胖
- 页码: 第80章“对肥胖的测量”“表80.2 成人肥胖分类”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第80章.md`

**目标 / Objective**
用 BMI 和腰围对肥胖程度及相关心血管风险进行标准化评估。

**适用范围 / Scope**
- 成人体重管理、慢病随访或健康体检场景

**操作步骤 / Procedure**
1. 测量体重和身高并计算 BMI。
2. 按 WHO 分类判断超重、I 级、II 级或 III 级肥胖。
3. 在肋缘与髂嵴中点测量腰围,评估中心型肥胖风险。
4. 结合 BMI、腰围和相关共病判断是否需强化干预、药物或手术评估。
5. 对儿童或高肌肉量成人避免机械套用 BMI 结果。

**注意事项 / Precautions**
- BMI 简便但粗略,腰围能补充评估腹型肥胖风险。
- 运动员和老年人解释 BMI 时要结合体成分和整体情况。
- 肥胖相关死亡风险更多来自并发症而非单一体重数字。

**量化指标 / Metrics**
- BMI 记录率
- 腰围记录率
- 中心型肥胖识别率
