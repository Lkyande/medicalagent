# Skill: 肥胖行为改变动机访谈

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第80章 肥胖
- 页码: 第80章“鼓励行为改变”“行为改变的阶段”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第80章.md`

**目标 / Objective**
通过动机访谈提升病人的内在减重动机和长期坚持度。

**适用范围 / Scope**
- 对减重犹豫、反复失败或处于不同改变阶段的肥胖病人

**操作步骤 / Procedure**
1. 判断病人处于意识前期、准备期或维持期等行为改变阶段。
2. 探索其个人价值、健康顾虑和过去减重经历。
3. 帮助病人识别饮食、活动、自我破坏和负性思维障碍。
4. 引导把外在要求转化为内在理由,形成现实可执行的下一步行动。
5. 通过复诊强化成功经验并调整计划。

**注意事项 / Precautions**
- 可持续行为改变往往来自内在动机而非外部命令。
- 反复失败不等于“不配合”,需要重新理解障碍。
- 动机访谈适合与营养和运动干预并行使用。

**量化指标 / Metrics**
- 动机阶段记录率
- 行为障碍识别率
- 3 个月持续执行率
