# Skill: 肥胖5As管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第80章 肥胖
- 页码: 第80章“表80.3 肥胖管理的 5As 模型”“在看诊过程中向病人提出肥胖问题”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第80章.md`

**目标 / Objective**
用 5As 框架开展敏感、系统且可持续的肥胖管理对话。

**适用范围 / Scope**
- 超重或肥胖且愿意讨论体重、或体重与主诉相关的病人

**操作步骤 / Procedure**
1. 谨慎提问病人对体重问题、顾虑和改变意愿的看法。
2. 评估 BMI、腰围、血压、血糖、血脂及睡眠呼吸暂停、抑郁等并发症。
3. 根据病人知识水平和动机给出个体化 SMART 建议。
4. 协助建立生活方式减重计划,并协调营养、运动和心理支持。
5. 安排持续复查和监测,必要时转诊专科或手术团队。

**注意事项 / Precautions**
- 讨论体重时要避免偏见和体重污名。
- 肥胖背后可能有创伤、进食障碍或情绪问题。
- 目标不只是减重数字,还包括健康和功能改善。

**量化指标 / Metrics**
- 肥胖病人的 5As 记录率
- SMART 目标设定率
- 连续随访完成率
