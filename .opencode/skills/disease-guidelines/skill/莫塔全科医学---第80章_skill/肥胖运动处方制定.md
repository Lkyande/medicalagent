# Skill: 肥胖运动处方制定

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第80章 肥胖
- 页码: 第80章“锻炼”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第80章.md`

**目标 / Objective**
制定兼顾减重与健康获益的个体化身体活动计划。

**适用范围 / Scope**
- 需要减重或改善肥胖相关健康风险的成人病人

**操作步骤 / Procedure**
1. 评估病人喜好、经济负担、时间安排和功能限制。
2. 设定每周至少 150 分钟中等强度活动为基本目标。
3. 说明单靠运动减重有限,需与饮食控制同步进行。
4. 优先选择可持续的日常活动,如步行、团体项目或上下班步行。
5. 随访时同时追踪步数、功能改善和体重趋势。

**注意事项 / Precautions**
- 运动对健康获益可能早于明显减重发生。
- 不现实的高强度计划容易导致放弃。
- 病人可能更容易坚持自己喜欢且负担得起的活动。

**量化指标 / Metrics**
- 运动处方记录率
- 每周活动目标达成率
- 3 个月功能改善率
