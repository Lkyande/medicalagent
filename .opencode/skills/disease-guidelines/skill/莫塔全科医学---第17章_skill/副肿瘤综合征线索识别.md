# Skill: 副肿瘤综合征线索识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第17章 恶性疾病
- 页码: 第17章“副肿瘤效应”“表17.2 副肿瘤综合征及其相关肿瘤”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第17章.md`

**目标 / Objective**
通过远隔效应识别潜在恶性肿瘤,特别是在原发症状尚不明显时。

**适用范围 / Scope**
- 高钙血症、异常发热、神经病变、凝血障碍、皮肌炎或不明贫血病人

**操作步骤 / Procedure**
1. 对内分泌、皮肤、神经、血液和代谢异常进行系统归类。
2. 将高钙血症、发热、神经症状、凝血障碍和血栓性静脉炎与常见相关肿瘤对应。
3. 对看似孤立的副肿瘤表现补问体重减轻、咳嗽、腹部症状和局部肿块。
4. 结合基础化验和影像选择最可能的原发部位进行筛查。
5. 对可能致命的代谢或凝血异常优先处理并加速转诊。

**注意事项 / Precautions**
- 副肿瘤综合征可能是癌症最早线索。
- 低钠或高钙等代谢效应本身也可危及生命。
- 仅纠正实验室异常而不追查肿瘤会延误诊断。

**量化指标 / Metrics**
- 副肿瘤表现病因追查率
- 通过副肿瘤线索发现恶性肿瘤比例
- 危及生命代谢异常处理时效
