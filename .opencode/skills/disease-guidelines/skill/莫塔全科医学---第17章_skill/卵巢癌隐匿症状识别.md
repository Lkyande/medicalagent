# Skill: 卵巢癌隐匿症状识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第17章 恶性疾病
- 页码: 第17章“卵巢癌”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第17章.md`

**目标 / Objective**
识别卵巢癌的隐匿腹盆腔症状并及时进入影像与肿瘤标志物评估路径。

**适用范围 / Scope**
- 40 岁以上女性腹胀、腹部不适、食欲下降、尿频或体重减轻者

**操作步骤 / Procedure**
1. 询问腹胀、腹部不适、食量减少、尿频、腹泻、恶心呕吐和异常子宫出血。
2. 体检时注意腹部膨隆、腹水或盆腹部肿块线索。
3. 对持续非特异腹盆腔症状而难以解释者提高卵巢癌警觉。
4. 安排盆腔超声和血清 CA125 作为支持性检查。
5. 对可疑结果及时转妇科肿瘤专科。

**注意事项 / Precautions**
- 卵巢癌在转移前常无明显症状,不能因症状轻微而延后评估。
- 40 岁以下较少见,但年龄不能完全排除诊断。
- 单一 CA125 不足以独立确诊,需结合影像和临床。

**量化指标 / Metrics**
- 持续腹胀女性盆腔超声完成率
- 卵巢癌高风险症状识别率
- 可疑病例专科转诊时效
