# Skill: 恶性肿瘤全身症状筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第17章 恶性疾病
- 页码: 第17章“全身的症状”“未分化的一般症状”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第17章.md`

**目标 / Objective**
在未分化全身不适病人中识别提示潜在恶性肿瘤的全身症状组合。

**适用范围 / Scope**
- 持续疲劳、厌食、体重减轻、发热或异常口渴嗜睡病人

**操作步骤 / Procedure**
1. 询问劳累、疲劳、食欲缺乏、恶心、体重减轻和不明原因发热。
2. 对口渴、嗜睡等症状联想到高钙血症或低钠血症等副肿瘤效应。
3. 结合症状持续时间、进展性和常规治疗无效情况评估恶性可能。
4. 同步采集职业暴露史、家族癌症史和相关器官症状。
5. 若存在进行性全身症状或实验室异常,启动针对性影像和专科转诊路径。

**注意事项 / Precautions**
- “沉默”恶性肿瘤常以一般不适起病。
- 单一全身症状意义有限,但组合出现时应提高警惕。
- 对长期无法解释的恶病质样表现不要简单归因于心理因素。

**量化指标 / Metrics**
- 未分化全身症状病人癌症风险评估率
- 持续体重减轻病例进一步检查率
- 早期恶性肿瘤检出率
