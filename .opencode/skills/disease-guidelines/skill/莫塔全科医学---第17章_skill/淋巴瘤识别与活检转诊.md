# Skill: 淋巴瘤识别与活检转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第17章 恶性疾病
- 页码: 第17章“霍奇金淋巴瘤”“非霍奇金淋巴瘤”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第17章.md`

**目标 / Objective**
识别持续无痛性淋巴结病和 B 症状,及时进入淋巴结活检与分期评估流程。

**适用范围 / Scope**
- 无痛性淋巴结肿大、发热盗汗、体重减轻或瘙痒病人

**操作步骤 / Procedure**
1. 评估淋巴结是否无痛、橡胶样、持续存在,并记录颈部、腋窝和腹股沟分布。
2. 询问发热、夜间盗汗、体重减轻、瘙痒和酒精诱发淋巴结痛等 B 症状或线索。
3. 检查是否伴肝大、脾大或其他结外病灶。
4. 对可疑病例安排全血细胞计数和胸片/CT 作为初步分期支持。
5. 核心步骤是尽快转诊进行淋巴结活组织检查确诊。

**注意事项 / Precautions**
- 霍奇金和非霍奇金淋巴瘤都以无痛性淋巴结肿大为常见表现。
- 仅凭影像不能代替组织学诊断。
- 长期“观察”等待会显著延误可治愈肿瘤的诊断。

**量化指标 / Metrics**
- 持续淋巴结肿大病例活检转诊率
- B 症状记录率
- 淋巴瘤确诊前延迟时间
