# Skill: 儿童癌症红旗识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第17章 恶性疾病
- 页码: 第17章“儿童的癌症”“儿童期癌症的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第17章.md`

**目标 / Objective**
在基层快速识别提示儿童恶性肿瘤的红旗症状并及时转诊。

**适用范围 / Scope**
- 15 岁以下出现持续全身症状、肿块、异常出血或家长强烈担忧的儿童

**操作步骤 / Procedure**
1. 主动询问持续疲惫、苍白、体重减轻、反复发热和晨起头痛等红旗症状。
2. 查找肿物、颈部或腹部肿块、不寻常瘀斑出血、白眼和骨痛肿胀。
3. 认真记录家长关于“孩子不太对劲”的具体观察,即使体检暂未见异常。
4. 对持续呕吐、进行性骨痛或明显肿块者安排进一步检查和专科转诊。
5. 在转诊前完成基础评估并向家长明确说明警惕原因。

**注意事项 / Precautions**
- 儿童癌症可只有模糊而非特异的表现。
- 忽视家长反复提出的异常观察会延误诊断。
- 晨起头痛和呕吐要警惕颅内肿瘤。

**量化指标 / Metrics**
- 儿童癌症红旗记录率
- 高危儿童转诊时效
- 首诊漏诊后再就诊率
