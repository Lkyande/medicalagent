# Skill: 肾细胞癌识别与转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第17章 恶性疾病
- 页码: 第17章“肾细胞癌”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第17章.md`

**目标 / Objective**
识别肾细胞癌的局部、全身和转移表现,及时安排影像确诊和专科处理。

**适用范围 / Scope**
- 血尿、腰痛、腰部包块、不明发热或左侧精索静脉曲张病人

**操作步骤 / Procedure**
1. 询问血尿、腰痛、不适、发热和体重变化等症状。
2. 体检时寻找可扪及肾包块、贫血体征、左锁骨上淋巴结和左侧精索静脉曲张。
3. 对伴高血压、呼吸道症状、骨痛或神经症状者考虑转移表现。
4. 初步尿检查隐血,并尽快安排 CT 或 MRI 影像确诊。
5. 一旦怀疑,转泌尿外科进一步评估根治性治疗可能性。

**注意事项 / Precautions**
- 经典三联征不是每个病人都会完整出现。
- 隐血阳性可作为线索,但阴性不能完全排除。
- 转移表现可能先于局部症状出现。

**量化指标 / Metrics**
- 血尿伴腰痛病人完成影像率
- 肾癌疑似病例转诊时效
- 转移性表现首诊识别率
