# Skill: 急性白血病识别与初筛

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第17章 恶性疾病
- 页码: 第17章“急性白血病”“症状”“征象”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第17章.md`

**目标 / Objective**
在不适、苍白、感染或出血倾向病人中及时识别急性白血病并完成初步血液学筛查。

**适用范围 / Scope**
- 儿童或成人出现不适、贫血、反复感染、骨痛、瘀点或口腔病变者

**操作步骤 / Procedure**
1. 询问不适、贫血症状、反复喉痛或胸部感染、鼻出血牙龈出血以及骨关节痛。
2. 体检查苍白、瘀点、瘀斑、牙龈肥大、口腔炎、肝脾大和淋巴结肿大。
3. 对儿童显著骨痛或成人明显口腔病变时提高急性白血病警惕。
4. 立即安排全血细胞计数和外周血涂片,寻找全血细胞减少和原始细胞。
5. 一旦怀疑,紧急转血液科行骨髓、PCR 和细胞遗传学检查。

**注意事项 / Precautions**
- 未治疗急性白血病进展迅速,延误可致命。
- 急性髓系白血病可出现牙龈肥大等浸润表现。
- 儿童骨痛容易误认为生长痛或骨科问题。

**量化指标 / Metrics**
- 白血病警示症状病例 CBC 完成率
- 疑似急性白血病转诊时效
- 首诊发现外周原始细胞比例
