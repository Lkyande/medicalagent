# Skill: 多发性骨髓瘤识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第17章 恶性疾病
- 页码: 第17章“多发性骨髓瘤”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第17章.md`

**目标 / Objective**
在老年病人中识别多发性骨髓瘤的典型三联征和关键实验室检查路径。

**适用范围 / Scope**
- 老年人不明原因背痛、贫血、反复感染、口渴或肾功能异常者

**操作步骤 / Procedure**
1. 识别贫血、背痛和 ESR 增快这一高价值提示组合。
2. 询问骨痛、病理性骨折、反复胸部感染、厌食、体重减轻和口渴加重。
3. 检查骨压痛、出血倾向和肾功能受损表现。
4. 安排血清蛋白电泳、免疫固定电泳、尿本周蛋白和骨骼影像检查。
5. 对发现副蛋白、溶骨性病变或多系统受累者转血液科确诊与治疗。

**注意事项 / Precautions**
- 多发性骨髓瘤可表现为普通老年背痛,需主动识别系统性线索。
- 高钙和肾衰竭是重要并发问题。
- 单克隆球蛋白病并不等同于骨髓瘤,需结合临床表现鉴别。

**量化指标 / Metrics**
- 老年不明原因背痛完成骨髓瘤筛查率
- 骨髓瘤疑似病例电泳完成率
- 首诊识别率
