# Skill: 转移灶原发部位推断

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第17章 恶性疾病
- 页码: 第17章“转移瘤”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第17章.md`

**目标 / Objective**
根据转移部位优先推断最可能的原发癌来源,提高后续检查效率。

**适用范围 / Scope**
- 已发现转移病灶但原发灶未明的病人

**操作步骤 / Procedure**
1. 先明确转移主要位于骨、脑、肝、肺纵隔、淋巴结、腹膜后或皮肤等部位。
2. 根据部位调用常见原发来源清单,如骨转移优先考虑乳腺、前列腺和肺癌。
3. 结合病人性别、年龄和伴随症状进一步排序最可能原发部位。
4. 以最可能部位为导向选择针对性影像和实验室检查。
5. 若仍无法定位,推动活检与免疫组织化学完善评估。

**注意事项 / Precautions**
- 转移部位能显著缩小原发灶搜索范围,但不是绝对诊断。
- 可治愈肿瘤必须优先识别并加速转诊。
- 过度泛化全身检查会延误关键定位。

**量化指标 / Metrics**
- 原发不明转移瘤初步定位率
- 转移部位导向检查匹配率
- 可治愈肿瘤快速转诊率
