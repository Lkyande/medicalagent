# Skill: 宫颈筛查样本采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第91章 宫颈癌筛查
- 页码: 第91章“由临床医生采集样本”“方法 2-8”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第91章.md`

**目标 / Objective**
规范采集宫颈筛查样本,提高转化区取样充分性和检测质量。

**适用范围 / Scope**
- 由临床医生实施宫颈筛查测试的门诊场景

**操作步骤 / Procedure**
1. 准备合适窥器、光源、润滑剂和对应取样器械。
2. 让病人取适宜体位,先检查外阴和阴道情况。
3. 正确插入窥器并充分暴露宫颈,观察转化区和异常外观。
4. 根据转化区位置选择宫颈取样刷、刮板、宫颈管刷或宫颈梳刷组合进行取样。
5. 迅速将样本转入液体介质,密封并在送检单中完整填写临床信息。

**注意事项 / Precautions**
- 取到转化区细胞是筛查质量关键。
- 妊娠期避免使用宫颈管刷和宫颈梳刷组合。
- 应避开月经期、明显感染期及阴道制剂使用后短时间采样。

**量化指标 / Metrics**
- 充分样本采集率
- 不满意样本比例
- 临床信息完整送检率
