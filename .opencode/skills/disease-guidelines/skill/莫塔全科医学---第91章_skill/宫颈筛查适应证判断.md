# Skill: 宫颈筛查适应证判断

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第91章 宫颈癌筛查
- 页码: 第91章“筛查建议”“谁应该接受筛查?”“特定人群筛查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第91章.md`

**目标 / Objective**
判断女性是否属于常规宫颈筛查、联合检测或特殊筛查人群。

**适用范围 / Scope**
- 有或无症状的适龄女性、特殊高危女性及妇科门诊场景

**操作步骤 / Procedure**
1. 判断是无症状常规筛查,还是因异常出血等症状需要诊断性检测。
2. 确认常规筛查起始年龄、5 年间隔及退出年龄范围。
3. 对妊娠、绝经后、免疫缺陷、DES 暴露或子宫切除术后病人按特殊路径处理。
4. 对性交后出血、持续经间期出血或绝经后出血者升级为联合检测和进一步转诊。
5. 对筛查不足人群主动加强可及性和提醒。

**注意事项 / Precautions**
- HPV 疫苗接种过的女性仍需筛查。
- 宫颈筛查只适用于无症状女性,有症状者需诊断性评估。
- 特殊人群筛查频率和方式不同,不能套用普通间隔。

**量化指标 / Metrics**
- 适龄女性筛查覆盖率
- 有症状女性联合检测实施率
- 筛查不足人群补筛率
