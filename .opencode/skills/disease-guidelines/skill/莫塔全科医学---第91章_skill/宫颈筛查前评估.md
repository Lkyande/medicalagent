# Skill: 宫颈筛查前评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第91章 宫颈癌筛查
- 页码: 第91章“宫颈筛查测试的看诊”“方法 1.解释和病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第91章.md`

**目标 / Objective**
在宫颈筛查前完成解释、同意和影响采样质量的重要病史评估。

**适用范围 / Scope**
- 准备接受宫颈筛查测试或联合检测的女性

**操作步骤 / Procedure**
1. 解释筛查目的、过程、不适感和大致耗时。
2. 询问既往筛查结果及是否曾经检查困难或焦虑。
3. 重点排查经间期或性交后出血、激素状态、妊娠和宫内节育器情况。
4. 获得口头同意,并询问是否需要陪伴者在场。
5. 若存在萎缩性阴道炎或强烈焦虑,提前采取改善舒适度措施。

**注意事项 / Precautions**
- 焦虑和疼痛预期会影响配合度和采样质量。
- 有症状者需在送检单上注明症状,以改变病理流程。
- 先排空膀胱和保护隐私可改善体验。

**量化指标 / Metrics**
- 宫颈筛查前解释记录率
- 异常出血病史记录率
- 口头同意记录率
