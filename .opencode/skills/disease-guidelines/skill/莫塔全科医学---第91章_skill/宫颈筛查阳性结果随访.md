# Skill: 宫颈筛查阳性结果随访

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第91章 宫颈癌筛查
- 页码: 第91章“随访”“宫颈筛查测试结果的管理”“表91.2”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第91章.md`

**目标 / Objective**
确保 HPV 阳性或细胞学异常结果的女性获得及时解释和后续处理。

**适用范围 / Scope**
- 宫颈筛查测试结果阳性、可疑或不满意的女性

**操作步骤 / Procedure**
1. 与病人确认结果已送达并安排解释结果的随访。
2. 按 HPV 16/18、非 16/18 及细胞学结果不同决定复查或阴道镜转诊。
3. 对不满意结果安排 6 至 12 周内重复测试。
4. 对 HSIL 治疗后病人安排年度联合检测直至连续两次阴性。
5. 用提醒系统追踪未完成复查或转诊者。

**注意事项 / Precautions**
- 常见医疗法律问题来自异常结果未沟通或未安排足够转诊。
- 结果阴性也要告知下次筛查时间。
- 失访管理是筛查项目质量的关键环节。

**量化指标 / Metrics**
- 阳性结果告知完成率
- 阴道镜转诊完成率
- 失访追踪成功率
