# Skill: 甲黑色素瘤警讯识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第119章 指/趾甲病
- 页码: 第119章“关键事实和要点”“甲黑色素瘤”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第119章.md`

**目标 / Objective**
在甲下色素异常中尽早识别甲黑色素瘤并避免误判为血肿或良性色带。

**适用范围 / Scope**
- 甲下黑色素沉着、纵行色素带或慢性甲周异常病变病人

**操作步骤 / Procedure**
1. 询问色素变化出现时间、是否随甲板生长向外移动以及外伤史。
2. 观察是否为持续纵行色素带、颜色不均或伴甲器结构破坏。
3. 与甲下血肿区分:血肿通常会随甲生长逐渐向远端移出。
4. 对任何疑似甲黑色素瘤或无色素性异常病变尽早专科转诊。
5. 避免在门诊反复观察拖延诊断。

**注意事项 / Precautions**
- 任何甲下色素病变都应先按黑色素瘤考虑。
- 无色素性黑色素瘤可伪装成慢性甲沟炎或化脓性肉芽肿。
- 早期识别直接影响预后。

**量化指标 / Metrics**
- 可疑甲黑色素瘤转诊率
- 血肿与黑色素瘤鉴别记录率
- 延迟诊断率
