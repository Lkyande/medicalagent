# Skill: 指趾甲异常系统评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第119章 指/趾甲病
- 页码: 第119章“重要病史”“重点身体检查”“重点辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第119章.md`

**目标 / Objective**
对指趾甲异常进行结构化评估,提高创伤、感染和炎症性病变的识别率。

**适用范围 / Scope**
- 指甲或趾甲出现变色、增厚、分离、脆裂、疼痛或畸形的病人

**操作步骤 / Procedure**
1. 询问病程、压力、职业潮湿暴露、剔甲癖和外伤史。
2. 检查所有手足甲,并同时寻找银屑病、斑秃、湿疹、足癣和扁平苔藓等皮肤证据。
3. 按甲分离、增厚、变薄、凹点、纵纹、横沟、变色等形态进行分类。
4. 对疑似甲真菌病采集剪甲和甲下刮屑做显微镜和培养。
5. 对可疑系统病线索补做 CBC、ESR、肝功能或其他针对性检查。

**注意事项 / Precautions**
- 甲病形态有限,但病因很多,需结合全身皮肤检查。
- 不要把所有白色脆甲都当作真菌感染。
- 慢性甲沟炎与甲真菌病需特别区分。

**量化指标 / Metrics**
- 甲病结构化记录率
- 真菌学采样率
- 伴发皮肤病识别率
