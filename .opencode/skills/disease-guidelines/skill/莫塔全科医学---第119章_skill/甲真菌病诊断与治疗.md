# Skill: 甲真菌病诊断与治疗

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第119章 指/趾甲病
- 页码: 第119章“甲癣(甲真菌感染)”“治疗”“局部治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第119章.md`

**目标 / Objective**
对甲真菌病进行病原学确认并选择合适的局部或系统治疗方案。

**适用范围 / Scope**
- 可疑甲癣、甲板增厚、甲营养不良或反复治疗失败的病人

**操作步骤 / Procedure**
1. 采集剪下的甲和甲下刮屑做显微镜和培养,尽量在用药前完成。
2. 评估受累甲数、受累部位和严重程度。
3. 对表浅或远端少量受累病甲考虑局部治疗。
4. 对范围较大、甲板明显增厚或局部疗法失败者考虑系统治疗。
5. 复诊追踪新甲生长和治疗依从性,提醒疗程较长。

**注意事项 / Precautions**
- 真菌学检查常是区分甲营养不良和甲癣的唯一方法。
- 趾甲生长慢,疗效评估要有足够时间。
- 需先排除银屑病和慢性甲沟炎等非真菌病因。

**量化指标 / Metrics**
- 甲癣真菌学确诊率
- 局部与系统治疗匹配率
- 随访中新甲改善率
