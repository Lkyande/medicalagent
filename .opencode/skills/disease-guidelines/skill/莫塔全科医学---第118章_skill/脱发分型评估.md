# Skill: 脱发分型评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第118章 毛发疾病
- 页码: 第118章“脱发诊断策略模型”“重要病史”“重要的身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第118章.md`

**目标 / Objective**
快速区分局灶性、弥漫性、瘢痕性和非瘢痕性脱发并决定下一步检查。

**适用范围 / Scope**
- 男性或女性主诉脱发、毛发稀疏或局部秃斑时

**操作步骤 / Procedure**
1. 明确脱发是局灶性还是弥漫性,急性还是慢性。
2. 询问伴随瘙痒、鳞屑、脓疱、发热、压力事件和药物暴露。
3. 检查头皮是否有干净秃块、瘢痕、炎症、鳞屑或异常拔毛图案。
4. 查找惊叹号发、白球发和全身内分泌线索。
5. 根据分型决定是否做牵拉试验、真菌检查、实验室筛查或活检。

**注意事项 / Precautions**
- 脱发可引发显著焦虑,解释预后很重要。
- 局灶性与弥漫性脱发路径不同。
- 瘢痕性脱发需要更早活检和专科介入。

**量化指标 / Metrics**
- 脱发分型记录率
- 伴随症状评估率
- 必要检查完成率
