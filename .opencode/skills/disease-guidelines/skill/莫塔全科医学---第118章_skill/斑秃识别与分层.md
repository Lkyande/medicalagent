# Skill: 斑秃识别与分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第118章 毛发疾病
- 页码: 第118章“斑秃、全秃和普秃”“临床特点”“局限性秃块”“广泛性区域”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第118章.md`

**目标 / Objective**
识别斑秃并区分局限型、全秃和普秃以指导预后和管理。

**适用范围 / Scope**
- 突发秃斑、眉睫毛脱落或弥漫性斑秃样脱发病人

**操作步骤 / Procedure**
1. 识别完全脱发秃块、干净头皮和惊叹号发三联征。
2. 判断是局限秃块、脱发超过 50% 的广泛区域、全秃还是普秃。
3. 询问起病年龄、家族史和指甲改变等预后因素。
4. 对局限型可给予局部强效激素或病灶内治疗选择。
5. 对广泛型安排心理支持、专科转诊和长期外观管理方案。

**注意事项 / Precautions**
- 起病年龄越早、范围越广,预后通常越差。
- 日常压力未必是直接诱因,需避免责备病人。
- 眉毛和睫毛脱落提示更重疾病谱。

**量化指标 / Metrics**
- 斑秃分层记录率
- 惊叹号发识别率
- 广泛型专科转介率
