# Skill: 头发牵拉试验

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第118章 毛发疾病
- 页码: 第118章“头发牵拉试验”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第118章.md`

**目标 / Objective**
通过简单床旁试验判断是否存在异常活动性脱发。

**适用范围 / Scope**
- 弥漫性脱发、休止期脱发或活动性斑秃评估时

**操作步骤 / Procedure**
1. 用拇指和示指抓住约 50 至 100 根头发。
2. 从近端向远端轻轻牵拉,重复 6 至 8 次。
3. 收集脱落毛发用于进一步观察分析。
4. 记录每次牵拉脱落头发数量。
5. 若每次超过 8 根脱落,视为异常并进一步评估病因。

**注意事项 / Precautions**
- 试验要轻柔且标准化,提高可比性。
- 结果应结合整体分型和病史解读。
- 异常并不能单独确定病因,仅提示活动性脱发。

**量化指标 / Metrics**
- 牵拉试验实施率
- 异常检出率
- 与后续诊断一致率
