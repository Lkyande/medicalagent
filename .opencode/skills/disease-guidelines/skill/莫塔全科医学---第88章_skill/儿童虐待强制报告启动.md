# Skill: 儿童虐待强制报告启动

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第88章 儿童虐待
- 页码: 第88章“争取基本帮助”“强制性报告”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第88章.md`

**目标 / Objective**
在怀疑儿童受虐时及时启动法定报告和多学科保护流程。

**适用范围 / Scope**
- 怀疑儿童正处于身体、情感、性虐待或忽视风险中的病例

**操作步骤 / Procedure**
1. 先评估当前儿童及同住儿童是否存在立即危险。
2. 收集和整理病史、伤情记录及其他信息来源。
3. 及时与儿童保护部门、同事或专科团队讨论。
4. 按法律要求完成强制性报告并记录时间、对象和内容。
5. 继续参与后续住院、社会心理评估和家庭支持协调。

**注意事项 / Precautions**
- 迈出第一步往往困难,但越早越重要。
- 报告并不终止全科医生职责,后续协调同样关键。
- 不确定细节并不等于不能报告风险。

**量化指标 / Metrics**
- 高危病例强制报告完成率
- 报告时效
- 多学科跟进覆盖率
