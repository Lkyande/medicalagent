# Skill: 儿童虐待警讯识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第88章 儿童虐待
- 页码: 第88章“定义”“身体虐待指征”“行为指标”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第88章.md`

**目标 / Objective**
在临床接触中及早识别可能提示儿童虐待或忽视的伤情和行为线索。

**适用范围 / Scope**
- 所有儿童门诊、急诊、慢病随访和家庭就诊场景

**操作步骤 / Procedure**
1. 对与病史不符、延迟就医或解释前后不一致的伤情保持警觉。
2. 检查可疑淤伤、烫伤、骨折和不会行走儿童的受伤模式。
3. 观察孩子是否过度顺从、害怕回家、对成人高度警惕或行为极端。
4. 同时留意忽视线索,如营养不良、卫生差、监督缺失和医疗需求被忽视。
5. 一旦怀疑,立即进入安全评估、记录和求助路径。

**注意事项 / Precautions**
- 孩子越小、残疾越重,受虐风险越高。
- 虐待可发生在任何社会经济层面。
- 必须同时考虑其他同居儿童的安全。

**量化指标 / Metrics**
- 可疑受虐线索记录率
- 高危病例进一步评估率
- 同住儿童安全评估率
