# Skill: 与照护者讨论可疑虐待

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第88章 儿童虐待
- 页码: 第88章“与父母或监护人的交谈”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第88章.md`

**目标 / Objective**
在保障儿童利益前提下,以专业且不升级冲突的方式与照护者沟通可疑虐待问题。

**适用范围 / Scope**
- 已怀疑受虐且需要与父母或监护人进行临床沟通的场景

**操作步骤 / Procedure**
1. 采用放松、非偏见和开放式提问方式开始交谈。
2. 描述伤情与现有解释之间的不一致,基于事实而非指责。
3. 明确告知你有法律和专业义务为儿童寻求协助。
4. 说明你的职责是帮助孩子并协助家庭获得支持。
5. 沟通后立即启动社工、住院评估或强制报告等下一步。

**注意事项 / Precautions**
- 交流中要始终把儿童最大利益放在首位。
- 不要等待“百分之百确定”才行动。
- 照护者可能愤怒、否认或操控,需保持冷静和一致。

**量化指标 / Metrics**
- 可疑虐待沟通记录率
- 沟通后保护措施启动率
- 团队协同介入时效
