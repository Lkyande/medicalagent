# Skill: 可疑虐待伤情记录

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第88章 儿童虐待
- 页码: 第88章“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第88章.md`

**目标 / Objective**
对可疑虐待病例进行可支持后续保护和法律流程的规范化记录。

**适用范围 / Scope**
- 临床上怀疑存在身体虐待、忽视或其他非意外伤害的儿童

**操作步骤 / Procedure**
1. 记录完整病史,尤其是照护者解释和受伤时间线。
2. 对淤伤、烧伤和其他伤痕进行详细测量、描述位置和形态。
3. 在条件允许时拍摄照片并注明日期与部位。
4. 尽可能逐字记录孩子、照护者和证人的原话。
5. 与同事、儿童保护部门或专科团队共享关键信息并保存原始记录。

**注意事项 / Precautions**
- 伤痕颜色不能可靠判断受伤时间。
- 记录要客观,避免主观推断替代事实。
- 文书质量直接影响后续保护和法律支持。

**量化指标 / Metrics**
- 可疑虐待病例完整记录率
- 照片和测量留存率
- 逐字引述记录率
