# Skill: 亲密伴侣暴力筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第110章 亲密伴侣暴力和性骚扰
- 页码: 第110章“可能的表现”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第110章.md`

**目标 / Objective**
在全科场景中主动识别 IPV 的隐匿表现并安全地询问受害者。

**适用范围 / Scope**
- 非特异躯体症状、心理问题、妊娠期或反复受伤来诊的女性

**操作步骤 / Procedure**
1. 对慢性疼痛、失眠、抑郁、进食障碍、反复损伤和妊娠期问题保持怀疑。
2. 确保病人与潜在施暴者分开后单独交谈。
3. 使用直接、非评判性问题询问是否感到害怕、不安全或遭受威胁伤害。
4. 对所有孕妇常规纳入 IPV 筛查。
5. 若筛查阳性,立即进入安全评估和支持路径。

**注意事项 / Precautions**
- 病人往往不会主动披露。
- 妊娠期是 IPV 高风险时段。
- 保密性和非批判态度决定披露成功率。

**量化指标 / Metrics**
- IPV 风险病人的筛查率
- 妊娠女性 IPV 常规询问率
- 阳性披露率
