# Skill: IPV安全计划制定

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第110章 亲密伴侣暴力和性骚扰
- 页码: 第110章“安全”“管理”“持续性照顾”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第110章.md`

**目标 / Objective**
为遭受亲密伴侣暴力的女性建立现实可执行的安全计划。

**适用范围 / Scope**
- 已披露 IPV 且对回家或持续共处安全存在担忧的女性

**操作步骤 / Procedure**
1. 结合病人自评、施暴者危险因素和临床判断评估当前危险程度。
2. 协助准备紧急电话号码、可求助亲友和安全地点。
3. 提醒准备应急现金、衣物、药物和重要文件备用包。
4. 讨论何时报警、邻居协助和儿童保护报告触发条件。
5. 安排持续跟进,定期复评暴力是否升级。

**注意事项 / Precautions**
- 离开关系的阶段往往风险最高。
- 儿童安全要同步评估。
- 计划必须由病人掌控并符合她现实处境。

**量化指标 / Metrics**
- IPV 阳性病人的安全计划制定率
- 危机资源连接率
- 安全复评完成率
