# Skill: 性侵犯近期处置

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第110章 亲密伴侣暴力和性骚扰
- 页码: 第110章“性侵犯”“对性侵犯的披露”“近期性侵犯”“STI 检查和预防”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第110章.md`

**目标 / Objective**
对近期性侵犯幸存者提供创伤知情、法医、避孕和感染预防支持。

**适用范围 / Scope**
- 近期遭受性侵犯或性威胁并主动披露的女性或男性幸存者

**操作步骤 / Procedure**
1. 提供隐私、安全和情感支持,先说出支持性关键话语。
2. 解释保密边界和病人对检查及治疗的选择权。
3. 采集指导管理所需的最小必要信息,避免过度追问创伤细节。
4. 在适当时窗内转介法医检查、紧急避孕和 STI/HIV 预防。
5. 评估病人及其儿童回家后的安全,并安排后续支持服务。

**注意事项 / Precautions**
- 法医检查通常以 72 小时内最关键。
- 记录的每个字都可能成为法律证据。
- 幸存者有权接受或拒绝评估和治疗方案。

**量化指标 / Metrics**
- 近期性侵犯病人的法医转介时效
- 紧急避孕和 STI 预防覆盖率
- 后续心理支持连接率
