# Skill: 网球肘诊断与基础锻炼

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第53章 手臂和手部的疼痛
- 页码: 第53章“外侧网球肘”“管理”“锻炼”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第53章.md`

**目标 / Objective**
通过典型体征识别外侧网球肘并启动以负荷管理和锻炼为核心的保守治疗。

**适用范围 / Scope**
- 肘外侧疼痛并怀疑外上髁肌腱病变的病人

**操作步骤 / Procedure**
1. 识别肘外侧局部压痛,确认肘关节屈伸活动基本正常。
2. 进行被动屈腕拉伸试验和抗阻力背伸手腕或中指试验。
3. 指导避免引起疼痛的抓握、拧转和过度伸腕活动。
4. 急性期采用 RICE 原则和短期非甾体抗炎药或局部 NSAID。
5. 启动前臂伸肌强化与伸展训练,如拧毛巾练习和渐进哑铃训练。

**注意事项 / Precautions**
- 只有极少数网球肘与真正打网球有关,不要因名称误导病因判断。
- 症状常自限但可持续很久,病人教育有助于提高依从性。
- 注射不应作为仅间歇痛病人的首选初始治疗。

**量化指标 / Metrics**
- 网球肘临床识别率
- 锻炼方案启动率
- 6 周疼痛缓解率
