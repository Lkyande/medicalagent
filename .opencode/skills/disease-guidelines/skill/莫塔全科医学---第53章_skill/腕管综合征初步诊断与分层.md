# Skill: 腕管综合征初步诊断与分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第53章 手臂和手部的疼痛
- 页码: 第53章“腕管综合征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第53章.md`

**目标 / Objective**
识别正中神经卡压的典型症状并完成轻重分层与后续检查选择。

**适用范围 / Scope**
- 手指麻刺痛、夜间痛醒或怀疑正中神经卡压的病人

**操作步骤 / Procedure**
1. 询问拇指、示指、中指和半侧环指出现针刺样感觉的分布。
2. 记录夜间痛醒、甩手后缓解以及快速活动双手后加重等典型病史。
3. 识别妊娠、糖尿病、甲减、类风湿和重复屈腕工作等相关因素。
4. 进行 Tinel 试验、Phalen 试验,必要时补做两点分辨觉测试。
5. 对诊断不明、持续不缓解或出现麻木无力者安排神经传导和肌电图。

**注意事项 / Precautions**
- Tinel 和 Phalen 都是软体征,阴性不能完全排除腕管综合征。
- 工作相关病例更需要客观电生理支持。
- 手部症状放射至肩部并不罕见,不要因此误判为纯肩病。

**量化指标 / Metrics**
- 腕管综合征识别率
- 夜间症状记录率
- 电生理检查适当开具率
