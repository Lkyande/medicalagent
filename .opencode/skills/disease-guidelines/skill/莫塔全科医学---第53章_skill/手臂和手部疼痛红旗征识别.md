# Skill: 手臂和手部疼痛红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第53章 手臂和手部的疼痛
- 页码: 第53章“不能遗漏的严重疾病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第53章.md`

**目标 / Objective**
及时识别提示心血管急症、严重感染、肿瘤或静脉血栓的手臂与手部疼痛。

**适用范围 / Scope**
- 所有手臂、肘、腕或手部疼痛病人

**操作步骤 / Procedure**
1. 对左臂突发向下放射痛优先排查心肌缺血或心肌梗死。
2. 识别手臂肿胀伴腋下痛或长期高举用力背景,警惕腋静脉血栓形成。
3. 检查是否存在局部红肿热痛、深部压痛或手部筋膜间隙感染线索。
4. 追问夜间持续重痛、进行性加重或伴全身症状,警惕肺上沟瘤和骨肿瘤。
5. 红旗征阳性时立即升级影像、心电图或急诊专科分流。

**注意事项 / Precautions**
- 手掌深部感染若延误处理,可迅速导致严重功能并发症。
- 突发上肢肿胀不应只按肌肉劳损解释。
- 肿瘤在明显体征出现前可能仅表现为顽固手臂痛。

**量化指标 / Metrics**
- 手臂痛红旗征记录率
- 高危病例急诊分流率
- 严重病因漏诊率
