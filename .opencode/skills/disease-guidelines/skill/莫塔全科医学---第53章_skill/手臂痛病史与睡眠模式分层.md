# Skill: 手臂痛病史与睡眠模式分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第53章 手臂和手部的疼痛
- 页码: 第53章“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第53章.md`

**目标 / Objective**
利用疼痛模式和睡眠特点快速区分颈椎病、腕管综合征和胸廓出口综合征。

**适用范围 / Scope**
- 以手臂或手部疼痛为主诉的门急诊病人

**操作步骤 / Procedure**
1. 询问疼痛分布、是否放射至肘下及与外伤或非常规动作的关系。
2. 追问夜间症状模式:无法入睡提示胸廓出口综合征,半夜痛醒提示腕管综合征。
3. 若手臂痛和僵硬从夜间持续到白天,提高对颈椎病的怀疑。
4. 对儿童补问上拉手臂、跌倒压到外展手臂等损伤机制。
5. 结合工作中重复用力、举臂或手腕负重动作完成初步病因分层。

**注意事项 / Precautions**
- 手臂痛的问诊不能只停留在局部,必须回问颈部和肩部。
- 睡眠模式是本章很有用的定位线索,应主动询问。
- 儿童损伤机制常决定是否存在肘周严重骨折或牵拉肘。

**量化指标 / Metrics**
- 手臂痛病史完整率
- 睡眠模式记录率
- 初步分层准确率
