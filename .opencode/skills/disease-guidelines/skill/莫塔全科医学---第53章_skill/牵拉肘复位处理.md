# Skill: 牵拉肘复位处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第53章 手臂和手部的疼痛
- 页码: 第53章“牵拉肘”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第53章.md`

**目标 / Objective**
对典型儿童牵拉肘进行床旁复位并减少不必要影像检查。

**适用范围 / Scope**
- 2 至 5 岁最常见的典型牵拉肘儿童,无青紫和畸形表现

**操作步骤 / Procedure**
1. 根据突然牵拉伸直旋前手臂的机制,识别患儿拒绝用手、肘轻屈和前臂旋前体位。
2. 让患儿坐在家长腿上,取得配合并固定健侧手臂。
3. 一手托肘并以拇指放在桡骨头上,另一手控制前臂。
4. 施以轻柔牵引后将前臂平稳完全旋后并同步充分屈肘,听触是否出现咔嗒感。
5. 观察数分钟内疼痛是否消失并恢复使用手臂,同时向家长说明可能复发。

**注意事项 / Precautions**
- 典型病例通常不需常规 X 线,但有畸形、青紫或机制不符时需重新评估骨折。
- 也可采用过度旋前屈肘法作为替代复位方法。
- 操作要轻柔,避免因过猛造成额外损伤。

**量化指标 / Metrics**
- 牵拉肘床旁复位成功率
- 不必要 X 线减少率
- 当场恢复使用手臂比例
