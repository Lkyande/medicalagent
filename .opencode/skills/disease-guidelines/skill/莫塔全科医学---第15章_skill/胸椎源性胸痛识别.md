# Skill: 胸椎源性胸痛识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第15章 脊柱功能障碍
- 页码: 第15章“胸椎功能障碍”“低位颈椎引起的胸痛”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第15章.md`

**目标 / Objective**
在胸痛或上腹痛鉴别中识别胸椎和低位颈椎牵涉痛,减少不必要的误诊与焦虑。

**适用范围 / Scope**
- 单侧胸壁痛、前胸痛、肩胛区痛或上腹痛而内脏原因未明者

**操作步骤 / Procedure**
1. 询问疼痛是否为单侧,是否位于肩胛区、椎旁 2 到 5 cm 区域或肋软骨区。
2. 同步排查急性冠脉综合征、肺栓塞、气胸、胆绞痛和阑尾炎等危险内脏病因。
3. 若内脏病因证据不足,追问脊柱活动相关性、低位颈椎损伤史及挥鞭样损伤史。
4. 将胸椎功能障碍和低位颈椎牵涉痛纳入鉴别,特别是在年轻人和儿童中也不要忽视。
5. 确认为肌骨来源后,安排恰当物理治疗和病人解释,减轻“心脏病”样恐惧。

**注意事项 / Precautions**
- 胸椎功能障碍最常见也最容易漏诊。
- 诊断前必须先排除危重的心肺和腹部急症。
- 低位颈椎疼痛可牵涉至胸前区,很像冠脉缺血。

**量化指标 / Metrics**
- 非心源性胸痛完成脊柱评估率
- 胸椎源性胸痛识别率
- 不必要急诊复诊率
