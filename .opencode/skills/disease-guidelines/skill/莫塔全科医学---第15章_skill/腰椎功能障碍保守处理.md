# Skill: 腰椎功能障碍保守处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第15章 脊柱功能障碍
- 页码: 第15章“腰骶椎功能障碍”“腰椎功能障碍的处理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第15章.md`

**目标 / Objective**
对腰椎功能障碍和相关疼痛综合征实施以活动维持为核心的保守治疗。

**适用范围 / Scope**
- 腰痛、臀部痛、下肢后侧牵涉痛或坐骨神经痛而适合保守管理者

**操作步骤 / Procedure**
1. 明确疼痛位于腰部并可牵涉至臀部、下肢后部、腹股沟或大腿前部。
2. 与有经验的物理治疗师协作,制定医学观察和保守治疗计划。
3. 指导病人尽量维持日常活动,即使活动中会有一定不适。
4. 嘱病人避免明显加重疼痛的动作,并使用基础止痛药如对乙酰氨基酚和布洛芬。
5. 对持续性疼痛者安排指导下运动及物理干预,如牵引、脊柱松动或推拿。

**注意事项 / Precautions**
- 腹股沟和大腿前部牵涉痛容易被误诊为疝或神经卡压。
- 保守治疗需要与危险神经压迫或其他严重病因鉴别。
- 维持活动通常优于长期卧床。

**量化指标 / Metrics**
- 腰痛病人活动维持指导率
- 保守治疗后疼痛改善率
- 物理治疗转介完成率
