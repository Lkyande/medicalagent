# Skill: 颈椎手法治疗禁忌筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第15章 脊柱功能障碍
- 页码: 第15章“颈椎功能障碍”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第15章.md`

**目标 / Objective**
在考虑颈椎推拿或其他手法治疗前识别高风险禁忌,避免严重神经血管并发症。

**适用范围 / Scope**
- 拟接受颈椎推拿、松动或肌肉能量治疗的颈部疼痛病人

**操作步骤 / Procedure**
1. 先确认病人症状是否可能由器质性疾病或血管性疾病引起。
2. 筛查椎基底动脉供血不足的病史或提示症状。
3. 询问类风湿关节炎、唐氏综合征和可能导致齿状突不稳的病史。
4. 对高风险病人避免颈椎推拿术,改为进一步影像或专科评估。
5. 若适合保守治疗,优先考虑更温和的关节松动和肌肉能量技术,并交由熟练治疗师实施。

**注意事项 / Precautions**
- 颈椎推拿术绝不能用于器质性疾病或椎基底动脉供血不足者。
- 类风湿关节炎和唐氏综合征病人存在四肢瘫痪风险。
- 只有熟练治疗师才应进行颈部手法治疗。

**量化指标 / Metrics**
- 颈部手法治疗前禁忌筛查率
- 高风险病人正确回避推拿率
- 手法治疗严重不良事件发生率
