# Skill: 颈椎源性疼痛识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第15章 脊柱功能障碍
- 页码: 第15章“颈椎功能障碍”“源于颈椎的临床问题”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第15章.md`

**目标 / Objective**
识别由颈椎功能障碍引起的非典型疼痛或神经症状,将其纳入鉴别诊断。

**适用范围 / Scope**
- 颈痛、头痛、肩臂痛、耳周面部痛、上胸背痛或眩晕病人

**操作步骤 / Procedure**
1. 询问是否存在抬重物、扭转颈部或车祸等诱因。
2. 确认疼痛是否位于颈部正中,或由颈部向头部、肩部、手臂、上胸和背部牵涉。
3. 对头痛、面部痛、耳痛和眩晕等看似不相关的症状,主动追问颈部僵硬和活动受限。
4. 判断手臂疼痛更像牵涉痛还是神经根放射痛,并留意脊髓病变的感觉和运动异常。
5. 在排除器质性急症后,将颈椎功能障碍列入主要诊断路径并考虑物理治疗评估。

**注意事项 / Precautions**
- 任何部位的疼痛都可能是脊柱源性的,不能只盯住疼痛所在器官。
- 颈椎问题可表现为“偏头痛样”头痛,容易被误诊为原发性头痛。
- 一旦出现脊髓病变体征,应优先排除压迫性或器质性病变。

**量化指标 / Metrics**
- 非典型头面肩臂痛完成颈椎评估率
- 颈椎源性疼痛识别率
- 误诊后再次就诊率
