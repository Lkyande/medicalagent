# Skill: 不明原因发热序贯评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第42章 发热和畏寒
- 页码: 第42章“不明原因发热”“病史”“身体检查”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第42章.md`

**目标 / Objective**
用分阶段而非一次性铺开的方式评估 FUO,提高诊断效率并减少无效检查。

**适用范围 / Scope**
- 符合或接近 FUO 标准的持续发热病人

**操作步骤 / Procedure**
1. 先确认发热病程、体温阈值和既往检查,判断是否进入 FUO 评估。
2. 重复采集病史,重点覆盖职业、旅行、性生活、静脉用药、动物接触和药物史。
3. 重复体格检查,特别查看皮肤、眼底、颞动脉、心脏、腹部、淋巴结和尿液线索。
4. 先行基础序贯检查,包括血常规、炎症指标、胸片、尿检培养和血培养。
5. 根据前一轮结果再聚焦更深层诊断,避免一次性并行铺开所有检查。

**注意事项 / Precautions**
- FUO 诊断常依赖重复病史和重复体检,一次检查不足以排除关键线索。
- 必须始终排除 HIV、结核、感染性心内膜炎、血管炎和恶性肿瘤。
- 药物热和人为发热是常见陷阱,长期查无结果时要重新回看。

**量化指标 / Metrics**
- FUO 重复病史采集次数
- 序贯基础检查完成率
- 最终明确病因诊断率
