# Skill: 真性寒战识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第42章 发热和畏寒
- 页码: 第42章“畏寒/寒战”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第42章.md`

**目标 / Objective**
区分普通畏寒感与真正寒战,提高对菌血症和严重感染的警觉。

**适用范围 / Scope**
- 发热伴发冷、颤抖或寒战主诉的病人

**操作步骤 / Procedure**
1. 询问寒战是否为不能自主停止的剧烈颤抖。
2. 观察是否有上下牙齿快速磕碰和牙床颤抖表现。
3. 记录持续时间,真正寒战通常持续 10~20 分钟。
4. 查找无出汗、肢端冰冷苍白、口干和汗毛竖立等伴随体征。
5. 若符合真正寒战特征,优先排查菌血症、肾盂肾炎、脓肿、疟疾和胆源性脓毒症。

**注意事项 / Precautions**
- 普通病毒性发热常有怕冷感,但并不等同于真正寒战。
- 真性寒战出现时要提高对败血症和化脓性感染的警惕。
- 老年人和免疫低下者即使症状不典型也不可轻视。

**量化指标 / Metrics**
- 寒战特征记录率
- 真性寒战后严重感染筛查率
- 败血症早期识别率
