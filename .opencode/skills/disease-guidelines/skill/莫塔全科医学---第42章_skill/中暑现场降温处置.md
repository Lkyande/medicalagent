# Skill: 中暑现场降温处置

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第42章 发热和畏寒
- 页码: 第42章“中暑(日射病,热射病)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第42章.md`

**目标 / Objective**
对中暑病人立即实施有效降温,减少循环衰竭和器官损伤风险。

**适用范围 / Scope**
- 暴露高热环境后出现高热、热干皮肤和意识改变的病人

**操作步骤 / Procedure**
1. 识别体温超过 40℃、皮肤热而干燥、脉快及意识改变等中暑表现。
2. 立即开始冷水擦拭、清凉喷雾配合扇风等体表降温。
3. 在腋下、颈部和头部等关键部位放置冰袋。
4. 条件允许时考虑全身浸泡降温,但对病重者需谨慎监护。
5. 以每 10 分钟下降约 1℃为目标,并同步准备更高等级救治。

**注意事项 / Precautions**
- 中暑是危及生命的急症,不能等待化验后再处理。
- 老年人、体弱者和被留在车内儿童风险尤其高。
- 需与严重感染、中毒性休克和药物中毒等鉴别,但降温不应延迟。

**量化指标 / Metrics**
- 中暑识别到降温启动时间
- 30 分钟核心体温下降幅度
- 循环衰竭发生率
