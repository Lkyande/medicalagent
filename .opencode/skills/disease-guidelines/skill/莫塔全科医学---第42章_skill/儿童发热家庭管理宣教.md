# Skill: 儿童发热家庭管理宣教

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第42章 发热和畏寒
- 页码: 第42章“儿童的发热”“给父母的建议”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第42章.md`

**目标 / Objective**
指导照护者安全处理常见儿童发热,减少过度包裹和不当退热行为。

**适用范围 / Scope**
- 一般情况尚可、可在门诊或家庭观察的发热儿童及其照护者

**操作步骤 / Procedure**
1. 向家长说明发热本身多为感染反应,轻度发热通常不需积极退热。
2. 建议给孩子穿轻薄衣物,避免过多衣服或毯子包裹。
3. 强调少量多次补充液体,特别是水,预防脱水。
4. 当体温超过 38.5℃且孩子明显不适时按体重使用对乙酰氨基酚或布洛芬。
5. 教育家长若出现危险征象、持续高热或精神状态改变应立即复诊。

**注意事项 / Precautions**
- 冷水海绵擦洗和风扇并非有效常规退热方法。
- 阿司匹林不适用于幼儿常规退热。
- 出牙不会引起发热,不要因此忽视真正感染。

**量化指标 / Metrics**
- 发热儿童家庭宣教覆盖率
- 按体重正确用药率
- 因不当包裹导致就诊加重率
