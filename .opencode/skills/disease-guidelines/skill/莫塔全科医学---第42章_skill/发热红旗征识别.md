# Skill: 发热红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第42章 发热和畏寒
- 页码: 第42章“发热的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第42章.md`

**目标 / Objective**
快速筛出可能存在败血症、会厌炎或其他致命感染的发热病人。

**适用范围 / Scope**
- 所有急性或持续性发热病人

**操作步骤 / Procedure**
1. 评估是否存在高热、反复寒战、湿透性盗汗或严重肌痛。
2. 询问任何部位的剧烈疼痛,重点警惕深部化脓性感染或败血症。
3. 识别剧烈咽痛、吞咽困难、精神状态改变和持续呕吐。
4. 观察是否合并不明原因皮疹、黄疸、显著苍白、心动过速或呼吸急促。
5. 任何红旗征阳性时立即升级监测、完善检查并考虑住院评估。

**注意事项 / Precautions**
- 红旗征敏感但不特异,宁可扩大评估也不要延误严重感染。
- 极端年龄和免疫低下者常表现不典型,阈值应更低。
- 老年人即使体温不高,合并心动过速或意识改变也要高度警惕。

**量化指标 / Metrics**
- 发热病人红旗征筛查率
- 高危病人升级处置及时率
- 败血症漏诊率
