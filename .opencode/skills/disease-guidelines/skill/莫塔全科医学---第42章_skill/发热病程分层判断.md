# Skill: 发热病程分层判断

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第42章 发热和畏寒
- 页码: 第42章“临床方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第42章.md`

**目标 / Objective**
按照发热持续时间分层诊断思路,提高初诊时的病因判断效率。

**适用范围 / Scope**
- 所有以发热为主要主诉的门诊或初诊病人

**操作步骤 / Procedure**
1. 先确认发热持续时间并分为少于 3 日、4~14 日和超过 14 日三类。
2. 对少于 3 日的发热重点寻找自限性病毒感染与常见局灶性感染证据。
3. 对持续 4~14 日的发热提高对不常见感染的警惕,补充详细病史和基础检查。
4. 对持续超过 14 日的发热转入长期发热或 FUO 评估路径。
5. 在任何时点若出现危重征象,都优先按严重感染或败血症路径处理。

**注意事项 / Precautions**
- 单凭病程不能替代严重程度判断,红旗征优先级更高。
- 女性和儿童无明显病灶时,尿液检查是重要筛查步骤。
- 持续时间越长,感染性病因的相对概率会下降。

**量化指标 / Metrics**
- 发热病程分类记录率
- 各病程层级检查匹配率
- FUO 评估启动及时率
