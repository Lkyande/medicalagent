# Skill: 库欣综合征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第67章 体重改变
- 页码: 第67章“库欣综合征”“临床特征”“征象”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第67章.md`

**目标 / Objective**
在异常增重病人中识别提示高糖皮质激素状态的典型体貌和症状组合。

**适用范围 / Scope**
- 中心性肥胖、外观改变或伴代谢异常的成人病人

**操作步骤 / Procedure**
1. 询问外表变化、近端肌无力、月经异常、痤疮、多毛和情绪改变。
2. 查找满月脸、水牛背、紫纹、躯干肥大和四肢相对纤细等特征。
3. 核对外源性糖皮质激素使用史,包括口服、局部和注射剂型。
4. 若高度怀疑,转入血浆皮质醇和隔夜地塞米松抑制试验路径。
5. 及早转诊内分泌专科明确病因并处理并发症风险。

**注意事项 / Precautions**
- 最常见病因为医源性糖皮质激素暴露。
- 未治疗库欣综合征预后差,不应长期观察等待。
- 单纯肥胖通常不具备典型紫纹、肌萎缩和体貌组合。

**量化指标 / Metrics**
- 可疑库欣病例的药物史核对率
- 典型体征记录率
- 内分泌转诊完成率
