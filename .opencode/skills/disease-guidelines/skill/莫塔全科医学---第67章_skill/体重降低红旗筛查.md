# Skill: 体重降低红旗筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第67章 体重改变
- 页码: 第67章“体重降低”“不能遗漏的严重疾病”“体重降低的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第67章.md`

**目标 / Objective**
识别非意愿性体重降低背后的恶性、感染性、内分泌和精神心理危险病因。

**适用范围 / Scope**
- 非意愿性体重下降或短期明显消瘦的成人和老年病人

**操作步骤 / Procedure**
1. 确认体重下降是否真实,记录幅度、持续时间及食欲变化。
2. 询问发热、盗汗、疼痛、吞咽困难、腹泻、抑郁和药物使用等伴随线索。
3. 优先排查恶性肿瘤、慢性感染、糖尿病、甲状腺功能亢进和抑郁。
4. 检查一般营养状态、淋巴结、腹部、甲状腺和口腔牙齿情况。
5. 安排基础化验和必要影像,对红旗明显者加快专科转诊。

**注意事项 / Precautions**
- 老年人非意愿性体重下降尤其要警惕恶性肿瘤和抑郁。
- 不能只归因于“年纪大”或“吃得少”。
- 体重下降常由多因素共同造成,包括社会与心理问题。

**量化指标 / Metrics**
- 非意愿性体重下降病人的红旗征记录率
- 基础检查完成率
- 高危病例专科转诊率
