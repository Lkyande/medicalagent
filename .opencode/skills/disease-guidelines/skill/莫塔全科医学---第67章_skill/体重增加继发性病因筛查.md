# Skill: 体重增加继发性病因筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第67章 体重改变
- 页码: 第67章“体重增加”“表67.1 体重增加:诊断策略模型”“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第67章.md`

**目标 / Objective**
在体重增加病人中筛查需要优先处理的继发性病因和液体潴留状态。

**适用范围 / Scope**
- 近期体重明显增加或原因不明增重的成人病人

**操作步骤 / Procedure**
1. 区分脂肪增加还是体液潴留,明确增重速度和时间跨度。
2. 询问饮食、饮酒、运动、妊娠可能性和增重相关药物使用史。
3. 查找甲减、库欣综合征、PCOS、性腺功能减退和下丘脑病变线索。
4. 评估心力衰竭、肝衰竭和肾病综合征的体征,如水肿、呼吸困难和腹胀。
5. 安排 BMI、腰围、血压、尿检、血糖、血脂及必要的甲状腺和皮质醇检查。

**注意事项 / Precautions**
- 大多数肥胖为外源性,但仍需主动排除少数重要继发性因素。
- 快速增重伴水肿更提示器官衰竭而非单纯肥胖。
- 肥胖病人若伴视力障碍或头痛,需警惕下丘脑或垂体病变。

**量化指标 / Metrics**
- 原因不明增重病人的继发性病因筛查率
- BMI 和腰围记录率
- 可逆性继发病因识别率
