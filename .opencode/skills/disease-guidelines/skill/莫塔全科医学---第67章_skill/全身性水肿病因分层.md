# Skill: 全身性水肿病因分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第67章 体重改变
- 页码: 第67章“水肿”“表67.2 全身性水肿的病因”“诊断”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第67章.md`

**目标 / Objective**
对全身性水肿进行容量和病因分层,指导基础检查与初步处理。

**适用范围 / Scope**
- 出现面部、眶周、外周或全身性水肿并伴体重增加的病人

**操作步骤 / Procedure**
1. 判断水肿分布及是否受重力影响,区分全身性与局部性水肿。
2. 依据病史将病因先分为低白蛋白相关和容量增加相关两大类。
3. 筛查心衰、慢性肾衰、肝病、肾病综合征及药物相关水肿。
4. 完成尿液分析、肾功能、肝功能及必要的心血管评估。
5. 针对明确病因处理,并辅以限盐和恰当利尿剂方案。

**注意事项 / Precautions**
- 特发性水肿多见于女性,需结合典型日间体重波动病史。
- 单纯利尿不能替代病因治疗。
- 单侧肢体肿胀应另行考虑静脉或淋巴回流障碍。

**量化指标 / Metrics**
- 水肿病人尿检完成率
- 肝肾功能检查完成率
- 明确病因后针对性处理率
