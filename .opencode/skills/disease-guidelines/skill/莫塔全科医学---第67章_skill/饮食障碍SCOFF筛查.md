# Skill: 饮食障碍SCOFF筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第67章 体重改变
- 页码: 第67章“青少年饮食障碍”“SCOFF 筛查工具”“神经性厌食”“神经性贪食”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第67章.md`

**目标 / Objective**
在体重下降或进食异常病人中快速筛查神经性厌食和神经性贪食风险。

**适用范围 / Scope**
- 青少年和年轻成人出现消瘦、进食受限、暴食、催吐或体型过度关注时

**操作步骤 / Procedure**
1. 询问体重变化、月经情况、暴食行为、催吐、过度运动和体型认知。
2. 使用 SCOFF 工具进行简短筛查并记录阳性项数。
3. 查找神经性厌食的低体重、怕胖、形体认知扭曲和营养不良体征。
4. 查找神经性贪食的暴食后补偿行为,如催吐、泻药或极端节食。
5. 对筛查阳性或生命体征异常者启动精神心理及营养专科评估。

**注意事项 / Precautions**
- 低体重不是饮食障碍的唯一入口,正常体重也可存在严重补偿行为。
- 青少年评估需兼顾家庭动力学和学校环境。
- 电解质紊乱、心动过缓和脱水提示需要更高级别处置。

**量化指标 / Metrics**
- 可疑饮食障碍病人的 SCOFF 使用率
- 筛查阳性后的专科转介率
- 生命体征和营养风险记录率
