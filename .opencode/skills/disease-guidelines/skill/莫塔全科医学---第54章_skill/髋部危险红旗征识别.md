# Skill: 髋部危险红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第54章 髋部、臀部和腹股沟区疼痛
- 页码: 第54章“潜在严重髋关节疾病的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第54章.md`

**目标 / Objective**
快速识别提示感染、骨折、神经损害或肿瘤的高危髋部疼痛表现。

**适用范围 / Scope**
- 所有髋部、臀部、腹股沟或大腿上部疼痛病人

**操作步骤 / Procedure**
1. 查找关节肿胀、发红和明显运动严重受限。
2. 对无外伤的疼痛合并发热或全身症状,优先考虑感染性病因。
3. 评估是否存在肌力下降或其他神经功能障碍。
4. 识别外伤后关节快速肿胀以及持续局部痛但活动不受限的异常模式。
5. 红旗征阳性时立即升级影像、实验室和骨科或急诊评估。

**注意事项 / Precautions**
- 儿童急性髋痛应优先排除化脓性关节炎和骨髓炎。
- 老年髋痛即使还能负重,也不能排除股骨颈骨折。
- 活动不受限却持续局部痛要警惕骨性病变或肿瘤。

**量化指标 / Metrics**
- 髋痛红旗征记录率
- 高危病例急诊转诊率
- 严重病因漏诊率
