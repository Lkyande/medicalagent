# Skill: 大转子疼痛综合征初始处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第54章 髋部、臀部和腹股沟区疼痛
- 页码: 第54章“大转子疼痛综合征”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第54章.md`

**目标 / Objective**
对髋外侧大转子疼痛实施保守治疗并识别局部注射时机。

**适用范围 / Scope**
- 中老年人髋外侧痛、夜间侧卧痛或怀疑臀中肌腱病变与转子滑囊炎者

**操作步骤 / Procedure**
1. 确认髋外侧压痛最明显点位于股骨大转子上或其附近。
2. 试验性应用非甾体抗炎药并评估其风险。
3. 启动包括髋外展肌强化在内的物理治疗作为一线方案。
4. 必要时在超声引导下进行局部注射,为后续锻炼创造条件。
5. 指导患侧臀下垫枕、拉伸臀肌、局部冰敷按摩及双脚外旋步态减负。

**注意事项 / Precautions**
- 中年和老年女性髋痛常被误判为髋关节炎,需主动触诊大转子区域。
- 超声常较 X 线更能显示相关软组织病变。
- 顽固病例可能需要重复注射或手术,但应先完成规范保守治疗。

**量化指标 / Metrics**
- 大转子压痛定位率
- 物理治疗启动率
- 6 至 12 周症状改善率
