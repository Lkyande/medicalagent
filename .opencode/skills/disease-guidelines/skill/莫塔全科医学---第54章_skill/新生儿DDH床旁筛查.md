# Skill: 新生儿DDH床旁筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第54章 髋部、臀部和腹股沟区疼痛
- 页码: 第54章“发育性髋关节发育不良”“筛查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第54章.md`

**目标 / Objective**
在新生儿期识别髋关节不稳或脱位,尽早启动 DDH 转诊路径。

**适用范围 / Scope**
- 出生当天、出院前和 6 周复查的新生儿及高危婴儿

**操作步骤 / Procedure**
1. 让婴儿充分放松并脱去衣物,观察双腿长度和皮肤皱褶是否对称。
2. 进行弹进试验:髋屈 90 度后逐渐外展至约 45 度,感受复位咔嗒或弹动。
3. 进行弹出试验:髋屈 90 度并轻度内收,施以后向轻压观察股骨头是否滑出髋臼。
4. 对臀位分娩、家族史等高危婴儿安排超声检查,不要依赖普通 X 线。
5. 一旦筛查阳性或高度怀疑,尽快转专科决定吊带、外展夹板或进一步处理。

**注意事项 / Precautions**
- 3 个月以内普通 X 线对 DDH 价值很有限,超声更重要。
- 检查动作要轻柔,避免粗暴牵拉。
- 早诊早治可显著改善预后,漏筛会带来后续跛行和早发骨关节炎。

**量化指标 / Metrics**
- 新生儿 DDH 筛查覆盖率
- 高危婴儿超声完成率
- 早期专科转诊率
