# Skill: 髋痛病史与步态分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第54章 髋部、臀部和腹股沟区疼痛
- 页码: 第54章“病史”“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第54章.md`

**目标 / Objective**
通过疼痛部位、诱因和步态线索区分髋关节源性、骶髂源性和牵涉性髋痛。

**适用范围 / Scope**
- 门急诊髋部、臀部、腹股沟或大腿上段疼痛病人

**操作步骤 / Procedure**
1. 询问疼痛确切位置,重点区分腹股沟深部痛、臀外侧痛和后臀痛。
2. 追问活动后加重、晨僵、跛行、腰酸、楼梯困难和夜间痛等特征。
3. 询问是否存在跌倒、生育史、童年髋病史以及患侧卧位疼痛。
4. 观察步态,注意跛行、下肢内收伴足外旋等提示髋关节骨关节炎的模式。
5. 将病史和步态与腰骶部、骶髂关节、疝气和膝部来源进行对照分层。

**注意事项 / Precautions**
- 真实髋关节痛常位于腹股沟并可放射到膝部,不要只追着膝痛处理。
- 多产女性双侧臀髋痛要主动考虑骶髂关节问题。
- 侧卧患侧痛是大转子疼痛综合征的重要线索。

**量化指标 / Metrics**
- 髋痛病史完整率
- 步态观察记录率
- 初步来源分层准确率
