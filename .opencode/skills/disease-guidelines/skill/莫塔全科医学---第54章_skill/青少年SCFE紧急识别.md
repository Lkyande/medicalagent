# Skill: 青少年SCFE紧急识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第54章 髋部、臀部和腹股沟区疼痛
- 页码: 第54章“股骨头骨骺滑脱”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第54章.md`

**目标 / Objective**
尽早识别股骨头骨骺滑脱并在缺血坏死前完成停负重和骨科转诊。

**适用范围 / Scope**
- 10 至 15 岁肥胖青少年出现跛行、膝痛或腹股沟痛时

**操作步骤 / Procedure**
1. 对青春期肥胖患儿出现轻微跛行、膝痛或腹股沟痛时立即想到 SCFE。
2. 检查髋关节活动范围,重点识别内旋受限和屈髋时外旋。
3. 不要因主诉是膝痛而忽略双侧髋关节检查。
4. 立即安排双侧髋关节前后位和蛙式位 X 线。
5. 在确诊或高度怀疑时立刻停止负重并紧急转骨科进一步固定处理。

**注意事项 / Precautions**
- X 线一时正常但临床高度可疑者也应转诊,不要等待明显滑脱后再处理。
- SCFE 可双侧发生,影像要拍双侧。
- 手法强行复位可增加缺血坏死风险。

**量化指标 / Metrics**
- SCFE 早期识别率
- 膝痛青少年髋部评估率
- 首诊到骨科转诊时间
