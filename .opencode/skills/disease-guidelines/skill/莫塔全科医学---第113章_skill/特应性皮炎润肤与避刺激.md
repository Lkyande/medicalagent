# Skill: 特应性皮炎润肤与避刺激

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第113章 常见的皮肤疾病
- 页码: 第113章“避免刺激物”“改善皮肤状况”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第113章.md`

**目标 / Objective**
通过润肤和避免刺激物恢复皮肤屏障并减少特应性皮炎复发。

**适用范围 / Scope**
- 轻中度特应性皮炎病人及其照护者

**操作步骤 / Procedure**
1. 去除肥皂、香水、热水、羊毛、摩擦和过热等常见刺激因素。
2. 指导短时温水淋浴和使用肥皂替代品。
3. 沐浴后立即全身涂抹润肤剂,并每日重复至少 2 次。
4. 必要时实施防尘螨和夜间防抓挠措施。
5. 通过复诊评估皮肤干燥和复发频率变化。

**注意事项 / Precautions**
- 润肤是长期管理核心,不是仅在发作时使用。
- 过热和出汗常使夜间瘙痒加重。
- 家庭教育对儿童病人尤为关键。

**量化指标 / Metrics**
- 润肤剂使用教育覆盖率
- 避刺激措施执行率
- 复发频率下降率
