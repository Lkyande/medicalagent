# Skill: 特应性皮炎局部激素分区用药

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第113章 常见的皮肤疾病
- 页码: 第113章“药物”“外用类固醇皮质治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第113章.md`

**目标 / Objective**
按部位和严重度合理选择局部糖皮质激素强度治疗特应性皮炎。

**适用范围 / Scope**
- 需要局部抗炎治疗的特应性皮炎病人

**操作步骤 / Procedure**
1. 明确皮炎部位是面部/腹股沟、躯干四肢还是手足苔藓样变区域。
2. 面部、腋窝和腹股沟优先选弱效激素。
3. 躯干和四肢选中效,严重时短期加强效。
4. 手足和明显苔藓样变区域可选强效制剂。
5. 7 至 14 日复查效果,病情复发时及时重启治疗直到皮肤恢复正常。

**注意事项 / Precautions**
- 关键是足量使用直至炎症真正消退。
- 不同部位皮肤厚度不同,不能一管药全身用。
- 家长常担心激素,需要主动释疑和示范正确使用。

**量化指标 / Metrics**
- 分区用药记录率
- 7~14 日复查率
- 激素不当使用率
