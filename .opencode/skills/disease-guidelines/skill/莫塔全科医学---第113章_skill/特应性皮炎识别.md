# Skill: 特应性皮炎识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第113章 常见的皮肤疾病
- 页码: 第113章“特应性皮炎”“诊断标准”“分布”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第113章.md`

**目标 / Objective**
根据瘙痒、分布和病史识别特应性皮炎并与其他皮炎区分。

**适用范围 / Scope**
- 婴儿、儿童和成人出现慢性复发性瘙痒性皮炎时

**操作步骤 / Procedure**
1. 识别瘙痒、皮肤干燥和慢性复发病程。
2. 询问特应性家族史及常见触发因素。
3. 根据年龄判断面部、伸侧或屈侧等典型分布。
4. 查找苔藓样变、抓痕和继发感染表现。
5. 用诊断标准整合判断并与接触性皮炎、癣等鉴别。

**注意事项 / Precautions**
- 食物过敏很少是主要原因。
- 不同年龄分布差异明显,需结合年龄解释。
- 特应性是倾向,不是“过敏”同义词。

**量化指标 / Metrics**
- 特应性皮炎诊断标准记录率
- 触发因素识别率
- 继发感染识别率
