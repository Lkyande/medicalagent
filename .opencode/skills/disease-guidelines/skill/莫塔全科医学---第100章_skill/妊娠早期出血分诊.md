# Skill: 妊娠早期出血分诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第100章 基本的产前服务
- 页码: 第100章“妊娠早期阴道出血”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第100章.md`

**目标 / Objective**
对妊娠早期阴道出血进行快速分诊,区分可继续妊娠、流产和异位妊娠风险。

**适用范围 / Scope**
- 妊娠前 12 周出现阴道出血的孕妇

**操作步骤 / Procedure**
1. 评估出血量、疼痛程度、晕厥和生命体征稳定性。
2. 根据孕周安排动态 hCG 或经阴道超声。
3. 在 hCG 达到相应阈值但宫内未见妊娠囊时提高异位妊娠警惕。
4. 对疑似不完全流产、异位妊娠或 hemodynamic 不稳定者紧急转诊。
5. 对轻中度、稳定病例安排复查并给予明确警示教育。

**注意事项 / Precautions**
- 先兆流产通常不需要卧床休息。
- 异位妊娠必须始终纳入鉴别。
- 抗 D 使用要按流产类型和 Rh 情况规范判断。

**量化指标 / Metrics**
- 妊娠早期出血 hCG/超声评估率
- 异位妊娠高危识别率
- 紧急转诊时效
