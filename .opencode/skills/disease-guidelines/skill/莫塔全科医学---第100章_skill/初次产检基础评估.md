# Skill: 初次产检基础评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第100章 基本的产前服务
- 页码: 第100章“初诊”“病史要点”“身体检查”“产前筛查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第100章.md`

**目标 / Objective**
在首次产检时建立完整妊娠基线并规划筛查路径。

**适用范围 / Scope**
- 已确认或怀疑妊娠的孕妇首次产前就诊

**操作步骤 / Procedure**
1. 记录产科、内外科、药物、家族史和社会心理背景。
2. 完成基础体检,包括血压、体重、一般状况和必要的产科检查。
3. 安排常规实验室和感染筛查,并说明后续时间表。
4. 结合孕周介绍联合筛查、无创产前筛查和超声安排。
5. 建立常规产检随访计划并教育红旗症状。

**注意事项 / Precautions**
- 首次产检不仅是确认妊娠,也是建立长期关系的关键机会。
- 风险筛查和病史质量会影响后续整个孕期管理。
- 需要尽早识别精神心理和社会支持问题。

**量化指标 / Metrics**
- 初次产检病史完整率
- 基线检查完成率
- 筛查路径告知率
