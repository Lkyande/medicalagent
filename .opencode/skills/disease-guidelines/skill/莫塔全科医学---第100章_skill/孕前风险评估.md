# Skill: 孕前风险评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第100章 基本的产前服务
- 页码: 第100章“孕前服务”“要点归纳”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第100章.md`

**目标 / Objective**
在受孕前识别可干预风险,改善妊娠结局和母婴健康。

**适用范围 / Scope**
- 计划妊娠的女性及其伴侣

**操作步骤 / Procedure**
1. 询问既往妊娠史、慢病、用药、家族遗传病和免疫状态。
2. 优化糖尿病、甲状腺病、高血压和精神健康等基础疾病。
3. 评估吸烟、酒精、娱乐性药物和营养状态。
4. 提供叶酸、碘和疫苗等孕前预防建议。
5. 讨论体重、环境暴露、感染风险和遗传咨询需求。

**注意事项 / Precautions**
- 孕前阶段是纠正慢病和不良生活方式的最佳窗口。
- 伴侣因素同样会影响妊娠和育儿准备。
- 高风险女性应在受孕前就进入专科协同管理。

**量化指标 / Metrics**
- 孕前咨询覆盖率
- 叶酸和碘补充建议率
- 可修改风险因素纠正率
