# Skill: 妊娠剧吐识别与入院

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第100章 基本的产前服务
- 页码: 第100章“妊娠期恶心和呕吐”“妊娠剧吐”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第100章.md`

**目标 / Objective**
识别妊娠剧吐并及时进行补液、电解质和病因评估。

**适用范围 / Scope**
- 持续恶心呕吐、脱水或酮体阳性的早孕女性

**操作步骤 / Procedure**
1. 先区分轻度妊娠恶心与剧吐,重点评估进食、体液和功能受损情况。
2. 检测尿酮体、尿液培养、电解质、尿素和肝功能。
3. 安排超声排除葡萄胎和多胎妊娠等相关病症。
4. 对酮体阳性或明显脱水者安排入院、补液和止吐治疗。
5. 出院后继续随访饮食恢复、体重和复发风险。

**注意事项 / Precautions**
- 妊娠剧吐可导致严重水电解质紊乱。
- 不能把所有早孕呕吐都视为“正常反应”。
- 需同时排除尿路感染等加重因素。

**量化指标 / Metrics**
- 可疑剧吐病人的酮体检测率
- 入院指征识别率
- 补液后症状改善率
