# Skill: 妊娠危险暴露预防

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第100章 基本的产前服务
- 页码: 第100章“健康的环境”“李斯特菌属”“弓形虫病”“吸烟、酒精和其他毒品”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第100章.md`

**目标 / Objective**
减少妊娠期感染、毒物和生活方式暴露对母胎的危害。

**适用范围 / Scope**
- 所有妊娠女性,尤其早孕和首次产检人群

**操作步骤 / Procedure**
1. 指导避免李斯特菌高风险食物并强调食品卫生。
2. 解释猫砂、未熟肉和接触儿童体液相关的弓形虫、CMV 和细小病毒风险。
3. 建议限制含汞大鱼摄入并合理安排海鲜食用。
4. 强烈建议停止吸烟、酒精和娱乐性药物,必要时提供戒烟支持。
5. 将环境和感染预防建议写入孕期教育内容中。

**注意事项 / Precautions**
- 孕期没有明确安全的酒精下限,最好完全避免。
- 被动吸烟同样有害。
- 高危暴露预防需要具体到食物和家庭场景,不能只说“注意卫生”。

**量化指标 / Metrics**
- 孕妇危险暴露教育覆盖率
- 吸烟/饮酒筛查率
- 戒烟支持提供率
