# Skill: 皮疹分布模式分析

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第111章 皮肤问题的诊断和管理方法
- 页码: 第111章“身体检查”“单个病灶特征”“分布或形态分析”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第111章.md`

**目标 / Objective**
结合分布和形态模式快速缩小皮肤病鉴别诊断。

**适用范围 / Scope**
- 需要在门诊进行皮疹临床判断的所有病人

**操作步骤 / Procedure**
1. 在自然光或良好照明下检查全身皮肤,必要时卸妆。
2. 观察皮疹是否对称、局灶、屈侧、伸侧、面部、躯干或掌跖分布。
3. 判断是否呈环状、弓形、钱币状、网状、圣诞树样等典型模式。
4. 结合单个病灶性质推断常见疾病类别,如癣、银屑病、荨麻疹或疥疮。
5. 对不符合常见模式者考虑少见病或非常见表现并转诊。

**注意事项 / Precautions**
- 只看局部而不看全身常导致误诊。
- 分布模式往往比单个病灶更具提示性。
- 化妆、抓挠和继发感染会改变原始外观。

**量化指标 / Metrics**
- 全身皮肤检查完成率
- 分布模式记录率
- 非典型病例转诊率
