# Skill: 皮损原发继发表现分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第111章 皮肤问题的诊断和管理方法
- 页码: 第111章“原发性皮损”“继发性皮损”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第111章.md`

**目标 / Objective**
通过皮损形态学分层提高皮肤病诊断准确率。

**适用范围 / Scope**
- 任何可见皮疹或皮损的临床检查场景

**操作步骤 / Procedure**
1. 先区分病灶是否为斑、丘疹、斑块、结节、水疱或脓疱等原发皮损。
2. 再识别鳞屑、痂、糜烂、溃疡、裂隙、萎缩或苔藓样变等继发表现。
3. 记录颜色、边界、大小和是否隆起。
4. 判断病变主要累及表皮还是真皮,帮助缩小鉴别范围。
5. 将单个皮损形态与整体分布结合,形成工作诊断。

**注意事项 / Precautions**
- 抓痕和苔藓样变常掩盖原始病变。
- 同一疾病可同时存在原发和继发皮损。
- 正确命名皮损是后续沟通、转诊和复查的基础。

**量化指标 / Metrics**
- 皮损形态标准化记录率
- 原发/继发皮损分层率
- 复诊可比性描述率
