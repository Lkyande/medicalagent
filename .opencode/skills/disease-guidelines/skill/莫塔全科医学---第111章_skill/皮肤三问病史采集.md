# Skill: 皮肤三问病史采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第111章 皮肤问题的诊断和管理方法
- 页码: 第111章“病史”“三个基本提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第111章.md`

**目标 / Objective**
用简洁高效的病史框架为皮肤病诊断建立方向。

**适用范围 / Scope**
- 所有新发或复发皮疹、皮损、瘙痒或肿块的皮肤相关就诊

**操作步骤 / Procedure**
1. 先问皮疹在哪里,从哪里开始。
2. 询问皮疹出现和持续了多久,并按急性、亚急性或慢性分组理解。
3. 询问皮疹是否瘙痒及瘙痒程度。
4. 继续追问药物史、接触史、接触者是否有类似皮疹、既往皮肤病和家族史。
5. 根据时间、瘙痒和暴露线索初步缩小到常见七大类皮肤病范围。

**注意事项 / Precautions**
- 药疹必须始终作为早期鉴别之一。
- 严重瘙痒对鉴别诊断价值很高。
- 这些问题是框架起点,不能替代完整临床判断。

**量化指标 / Metrics**
- 皮肤病三问记录率
- 药物史记录率
- 病程分层记录率
