# Skill: 儿童气道呼吸ABCDE评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第89章 儿童急诊
- 页码: 第89章“气道和呼吸”“观察的重要症状和指标”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第89章.md`

**目标 / Objective**
系统评估儿童气道与呼吸功能,尽早发现低氧和阻塞恶化。

**适用范围 / Scope**
- 呼吸困难、喘鸣、哮鸣、发绀或不明状态恶化的儿童

**操作步骤 / Procedure**
1. 检查是否存在气泡音、鼾音或喘鸣等上气道阻塞提示音。
2. 观察呼吸频率、胸壁凹陷、气管牵引、鼻翼扇动和辅助肌使用。
3. 评估氧饱和度并结合临床解释,不要只看仪器数值。
4. 识别发绀、心动过速加重、烦躁或意识下降等继发恶化体征。
5. 一旦发现明显低氧或呼吸衰竭趋势,立即启动氧疗和升级处置。

**注意事项 / Precautions**
- 缺氧可很快诱发心跳骤停。
- SpO2 低于 95% 需关注,低于 92% 更应高度警惕。
- 儿童气道阻塞恶化常先表现为努力呼吸增加。

**量化指标 / Metrics**
- 呼吸困难儿童 ABCDE 评估完整率
- SpO2 记录率
- 低氧病例升级处置时效
