# Skill: 儿童危重征象快速识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第89章 儿童急诊
- 页码: 第89章“严重疾病的征象和症状”“病情危重婴儿的临床特征”“诊治策略”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第89章.md`

**目标 / Objective**
在初诊数分钟内识别需要优先处置或住院的危重儿童。

**适用范围 / Scope**
- 发热、呼吸困难、晕厥、抽搐或状态异常来诊的婴幼儿和儿童

**操作步骤 / Procedure**
1. 观察活动性、警觉性、面色、呼吸功和四肢灌注情况。
2. 重点识别昏睡、面色苍白、胸壁内陷、异常体温和大于 2 cm 肿块等高危标志。
3. 使用 ABCDEFG 或 ABCD 结构快速分层病情。
4. 对存在危险征象者优先检查和治疗,而非按排队顺序等待。
5. 决定是否需要立即住院、急救或进一步检查。

**注意事项 / Precautions**
- 面色苍白、安静和呜咽往往比“高热但精神好”更危险。
- 6 个月以下婴儿需更低阈值警惕严重感染。
- 发热本身不是严重程度唯一指标。

**量化指标 / Metrics**
- 高危儿童首轮分层评估率
- 危重征象识别时效
- 高危患儿优先处置率
