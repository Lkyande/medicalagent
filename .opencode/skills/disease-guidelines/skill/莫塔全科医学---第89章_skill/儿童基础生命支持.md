# Skill: 儿童基础生命支持

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第89章 儿童急诊
- 页码: 第89章“心肺复苏”“指南”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第89章.md`

**目标 / Objective**
在儿童心跳呼吸骤停时实施符合年龄特点的基础生命支持。

**适用范围 / Scope**
- 院前、门诊或基层场景中的儿童心跳呼吸骤停或严重心动过缓

**操作步骤 / Procedure**
1. 检查呼吸和脉搏,必要时清理口咽异物。
2. 进行仰头抬颏或推举下颌开放气道。
3. 给予救援通气,并在无脉或脉搏小于 60 次/分时立即胸外按压。
4. 根据救援人数和场景选择合适的按压通气比例。
5. 按年龄调整按压手法,并尽快进入高级生命支持路径。

**注意事项 / Precautions**
- 儿童骤停多由缺氧引起,不是原发心律失常。
- 年龄越小,按压部位和手法越要精确。
- 若不能插管,需考虑紧急气道替代方案。

**量化指标 / Metrics**
- 儿童骤停 CPR 启动时效
- 年龄适配手法正确率
- 复苏后转入高级生命支持率
