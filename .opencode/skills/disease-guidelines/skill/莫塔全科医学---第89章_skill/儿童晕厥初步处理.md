# Skill: 儿童晕厥初步处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第89章 儿童急诊
- 页码: 第89章“儿童晕厥”“最初基本管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第89章.md`

**目标 / Objective**
在儿童晕厥场景中快速恢复基本生命支持并寻找可逆原因。

**适用范围 / Scope**
- 晕倒、无反应或明显虚脱的儿童和婴儿

**操作步骤 / Procedure**
1. 立即将孩子置于安全侧卧位并清理口鼻咽部分泌物。
2. 同步评估呼吸、脉搏和是否需要心肺复苏。
3. 给予高流量氧气,并尽快建立循环支持和抽血检查。
4. 优先考虑低血糖、低氧、严重感染、呼吸道梗阻和中毒等病因。
5. 在稳定生命体征后进一步按病因方向检查与转运。

**注意事项 / Precautions**
- 氧气和葡萄糖是儿童脑最关键的两个要素。
- 儿童虐待也可能是晕厥原因之一。
- 中枢感染和代谢异常需保持高警惕。

**量化指标 / Metrics**
- 儿童晕厥首轮 ABC 处理率
- 氧疗启动时效
- 低血糖/低氧排查率
