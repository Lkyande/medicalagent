# Skill: 头痛红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第45章 头痛
- 页码: 第45章“头痛的红旗征”“身体检查的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第45章.md`

**目标 / Objective**
快速识别提示蛛网膜下腔出血、脑膜炎、占位性病变或颅压升高的头痛表现。

**适用范围 / Scope**
- 所有急性、亚急性或进行性头痛病人

**操作步骤 / Procedure**
1. 识别突发、首发、剧烈或进行性加重的头痛。
2. 询问发热、呕吐、意识障碍、性格改变和夜间痛醒等伴随表现。
3. 关注弯腰、体位变化、咳嗽或喷嚏是否使头痛加重。
4. 对 >50 岁新发头痛、创伤后头痛和孕产期非偏头痛提高警惕。
5. 查体时重点寻找脑膜刺激征、局灶神经体征、视乳头水肿和颞动脉异常。

**注意事项 / Precautions**
- 红旗征存在时不应先按紧张性头痛或偏头痛经验处理后观察。
- 年轻肥胖女性合并视力下降要考虑颅内压增高。
- 老年新发头痛即使程度不剧烈也要高度重视。

**量化指标 / Metrics**
- 头痛红旗征筛查率
- 紧急神经影像转诊及时率
- 严重继发性头痛漏诊率
