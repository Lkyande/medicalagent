# Skill: 头痛昼夜波动图记录

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第45章 头痛
- 页码: 第45章“疼痛的昼夜波动模式”“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第45章.md`

**目标 / Objective**
利用头痛日内强度变化图帮助区分偏头痛、鼻窦炎、紧张性和混合性头痛。

**适用范围 / Scope**
- 慢性、反复发作或模式不清的头痛病人

**操作步骤 / Procedure**
1. 提供网格或日记模板,让病人记录白天和夜间头痛强度变化。
2. 标注头痛最早出现时间、峰值时间及缓解时间。
3. 同步记录恶心、畏光、鼻部症状、睡眠和用药情况。
4. 分析是否存在晨起型、上午逐渐加重型或恒定重复型模式。
5. 结合病史将结果用于支持偏头痛、额窦炎、紧张性或混合性头痛判断。

**注意事项 / Precautions**
- 多日连续记录比单次回忆更可靠。
- 昼夜模式仅为辅助线索,不能单独决定诊断。
- 必须同时记录止痛药使用,避免漏掉反跳性头痛。

**量化指标 / Metrics**
- 头痛日记完成率
- 昼夜模式可解释率
- 记录后诊断清晰化比例
