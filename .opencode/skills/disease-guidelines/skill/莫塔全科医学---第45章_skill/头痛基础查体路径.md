# Skill: 头痛基础查体路径

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第45章 头痛
- 页码: 第45章“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第45章.md`

**目标 / Objective**
在基层完成覆盖血压、脑膜刺激征、眼底和颈源因素的系统头痛查体。

**适用范围 / Scope**
- 需要进行初始体格评估的头痛病人

**操作步骤 / Procedure**
1. 测量生命体征,尤其是血压和体温。
2. 视诊头部、眼和颞动脉,并触诊面部、颈部肌肉、颈椎、鼻窦、牙齿和颞下颌关节。
3. 检查脑膜刺激征和视神经乳头水肿。
4. 完成精神状态和神经系统检查,包括视野、瞳孔、眼球运动及肢体感觉运动。
5. 对可疑颈源性头痛者重点触诊 C2 和 C3 区域并评估是否可诱发熟悉疼痛。

**注意事项 / Precautions**
- 对诉头痛病人未测血压是常见错误。
- 详细查体应优先于无指向的大量辅助检查。
- 颞动脉压痛或搏动减弱提示需尽快评估颞动脉炎。

**量化指标 / Metrics**
- 头痛基础查体完成率
- 视乳头水肿检查记录率
- 颈源性头痛识别率
