# Skill: 头痛时间轴分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第45章 头痛
- 页码: 第45章“头面部疼痛原因的时间轴”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第45章.md`

**目标 / Objective**
依据头痛的起病节奏和病程模式缩小原发性与继发性病因范围。

**适用范围 / Scope**
- 初诊或反复就诊但病因未明的头痛病人

**操作步骤 / Procedure**
1. 先将头痛归类为急性剧烈、亚急性进展、反复发作或慢性持续。
2. 对急性剧烈头痛优先考虑 SAH、偏头痛或劳累性交后头痛等。
3. 对亚急性逐渐增强的头痛重点排查占位性病变和颞动脉炎。
4. 对反复发作型考虑偏头痛、丛集性头痛和神经痛。
5. 对慢性头痛评估紧张性头痛、慢性偏头痛、反跳性头痛和颈源性头痛。

**注意事项 / Precautions**
- 时间进程是识别险恶头痛最重要的指标之一。
- 同一病人可有混合性头痛,不能因符合一种模式就停止排查其他因素。
- 病程分层要与红旗征和查体结果结合解释。

**量化指标 / Metrics**
- 头痛病程分类记录率
- 病程模式与最终诊断一致率
- 继发性头痛早期识别率
