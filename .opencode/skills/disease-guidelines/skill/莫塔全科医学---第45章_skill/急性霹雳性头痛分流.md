# Skill: 急性霹雳性头痛分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第45章 头痛
- 页码: 第45章“急性霹雳性头痛”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第45章.md`

**目标 / Objective**
将突发剧烈头痛快速分流到蛛网膜下腔出血和其他脑血管急症评估路径。

**适用范围 / Scope**
- 突然达到高峰、首发或“最严重一次”的急性头痛病人

**操作步骤 / Procedure**
1. 将霹雳性头痛首先视作可能的脑血管急症。
2. 评估是否伴枕部起病、全颅扩散、颈部不适、发热或神经系统症状。
3. 同时考虑 SAH、可逆性脑血管收缩、动脉夹层和脑膜炎等病因。
4. 紧急安排非增强 CT 作为首选影像检查。
5. 当 CT 阴性但仍高度怀疑 SAH 或脑膜炎时,继续衔接腰椎穿刺等进一步评估。

**注意事项 / Precautions**
- 不要将首发霹雳性头痛简单归因于偏头痛。
- 影像和穿刺顺序应围绕急诊安全性和颅压风险判断。
- 镇痛不能替代对病因的紧急排查。

**量化指标 / Metrics**
- 霹雳性头痛急诊 CT 完成率
- SAH 高危病例识别率
- 霹雳性头痛误诊延误率
