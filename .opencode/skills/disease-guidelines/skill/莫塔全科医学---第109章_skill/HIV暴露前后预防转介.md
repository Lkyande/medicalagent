# Skill: HIV暴露前后预防转介

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第109章 性传播感染
- 页码: 第109章“HIV 感染”“暴露前预防和接触后预防”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第109章.md`

**目标 / Objective**
对 HIV 高风险暴露者及时识别并转入 PrEP 或 PEP 路径。

**适用范围 / Scope**
- 有高风险性暴露或持续高风险性行为的个体

**操作步骤 / Procedure**
1. 评估暴露类型、时间和 HIV 风险背景。
2. 对近期高风险暴露立即评估 PEP 时窗和转介可行性。
3. 对持续高风险行为者讨论 PrEP 适应证和随访框架。
4. 同步安排基线 STI/HIV 检测和安全套教育。
5. 记录并随访后续检测与依从性。

**注意事项 / Precautions**
- PEP 是时间敏感干预。
- PrEP 不是替代 STI 筛查和安全套教育。
- 高风险病人常合并其他 STI 需要一起处理。

**量化指标 / Metrics**
- 高风险暴露 PEP 转介时效
- PrEP 咨询率
- 基线 HIV/STI 检测完成率
