# Skill: 男性尿道炎经验处理

- 文章标题: 莫塔全科医学（第8版） 第109章 性传播感染
- 页码: 第109章“男性尿道炎”“诊断”“管理原则”“衣原体感染”“淋病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第109章.md`

**目标 / Objective**
对男性尿道炎进行初步病原判断、样本采集和经验性治疗。

**适用范围 / Scope**
- 出现排尿痛、尿道分泌物或相关 STI 暴露的男性

**操作步骤 / Procedure**
1. 询问分泌物、潜伏期、性暴露和并发睾丸附睾疼痛情况。
2. 采集初尿和必要拭子进行 NAAT/PCR 检测衣原体、淋病和支原体。
3. 在等待结果时按高概率病原给予经验治疗。
4. 说明禁欲、伴侣通知和复检安排。
5. 对持续症状或治疗失败者重新评估耐药和其他病原体。

**注意事项 / Precautions**
- 男性尿道炎最常见病原是衣原体和淋球菌。
- 初尿样本很关键。
- 治疗必须伴随接触者管理和行为指导。

**量化指标 / Metrics**
- 男性尿道炎 NAAT 采样率
- 经验治疗及时率
- 接触者告知完成率
