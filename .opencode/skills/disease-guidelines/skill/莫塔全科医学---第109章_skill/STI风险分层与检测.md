# Skill: STI风险分层与检测

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第109章 性传播感染
- 页码: 第109章“谁处于 STI 的风险中”“对无症状 STI 的检测”“采集性活动史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第109章.md`

**目标 / Objective**
根据性暴露和症状风险分层选择 STI 检测策略。

**适用范围 / Scope**
- 有无症状但存在性暴露风险,或主诉尿道炎、分泌物、溃疡等的病人

**操作步骤 / Procedure**
1. 采集明确的性活动史,包括伴侣数、性行为方式和暴露时间。
2. 区分无症状筛查、暴露后检测和症状性检测三类路径。
3. 按暴露部位选择尿样、拭子或血清学检测。
4. 对高风险或暴露后病人安排适当时点复检。
5. 同步进行咨询、避孕套教育和接触者管理准备。

**注意事项 / Precautions**
- 风险评估比“有没有症状”更重要。
- 检测窗口期会影响结果解释。
- 采样部位必须与性行为部位匹配。

**量化指标 / Metrics**
- STI 风险分层记录率
- 合适样本采集率
- 暴露后复检完成率
