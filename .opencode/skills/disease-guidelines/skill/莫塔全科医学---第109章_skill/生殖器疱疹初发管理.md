# Skill: 生殖器疱疹初发管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第109章 性传播感染
- 页码: 第109章“生殖器疱疹”“样本采集”“治疗”“支持性治疗”“咨询”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第109章.md`

**目标 / Objective**
识别首次发作的生殖器疱疹并尽早启动抗病毒和支持治疗。

**适用范围 / Scope**
- 出现肛门生殖器溃疡、疼痛性疱疹或相关全身症状的男性和女性

**操作步骤 / Procedure**
1. 识别疼痛性溃疡、水疱和首发全身不适等表现。
2. 尽早采集病损样本进行病毒检测。
3. 在症状开始早期尽快启动口服抗病毒治疗。
4. 提供局部疼痛缓解和日常护理建议。
5. 进行关于复发、传播风险和伴侣沟通的咨询。

**注意事项 / Precautions**
- 早期抗病毒治疗获益最大。
- 疱疹是一种长期管理问题,不只是一次性处方。
- 咨询和支持与药物治疗同等重要。

**量化指标 / Metrics**
- 初发疱疹样本采集率
- 24 小时内抗病毒启动率
- 复发和传播教育完成率
