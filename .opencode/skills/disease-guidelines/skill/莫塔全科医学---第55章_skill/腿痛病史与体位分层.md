# Skill: 腿痛病史与体位分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第55章 腿部疼痛
- 页码: 第55章“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第55章.md`

**目标 / Objective**
通过疼痛发作方式、体位关系和行走模式快速区分机械性、血管性和神经性腿痛。

**适用范围 / Scope**
- 门急诊各种急性或慢性腿部疼痛病人

**操作步骤 / Procedure**
1. 判断疼痛是急性还是慢性,并追问是否由外伤、活动或自发发生。
2. 询问疼痛是否随腿部活动、姿势或负重变化而改变。
3. 分析坐位、站位、卧位和侧卧位对疼痛的影响,分别指向脊柱、静脉、血管或大转子来源。
4. 明确疼痛是否与行走相关,以及是立即发作还是延迟出现。
5. 结合深部骨痛、关节痛或非对应外伤部位疼痛,补查脊柱、髋关节和腹部来源。

**注意事项 / Precautions**
- 神经根痛可以没有背痛,不能因无腰痛就排除脊柱来源。
- 髋关节病变可仅表现为膝周疼痛,病史要主动追问。
- 与活动无关的持续剧痛需提高血管或骨肿瘤警惕。

**量化指标 / Metrics**
- 腿痛标准病史完整率
- 体位诱发因素记录率
- 首诊病因分层准确率
