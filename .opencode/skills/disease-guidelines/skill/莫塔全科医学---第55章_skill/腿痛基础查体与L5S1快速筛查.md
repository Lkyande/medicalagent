# Skill: 腿痛基础查体与L5S1快速筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第55章 腿部疼痛
- 页码: 第55章“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第55章.md`

**目标 / Objective**
通过局部、血管和神经系统查体快速定位常见腿痛来源并筛查 L5 与 S1 根性受累。

**适用范围 / Scope**
- 需要门诊快速分流的腿部疼痛病人

**操作步骤 / Procedure**
1. 先观察步态并判断是否存在跛行或疼痛回避动作。
2. 检查站姿、皮色、溃疡、静脉、肿胀、双腿对称性和足部缺血改变。
3. 触诊坐骨结节、股骨大转子、筋膜和肌腱,并补查脊柱与髋关节。
4. 完成血管检查,包括皮温、周围脉搏和静脉状态,必要时听诊腹股沟及腘区血管。
5. 快速测试 L5 的趾背屈与 S1 的踮脚行走能力,筛查常见根性功能缺损。

**注意事项 / Precautions**
- 没有明显局部体征时,不要停在“肌肉痛”结论上,需回查脊柱和血管。
- 足部温度和脉搏对鉴别急慢性缺血非常重要。
- L5 与 S1 功能筛查适合快速分流,异常时应补充完整神经查体。

**量化指标 / Metrics**
- 腿痛基础查体完成率
- L5/S1 功能记录率
- 血管性病因识别率
