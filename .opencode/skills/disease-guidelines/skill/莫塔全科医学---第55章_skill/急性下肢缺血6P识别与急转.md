# Skill: 急性下肢缺血6P识别与急转

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第55章 腿部疼痛
- 页码: 第55章“急性下肢缺血”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第55章.md`

**目标 / Objective**
尽早识别急性下肢动脉闭塞并在保肢时间窗内完成紧急分流。

**适用范围 / Scope**
- 突发严重腿痛、足痛或肢体发冷的病人

**操作步骤 / Procedure**
1. 对突发剧烈腿痛立即评估 6P:疼痛、苍白、感觉异常、无脉搏、瘫痪和肢体冰冷。
2. 检查浅静脉是否塌陷、毛细血管回流是否延迟以及足部颜色是否转暗紫。
3. 触诊股、腘、胫后和足背动脉,同时寻找心房颤动等栓塞来源线索。
4. 将发病时间作为关键记录项,以 4 小时内治疗为最佳保肢目标。
5. 立即联系血管外科或急诊转运,不要以止痛后短暂缓解误判病情改善。

**注意事项 / Precautions**
- 超过 6 小时通常显著增加不可逆坏死和截肢风险。
- 瘫痪和肌筋膜室痛是严重缺血的重要晚期征象。
- 急性肢体缺血短期内未必直接致命,但延误会直接损害肢体预后。

**量化指标 / Metrics**
- 急性缺血识别率
- 发病到血管外科评估时间
- 保肢率
