# Skill: 感觉异常性股痛识别与处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第55章 腿部疼痛
- 页码: 第55章“感觉异常性股痛”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第55章.md`

**目标 / Objective**
识别股外侧皮神经卡压所致的大腿外侧灼痛并实施针对病因的保守处理。

**适用范围 / Scope**
- 大腿外侧局限性烧灼痛、麻木或刺痛的成人病人

**操作步骤 / Procedure**
1. 确认疼痛局限于大腿外侧,且不越过中线。
2. 追问肥胖、妊娠、腹水、局部外伤以及腰带、束身或紧身衣压迫史。
3. 与 L2/L3 神经根痛和股神经病变做分布范围鉴别。
4. 优先实施减重、去除压迫衣物和局部负荷控制。
5. 症状持续时可在髂前上棘内侧腹股沟韧带下方考虑类固醇注射,难治者转诊神经松解。

**注意事项 / Precautions**
- 这是感觉神经病变,通常不出现明显肌力下降。
- 很多病例可自行缓解,需做好释疑避免过度检查。
- 分布越过中线时要回头考虑其他神经源性病因。

**量化指标 / Metrics**
- 感觉异常性股痛识别率
- 压迫因素去除率
- 症状缓解率
