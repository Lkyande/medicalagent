# Skill: 神经源性与血管性跛行鉴别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第55章 腿部疼痛
- 页码: 第55章“表55.2 神经源性和血管性跛行的临床特征比较”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第55章.md`

**目标 / Objective**
依据诱发方式、缓解特点和伴随体征快速区分神经源性与血管性跛行。

**适用范围 / Scope**
- 50 岁以上行走后出现腿痛、麻木或无力的病人

**操作步骤 / Procedure**
1. 询问疼痛起始部位,近端臀腿开始更支持神经源性,远端小腿开始更支持血管性。
2. 询问疼痛性质,烧灼麻木更偏神经源性,痉挛挤压痛更偏血管性。
3. 记录诱发距离和情境,固定步行距离诱发更支持血管性跛行。
4. 询问缓解方式,弯腰或蹲姿缓解更支持神经源性,站立休息快速缓解更支持血管性。
5. 结合外围脉搏、运动后反射变化、腹部或股动脉杂音及肠膀胱症状完成分流。

**注意事项 / Precautions**
- 老年人可同时存在椎管狭窄与闭塞性动脉病,不要强行单选一种病因。
- 阳痿与近端血管阻塞并存时要想到主髂动脉闭塞。
- 将闭塞性动脉疾病误判为坐骨神经痛是常见错误。

**量化指标 / Metrics**
- 跛行分型记录率
- 血管与神经影像检查适配率
- 误分流率
