# Skill: 以病人为中心诊疗实施

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第1章 全科医学的性质、范围和内容
- 页码: 第1章“对病人管理的整体方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第1章.md`

**目标 / Objective**
通过系统探索病人的想法、感受和期望,把疾病管理方案建立在医患共同理解基础上。

**适用范围 / Scope**
- 需要提升沟通质量和依从性的全科诊疗场景
- 初诊、慢病复诊及病情反复不清的病人

**操作步骤 / Procedure**
1. 同时探索疾病过程和病人的生病体验,分别记录医学问题与主观困扰。
2. 询问病人对疾病原因、严重程度和结局的理解。
3. 结合家庭、关系、工作和生活方式信息,理解“整体人”背景。
4. 与病人讨论诊疗优先级,寻找双方对管理方案的共识点。
5. 在本次处理里加入预防与健康促进内容,而不局限于当下症状。
6. 根据门诊时间和可用资源,形成现实可执行的近期计划与随访安排。

**注意事项 / Precautions**
- 共识不等于迎合病人要求,遇到不合理诉求仍需坚持医学原则。
- 对表达能力受限者,应适当简化语言并重复确认理解程度。
- 对青少年、精神心理问题病人或家庭暴力风险者,需注意隐私与安全边界。

**量化指标 / Metrics**
- 病人想法/关注/期望记录完成率
- 共同决策项目数
- 病人对诊疗解释的复述正确率
