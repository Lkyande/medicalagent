# Skill: 疾病危机中的家庭参与

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第1章 全科医学的性质、范围和内容
- 页码: 第1章“处于危机的家庭”“给医生的建议”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第1章.md`

**目标 / Objective**
在严重疾病或长期病程中尽早把家庭纳入照护过程,降低家庭危机对病人和照护结局的负面影响。

**适用范围 / Scope**
- 急性重病、长期慢病、出院过渡期或家庭受疾病显著冲击的病人

**操作步骤 / Procedure**
1. 从疾病急性期开始识别关键家庭成员和主要照护者。
2. 尽早邀请家庭参与沟通,必要时组织家庭会议。
3. 在持续病程中反复评估家庭成员态度变化,特别关注愤怒、抱怨和照护疲惫。
4. 将家庭纳入出院计划,明确照护分工、警示症状和复诊安排。
5. 如发现家庭动态明显恶化或照护系统失衡,及时转介相关专家或支持资源。
6. 在关键节点再次召开家庭会议,重新校准目标和责任。

**注意事项 / Precautions**
- 家庭参与不能替代病人自主决定,需优先尊重病人意愿和知情同意。
- 对未成年人、认知障碍者或失能病人,要同时保护其权益与安全。
- 存在家庭暴力、虐待或严重冲突风险时,不宜简单扩大家庭参与,应先做安全评估。

**量化指标 / Metrics**
- 家庭会议召开次数
- 出院计划中家庭任务明确率
- 再入院或照护中断发生率
