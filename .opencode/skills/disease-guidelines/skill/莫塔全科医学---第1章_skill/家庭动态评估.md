# Skill: 家庭动态评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第1章 全科医学的性质、范围和内容
- 页码: 第1章“如何评估家庭动态”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第1章.md`

**目标 / Objective**
通过结构化观察和会谈评估家庭成员互动模式,明确其对病人症状和管理的影响。

**适用范围 / Scope**
- 怀疑家庭关系、照护模式或社会心理压力影响健康结局的病人

**操作步骤 / Procedure**
1. 在诊室内观察家庭成员之间的交流方式、主导者和回避模式。
2. 条件允许时邀请全体关键家庭成员参加联合咨询。
3. 询问工作、家庭结构和性关系等可能导致功能失调的压力源。
4. 在必要时安排家访,观察自然环境中的互动与照护分工。
5. 记录与症状相关的主要外部压力和内部心理社会因素。
6. 根据评估结果判断是否需要持续家庭介入或转介。

**注意事项 / Precautions**
- 家庭联合会谈前应确认病人是否同意共享相关信息。
- 讨论性关系、家庭冲突或心理压力时要保护隐私并避免羞辱式提问。
- 对潜在暴力或强控制关系,不宜在所有家庭成员同时在场时直接暴露敏感信息。

**量化指标 / Metrics**
- 家庭动态关键要素记录完整率
- 识别出的主要压力源数量
- 家庭因素纳入管理计划的比例
