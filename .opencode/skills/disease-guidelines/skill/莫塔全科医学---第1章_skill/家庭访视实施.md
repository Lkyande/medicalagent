# Skill: 家庭访视实施

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第1章 全科医学的性质、范围和内容
- 页码: 第1章“家庭访视”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第1章.md`

**目标 / Objective**
通过居家场景观察补充门诊信息,了解家庭内部动态,增强连续性照护与医患关系。

**适用范围 / Scope**
- 行动不便、长期照护或家庭因素明显影响疾病管理的病人
- 需要了解居家照护能力和家庭支持结构的情况

**操作步骤 / Procedure**
1. 明确访视目的,重点放在了解家庭动态、照护环境和治疗执行情况。
2. 到达家庭环境后,观察病人与家属互动、居住条件和照护资源。
3. 询问主要照护者对疾病的理解、困难和支持需求。
4. 核对药物、随访、生活方式建议在家庭中的实际执行情况。
5. 识别影响治疗的家庭冲突、照护负担或环境障碍。
6. 访视后把关键信息纳入后续门诊管理和随访计划。

**注意事项 / Precautions**
- 家访应尊重病人和家庭隐私,避免超出医疗目的的介入。
- 对高风险家庭环境,应优先考虑人员安全和必要的多学科支持。
- 对认知障碍老人、儿童和姑息照护病人,需重点评估照护者能力与负担。

**量化指标 / Metrics**
- 家访后新增关键问题识别数
- 居家治疗执行偏差纠正率
- 访视后计划随访完成率
