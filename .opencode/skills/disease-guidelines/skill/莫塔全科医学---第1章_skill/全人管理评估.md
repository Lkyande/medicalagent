# Skill: 全人管理评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第1章 全科医学的性质、范围和内容
- 页码: 第1章“对病人管理的整体方法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第1章.md`

**目标 / Objective**
在常规疾病诊断之外同步纳入病人的心理、家庭、工作和环境因素,形成可执行的全人管理判断。

**适用范围 / Scope**
- 全科门诊首诊或复诊病人
- 症状复杂、反复就诊或单纯生物医学解释不足的情形

**操作步骤 / Procedure**
1. 先完成以疾病为中心的评估,依据病史、体格检查和必要辅助检查明确主要临床问题。
2. 追加以病人为中心的评估,询问病人本人感受、情绪反应和对疾病的理解。
3. 评估家庭因素,了解家庭结构、支持情况及疾病对家庭成员的影响。
4. 评估工作、休闲、生活方式和居住环境,识别持续诱因或康复障碍。
5. 区分“疾病过程”和“生病体验”,避免只给出病理诊断而忽略受苦体验。
6. 与病人就管理重点达成共识,把治疗、预防和健康促进一并纳入计划。

**注意事项 / Precautions**
- 不可用社会心理解释替代必要的器质性疾病排查。
- 对情绪反应强烈、家庭冲突明显或存在安全风险者,需提高随访频率。
- 对老年人、儿童、孕产妇和长期慢病患者,需额外关注照护者和家庭支持系统。

**量化指标 / Metrics**
- 完整记录的生物-心理-社会评估要素数
- 医患共同确认的管理目标数
- 随访中症状改善与依从性变化
