# Skill: 家庭功能失调识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第1章 全科医学的性质、范围和内容
- 页码: 第1章“家庭功能失调的重要表现”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第1章.md`

**目标 / Objective**
在全科接诊中尽早识别可能由家庭因素驱动或加重的健康问题,触发进一步家庭评估。

**适用范围 / Scope**
- 反复就诊、症状多样、精神心理症状明显或怀疑家庭冲突的病人

**操作步骤 / Procedure**
1. 在常规问诊中筛查婚姻/性关系困难、儿童异常行为和长期焦虑失眠等提示信号。
2. 关注多个家庭成员就诊并陈述多种症状的模式,识别潜在家庭系统问题。
3. 询问物质滥用、妊娠或产后异常行为以及精神障碍病史。
4. 对虐待或暴力线索进行更深入但保护性的评估。
5. 一旦怀疑家庭功能失调,把“家庭因素”加入问题清单并安排进一步评估。
6. 根据风险程度决定随访、家访、家庭会议或转介支持服务。

**注意事项 / Precautions**
- 怀疑虐待、家暴或儿童受害时,应优先保障安全并遵循报告规范。
- 不要仅凭单一症状给家庭贴标签,需结合多来源信息判断。
- 对孕产妇、儿童青少年和严重精神障碍病人,需提高筛查敏感度。

**量化指标 / Metrics**
- 家庭风险线索筛查完成率
- 识别后进入进一步评估的比例
- 高风险个案安全干预启动率
