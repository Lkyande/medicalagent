# Skill: 家系图绘制与应用

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第1章 全科医学的性质、范围和内容
- 页码: 第1章“家系图”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第1章.md`

**目标 / Objective**
利用三代家系图可视化家庭结构和关系,辅助理解家庭动态及其对健康问题的影响。

**适用范围 / Scope**
- 需要分析遗传背景、家庭结构、照护关系或长期心理社会问题的病人

**操作步骤 / Procedure**
1. 以病人为中心,收集至少三代家庭成员的基本结构信息。
2. 使用统一符号绘制家庭树,标注成员关系、同住情况和关键事件。
3. 在图中补充重要互动关系,如亲密、冲突、疏离或照护依赖。
4. 结合当前主诉,识别与疾病管理相关的家庭模式或风险点。
5. 与病人或家属一起回顾家系图,核实信息并促进反思。
6. 在后续随访中持续更新家系图,作为长期管理参考。

**注意事项 / Precautions**
- 绘制前需说明用途并获得病人同意,避免不必要暴露家族隐私。
- 对非传统家庭结构应使用中性、尊重的记录方式。
- 家系图是辅助工具,不能替代对个体风险和症状的独立评估。

**量化指标 / Metrics**
- 三代信息完整率
- 关键关系事件标注完整率
- 家系图辅助识别管理问题的次数
