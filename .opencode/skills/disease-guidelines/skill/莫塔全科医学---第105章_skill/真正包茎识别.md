# Skill: 真正包茎识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第105章 阴茎疾病
- 页码: 第105章“包茎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第105章.md`

**目标 / Objective**
区分正常年龄相关包皮不可回缩与需要治疗的真正包茎。

**适用范围 / Scope**
- 婴幼儿、男童、青少年及成人因包皮问题就诊时

**操作步骤 / Procedure**
1. 结合年龄判断包皮不可回缩是否仍在正常发育范围内。
2. 识别真正包茎信号,如瘢痕环、针孔样开口、喷射尿流和既往可回缩后再次不能回缩。
3. 询问是否有反复炎症、排尿困难或性生活相关问题。
4. 对炎性包茎先进行局部类固醇乳膏试验治疗。
5. 对瘢痕明显或保守治疗失败者转介包皮环切或进一步处理评估。

**注意事项 / Precautions**
- 在自然分离前不应强行回缩包皮。
- 多数儿童包皮不可回缩属正常生理现象。
- 需同时教育日常包皮清洁和回位方法。

**量化指标 / Metrics**
- 包茎类型正确分层率
- 局部类固醇保守治疗率
- 不必要包皮环切避免率
