# Skill: 包皮卫生指导

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第105章 阴茎疾病
- 页码: 第105章“包皮的清洁卫生”“给病人的指导”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第105章.md`

**目标 / Objective**
指导男童和男性进行安全、温和的包皮清洁,减少炎症和误操作并发症。

**适用范围 / Scope**
- 包皮已可自然回缩的男童、青少年和成人

**操作步骤 / Procedure**
1. 强调包皮只应由本人或专业人员回缩。
2. 在淋浴或盆浴时轻轻向后滑动包皮。
3. 用肥皂和水清洗龟头和包皮内侧后充分冲净。
4. 擦干后将包皮复位覆盖龟头。
5. 对有炎症倾向者强化排尿和清洗后的复位习惯。

**注意事项 / Precautions**
- 不应强行回缩包皮。
- 忘记将包皮复位可能诱发嵌顿包茎。
- 包皮垢珍珠是正常现象,无需治疗。

**量化指标 / Metrics**
- 卫生指导覆盖率
- 嵌顿包茎复发率
- 因包皮卫生不良引发炎症比例
