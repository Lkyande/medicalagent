# Skill: 嵌顿包茎紧急复位

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第105章 阴茎疾病
- 页码: 第105章“嵌顿包茎”“管理”“方法1-4”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第105章.md`

**目标 / Objective**
对嵌顿包茎进行及时减压和复位,防止持续缺血和坏死。

**适用范围 / Scope**
- 包皮回缩后卡在冠状沟远端、阴茎头及远端包皮肿胀疼痛的男童和男性

**操作步骤 / Procedure**
1. 迅速识别包皮收缩环和远端肿胀,确认属于急症。
2. 先用持续挤压方式减轻水肿,配合润滑进行手法复位。
3. 复位成功后立即进行包皮护理教育,避免再次发生。
4. 若手法失败,紧急转诊行背侧切开或其他减压处理。
5. 复位后再评估是否存在真正包茎并讨论后续手术需要。

**注意事项 / Precautions**
- 不要使用冰。
- 手法复位失败不能拖延观察。
- 单次嵌顿包茎发作不等于绝对需要立即环切,但需后续评估。

**量化指标 / Metrics**
- 嵌顿包茎复位成功率
- 紧急转诊时效
- 复发预防教育覆盖率
