# Skill: 阴茎头炎病因分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第105章 阴茎疾病
- 页码: 第105章“阴茎头炎”“治疗”“干燥闭塞性阴茎头炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第105章.md`

**目标 / Objective**
根据临床表现和风险因素区分感染性、炎症性和癌前性阴茎头炎。

**适用范围 / Scope**
- 阴茎头红斑、疼痛、瘙痒、分泌物或包皮炎的男性

**操作步骤 / Procedure**
1. 询问卫生习惯、糖尿病、HIV、性暴露和局部刺激物因素。
2. 观察是念珠菌样红斑、脓性分泌物、苔藓硬化还是可疑癌前病变表现。
3. 必要时取拭子进行培养或 STI 相关检测。
4. 轻症炎症性病例用清洁、保湿和低效激素处理,念珠菌用抗真菌方案。
5. 对细菌性重症、反复发作或 BXO/癌前病变可疑者升级转诊。

**注意事项 / Precautions**
- 阴茎头炎是一个临床综合征,不是单一病因。
- 糖尿病和 HIV 是重要诱因,不能忽略。
- 持续苍白瘢痕增厚要考虑 BXO。

**量化指标 / Metrics**
- 阴茎头炎病因分层记录率
- 诱因筛查率
- 复发病例专科转介率
