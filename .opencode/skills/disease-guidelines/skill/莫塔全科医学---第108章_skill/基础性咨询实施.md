# Skill: 基础性咨询实施

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第108章 性健康
- 页码: 第108章“基本的性咨询”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第108章.md`

**目标 / Objective**
在全科场景中提供基础性咨询,改善性健康沟通和初步干预效果。

**适用范围 / Scope**
- 性关系困扰、性功能障碍或对性行为感到焦虑的病人或伴侣

**操作步骤 / Procedure**
1. 肯定病人愿意讨论性问题的行为,降低羞耻感。
2. 解释性反应和性功能可能受关系、健康和药物共同影响。
3. 与病人或伴侣共同设定现实目标,如改善沟通、减少疼痛或减轻焦虑。
4. 提供简单教育、建议和可尝试的行为策略。
5. 对复杂、创伤相关或持续障碍转介专业性治疗。

**注意事项 / Precautions**
- 医生的态度会直接影响病人是否继续披露。
- 避免把所有问题都简化为“心理作用”。
- 若伴暴力或性侵犯背景,需转入安全与创伤知情路径。

**量化指标 / Metrics**
- 性咨询实施率
- 伴侣共同参与率
- 转介专业性治疗率
