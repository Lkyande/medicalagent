# Skill: 性功能障碍共病排查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第108章 性健康
- 页码: 第108章“疾病对性功能的影响”“影响性兴奋和性功能的药物”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第108章.md`

**目标 / Objective**
识别导致性功能障碍的躯体疾病和药物因素。

**适用范围 / Scope**
- 男性或女性出现性欲低下、勃起障碍、性交痛、高潮障碍等问题时

**操作步骤 / Procedure**
1. 回顾心血管、神经、肌骨、肾、肝胆、妇科和结直肠疾病史。
2. 核对抗雄激素、精神科药物、降压药、酒精和其他影响性功能药物。
3. 根据症状选择身体检查和基础实验室评估。
4. 区分原发关系/心理因素与继发躯体病因。
5. 优先处理可逆共病或药物调整需求。

**注意事项 / Precautions**
- 药物和慢病是常被忽略的性问题根源。
- 躯体和心理因素常并存,不应二选一。
- 仅针对症状开药而不评估共病,容易失败。

**量化指标 / Metrics**
- 性功能障碍病人的共病筛查率
- 用药核对率
- 可逆病因纠正率
