# Skill: 性生活史采集

- 页码: 第108章“采集性生活史”“针对可疑的性问题作出的提问”“性关系史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第108章.md`

**目标 / Objective**
以尊重和非评判方式采集完整性生活史,支持性健康和功能障碍评估。

**适用范围 / Scope**
- 性功能问题、关系困扰、STI 风险或相关躯体主诉就诊者

**操作步骤 / Procedure**
1. 在适当隐私环境下说明提问目的并获得病人接受。
2. 询问伴侣关系、性欲、勃起/润滑、高潮、疼痛和满意度。
3. 回顾性活动方式、频率、避孕和 STI 风险。
4. 探讨关系质量、压力、创伤史和情绪问题。
5. 将性生活史与疾病、药物和体检发现整合解释。

**注意事项 / Precautions**
- 清晰、直接但不冒犯的语言最重要。
- 病人可能以躯体症状而非“性问题”主诉就诊。
- 医生应避免回避或尴尬,否则会中断信息获取。

**量化指标 / Metrics**
- 性问题就诊性生活史记录率
- STI 风险评估率
- 关系/心理因素识别率
