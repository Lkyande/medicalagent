# Skill: 慢性心衰临床识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第76章 慢性心力衰竭
- 页码: 第76章“诊断”“主要症状”“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第76章.md`

**目标 / Objective**
根据典型症状和体征尽早识别慢性心力衰竭并区分左、右心衰表现。

**适用范围 / Scope**
- 出现劳力性呼吸困难、端坐呼吸、水肿、疲劳或体重改变的中老年病人

**操作步骤 / Procedure**
1. 询问呼吸困难是否按劳力性、静息性、端坐呼吸和夜间阵发性呼吸困难逐步进展。
2. 记录干咳、疲劳、踝水肿、腹胀、头晕和晕厥等症状。
3. 查找左心衰体征,如湿啰音、第三心音、心尖移位和外周灌注差。
4. 查找右心衰体征,如颈静脉压升高、肝大、踝部水肿和腹水。
5. 对疑似心衰者安排超声心动图和基础检查,尽快确认病型。

**注意事项 / Precautions**
- 久坐生活方式可掩盖早期症状。
- 左心衰干咳可被误认为哮喘、支气管炎或 ACEI 咳嗽。
- 初期体检可能并不明显,需结合病史综合判断。

**量化指标 / Metrics**
- 可疑心衰病人的典型症状记录率
- 左右心衰体征检查完成率
- 首诊后超声心动图完成率
