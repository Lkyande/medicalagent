# Skill: 慢性心衰利尿与体重监测

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第76章 慢性心力衰竭
- 页码: 第76章“心力衰竭的初始治疗”“常见的非药物管理”“慢性心力衰竭管理的误区”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第76章.md`

**目标 / Objective**
在液体超负荷心衰病人中合理使用利尿剂并防止过度脱水和电解质紊乱。

**适用范围 / Scope**
- 存在踝水肿、肺充血、体重增加或其他液体潴留表现的心衰病人

**操作步骤 / Procedure**
1. 确认存在液体潴留证据后再启动或加强利尿剂治疗。
2. 按病情选择袢利尿剂或轻度病人可用噻嗪类,必要时加醛固酮拮抗剂。
3. 与 ACEI 等基础治疗联合使用,避免把利尿剂作为唯一长期方案。
4. 指导病人每日称重、限制盐摄入,晚期者必要时限水。
5. 密切复查体重、症状、肾功能和电解质,防止过度利尿。

**注意事项 / Precautions**
- 过度使用利尿剂是心衰管理常见误区。
- 利尿剂在液体超负荷时有效,但不能替代改善预后的基础药物。
- ACEI 或 ARB 联合螺内酯时需特别监测高钾风险。

**量化指标 / Metrics**
- 心衰液体超负荷病人的每日体重记录率
- 利尿后肾功能/电解质复查率
- 过度利尿不良事件发生率
