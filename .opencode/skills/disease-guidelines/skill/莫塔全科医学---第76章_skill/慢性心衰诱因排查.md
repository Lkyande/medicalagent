# Skill: 慢性心衰诱因排查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第76章 慢性心力衰竭
- 页码: 第76章“治疗病因和诱发因素”“表76.2 可加重 CHF 的药物”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第76章.md`

**目标 / Objective**
识别导致慢性心衰失代偿或反复恶化的可逆诱因并及时纠正。

**适用范围 / Scope**
- 心衰新发恶化、液体潴留反复或疗效不佳的病人

**操作步骤 / Procedure**
1. 排查心律失常、心肌缺血、感染、贫血和甲状腺异常。
2. 核查饮食中盐和酒精摄入是否增加,以及依从性是否下降。
3. 复核所有处方、非处方和补充医学用药,尤其 NSAIDs、类固醇和部分抗心律失常药。
4. 检查电解质紊乱和肾功能变化是否促成失代偿。
5. 针对已识别诱因逐项干预,并调整后续监测频率。

**注意事项 / Precautions**
- 未纠正诱因会削弱标准药物治疗效果。
- 药物相关水肿和恶化极常见,需主动复核。
- 轻微感染和房颤也可能触发明显失代偿。

**量化指标 / Metrics**
- 心衰恶化病人的诱因排查完整率
- 药物复核率
- 纠正诱因后再入院率
