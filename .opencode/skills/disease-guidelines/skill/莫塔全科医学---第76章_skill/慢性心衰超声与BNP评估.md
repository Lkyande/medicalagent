# Skill: 慢性心衰超声与BNP评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第76章 慢性心力衰竭
- 页码: 第76章“辅助检查”“外周标记物”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第76章.md`

**目标 / Objective**
用超声心动图和关键实验室指标确认心衰类型并指导治疗。

**适用范围 / Scope**
- 已临床怀疑心力衰竭、需进一步分类为 HFrEF 或 HFpEF 的病人

**操作步骤 / Procedure**
1. 优先安排经胸超声心动图,评估心室大小、射血分数和舒张功能。
2. 区分收缩功能下降型与射血分数保留型心衰。
3. 同步检测 BNP、心电图、胸片以及肾功能、电解质和甲状腺功能。
4. 查找缺血、瓣膜病、心律失常和液体负荷证据。
5. 将影像和生化结果整合到后续 ACEI/利尿剂/β阻滞剂或合并症管理决策中。

**注意事项 / Precautions**
- 超声心动图是诊断 CHF 的金标准。
- 胸片正常不能排除心衰。
- HFpEF 常见于高血压、糖尿病和房颤老年病人,需主动识别。

**量化指标 / Metrics**
- 可疑心衰病人的超声完成率
- BNP 检测率
- HFrEF/HFpEF 分类记录率
