# Skill: 慢性心衰ACEI起始

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第76章 慢性心力衰竭
- 页码: 第76章“心力衰竭的初始治疗”“ACEI”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第76章.md`

**目标 / Objective**
为适合的慢性心衰病人安全启动 ACEI 并逐步达到耐受治疗量。

**适用范围 / Scope**
- 收缩期心力衰竭且无 ACEI 禁忌证的病人

**操作步骤 / Procedure**
1. 在开始前排查肾动脉狭窄、血管性水肿和高钾等禁忌证。
2. 以推荐剂量的四分之一到二分之一小剂量起始。
3. 对直立性低血压风险高者,首次给药安排在睡前。
4. 根据耐受情况逐步滴定至维持剂量或最大耐受剂量。
5. 监测肾功能和血钾,若不能耐受咳嗽可考虑改用 ARB。

**注意事项 / Precautions**
- ACEI 应作为大多数心衰病人的基础治疗。
- 与保钾利尿剂联用时更要警惕高钾血症。
- 不应因症状早期缓解而停止滴定到有效剂量。

**量化指标 / Metrics**
- HFrEF 病人的 ACEI 启动率
- 启动后肾功能和血钾复查率
- 达到目标或最大耐受剂量比例
