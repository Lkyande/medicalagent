# Skill: 焦虑器质性病因排查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第70章 焦虑障碍
- 页码: 第70章“广泛性焦虑障碍的诊断”“表70.1 焦虑的重要鉴别诊断”“关注要点”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第70章.md`

**目标 / Objective**
在焦虑样主诉中系统排除医源性、内分泌、心肺和神经系统病因。

**适用范围 / Scope**
- 新发、非典型或伴明显躯体症状的焦虑病人

**操作步骤 / Procedure**
1. 区分原发性焦虑与继发性焦虑,注意发病时间与药物或疾病的关系。
2. 重点询问咖啡因、尼古丁、苯丙胺、支气管扩张药、甲状腺素和苯二氮䓬类使用情况。
3. 筛查甲亢、低血糖、心绞痛、心律失常、哮喘、肺栓塞和癫痫等器质性疾病线索。
4. 根据临床情况安排甲状腺功能、心电图、胸片和药物筛查等检查。
5. 排除器质性原因后,再进入焦虑障碍的心理和药物治疗决策。

**注意事项 / Precautions**
- 焦虑样症状可由多种躯体疾病伪装,尤其是甲亢和心律失常。
- 医源性药物和物质使用是重要线索。
- 胸痛、低氧或发作性晕厥伴焦虑时应先排除急症。

**量化指标 / Metrics**
- 焦虑病人器质性鉴别记录率
- 关键药物和物质暴露问诊率
- 非典型焦虑病人的 ECG/TFT 完成率
