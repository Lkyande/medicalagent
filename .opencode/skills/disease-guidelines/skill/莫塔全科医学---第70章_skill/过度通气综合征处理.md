# Skill: 过度通气综合征处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第70章 焦虑障碍
- 页码: 第70章“过度通气综合征”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第70章.md`

**目标 / Objective**
识别过度通气综合征并通过呼吸重建缓解症状。

**适用范围 / Scope**
- 焦虑状态下出现呼吸急促、胸闷、头晕、四肢麻木或手足搐搦的病人

**操作步骤 / Procedure**
1. 先排除哮喘、低氧、肺栓塞和代谢性问题等危险病因。
2. 解释症状与过快呼吸导致的生理变化有关,降低病人恐惧感。
3. 指导病人放慢呼吸频率,采用节律性腹式呼吸。
4. 观察头晕、手足麻木和胸闷是否随呼吸调整而减轻。
5. 发作缓解后讨论压力源和长期焦虑管理策略。

**注意事项 / Precautions**
- 不能在未评估危险病因前直接归为过度通气。
- 不建议使用会强化依赖的无计划镇静方式。
- 反复发作提示需进一步处理基础焦虑障碍。

**量化指标 / Metrics**
- 过度通气病人的危险病因排查率
- 呼吸训练即时缓解率
- 反复发作病人的后续干预率
