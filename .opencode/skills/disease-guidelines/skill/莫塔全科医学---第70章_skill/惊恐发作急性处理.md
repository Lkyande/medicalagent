# Skill: 惊恐发作急性处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第70章 焦虑障碍
- 页码: 第70章“惊恐发作”“管理”“药物治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第70章.md`

**目标 / Objective**
在急性惊恐发作中迅速稳定病人并避免把焦虑体验进一步灾难化。

**适用范围 / Scope**
- 突发强烈恐惧、心悸、呼吸困难、濒死感或失控感的病人

**操作步骤 / Procedure**
1. 先排除胸痛、低氧、心律失常、哮喘和低血糖等急性躯体问题。
2. 用平静和简短语言解释当前症状符合惊恐发作表现,帮助病人重新定向。
3. 指导缓慢控制呼吸,减少过度换气和灾难化解释。
4. 回顾既往发作模式和诱因,判断是否符合惊恐障碍。
5. 稳定后安排 CBT 为主的后续治疗,必要时评估药物方案。

**注意事项 / Precautions**
- 首次发作或年龄较大者更应排除心肺器质性原因。
- 解释和释除担忧本身就是重要干预。
- 不宜把短期药物镇静当作唯一处理方式。

**量化指标 / Metrics**
- 惊恐发作急性躯体排查率
- 呼吸指导实施率
- 发作后随访安排率
