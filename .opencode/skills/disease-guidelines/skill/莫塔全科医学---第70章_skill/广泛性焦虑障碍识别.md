# Skill: 广泛性焦虑障碍识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第70章 焦虑障碍
- 页码: 第70章“广泛性焦虑障碍”“广泛性焦虑障碍的诊断标准”“临床特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第70章.md`

**目标 / Objective**
识别持续性、弥散性担忧为主的广泛性焦虑障碍,并与正常压力反应区分。

**适用范围 / Scope**
- 长期紧张、担忧过多、伴多系统躯体症状的青少年和成人病人

**操作步骤 / Procedure**
1. 确认焦虑和担忧是否持续 6 个月或更久且涉及多个生活领域。
2. 核查是否符合至少 3 项核心表现,如易疲劳、注意力困难、易怒、肌紧张和睡眠紊乱。
3. 评估心理、躯体和认知三个维度的症状组合。
4. 判断焦虑是否已导致工作、学习、人际或生活功能受损。
5. 若符合广泛性模式,进入进一步排除器质性病因和非药物管理路径。

**注意事项 / Precautions**
- 焦虑是正常反应的一部分,关键在于强度、持续时间和功能损害。
- 病人常首先以躯体症状就诊,需主动连接到焦虑机制。
- 焦虑与抑郁经常共存,要同步筛查。

**量化指标 / Metrics**
- 广泛性焦虑核心症状记录率
- 功能损害评估率
- 焦虑合并抑郁筛查率
