# Skill: 焦虑非药物一线干预

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第70章 焦虑障碍
- 页码: 第70章“管理原则”“药物治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第70章.md`

**目标 / Objective**
落实焦虑障碍的一线非药物管理,减少对短期药物的过度依赖。

**适用范围 / Scope**
- 已排除主要器质性病因的轻中度焦虑障碍病人

**操作步骤 / Procedure**
1. 向病人解释焦虑的生理机制和躯体症状来源,完成心理教育。
2. 优先推荐 CBT、生活指导、压力管理、放松训练、正念和规律运动。
3. 提供具体可执行的应对技巧,包括管理困难场景和人际压力的方法。
4. 建议减少咖啡因、尼古丁和其他会加重焦虑的物质。
5. 通过随访强化执行情况,仅在必要时再评估 SSRI 或其他药物治疗。

**注意事项 / Precautions**
- 非药物管理是一线策略,应先于常规处方药。
- 不能把“去自己放松”作为空泛建议,需要给出具体路径。
- 焦虑病人常会对自己的焦虑再次产生担心,解释需有针对性。

**量化指标 / Metrics**
- 焦虑病人心理教育完成率
- 非药物方案启动率
- 6 至 12 周症状改善或功能恢复率
