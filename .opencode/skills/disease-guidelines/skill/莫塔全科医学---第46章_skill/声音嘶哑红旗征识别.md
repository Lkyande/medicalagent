# Skill: 声音嘶哑红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第46章 声音嘶哑
- 页码: 第46章“红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第46章.md`

**目标 / Objective**
快速识别提示喉癌、气道受损或严重基础病的声音嘶哑表现。

**适用范围 / Scope**
- 所有急性或慢性声音嘶哑病人

**操作步骤 / Procedure**
1. 询问是否有重度吸烟史和症状持续超过 3 周。
2. 评估是否合并吞咽困难、吞咽痛或耳痛。
3. 查找颈部肿块、咯血和一般情况下降如体重减轻或发热。
4. 识别喘鸣或气道受损表现,将其视为紧急情况。
5. 红旗征阳性时尽快转耳鼻喉专科做喉镜评估和必要活检。

**注意事项 / Precautions**
- 成人持续性嘶哑超过 3 周必须排除喉癌。
- 喘鸣合并急性嘶哑提示气道受损,要准备急救。
- 间歇性嘶哑常见于良性病变,持续进展更需警惕恶性病因。

**量化指标 / Metrics**
- 嘶哑红旗征记录率
- 高危病例专科转诊率
- 喉癌漏诊率
