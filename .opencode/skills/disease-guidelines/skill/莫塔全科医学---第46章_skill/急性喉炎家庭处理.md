# Skill: 急性喉炎家庭处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第46章 声音嘶哑
- 页码: 第46章“急性喉炎”“处理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第46章.md`

**目标 / Objective**
对典型急性喉炎提供以声带休息和环境控制为核心的家庭管理方案。

**适用范围 / Scope**
- 无气道红旗征的急性病毒性喉炎或短期用嗓过度病人

**操作步骤 / Procedure**
1. 建议在家休息并尽量减少说话,保持正常对话音量而非低语。
2. 鼓励充足饮水和温热饮品促进舒适感。
3. 避免吸烟、被动吸烟、酒精和其他刺激物暴露。
4. 可采用热蒸汽吸入和简单镇痛药缓解不适,必要时辅助止咳。
5. 明确告知多数病例自限,但若超过 3 周不愈或加重需复诊转诊。

**注意事项 / Precautions**
- 除非有细菌感染证据,抗生素通常无效。
- 低声说话并不能保护声带,反而可能增加发声负担。
- 出现喘鸣、吞咽困难或明显呼吸受限时不适合家庭处理。

**量化指标 / Metrics**
- 急性喉炎家庭宣教覆盖率
- 非适应证抗生素使用率
- 3 周内症状缓解率
