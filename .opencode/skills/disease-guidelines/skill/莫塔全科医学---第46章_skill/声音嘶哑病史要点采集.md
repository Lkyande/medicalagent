# Skill: 声音嘶哑病史要点采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第46章 声音嘶哑
- 页码: 第46章“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第46章.md`

**目标 / Objective**
通过结构化病史在嘶哑病人中快速定位感染、用嗓过度、反流和肿瘤风险。

**适用范围 / Scope**
- 新发、反复或持续声音嘶哑病人

**操作步骤 / Procedure**
1. 记录嗓音改变的性质和持续时间,并区分急性与慢性。
2. 询问近期上呼吸道感染、唱歌喊叫或其他不习惯的声带劳损。
3. 核查类固醇吸入、近期插管或手术史。
4. 询问吸烟、饮酒、环境刺激物暴露和反流相关症状。
5. 主动筛查咳嗽、体重减轻、甲减和帕金森病相关症状。

**注意事项 / Precautions**
- 急性嘶哑常可仅靠病史定位,但慢性嘶哑必须避免想当然归因。
- 吸入激素和用嗓习惯是最容易漏掉的可逆因素。
- 病史中出现全身消耗症状时要及时提升恶性肿瘤警觉度。

**量化指标 / Metrics**
- 嘶哑关键病史完成率
- 可逆危险因素识别率
- 慢性嘶哑早期转诊率
