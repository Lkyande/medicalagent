# Skill: 声音嘶哑基础查体

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第46章 声音嘶哑
- 页码: 第46章“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第46章.md`

**目标 / Objective**
用基层查体快速识别颈部肿块、甲状腺异常、气道受损和特征性嗓音线索。

**适用范围 / Scope**
- 初诊或复诊的声音嘶哑病人

**操作步骤 / Procedure**
1. 触诊颈部,重点检查甲状腺和颈部淋巴结是否肿大。
2. 在非会厌炎疑虑下做简单口咽检查。
3. 查找甲减体征如皮肤头发粗糙、迟脉和精神迟钝。
4. 听诊胸部是否有喘鸣,评估是否存在上气道受累。
5. 结合嗓音特征判断方向,如深沉、沙砾样、柔软或间断性声音。

**注意事项 / Precautions**
- 怀疑会厌炎时不应做可能加重气道风险的刺激性检查。
- 颈部淋巴结和甲状腺异常对恶性或压迫性病因提示价值高。
- 嗓音特征只是提示线索,不能替代喉镜检查。

**量化指标 / Metrics**
- 嘶哑病人颈部查体完成率
- 喘鸣识别率
- 甲状腺相关病因提示率
