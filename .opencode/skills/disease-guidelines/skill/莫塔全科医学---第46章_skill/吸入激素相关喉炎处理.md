# Skill: 吸入激素相关喉炎处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第46章 声音嘶哑
- 页码: 第46章“类固醇吸入剂诱发的喉炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第46章.md`

**目标 / Objective**
识别并纠正吸入激素导致的声音嘶哑和真菌相关喉炎。

**适用范围 / Scope**
- 使用类固醇吸入剂后出现声音嘶哑或口咽不适的病人

**操作步骤 / Procedure**
1. 主动询问是否长期或近期使用类固醇吸入剂。
2. 检查口腔和咽部是否存在鹅口疮或其他念珠菌感染表现。
3. 如有真菌感染证据,按需给予抗真菌治疗。
4. 复核吸入器和储雾罐使用技巧,纠正错误操作。
5. 叮嘱每次吸入后及时冲洗口腔和漱口,减少再次发生。

**注意事项 / Precautions**
- 该问题常见且可逆,但若不主动询问容易漏诊。
- 单纯反复加大抗生素或止咳药并不能解决问题。
- 若症状持续,仍需排除声带良性病变或肿瘤。

**量化指标 / Metrics**
- 吸入激素使用者口腔检查率
- 吸入技巧纠正率
- 复发性嘶哑改善率
