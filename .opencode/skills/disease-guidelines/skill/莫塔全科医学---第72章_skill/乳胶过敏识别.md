# Skill: 乳胶过敏识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第72章 过敏性疾病(包括花粉症)
- 页码: 第72章“乳胶过敏”“诊断”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第72章.md`

**目标 / Objective**
识别对乳胶制品高度敏感的人群并减少暴露相关严重过敏反应。

**适用范围 / Scope**
- 医护人员、多次手术病人、脊柱裂病人及接触橡胶制品后出现过敏反应者

**操作步骤 / Procedure**
1. 询问接触手套、避孕套、气球等浸渍橡胶制品后的症状。
2. 关注荨麻疹、特应性皮炎加重、鼻结膜炎、哮喘及全身反应。
3. 核查是否伴香蕉、猕猴桃、牛油果等相关水果过敏史。
4. 根据情况选择皮肤点刺、特异性 IgE 或斑贴试验确认不同机制反应。
5. 一旦确认,要求避免乳胶暴露并在医疗接触前主动标注过敏信息。

**注意事项 / Precautions**
- 皮肤点刺更敏感但存在诱发反应风险。
- 手术和侵入性操作前必须提前沟通乳胶禁用。
- 医护人员自身乳胶过敏不应继续佩戴乳胶手套。

**量化指标 / Metrics**
- 高危人群乳胶过敏询问率
- 过敏标识完成率
- 乳胶替代措施落实率
