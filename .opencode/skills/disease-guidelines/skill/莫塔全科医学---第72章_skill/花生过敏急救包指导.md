# Skill: 花生过敏急救包指导

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第72章 过敏性疾病(包括花粉症)
- 页码: 第72章“花生过敏”“表72.2 成人过敏反应急救包”“食物过敏风险最小化策略”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第72章.md`

**目标 / Objective**
为高风险花生过敏病人建立随身急救包和暴露后自救方案。

**适用范围 / Scope**
- 已确诊或高度怀疑花生过敏,尤其合并哮喘的儿童和成人

**操作步骤 / Procedure**
1. 向病人和家属说明花生过敏可在进食后数分钟内迅速恶化。
2. 指导准备急救包,包含肾上腺素自动注射器、抗组胺药和泼尼松龙等。
3. 强调出现咽喉或舌肿胀、呼吸困难等首发重症信号时立即肌注肾上腺素。
4. 同步告知学校、家庭和餐饮场所,落实食物识别与避免策略。
5. 合并哮喘者优先优化哮喘控制,并定期复核急救包使用方法。

**注意事项 / Precautions**
- 花生过敏合并哮喘是致命反应的重要危险因素。
- 当前不推荐常规脱敏疗法作为一般管理。
- 急救包教育应覆盖病人、家属和主要照护场景。

**量化指标 / Metrics**
- 高危花生过敏病人的急救包配备率
- 肾上腺素使用教育完成率
- 学校或家庭告知完成率
