# Skill: 皮肤点刺试验适应证判断

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第72章 过敏性疾病(包括花粉症)
- 页码: 第72章“皮肤点刺试验”“血清特异性 IgE 检测”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第72章.md`

**目标 / Objective**
合理选择皮肤点刺试验或血清特异性 IgE 检测来确认 IgE 介导过敏。

**适用范围 / Scope**
- 需要进一步确认过敏原的鼻炎、哮喘、食物过敏和乳胶过敏病人

**操作步骤 / Procedure**
1. 先确认病史中存在与特定过敏原一致的症状和时序。
2. 优先考虑皮肤点刺试验作为首选方法,尤其在可疑 IgE 介导反应时。
3. 对病史与点刺结果不符、广泛湿疹、皮肤划纹症、婴幼儿或近期使用抗组胺药者,改选血清特异性 IgE 检测。
4. 对仅检测阳性但无临床症状者,不要过度解释为疾病诊断。
5. 将检查结果与病史整合,再决定回避、免疫治疗或进一步专科评估。

**注意事项 / Precautions**
- 皮肤点刺阴性有助于排除 IgE 介导过敏。
- 仅凭实验室阳性而无症状,诊断意义有限。
- 点刺试验存在诱发反应风险,应在合适环境下进行。

**量化指标 / Metrics**
- 过敏检测前完整病史记录率
- 检测结果与临床整合记录率
- 不适当检测使用率
