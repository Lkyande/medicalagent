# Skill: IgE介导食物过敏识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第72章 过敏性疾病(包括花粉症)
- 页码: 第72章“IgE 介导的食物反应”“临床特征”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第72章.md`

**目标 / Objective**
识别速发型 IgE 介导食物过敏并及时进入避免和急救路径。

**适用范围 / Scope**
- 婴幼儿、儿童或成人在进食后短时间内出现过敏症状者

**操作步骤 / Procedure**
1. 明确症状是否在进食后 30 至 60 分钟内出现,通常不超过 2 小时。
2. 查找口咽瘙痒、荨麻疹、潮红、喘息、呕吐、腹痛、血管性水肿或濒死感。
3. 锁定常见诱因,如牛奶、鸡蛋、花生、坚果、鱼和贝类。
4. 记录饮食和反应经过,并安排皮肤点刺或特异性 IgE 检测协助确认。
5. 明确可疑食物后指导严格避免,高危者进入肾上腺素急救管理。

**注意事项 / Precautions**
- 伴哮喘的食物过敏更危险,尤其花生过敏。
- 不能把乳糖不耐受等非免疫反应归为 IgE 过敏。
- 严重反应病人需准备急救包并接受明确教育。

**量化指标 / Metrics**
- 进食后速发反应病人的时序记录率
- 高危食物过敏病人的专科转介率
- 急救教育完成率
