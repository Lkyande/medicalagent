# Skill: 过敏原接触史采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第72章 过敏性疾病(包括花粉症)
- 页码: 第72章“常见过敏原”“吸入性过敏”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第72章.md`

**目标 / Objective**
通过系统病史快速定位可能的吸入、食物、药物和职业性过敏原。

**适用范围 / Scope**
- 出现鼻结膜炎、哮喘、荨麻疹、血管性水肿或疑似食物过敏反应的病人

**操作步骤 / Procedure**
1. 先按吸入、食物和其他三大类回顾可能接触的过敏原。
2. 询问症状与季节、环境、宠物、打扫、修剪草坪或工作暴露的关系。
3. 核查花生、坚果、牛奶、鸡蛋、鱼贝类和小麦等高频食物诱因。
4. 记录药物、乳胶、昆虫毒液及职业因素暴露史。
5. 根据暴露与症状时间关系初步判断速发型还是迟发型过敏反应。

**注意事项 / Precautions**
- 接触史必须结合症状时序,不能仅凭“接触过”作诊断。
- 乳胶过敏与香蕉、猕猴桃、牛油果等水果过敏可能相关。
- 要避免把非免疫性食物不耐受误判为食物过敏。

**量化指标 / Metrics**
- 过敏病人的标准化接触史记录率
- 暴露-症状时序记录率
- 明确可疑过敏原比例
