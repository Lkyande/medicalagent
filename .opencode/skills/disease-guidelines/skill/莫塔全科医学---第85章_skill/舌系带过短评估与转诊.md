# Skill: 舌系带过短评估与转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第85章 儿童的外科问题
- 页码: 第85章“舌系带过短”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第85章.md`

**目标 / Objective**
识别影响哺乳或发音的舌系带过短并把握最佳干预时机。

**适用范围 / Scope**
- 婴儿母乳喂养困难或儿童伸舌受限、疑似发音受影响时

**操作步骤 / Procedure**
1. 观察舌尖是否呈心形以及伸舌是否不能超过下唇。
2. 结合哺乳困难和家族严重语言障碍史判断临床意义。
3. 对 4 个月内婴儿评估是否适合早期简单系带切开。
4. 超过婴儿期但仍明显受影响者安排后续外科或专科评估。
5. 记录功能受限而不仅是解剖外观。

**注意事项 / Precautions**
- 并非所有舌系带短都需要手术。
- 婴儿期系带较薄且血管少,处理时机更合适。
- 重点在功能影响而不是单纯外观。
**量化指标 / Metrics**
- 哺乳困难婴儿的舌系带评估率
- 功能受限记录率
- 合适时机转诊率
