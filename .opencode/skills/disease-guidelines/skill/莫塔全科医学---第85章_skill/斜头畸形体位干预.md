# Skill: 斜头畸形体位干预

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第85章 儿童的外科问题
- 页码: 第85章“斜头畸形(扁头综合征)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第85章.md`

**目标 / Objective**
早期识别姿势性斜头畸形并通过体位调整减少持续变形。

**适用范围 / Scope**
- 婴儿头颅不对称、头围正常且怀疑姿势相关扁头时

**操作步骤 / Procedure**
1. 观察头颅是否呈平行四边形样不对称并记录耳位差异。
2. 排除颅缝脊样改变和颅骨狭窄线索。
3. 指导家长定期改变睡姿方向并增加清醒时俯卧时间。
4. 追踪 4 至 8 个月内改善情况。
5. 若无明显改善或怀疑非姿势性病因,转诊进一步评估,必要时考虑头盔治疗。

**注意事项 / Precautions**
- 多数斜头畸形不会影响智力或脑发育。
- 持续不对称需与颅骨狭窄鉴别。
- 干预越早越容易获得改善。

**量化指标 / Metrics**
- 斜头畸形体位指导率
- 随访改善记录率
- 非姿势性病例转诊率
