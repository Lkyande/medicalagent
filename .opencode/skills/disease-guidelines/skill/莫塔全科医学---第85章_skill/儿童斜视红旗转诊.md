# Skill: 儿童斜视红旗转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第85章 儿童的外科问题
- 页码: 第85章“斜视”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第85章.md`

**目标 / Objective**
区分真性斜视与假性斜视并及时转诊需早治病例。

**适用范围 / Scope**
- 婴幼儿和儿童出现眼位异常、家长怀疑“斗鸡眼”或眼偏斜时

**操作步骤 / Procedure**
1. 判断是持续性、交替性、短暂性还是隐性斜视。
2. 用手电筒角膜光反射位置比较真性与假性斜视。
3. 对首次发现斜视的儿童同步警惕视网膜母细胞瘤、白内障和青光眼。
4. 对持续性或交替性斜视尽早眼科转诊。
5. 说明若 7 岁前不能纠正,有发展为弱视和不可逆视力下降的风险。

**注意事项 / Precautions**
- 即使普通查体看似正常,真性斜视也需专科管理。
- 短暂性或隐性斜视通常不如持续性严重,但仍需随访。
- 早期识别和转诊直接影响视力预后。

**量化指标 / Metrics**
- 斜视病人的角膜反射检查率
- 持续性斜视早期转诊率
- 继发弱视预防覆盖率
