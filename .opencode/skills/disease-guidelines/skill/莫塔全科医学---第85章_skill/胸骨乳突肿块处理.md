# Skill: 胸骨乳突肿块处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第85章 儿童的外科问题
- 页码: 第85章“胸骨乳突的肿瘤/纤维化”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第85章.md`

**目标 / Objective**
识别胸骨乳突肿块/纤维化并通过早期物理干预减少持续斜颈。

**适用范围 / Scope**
- 出生后 20 至 30 日出现颈部无痛肿块或头位偏斜的婴儿

**操作步骤 / Procedure**
1. 触诊胸锁乳突肌内是否存在 2 至 3 cm 无痛硬肿块。
2. 观察头部倾斜方向和向患侧转头受限情况。
3. 向家长解释多数病例可在 1 年内自行消退。
4. 尽早转诊物理治疗并指导轻柔按摩和伸展练习。
5. 对持续纤维化或较大儿童斜颈安排外科评估。

**注意事项 / Precautions**
- 越早进行姿势和牵伸干预效果越好。
- 练习应轻柔,避免粗暴牵拉。
- 年龄较大且伴面部发育不对称者更需要专科处理。

**量化指标 / Metrics**
- 胸骨乳突肿块早期识别率
- 物理治疗转介率
- 随访头位改善率
