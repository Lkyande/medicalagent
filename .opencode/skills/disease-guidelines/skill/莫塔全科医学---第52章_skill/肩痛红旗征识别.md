# Skill: 肩痛红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第52章 肩部疼痛
- 页码: 第52章“肩痛的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第52章.md`

**目标 / Objective**
及时识别提示脓毒性感染、骨折脱位、恶性病变或神经损伤的危险肩痛表现。

**适用范围 / Scope**
- 所有肩部疼痛病人

**操作步骤 / Procedure**
1. 询问是否发热、皮肤发红或局部明显肿胀。
2. 核查有无外伤史,包括脱位、骨折和肩袖撕裂可能。
3. 追问炎症性关节炎史和既往癌症史。
4. 评估手臂是否存在感觉或运动丧失。
5. 红旗征阳性时优先行影像和急诊分流,避免按单纯肩袖病变处理。

**注意事项 / Precautions**
- 左肩痛必须始终考虑心肌缺血牵涉痛。
- 肩顶痛与腹腔、膈肌和胸腔病变有关时,肩部活动不一定能诱发加重。
- 儿童肩痛少见但一旦出现需警惕化脓性关节炎或骨髓炎。

**量化指标 / Metrics**
- 肩痛红旗征记录率
- 高危病例急诊转诊率
- 严重病因漏诊率
