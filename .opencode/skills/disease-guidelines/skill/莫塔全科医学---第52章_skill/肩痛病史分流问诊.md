# Skill: 肩痛病史分流问诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第52章 肩部疼痛
- 页码: 第52章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第52章.md`

**目标 / Objective**
通过问诊初步区分颈源性、肩袖性、关节囊性和牵涉性肩痛。

**适用范围 / Scope**
- 以肩部疼痛、僵硬或无力就诊的病人

**操作步骤 / Procedure**
1. 先明确疼痛究竟来自颈部、肩部还是两者兼有。
2. 询问是否存在僵硬、活动过度、不稳定、乏力和动作不平滑。
3. 追问梳头、穿脱胸罩、摸肩胛骨和过顶活动是否受限或诱发疼痛。
4. 询问夜间痛、晨起加重、双肩或臀带痛以及运动或家务诱发情况。
5. 结合是否有颈痛、创伤和功能丧失初步判断肩袖、关节囊或颈源性问题。

**注意事项 / Precautions**
- 病人描述的“肩痛”范围常包含肩胛周围和侧颈,需让其手指定位。
- 老年双侧肩带痛且晨僵要优先考虑风湿性多肌痛。
- 完全不能完成过顶动作时要警惕肩袖完全撕裂。

**量化指标 / Metrics**
- 肩痛病史完整率
- 疼痛来源初步定位准确率
- 夜间痛记录率
