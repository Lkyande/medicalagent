# Skill: 肩袖抗阻试验分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第52章 肩部疼痛
- 页码: 第52章“抗阻运动”“特殊检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第52章.md`

**目标 / Objective**
利用抗阻动作快速分辨冈上肌、肩胛下肌、冈下肌和肱二头肌长头病变。

**适用范围 / Scope**
- 怀疑肩袖或肱二头肌腱病变的肩痛病人

**操作步骤 / Procedure**
1. 先做抗阻外展测试,观察冈上肌区域是否再现疼痛。
2. 采用“倒罐头”试验提高对冈上肌撞击和无力的识别度。
3. 在肘屈 90 度、上臂贴体位测试抗阻内旋,筛查肩胛下肌病变。
4. 用同样体位测试抗阻外旋,筛查冈下肌病变并与 C5 神经根问题区分。
5. 追加 Speed 或 Yergason 试验,判断肱二头肌长头病变是否参与疼痛。

**注意事项 / Precautions**
- 抗阻试验应双侧对比,注意疼痛与无力并存时更提示撕裂。
- 肩袖检查阳性不排除轻度关节囊炎共存。
- 神经根病可使外旋试验假阳性,需回看颈部查体。

**量化指标 / Metrics**
- 肩袖抗阻试验完成率
- 肌腱定位准确率
- 肩袖撕裂识别率
