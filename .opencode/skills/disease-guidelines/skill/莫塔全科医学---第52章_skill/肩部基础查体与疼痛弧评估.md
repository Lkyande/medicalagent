# Skill: 肩部基础查体与疼痛弧评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第52章 肩部疼痛
- 页码: 第52章“身体检查”“肩部检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第52章.md`

**目标 / Objective**
通过视、触、动的基础查体区分肌腱性与关节囊性肩痛。

**适用范围 / Scope**
- 无明显急性骨折脱位征象的肩痛病人

**操作步骤 / Procedure**
1. 观察双肩轮廓、肩胛姿势、肌肉萎缩、肿胀和畸形。
2. 触诊肩锁关节、肩峰下间隙、冈上肌肌腱群、肱二头肌长头和腋窝。
3. 双侧比较主动前屈、后伸、外展、内收、内旋和外旋范围。
4. 在外展过程中记录疼痛开始与结束角度,识别 60 至 120 度的疼痛弧。
5. 根据单方向受限还是多方向受限,区分肌腱疾病与关节囊炎或滑囊炎。

**注意事项 / Precautions**
- 需要固定肩胛骨时才能更准确判断盂肱关节真实活动范围。
- 肩顶痛若不随活动改变,更应考虑胸腹腔牵涉痛。
- 腋窝触诊可帮助发现淋巴结病变或肿瘤线索。

**量化指标 / Metrics**
- 肩部基础查体完成率
- 疼痛弧记录率
- 肌腱性与关节囊性分层准确率
