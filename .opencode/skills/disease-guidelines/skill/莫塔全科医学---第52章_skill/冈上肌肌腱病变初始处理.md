# Skill: 冈上肌肌腱病变初始处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第52章 肩部疼痛
- 页码: 第52章“冈上肌肌腱病变”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第52章.md`

**目标 / Objective**
对典型冈上肌肌腱病变实施保守治疗并识别注射和手术时机。

**适用范围 / Scope**
- 以肩峰下撞击样疼痛为主且无明确完全撕裂证据的病人

**操作步骤 / Procedure**
1. 以对乙酰氨基酚为首选止痛,必要时短期加用非甾体抗炎药。
2. 给予肩胛稳定和肩袖强化为核心的物理治疗方案。
3. 在未见明确撕裂时,对症状明显者考虑腱膜或肩峰下注射类固醇加局麻药。
4. 评估治疗后活动范围和夜间痛改善情况,督促继续功能训练。
5. 症状持续 3 至 6 个月、怀疑钙化或撕裂时转诊考虑超声评估和手术。

**注意事项 / Precautions**
- 注射应尽量定位准确,而非无差别浸润整个肩峰下间隙。
- 老年人顽固冈上肌痛更要警惕肩袖撕裂或退变。
- 游泳肩更强调调整训练和肩胛稳定,应避免类固醇注射。

**量化指标 / Metrics**
- 肩袖保守治疗启动率
- 6 周症状改善率
- 顽固病例及时转诊率
