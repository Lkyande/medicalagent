# Skill: 反射性晕厥识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第64章 失去意识的病人
- 页码: 第64章“直立不耐受和晕厥”“反射性晕厥”“其他形式的晕厥”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第64章.md`

**目标 / Objective**
识别最常见的反射性晕厥模式,并与心源性和神经系统危险病因区分。

**适用范围 / Scope**
- 短暂意识丧失后迅速恢复的门诊或社区病人

**操作步骤 / Procedure**
1. 明确发作前诱因,如久站、情绪刺激、疼痛、排尿、咳嗽或用力。
2. 询问前驱症状,如恶心、出汗、头晕、视物变暗和耳鸣。
3. 记录发作持续时间、恢复速度及是否伴抽搐、舌咬伤或尿失禁。
4. 测量卧立位血压和脉搏,排查直立性低血压及心律失常线索。
5. 若缺乏典型诱因、发作时受伤明显或伴胸痛心悸,按高危晕厥进一步评估。

**注意事项 / Precautions**
- 心律失常和脑血管事件是不能遗漏的严重病因。
- 老年人和合并心脏病者不应轻易归为单纯反射性晕厥。
- 抽搐样动作并不一定等于癫痫,需结合恢复期表现判断。

**量化指标 / Metrics**
- 晕厥前驱症状记录率
- 卧立位血压检测完成率
- 高危晕厥进一步转诊率
