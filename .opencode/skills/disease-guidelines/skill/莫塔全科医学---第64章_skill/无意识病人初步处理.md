# Skill: 无意识病人初步处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第64章 失去意识的病人
- 页码: 第64章“紧急关注”“表64.5 身体检查及措施”“对失去意识的病人的初步管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第64章.md`

**目标 / Objective**
在最短时间内稳定无意识病人的生命体征并处理可逆性原因。

**适用范围 / Scope**
- 门诊、院前或基层场景中发现无意识或无反应病人时

**操作步骤 / Procedure**
1. 立即评估气道、呼吸和循环,必要时清理气道并开始辅助通气或心肺复苏。
2. 观察胸壁运动、脉搏、瞳孔和皮肤颜色,快速判断缺氧、发绀或休克。
3. 立刻测量床旁血糖,并同步考虑低血糖和阿片类药物过量。
4. 在排除外伤前保护颈椎,并记录基线意识状态以便后续比较。
5. 处理可逆因素后,将病人置于安全体位并尽快转送进一步救治。

**注意事项 / Precautions**
- 未取得完整信息前不要让陪同人员离开。
- 病史不明的昏迷病人必须优先考虑低血糖和药物过量。
- 发绀伴意识障碍时先按上气道阻塞处理,除非已有明确其他证据。

**量化指标 / Metrics**
- 无意识病人 ABC 首轮评估完成时间
- 床旁血糖检测完成率
- 可逆性病因干预前置率
