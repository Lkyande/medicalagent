# Skill: 昏迷程度快速评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第64章 失去意识的病人
- 页码: 第64章“表64.1 意识的五个程度”“表64.3 格拉斯哥昏迷评分量表”“表64.4 AVPU量表”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第64章.md`

**目标 / Objective**
用统一语言记录意识受损程度,为病情监测和转运交接提供基线。

**适用范围 / Scope**
- 意识模糊、嗜睡、昏睡、轻度昏迷和昏迷病人

**操作步骤 / Procedure**
1. 先用一句临床描述概括病人的实际状态,如对呼喊有反应或仅对疼痛有反应。
2. 使用 AVPU 量表快速分为清醒、对言语反应、对疼痛反应或无反应。
3. 在条件允许时进一步完成 GCS 评分,分别记录睁眼、言语和运动反应。
4. 对 GCS 8 至 10 分病人加强气道监测,警惕病情迅速恶化。
5. 重复记录分值和时间点,比较意识状态是改善还是恶化。

**注意事项 / Precautions**
- 宽泛术语不能替代具体反应描述。
- 镇静药、酒精和抽搐后状态会影响评分,需结合背景解释。
- 重复评分时应尽量使用相同刺激方法以保证可比性。

**量化指标 / Metrics**
- 意识障碍病人的 AVPU 或 GCS 记录率
- 初评后重复评分完成率
- GCS 下降病人的升级处置率
