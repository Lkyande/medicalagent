# Skill: 低血糖性意识障碍排查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第64章 失去意识的病人
- 页码: 第64章“关键事实和要点”“低血糖症”“G=葡萄糖”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第64章.md`

**目标 / Objective**
在意识障碍场景中快速识别和纠正低血糖,减少可逆性脑损伤。

**适用范围 / Scope**
- 病因未明的意识模糊、抽搐、无意识或行为异常病人

**操作步骤 / Procedure**
1. 询问或寻找糖尿病、胰岛素使用、进食减少、感染或降糖药暴露线索。
2. 立即使用血糖仪检测床旁血糖,不要等待实验室结果。
3. 若血糖低或高度怀疑低血糖,立即补充葡萄糖并观察意识改善情况。
4. 同步评估诱因,如过量降糖药、漏餐、饮酒、感染或肝肾功能问题。
5. 意识恢复后安排进一步病因复核和治疗方案调整,必要时住院观察。

**注意事项 / Precautions**
- 所有无意识病人都应优先考虑低血糖。
- 老年人和多病共存者可仅表现为混乱、跌倒或异常行为。
- 纠正低血糖后仍意识不清时,需继续寻找其他中枢病因。

**量化指标 / Metrics**
- 意识障碍病人床旁血糖首测率
- 低血糖纠正后意识改善记录率
- 低血糖诱因复盘完成率
