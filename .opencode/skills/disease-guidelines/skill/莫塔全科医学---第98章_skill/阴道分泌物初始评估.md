# Skill: 阴道分泌物初始评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第98章 阴道分泌物
- 页码: 第98章“临床方法”“病史”“身体检查”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第98章.md`

**目标 / Objective**
对阴道分泌物进行系统评估,区分生理性、感染性和恶性病变信号。

**适用范围 / Scope**
- 主诉阴道分泌物增多、异味、瘙痒、灼热或相关不适的女性和女童

**操作步骤 / Procedure**
1. 询问分泌物颜色、气味、量、瘙痒、疼痛、周期关系和性暴露史。
2. 判断可能是生理性分泌物还是阴道炎、宫颈炎或萎缩性阴道炎。
3. 进行外阴、窥器和必要的双合诊检查,观察分泌物性质和宫颈情况。
4. 进行湿片、pH、拭子或 PCR 检测,必要时安排 STI 检查。
5. 对持续异常、恶臭、血性分泌物或可疑肿瘤者安排进一步检查。

**注意事项 / Precautions**
- 阴道分泌物可能是生理现象,也可能提示肿瘤或异物。
- 儿童分泌物要考虑外阴阴道炎、异物和虐待可能。
- 必须结合病史、查体和显微镜结果综合判断。

**量化指标 / Metrics**
- 阴道分泌物病史完整率
- 湿片或拭子完成率
- 红旗病例专科转诊率
