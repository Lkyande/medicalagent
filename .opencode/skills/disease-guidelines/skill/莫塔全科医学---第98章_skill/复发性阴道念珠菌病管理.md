# Skill: 复发性阴道念珠菌病管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第98章 阴道分泌物
- 页码: 第98章“复发性外阴阴道念珠菌病”“治疗”“对阴道念珠菌病人的建议”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第98章.md`

**目标 / Objective**
规范识别和长期管理复发性外阴阴道念珠菌病。

**适用范围 / Scope**
- 反复瘙痒、豆渣样分泌物或多次发作的女性

**操作步骤 / Procedure**
1. 确认典型临床表现并尽可能获得显微镜或培养支持。
2. 回顾糖尿病、抗生素、免疫抑制和激素因素等易感背景。
3. 给予足够的初始治疗以控制急性症状。
4. 对反复发作者进入维持治疗和生活建议路径。
5. 对非典型、耐药或光滑念珠菌可疑病例补充培养和专科建议。

**注意事项 / Precautions**
- 复发性病例需要寻找诱因而非反复短疗程经验用药。
- 光滑念珠菌病治疗策略不同。
- 需向病人解释外因和内因并不等于“卫生差”。

**量化指标 / Metrics**
- 复发病例诱因评估率
- 显微镜/培养确认率
- 维持治疗依从率
