# Skill: 细菌性阴道病识别与治疗

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第98章 阴道分泌物
- 页码: 第98章“细菌性阴道病”“临床特点”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第98章.md`

**目标 / Objective**
识别细菌性阴道病并给予针对性治疗,减少异味和复发困扰。

**适用范围 / Scope**
- 分泌物有鱼腥味、灰白稀薄或复发性阴道不适的女性

**操作步骤 / Procedure**
1. 询问分泌物气味、颜色和是否伴明显瘙痒或刺激。
2. 结合查体、pH 和显微镜线索区分 BV 与念珠菌或滴虫感染。
3. 排除 STI 风险和合并宫颈炎情况。
4. 给予推荐的一线药物治疗并说明服药期间注意事项。
5. 对持续或反复症状重新评估诊断和诱因。

**注意事项 / Precautions**
- BV 常以异味为主,瘙痒未必明显。
- 反复发作时需重新确认诊断而非机械重复处方。
- 与滴虫或 STI 混合感染时管理路径不同。

**量化指标 / Metrics**
- BV 与其他阴道炎鉴别记录率
- 一线治疗使用率
- 复发后复评率
