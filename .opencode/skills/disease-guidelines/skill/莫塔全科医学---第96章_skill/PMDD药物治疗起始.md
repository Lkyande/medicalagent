# Skill: PMDD药物治疗起始

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第96章 经前综合征
- 页码: 第96章“中度至重度症状”“口服避孕药”“临床要领”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第96章.md`

**目标 / Objective**
为中重度 PMS/PMDD 病人启动有证据支持的药物治疗。

**适用范围 / Scope**
- 经前症状已明显影响工作、学习、人际或家庭功能的女性

**操作步骤 / Procedure**
1. 先确认症状符合周期性并已排除其他精神或内分泌疾病。
2. 对中重度情绪症状可在预期月经前 14 日起使用氟西汀或舍曲林。
3. 对有避孕需求者可考虑含炔雌醇和屈螺酮的口服避孕药。
4. 设定至少连续 3 个周期观察疗效。
5. 若治疗无效或伴严重抑郁精神症状,安排专科转诊。

**注意事项 / Precautions**
- 单独孕激素可能无效甚至加重症状。
- SSRI/SNRI 适用于中重度病例,不宜跳过诊断确认直接处方。
- 药物选择应兼顾避孕需求和心理症状谱。

**量化指标 / Metrics**
- PMDD 药物起始率
- 连续 3 周期随访完成率
- 中重度症状改善率
