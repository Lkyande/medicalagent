# Skill: 经前综合征症状日记

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第96章 经前综合征
- 页码: 第96章“诊断”“症状日记”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第96章.md`

**目标 / Objective**
通过周期性症状记录提高 PMS/PMDD 诊断准确性和管理针对性。

**适用范围 / Scope**
- 怀疑经前综合征或经前烦躁障碍的育龄女性

**操作步骤 / Procedure**
1. 指导病人连续 2 至 3 个月经周期每日记录主要症状和时间点。
2. 重点标记症状是否在月经前 1 周加重、月经后数日缓解。
3. 同步记录情绪、乳房症状、腹胀、头痛和功能受损程度。
4. 用记录帮助区分 PMS 与抑郁、甲状腺疾病或更年期问题。
5. 依据症状节律安排生活和治疗计划。

**注意事项 / Precautions**
- 周期性证据是 PMS 诊断核心之一。
- 不要仅凭单次主诉就下 PMDD 诊断。
- 症状日记对医生和病人都具有教育价值。

**量化指标 / Metrics**
- 可疑 PMS 病人的症状日记完成率
- 周期相关性确认率
- 诊断修正率
