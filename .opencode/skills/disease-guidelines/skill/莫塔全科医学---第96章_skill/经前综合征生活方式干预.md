# Skill: 经前综合征生活方式干预

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第96章 经前综合征
- 页码: 第96章“管理”“饮食建议”“运动”“放松”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第96章.md`

**目标 / Objective**
用教育和生活方式措施减轻 PMS 症状并降低对药物依赖。

**适用范围 / Scope**
- 轻度到中度经前综合征女性

**操作步骤 / Procedure**
1. 解释 PMS 是可理解、可管理的周期性症状群。
2. 指导规律进食、少量多餐并减少精制糖、盐、酒精和咖啡因。
3. 鼓励游泳、有氧运动、慢跑或网球等规律运动。
4. 安排放松、冥想、瑜伽或其他减压活动。
5. 建议在症状高峰期提前调整社交和工作安排。

**注意事项 / Precautions**
- 生活方式干预是一线管理基础。
- 不要过度诊断 PMS 而漏掉抑郁等心理障碍。
- 月见草油等补充剂证据有限,需如实告知。

**量化指标 / Metrics**
- PMS 生活方式干预覆盖率
- 症状严重度改善率
- 非药物管理依从率
