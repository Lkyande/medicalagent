# Skill: 慢性疲劳初始评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第63章 劳累/疲劳
- 页码: 第63章“临床方法——关键病史”“身体检查——主要特征”“关键性辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第63章.md`

**目标 / Objective**
建立对慢性疲劳病人的标准化首诊评估框架,避免漏诊常见心理和器质性原因。

**适用范围 / Scope**
- 持续 2 周以上疲劳或反复主诉“总是累”的病人

**操作步骤 / Procedure**
1. 区分生理性劳累、主观疲惫感与能力下降性疲劳,明确起病时间和持续时间。
2. 询问睡眠质量、压力事件、情绪症状、工作负荷、运动水平和物质使用情况。
3. 系统回顾感染、心血管、呼吸、内分泌、贫血和药物不良反应相关症状。
4. 检查体温、脉搏、血压、体重变化、甲状腺、心肺和神经肌肉体征。
5. 根据病史与查体选择基础筛查,如全血细胞计数、血糖、甲状腺功能、肝肾功能和尿检。

**注意事项 / Precautions**
- 超过半数疲劳病例可能与心理困扰有关,但不能因此忽略器质性评估。
- 药物、酒精和戒断反应是常见陷阱,应主动核对用药清单。
- 儿童和老年人的疲劳表现常不典型,应结合照护者信息补充病史。

**量化指标 / Metrics**
- 慢性疲劳首诊完整病史采集率
- 基础筛查项目完成率
- 首诊后 4 周明确病因或管理路径的比例
