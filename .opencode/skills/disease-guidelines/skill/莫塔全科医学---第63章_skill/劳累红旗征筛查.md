# Skill: 劳累红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第63章 劳累/疲劳
- 页码: 第63章“不能遗漏的严重疾病”“劳累的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第63章.md`

**目标 / Objective**
在劳累主诉中尽快识别提示严重器质性疾病的危险信号并决定进一步检查或转诊。

**适用范围 / Scope**
- 以持续或进行性劳累、疲劳、乏力为主诉的青少年和成人病人

**操作步骤 / Procedure**
1. 明确劳累是否持续超过 2 周,以及是否影响工作、学习或日常功能。
2. 询问体重下降、发热、盗汗、持续疼痛、夜间症状或进行性加重。
3. 筛查贫血、恶性肿瘤、慢性感染、心力衰竭、内分泌疾病和自身免疫病的线索。
4. 询问神经肌肉症状,如复视、肌无力、步态异常或进行性肢体无力。
5. 若存在红旗征或系统受累证据,立即进入有针对性的检查或专科转诊。

**注意事项 / Precautions**
- 不要在未排除器质性病因前直接归因于心理因素。
- 妊娠早期和更年期可表现为劳累,需结合病史避免误判。
- 老年人和合并多病共存者更容易隐藏严重病因。

**量化指标 / Metrics**
- 劳累病人红旗征记录率
- 存在红旗征病人的检查完成率
- 严重器质性疾病的及时转诊率
