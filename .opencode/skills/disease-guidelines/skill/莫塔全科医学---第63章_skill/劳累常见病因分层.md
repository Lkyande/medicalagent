# Skill: 劳累常见病因分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第63章 劳累/疲劳
- 页码: 第63章“概率诊断”“表63.1”“表63.2”“七个戴面具问题的清单”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第63章.md`

**目标 / Objective**
按常见性和危险性对劳累病因进行分层,指导优先排查顺序。

**适用范围 / Scope**
- 已完成初步问诊和体格检查的疲劳病人

**操作步骤 / Procedure**
1. 先将病因分为心理/生活方式、睡眠相关、感染后、器质性和原因不明五类。
2. 优先考虑压力、焦虑、抑郁、不适当生活方式和睡眠障碍等高概率病因。
3. 同步核查“戴面具问题”,重点包括抑郁、糖尿病、药物、贫血、甲状腺病和尿路感染。
4. 若伴系统症状或异常体征,上调贫血、恶性肿瘤、慢性感染、心衰和自身免疫病的优先级。
5. 根据分层结果制定处理路径:生活方式干预、心理评估、基础检查或专科转诊。

**注意事项 / Precautions**
- 避免“一次查遍所有项目”的过度检查模式。
- 睡眠呼吸暂停在中年男性和肥胖者中常见,不要漏问打鼾和白天嗜睡。
- 生活压力和丧亲之痛可与器质性病因并存。

**量化指标 / Metrics**
- 疲劳病因分层记录率
- 戴面具问题筛查完成率
- 睡眠障碍相关问诊覆盖率
