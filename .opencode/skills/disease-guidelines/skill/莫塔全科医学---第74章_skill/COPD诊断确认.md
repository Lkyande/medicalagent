# Skill: COPD诊断确认

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第74章 慢性阻塞性肺疾病
- 页码: 第74章“确认诊断和评估病情严重程度”“肺功能测试”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第74章.md`

**目标 / Objective**
对疑似 COPD 病人完成客观诊断确认并初步分级。

**适用范围 / Scope**
- 35 岁以上吸烟或既往吸烟者,伴慢性咳嗽、咳痰或进行性呼吸困难

**操作步骤 / Procedure**
1. 识别吸烟、职业粉尘、空气污染和 α1 抗胰蛋白酶缺乏等风险因素。
2. 询问进行性气促、慢性咳嗽、咳痰和反复胸部感染史。
3. 完成肺量计检查,确认支气管扩张后 FEV1/FVC <0.70。
4. 根据 FEV1 占预计值百分比分层病情严重程度。
5. 同步评估哮喘重叠、并发症和基线胸片或心电图需要。

**注意事项 / Precautions**
- COPD 不能仅凭病史推断,肺功能是金标准。
- 早期查体可能完全正常。
- 要主动识别哮喘-COPD 重叠而不是混为一谈。

**量化指标 / Metrics**
- 疑似 COPD 病人的肺功能完成率
- 支扩后 FEV1/FVC 记录率
- 初诊分级记录率
