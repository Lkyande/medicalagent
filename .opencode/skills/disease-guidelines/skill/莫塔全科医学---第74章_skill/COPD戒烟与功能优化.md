# Skill: COPD戒烟与功能优化

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第74章 慢性阻塞性肺疾病
- 页码: 第74章“O——优化功能”“给病人的建议”“肺康复”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第74章.md`

**目标 / Objective**
通过戒烟、吸入治疗和肺康复改善 COPD 症状并延缓恶化。

**适用范围 / Scope**
- 已确诊 COPD 的稳定期病人

**操作步骤 / Procedure**
1. 将戒烟设为首要治疗目标,每次就诊都实施简短干预。
2. 根据症状和分级优化吸入支气管扩张药方案,并复核装置使用技术。
3. 指导避免空气污染、烟雾和其他刺激性环境。
4. 尽早转入肺康复,包括教育、运动、行为矫正和支持。
5. 建立定期复查计划,追踪肺功能、症状、急性加重和药物减方机会。

**注意事项 / Precautions**
- 戒烟是唯一能延缓 COPD 病程的治疗方法。
- LAMA 是 COPD 治疗基石之一。
- 设备使用不当会显著降低吸入治疗效果。

**量化指标 / Metrics**
- COPD 病人的戒烟干预覆盖率
- 肺康复转介率
- 吸入技术复核率
