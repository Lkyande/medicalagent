# Skill: COPD急性加重门诊处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第74章 慢性阻塞性肺疾病
- 页码: 第74章“X——急性加重期的管理”“治疗的归纳”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第74章.md`

**目标 / Objective**
在门诊或基层场景中快速处理 COPD 急性加重并识别需住院者。

**适用范围 / Scope**
- COPD 病人出现呼吸困难、痰量或脓痰急性增加时

**操作步骤 / Procedure**
1. 识别急性加重三联征:呼吸困难加重、痰量增加、脓痰增加。
2. 先给予 SABA 和/或异丙托溴铵,优先使用 MDI 加储雾罐。
3. 评估氧饱和度,必要时给予控制性氧疗并警惕高碳酸血症。
4. 对中重度加重给予短疗程全身糖皮质激素。
5. 若有细菌感染指征则启动抗生素,并评估是否需要住院。

**注意事项 / Precautions**
- 雾化器最好由压缩空气驱动,避免高氧诱发问题。
- 抗生素不是所有急性加重的常规治疗。
- 精神状态改变、无法进食睡眠或发绀提示需更高级别照护。

**量化指标 / Metrics**
- 急性加重病人的支气管扩张剂首剂时效
- 系统激素使用符合率
- 门诊处理后转住院比例
