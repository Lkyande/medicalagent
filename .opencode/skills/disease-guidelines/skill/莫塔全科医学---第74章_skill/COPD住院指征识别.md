# Skill: COPD住院指征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第74章 慢性阻塞性肺疾病
- 页码: 第74章“转诊到住院服务”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第74章.md`

**目标 / Objective**
识别不能继续居家或门诊处理的 COPD 病人并及时转入住院治疗。

**适用范围 / Scope**
- 急性加重或功能明显下降的 COPD 病人

**操作步骤 / Procedure**
1. 评估是否快速恶化,并伴呼吸困难、咳嗽或痰液明显加重。
2. 询问病人是否已无法在家应对、无法自由走动、无法进食或睡眠。
3. 检查是否存在心理状态改变、发绀、新发心律失常或明显合并症。
4. 观察门诊治疗反应,若反应不佳则上调为住院评估。
5. 及早联系住院或专科团队,避免延迟至呼吸衰竭阶段。

**注意事项 / Precautions**
- 心理状态改变常提示高碳酸血症。
- 发绀和活动能力急剧下降是重要危险信号。
- 不要因病人平时“慢性差”而低估这次加重严重度。

**量化指标 / Metrics**
- COPD 住院指征记录率
- 住院决策时效
- 延迟转诊后急性恶化发生率
