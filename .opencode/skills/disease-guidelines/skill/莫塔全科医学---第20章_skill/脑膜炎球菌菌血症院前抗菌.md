# Skill: 脑膜炎球菌菌血症院前抗菌

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第20章 中枢神经系统感染
- 页码: 第20章“治疗(脑膜炎球菌菌血症:所有年龄)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第20章.md`

**目标 / Objective**
在疑似脑膜炎球菌菌血症时于到院前或到院即刻启动经验性抗菌治疗。

**适用范围 / Scope**
- 瘀点或紫癜性皮疹合并发热、休克或重病状态者

**操作步骤 / Procedure**
1. 识别躯干和四肢的瘀点或紫癜性皮疹,尤其压之不褪色者。
2. 将脑膜炎球菌菌血症视为急危重症,不等待典型脑膜炎体征出现。
3. 立即给予苄星青霉素或头孢曲松经验性治疗。
4. 若静脉通路不可行,改用肌内注射以避免治疗延误。
5. 紧急转运并同步进行败血症复苏与监护。

**注意事项 / Precautions**
- 可仅以脓毒症休克表现而无脑膜刺激征。
- 紫癜性皮疹是关键警讯。
- 任何年龄均应按急症处理。

**量化指标 / Metrics**
- 皮疹识别到首剂抗菌时间
- 院前或分诊即刻给药率
- 脓毒症转运时效
