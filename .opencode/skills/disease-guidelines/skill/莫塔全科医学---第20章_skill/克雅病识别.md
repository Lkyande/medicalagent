# Skill: 克雅病识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第20章 中枢神经系统感染
- 页码: 第20章“克-雅病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第20章.md`

**目标 / Objective**
对快速进展性痴呆伴肌阵挛病人识别克雅病的可能性并启动神经专科评估。

**适用范围 / Scope**
- 进行性痴呆、肌阵挛、共济失调或精神症状病人

**操作步骤 / Procedure**
1. 识别疲劳、嗜睡、人格改变和快速进展性认知下降。
2. 检查肌阵挛、共济失调、舞蹈样动作等神经体征。
3. 安排 MRI、脑电图和脑脊液 14-3-3 蛋白检测。
4. 排除其他可治疗的感染性、代谢性和结构性病因。
5. 转神经专科进行进一步确认和支持治疗规划。

**注意事项 / Precautions**
- 目前无特异性有效治疗。
- 最终确认通常依赖病理学。
- 需与其他快速进展性痴呆相鉴别。

**量化指标 / Metrics**
- 快速进展性痴呆 MRI 完成率
- 肌阵挛记录率
- 专科会诊完成率
