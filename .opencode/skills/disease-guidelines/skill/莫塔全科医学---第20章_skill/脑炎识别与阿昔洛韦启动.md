# Skill: 脑炎识别与阿昔洛韦启动

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第20章 中枢神经系统感染
- 页码: 第20章“脑炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第20章.md`

**目标 / Objective**
识别脑炎的脑功能障碍表现,并在疑似疱疹性脑炎时立即启动阿昔洛韦。

**适用范围 / Scope**
- 发热或病毒前驱症状后出现意识改变、癫痫、性格改变或局灶神经体征者

**操作步骤 / Procedure**
1. 识别前驱发热、不适、肌痛后出现的脑功能障碍。
2. 重点检查意识模糊、嗜睡、非理性行为、癫痫和局灶神经缺损。
3. 安排脑脊液 PCR、CT 或 MRI 以及必要时 EEG。
4. 对疑似单纯疱疹性脑炎者立即静脉滴注阿昔洛韦。
5. 住院进行支持治疗并排查弓形虫等免疫低下相关病因。

**注意事项 / Precautions**
- 非感染性自身免疫性脑炎也需纳入鉴别。
- 脑膜脑炎提示脑膜炎伴脑实质受累。
- 不应等待全部检查完成后再启动阿昔洛韦。

**量化指标 / Metrics**
- 疑似脑炎阿昔洛韦启动时效
- CSF PCR 完成率
- MRI 或 CT 完成率
