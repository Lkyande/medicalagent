# Skill: 病毒性脑膜炎与停抗评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第20章 中枢神经系统感染
- 页码: 第20章“病毒性脑膜炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第20章.md`

**目标 / Objective**
识别病毒性脑膜炎特征并结合 PCR 结果评估是否可尽早停用经验性抗生素。

**适用范围 / Scope**
- 临床类似脑膜炎但病情较轻、脑膜刺激征较少或 PCR 可及者

**操作步骤 / Procedure**
1. 识别儿童常见的良性、自限性脑膜炎表现。
2. 行腰椎穿刺并送脑脊液常规和 PCR 检测。
3. 将肠道病毒和疱疹病毒作为常见病原纳入分析。
4. 若 PCR 明确支持病毒性病因,重新评估继续使用经验性抗菌药的必要性。
5. 以补液、止痛和必要时阿昔洛韦为主要支持治疗。

**注意事项 / Precautions**
- 病毒性脑膜炎临床可模拟细菌性脑膜炎。
- 免疫缺陷病人需要特殊管理。
- 停抗前应结合全貌而非仅凭症状轻重。

**量化指标 / Metrics**
- 可疑病毒性脑膜炎 CSF PCR 完成率
- PCR 阳性后抗生素复评率
- 支持治疗实施率
