# Skill: 脑脓肿识别与禁忌腰穿

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第20章 中枢神经系统感染
- 页码: 第20章“脑脓肿和硬膜下脓肿”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第20章.md`

**目标 / Objective**
识别脑脓肿的占位和感染特征,避免误行腰椎穿刺并尽快转神经外科。

**适用范围 / Scope**
- 头痛、呕吐、乳头水肿、癫痫或局灶神经体征伴感染线索者

**操作步骤 / Procedure**
1. 识别颅内压升高表现,如头痛、呕吐、意识改变和视乳头水肿。
2. 检查局灶性神经缺损、癫痫及可能的牙源、耳源或鼻窦感染线索。
3. 安排 MRI 或 CT 评估占位性病变。
4. 完成血培养、炎症指标并考虑心内膜炎来源。
5. 明确腰椎穿刺禁忌,紧急转神经外科行抽吸或活检指导治疗。

**注意事项 / Precautions**
- 免疫抑制者病原谱不同,需考虑弓形虫、诺卡菌和真菌。
- 腰椎穿刺可带来危险,应避免。
- 抗菌治疗需结合外科取材结果优化。

**量化指标 / Metrics**
- 疑似脑脓肿影像完成率
- 腰穿禁忌识别率
- 神经外科转诊时效
