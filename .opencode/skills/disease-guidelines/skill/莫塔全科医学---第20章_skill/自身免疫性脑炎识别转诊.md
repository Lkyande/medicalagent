# Skill: 自身免疫性脑炎识别转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第20章 中枢神经系统感染
- 页码: 第20章“自身免疫性脑炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第20章.md`

**目标 / Objective**
对持续精神行为异常伴发热头痛前驱的年轻病人识别自身免疫性脑炎并尽快转专科。

**适用范围 / Scope**
- 年轻人出现奇怪行为、持续精神症状、癫痫或脑炎样表现者

**操作步骤 / Procedure**
1. 识别发热和头痛前驱后出现数日至数周持续精神行为异常。
2. 记录奇怪症状、非典型精神表现和神经系统伴随体征。
3. 考虑副肿瘤背景,尤其是卵巢肿瘤等相关线索。
4. 安排血液和脑脊液相关抗体检测,如 NMDA 受体抗体。
5. 尽快转神经专科进一步确诊并接受特异性免疫治疗。

**注意事项 / Precautions**
- 易被误诊为原发精神疾病。
- 抗体检测是重要确诊依据之一。
- 早期识别有助于改善功能结局。

**量化指标 / Metrics**
- 脑炎样精神症状病例抗体评估率
- 专科转诊时效
- 副肿瘤筛查启动率
