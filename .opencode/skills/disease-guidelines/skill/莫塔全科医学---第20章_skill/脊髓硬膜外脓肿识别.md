# Skill: 脊髓硬膜外脓肿识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第20章 中枢神经系统感染
- 页码: 第20章“脊髓硬膜下或硬膜外脓肿”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第20章.md`

**目标 / Objective**
在背痛和进行性神经功能损害病人中及时识别脊髓硬膜外脓肿。

**适用范围 / Scope**
- 进行性背痛、脊柱压痛、下肢无力或感觉丧失者

**操作步骤 / Procedure**
1. 对逐渐加重的背痛和脊柱叩击痛保持高度警惕。
2. 识别伴或不伴发热的神经根痛和进行性下肢无力。
3. 追问疖肿、压疮、骨髓炎、创伤及硬膜外麻醉史。
4. 安排血培养和 MRI 明确脓肿位置及脊髓受压程度。
5. 紧急转神经外科,并按经验性静脉抗菌路径处理。

**注意事项 / Precautions**
- 约 1/3 为自发性,无明显诱因不能排除。
- 常见病原为金黄色葡萄球菌。
- 误诊可导致不可逆瘫痪。

**量化指标 / Metrics**
- 背痛伴神经缺损病例 MRI 完成率
- 神经外科急诊转诊时效
- 血培养完成率
