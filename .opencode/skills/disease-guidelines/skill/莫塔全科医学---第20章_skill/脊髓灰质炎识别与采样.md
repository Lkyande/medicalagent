# Skill: 脊髓灰质炎识别与采样

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第20章 中枢神经系统感染
- 页码: 第20章“脊髓灰质炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第20章.md`

**目标 / Objective**
识别脊髓灰质炎的麻痹前和弛缓性麻痹阶段,并完成病原学采样。

**适用范围 / Scope**
- 流感样前驱后出现弛缓性麻痹或延髓症状者

**操作步骤 / Procedure**
1. 询问流行地区暴露和粪口传播风险。
2. 识别发热、咽痛后出现恶心呕吐、头痛和颈项僵直的麻痹前阶段。
3. 检查弛缓性麻痹是否以肢体为主且无明显感觉减退。
4. 采集咽拭子、粪便及必要时脑脊液进行培养和 PCR。
5. 将有症状或瘫痪病人转医院并核查疫苗接种状态。

**注意事项 / Precautions**
- 95% 感染者可无症状。
- 需与非病毒性弛缓性麻痹病因鉴别。
- 呼吸衰竭提示延髓受累,应急转。

**量化指标 / Metrics**
- 急性弛缓性麻痹病例脊灰纳入鉴别率
- 咽拭子和粪便采样完成率
- 住院转诊时效
