# Skill: 细菌性脑膜炎识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第20章 中枢神经系统感染
- 页码: 第20章“脑膜炎”“细菌性脑膜炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第20章.md`

**目标 / Objective**
尽早识别细菌性脑膜炎的典型和非典型表现,避免延误抗感染治疗。

**适用范围 / Scope**
- 发热、头痛、颈项强直、嗜睡、呕吐或意识改变者

**操作步骤 / Procedure**
1. 识别头痛、畏光、颈项强直三联征及不适、呕吐、发热、嗜睡等症状。
2. 婴幼儿重点观察发热、拒食、易激惹、四肢冰凉和囟门膨隆。
3. 3 岁以上儿童和成人重点识别明显脑膜刺激征与后期谵妄。
4. 牢记抗生素可能掩盖症状,发热治疗后不缓解仍需考虑脑膜炎。
5. 一旦怀疑,立即进入血培养、腰穿和经验性治疗流程。

**注意事项 / Precautions**
- 细菌性脑膜炎是医疗急症。
- 四肢冰凉是幼儿可靠体征之一。
- 疾病暴发期可先表现为败血症而非典型脑膜炎体征。

**量化指标 / Metrics**
- 脑膜炎三联征记录率
- 婴幼儿高危体征识别率
- 疑似病例转入急救流程时效
