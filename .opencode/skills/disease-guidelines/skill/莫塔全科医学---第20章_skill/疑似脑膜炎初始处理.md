# Skill: 疑似脑膜炎初始处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第20章 中枢神经系统感染
- 页码: 第20章“治疗(疑似脑膜炎)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第20章.md`

**目标 / Objective**
在怀疑脑膜炎时快速完成复苏、取样和经验性治疗启动。

**适用范围 / Scope**
- 所有疑似细菌性脑膜炎病人

**操作步骤 / Procedure**
1. 立即吸氧并建立静脉通路。
2. 在评估后 30 分钟内采集血培养,理想状态下在入院前完成。
3. 对儿童按灌注状态给予生理盐水复苏,必要时增量至 60ml/kg。
4. 评估腰穿时机与安全性,成人必要时先行 CT。
5. 在不显著延迟前提下尽快给予地塞米松和头孢曲松或头孢噻肟。

**注意事项 / Precautions**
- 不要因等待检查而暂停治疗。
- 静脉给药最佳,肌内或骨间给药优于无治疗。
- 地塞米松与抗生素同步或稍早给药更合适。

**量化指标 / Metrics**
- 疑似脑膜炎首剂抗生素时间
- 血培养抗生素前完成率
- 复苏液体管理及时率
