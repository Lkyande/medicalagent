# Skill: 急性细菌性前列腺炎识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第106章 前列腺疾病
- 页码: 第106章“急性细菌性前列腺炎的临床特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第106章.md`

**目标 / Objective**
根据典型三联征快速识别急性细菌性前列腺炎并防止败血症和尿潴留。

**适用范围 / Scope**
- 25 至 50 岁男性发热、排尿困难和会阴痛就诊时

**操作步骤 / Procedure**
1. 识别发热、会阴痛和排尿困难的诊断三联征。
2. 询问尿频、尿急、寒战和膀胱出口梗阻症状。
3. 进行温和 DRE,查找前列腺触痛、肿胀和温度升高。
4. 警惕脓肿、急性尿潴留和菌血症并发症。
5. 根据严重程度决定门诊口服或住院静脉抗感染路径。

**注意事项 / Precautions**
- 急性细菌性前列腺炎虽不常见,但可危及生命。
- DRE 应避免粗暴操作。
- 并发尿潴留或脓肿时需泌尿外科介入。

**量化指标 / Metrics**
- 前列腺炎三联征识别率
- 并发症早期识别率
- 重症住院转诊率
