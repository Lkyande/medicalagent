# Skill: LUTS与BOO评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第106章 前列腺疾病
- 页码: 第106章“下尿路症状”“膀胱出口梗阻”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第106章.md`

**目标 / Objective**
区分下尿路储尿期和排尿期症状,判断是否存在膀胱出口梗阻。

**适用范围 / Scope**
- 60 岁以上男性或其他出现尿频、尿急、夜尿、尿流弱的男性

**操作步骤 / Procedure**
1. 将症状分为排尿期梗阻性与储尿期刺激性两类。
2. 使用 IPSS 量化症状负担。
3. 完成腹部检查、DRE 和生殖器检查,评估前列腺大小及膀胱充盈。
4. 安排中段尿、肾功能、PSA、泌尿系超声和残余尿评估。
5. 根据症状负担和检查结果区分观察随访、药物治疗或泌尿科转诊路径。

**注意事项 / Precautions**
- 小前列腺也可能引起 BOO。
- 多尿或夜尿增多不一定全由前列腺梗阻造成。
- 病人烦恼程度与客观梗阻程度并不总是平行。

**量化指标 / Metrics**
- LUTS 分类记录率
- IPSS 使用率
- 超声残余尿评估率
