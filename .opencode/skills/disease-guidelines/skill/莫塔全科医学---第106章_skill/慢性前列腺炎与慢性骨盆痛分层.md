# Skill: 慢性前列腺炎与慢性骨盆痛分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第106章 前列腺疾病
- 页码: 第106章“慢性细菌性前列腺炎”“慢性前列腺炎/慢性骨盆疼痛综合征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第106章.md`

**目标 / Objective**
区分慢性细菌性前列腺炎与非感染性慢性骨盆疼痛综合征,避免抗生素过度使用。

**适用范围 / Scope**
- 会阴痛、射精痛、轻度尿路刺激症状反复发作的男性

**操作步骤 / Procedure**
1. 询问反复尿路感染、会阴痛、耻骨上痛和射精痛病史。
2. 结合前列腺按压分泌液、尿液培养和白细胞情况判断是否感染。
3. 对培养阳性且伴脓细胞者采用针对性长疗程抗生素。
4. 对多数非感染性病例强调症状管理,避免反复经验性抗生素。
5. 可使用 NSAIDs、生活方式调整和疼痛/心理支持,必要时转诊。

**注意事项 / Precautions**
- 90%~95% 的慢性前列腺炎并非感染所致。
- 反复抗生素治疗会带来伤害且获益有限。
- IPSS 可用于追踪症状严重度和疗效。

**量化指标 / Metrics**
- 慢性前列腺炎病因分层率
- 不必要抗生素使用率
- 症状量表随访率
