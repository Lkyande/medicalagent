# Skill: 行为改变支持

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“行为改善”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
运用指导式、动机式和行为式策略支持病人完成困难的生活方式改变。

**适用范围 / Scope**
- 吸烟、饮酒、运动不足、肥胖和其他长期行为风险因素管理

**操作步骤 / Procedure**
1. 评估病人的改变动机和当前障碍。
2. 根据病人状态选择指导式、动机式或行为式技术。
3. 与病人制订小而可执行的改变目标。
4. 调用多学科团队资源提供持续支持。
5. 在随访中监测改变进度并调整策略。

**注意事项 / Precautions**
- 多年形成的习惯通常难以快速改变,应避免不切实际期待。
- 单靠说教往往无效,需要持续支持和强化。
- 对依赖性行为应同时评估精神心理共病和复发风险。

**量化指标 / Metrics**
- 行为改变目标设定率
- 随访中的维持率
- 多学科支持使用率
