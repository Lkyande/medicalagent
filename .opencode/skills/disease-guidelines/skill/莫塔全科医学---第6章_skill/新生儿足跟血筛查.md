# Skill: 新生儿足跟血筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“新生儿的筛查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
在出生后规定时间完成新生儿足跟血筛查,及早识别可治疗的先天代谢和内分泌异常。

**适用范围 / Scope**
- 出生后 48 到 72 小时的新生儿

**操作步骤 / Procedure**
1. 在出生后 48 到 72 小时安排足跟采血。
2. 按当地筛查程序采集并送检标准筛查项目。
3. 重点确认是否涵盖囊性纤维化、苯丙酮尿症和甲状腺功能减退症等项目。
4. 记录筛查已完成情况及结果回报路径。
5. 对异常结果立即通知家属并安排进一步评估和管理。

**注意事项 / Precautions**
- 错过采样时间会延误可逆疾病的诊断窗口。
- 结果异常后的联系和复查安排必须明确可靠。
- 向家属解释筛查目的可提高配合度并减少焦虑。

**量化指标 / Metrics**
- 48-72小时内筛查完成率
- 异常结果回报时效
- 异常筛查后复查到位率
