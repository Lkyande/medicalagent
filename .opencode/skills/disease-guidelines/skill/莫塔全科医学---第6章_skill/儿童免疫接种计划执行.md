# Skill: 儿童免疫接种计划执行

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“免疫接种”“NHMRC 推荐的免疫接种计划”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
按儿童免疫程序表执行和追踪接种,保障连续预防和补种完整性。

**适用范围 / Scope**
- 新生儿、婴幼儿、学龄儿童和学校接种项目

**操作步骤 / Procedure**
1. 核对儿童年龄与既往接种记录。
2. 按年龄节点安排相应疫苗,包括出生、2 月龄、4 月龄、6 月龄、12 月龄、18 月龄和 4 岁程序。
3. 同步关注学校项目如 HPV、DTP 和脑膜炎球菌疫苗。
4. 对遗漏接种者尽快制定补种计划。
5. 对原住民和其他高危儿童补充额外推荐疫苗。
6. 每次接种后更新记录并告知下一次时间点。

**注意事项 / Precautions**
- 轻微上呼吸道感染通常不是推迟接种的理由。
- 接种依从性高度依赖清晰记录和提醒系统。
- 对家长迟疑或担忧者应充分解释获益与常见不良反应。

**量化指标 / Metrics**
- 儿童按时接种率
- 漏种补种完成率
- 学校项目覆盖率
