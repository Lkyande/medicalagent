# Skill: 成人周期性筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“成年人的筛查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
按年龄和风险因素实施成人周期性筛查,早期发现可干预疾病和危险状态。

**适用范围 / Scope**
- 成人体检、慢病风险管理和预防门诊

**操作步骤 / Procedure**
1. 定期记录体重、BMI 和腹部肥胖指标。
2. 对 16 岁及以上人群至少每 1 到 2 年测量一次血压。
3. 对 45 岁及以上成年人每 5 年评估一次胆固醇。
4. 对 40 岁以上病人每 3 年筛查一次空腹血糖。
5. 根据年龄和风险安排宫颈癌、乳腺癌和结直肠癌筛查。
6. 对皮肤癌和口腔癌风险人群进行防晒、口腔检查和生活方式教育。
7. 对前列腺癌筛查使用知情决策而非常规普筛。

**注意事项 / Precautions**
- 筛查年龄和间隔需结合当前指南更新,避免机械套用。
- 阳性或异常结果必须有明确后续路径。
- 对高风险家族史人群需考虑更早或更强化的筛查策略。

**量化指标 / Metrics**
- 关键筛查项目完成率
- 异常结果跟进率
- 高风险人群覆盖率
