# Skill: 结直肠癌筛查安排

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“成年人的筛查”中结直肠癌相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
根据风险分层安排 FOBT 和结肠镜筛查,提高结直肠癌和癌前病变早期发现率。

**适用范围 / Scope**
- 50 到 74 岁平均风险人群及有家族史或炎症性肠病的高风险人群

**操作步骤 / Procedure**
1. 采集家族史、炎症性肠病史、直肠出血史和既往息肉/癌症史。
2. 对平均或略高风险的 50 到 74 岁无症状人群每 2 年安排一次 FOBT。
3. 对中危和高危家族史人群按指南安排更早及更频繁的 FOBT 或结肠镜。
4. 对既往大肠癌、结肠腺瘤或溃疡性结肠炎病人安排结肠镜及必要活检。
5. 对某些极高风险病人考虑外科预防方案评估。

**注意事项 / Precautions**
- 仅做 FOBT 而忽略高危家族史会漏掉需要结肠镜的人群。
- 阳性筛查结果必须有清晰的结肠镜后续路径。
- 高风险人群应考虑遗传检测和专科协作。

**量化指标 / Metrics**
- FOBT覆盖率
- 阳性FOBT后结肠镜完成率
- 高风险家族史分层准确率
