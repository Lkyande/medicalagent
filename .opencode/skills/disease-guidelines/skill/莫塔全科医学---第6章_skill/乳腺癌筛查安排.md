# Skill: 乳腺癌筛查安排

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“成年人的筛查”中乳腺癌相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
根据年龄和风险合理安排乳腺癌筛查,同时避免把阴性影像误作排除依据。

**适用范围 / Scope**
- 中年及老年女性,尤其 50 到 74 岁人群

**操作步骤 / Procedure**
1. 确认病人年龄和乳腺癌家族及个人风险因素。
2. 对 50 到 74 岁女性建议至少每 2 年进行一次乳房 X 线检查。
3. 对 40 到 49 岁女性根据个体情况讨论选择性筛查。
4. 对高风险人群考虑基因检测和更强化监测。
5. 若存在可触及肿块,即使影像阴性也进行整体评估和进一步检查。

**注意事项 / Precautions**
- 乳房 X 线存在假阴性,尤其在致密乳腺组织中。
- 可触及病灶不能被单次阴性影像轻率排除。
- 筛查决策需结合年龄、风险和病人偏好。

**量化指标 / Metrics**
- 50-74岁筛查覆盖率
- 高风险人群识别率
- 可疑病灶进一步评估完成率
