# Skill: 儿童健康筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“儿童健康筛查”“总体发育”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
通过分年龄儿童筛查早期识别生长、感觉、运动和发育异常,实现及时干预和转诊。

**适用范围 / Scope**
- 婴幼儿、学龄前儿童和学龄儿童的常规预防保健

**操作步骤 / Procedure**
1. 使用儿童健康记录本并鼓励家长每次就诊携带。
2. 连续记录身高、体重、头围和生长曲线,必要时计算 BMI。
3. 按年龄节点筛查髋关节、斜视、视力、听力和睾丸下降情况。
4. 评估口腔健康、脊柱侧凸、心脏听诊和股动脉搏动。
5. 评估说话语言及总体发育,包括社交情感、如厕习惯、行为和情绪。
6. 对异常结果及时转诊上级医疗机构或相关专科。

**注意事项 / Precautions**
- 不能单凭一次测量判断儿童发育是否正常,应连续观察。
- 若家长担心听力或发育问题,即使常规节点未到也应及时评估。
- 需警惕自闭症谱系障碍等发育危险信号。

**量化指标 / Metrics**
- 儿童筛查节点完成率
- 生长曲线连续记录率
- 异常结果及时转诊率
