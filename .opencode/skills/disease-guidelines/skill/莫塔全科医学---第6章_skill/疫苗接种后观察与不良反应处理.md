# Skill: 疫苗接种后观察与不良反应处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“疫苗接种的不良反应”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
规范疫苗接种后观察和常见不良反应处置,提高接种安全性与家属信心。

**适用范围 / Scope**
- 所有门诊免疫接种场景

**操作步骤 / Procedure**
1. 接种前询问既往严重过敏反应和相关禁忌证。
2. 接种后安排观察 15 到 30 分钟。
3. 告知常见反应如烦躁、不适、发热和局部反应。
4. 对发热和局部疼痛根据需要给予对乙酰氨基酚。
5. 对高热或严重过敏反应立即启动相应急救流程。
6. 向家属说明何种情况需尽快复诊或就医。

**注意事项 / Precautions**
- 不建议在接种时或接种后立即常规使用对乙酰氨基酚。
- 体温过高时应推迟接种,轻微疾病通常不需推迟。
- 百白破相关严重反应属于重要绝对禁忌证,需严格核查。

**量化指标 / Metrics**
- 接种后观察完成率
- 不良反应宣教完成率
- 严重不良反应及时处置率
