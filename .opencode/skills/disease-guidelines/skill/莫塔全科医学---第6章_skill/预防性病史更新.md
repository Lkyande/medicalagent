# Skill: 预防性病史更新

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
通过结构化预防性病史更新识别危险因素、家庭倾向和可干预问题。

**适用范围 / Scope**
- 周期性健康检查、慢病随访和新病人建档

**操作步骤 / Procedure**
1. 回顾并更新既有病历中的重要预防信息。
2. 采集家族史,重点关注心血管病、癌症、糖尿病、哮喘和遗传病。
3. 询问自杀、意外事故和药物滥用相关风险。
4. 评估运动、营养、职业危害和性健康/避孕情况。
5. 对老年人补充躯体功能、家庭情况和社会支持评估。
6. 同时警惕抑郁、糖尿病、药物问题、贫血和甲减等“戴面具问题”。

**注意事项 / Precautions**
- 预防性病史不能只复制旧记录,需动态更新。
- 谈及性健康、自杀和物质使用时要确保隐私和非评判氛围。
- 老年人和未分化症状病人更需要关注“戴面具问题”。

**量化指标 / Metrics**
- 预防性病史完整率
- 家族和行为风险识别率
- 隐匿问题后续评估启动率
