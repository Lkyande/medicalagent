# Skill: 机会性预防实施

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“定义”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
在每次全科看诊中主动识别可预防因素并嵌入预防措施,把预防态度落实到临床服务。

**适用范围 / Scope**
- 所有全科门诊咨询,尤其慢病管理、复诊和健康行为问题场景

**操作步骤 / Procedure**
1. 在处理当次主诉外,主动寻找当前疾病或生活方式中的可预防因素。
2. 识别病人当前状况与既往不健康行为之间的关联。
3. 判断可采用的一级、二级或三级预防措施。
4. 提供生病教育、健康行为指导或必要的早期筛查。
5. 将预防干预纳入病历和后续管理计划。

**注意事项 / Precautions**
- 机会性预防不应脱离病人当次就诊目的和接受能力。
- 医源性问题本身也属于预防关注范围,需避免因过度干预带来新风险。
- 对多病共存和时间受限场景,应明确优先级。

**量化指标 / Metrics**
- 看诊中预防性干预触发率
- 可预防风险记录率
- 后续预防计划执行率
