# Skill: 筛查目标分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“筛查的目的”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
明确筛查对象属于风险个体、无症状早期疾病个体还是已出现可控影响的有症状个体,提高筛查针对性。

**适用范围 / Scope**
- 全科体检、预防性门诊和人群健康管理

**操作步骤 / Procedure**
1. 先判断对象是否属于存在发病风险但尚“健康”的个体。
2. 再判断是否存在无症状但已有早期疾病征象。
3. 识别是否存在已有症状但尚无不可逆异常、仍可控制影响的个体。
4. 根据分层结果选择适合的筛查方式和随访路径。
5. 将筛查结果与后续干预措施一并记录。

**注意事项 / Precautions**
- 筛查目的不只是找病,还包括识别风险和未获足够服务的病人。
- 对假阳性、假阴性和过度诊断风险要提前沟通。
- 分层后必须有后续处理计划,否则筛查价值有限。

**量化指标 / Metrics**
- 筛查对象分层记录率
- 高风险或阳性结果后续跟进率
- 无效筛查减少率
