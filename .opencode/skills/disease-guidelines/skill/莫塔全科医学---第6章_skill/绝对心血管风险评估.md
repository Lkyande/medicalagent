# Skill: 绝对心血管风险评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“血管疾病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
结合多项风险因素评估病人 5 年心血管事件绝对风险,用于指导预防干预强度。

**适用范围 / Scope**
- 需要进行心血管一级或二级预防评估的成年人

**操作步骤 / Procedure**
1. 记录性别和年龄。
2. 评估吸烟状态、糖尿病情况和家族史。
3. 测量血压。
4. 获取总胆固醇与 HDL 比值。
5. 使用绝对心血管风险工具计算 5 年事件风险。
6. 根据风险分层制定戒烟、饮食、运动和药物等预防策略。

**注意事项 / Precautions**
- 风险工具是辅助决策工具,不能替代临床判断。
- 重度吸烟者和高危共病者即使症状不明显也需积极干预。
- 风险沟通时应避免只报数字而不解释具体可改变因素。

**量化指标 / Metrics**
- 5年风险评估完成率
- 高风险病人干预启动率
- 血压、血脂或吸烟状态改善率
