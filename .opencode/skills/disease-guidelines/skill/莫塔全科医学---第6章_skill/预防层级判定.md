# Skill: 预防层级判定

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“一级预防”“二级预防”“三级预防”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
根据疾病所处阶段准确判定一级、二级或三级预防策略,提高预防措施匹配度。

**适用范围 / Scope**
- 全科预防决策、慢病管理、筛查和康复衔接场景

**操作步骤 / Procedure**
1. 判断病人当前处于无病、无症状早期、已确诊或失能阶段。
2. 若目标是防止疾病发生,优先归入一级预防并选择教育、接种或环境干预。
3. 若目标是无症状期早发现和延缓进展,归入二级预防并安排筛查或早治疗。
4. 若病人已确诊并存在损害或失能风险,归入三级预防并强调康复和功能重建。
5. 在病历中注明所采用的预防层级和干预目的。

**注意事项 / Precautions**
- 二级和三级预防边界常不完全清晰,应以临床目的为核心。
- 老年人和残障人士场景中三级预防尤为重要。
- 预防层级判定不是理论练习,应服务于实际干预决策。

**量化指标 / Metrics**
- 预防层级记录率
- 干预与疾病阶段匹配率
- 康复或筛查计划完成率
