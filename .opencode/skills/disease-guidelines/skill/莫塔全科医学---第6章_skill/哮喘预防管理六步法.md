# Skill: 哮喘预防管理六步法

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“哮喘和其他呼吸系统疾病”“六步哮喘管理计划”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
通过结构化评估、监测、用药和教育,最大程度控制哮喘并减少可预防的发病和死亡。

**适用范围 / Scope**
- 已确诊或疑似哮喘的儿童和成人病人

**操作步骤 / Procedure**
1. 确定哮喘严重程度。
2. 设法达到最佳肺功能。
3. 识别并避免诱发因素,维持最佳肺功能。
4. 采用最佳用药方案维持控制。
5. 为病人制订书面且易理解的哮喘行动计划。
6. 定期进行教育、复核和病情评估,必要时使用家庭峰流速监测。

**注意事项 / Precautions**
- 许多已治疗病人仍控制不足,需定期复核而非默认稳定。
- 必须同时管理病因性支气管炎症和诱发因素。
- 书面计划应确保病人和家属都能理解并执行。

**量化指标 / Metrics**
- 书面行动计划覆盖率
- 峰流速或肺功能改善情况
- 急性发作和急诊就诊次数
