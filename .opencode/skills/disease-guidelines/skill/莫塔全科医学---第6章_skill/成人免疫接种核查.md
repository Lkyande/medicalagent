# Skill: 成人免疫接种核查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“免疫接种”“疫苗情况”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
系统核查成人免疫状态并按年龄、妊娠和风险暴露补足必要疫苗。

**适用范围 / Scope**
- 成人预防门诊、慢病管理、妊娠管理和职业暴露评估

**操作步骤 / Procedure**
1. 核对基础免疫史和既往加强免疫记录。
2. 确认所有成年人是否每 10 年接受一次成人白喉破伤风强化免疫。
3. 对妊娠女性评估并安排流感疫苗和孕晚期百日咳疫苗。
4. 对 65 岁以上安排年度流感疫苗,必要时补充肺炎球菌疫苗。
5. 对 70 到 79 岁评估带状疱疹疫苗适应证。
6. 根据职业、旅行、慢病和免疫抑制情况补充甲肝、乙肝等疫苗。

**注意事项 / Precautions**
- 成人免疫遗漏常见于多机构就诊病人,需主动核查而非等待病人提出。
- 风险暴露和免疫抑制状态会改变免疫策略。
- 疫苗禁忌证和既往严重反应需详细记录。

**量化指标 / Metrics**
- 成人免疫史核查率
- 适应证疫苗补种完成率
- 高危人群流感/肺炎球菌覆盖率
