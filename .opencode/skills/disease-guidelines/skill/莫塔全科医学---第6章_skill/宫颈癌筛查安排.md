# Skill: 宫颈癌筛查安排

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“成年人的筛查”中宫颈癌相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
按年龄和结果安排宫颈癌筛查与随访,提高癌前病变早发现率。

**适用范围 / Scope**
- 有过性生活的适龄女性

**操作步骤 / Procedure**
1. 确认病人年龄和既往宫颈筛查史。
2. 从 25 岁开始到 74 岁安排 HPV 宫颈筛查。
3. 若本次结果阴性,按 5 年间隔安排下一次筛查。
4. 若 HPV 阳性,进一步进行宫颈细胞学检查并按指南随访。
5. 对 70 到 74 岁女性提供最终退出检测,阴性后停止常规筛查。

**注意事项 / Precautions**
- 筛查安排需基于最新国家指南和病人既往结果。
- 对筛查羞怯或依从性差病人要加强解释和提醒。
- 阳性结果后的失访会显著削弱筛查效果。

**量化指标 / Metrics**
- 适龄女性筛查覆盖率
- HPV阳性后细胞学随访完成率
- 退出检测完成率
