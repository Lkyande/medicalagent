# Skill: 高价值预防时机识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第6章 全科医学中的预防
- 页码: 第6章“预防的最佳时机”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第6章.md`

**目标 / Objective**
在高收益临床节点主动启动预防服务,提升预防干预命中率和实际效果。

**适用范围 / Scope**
- 产前、产后、计划生育、婴儿就诊、旅行咨询、危机事件和慢病场景

**操作步骤 / Procedure**
1. 在产前、产后和妊娠计划阶段主动评估预防需求。
2. 在婴儿就诊时同步核对免疫、喂养和家庭安全问题。
3. 在海外旅行前提供针对性预防咨询和接种建议。
4. 在危急或潜在危急时刻利用病人高关注度进行行为干预。
5. 优先关注计划生育、免疫、母婴关系、戒烟、高血压和丧亲支持等高价值时机。

**注意事项 / Precautions**
- 病人处于压力事件中时,预防信息应简短且以安全为先。
- 对妊娠和婴幼儿相关时机,需兼顾家庭整体教育。
- 旅行和产前预防往往需要提前介入,避免临近节点过晚处理。

**量化指标 / Metrics**
- 关键预防时机识别率
- 对应预防服务完成率
- 相关高风险行为改善率
