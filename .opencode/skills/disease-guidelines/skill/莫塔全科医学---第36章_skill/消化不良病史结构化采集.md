# Skill: 消化不良病史结构化采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第36章 消化不良
- 页码: 第36章“病史”“关键的提问”“症状分析”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第36章.md`

**目标 / Objective**
通过澄清症状定义和诱因关系,区分反流、溃疡、胆道病和非胃肠道疼痛。

**适用范围 / Scope**
- 上腹不适、烧心、反酸、餐后不适或泛称“消化不良”的病人

**操作步骤 / Procedure**
1. 先澄清病人所说“消化不良”或“烧心”的具体含义和主诉位置。
2. 追问症状与进食、牛奶、抗酸药、油腻食物、酒精、弯腰和平卧的关系。
3. 记录不适部位和放射范围,如胸骨后、上腹、肩胛间区或肩部放射。
4. 询问伴随吞咽困难、反酸、体重减轻、贫血症状、便秘腹泻和呼吸短促。
5. 核对用药、烟酒和压力因素,同时主动排除缺血性心脏病可能。

**注意事项 / Precautions**
- 消化不良样疼痛必须始终考虑心绞痛和食管痉挛等非胃病原因。
- 进食加重或缓解模式对胃溃疡与十二指肠溃疡鉴别有帮助。
- 症状与餐后、弯腰、平卧关系往往比体格检查更有提示性。

**量化指标 / Metrics**
- 病史要素完整率
- 心源性风险评估率
- 初始病因分层准确率
