# Skill: 消化不良红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第36章 消化不良
- 页码: 第36章“消化不良的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第36章.md`

**目标 / Objective**
在消化不良病人中及时识别提示癌症、出血或严重溃疡病变的警报信号。

**适用范围 / Scope**
- 所有消化不良、烧心或持续上腹不适病人

**操作步骤 / Procedure**
1. 筛查吞咽困难、厌食、黑便、呕血、夜间痛和症状模式改变。
2. 评估不明原因体重减轻、疼痛放射至背部和身体检查异常征象。
3. 对 >40 岁尤其 >50 岁病人提高对器质性病变的警惕。
4. 红旗征存在时优先安排上消化道内镜而不是长期经验性用药观察。
5. 对老年病人合并呕吐、厌食和消瘦时优先排除胃癌。

**注意事项 / Precautions**
- 夜间疼痛和背部放射痛不能简单解释为功能性消化不良。
- 老年消化不良更常见器质性病因。
- 红旗征阴性并不代表永远不需要内镜,需结合病程变化复评。

**量化指标 / Metrics**
- 红旗征记录率
- 高危病人胃镜完成率
- 胃癌或复杂溃疡早期检出率
