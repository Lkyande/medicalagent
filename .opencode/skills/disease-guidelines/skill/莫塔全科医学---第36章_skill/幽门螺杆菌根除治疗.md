# Skill: 幽门螺杆菌根除治疗

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第36章 消化不良
- 页码: 第36章“根除幽门螺杆菌的治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第36章.md`

**目标 / Objective**
按一线或补救方案完成幽门螺杆菌根除,降低溃疡复发和胃癌风险。

**适用范围 / Scope**
- 已证实 Hp 感染并需根除治疗的消化性溃疡或相关病变病人

**操作步骤 / Procedure**
1. 一线方案首选 PPI + 克拉霉素 500mg + 阿莫西林 1g,每日 2 次,疗程 7 日。
2. 青霉素过敏者改用 PPI + 克拉霉素 + 甲硝唑方案。
3. 三联失败时升级至左氧氟沙星补救方案或铋剂四联方案。
4. 解释依从性和耐药问题,强调按时足疗程服药。
5. 治疗后用尿素呼气试验或按溃疡部位要求复查根除效果。

**注意事项 / Precautions**
- 克拉霉素和甲硝唑耐药上升,失败后不要简单重复原方案。
- 根除后通常不需长期针对 Hp 溃疡维持抗分泌治疗。
- 儿童确诊感染的根除方案需按年龄和专科建议调整。

**量化指标 / Metrics**
- 根除方案完成率
- 根除成功率
- 一线失败后规范补救率
