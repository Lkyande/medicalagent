# Skill: 婴儿胃食管反流非药物管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第36章 消化不良
- 页码: 第36章“胃食管反流”“管理”“喂食增稠”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第36章.md`

**目标 / Objective**
通过喂养和体位调整减少婴儿生理性反流及家长焦虑。

**适用范围 / Scope**
- 新生儿和婴儿轻中度胃食管反流或溢奶

**操作步骤 / Procedure**
1. 向家长解释多数婴儿反流是生理性的,通常不影响生长发育。
2. 建议少食多餐,并根据喂养方式考虑适度增稠奶液。
3. 婴儿睡觉时采取左侧卧位并将床头抬高约 20°~30°。
4. 对配方奶或母乳喂养婴儿,按指导加入增稠粉、反流剂或玉米淀粉。
5. 若出现呕血、贫血、食管炎、生长迟缓或吸入性肺炎迹象,及时转儿科进一步评估。

**注意事项 / Precautions**
- 大多数病例随年龄增长改善,家长释疑本身很重要。
- 严重病理性反流不能只靠家庭调整,需专科介入。
- 增稠配方和添加剂比例需按指导使用,避免随意加量。

**量化指标 / Metrics**
- 家长教育覆盖率
- 非药物干预后反流症状改善率
- 并发症转诊及时率
