# Skill: 幽门螺杆菌检测路径

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第36章 消化不良
- 页码: 第36章“幽门螺杆菌试验”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第36章.md`

**目标 / Objective**
为消化不良和疑似溃疡病人选择合适的幽门螺杆菌检测方式并区分诊断与随访用途。

**适用范围 / Scope**
- 怀疑消化性溃疡、慢性消化不良或需溃疡病因评估的病人

**操作步骤 / Procedure**
1. 判断是否需要非侵入性初筛还是已进入胃镜路径下的侵入性检测。
2. 初筛时可选血清 IgG、尿素呼气试验或粪便抗原试验。
3. 需要随访根除效果时优先选择尿素呼气试验或粪便抗原,不以血清学复查。
4. 若病人接受胃镜,同步考虑黏膜活检做组织学、快速尿素酶或培养检查。
5. 将检测结果与溃疡类型、NSAIDs 暴露和症状严重度一起解释,决定是否根除治疗。

**注意事项 / Precautions**
- 血清 IgG 适合诊断,不适合判断是否根除成功。
- 检测选择要结合病人是否需要内镜、是否用于复查和当地可及性。
- 幽门螺杆菌与反流关系证据不一致,不能把所有反流都归因于 Hp。

**量化指标 / Metrics**
- 适应证病人 Hp 检测完成率
- 根除后规范复查率
- 检测方式选择合规率
