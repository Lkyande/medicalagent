# Skill: 消化性溃疡识别与初始管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第36章 消化不良
- 页码: 第36章“消化性溃疡”“临床特征”“消化性溃疡的管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第36章.md`

**目标 / Objective**
识别消化性溃疡的典型模式并启动生活方式、抑酸和病因治疗。

**适用范围 / Scope**
- 上腹部烧灼痛、餐后疼痛或疑似溃疡性消化不良病人

**操作步骤 / Procedure**
1. 根据与进食相关的上腹烧灼痛、抗酸剂缓解和 NSAIDs/Hp 暴露识别溃疡可能。
2. 结合年龄和危险因素判断胃溃疡与十二指肠溃疡的可能性。
3. 有条件时安排胃镜确认,并同步做幽门螺杆菌检测。
4. 初始管理包括戒烟、停 NSAIDs/阿司匹林、症状缓解及全剂量 PPI 治疗。
5. Hp 阳性者加根除方案,并根据溃疡部位安排后续确认根除或复镜。

**注意事项 / Precautions**
- 老年 NSAIDs 相关溃疡可为“静默型”,不要因无典型疼痛而低估风险。
- 胃溃疡较十二指肠溃疡更需考虑恶性病变。
- PPI 长期使用前应定期重新评估指征。

**量化指标 / Metrics**
- 可疑溃疡胃镜完成率
- NSAIDs 停用率
- Hp 阳性后根除启动率
