# Skill: 成人GERD分阶段管理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第36章 消化不良
- 页码: 第36章“成人的胃食管反流病”“胃食管反流病的管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第36章.md`

**目标 / Objective**
对成人胃食管反流病实施生活方式加抑酸治疗的分阶段管理。

**适用范围 / Scope**
- 以胃灼热、反酸和平卧后加重为主的成人 GERD 病人

**操作步骤 / Procedure**
1. 根据典型病史初步诊断 GERD,并先筛查内镜红旗征。
2. 阶段 1 先进行病人教育、体重控制、戒烟限酒、晚餐提前和抬高床头等生活方式干预。
3. 对轻度间歇症状按需使用液态藻酸盐/抗酸剂混合制剂快速缓解。
4. 若数周仍无缓解,升级到阶段 2,优先使用标准剂量 PPI 4 周,于餐前 30~60 分钟服用。
5. 复评症状后决定降阶、维持或进一步内镜和专科评估。

**注意事项 / Precautions**
- 夜间咳嗽和哮喘样症状也可能由反流导致。
- 长期大剂量 PPI 并非人人需要,应避免无指征长期使用。
- 某些药物如抗胆碱能药、茶碱、硝酸盐和 CCB 可加重 GERD。

**量化指标 / Metrics**
- 生活方式干预执行率
- 4 周症状缓解率
- 不必要长期 PPI 使用率
