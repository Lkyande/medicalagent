# Skill: 阴囊肿块透光与定位检查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第104章 腹股沟阴囊肿块
- 页码: 第104章“阴囊检查”“单侧阴囊肿胀”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第104章.md`

**目标 / Objective**
用床旁检查快速区分阴囊肿块的囊性、实性及腹股沟来源特征。

**适用范围 / Scope**
- 单侧或双侧阴囊肿胀、无痛肿块或牵拉不适的男性

**操作步骤 / Procedure**
1. 分别在仰卧位和站立位检查阴囊。
2. 先判断能否从上方触及肿块上缘,区分真性阴囊肿块与腹股沟阴囊肿块。
3. 轻触睾丸、附睾和精索,判断肿块与睾丸是否分离。
4. 在暗室进行透光试验,识别鞘膜积液或囊肿等囊性病变。
5. 对实性、不透光或与睾丸一体的肿块安排超声和进一步评估。

**注意事项 / Precautions**
- 无痛性睾丸肿块首先要考虑癌症,除非证据另有指向。
- 透光试验不能替代超声,但有很高的床旁价值。
- 必须同时检查阴囊皮肤病变和更深层结构。

**量化指标 / Metrics**
- 阴囊肿块定位检查率
- 透光试验记录率
- 可疑肿瘤超声转介率
