# Skill: 睾丸肿瘤警讯识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第104章 腹股沟阴囊肿块
- 页码: 第104章“睾丸肿瘤”“临床特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第104章.md`

**目标 / Objective**
在年轻男性阴囊肿块中尽早识别睾丸肿瘤并减少误诊为炎症或积液。

**适用范围 / Scope**
- 15 至 40 岁男性出现无痛或轻痛性睾丸肿块时

**操作步骤 / Procedure**
1. 对与睾丸一体的实性肿块保持高度恶性怀疑。
2. 询问疼痛、感觉缺失、鞘膜积液、精索静脉曲张或腰背痛等伴随线索。
3. 区分肿块是否可与附睾囊肿等睾丸外病变分离。
4. 立即安排阴囊超声和专科评估。
5. 避免把肿瘤长期当作附睾炎、外伤或积液随访观察。

**注意事项 / Precautions**
- 年轻男性最常见的实体肿块恶性可能高。
- 多达 1/4 病人可伴疼痛,不能因疼痛而放松警惕。
- 鞘膜积液或轻微外伤可掩盖肿瘤。

**量化指标 / Metrics**
- 可疑睾丸肿瘤超声完成率
- 专科转诊时效
- 炎症误诊率
