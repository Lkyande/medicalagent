# Skill: 腹股沟疝与股疝识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第104章 腹股沟阴囊肿块
- 页码: 第104章“腹股沟肿块”“临床特征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第104章.md`

**目标 / Objective**
识别腹股沟疝和股疝并区分高绞窄风险类型。

**适用范围 / Scope**
- 男性或女性腹股沟肿块、站立后加重不适或可复性包块来诊时

**操作步骤 / Procedure**
1. 判断肿块位于耻骨结节内侧还是外侧,并评估是否在腹股沟韧带下方。
2. 检查站立位和咳嗽冲击感,观察肿块是否可复。
3. 结合年龄、肥胖、妊娠、便秘和慢性咳嗽等易患因素评估类型。
4. 对女性小而不明显的股疝保持高度警惕。
5. 一旦症状性疝明确,安排外科评估和修补建议。

**注意事项 / Precautions**
- 股疝绞窄风险最高。
- 肥胖病人容易漏诊股疝。
- 鉴别直疝和斜疝临床获益有限,重点在是否为真疝及并发症风险。

**量化指标 / Metrics**
- 腹股沟肿块疝类型识别率
- 咳嗽冲击检查率
- 症状性疝外科转介率
