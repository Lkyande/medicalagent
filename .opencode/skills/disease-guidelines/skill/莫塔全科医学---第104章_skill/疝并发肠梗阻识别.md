# Skill: 疝并发肠梗阻识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第104章 腹股沟阴囊肿块
- 页码: 第104章“表104.2 疝引起肠梗阻的症状和体征”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第104章.md`

**目标 / Objective**
识别疝并发嵌顿、梗阻或绞窄的紧急外科情况。

**适用范围 / Scope**
- 已知或怀疑疝病人出现急性腹痛、恶心呕吐或不可还纳肿块时

**操作步骤 / Procedure**
1. 询问腹部绞痛、恶心呕吐、停止排气排便和腹胀。
2. 触诊局部是否压痛、肿胀且咳嗽冲击消失。
3. 识别嵌顿或绞窄高风险类型,尤其股疝和腹股沟斜疝。
4. 不要尝试延迟观察,尽快安排急诊外科处理。
5. 记录症状起始时间和肿块可还纳状态变化。

**注意事项 / Precautions**
- 疝致肠梗阻和绞窄属于急症。
- 咳嗽冲击阴性是重要危险线索。
- 观察等待不适用于急性症状病人。

**量化指标 / Metrics**
- 疝并发症早期识别率
- 急诊外科转诊时效
- 绞窄前处置比例
