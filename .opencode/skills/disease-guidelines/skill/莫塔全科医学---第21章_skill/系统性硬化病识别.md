# Skill: 系统性硬化病识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“系统性硬化病(硬皮病)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
根据皮肤紧绷、雷诺现象和内脏受累线索识别系统性硬化病。

**适用范围 / Scope**
- 手指僵硬、皮肤紧绷、雷诺现象或吞咽困难病人

**操作步骤 / Procedure**
1. 识别雷诺现象和早期“香肠样手指”或多关节不适。
2. 检查手指及其他皮肤区域是否僵硬、紧绷和增厚。
3. 追问吞咽困难、反流、腹泻、呼吸困难和心脏症状。
4. 检查典型“鸟样脸”和胸部紧绷皮肤表现。
5. 安排 ANA、抗着丝粒抗体、抗 Scl-70 等检查并转专科。

**注意事项 / Precautions**
- 超过 85% 病人有雷诺现象。
- 该病为多器官进行性疾病,不能仅看皮肤表现。
- 需同时监测血压及肺动脉高压风险。

**量化指标 / Metrics**
- 雷诺现象伴皮肤紧绷病例硬皮病评估率
- 硬皮病特异抗体检测率
- 专科转诊完成率
