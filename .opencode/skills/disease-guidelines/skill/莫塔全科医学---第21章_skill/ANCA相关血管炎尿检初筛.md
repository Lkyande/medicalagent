# Skill: ANCA相关血管炎尿检初筛

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“临床要领”“肉芽肿性多血管炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
在疑似严重 ANCA 相关疾病时通过尿检快速发现肾脏受累并触发紧急转诊。

**适用范围 / Scope**
- 上下呼吸道症状、全身炎症和多系统体征提示 ANCA 相关血管炎者

**操作步骤 / Procedure**
1. 对鼻出血、鼻窦炎、咳嗽、呼吸困难和全身症状并存者考虑 ANCA 相关血管炎。
2. 立即完成尿液血尿和蛋白尿检查。
3. 若尿检阳性,追加 ANCA 检测。
4. 结合胸片或 CT 上结节、空洞等线索判断是否为肉芽肿性多血管炎。
5. 对疑似严重病例紧急转专科,避免等待病情完全展开。

**注意事项 / Precautions**
- 肾脏损害是致命风险核心。
- ANCA 有用但并非绝对特异。
- 早诊断能挽救生命。

**量化指标 / Metrics**
- 疑似 ANCA 血管炎尿检完成率
- 尿异常病例 ANCA 检测率
- 紧急转诊时效
