# Skill: 系统性红斑狼疮识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“系统性红斑狼疮”“分类标准”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
根据典型多系统表现尽早识别系统性红斑狼疮。

**适用范围 / Scope**
- 年轻女性出现关节炎、皮损、疲劳或多系统炎症表现者

**操作步骤 / Procedure**
1. 识别高发人群,尤其是 15~45 岁女性。
2. 询问发热、不适、疲倦、多药过敏及缓解复发病程特点。
3. 检查蝴蝶疹、盘状皮疹、光敏感、口腔溃疡和对称性非侵蚀性关节炎。
4. 评估浆膜炎、肾脏、神经系统和血液系统受累证据。
5. 若临床标准累积达 4 项或以上,进入狼疮确证与转诊流程。

**注意事项 / Precautions**
- SLE 是“伟大的伪装者”。
- 关节炎是最常见特征之一。
- 仅凭抽血结果不能替代临床判断。

**量化指标 / Metrics**
- 可疑 SLE 分类标准记录率
- 肾脏和神经系统受累筛查率
- 风湿专科转诊完成率
