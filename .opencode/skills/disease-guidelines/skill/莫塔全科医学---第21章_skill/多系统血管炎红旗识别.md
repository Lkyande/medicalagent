# Skill: 多系统血管炎红旗识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“血管炎”“小血管炎”“罕见但致命的病因”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
在未确诊多系统疾病中识别提示血管炎的关键临床红旗。

**适用范围 / Scope**
- 发热、体重减轻、紫癜、肾脏异常、呼吸或 ENT 症状并存者

**操作步骤 / Procedure**
1. 识别全身症状如不适、发热、体重减轻和关节痛。
2. 检查皮肤紫癜、溃疡、梗塞和其他血管性损害。
3. 同步评估喘息、咳嗽、鼻出血、鼻窦炎、胸痛和神经系统表现。
4. 常规筛查尿检中的血尿和蛋白尿。
5. 对疑似全身性血管炎病例尽快安排进一步免疫学检查并转专科。

**注意事项 / Precautions**
- 任何未确诊的多系统疾病都应考虑血管炎。
- 肾脏损害是致命风险的关键指征。
- 皮肤可触及紫癜是常见线索之一。

**量化指标 / Metrics**
- 多系统炎症病例尿检完成率
- 血管炎红旗记录率
- 风湿专科紧急转诊率
