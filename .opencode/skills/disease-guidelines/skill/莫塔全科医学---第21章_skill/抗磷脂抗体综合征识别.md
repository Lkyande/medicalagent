# Skill: 抗磷脂抗体综合征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“抗磷脂抗体综合征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
识别抗磷脂抗体综合征的血栓和妊娠丢失模式,及时转专科处理。

**适用范围 / Scope**
- 复发性动静脉血栓、反复流产或血小板减少者

**操作步骤 / Procedure**
1. 询问动脉或静脉血栓栓塞和复发性自然流产病史。
2. 检查网状青斑、皮肤溃疡和神经精神症状等支持线索。
3. 识别是否合并 SLE,或作为单独综合征存在。
4. 安排抗磷脂抗体、抗心磷脂、抗 β2 糖蛋白 1 抗体及狼疮抗凝物检测。
5. 疑诊时可先使用阿司匹林并尽快转专科,妊娠期更应加速处理。

**注意事项 / Precautions**
- 并非所有病例都合并 SLE。
- 妊娠相关病例风险高,管理需更谨慎。
- 不能忽视血小板减少这一提示。

**量化指标 / Metrics**
- 反复流产病例 APS 评估率
- 血栓伴自身免疫线索病例抗体检测率
- 妊娠相关专科转诊时效
