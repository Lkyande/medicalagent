# Skill: 干燥综合征识别与Schirmer试验

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“干燥综合征”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
在干眼、口干和关节症状病人中识别干燥综合征并安排基础评估。

**适用范围 / Scope**
- 干眼、口干、阴道干涩或慢性干咳伴关节痛者

**操作步骤 / Procedure**
1. 询问口干、眼干、阴道干涩、吞咽困难和性交困难。
2. 检查龋齿增多、唾液腺肿大、唾液减少和声音嘶哑。
3. 评估是否伴非侵蚀性关节炎或其他结缔组织病背景。
4. 安排 ANA/ENA、抗 SSA、抗 SSB 及 ESR、RF 等检查。
5. 进行 Schirmer 试验评估结膜干燥,并转风湿专科管理。

**注意事项 / Precautions**
- 可为原发性,也可继发于类风湿关节炎或系统性硬化病。
- 长期存在非霍奇金淋巴瘤转化风险。
- 呼吸道干燥可表现为慢性干咳,易误判为单纯呼吸道疾病。

**量化指标 / Metrics**
- 干燥三联征病例 Schirmer 试验完成率
- SSA/SSB 抗体检测率
- 风湿专科转诊率
