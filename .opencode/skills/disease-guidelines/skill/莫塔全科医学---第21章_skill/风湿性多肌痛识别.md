# Skill: 风湿性多肌痛识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“巨细胞动脉炎和风湿性多肌痛”“临床特征(风湿性多肌痛)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
识别老年病人肩胛带和骨盆带疼痛僵硬所代表的风湿性多肌痛。

**适用范围 / Scope**
- 50 岁以上出现近端肌肉疼痛、晨僵和活动受限者

**操作步骤 / Procedure**
1. 识别肩部、骨盆带和颈部对称性疼痛与僵硬。
2. 记录晨僵是否持续超过 45 分钟。
3. 询问体重减轻、不适、厌食和发热等全身症状。
4. 安排 ESR、CRP 和全血细胞计数评估炎症与轻度贫血。
5. 同时筛查颞动脉炎症状,必要时紧急转诊。

**注意事项 / Precautions**
- 典型年龄 60~70 岁,少见于 50 岁以下。
- 体征在当天稍晚时可减轻,易被低估。
- 常与巨细胞动脉炎伴随存在。

**量化指标 / Metrics**
- 老年近端疼痛病例 PMR 考虑率
- ESR/CRP 完成率
- GCA 症状联筛率
