# Skill: CREST综合征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“CREST综合征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
识别局限性硬皮病谱系中的 CREST 综合征组合特征。

**适用范围 / Scope**
- 雷诺现象、食管症状或毛细血管扩张伴皮肤硬化病人

**操作步骤 / Procedure**
1. 主动检查是否有钙质沉着和雷诺现象。
2. 询问吞咽困难、反流等食管运动障碍症状。
3. 观察手指或皮肤硬化表现。
4. 检查面部或四肢毛细血管扩张症。
5. 安排抗着丝粒抗体检测并转风湿专科。

**注意事项 / Precautions**
- 抗着丝粒抗体通常阳性且具较高提示价值。
- CREST 属局限性谱系,但仍可能有器官并发症。
- 易在长期雷诺现象背景下被忽视。

**量化指标 / Metrics**
- 雷诺现象病例 CREST 要素筛查率
- 抗着丝粒抗体检测率
- 局限性硬皮病专科评估率
