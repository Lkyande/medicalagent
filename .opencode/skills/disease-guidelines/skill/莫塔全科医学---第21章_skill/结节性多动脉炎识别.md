# Skill: 结节性多动脉炎识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“结节性多动脉炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
在多系统炎症伴皮肤和肾脏损害病人中识别结节性多动脉炎。

**适用范围 / Scope**
- 发热、体重减轻、肌痛、皮下结节或肾损害病人

**操作步骤 / Procedure**
1. 识别青中年男性多系统炎症背景。
2. 记录发热、不适、肌痛、体重减轻和游走性关节痛。
3. 检查沿动脉分布的皮下结节、网状青斑和皮肤溃疡。
4. 评估高血压、肾损害及心脏受累迹象。
5. 通过活检或血管造影进一步确诊并转专科控制血压与免疫治疗。

**注意事项 / Precautions**
- 死亡常由肾脏疾病所致。
- 与药物滥用、B 细胞淋巴瘤和乙肝表面抗原有关。
- 任何病因不明的多系统病都应考虑本病。

**量化指标 / Metrics**
- 可疑病例尿检和血压评估率
- 活检或血管造影转诊率
- 肾功能受累识别率
