# Skill: 巨细胞动脉炎识别与紧急转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“巨细胞动脉炎和风湿性多肌痛”“临床特征(颞动脉炎)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
识别巨细胞动脉炎的缺血性红旗,避免延误导致失明或卒中。

**适用范围 / Scope**
- 50 岁以上新发头痛、颌跛行、视力症状或伴 PMR 表现者

**操作步骤 / Procedure**
1. 对 50 岁以上新发单侧搏动性头痛提高警惕。
2. 主动询问一过性黑矇、复视等视觉症状和下颌跛行。
3. 触诊颞动脉压痛和搏动是否减弱或消失。
4. 安排 ESR、CRP 和贫血评估,必要时计划颞动脉活检。
5. 对任何疑似 GCA 病人紧急转诊并尽早启动类固醇治疗路径。

**注意事项 / Precautions**
- 延误诊断可造成失明和卒中。
- PMR 常在 GCA 前出现,需联想两者关系。
- 视力丧失并发症时需考虑静脉甲泼尼龙。

**量化指标 / Metrics**
- 50 岁以上新发头痛病例 GCA 联筛率
- 视觉症状记录率
- 紧急转诊或治疗启动时效
