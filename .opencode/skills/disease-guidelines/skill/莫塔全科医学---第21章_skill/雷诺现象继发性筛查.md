# Skill: 雷诺现象继发性筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“雷诺现象”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
区分原发性与继发性雷诺现象,并筛查潜在结缔组织病。

**适用范围 / Scope**
- 手指、足趾、鼻、耳或乳头发作性发白发紫发冷者

**操作步骤 / Procedure**
1. 记录发作诱因、受累部位和严重程度。
2. 询问是否伴皮肤紧绷、关节痛、干燥症状或吞咽困难等 CTD 线索。
3. 评估症状是否逐渐加重或伴溃疡等更严重表现。
4. 对疑似继发性病例安排自身抗体与炎症指标检查。
5. 根据风险程度进行长期随访或转风湿专科。

**注意事项 / Precautions**
- 原发性雷诺现象仍可在多年后进展为 CTD。
- 症状越严重,越提示潜在系统性疾病。
- 平均诊断延迟可长达 10 年。

**量化指标 / Metrics**
- 雷诺现象病例 CTD 线索筛查率
- 继发性风险病例抗体检测率
- 长期随访安排率
