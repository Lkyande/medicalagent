# Skill: 多发性肌炎皮肌炎识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“多发性肌炎和皮肌炎”“皮疹”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
在近端肌无力和特征性皮疹病人中识别多发性肌炎或皮肌炎。

**适用范围 / Scope**
- 对称性近端肌无力、吞咽困难或紫红色皮疹者

**操作步骤 / Procedure**
1. 识别肩带和骨盆带对称性无力与萎缩。
2. 询问主诉是否以“无力”而非疼痛为主,并评估吞咽困难与雷诺现象。
3. 检查眼睑、前额、面颊、上胸部和肩背部紫红色或光敏性皮疹。
4. 观察手指、甲襞、膝肘等特征性皮损。
5. 对伴恶性肿瘤风险线索者同步计划筛查并转专科。

**注意事项 / Precautions**
- 约半数病人伴关节痛或关节炎。
- 需与他汀相关坏死性肌炎鉴别。
- 肺和卵巢恶性肿瘤关联需特别注意。

**量化指标 / Metrics**
- 近端肌无力病例炎性肌病考虑率
- 皮疹分布记录率
- 恶性肿瘤筛查启动率
