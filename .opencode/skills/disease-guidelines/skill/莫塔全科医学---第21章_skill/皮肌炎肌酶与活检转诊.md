# Skill: 皮肌炎肌酶与活检转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“多发性肌炎和皮肌炎”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
对疑似炎性肌病病人完成初步实验室和病理转诊路径。

**适用范围 / Scope**
- 怀疑多发性肌炎或皮肌炎的病人

**操作步骤 / Procedure**
1. 安排血清肌酸激酶和醛缩酶等肌酶检测。
2. 根据临床表现追加 Jo-1 等相关抗体。
3. 转专科安排肌电图评估特征性模式。
4. 进一步计划皮肤和肌肉活检确诊。
5. 同步纳入恶性肿瘤筛查和长期随访。

**注意事项 / Precautions**
- 早期转诊有助于避免功能恶化。
- 活检和肌电图对确诊价值高。
- 诊断阶段就应考虑肿瘤相关性。

**量化指标 / Metrics**
- 疑似炎性肌病 CK 检测率
- 活检转诊完成率
- 恶性肿瘤筛查完成率
