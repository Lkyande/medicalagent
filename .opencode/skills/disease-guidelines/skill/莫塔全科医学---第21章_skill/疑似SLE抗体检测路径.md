# Skill: 疑似SLE抗体检测路径

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“系统性红斑狼疮”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
对疑似 SLE 病人采用分层抗体检测,提高检验效率与诊断准确性。

**适用范围 / Scope**
- 有临床证据支持 SLE 的病人

**操作步骤 / Procedure**
1. 首先依据临床表现确认存在支持 SLE 的证据。
2. 首选 ANA 作为初始关键筛查检验。
3. 若 ANA 阳性,追加 dsDNA 和 ENA 尤其是 Sm 抗体检测。
4. 同步评估 ESR/CRP、类风湿因子及血液系统异常。
5. 结合抗磷脂抗体结果判断是否存在 APS 重叠。

**注意事项 / Precautions**
- ANA 阳性率高但缺乏特异度。
- dsDNA 特异度高但并非所有 SLE 都阳性。
- 没有支持性临床证据时不宜仅凭抗体下诊断。

**量化指标 / Metrics**
- 疑似 SLE ANA 首检率
- ANA 阳性后 dsDNA/ENA 追加率
- 临床与实验室联合判读记录率
