# Skill: 结缔组织病抗体检测路径

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“结缔组织病辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
在疑似结缔组织病时合理安排基础炎症指标与自身抗体检测顺序。

**适用范围 / Scope**
- 疲劳、关节痛、多系统症状、雷诺现象或干燥症状病人

**操作步骤 / Procedure**
1. 先以临床评估为核心,确认是否存在多系统炎症线索。
2. 基础检查优先安排全血细胞计数、ESR、CRP 和类风湿因子。
3. 对年轻女性伴小关节痛、疲劳和疑似狼疮皮肤表现者安排 ANA。
4. 仅在 ANA 明显阳性或临床高度提示时进一步安排 dsDNA 和 ENA。
5. 结合具体临床表型选择 Jo-1、抗 Scl-70、抗着丝粒或 ANCA 等特异检测。

**注意事项 / Precautions**
- ANA 敏感但不特异,病毒感染等可假阳性。
- 不能仅凭化验结果诊断 CTD。
- 不建议将 X 线和 HLA-B27 作为本章此类病的常规筛查。

**量化指标 / Metrics**
- 疑似 CTD 基础检验完成率
- ANA 阳性后分层追加抗体检测率
- 不必要广泛自身抗体检测减少率
