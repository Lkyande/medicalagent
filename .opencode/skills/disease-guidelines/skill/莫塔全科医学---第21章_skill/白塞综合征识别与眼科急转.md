# Skill: 白塞综合征识别与眼科急转

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第21章 结缔组织病和全身性血管炎
- 页码: 第21章“白塞综合征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第21章.md`

**目标 / Objective**
识别白塞综合征的复发性黏膜溃疡和眼部血管炎表现,并及时保护视力。

**适用范围 / Scope**
- 复发性口腔或生殖器溃疡伴关节炎、皮肤病变或眼症状者

**操作步骤 / Procedure**
1. 询问反复口腔溃疡和生殖器溃疡病史。
2. 检查结节性红斑样皮损和膝关节炎等系统表现。
3. 询问针刺后丘疹或脓疱形成的病史。
4. 一旦出现眼痛、视力下降或飞蚊症,立即联系眼科评估。
5. 转风湿或相关专科评估全身血管炎治疗方案。

**注意事项 / Precautions**
- 没有特异性实验室确诊试验。
- 眼部受累可导致失明。
- 还可并发静脉血栓和脑膜脑炎。

**量化指标 / Metrics**
- 复发性口腔溃疡病例系统问诊率
- 眼部症状病例眼科急转率
- 多系统并发症评估率
