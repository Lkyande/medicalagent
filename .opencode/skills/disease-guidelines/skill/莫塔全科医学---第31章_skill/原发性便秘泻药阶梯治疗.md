# Skill: 原发性便秘泻药阶梯治疗

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第31章 便秘
- 页码: 第31章“一线治疗”“二线治疗”“三线治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第31章.md`

**目标 / Objective**
按阶梯方式使用泻药治疗原发性便秘,兼顾疗效和安全性。

**适用范围 / Scope**
- 生活方式干预后仍有症状的原发性便秘病人

**操作步骤 / Procedure**
1. 首选容积形成性泻药,如洋车前子或欧车前,按说明每日 1~2 次使用。
2. 若效果不足,升级为二线渗透性方案,如聚乙二醇 3350 或乳果糖。
3. 可在短期内辅助使用甘油栓剂、微型灌肠剂或少量刺激性泻药以快速解除症状。
4. 顽固病例复核病因后再考虑三线方案,如肾功能正常者用硫酸镁或其他强化方案。
5. 全程随访排便频率、腹胀、腹痛和泻药依赖情况,及时降阶或调整。

**注意事项 / Precautions**
- 除短期速效用途外,应避免长期依赖刺激性泻药。
- 容积性泻药需配足量水,否则可能加重梗阻感。
- 三线治疗前要重新评估器质性病因和药物诱因。

**量化指标 / Metrics**
- 一线泻药响应率
- 需要升级二线/三线比例
- 长期刺激性泻药使用率
