# Skill: 便秘病史结构化采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第31章 便秘
- 页码: 第31章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第31章.md`

**目标 / Objective**
澄清病人对便秘的定义并通过结构化病史区分功能性与器质性便秘。

**适用范围 / Scope**
- 急性、慢性或复发性便秘病人

**操作步骤 / Procedure**
1. 先明确病人所说“便秘”具体是排便次数减少、粪便坚硬还是排便困难。
2. 询问排便频率、粪便形态、排便时间及是否伴疼痛、血便或黏液便。
3. 追问是否有肿块感、大便失禁或弄脏内裤情况,以及整体自我感觉变化。
4. 核对饮食模式、液体摄入、活动量和是否存在忽视便意的习惯。
5. 完整记录当前药物使用,并建议病人记录 10 日大便日记以量化症状。

**注意事项 / Precautions**
- 很多病人把“不是每日排便”误认为疾病,解释正常变异很重要。
- 血便、疼痛和黏液提示需升级器质性评估,不能归为单纯功能性便秘。
- 大便失禁可能是粪便嵌塞后的溢出性腹泻而不是“腹泻”。

**量化指标 / Metrics**
- 便秘病史要素完整率
- 大便日记完成率
- 功能性与器质性初步分层率
