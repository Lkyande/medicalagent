# Skill: 便秘直肠指检执行

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第31章 便秘
- 页码: 第31章“直肠检查”“方法”“注意事项”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第31章.md`

**目标 / Objective**
通过规范直肠指检发现粪便嵌塞、直肠肿瘤、括约肌异常和巨结肠线索。

**适用范围 / Scope**
- 需要体格评估的便秘病人,尤其是老年人和儿童

**操作步骤 / Procedure**
1. 先向病人解释检查目的,让病人取左侧卧屈膝位。
2. 分开臀部,润滑示指后在病人缓慢深呼吸时轻柔进入肛管和直肠。
3. 评估有无疼痛、肛裂、肛瘘硬结、括约肌张力和粪便嵌塞。
4. 系统触摸直肠壁及周围结构,寻找硬结、溃疡、柔软绒毛样肿物或狭窄。
5. 同时检查前方结构,男性评估前列腺,女性注意宫颈或阴道避免误判为肿瘤。

**注意事项 / Precautions**
- 存在急性肛裂时不适合做直肠检查。
- 婴儿期长期便秘伴直肠正常或狭窄提示先天性巨结肠,直肠扩张更支持获得性巨结肠。
- 女性宫颈或阴道可被误认作直肠外肿块,需保持解剖定位清楚。

**量化指标 / Metrics**
- 直肠指检完成率
- 粪便嵌塞检出率
- 直肠肿瘤早期识别率
