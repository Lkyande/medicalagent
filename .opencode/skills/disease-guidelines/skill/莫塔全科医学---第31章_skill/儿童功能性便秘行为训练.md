# Skill: 儿童功能性便秘行为训练

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第31章 便秘
- 页码: 第31章“功能性便秘的治疗原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第31章.md`

**目标 / Objective**
通过如厕训练和家庭行为干预改善儿童功能性便秘和粪便潴留。

**适用范围 / Scope**
- >95% 无明显器质性病因的儿童功能性便秘

**操作步骤 / Procedure**
1. 向家长解释多数儿童便秘为功能性,核心问题是粪便潴留和直肠扩张。
2. 建立轻松的孩子-家长互动,避免惩罚式如厕训练。
3. 训练孩子餐后定时如厕,每日 3 次,每次 3~5 分钟,用贴纸或图表强化行为。
4. 调整排便姿势:双脚有支撑、膝高于臀、身体前倾并保证隐私。
5. 同步增加水分、纤维和运动,必要时联合维持期泻药至少 3~6 个月。

**注意事项 / Precautions**
- 害怕上厕所的儿童常需配合心理和行为纠正支持。
- 粪便失禁往往是潴留后的溢出,不是孩子“故意”排便。
- 近期再度尿床应考虑便秘相关压迫影响。

**量化指标 / Metrics**
- 规律如厕执行率
- 每周排便次数改善
- 粪便失禁发生率下降幅度
