# Skill: 儿童便秘红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第31章 便秘
- 页码: 第31章“器质性原因的红旗征”“其他重要疾病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第31章.md`

**目标 / Objective**
尽早识别儿童便秘中的器质性病因,避免漏诊巨结肠、神经异常和全身疾病。

**适用范围 / Scope**
- 所有儿童便秘或大便失禁病人

**操作步骤 / Procedure**
1. 筛查便血、肛周疾病、发热、体重减轻或生长迟缓等危险信号。
2. 询问是否有呕吐、泌尿系统症状、腿部神经异常或发育行为问题。
3. 追问是否有胎粪排出延迟和婴儿期起病的长期便秘。
4. 对粪便条状稀细、腹胀明显或直肠检查异常者,升级影像和专科评估。
5. 红旗征存在时优先排查先天性巨结肠、神经系统病变和肛裂等器质性病因。

**注意事项 / Precautions**
- 先天性巨结肠的关键线索是初次胎粪延迟后持续便秘。
- 便血伴干硬痛便在婴儿更常提示肛裂,但仍需整体评估。
- 绝大多数为功能性便秘,但不能因此忽视红旗征。

**量化指标 / Metrics**
- 红旗征记录率
- 专科转诊及时率
- 巨结肠等器质性病因检出率
