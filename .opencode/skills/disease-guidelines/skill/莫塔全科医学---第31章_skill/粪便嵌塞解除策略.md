# Skill: 粪便嵌塞解除策略

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第31章 便秘
- 页码: 第31章“粪便嵌塞”“手工嵌塞解除法”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第31章.md`

**目标 / Objective**
对粪便嵌塞进行分层解除,缓解梗阻样症状和溢出性腹泻。

**适用范围 / Scope**
- 老年、长期卧床或阿片使用后疑似粪便嵌塞病人

**操作步骤 / Procedure**
1. 根据乏力、恶心、腹部不适、便意不足和假性腹泻怀疑粪便嵌塞。
2. 通过直肠指检并在必要时辅以腹部 X 线确认嵌塞。
3. 优先使用口服渗透性泻药、聚乙二醇 3350 或灌肠剂进行解除。
4. 对巨大粪块或解除失败者实施手工排嵌,必要时预先给予咪达唑仑或芬太尼减轻痛苦。
5. 解除后立即建立维持方案,处理阿片、长期卧床和排便习惯等诱因。

**注意事项 / Precautions**
- 大便失禁或“腹泻”可能只是嵌塞后的液体溢出。
- 阿片类药物是重要诱因,需同步调整用药。
- 排嵌后若不做维持治疗,极易再次嵌塞。

**量化指标 / Metrics**
- 嵌塞确认后解除时间
- 假性腹泻纠正率
- 30 日内复发率
