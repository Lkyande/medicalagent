# Skill: 结直肠癌便秘红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第31章 便秘
- 页码: 第31章“结肠直肠肿瘤”“症状”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第31章.md`

**目标 / Objective**
在便秘病人中识别提示结直肠癌的危险模式并尽快转入内镜路径。

**适用范围 / Scope**
- 50 岁以上新发便秘或伴排便习惯改变病人

**操作步骤 / Procedure**
1. 主动询问血便、黏液便、贫血、腹部绞痛和近期排便习惯改变。
2. 识别便秘与假性腹泻交替、直肠不适或梗阻样腹胀加重等高危表现。
3. 完成直肠指检,因为许多直肠癌位于肛缘 12cm 内可被触及。
4. 结合家族史、腺瘤史和长期溃疡性结肠炎等危险因素分层。
5. 一旦怀疑,尽快转入乙状结肠镜或结肠镜评估,避免仅按功能性便秘处理。

**注意事项 / Precautions**
- 老年新发便秘必须首先排除结肠癌。
- 梗阻伴进行性腹胀疼痛时需警惕闭袢梗阻和盲肠破裂风险。
- 家族性高风险者应考虑家庭癌症门诊评估。

**量化指标 / Metrics**
- 高危便秘镜检完成率
- 直肠指检记录率
- 结直肠癌早期检出率
