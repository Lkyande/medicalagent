# Skill: 功能性便秘生活方式干预

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第31章 便秘
- 页码: 第31章“原发性便秘”“管理”“给病人的建议”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第31章.md`

**目标 / Objective**
通过生活方式调整恢复正常排便反射,减少泻药依赖。

**适用范围 / Scope**
- 已排除器质性原因的单纯性或功能性便秘病人

**操作步骤 / Procedure**
1. 向病人解释单纯性便秘通常与纤维摄入不足、忽视便意和活动少有关。
2. 建议建立固定排便节律,尤其是早餐后留出放松排便时间并一有便意就如厕。
3. 鼓励规律步行或其他充足锻炼,避免久坐。
4. 指导增加水和果汁摄入,并补充富含纤维的蔬菜、全谷物和带皮水果。
5. 明确避免含可待因复方制剂,并对持续困难者配合大便日记和复诊调整。

**注意事项 / Precautions**
- 功能性便秘管理需要长期坚持,不是单靠一两次泻药即可解决。
- 大量增加纤维前应确保液体摄入充足,避免腹胀加重。
- 行为和心理因素明显者可联合心理咨询或生物反馈。

**量化指标 / Metrics**
- 生活方式建议执行率
- 每周自发排便次数
- 泻药依赖减少率
