# Skill: 心悸节律敲击问诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第59章 心悸
- 页码: 第59章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第59章.md`

**目标 / Objective**
借助病人敲击发作节律与速率,提高常见心律失常的初步识别率。

**适用范围 / Scope**
- 发作性心悸但就诊时未发作,且能回忆发作节律特征的病人

**操作步骤 / Procedure**
1. 先让病人描述心悸突然开始还是逐渐加快,以及每次持续时间。
2. 请病人在桌面敲出发作时的节律和快慢,必要时由医生示范不同节律供其比对。
3. 无规律乱打样节奏优先考虑房颤或房扑伴不规则传导。
4. 孤立扑通后接明显停顿,在规律心跳背景上更支持期前收缩。
5. 突然起止且规则快速节律时优先考虑 PSVT,并结合症状安排 ECG 记录路径。

**注意事项 / Precautions**
- 敲击法用于初筛,不能替代心电图确诊。
- 需同步追问胸痛、晕厥、呼吸困难等高危伴随症状。
- 无法准确再现节律时,应更依赖监测设备而非主观判断。

**量化指标 / Metrics**
- 发作性心悸节律信息记录率
- 敲击问诊后初步分型一致率
- 后续 ECG 证实率
