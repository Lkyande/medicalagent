# Skill: 心率与规则性床旁初筛

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第59章 心悸
- 页码: 第59章“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第59章.md`

**目标 / Objective**
通过心率与脉律床旁判断,快速缩小心悸的常见鉴别范围。

**适用范围 / Scope**
- 就诊时仍有心悸或可测得脉搏异常的病人

**操作步骤 / Procedure**
1. 在安静状态下测量心率,记录快慢和是否规则。
2. 心率约 150 次/min 时重点考虑 PSVT、房扑/房颤或室速。
3. 心率 <150 次/min 时,结合发热、运动、药物和甲亢考虑窦速更常见。
4. 若脉律不规则,优先排查异位搏动、房颤及不同传导比例的房扑。
5. 同时检查发热、贫血、甲状腺病、JVP 增高、肺淤血等潜在病因线索。

**注意事项 / Precautions**
- 规则快速心律并不自动等于良性,仍需 ECG 明确类型。
- 病人发作结束后床旁检查可能恢复正常,需记录发作时特征。
- 头晕或晕厥合并心动过缓时要警惕病态窦房结和高级传导阻滞。

**量化指标 / Metrics**
- 心率与脉律记录完整率
- 床旁初筛与 ECG 分型一致率
- 高危缓慢型心律失常识别率
