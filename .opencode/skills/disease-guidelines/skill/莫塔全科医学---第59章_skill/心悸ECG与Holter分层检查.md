# Skill: 心悸ECG与Holter分层检查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第59章 心悸
- 页码: 第59章“关键事实和要点”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第59章.md`

**目标 / Objective**
按发作特点选择合适的心电监测,提高心悸病因确诊率。

**适用范围 / Scope**
- 需进一步明确心悸是否由心律失常、缺血或结构性心脏病导致的病人

**操作步骤 / Procedure**
1. 将十二导联 ECG 作为明确诊断的基础检查。
2. 常规 ECG 未捕获异常但仍高度怀疑心律失常时,安排 24 小时 Holter。
3. 发作间隔更长时,根据可及性考虑更长时程监视器或植入式监测。
4. 伴瓣膜病、心衰或结构性心脏病线索时,补充超声心动图。
5. 同步按病史选择血常规、电解质、镁、甲功及地高辛浓度等病因检查。

**注意事项 / Precautions**
- 正常静息 ECG 不能排除阵发性心律失常。
- 影像和实验室检查应围绕临床问题选择,避免无指向性堆砌。
- 怀疑缺血性病因时,需把急性冠脉综合征置于更高优先级。

**量化指标 / Metrics**
- 心悸病人十二导联 ECG 完成率
- Holter 或延长监测阳性捕获率
- 结构性心脏病补充检查到位率
