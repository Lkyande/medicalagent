# Skill: 心悸诱发因素与药物排查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第59章 心悸
- 页码: 第59章“关键的提问”“引起心悸的某些药物”“管理策略”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第59章.md`

**目标 / Objective**
系统识别可逆的生活方式、药物和代谢性诱因,减少不必要的抗心律失常治疗。

**适用范围 / Scope**
- 首诊或复诊的心悸病人,尤其怀疑功能性或诱发性发作时

**操作步骤 / Procedure**
1. 逐项核查处方药、非处方药、鼻减充血剂、吸入 β 受体激动药和地高辛使用情况。
2. 追问酒精、咖啡因、能量饮料、吸烟和毒品暴露。
3. 结合体重下降、多汗和疲劳等线索筛查甲状腺毒症、贫血和感染。
4. 对疑似诱因给予明确停用、减量或规避建议,并处理基础疾病。
5. 向病人说明几乎所有抗心律失常药物均有致心律失常风险,优先处理病因。

**注意事项 / Precautions**
- 老年人药物相关心悸和地高辛毒性更常见,症状可不典型。
- 诱因排查不能替代对高危心律失常的急诊分流。
- 焦虑可诱发和放大症状,但只能在排除器质性危险后再归因。

**量化指标 / Metrics**
- 药物与刺激物暴露记录率
- 可逆诱因识别率
- 生活方式干预后症状改善率
