# Skill: 心悸红旗征快速分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第59章 心悸
- 页码: 第59章“心悸的红旗征”“不能遗漏的严重疾病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第59章.md`

**目标 / Objective**
在首诊时快速识别需要急诊或专科加速评估的高危心悸。

**适用范围 / Scope**
- 主诉心悸、心跳异常感、胸内扑动或停搏感的病人

**操作步骤 / Procedure**
1. 先确认是否伴头晕、晕厥前兆、胸痛或呼吸困难等高危症状。
2. 立即测量静息心率,重点识别 >120 次/min 或 <45 次/min。
3. 评估是否存在新发心律不齐或已知严重基础心脏病。
4. 追问猝死家族史、劳力性发作和近期急性冠脉综合征线索。
5. 出现任何红旗征时尽快安排急诊评估、十二导联 ECG 和心脏专科分流。

**注意事项 / Precautions**
- 心悸可是不典型急性冠脉综合征的表现,不能仅按焦虑处理。
- 老年人感染、电解质紊乱和药物因素可掩盖高危心律失常。
- 合并晕厥或胸痛时优先排除室速、病态窦房结和完全性传导阻滞。

**量化指标 / Metrics**
- 高危心悸识别率
- 红旗征病人 ECG 完成率
- 首诊到急诊或专科分流时间
