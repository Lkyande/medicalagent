# Skill: 昏厥与抽搐红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第43章 昏厥和抽搐
- 页码: 第43章“昏厥和抽搐的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第43章.md`

**目标 / Objective**
快速识别提示严重心血管、神经系统或感染性病因的昏厥与抽搐表现。

**适用范围 / Scope**
- 所有以昏厥、抽搐、断片或突然病情恶化感就诊的病人

**操作步骤 / Procedure**
1. 先记录病人年龄,对老年首次发作提高警惕。
2. 评估是否存在神经系统症状、头痛、认知损伤或逐渐加重的混乱。
3. 检查心率和脉律,识别心动过速或脉搏不规则。
4. 测量体温并观察是否合并发热或皮疹。
5. 主动核查处方药、社交娱乐药和酒精暴露,红旗征阳性时立即升级评估。

**注意事项 / Precautions**
- 老年新发昏厥或抽搐要优先排除心律失常、TIA 和占位性病变。
- 发热、皮疹或意识改变提示感染性中枢神经系统疾病可能。
- 药物和违禁药物可直接诱发发作或混淆病史判断。

**量化指标 / Metrics**
- 昏厥病人红旗征记录率
- 高危病例当日升级评估率
- 严重病因漏诊率
