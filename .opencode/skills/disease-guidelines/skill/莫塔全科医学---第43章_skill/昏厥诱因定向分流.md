# Skill: 昏厥诱因定向分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第43章 昏厥和抽搐
- 页码: 第43章“诱发因素”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第43章.md`

**目标 / Objective**
根据触发场景快速缩小昏厥或抽搐样事件的可能病因范围。

**适用范围 / Scope**
- 可提供较清楚诱发经过的发作性意识障碍病人

**操作步骤 / Procedure**
1. 询问发作是否由情绪激动、压力或过度呼吸触发。
2. 识别恐惧、疼痛或见血后发作,优先考虑血管迷走性晕厥。
3. 识别突然站立后发作,评估直立性低血压可能。
4. 识别劳力后发作、胸闷或呼吸困难,警惕主动脉瓣狭窄或心律失常。
5. 对头部运动或嗜睡诱发者,分别考虑颈椎病相关椎基底供血不足和发作性睡病。

**注意事项 / Precautions**
- 劳力性发作比静息发作更应优先排查结构性心脏病。
- 焦虑相关过度通气可伴四肢刺痛和手足僵硬,易被误认为神经系统病变。
- 诱因只能帮助分流,不能替代心电图和基础检查。

**量化指标 / Metrics**
- 诱因记录完整率
- 诱因导向初步分类准确率
- 心血管高危诱因识别率
