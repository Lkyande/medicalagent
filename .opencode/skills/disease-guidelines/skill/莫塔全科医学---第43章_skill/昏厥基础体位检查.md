# Skill: 昏厥基础体位检查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第43章 昏厥和抽搐
- 页码: 第43章“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第43章.md`

**目标 / Objective**
在基层通过核心查体快速筛查直立性低血压、心血管和颈椎相关病因。

**适用范围 / Scope**
- 昏厥、头重脚轻、断片或发作后恢复期病人

**操作步骤 / Procedure**
1. 评估精神状态,特别注意焦虑、意识和认知变化。
2. 查找贫血、感染和酗酒的体征。
3. 完成心血管检查,包括脉搏、心脏听诊和卧位、立位血压测量。
4. 进行脑血管相关查体,关注颈动脉、血管杂音和眼底。
5. 检查颈椎活动和压痛,判断是否可能诱发椎基底供血不足症状。

**注意事项 / Precautions**
- 卧立位血压是昏厥查体中的关键步骤,不应遗漏。
- 脉搏不规则或杂音提示需优先转入心源性评估。
- 颈部操作应谨慎,避免在明显不稳病人中反复诱发症状。

**量化指标 / Metrics**
- 卧立位血压完成率
- 心血管异常发现率
- 直立性低血压识别率
