# Skill: 热性惊厥急救分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第43章 昏厥和抽搐
- 页码: 第43章“热性惊厥”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第43章.md`

**目标 / Objective**
对儿童热性惊厥进行时长分层和初始处理,及时识别需要药物终止的发作。

**适用范围 / Scope**
- 3 个月至 6 岁伴发热的强直阵挛性发作儿童

**操作步骤 / Procedure**
1. 确认年龄和发热背景,将发作首先归入热性惊厥可能。
2. 记录发作持续时间和是否已自行停止。
3. 对持续 5 分钟以上的发作按书中建议考虑咪达唑仑或地西泮。
4. 发作停止后继续寻找感染来源并评估是否存在非典型危险特征。
5. 向家长说明热性惊厥长期预后通常良好,但首次或复杂发作需进一步评估。

**注意事项 / Precautions**
- 新生儿发作不应简单归为热性惊厥,需要专门护理和病因追查。
- 发作时间是分流关键,必须准确记录。
- 高热只是背景因素,仍需排除脑膜炎和其他严重感染。

**量化指标 / Metrics**
- 热性惊厥持续时间记录率
- 5 分钟以上发作及时止痉率
- 首次发作规范评估率
