# Skill: 昏厥发作三阶段病史采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第43章 昏厥和抽搐
- 页码: 第43章“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第43章.md`

**目标 / Objective**
通过发作前、中、后的结构化病史提高昏厥与癫痫样事件的鉴别效率。

**适用范围 / Scope**
- 病史不清或需要鉴别昏厥、癫痫和心因性事件的病人

**操作步骤 / Procedure**
1. 先明确病人所谓“突然病得要死”具体指什么感觉或事件。
2. 将病史分为发作前兆、发作过程和发作后恢复三个部分分别询问。
3. 询问现场环境、姿势、诱因及旁观者目击描述。
4. 记录相关症状,如恐慌、幻觉、语言问题、出汗、饥饿感或视觉异常。
5. 若首诊无法定性,安排事件日记记录发作前中后细节和场景。

**注意事项 / Precautions**
- 旁观者描述常比病人回忆更能帮助区分癫痫与晕厥。
- 文化或语言差异可让“头晕”“断片”等表述失真,要反复澄清。
- 仅凭一次标准脑电图不能替代高质量病史。

**量化指标 / Metrics**
- 发作三阶段病史完成率
- 旁观者信息获取率
- 首诊病因分类明确率
