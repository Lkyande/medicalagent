# Skill: 外阴皮炎刺激物回避

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第99章 外阴疾病
- 页码: 第99章“皮炎”“管理原则”“治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第99章.md`

**目标 / Objective**
通过识别和去除刺激因素控制外阴皮炎症状并减少复发。

**适用范围 / Scope**
- 过敏性皮炎、刺激性接触性皮炎或疑似外阴皮炎女性

**操作步骤 / Procedure**
1. 逐项排查卫生用品、局部药物、洗液、香水、乳胶和衣物摩擦等刺激物。
2. 纠正大小便失禁、潮湿、过度清洗和紧身衣等促发因素。
3. 建议使用水性保湿面霜替代肥皂清洁。
4. 给予局部强效类固醇短疗程控制炎症,随后以低强度制剂维持。
5. 2 周后复诊评估症状和复发风险。

**注意事项 / Precautions**
- 生殖器皮肤敏感,过度清洁本身会加重问题。
- 强效局部激素需指导正确部位和疗程使用。
- 继发感染需同步处理。

**量化指标 / Metrics**
- 外阴皮炎刺激物识别率
- 替代清洁方案采用率
- 2 周复诊症状改善率
