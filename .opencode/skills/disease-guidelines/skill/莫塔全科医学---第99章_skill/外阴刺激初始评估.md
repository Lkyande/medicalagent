# Skill: 外阴刺激初始评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第99章 外阴疾病
- 页码: 第99章“表99.1 外阴不适/刺激:诊断策略模型”“皮炎管理原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第99章.md`

**目标 / Objective**
系统评估外阴瘙痒、灼热和刺激,区分皮肤病、感染和恶性病变信号。

**适用范围 / Scope**
- 主诉外阴瘙痒、灼痛、糜烂、白斑或性交不适的女性和女童

**操作步骤 / Procedure**
1. 询问症状起病、刺激物接触、过敏史、泌尿妇科病史和性生活相关问题。
2. 回顾局部使用肥皂、香水、衬垫、乳胶、茶树油、紧身衣和汗湿摩擦暴露。
3. 检查外阴并同时查看身体其他部位皮肤、头皮和指甲。
4. 需要时取阴道拭子、宫颈筛查或安排活检以排除感染和恶性病变。
5. 根据皮炎、念珠菌、苔藓类或前庭痛方向进入对应管理路径。

**注意事项 / Precautions**
- 并非所有外阴瘙痒都是念珠菌感染。
- 多因素叠加很常见,如刺激性皮炎合并继发感染。
- 对白斑、结构改变或可疑色素病灶要警惕肿瘤。

**量化指标 / Metrics**
- 外阴病人的暴露史记录率
- 全身皮肤联合检查率
- 可疑恶性病例活检或转诊率
