# Skill: 硬化性苔藓识别与随访

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第99章 外阴疾病
- 页码: 第99章“硬化性苔藓”“临床特征”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第99章.md`

**目标 / Objective**
尽早识别硬化性苔藓并通过长期随访降低瘢痕和鳞癌风险。

**适用范围 / Scope**
- 青春期前女童、围绝经期或绝经后女性出现外阴瘙痒、白斑和性交痛时

**操作步骤 / Procedure**
1. 识别生殖器瘙痒、酸痛、灼热及白色皱纹样斑块三联征。
2. 检查是否存在“8”字形苍白皮肤、龟裂、紫癜或阴唇融合趋势。
3. 在合适情况下通过活检明确诊断。
4. 使用强效局部类固醇控制症状并在改善后转入维持治疗。
5. 安排终生定期复查,监测萎缩、狭窄和鳞状细胞癌风险。

**注意事项 / Precautions**
- 阴道本身通常不受累。
- 未治疗可致外阴结构改变和狭窄。
- 存在 2%~6% 鳞癌风险,不能一次性治愈后放手。

**量化指标 / Metrics**
- 可疑硬化性苔藓识别率
- 强效局部激素规范使用率
- 长期复诊完成率
