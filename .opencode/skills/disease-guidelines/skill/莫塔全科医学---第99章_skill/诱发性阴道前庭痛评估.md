# Skill: 诱发性阴道前庭痛评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第99章 外阴疾病
- 页码: 第99章“诱发性阴道前庭痛”“诊断”“管理”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第99章.md`

**目标 / Objective**
识别诱发性阴道前庭痛并与感染、皮肤病和结构性病变区分。

**适用范围 / Scope**
- 浅表性交痛、轻触即痛或插入性疼痛的女性

**操作步骤 / Procedure**
1. 询问浅表性交痛、棉签轻触痛和对局部接触的敏感性。
2. 排除念珠菌、皮炎、硬化性苔藓和其他可见皮肤病变。
3. 进行温和前庭检查,评估触物诱发痛区域。
4. 向病人解释这是常见但痛苦的外阴痛综合征。
5. 结合局部护理、心理性支持和盆底相关干预制定治疗计划。

**注意事项 / Precautions**
- 该病常造成显著心理和性关系困扰。
- 轻触痛是重要诊断线索。
- 需避免把症状简单归结为感染反复发作。

**量化指标 / Metrics**
- 浅表性交痛病人的前庭痛筛查率
- 合并皮肤病排除率
- 多学科干预转介率
