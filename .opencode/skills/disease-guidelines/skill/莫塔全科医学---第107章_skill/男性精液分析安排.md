# Skill: 男性精液分析安排

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第107章 生育力低下的夫妇
- 页码: 第107章“初步辅助检查”“男性:精液分析”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第107章.md`

**目标 / Objective**
规范安排精液分析并正确解释首次异常结果的后续步骤。

**适用范围 / Scope**
- 不孕评估中的男性伴侣

**操作步骤 / Procedure**
1. 指导在禁欲 2 至 3 日后采集精液样本。
2. 强调样本需尽快送检,保持接近体温并在 1 小时内检测。
3. 依据 WHO 指标查看容量、密度、总数、活力、形态和白细胞。
4. 若首次异常,安排 1 至 3 个月内复查。
5. 将结果与睾丸、输精管和生活方式线索整合判断下一步检查。

**注意事项 / Precautions**
- 单次异常不能直接下永久性男性不育结论。
- 采样方式和运输条件会明显影响结果。
- 合成类固醇、热暴露和药物毒性需主动追问。

**量化指标 / Metrics**
- 精液分析规范采样率
- 首次异常复查率
- 男性因素识别率
