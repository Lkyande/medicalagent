# Skill: 不孕夫妇共同评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第107章 生育力低下的夫妇
- 页码: 第107章“不孕症定义”“诊断的方法”“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第107章.md`

**目标 / Objective**
在不孕症评估中同时纳入双方因素,尽快明确主要检查方向。

**适用范围 / Scope**
- 12 个月无保护规律性生活后未孕的夫妇

**操作步骤 / Procedure**
1. 向双方说明评估应同时进行,避免只聚焦女性或男性一方。
2. 记录双方年龄、既往妊娠史、性生活频率和尝试受孕时长。
3. 分别采集疾病、手术、性传播感染、药物、毒物和生活方式史。
4. 对双方完成一般体征和第二性征评估,按需补充生殖系统检查。
5. 根据线索决定初步转向男科、妇科、内分泌或生殖专科路径。

**注意事项 / Precautions**
- 女性、男性和双方因素大致各占三分之一。
- 年龄增长会显著降低生育力,尤其女性。
- 共情和相对快速的评估对夫妇心理状态很重要。

**量化指标 / Metrics**
- 不孕夫妇双方共同评估率
- 基础病史完整率
- 初步病因方向明确率
