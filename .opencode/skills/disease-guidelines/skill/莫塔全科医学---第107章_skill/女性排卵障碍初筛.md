# Skill: 女性排卵障碍初筛

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第107章 生育力低下的夫妇
- 页码: 第107章“女性病史”“女性:排卵状态”“女性因素”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第107章.md`

**目标 / Objective**
在不孕女性中早期识别排卵障碍及其常见病因。

**适用范围 / Scope**
- 月经不规则、疑似无排卵或不孕评估中的女性伴侣

**操作步骤 / Procedure**
1. 询问月经周期规律性、初潮、排卵症状和宫颈黏液变化。
2. 筛查 PCOS、甲状腺疾病、高催乳素血症和卵巢早衰线索。
3. 结合痤疮、多毛、BMI 和第二性征进行体检。
4. 对怀疑排卵障碍者安排相应激素和相关基础检查。
5. 根据结果转入妇科、生殖内分泌或生殖专科路径。

**注意事项 / Precautions**
- PCOS 是最常见排卵障碍原因之一。
- 规律月经通常提示在排卵,但并非绝对。
- 年龄相关卵巢储备下降不能忽略。

**量化指标 / Metrics**
- 不孕女性排卵史记录率
- 排卵障碍线索识别率
- 内分泌检查完成率
