# Skill: 旅行者腹泻处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第129章 旅行者健康和热带医学
- 页码: 第129章“旅行者腹泻”“治疗”“预防建议”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第129章.md`

**目标 / Objective**
对轻中重度旅行者腹泻进行分层处理并加强补液与预防教育。

**适用范围 / Scope**
- 旅行中或归国后出现急性腹泻的成人和部分儿童旅行者

**操作步骤 / Procedure**
1. 区分轻度自限性腹泻与发热、血便、黏液便等中重度表现。
2. 以口服补液为核心治疗措施。
3. 对无血便的轻症成人可谨慎使用洛哌丁胺等对症药。
4. 对中重度腹泻考虑短疗程经验性抗生素,并评估是否需住院。
5. 教育病人后续遵守“不能削皮、煮沸或煮熟的东西不要吃”。

**注意事项 / Precautions**
- 大便带血或高热提示侵袭性病原体可能。
- 儿童慎用止泻药。
- 持续性腹泻要考虑寄生虫感染。

**量化指标 / Metrics**
- 旅行者腹泻分层记录率
- 补液指导覆盖率
- 中重度病例抗生素使用规范率
