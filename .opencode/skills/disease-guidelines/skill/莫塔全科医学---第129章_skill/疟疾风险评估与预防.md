# Skill: 疟疾风险评估与预防

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第129章 旅行者健康和热带医学
- 页码: 第129章“疟疾”“疟疾的风险评估”“疟疾的预防”“药物预防”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第129章.md`

**目标 / Objective**
评估旅行者疟疾风险并制定蚊虫防护与药物预防方案。

**适用范围 / Scope**
- 前往疟疾流行地区旅行的成人、儿童和高风险特殊人群

**操作步骤 / Procedure**
1. 根据国家、城市/农村、季节、停留时间和住宿条件评估疟疾风险。
2. 识别妊娠、儿童、脾切除和依从性差等高风险宿主因素。
3. 先制定避免蚊虫叮咬的行为和环境防护措施。
4. 根据耐药区和旅程选择合适的预防药物并讲清起止时间。
5. 教育病人即使完成预防也不能完全排除疟疾,归国后发热仍需警惕。

**注意事项 / Precautions**
- 恶性疟可致命,诊断和治疗延误风险最高。
- 黄昏到黎明的蚊虫叮咬最关键,但白天叮咬仍可能传播登革热。
- 妊娠和小年龄儿童应尽量避免前往高流行区。

**量化指标 / Metrics**
- 疟疾风险评估记录率
- 预防药物依从性教育率
- 高危旅行者专门告知率
