# Skill: 旅行前健康评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第129章 旅行者健康和热带医学
- 页码: 第129章“提供旅行前健康服务的原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第129章.md`

**目标 / Objective**
在出发前系统评估旅行者的健康风险并制定个体化预防计划。

**适用范围 / Scope**
- 即将前往国内外尤其热带和发展中国家的旅行者

**操作步骤 / Procedure**
1. 建议至少提前 8 周计划并预约旅行医学咨询。
2. 了解目的地、旅行方式、停留时间、住宿条件和季节。
3. 回顾既往病史、现用药、疫苗状态、妊娠、儿童或老年因素。
4. 根据旅程制订疫苗、药物预防、食物水卫生和蚊虫防护建议。
5. 提供书面和口头建议,并列出慢病和治疗清单随身携带。

**注意事项 / Precautions**
- 旅行医学建议必须个体化,不能只按国家名单复制。
- 牙科检查和慢病稳定性也应纳入出发前准备。
- 书面材料能显著提高执行率。

**量化指标 / Metrics**
- 旅行前咨询提前完成率
- 个体化建议记录率
- 旅行相关疫苗和预防方案完成率
