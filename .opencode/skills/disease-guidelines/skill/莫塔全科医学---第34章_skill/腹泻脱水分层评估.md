# Skill: 腹泻脱水分层评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第34章 腹泻
- 页码: 第34章“脱水的评估”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第34章.md`

**目标 / Objective**
快速判断腹泻病人的脱水程度并选择口服或静脉补液路径。

**适用范围 / Scope**
- 急性腹泻、呕吐或疑似液体丢失的成人和儿童,尤其婴幼儿

**操作步骤 / Procedure**
1. 观察口渴、警觉程度、嗜睡、四肢发冷和尿量变化等总体表现。
2. 评估黏膜干燥、泪液、眼球或囟门凹陷、心率、血压和捏皮回弹时间。
3. 结合体重下降百分比判断轻度、中度或重度脱水。
4. 轻中度优先口服补液,重度脱水立即入院并以等渗液静脉复苏。
5. 在儿童中尽量使用同一体重秤动态复测,校正补液计划。

**注意事项 / Precautions**
- 婴儿严重胃肠炎可迅速危及生命,需优先评估。
- 血清电解质在等渗脱水时可能暂时正常,不能因此低估病情。
- 无尿、皮肤回弹极慢和意识改变提示重度脱水。

**量化指标 / Metrics**
- 脱水分层记录率
- 适当补液路径选择率
- 重度脱水延迟识别率
