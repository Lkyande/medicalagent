# Skill: 抗生素相关腹泻与C.diff识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第34章 腹泻
- 页码: 第34章“假膜性肠炎(抗生素相关性腹泻)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第34章.md`

**目标 / Objective**
及时识别艰难梭菌相关腹泻并避免误用止泻药或延迟病原学处理。

**适用范围 / Scope**
- 近期使用抗生素后出现重度水样腹泻、腹胀或腹部绞痛病人

**操作步骤 / Procedure**
1. 询问近期开立或自行使用抗生素史,尤其是腹泻发生前数周内。
2. 识别 Girotra 三联征:重度水样腹泻、腹部绞痛和腹胀加剧。
3. 停止可疑诱因药物并送检艰难梭菌及毒素相关粪便检测。
4. 避免使用抗动力止泻药,优先补液和病原学导向治疗。
5. 出现重症表现者加快住院评估和感染管理。

**注意事项 / Precautions**
- 抗生素相关腹泻并非都为 C. diff,但该病需要优先排除。
- 抗动力药在此场景下风险更高。
- 长期住院、老年和免疫低下病人风险更高。

**量化指标 / Metrics**
- 抗生素史记录率
- 可疑 C. diff 粪检完成率
- 止泻药禁忌误用率
