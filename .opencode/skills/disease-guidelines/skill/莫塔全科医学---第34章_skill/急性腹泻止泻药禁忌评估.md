# Skill: 急性腹泻止泻药禁忌评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第34章 腹泻
- 页码: 第34章“治疗原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第34章.md`

**目标 / Objective**
避免在不适合的腹泻病人中使用抗动力药和无效吸附剂,降低并发症风险。

**适用范围 / Scope**
- 计划使用止泻药的急性腹泻病人

**操作步骤 / Procedure**
1. 判断腹泻是否为短期症状缓解需求,如旅行途中成人特殊场景。
2. 排除婴幼儿、儿童、艰难梭菌、沙门菌和志贺菌等高风险感染场景。
3. 仅在适当成人病人中短期考虑洛哌丁胺、地芬诺酯或可待因等抗动力药。
4. 明确告知传统吸附收敛剂如白陶土/果胶和活性炭缺乏价值,不推荐使用。
5. 若发现侵袭性或持续性感染证据,改走病原学和补液优先路径。

**注意事项 / Precautions**
- 抗动力药在某些细菌感染中可加重病情或延迟清除病原。
- 禁用于婴幼儿和儿童急性腹泻。
- 治疗目标不应只是“止住腹泻”,而是维持水化和识别严重病因。

**量化指标 / Metrics**
- 禁忌场景下止泻药误用率
- 吸附剂不合理处方率
- 旅行相关短期对症使用合规率
