# Skill: 旅行者腹泻经验性处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第34章 腹泻
- 页码: 第34章“旅行者腹泻”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第34章.md`

**目标 / Objective**
对中重度旅行者腹泻进行经验性处理,同时识别更严重的肠道感染。

**适用范围 / Scope**
- 出国旅行后 14 日内发生水样腹泻的成人病人

**操作步骤 / Procedure**
1. 询问旅行国家、时间、饮食水源和腹泻起病时距返程或到达目的地的间隔。
2. 判断腹泻是否为严重水样便或伴血便、黏液便等侵袭性感染特征。
3. 对轻症优先口服补液和短期观察。
4. 对中重度旅行者腹泻可经验性使用阿奇霉素 2~3 日。
5. 若症状迁延或伴血便、发热、体重下降,进一步排查阿米巴、贾第鞭毛虫和隐孢子虫等病原。

**注意事项 / Precautions**
- 大多数旅行者腹泻由大肠埃希菌引起,但血便提示更严重病原体可能。
- 迁延性病例不能只继续对症,要转入寄生虫和 HIV 等鉴别路径。
- 补液始终是治疗基础。

**量化指标 / Metrics**
- 旅行史记录率
- 中重度病例经验性抗菌治疗合规率
- 迁延病例病原学评估率
