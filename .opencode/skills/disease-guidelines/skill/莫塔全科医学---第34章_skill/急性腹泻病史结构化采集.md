# Skill: 急性腹泻病史结构化采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第34章 腹泻
- 页码: 第34章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第34章.md`

**目标 / Objective**
通过结构化病史区分急性胃肠炎、食物中毒、旅行相关感染和炎症性腹泻。

**适用范围 / Scope**
- 急性发作的腹泻、腹痛或伴呕吐病人

**操作步骤 / Procedure**
1. 明确病人平时排便模式与当前腹泻的差异,并记录腹泻频率和持续时间。
2. 追问过去 24~72 小时内的就餐地点、具体食物和是否有同餐者同病。
3. 询问近期国外旅行史,特别是鸡肉、海鲜和高风险水源暴露。
4. 记录是否有血便、黏液便、发热、乏力、腹痛和既往类似发作。
5. 依据潜伏期和大便性状初步分层为食物中毒、感染性胃肠炎或其他病因。

**注意事项 / Precautions**
- 急性胃肠炎多为排除性诊断,外科急腹症不能漏诊。
- 同餐者同病强烈提示食源性暴发,需询问得很具体。
- 旅行史对贾第鞭毛虫、阿米巴和旅行者腹泻判断价值高。

**量化指标 / Metrics**
- 急性腹泻病史要素完整率
- 旅行史记录率
- 食源性聚集识别率
