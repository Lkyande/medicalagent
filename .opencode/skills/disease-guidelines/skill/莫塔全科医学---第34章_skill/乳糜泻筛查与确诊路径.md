# Skill: 乳糜泻筛查与确诊路径

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第34章 腹泻
- 页码: 第34章“乳糜泻”“诊断”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第34章.md`

**目标 / Objective**
在慢性腹泻、缺铁或体重减轻病人中识别乳糜泻并按规范完成血清学和活检确诊。

**适用范围 / Scope**
- 慢性腹泻、腹胀、缺铁/叶酸缺乏、体重减轻或一级亲属阳性病人

**操作步骤 / Procedure**
1. 识别典型四联征:腹泻、体重减轻、铁/叶酸缺乏和腹胀。
2. 追问一级亲属病史及疲劳、口腔溃疡、便秘腹泻交替等非典型表现。
3. 首轮检测总 IgA、IgA 抗肌内膜抗体或转谷氨酰胺酶抗体,必要时加 DGP-IgG。
4. 血清学支持时安排十二指肠活检,以绒毛萎缩作为关键确诊依据。
5. 确诊后再启动无麸质饮食和营养缺乏纠正,并评估骨质疏松等伴发疾病。

**注意事项 / Precautions**
- 不要在确诊前自行长期无麸质饮食,以免影响活检和血清学判断。
- 乳糜泻可仅以疲劳或缺铁表现,缺少明显腹泻并不排除。
- 一级亲属风险高,可考虑定期筛查。

**量化指标 / Metrics**
- 高危人群血清学筛查率
- 阳性后活检完成率
- 确诊至饮食干预时间
