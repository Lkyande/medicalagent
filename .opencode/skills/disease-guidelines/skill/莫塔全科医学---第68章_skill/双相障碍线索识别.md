# Skill: 双相障碍线索识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第68章 抑郁和其他心境障碍
- 页码: 第68章“双相障碍”“双相Ⅰ型障碍”“双相Ⅱ型障碍”“轻躁狂”“循环性情感障碍”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第68章.md`

**目标 / Objective**
在抑郁或情绪波动病人中识别潜在双相障碍谱系线索。

**适用范围 / Scope**
- 反复抑郁、情绪高涨期或情绪大幅波动的青少年和成人病人

**操作步骤 / Procedure**
1. 询问既往是否有持续数日以上心境高涨、精力增加、睡眠需求减少或冲动行为。
2. 区分是否达到完整躁狂发作,还是仅有轻躁狂表现。
3. 评估抑郁发作与高涨期交替出现的模式及发作频率。
4. 对反复短期波动者考虑循环性情感障碍或阈下双相障碍可能。
5. 一旦怀疑双相谱系,避免仅按单相抑郁思路管理并安排精神科评估。

**注意事项 / Precautions**
- 双相Ⅱ型障碍常被误认为单纯重性抑郁。
- 后续重性抑郁期与高自杀风险相关。
- 家族史对识别双相障碍有重要价值。

**量化指标 / Metrics**
- 抑郁病人轻躁狂追问率
- 可疑双相障碍精神科转介率
- 反复发作模式记录率
