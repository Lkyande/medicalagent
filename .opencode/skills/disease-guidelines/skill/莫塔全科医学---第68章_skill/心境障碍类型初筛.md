# Skill: 心境障碍类型初筛

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第68章 抑郁和其他心境障碍
- 页码: 第68章“分类”“心境障碍的类型”“关键要点”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第68章.md`

**目标 / Objective**
在基层场景中快速区分抑郁性、躁狂性和双相谱系的主要心境障碍类型。

**适用范围 / Scope**
- 出现持续心境低落、高涨、易激惹或明显功能受损的病人

**操作步骤 / Procedure**
1. 先判断当前以抑郁、躁狂/轻躁狂,还是二者交替或混合为主。
2. 询问症状持续时间、功能损害和既往类似发作史。
3. 对抑郁状态进一步区分重性抑郁、持续性抑郁、适应障碍和季节性模式。
4. 对高涨心境状态筛查轻躁狂、躁狂和双相障碍病史。
5. 对所有明显心境障碍同步评估自杀风险和精神病性症状。

**注意事项 / Precautions**
- 诊断不能只看一次情绪状态,需结合病程和发作模式。
- 双相障碍常先以抑郁表现出现,应主动追问既往高涨期。
- 存在精神病性特征时风险升级,需更高级别干预。

**量化指标 / Metrics**
- 心境障碍病人的病程记录率
- 轻躁狂/躁狂追问率
- 自杀风险同步评估率
