# Skill: 产后精神病紧急识别与转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第68章 抑郁和其他心境障碍
- 页码: 第68章“产后精神病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第68章.md`

**目标 / Objective**
尽早识别产后精神病并启动紧急精神科处置。

**适用范围 / Scope**
- 产后 1 个月内出现行为异常、激越、妄想、幻觉或躁狂样表现的产妇

**操作步骤 / Procedure**
1. 确认发病与分娩时间关系,尤其关注产后 2 周内的急性变化。
2. 识别异常行为、谵妄、幻觉、躁狂、严重抑郁和自杀意念。
3. 评估病人对自身和婴儿的安全风险,不要单独留置。
4. 通知家属参与并启动紧急精神科评估或住院通道。
5. 在转运前持续观察意识、激越程度和伤人伤己风险。

**注意事项 / Precautions**
- 产后精神病是少见但高危急症,不能按普通产后情绪波动处理。
- 常见表现属于情感障碍谱系,可为躁狂或激越性抑郁。
- 自杀和伤婴风险必须主动评估。

**量化指标 / Metrics**
- 可疑产后精神病的当日精神科评估率
- 高危安全措施落实率
- 转运或住院完成率
