# Skill: 围产期抑郁分层识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第68章 抑郁和其他心境障碍
- 页码: 第68章“围产期抑郁”“产后忧郁”“产后适应障碍”“产后抑郁”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第68章.md`

**目标 / Objective**
区分围产期常见情绪波动、产后适应困难与需要治疗的产后抑郁。

**适用范围 / Scope**
- 妊娠期、产后 12 个月内出现情绪低落、焦虑、疲惫或照护困难的女性

**操作步骤 / Procedure**
1. 明确症状发生时间,判断在孕期、产后 2 周内还是产后数月内出现。
2. 区分短暂产后忧郁与持续至少 2 周的抑郁状态。
3. 评估焦虑、激越、情绪波动、记忆力差、注意力不集中和婴儿照护受损情况。
4. 询问既往抑郁史、支持系统和自伤或伤婴念头。
5. 对疑似产后抑郁者安排心理干预或精神科评估,并加强随访。

**注意事项 / Precautions**
- 产后忧郁常见且短暂,但持续或加重需重新分类。
- 频繁就诊的产妇要主动考虑产后抑郁。
- 自伤、伤婴或明显功能受损提示高危。

**量化指标 / Metrics**
- 围产期情绪症状病人的分层记录率
- 产后抑郁高危者转介率
- 随访完成率
