# Skill: 耳语试验执行

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第33章 耳聋与听力损失
- 页码: 第33章“耳语试验”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第33章.md`

**目标 / Objective**
用简便床旁方法粗筛明显听力减退,决定是否需进一步测听。

**适用范围 / Scope**
- 门诊初筛听力下降的成人或配合良好的儿童

**操作步骤 / Procedure**
1. 让病人用一只手遮挡视线并堵塞对侧外耳道。
2. 检查者站在距病人约 50cm 处,用力低声说出数字或字母组合。
3. 让病人重复所听到的内容,再以正常音量复测一次。
4. 双耳分别完成测试并比较差异。
5. 结果异常时安排正式听力评估,不要止步于床旁筛查。

**注意事项 / Precautions**
- 病人应看不到唇形,否则易产生假阴性。
- 耳语试验只能粗筛,不能排除轻度或早期耳聋。
- 儿童或认知受限病人需要改用更适合年龄的正式测试方法。

**量化指标 / Metrics**
- 床旁听力筛查完成率
- 异常筛查后正式测听完成率
- 耳语试验与正式测听一致率
