# Skill: 听力损失病史结构化采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第33章 耳聋与听力损失
- 页码: 第33章“病史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第33章.md`

**目标 / Objective**
通过系统病史快速识别传导性、感觉神经性及暴露相关听力损失线索。

**适用范围 / Scope**
- 新生儿、儿童、成人和老年人的听力减退或耳鸣病人

**操作步骤 / Procedure**
1. 记录听力下降的起病方式、进展速度及是否单侧或双侧。
2. 询问噪声暴露、游泳潜水、飞行、头部外伤和近期感染史。
3. 核对用药史,特别是氨基糖苷类、利尿剂、化疗药和水杨酸盐。
4. 追问并存耳痛、耳漏、耳鸣、眩晕及家族性耳聋病史。
5. 结合“游泳或淋浴后突然变差”等情景线索,初步判断耵聍、气压伤、耳毒性或神经性病因。

**注意事项 / Precautions**
- 单侧感觉神经性耳聋必须视为红旗征处理。
- 听力损失可由耳毒性药物导致,药史不能省略。
- 儿童和老年病人的症状表达常不典型,需主动追问行为改变和社交回避。

**量化指标 / Metrics**
- 病史要素完整率
- 耳毒性药物识别率
- 单侧神经性耳聋早期转诊率
