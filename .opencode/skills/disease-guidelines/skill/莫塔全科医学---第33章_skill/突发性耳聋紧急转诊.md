# Skill: 突发性耳聋紧急转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第33章 耳聋与听力损失
- 页码: 第33章“突发性耳聋”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第33章.md`

**目标 / Objective**
尽早识别突发性感觉神经性耳聋并加速进入耳科和影像评估路径。

**适用范围 / Scope**
- 12 小时至 3 日内突然发生听力下降超过约 30~35dB 的病人

**操作步骤 / Procedure**
1. 确认听力下降发生在数小时至 3 日内,并排除逐渐累积性噪声损伤或老年性耳聋。
2. 先用耳镜排除耵聍、中耳积液和鼓膜病变等可逆传导性原因。
3. 追问潜水、飞行、爆炸声、病毒感染、耳毒性药物和既往镫骨切除术史。
4. 将病人视为耳科急症,尽快转诊并安排测听、全血细胞计数、ESR、病毒检测和 MRI。
5. 对特别可疑的淋巴外瘘或听神经瘤保持高度警觉,不延迟专科处理。

**注意事项 / Precautions**
- 突发性耳聋早期诊断和高度怀疑是治疗关键。
- 很多病例病因不明但可自行恢复,不能因此延误排除严重病因。
- 单侧神经性耳聋伴脑神经异常更应紧急处理。

**量化指标 / Metrics**
- 发病至耳科转诊时间
- 同日或次日测听完成率
- MRI 完成率
