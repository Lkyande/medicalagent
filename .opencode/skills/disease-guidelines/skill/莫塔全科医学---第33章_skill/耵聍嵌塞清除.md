# Skill: 耵聍嵌塞清除

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第33章 耳聋与听力损失
- 页码: 第33章“耵聍嵌塞”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第33章.md`

**目标 / Objective**
安全去除耵聍嵌塞,恢复传导性听力并避免外耳道或鼓膜损伤。

**适用范围 / Scope**
- 耵聍堵塞导致听力下降、耳闷或助听器使用受限的病人

**操作步骤 / Procedure**
1. 耳镜确认耵聍嵌塞并评估是否伴感染或鼓膜穿孔。
2. 必要时提前数日使用溶耵聍滴剂,如碳酸氢钠、过氧化氢或油性滴剂。
3. 对鼓膜完整且无感染者,由有经验的医生用体温温水或生理盐水轻柔冲洗。
4. 清除后复查外耳道和鼓膜,确认无残留堵塞或并发损伤。
5. 教育病人避免使用棉签反复推耵聍入深部。

**注意事项 / Precautions**
- 感染或鼓膜穿孔时避免冲洗。
- 助听器使用者和老年人更易耵聍嵌塞,需定期复查。
- 闭孔角化病并非普通耳垢,需识别珍珠白色角蛋白堵塞。

**量化指标 / Metrics**
- 冲洗后症状缓解率
- 冲洗并发症发生率
- 复发性耵聍嵌塞再就诊率
