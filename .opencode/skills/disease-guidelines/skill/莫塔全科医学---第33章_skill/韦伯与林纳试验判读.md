# Skill: 韦伯与林纳试验判读

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第33章 耳聋与听力损失
- 页码: 第33章“音叉试验”“韦伯试验”“林纳试验”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第33章.md`

**目标 / Objective**
区分传导性与感觉神经性听力损失,为后续影像和专科路径提供方向。

**适用范围 / Scope**
- 已发现听力减退并可配合音叉测试的病人

**操作步骤 / Procedure**
1. 用 512Hz 音叉做韦伯试验,置于前额正中或颅骨中点。
2. 询问声音偏向哪一侧,判断是患侧传导性损失还是对侧感觉神经性损失。
3. 对每只耳分别做林纳试验,比较空气传导与骨传导强弱。
4. 将 AC>BC 判为林纳阳性,更支持正常或感觉神经性损失;BC>AC 提示传导性损失。
5. 综合韦伯和林纳结果,决定是否需测听、鼓室图或 MRI/CT。

**注意事项 / Precautions**
- 韦伯试验仅在单侧或双侧不对称耳聋时最有价值。
- 重度感觉神经性耳聋可出现假阴性林纳结果,需谨慎解释。
- 音叉试验不能替代纯音测听,只用于床旁分型。

**量化指标 / Metrics**
- 音叉试验完成率
- 床旁分型与纯音测听一致率
- 正确分流至影像或耳科转诊率
