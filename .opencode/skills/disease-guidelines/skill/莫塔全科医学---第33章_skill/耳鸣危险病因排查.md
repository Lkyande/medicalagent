# Skill: 耳鸣危险病因排查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第33章 耳聋与听力损失
- 页码: 第33章“耳鸣”“预防措施”“辅助检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第33章.md`

**目标 / Objective**
在耳鸣初诊时排除听神经瘤、血管病变、药物和重度抑郁等重要病因。

**适用范围 / Scope**
- 主诉持续性、单侧、搏动性或严重耳鸣的病人

**操作步骤 / Procedure**
1. 先区分主观耳鸣与客观耳鸣,再区分搏动性和非搏动性耳鸣。
2. 排查耵聍、药物、贫血、抑郁、血管杂音、梅尼埃病和感染等常见加重因素。
3. 对搏动性耳鸣重点考虑颈动脉病变、动静脉畸形和静脉嗡鸣。
4. 对单侧进行性耳鸣合并听损者优先排查听神经瘤,安排听力测试和 MRI/CT。
5. 同时评估独居老人的情绪和自杀风险,必要时联合心理支持。

**注意事项 / Precautions**
- 单侧耳鸣伴进行性听损属于高危模式,不能简单安抚。
- 药物包括阿司匹林、袢利尿剂、大麻、奎宁和氨基糖苷类都需核查。
- 阻生智齿和颞下颌关节问题也可模拟耳鸣,易被遗漏。

**量化指标 / Metrics**
- 耳鸣病因分层记录率
- 高危耳鸣影像完成率
- 可逆加重因素识别率
