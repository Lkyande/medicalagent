# Skill: 儿童听力损失早期识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第33章 耳聋与听力损失
- 页码: 第33章“儿童的耳聋”“筛查”“听力丧失的早期征象”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第33章.md`

**目标 / Objective**
在语言发育关键期内发现儿童听力损失并尽早转介听力和语言服务。

**适用范围 / Scope**
- 新生儿、婴幼儿和学龄前儿童的听力筛查或发育评估场景

**操作步骤 / Procedure**
1. 根据年龄核对正常听觉反应里程碑,如 4 月龄回头寻找声源、12 月龄对名字有反应。
2. 筛查高危因素,包括耳聋家族史、围生期问题、NICU 住院、极低出生体重和脑瘫等。
3. 对言语发育迟缓、只对大声有反应、不能辨别声源或行为问题儿童提高警惕。
4. 对婴幼儿安排 AABR、TEOAE 或鼓室测量等适龄正式检查,并做耳镜排除中耳积液。
5. 一旦发现中耳病变或听力损失,及时转耳科、听力中心和语言教育支持机构。

**注意事项 / Precautions**
- 家长尤其母亲的怀疑很少出错,不能轻易安抚了事。
- 非正式的耳语或摇钥匙测试不足以排除耳聋。
- 1 岁前是语言学习关键期,延迟识别会显著影响语言发育。

**量化指标 / Metrics**
- 高危儿童正式筛查完成率
- 听损发现年龄
- 听力异常后转介完成率
