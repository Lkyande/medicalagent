# Skill: 男性健康机会性筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第102章 男人的健康概述
- 页码: 第102章“男性健康速览”“小结”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第102章.md`

**目标 / Objective**
利用男性就诊机会主动筛查高负担的慢病和高风险行为问题。

**适用范围 / Scope**
- 青少年至老年男性全科就诊场景

**操作步骤 / Procedure**
1. 结合年龄关注交通伤害、自杀、心血管病、肥胖和呼吸病等高负担问题。
2. 主动询问吸烟、饮酒、身体活动、饮食和冒险行为。
3. 记录心理健康、自杀风险和家庭社会压力线索。
4. 针对下尿路症状、性功能和肥胖等男性常忽视问题主动切入。
5. 将筛查结果转化为具体预防建议和后续复诊安排。

**注意事项 / Precautions**
- 男性往往较少主动寻求医疗服务,机会性筛查特别重要。
- 低社会经济地位男性风险更高。
- 咨询应避免羞辱和刻板印象化。
**量化指标 / Metrics**
- 男性就诊机会性筛查覆盖率
- 生活方式风险因素记录率
- 后续预防随访率
