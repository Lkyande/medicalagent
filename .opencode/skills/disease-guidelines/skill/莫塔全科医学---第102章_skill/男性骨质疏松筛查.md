# Skill: 男性骨质疏松筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第102章 男人的健康概述
- 页码: 第102章“男性的骨质疏松”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第102章.md`

**目标 / Objective**
提升男性骨质疏松识别率并减少低创伤骨折漏诊。

**适用范围 / Scope**
- 老年男性、低冲击骨折者或存在骨质疏松危险因素的男性

**操作步骤 / Procedure**
1. 询问低钙饮食、缺乏负重运动、维生素 D 缺乏、吸烟、酗酒和长期类固醇使用。
2. 关注性腺功能减退、低体重、跌倒风险和脊柱后凸或身高下降。
3. 对高危者安排 BMD、CBC、肝功能、睾酮和维生素 D 检查。
4. 一旦确诊,指导补钙、补维生素 D、负重锻炼和跌倒预防。
5. 必要时启动双膦酸盐等药物治疗或进一步专科评估。

**注意事项 / Precautions**
- 男性骨质疏松识别不足很常见。
- 骨折和背痛可能是首发表现。
- 跌倒预防是减少骨折的重要组成部分。

**量化指标 / Metrics**
- 高危男性 BMD 检测率
- 骨质疏松风险因素记录率
- 低创伤骨折后的治疗启动率
