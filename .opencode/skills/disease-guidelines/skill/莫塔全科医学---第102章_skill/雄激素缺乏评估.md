# Skill: 雄激素缺乏评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第102章 男人的健康概述
- 页码: 第102章“雄激素缺乏”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第102章.md`

**目标 / Objective**
识别不同年龄阶段提示雄激素缺乏的体征症状并进行规范检测。

**适用范围 / Scope**
- 青春期发育迟缓、性欲下降、ED、男性乳房发育或骨质疏松的男性

**操作步骤 / Procedure**
1. 按年龄询问小睾丸、青春期发育迟缓、男性化退化、潮热、性欲减退和嗜睡等表现。
2. 完成病史和体检,尤其检查睾丸大小和硬度。
3. 用不同日子的清晨睾酮检测至少两次确认结果,必要时加测 LH、FSH。
4. 根据生育需求和相关线索补充精液分析、核型、骨密度和铁代谢检查。
5. 确诊后评估是否适合睾酮替代及专科转诊。

**注意事项 / Precautions**
- 评估应先从病史和查体开始,而非直接只开血检。
- ED 并不常由雄激素缺乏引起,但可作为筛查线索。
- 睾酮补充剂不应在无医学证据支持下随意使用。

**量化指标 / Metrics**
- 可疑病例双次清晨睾酮检测率
- 体检记录率
- 适当专科转介率
