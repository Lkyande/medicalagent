# Skill: 酒精戒断处理

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第12章 药物和酒精问题
- 页码: 第12章“戒断症状”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第12章.md`

**目标 / Objective**
识别并处理长期饮酒者的急性戒断症状,预防震颤性谵妄和营养并发症。

**适用范围 / Scope**
- 停止或显著减少长期饮酒后出现戒断表现的病人

**操作步骤 / Procedure**
1. 识别烦乱、明显震颤、多汗、失眠、癫痫发作等戒断表现。
2. 先保障液体、电解质和营养摄入,同步补充复合维生素 B 和维生素 B1。
3. 需要药物时,在专业建议下使用地西泮 20 mg 口服每 2 小时一次,按临床反应滴定并于 2 日后逐渐减量。
4. 维生素 B1 给予 100 mg 每日肌注或静注 3 日,随后口服 300 mg 持续数周。
5. 若伴精神症状,加用氟哌啶醇并严密观察,必要时住院。

**注意事项 / Precautions**
- 急性戒断治疗的核心目标是预防震颤性谵妄。
- 长期饮酒者几乎都要考虑维生素 B1 缺乏。
- 门诊处理前要评估监督条件,无法确保安全时应住院。

**量化指标 / Metrics**
- 戒断病人维生素 B1 补充率
- 戒断后进展为震颤性谵妄比例
- 戒断期非计划住院率
