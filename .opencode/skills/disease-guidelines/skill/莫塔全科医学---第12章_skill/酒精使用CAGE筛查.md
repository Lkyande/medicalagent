# Skill: 酒精使用CAGE筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第12章 药物和酒精问题
- 页码: 第12章“采集饮酒史”“有用的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第12章.md`

**目标 / Objective**
在全科就诊中快速识别可能存在问题饮酒或酒精依赖的病人。

**适用范围 / Scope**
- 饮酒史不清、怀疑过量饮酒、反复躯体或社会问题相关就诊者

**操作步骤 / Procedure**
1. 以非指责方式询问上次饮酒时间、饮酒频率和标准酒精量。
2. 避免问“你喝酒吗”这类容易引出否认的封闭式问题。
3. 依次完成 CAGE 四问,包括是否想减少、被批评恼怒、因饮酒内疚和晨起饮酒。
4. 若 CAGE 有 2 项或以上阳性,标记为存在饮酒问题可能并进入进一步评估。
5. 同步核实每日饮酒时间、花费和家庭或工作影响,提高病史可信度。

**注意事项 / Precautions**
- 很多问题饮酒者会低报摄入量,需交叉核对饮酒时间和消费信息。
- 饮酒量应尽量换算为标准酒精量记录。
- CAGE 是筛查工具,阳性后仍需结合临床危害程度和依赖表现综合判断。

**量化指标 / Metrics**
- 成人饮酒史记录率
- CAGE 筛查完成率
- CAGE 阳性者后续评估率
