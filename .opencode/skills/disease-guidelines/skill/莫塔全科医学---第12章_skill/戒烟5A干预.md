# Skill: 戒烟5A干预

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第12章 药物和酒精问题
- 页码: 第12章“帮助病人戒烟”“干预:5A策略”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第12章.md`

**目标 / Objective**
通过结构化 5A 流程提升吸烟者戒烟意愿、制定戒烟计划并安排持续随访。

**适用范围 / Scope**
- 所有当前吸烟者,尤其高危重度吸烟者

**操作步骤 / Procedure**
1. 询问并记录每位病人的吸烟状态、每日支数和首次晨烟时间。
2. 评估戒烟的动力和信心,直接询问是否愿意戒烟。
3. 清楚建议所有吸烟者戒烟,并说明对健康、寿命、财富和家庭的获益。
4. 通过咨询、行为策略、戒烟日志和药物治疗帮助病人实施戒烟计划。
5. 安排随访,至少每月一次,尤其在戒烟后前 3 个月内持续追踪。

**注意事项 / Precautions**
- 如果病人暂不愿戒烟,应提供激励资料并保留再次讨论的机会。
- 每日吸烟大于等于 20 支或醒后 30 分钟内吸烟者属于高依赖高风险人群。
- 戒烟建议要具体到计划与跟踪,不能停留在口头劝说。

**量化指标 / Metrics**
- 吸烟状态记录率
- 戒烟计划制定率
- 3 个月戒烟随访完成率
