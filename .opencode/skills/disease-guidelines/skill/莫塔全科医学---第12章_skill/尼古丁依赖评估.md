# Skill: 尼古丁依赖评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第12章 药物和酒精问题
- 页码: 第12章“干预:5A策略”“戒断反应”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第12章.md`

**目标 / Objective**
识别吸烟者的尼古丁依赖程度和戒断风险,为药物与行为干预分层。

**适用范围 / Scope**
- 拟戒烟、戒烟失败或怀疑高尼古丁依赖的吸烟者

**操作步骤 / Procedure**
1. 询问每日吸烟数量、醒来后首次吸烟时间及在禁烟场所维持不吸烟的困难程度。
2. 必要时使用基于 Fagerstrom 的尼古丁依赖量表辅助评估。
3. 将病人分为低依赖、中依赖和高依赖,重点标记每日吸烟大于 20 支者。
4. 向病人说明早期戒断症状,包括烦躁、渴求、饥饿、易怒、头痛和情绪低落。
5. 根据依赖程度决定是否进入 NRT 或其他戒烟药物路径。

**注意事项 / Precautions**
- 低依赖者药物获益证据较弱,可优先非药物策略。
- 戒断症状通常 10 日左右开始缓解,但完全消退可能需要约 3 个月。
- 依赖评估应服务于治疗选择,避免只打分不干预。

**量化指标 / Metrics**
- 戒烟者尼古丁依赖评估率
- 高依赖吸烟者药物干预率
- 戒断症状提前教育率
