# Skill: 震颤性谵妄识别与住院

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第12章 药物和酒精问题
- 页码: 第12章“酒精戒断谵妄(震颤性谵妄)”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第12章.md`

**目标 / Objective**
及早识别危及生命的酒精戒断谵妄,启动住院和强化支持治疗。

**适用范围 / Scope**
- 酒精戒断后 1 到 5 日内出现意识和自主神经症状的病人

**操作步骤 / Procedure**
1. 识别定向障碍、意识模糊、明显震颤、幻视、多汗、心动过速和发热。
2. 若怀疑震颤性谵妄,立即安排住院并接入酒精专科咨询服务。
3. 通过静脉滴注纠正液体和电解质失衡,同时筛查并治疗感染等诱因。
4. 给予维生素 B1 300 mg 每日肌注或静注 3 到 5 日,随后改口服维持。
5. 使用地西泮按症状滴定至控制,伴幻觉或妄想时加用氟哌啶醇。

**注意事项 / Precautions**
- 震颤性谵妄病死率高,不能门诊观察等待。
- 氯丙嗪不推荐用于该情境,因可能降低癫痫阈值。
- 地西泮和氟哌啶醇可能加重肝毒性表现,需动态评估。

**量化指标 / Metrics**
- 疑似震颤性谵妄住院转运时效
- 住院前维生素 B1 启动率
- 诱因感染识别率
