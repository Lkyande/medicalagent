# Skill: 药物不良反应评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第12章 药物和酒精问题
- 页码: 第12章“药物不良反应”“预防药物不良反应的黄金法则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第12章.md`

**目标 / Objective**
在出现新症状或用药变更后,系统识别可能的药物不良反应并降低再次暴露风险。

**适用范围 / Scope**
- 使用处方药、非处方药或多药并用后出现新症状的病人

**操作步骤 / Procedure**
1. 详细核对全部用药,包括处方药、非处方药和社交娱乐药物。
2. 判断不良反应更符合 A 型可预测、剂量相关反应,还是 B 型不可预测反应。
3. 将当前症状与常见受累系统逐项对应,包括中枢神经、心血管、胃肠、皮肤和精神情绪反应。
4. 回顾开药必要性、预期获益和潜在危害,评估是否需要停药、换药或减量。
5. 在病历中明确记录疑似不良反应和相关药物,后续避免再次不当使用。

**注意事项 / Precautions**
- 年龄越大药物不良反应越常见,老年病人尤其要警惕。
- 任何临床问题都可能与治疗措施有关,不要只把注意力放在原发病。
- 过敏或严重反应要优先保障安全,必要时立即停用并急诊处理。

**量化指标 / Metrics**
- 疑似不良反应病人完整用药核对率
- 高风险药物复核率
- 记录并标记过敏或严重不良反应率
