# Skill: 破裂腹主动脉瘤紧急识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第24章 腹痛
- 页码: 第24章“动脉瘤破裂”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第24章.md`

**目标 / Objective**
尽早识别破裂腹主动脉瘤这一外科急症,缩短转运和术前复苏时间。

**适用范围 / Scope**
- 老年急性腹痛、背痛、晕厥或休克病人

**操作步骤 / Procedure**
1. 对老年人突发剧烈腹痛或背痛伴苍白、晕厥时立即考虑破裂 AAA。
2. 询问是否在如厕或用力排便时突然发病。
3. 迅速评估血压、脉搏、意识状态和外周灌注,识别失血性休克。
4. 立即建立静脉通路补液扩容,必要时使用中心静脉通路。
5. 同时联系血管外科并直接转送具备急诊手术能力的医院,提前通知手术准备。

**注意事项 / Precautions**
- 这是时间敏感型病变,不要因等待完整影像而延误转运。
- 上厕所晕倒是重要线索,不能被误认为单纯排便性迷走反应。
- 任何短暂好转都不能排除持续出血。

**量化指标 / Metrics**
- 识别至转运时间
- 初始静脉通路建立时间
- 破裂 AAA 院前死亡率
