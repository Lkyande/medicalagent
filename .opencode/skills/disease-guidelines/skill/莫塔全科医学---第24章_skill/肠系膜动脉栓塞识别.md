# Skill: 肠系膜动脉栓塞识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第24章 腹痛
- 页码: 第24章“肠系膜动脉栓塞”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第24章.md`

**目标 / Objective**
在早期腹部体征尚不明显时识别肠系膜动脉栓塞并加速外科干预。

**适用范围 / Scope**
- 老年、房颤或动脉粥样硬化病人出现剧烈中腹痛和呕吐者

**操作步骤 / Procedure**
1. 对有房颤或动脉粥样硬化背景者,一旦出现逐渐加重的脐周剧痛即提高警惕。
2. 询问是否伴大量呕吐、水样腹泻、出血性腹泻和“害怕进食”。
3. 早期即使腹部体征不重,也要记录焦虑、虚脱、意识混乱等全身表现。
4. 紧急安排 CT 评估,必要时联系肠系膜动脉造影或外科直接评估。
5. 立即转外科,强调数小时内诊断和手术对保肠的重要性。

**注意事项 / Precautions**
- 早期疼痛程度常与腹部查体不成比例,这是关键提示。
- 休克和腹膜炎可在后期才出现,不能等到体征“典型”再转诊。
- 一旦怀疑,比起追求门诊明确诊断,更重要的是快速进入手术路径。

**量化指标 / Metrics**
- 高危腹痛识别率
- 疑似病例外科评估时间
- 坏死肠段切除比例
