# Skill: 腹痛初始辅助检查分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第24章 腹痛
- 页码: 第24章“辅助检查”“影像学检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第24章.md`

**目标 / Objective**
根据腹痛表现选择最有价值的实验室和影像检查,减少漏诊和无效检查。

**适用范围 / Scope**
- 需要进一步检查的腹痛病人

**操作步骤 / Procedure**
1. 根据临床问题选择实验室检查,如血常规、CRP、肝功能、脂肪酶或淀粉酶、尿检和妊娠试验。
2. 怀疑胰腺炎时优先看脂肪酶或淀粉酶是否达到正常上限 3 倍以上。
3. 怀疑胆道、肾脏、盆腔或异位妊娠时优先安排超声。
4. 诊断不明或需评估腹膜炎、憩室炎、创伤及阑尾炎时优先安排 CT。
5. 有肠梗阻、穿孔或结石指征时补充立卧位腹部 X 线和胸片寻找液平面、膈下游离气体等征象。

**注意事项 / Precautions**
- 腹痛检查应服务于具体诊断假设,不要机械性“全套化验”。
- 所有育龄女性腹痛都应考虑妊娠试验。
- 超声可能受肠气干扰,阴性结果不能完全排除严重疾病。

**量化指标 / Metrics**
- 妊娠试验适应证覆盖率
- 高危腹痛 CT/超声及时完成率
- 非必要检查比例
