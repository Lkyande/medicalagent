# Skill: 腹主动脉瘤家族筛查与转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第24章 腹痛
- 页码: 第24章“腹主动脉瘤”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第24章.md`

**目标 / Objective**
识别腹主动脉瘤高危人群并依据直径分层安排影像筛查和血管外科转诊。

**适用范围 / Scope**
- 有腹主动脉瘤家族史、腹部搏动性肿块或老年腹痛病人

**操作步骤 / Procedure**
1. 询问一级亲属中是否有腹主动脉瘤或相关手术史。
2. 对有家族史者建议 50 岁后行腹部超声筛查。
3. 对可触及搏动性肿块或腹部不适者安排超声,必要时进一步做 CT 或 MRI。
4. 依据直径分层: >30mm 视为动脉瘤, >=40mm 转专科, >50mm 视为显著扩大并评估手术。
5. 将结果和复查计划明确记录,交由血管外科持续管理。

**注意事项 / Precautions**
- 肥胖可影响触诊,不能因未触及肿块就排除动脉瘤。
- 破裂风险与直径和增长速度都有关,需强调定期复查。
- 老年腹痛合并背痛或晕厥时不要按普通消化道疾病处理。

**量化指标 / Metrics**
- 家族史阳性者超声筛查率
- 动脉瘤检出后的专科转诊率
- 随访超声依从率
