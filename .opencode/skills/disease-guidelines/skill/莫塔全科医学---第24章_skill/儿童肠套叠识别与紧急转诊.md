# Skill: 儿童肠套叠识别与紧急转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第24章 腹痛
- 页码: 第24章“肠套叠”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第24章.md`

**目标 / Objective**
在发病早期识别儿童肠套叠,尽快转入影像复位或手术路径,降低坏死和死亡风险。

**适用范围 / Scope**
- 3个月至2岁突发阵发性腹痛、呕吐或苍白的婴幼儿

**操作步骤 / Procedure**
1. 遇到婴幼儿突发剧烈哭闹性腹痛且每隔约 15 分钟重复发作时,首先考虑肠套叠。
2. 询问是否伴呕吐、嗜睡、明显苍白和红醋栗果冻样便。
3. 发作期间查体寻找右上腹或脐旁腊肠样肿块及右髂窝空虚感。
4. 立即安排腹部超声,必要时联系空气或氧气灌肠团队作诊断兼治疗。
5. 发病不超过 24 小时时优先转急诊,并提前告知可能需要手术干预。

**注意事项 / Precautions**
- 超过 24 小时后发病率和死亡率明显增加,不得延迟观察。
- 易与急性胃肠炎混淆,但若水样便不多而阵发性疼痛明显,应优先按肠套叠处理。
- 4~12 岁儿童还需考虑息肉或梅克尔憩室等病理性诱因。

**量化指标 / Metrics**
- 发病至转诊时间
- 超声确诊完成率
- 非手术复位成功率
