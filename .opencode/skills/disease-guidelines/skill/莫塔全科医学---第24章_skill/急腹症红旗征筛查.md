# Skill: 急腹症红旗征筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第24章 腹痛
- 页码: 第24章“急腹症的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第24章.md`

**目标 / Objective**
在初诊时快速识别需要紧急转诊或住院处理的腹痛病人。

**适用范围 / Scope**
- 所有急性腹痛或病情不明的腹痛病人

**操作步骤 / Procedure**
1. 询问是否存在厕所晕倒、头晕、月经异常、未排气、进行性呕吐腹胀及恶性肿瘤病史。
2. 测量生命体征,重点识别低血压、心房颤动、心动过速和发热。
3. 查体判断是否有苍白出汗、虚脱、反跳痛、拒按和尿量减少。
4. 对老年、房颤、动脉硬化及孕龄女性,优先排查肠系膜缺血、血管灾难和异位妊娠。
5. 任一红旗征阳性时,停止门诊观察策略并立即安排急诊评估或外科转诊。

**注意事项 / Precautions**
- 危险病因可在早期仅表现为腹痛,不要被短暂缓解所误导。
- 女性下腹痛必须保留异位妊娠诊断,即使有避孕史或自诉“来过月经”。
- 老年、肥胖、重病和使用类固醇者体征可不典型。

**量化指标 / Metrics**
- 急腹症红旗征记录率
- 红旗征阳性病人急诊转运率
- 危重腹痛漏诊率
