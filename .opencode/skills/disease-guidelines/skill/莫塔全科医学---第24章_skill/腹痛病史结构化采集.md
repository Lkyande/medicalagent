# Skill: 腹痛病史结构化采集

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第24章 腹痛
- 页码: 第24章“病史”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第24章.md`

**目标 / Objective**
通过标准化提问明确腹痛性质、危险线索和可能病因范围。

**适用范围 / Scope**
- 急性、亚急性、慢性或复发性腹痛病人

**操作步骤 / Procedure**
1. 明确疼痛的部位、放射方向、持续性或阵发性特点及严重程度评分。
2. 询问既往是否有类似发作,以及疼痛出现时伴随的恶心、呕吐、出汗、畏寒等症状。
3. 追问便秘、腹泻、便血、排尿异常、烧灼感和近期月经或避孕情况。
4. 记录药物使用,尤其是阿司匹林、NSAIDs、酒精、烟草和违禁药物摄入。
5. 补充旅行史、腹部手术史、疝史及家族中是否有类似腹痛发作。

**注意事项 / Precautions**
- 女性病人腹痛评估必须主动问月经和妊娠相关问题。
- “进食、牛奶、抗酸剂是否影响疼痛”常有定位价值,不应省略。
- 仅记录“腹痛”而不描述时间演变和伴随症状,容易错过阑尾炎等进行性疾病。

**量化指标 / Metrics**
- 腹痛病史要素完整率
- 女性腹痛妊娠相关问题询问率
- 初诊后诊断修正率
