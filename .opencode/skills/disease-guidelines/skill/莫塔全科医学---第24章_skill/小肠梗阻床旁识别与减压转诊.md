# Skill: 小肠梗阻床旁识别与减压转诊

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第24章 腹痛
- 页码: 第24章“小肠梗阻”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第24章.md`

**目标 / Objective**
快速识别小肠梗阻并启动液体复苏、胃肠减压和外科处理流程。

**适用范围 / Scope**
- 中腹绞痛、呕吐、腹胀和停止排便排气的病人

**操作步骤 / Procedure**
1. 根据严重绞痛、频繁呕吐、腹胀及无排便无排气识别小肠梗阻特征。
2. 追问既往剖腹手术史、疝病史和可能的异物或胆结石病史。
3. 查体寻找可见肠蠕动、高调肠鸣音、脱水征和所有疝口的绞窄表现。
4. 安排立位腹部 X 线寻找阶梯状液平,必要时补充 CT 判断肠外原因。
5. 立即开始静脉补液和鼻胃管减压,并同步联系外科准备手术或疝修补。

**注意事项 / Precautions**
- 绞窄性梗阻时腹部可不再柔软,病情会迅速恶化。
- 儿童和老年人脱水进展更快,需更积极复苏。
- 忽略疝口检查是常见失误,尤其要检查脐疝和腹股沟疝。

**量化指标 / Metrics**
- 梗阻病例补液启动时间
- 鼻胃管减压完成率
- 疝口检查记录率
