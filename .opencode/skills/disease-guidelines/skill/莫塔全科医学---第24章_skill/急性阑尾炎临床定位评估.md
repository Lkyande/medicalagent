# Skill: 急性阑尾炎临床定位评估

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第24章 腹痛
- 页码: 第24章“急性阑尾炎”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第24章.md`

**目标 / Objective**
通过典型病程演变和局部体征识别急性阑尾炎并区分常见变异位置。

**适用范围 / Scope**
- 怀疑急性阑尾炎的儿童或成人腹痛病人

**操作步骤 / Procedure**
1. 询问疼痛是否从腹中央开始并在约 6 小时内转移至右髂窝。
2. 记录是否伴突发厌食、随后出现恶心或呕吐,并判断疼痛是否随走路或咳嗽加重。
3. 查体寻找麦氏点压痛、局部强直、反跳痛和拒按。
4. 根据特殊体征判断变异位置:腰大肌征提示盲肠后位,闭孔征和尿频腹泻提示盆腔阑尾。
5. 结合血常规、CRP、超声或 CT 结果,对高度怀疑者立即转外科评估。

**注意事项 / Precautions**
- 老年、妊娠、糖尿病及年幼儿童表现常不典型,但穿孔风险更高。
- 腹泻不能排除阑尾炎,尤其是盆腔阑尾时易误诊为胃肠炎。
- 阑尾炎本质上仍是临床诊断,影像阴性不能完全替代动态复查。

**量化指标 / Metrics**
- 阑尾炎三联征记录率
- 高度怀疑病例外科转诊率
- 穿孔性阑尾炎比例
