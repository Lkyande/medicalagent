# Skill: 腹痛体格检查顺序执行

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第24章 腹痛
- 页码: 第24章“身体检查”“指导原则”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第24章.md`

**目标 / Objective**
按规范顺序完成腹痛查体,提高腹膜炎、疝和牵涉痛等关键体征的检出率。

**适用范围 / Scope**
- 需要进行腹部查体的腹痛病人

**操作步骤 / Procedure**
1. 先评估一般外观和生命体征,再检查胸部以排除心肺源性上腹痛。
2. 让病人平卧暴露剑突至腹股沟,依次进行视诊、听诊、触诊和叩诊。
3. 触诊从疼痛较轻区域开始,逐步寻找腹肌紧张、反跳痛和最明显压痛点。
4. 检查腹股沟和疝口、必要时做直肠检查及女性阴道检查。
5. 根据临床需要补充墨菲征、腰大肌试验、闭孔试验和尿液床旁分析。

**注意事项 / Precautions**
- 听诊应在触诊和叩诊前完成,避免人为改变肠鸣音。
- 老年、肥胖、重病和激素使用者体征可能轻微,不能因腹部“软”而放松警惕。
- 上腹痛在腹部体征不明显时,必须回头检查心脏和肺部。

**量化指标 / Metrics**
- 腹部查体顺序规范率
- 疝口检查完成率
- 腹膜刺激征记录率
