# Skill: 儿童就诊建立融洽关系

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第83章 给儿童看病的方法
- 页码: 第83章“与孩子的互动”“其他建立融洽关系的策略”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第83章.md`

**目标 / Objective**
在儿童就诊开始阶段迅速建立孩子和家长的安全感与合作关系。

**适用范围 / Scope**
- 婴幼儿、学龄前儿童及学龄儿童门诊就诊场景

**操作步骤 / Procedure**
1. 从候诊室叫名字时就开始与孩子和家长互动。
2. 同时问候家长和孩子,询问孩子喜欢怎样被称呼、年龄和兴趣。
3. 与孩子保持同一高度交流,避免居高临下。
4. 借助玩具、贴纸、泡泡和熟悉的话题降低陌生感。
5. 把孩子当作独立个体而不是仅仅一个“病例”来对待。

**注意事项 / Precautions**
- 赢得父母支持往往有助于赢得孩子合作。
- 年龄不同,沟通方式应从依恋、游戏到具体话题逐步调整。
- 对特殊需要儿童要额外注意尊重和节奏。
**量化指标 / Metrics**
- 儿童就诊初始互动记录率
- 儿童配合度提升率
- 家长满意度
