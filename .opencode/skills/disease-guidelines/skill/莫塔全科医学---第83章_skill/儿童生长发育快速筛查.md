# Skill: 儿童生长发育快速筛查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第83章 给儿童看病的方法
- 页码: 第83章“生长和发育”“表83.1 接种疫苗时检查发育节点”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第83章.md`

**目标 / Objective**
在常规门诊或免疫访视中快速发现儿童生长和发育偏离。

**适用范围 / Scope**
- 新生儿、婴儿及儿童预防保健或普通门诊复诊

**操作步骤 / Procedure**
1. 每次访视记录体重、身长/身高和头围,并绘制到生长曲线。
2. 快速询问大运动、精细运动、言语沟通和社交四个方面节点。
3. 比较当前百分位是否跨越明显通道或出现倒退。
4. 对照年龄节点判断是否需要进一步标准化筛查或专科评估。
5. 将发育结果与喂养、家庭和既往病史综合解读。

**注意事项 / Precautions**
- 纵向监测比单次筛查更可靠。
- 任何发育倒退都是红旗征。
- 生长图解释要结合早产、种族和喂养背景。

**量化指标 / Metrics**
- 儿童访视生长参数记录率
- 四领域快速筛查完成率
- 红旗征转介率
