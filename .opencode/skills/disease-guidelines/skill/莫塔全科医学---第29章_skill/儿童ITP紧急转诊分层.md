# Skill: 儿童ITP紧急转诊分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第29章 淤血与出血
- 页码: 第29章“特发性(免疫性)血小板减少性紫癜”“小童期急性血小板减少症”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第29章.md`

**目标 / Objective**
识别儿童急性 ITP 的高危出血风险并决定门诊观察还是住院转诊。

**适用范围 / Scope**
- 儿童瘀点瘀斑、鼻出血、牙龈出血或病毒感染后血小板减少者

**操作步骤 / Procedure**
1. 识别典型表现:急性发病、广泛瘀点瘀斑、鼻出血或牙龈出血,但无明显全身病。
2. 查体确认无脾大和其他异常系统体征,避免漏诊白血病等继发病因。
3. 通过外周血涂片和血小板计数确认孤立性血小板减少。
4. 若血小板 <30×10^9/L 或存在活动性出血,立即转诊或住院观察。
5. 必要时在专科指导下使用免疫球蛋白或糖皮质激素,并解释多数病例可在 6 个月内自限恢复。

**注意事项 / Precautions**
- 需先排除急性白血病和再生障碍性贫血等严重病因。
- 90% 儿童病例预后良好,但早期仍有自发性出血风险。
- 复发可见于后续病毒感染后,需向家属提前说明。

**量化指标 / Metrics**
- 高危患儿住院转诊率
- 血涂片完成率
- 6 个月内血小板恢复率
