# Skill: 脾切除术后感染预防

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第29章 淤血与出血
- 页码: 第29章“脾切除术后管理”“预防性的治疗”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第29章.md`

**目标 / Objective**
降低脾切除病人的暴发性感染和术后血栓并发症风险。

**适用范围 / Scope**
- 计划脾切除或已完成脾切除的儿童和成人病人

**操作步骤 / Procedure**
1. 围手术期监测术后 2~3 周内血小板升高,警惕血栓栓塞风险。
2. 对择期手术病人至少在术前 2 周完成肺炎球菌、脑膜炎球菌和 Hib 疫苗接种计划。
3. 术后建立长期免疫计划:肺炎球菌和脑膜炎球菌每 5 年加强,流感每年接种。
4. 对高风险病人安排长期青霉素或阿莫西林预防。
5. 教育病人一旦发热或感染征象出现需紧急就医,并特别提醒疟疾风险。

**注意事项 / Precautions**
- 2 岁以下幼儿术后感染风险尤其高。
- 妊娠时避免某些疫苗接种,需提前规划时间。
- 教育和急诊就医提醒与疫苗同样重要。

**量化指标 / Metrics**
- 术前疫苗完成率
- 年度流感疫苗接种率
- 术后严重感染发生率
