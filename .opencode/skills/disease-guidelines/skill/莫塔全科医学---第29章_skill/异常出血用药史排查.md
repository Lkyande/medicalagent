# Skill: 异常出血用药史排查

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第29章 淤血与出血
- 页码: 第29章“用药史”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第29章.md`

**目标 / Objective**
识别药物诱发或加重的出血问题,避免将可逆性药源性出血误诊为原发血液病。

**适用范围 / Scope**
- 所有异常出血、瘀斑或血小板减少病人

**操作步骤 / Procedure**
1. 逐一核对处方药、非处方药、保健品和近期临时用药。
2. 重点识别阿司匹林、NSAIDs、华法林、直接口服抗凝剂和肝素等止血相关药物。
3. 关注可能引发血小板减少的药物,如卡马西平、丙戊酸钠、青霉素、万古霉素和噻嗪类利尿剂。
4. 结合出血模式判断是血小板功能异常、血小板减少还是凝血因子抑制。
5. 对可疑药物及时停用或替换,并安排复查血小板和凝血功能。

**注意事项 / Precautions**
- 非处方产品如银杏叶也可能影响止血,不能只问处方药。
- 药物可暴露潜在的轻型凝血障碍,例如阿司匹林诱发潜在 vWD 出血。
- 在停药前需评估原始适应证风险,尤其是抗凝治疗病人。

**量化指标 / Metrics**
- 完整用药史记录率
- 药源性出血识别率
- 停药后出血改善率
