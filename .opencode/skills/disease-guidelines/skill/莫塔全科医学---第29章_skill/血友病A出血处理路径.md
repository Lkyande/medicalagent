# Skill: 血友病A出血处理路径

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第29章 淤血与出血
- 页码: 第29章“血友病 A”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第29章.md`

**目标 / Objective**
识别血友病 A 的关节和肌肉出血模式并尽快进入因子替代治疗路径。

**适用范围 / Scope**
- 男性病人自发性关节积血、肌肉血肿或术后迟发性出血者

**操作步骤 / Procedure**
1. 识别膝、踝、肘等大关节自发性积血以及肌肉血肿这一典型模式。
2. 结合 X 连锁家族史和实验室表现,如 aPTT 延长而 PT 与纤维蛋白原正常。
3. 申请凝血因子 VIII 检测明确严重度分层。
4. 出血发作时尽快转入重组凝血因子 VIII 浓缩物替代治疗。
5. 明确告知禁用阿司匹林,并为后续手术、创伤和家庭遗传咨询预作安排。

**注意事项 / Precautions**
- 低血小板不符合单纯血友病 A 表现,需考虑其他并存疾病如 HIV 相关 ITP。
- 迟发性创伤后出血是重要线索,不能因初始止血成功而掉以轻心。
- 女性携带者家庭也需遗传咨询。

**量化指标 / Metrics**
- 出血发作至因子治疗时间
- 关节积血控制率
- 阿司匹林误用率
