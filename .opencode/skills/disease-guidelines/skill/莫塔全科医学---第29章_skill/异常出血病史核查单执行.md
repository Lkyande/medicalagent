# Skill: 异常出血病史核查单执行

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第29章 淤血与出血
- 页码: 第29章“出血史核查单”“关键的提问”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第29章.md`

**目标 / Objective**
通过系统病史核查快速区分血管性、血小板性和凝血因子性出血倾向。

**适用范围 / Scope**
- 淤青增多、鼻出血、牙龈出血、月经过多或术后异常出血病人

**操作步骤 / Procedure**
1. 依次核查皮肤淤血、鼻出血、牙龈出血、血尿、直肠出血和月经过多等部位出血史。
2. 询问外伤后是否易淤血,以及拔牙、分娩、扁桃体切除或其他手术后的出血情况。
3. 追问是否有家庭成员出现类似淤血、出血或关节血肿。
4. 记录发热、体重减轻、夜汗、病毒感染或咽痛等伴随线索。
5. 将病史与黏膜出血、关节血肿或迟发性创伤出血模式对应,初步分型后安排检查。

**注意事项 / Precautions**
- 既往手术和拔牙后的出血史价值很高,不能遗漏。
- 儿童异常淤血必须同时考虑非意外损伤和虐待可能。
- 轻度 vWD 病人可长期未被识别,需主动追问月经过多和鼻出血。

**量化指标 / Metrics**
- 出血病史核查完整率
- 家族史记录率
- 初诊分型与最终诊断一致率
