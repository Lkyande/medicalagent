# Skill: 血管性血友病识别与围手术提醒

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第29章 淤血与出血
- 页码: 第29章“血管性血友病”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第29章.md`

**目标 / Objective**
识别轻型 vWD 并在手术、牙科和月经管理前采取安全预案。

**适用范围 / Scope**
- 月经过多、鼻出血、黏膜出血或术后出血异常病人

**操作步骤 / Procedure**
1. 识别黏膜皮肤出血模式,重点追问月经过多、鼻出血和创口出血延长。
2. 结合家族史和 aPTT 延长、vWF 抗原和活性降低等检查支持诊断。
3. 叮嘱病人避免阿司匹林、NSAIDs 和不必要肌内注射。
4. 对拟拔牙、手术或分娩病人提前制定止血方案并转血液科会诊。
5. 必要时在专科指导下使用去氨加压素、凝血因子浓缩物或氨甲环酸。

**注意事项 / Precautions**
- 关节血肿少见,若反复关节出血需考虑血友病而非单纯 vWD。
- 轻症病人平时可能仅表现为月经过多,容易长期漏诊。
- 用药和围手术计划需提前沟通,不能到出血后再被动处理。

**量化指标 / Metrics**
- 围手术预案建立率
- NSAIDs/阿司匹林避免率
- 出血并发症发生率
