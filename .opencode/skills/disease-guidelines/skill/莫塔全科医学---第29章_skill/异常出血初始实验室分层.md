# Skill: 异常出血初始实验室分层

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第29章 淤血与出血
- 页码: 第29章“辅助检查”“实验室辅助检查清单”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第29章.md`

**目标 / Objective**
用基础实验室检查快速区分血小板问题、凝血异常和系统性继发病因。

**适用范围 / Scope**
- 需要评估出血倾向的门诊或急诊病人

**操作步骤 / Procedure**
1. 首轮开立全血细胞计数、血涂片、PT/INR、aPTT 和 TT。
2. 结合血小板计数与血涂片判断是否存在血小板减少或形态异常。
3. 若怀疑凝血缺陷,加测纤维蛋白原和特异凝血因子检查。
4. 若疑似遗传性出血病,进一步申请因子 VIII、vWF 活性和 vWF 抗原。
5. 同时根据病情补充 ESR/CRP、肝肾功能、血清电泳和尿检,寻找继发原因。

**注意事项 / Precautions**
- 假性血小板减少症可由实验室误差造成,需通过血涂片和重复采血排除。
- 骨髓检查适用于排除继发性血小板减少,不作为所有病人的首轮检查。
- 检验结果必须结合出血模式解释,不能只凭单项异常下结论。

**量化指标 / Metrics**
- 基础止血检查完成率
- 假性血小板减少纠正率
- 初始实验室分层准确率
