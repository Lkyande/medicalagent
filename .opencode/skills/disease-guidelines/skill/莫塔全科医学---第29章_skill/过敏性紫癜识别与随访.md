# Skill: 过敏性紫癜识别与随访

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第29章 淤血与出血
- 页码: 第29章“过敏性紫癜”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第29章.md`

**目标 / Objective**
识别儿童 IgA 血管炎的典型三联征并及时监测肾脏受累。

**适用范围 / Scope**
- 儿童下肢可触及紫癜、关节痛或腹痛病人

**操作步骤 / Procedure**
1. 识别臀部和下肢为主的可触及紫癜分布,并追问近期上呼吸道感染史。
2. 评估是否伴踝膝关节炎、绞痛性腹痛、便血或阴囊受累。
3. 首轮检查全血细胞计数和尿检,确认血小板正常并筛查血尿蛋白尿。
4. 对腹痛明显者在排除肠套叠后给予对症镇痛并可短期使用糖皮质激素。
5. 若出现血尿或病程迁延,持续随访尿沉渣和肾功能直至恢复。

**注意事项 / Precautions**
- HSP 的严重并发症是肾炎和慢性肾病,皮疹消退后仍需随访。
- 血小板异常时要考虑其他诊断而非 HSP。
- 腹痛合并便血时需警惕肠套叠。

**量化指标 / Metrics**
- 尿检随访完成率
- 肾脏受累早期识别率
- 并发肠套叠识别率
