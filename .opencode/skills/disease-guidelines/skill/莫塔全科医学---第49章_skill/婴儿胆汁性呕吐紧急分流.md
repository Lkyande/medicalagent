# Skill: 婴儿胆汁性呕吐紧急分流

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第49章 恶心和呕吐
- 页码: 第49章“婴儿的呕吐”“新生儿的重要警示性征象”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第49章.md`

**目标 / Objective**
将婴儿胆汁性呕吐作为肠梗阻和肠扭转信号进行时间敏感型急诊分流。

**适用范围 / Scope**
- 新生儿和婴儿出现绿色或胆汁染色呕吐时

**操作步骤 / Procedure**
1. 确认呕吐物是否为绿色或明显胆汁染色,不要仅以“吐奶”概括。
2. 立即联想到肠扭转、胎粪性肠梗阻和十二指肠或小肠闭锁等外科病因。
3. 同步评估胎粪排出延迟、腹胀、腹股沟疝和过多泡沫样口腔分泌物。
4. 在禁食、补液和基础稳定支持下尽快联系儿童外科急诊。
5. 以数小时内完成影像和手术评估为目标转运,避免门诊观察延误。

**注意事项 / Precautions**
- 婴儿胆汁性呕吐通常不正常,必须优先按外科急症处理。
- 肠扭转存在短时间肠坏死风险,延误可显著恶化预后。
- 即使生命体征暂时稳定也不能排除危险病因。

**量化指标 / Metrics**
- 胆汁性呕吐识别率
- 从首诊到外科评估时间
- 外科急症延误率
