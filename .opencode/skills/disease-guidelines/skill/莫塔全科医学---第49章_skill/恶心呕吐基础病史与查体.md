# Skill: 恶心呕吐基础病史与查体

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第49章 恶心和呕吐
- 页码: 第49章“病史”“身体检查”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第49章.md`

**目标 / Objective**
用系统化问诊和查体快速定位恶心呕吐的胃肠、全身或神经系统病因。

**适用范围 / Scope**
- 门急诊恶心、干呕或呕吐病人

**操作步骤 / Procedure**
1. 询问用药史、酒精或毒物暴露、人为催吐、体重变化和伴随胃肠症状。
2. 根据呕吐物性质判断线索,如粪臭味提示肠梗阻,咖啡渣样提示上消化道出血。
3. 查找感染灶,包括中耳、脑膜和泌尿道等儿童常见源头。
4. 完成腹部检查并查看既往手术瘢痕,注意振水音和腹胀表现。
5. 评估脱水、神经系统体征、眼底和女性妊娠可能,必要时补充尿液分析。

**注意事项 / Precautions**
- 完整用药史对识别药物性呕吐十分关键。
- 女性育龄期病人默认需考虑妊娠,不要等到病人主动提及。
- 牙齿酸蚀提示暴食症或长期人为催吐。

**量化指标 / Metrics**
- 呕吐病史完整率
- 腹部检查完成率
- 妊娠相关筛查覆盖率
