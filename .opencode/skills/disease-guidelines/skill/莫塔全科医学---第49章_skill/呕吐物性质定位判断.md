# Skill: 呕吐物性质定位判断

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第49章 恶心和呕吐
- 页码: 第49章“诊断指南”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第49章.md`

**目标 / Objective**
利用呕吐物性质和伴随特征进行病变部位与病因初步定位。

**适用范围 / Scope**
- 已发生实际呕吐且可描述呕吐特征的病人

**操作步骤 / Procedure**
1. 无胆汁呕吐时优先考虑幽门梗阻等近端胃出口问题。
2. 呕吐胆汁时判断为十二指肠球部以下梗阻可能较高。
3. 呕吐刚摄入食物时考虑食管梗阻或上消化道动力异常。
4. 喷射状且不伴恶心时要警惕颅内压升高。
5. 结合腹痛、有无腹胀和神经系统症状决定后续影像和急诊分流。

**注意事项 / Precautions**
- 呕吐定位只是线索,必须结合查体和病程判断。
- 胆汁性呕吐在婴儿尤其危险,不能按普通胃肠炎观察。
- 喷射状呕吐也可见于婴儿幽门狭窄,要按年龄解读。

**量化指标 / Metrics**
- 呕吐特征记录率
- 定位判断与最终诊断一致率
- 胆汁性呕吐急诊分流率
