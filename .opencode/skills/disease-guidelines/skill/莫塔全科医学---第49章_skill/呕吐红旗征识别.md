# Skill: 呕吐红旗征识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第49章 恶心和呕吐
- 页码: 第49章“呕吐的红旗征”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第49章.md`

**目标 / Objective**
快速识别提示低血容量、腹膜炎或颅内病变的高危呕吐表现。

**适用范围 / Scope**
- 所有急性或持续性恶心呕吐病人

**操作步骤 / Procedure**
1. 观察是否存在明显苍白和其他循环不稳定表现。
2. 评估有无低血容量体征,如口干、心动过速、体位性不适或尿量减少。
3. 检查腹部有无腹膜刺激征和鼓样膨隆。
4. 问诊和查体是否存在头痛、颈部僵硬、神志不清等中枢神经系统危险信号。
5. 红旗征阳性时立即升级急诊评估,优先处理复苏和潜在外科或神经系统病因。

**注意事项 / Precautions**
- 无腹痛可降低外科腹部病因可能,但不能排除严重中枢或代谢病因。
- 单纯止吐不能替代对腹膜炎、肠梗阻或颅压升高的处置。
- 婴幼儿和老年人更容易因呕吐快速出现严重脱水。

**量化指标 / Metrics**
- 呕吐红旗征记录率
- 红旗征阳性病例急诊转诊率
- 严重病因漏诊率
