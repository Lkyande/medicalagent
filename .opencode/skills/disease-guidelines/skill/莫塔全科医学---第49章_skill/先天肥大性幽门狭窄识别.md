# Skill: 先天肥大性幽门狭窄识别

**来源 / Source**
- 文章标题: 莫塔全科医学（第8版） 第49章 恶心和呕吐
- 页码: 第49章“先天肥大性幽门狭窄”相关段落
- DOI/URL: 文件来源 `莫塔全科医学---第49章.md`

**目标 / Objective**
识别典型婴儿幽门狭窄表现并启动纠正脱水后外科处理路径。

**适用范围 / Scope**
- 3 至 6 周婴儿出现喷射性非胆汁性呕吐时

**操作步骤 / Procedure**
1. 识别第 3 至 6 周突然出现的喷射状、非胆汁性呕吐病史。
2. 评估体重增长停滞、脱水和喂养后胃蠕动由左向右通过上腹部的表现。
3. 在喂养试验中或呕吐后立即触诊右上腹深部是否有“幽门橄榄”样肿块。
4. 必要时用腹部超声或钡餐进一步证实,并检查低氯性代谢性碱中毒。
5. 先纠正液体和电解质紊乱,再转外科行幽门环肌切开术。

**注意事项 / Precautions**
- 触及典型幽门肿块时通常无需再追求过多额外检查。
- 术前复苏和纠正低氯性碱中毒比立即手术更关键。
- 胆汁性呕吐不符合典型幽门狭窄,应改按远端梗阻评估。

**量化指标 / Metrics**
- 幽门狭窄早期识别率
- 术前电解质纠正完成率
- 首诊到外科转诊时间
